# 현행 파이프라인 명세 (프로덕션 실제 동작)

> 🔴 **이 디렉터리는 "무엇이 돌고 있는가"를 적습니다. "무엇이 옳은가"가 아닙니다.**
>
> 레포의 다른 문서는 설계·규격이고, 여기는 **현재 코드가 실제로 하는 일**입니다.
> 둘이 어긋나는 것이 정상이며, 그 갭을 `IM_PIPELINE_UPGRADE.md`(D23)가 다룹니다.

| | |
|---|---|
| **편입** | 2026-08-25 (D25 §T3) |
| **갱신 주체** | **개발팀** — 코드가 바뀌면 여기를 고칩니다 |
| **정본 여부** | ✗ 규칙의 정본이 아닙니다. 현행 기록입니다 |

## 왜 레포에 넣었는가

편입 전까지 **이 세 문서가 레포 밖에 있었습니다.** 그래서 레포는 이상적인 설계를
말하고 프로덕션은 다르게 돌았습니다. D23이 갭을 실측했지만, **기준이 되는 현행
명세 자체가 없으면 갭 문서만으로는 아무것도 확인할 수 없습니다.**
