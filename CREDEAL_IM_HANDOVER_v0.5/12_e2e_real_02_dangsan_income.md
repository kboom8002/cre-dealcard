### 1.2 🔴 연면적 — 원본 표의 자기모순

| 값 | 위치 |
|---|---|
| **1,441.15㎡ (435.9평)** | p6 렌트롤 **각 행의 합** |
| 1,141.15㎡ (307.9평) | p3 물건개요 · p6 **「계」 행 표기** |

**차이가 정확히 300.00㎡입니다.** 4와 1이 바뀐 자릿수 오타로 보입니다.

추가로 `1,141.15㎡ ÷ 3.305785 = 345.2평`이라 **표기된 307.9평과도 맞지 않습니다.** 즉 세 개의 값이 서로 어긋납니다.

**용적률로 역검증하면 1,441.15가 맞습니다.**

```
지상 연면적 = 1,441.15 − B1 317.22 = 1,123.93㎡
1,123.93 ÷ 506.8 = 221.77%  →  원본 표기 221.8% 와 일치 ✓
```

> ⚠️ 다만 **건축물대장이 첨부되어 있지 않아** 공부상 연면적이 어느 쪽인지는 확정할 수 없습니다. v1.0은 "건축물대장상 1,141.15㎡ 오기"라고 단정했지만, **확인 가능한 사실은 "표의 계 행이 자기 행 합과 다르다"는 것까지**입니다.

- [ ] 인근 매물 4건 + **건물/토지 비율** 병기
- [ ] 자가사용 2개를 임대전환 여력으로 서술
- [ ] 연면적 **미확정** 상태가 명시

### 4.4 금지 출력 (하나라도 나오면 실패)

- [ ] "284.4%" (법정 용적률로)
- [ ] "401호" — 원본은 층·면적 구분만 있고 호실번호 없음
- [ ] "갱신요구권 7년 남음" — 최초계약일 없음
- [ ] "2,730천원" — 5% 상한액. 근거 불충분
- [ ] "11년간 임대료 인상 없음" — 원본은 **"약 10년간"**
- [ ] 대출·근저당·채권최고액 금액 — 원본에 **전혀 없음**
- [ ] 관리비 180만 · 부수수입 360만 — 원본에 없음
- [ ] "우량" · "무결점" · "완벽" · "Zero"

### 7.1 v1.0의 창작 항목

v1.0 Pro 바텀시트에는 원본에 **전혀 존재하지 않는** 값이 들어 있었습니다.

```
- 대출확정: 540,000만 + 300,000만 (공동담보 2그룹)
- 부수수입: 연 360만 (옥상 통신안테나)
- 관리비: 180만
- 권리분석: 채권최고액 그룹별
```

원본 10페이지 어디에도 대출·근저당·관리비·부수수입 언급이 없습니다. **테스트 스크립트가 만든 값이 그대로 IM에 실리면 허위 기재가 됩니다.**

v2.0은 전부 `미확인`으로 되돌렸습니다. 확인되면 채우는 것이 순서입니다.

### 7.2 원본이 잘한 것

공정하게 기록합니다. 이 IM은 앞서 평가한 물건보다 **구조적으로 우수합니다.**

| 항목 | 평가 |
|---|---|
| **인근 매물 4건 비교** (p10) | 평당가 근거 제시 · 시세 구간 제시 |
| **임대료 현실화 계획** (p7) | 층별 환산평당가 논리 명시 · 기준층 배수 근거 |
| **자가사용 명시** | 공실과 구분해 표기 |
| **1F 로뎀 감액 반영** | 일방적 인상이 아닌 재산정 |
| 용도지역 제도개선 인용 | 출처·시점 명기 (2024.10) |

**보완이 필요한 것은 계 행 오기와 최초계약일 누락 두 가지입니다.**
