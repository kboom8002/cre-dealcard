## 1. Basic과 Pro는 다른 문서입니다

같은 물건의 두 버전이 아니라 **다른 목적의 두 문서**입니다.

| | Basic | Pro |
|---|---|---|
| **읽는 사람** | 아직 관심만 있는 사람 | 검토를 시작한 사람 |
| **답해야 할 질문** | "볼 만한 물건인가" | "얼마에 왜 사야 하는가" |
| **성공** | 상세 요청 | 현장 실사 요청 |
| **어휘** | B2C — 쉬운 말 | 실무 — 정확한 말 |
| **분량** | **3문 + 4접기** | **9문** + 부속 |
| **배포** | 링크 공유 가능 | **지정 열람** |
| **틀리면** | 관심을 잃음 | **분쟁이 됨** |

마지막 줄이 설계를 가릅니다. **Pro는 정확성이 우선이고 Basic은 이해가 우선입니다.**

## 2. 노출 3단 — 딜카드 → Basic → Pro

```
딜카드   전부 밴드 · 권역까지 · 상세 요청 유도
  ↓  상세 요청
Basic    주요값 실수치 · 동까지 · 층별 요약 · 리스크 요약
  ↓  NDA · grant
Pro      전부 실수치 · 지번 · 호실별 · 법적 판정 · 자료등급 공개
```

### 2.1 단계별 공개 표

| 항목 | 딜카드 | Basic | Pro |
|---|---|---|---|
| 주소 | 권역 | **동까지** | **지번** |
| 매각가 | 밴드 | **실수치** | 실수치 |
| 수익률 | 밴드 1종 | **실수치 1종 + 기준** | **기준별 전체** |
| 대지·연면적 | 밴드 | 실수치 | 실수치 |
| 층별 구성 | 층수만 | **층별 요약** | **호실별 전체** |
| 임대차 | 공실 개수 | 총계 | **호실별 계약·만기** |
| 임대차 법적 지위 | ✗ | ✗ | **○ (T-C / T-R)** |
| 권리·등기 | ✗ | 요약 | **채권최고액·공동담보** |
| 취득 부대비용 | ✗ | ✗ | **○** |
| 자료등급 | **✗** | ✗ | **○** |
| DCF·민감도 | ✗ | ✗ | **A등급에서만** |

### 2.2 자료등급은 Pro에서만 밝힙니다

딜카드에서는 **감췄고**(매수자가 등급 체계를 모름), Pro에서는 **밝힙니다.**

> Pro를 보는 사람은 이미 NDA를 썼고 검토 중입니다. **이 자료가 무엇에 근거하는지 알 권리가 있고, 밝히는 편이 신뢰를 얻습니다.** 골든판 ⑧문이 이 역할입니다.

Basic에는 넣지 않습니다 — 아직 판단 단계가 아니라 관심 단계이고, 등급 설명에 지면을 쓸 여유가 없습니다.

## 3. Basic — 구조

> ⚠️ **이 절은 `MOBILE_IM_BASIC_PLAN.md`가 대체합니다.**
> 재검토 결과 7문 평면 구조는 "30초 판단"이라는 목적과 어긋났습니다. **3문 펼침 + 4문 접기**로 개정되었으며, 첫 숫자도 매각가 → 실투자금으로 바뀌었습니다.
> 아래 7문은 **이력으로만 남깁니다.**

기준판의 질문형 구조입니다. **질문이 곧 제목**인 것이 이 문서의 성격을 만듭니다.

| # | 질문 | 담는 것 |
|---:|---|---|
| ① | 이 건물, 어떤 자산인가? | 대지·연면적·규모·준공·건폐율/용적률·주차 |
| ② | 입지, 투자할 만한 곳인가? | 용도지역·상한·도로접면·역세권·공시지가 |
| ③ | 임대 현황과 공실은? | 층별 요약·공실률·총 보증금/월세 |
| ④ | 수익률, 진짜 나오는 딜인가? | 수익률 1종 + **기준 명시** · 실투자금 |
| ⑤ | 숨은 리스크는 없는가? | 상위 3건 — 감추지 않습니다 |
| ⑥ | 왜 지금 이 매물인가? | 관점별 핵심 논리 (§5) |
| ⑦ | 다음 단계는? | 상세 요청 CTA · 중개인 |

### 3.1 ⑤가 ⑥ 앞에 오는 이유

**리스크를 먼저 말하고 나서 사야 할 이유를 말합니다.** 순서를 바꾸면 설득 후 변명처럼 읽힙니다. 먼저 밝힌 약점은 신뢰를 만들고, 나중에 발견된 약점은 신뢰를 깎습니다.

### 3.2 히어로 카드

```
┌────────────────────────────────┐
│ 임대수익률      1.86%   ⚙실투자금 기준 │
│ 연 임대수입     0.72억  ● 중개인      │
│ 실투자금        38.7억  ⚙가정        │
│   계산: 42억 − 보증금 3.3억            │
│ 계약 잔여 평균   2.4년   ★ 전문가      │
└────────────────────────────────┘
```

**계산 과정을 한 줄로 노출**합니다. 결과만 주면 검증할 수 없고, 검증할 수 없는 숫자는 믿지 않습니다.

### 4.2 ⑧이 마지막 문인 이유

자료의 한계를 **끝에서 밝힙니다.** 앞에 두면 "부실한 자료"라는 인상으로 나머지를 읽게 되고, 없으면 과신하게 됩니다.

## 6. 반드시 고쳐야 할 것 — 기준판의 오류

### 6.1 🔴 대항력 "무" 표기 — 법적으로 틀립니다

기준판 Pro 렌트롤의 대항력 컬럼이 **전 호실 "무"** 입니다.

```
층    업종    전용    보증금   월세    만기      대항력
B1   창고    121평   0.5억   250    27.04     무      ← 틀림
1F   카페    103평   3.0억  1,300   28.09     무      ← 틀림
...
```

**대항력은 인도 + 사업자등록(주택은 주민등록)으로 성립하며, 환산보증금과 무관합니다.** 실제 영업 중인 임차인에게 대항력이 없다고 표기하면 매수인이 명도를 쉽게 볼 수 있고, 이는 거래 판단을 왜곡합니다.

```
v0.4     기본값 true. "무" 표기에는 근거를 요구합니다 (T-C-02 / T-R-02).
         근거 없이 false를 쓰면 발행이 차단됩니다 (G13).
```

> 이 오류는 온톨로지 v0.2에서 이미 `R10` 폐기·`T` 규칙군 신설로 잡았습니다. **기준판 화면에 반영이 안 되어 있을 뿐**입니다.

### 6.2 아키타입 코드 노출

```
기준판   🔧 밸류애드형   R02 · 건물연령 26년 ∧ 용적률 여유 113.9%p   [B등급]
v0.4     🔧 밸류애드형   건물연령 26년 · 용적률 여유 113%p
```

딜카드와 같은 처리입니다. **코드와 논리기호는 빼고 근거 문장은 남깁니다.** 다만 자료등급 배지는 **Pro에서만** 유지합니다 (§2.2).

### 6.3 Basic에 자료등급 노출

기준판 Basic에 `B등급` 배지가 있습니다. **제거합니다** (§2.2).

## 9. 계측 — S 신호의 유일한 근원

골든판은 `<script>` 0개입니다. Safari에서 깨졌던 원인이 `innerHTML` 주입이었기 때문인데, **계측까지 없애면 반응 신호(S)가 성립하지 않습니다** (`PRD_발행후관리.md` §8.1).

```
콘텐츠 렌더    서버 사이드 · DOM 조작 없음     ← 유지
계측 비콘      IntersectionObserver + 최소 스크립트
```

| 이벤트 | 발화 | 쓰이는 곳 |
|---|---|---|
| `view.opened` | 진입 | S03 열람률 |
| `view.section` | 섹션 3초 이상 체류 | **S01 이탈 집중** |
| `view.slider` | 조작 후 500ms | **S05 예산 하향 편중** |
| `view.completed` | 스크롤 80% | S02 완독률 |
| `intent.*` | CTA | S04 의향 |

**섹션 단위로 잡아야 "몇 번째 문에서 멈췄는지"를 알 수 있습니다.** 스크롤 깊이만으로는 원인을 특정하지 못합니다.
