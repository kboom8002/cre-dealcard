## 6. 해상도 — 정본과 픽스처가 달랐습니다

### 6.1 양평동은 R1입니다

| | |
|---|---|
| `fixtures/yangpyeong.json` | `expect.resolution: "R2"` |
| **`IM_RESOLUTION_TIERS.md` §1.3** | **R1** |
| **정본이 맞습니다** | R2는 **면적**을 요구하는데, 11행에 임대면적이 없습니다 |

**픽스처의 `expect.resolution`을 믿지 않고 규칙으로 재판정합니다.**

```python
@property
def resolution_computed(self) -> tuple[str, list[str]]:
    """R1 호실·업종·금액·만료일·임대상태
       R2 R1 + 면적·적용법령·관리비·시작일

       종합 등급은 가장 낮은 것을 따릅니다 (정본 §4.4)."""
```

## 7. 1층 비중 — 정본 수치와 일치

정본 §4.4는 **"1층 임대료 비중을 병기합니다 — 당산동 실측 54.8%"** 로 적고 있습니다.

```
당산동  1F 약국 183만 + 1F 의원(1F+2F 통합) 883만 = 1,066만
        1,066만 ÷ 1,946만 = 54.8%    ← 정본과 일치
양평동  1F 부동산 250만 ÷ 4,657만 = 5.4%
```

**양평동은 5.4%로 매우 낮습니다.** 1층 비중이 낮은 오피스 자산의 특성이며, 1층 공실 위험 노출이 작다는 뜻입니다.
