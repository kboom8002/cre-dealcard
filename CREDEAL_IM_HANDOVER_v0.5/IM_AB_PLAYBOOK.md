# A·B등급 IM 작성 플레이북

**문서번호** D22-4 · **버전** 1.0 · **작성일** 2026-08-24
**전제** 중개인 입력 충분 — L≥R2 · P≥P2
**상위** `IM_STANDARD_수익형.md` (정본) · `CREDEAL_IM_SPEC_수익형.md` v2.1
**기계 판독** `im.pages.yaml` · `im.lexicon.yaml` · `im.budget.yaml`

---

## §0 이 문서의 자리

D19가 **모든 해상도**에서 무엇을 낼 수 있는지를 정합니다. 이 문서는 **입력이 충분할 때만 쓸 수 있는 것**을 정합니다.

두 가지를 나누는 이유가 있습니다. 지금까지 규격은 "값이 없을 때 어떻게 버틸까"에 지면을 많이 썼습니다. 그것은 정확성을 지키는 일이고 잘 되어 있습니다. 그런데 **값이 다 있을 때 어떻게 잘 쓸까**는 아무 문서에도 없습니다. 결과가 "틀리지는 않지만 밋밋한 IM"입니다.

> "위의 너의 디자인과 카피는 너무 후지고 어색한 것 같은데?"

이 지적의 뿌리가 여기였습니다. 규격은 다 지켰는데 지면 문법이 없었습니다.

## §1 A·B등급이 여는 것

### 1.1 등급 판정

```
A = L≥R2 & P≥P2      B = L≥R1 & P≥P2
C = L≥R1 & P=P1      D = L=R0 or P=P0
```

| 축 | 단계 | 필요 입력 |
|---|---|---|
| L | R1 | 호실 · 업종 · 보증금 · 월세 · 만료일 · 상태 |
| L | **R2** | **+ 임대면적 · 적용 법령 · 관리비 · 계약 시작일** |
| L | R3 | + 최초 계약일 · 대항력 |
| P | P1 | 지번 |
| P | **P2** | **+ 대지면적 · 연면적 · 용도지역 · 공시지가** (공공 자동) |
| P | P3 | + 비교사례 식별 · 비교사례 대지면적 · 외부 사진 |

**P2는 지번만 넣으면 자동으로 채워집니다.** 실질 관문은 L축 R2 — 관리비와 계약 시작일입니다. 이 둘이 중개인 손에 달려 있습니다.

### 1.2 R2가 여는 블록

실측 — 당산동 R2 픽스처에서 잠긴 블록은 **13개**입니다. 그중 해상도로 열리는 것이 4개인데, **R2 진입으로 열리는 것은 2개**이고 나머지 2개는 R3까지 가야 합니다.

| 블록 | 잠금 사유 | 여는 입력 | 단계 |
|---|---|---|:-:|
| `contract_age` | 현 계약 시작일 미입력 | `rr_start` | **R2** |
| `gross_income` | 관리비·부담 주체 미입력 | `rr_mgmt` | **R2** |
| `renewal_right` | 최초 계약일 미입력 — 산출하지 않습니다 (불변조건 7) | `rr_first` | R3 |
| `opposing_power` | 대항력 요건 미입력 | `rr_opposing` | R3 |

나머지 9개는 해상도가 아니라 **중개인 판단**을 요구합니다 — 운영비·명도 책임·임대료 현실화 계획·중개인 견해. 이것들은 자동으로 열리지 않습니다.

### 1.3 A등급에서만 쓸 수 있는 문장

| 못 쓰는 것 (B 이하) | 쓸 수 있는 것 (A) |
|---|---|
| "임대 현황 8개 호실" | "계약 8건 · 평균 잔여 14개월 · 최장 2028-03" |
| "관리비 별도" | "관리비 임차인 부담 · 월 320만원 · 실질 부담률 16%" |
| "임대 수입 월 1,946만원" | "실질 수입 월 2,266만원 (월세 1,946 + 관리비 320)" |
| "만료 임박 계약 있음" | "2026-08-31 만료 4건 · 월세 비중 63%" |

**A등급의 값어치는 숫자가 늘어나는 데 있지 않고 문장이 구체적이 되는 데 있습니다.**

## §2 지면 문법

### 2.1 한국 IM의 첫 장

실제 국내 IM 3종을 뜯어본 결과 공통점이 셋이었습니다.

```
① 표지에 건물 외관이 크게 들어갑니다 — 로고나 색면이 아니라 사진입니다
② 가격이 표지에서 바로 보입니다 — "문의" 로 미루지 않습니다
③ 두 번째 장이 핵심 요약입니다 — 목차가 아닙니다
```

CREDEAL 표지 규격은 **좌 정보 패널 + 우 외관 사진**입니다. 풀블리드로 깔지 않는 이유는 4:3 원본이 위아래로 잘려 건물 아랫부분이 사라지기 때문입니다.

```
┌──────────────┬────────────────────────┐
│ · INFORMATION│                        │
│   MEMORANDUM │                        │
│              │      건물 외관         │
│ 영등포구     │      (8.20 × 7.50in)   │
│ 당산동5가    │                        │
│ 근린생활시설 │      실효 180dpi 이상  │
│              │                        │
│ 115억        │                        │
│ ▔▔▔▔        │                        │
│ 대지 153평   │                        │
│ 당산역 380m  │                        │
└──────────────┴────────────────────────┘
     4.51in            8.20in
```

금색 세로선(0.07in)이 경계에 섭니다. 남색 패널과 사진 사이에 완충이 없으면 사진이 잘린 것처럼 보입니다.

### 2.2 Hero 3지표 — 검산 가능한 것만

불변조건 19입니다. **매수인이 종이에 적어 확인할 수 있는 것**만 표지에 올립니다.

당산동 R2 실측:

| 라벨 | 값 | 근거 |
|---|---|---|
| 매매 희망가 | 115억 | 중개인 제공 |
| 평당가 (토지) | 7,492만원/평 | 건축물대장 대지면적 |
| 월 임대료 합계 | 1,946만원 | 임대 현황 8행 합계 |

세 값 모두 매수인이 검산할 수 있습니다. 115억 ÷ 153.5평 = 7,492만원. 임대 현황 표의 월세 열을 더하면 1,946만원.

**올리면 안 되는 것** — 수익률입니다. 분모가 여럿이라 표지에서 한 줄로 쓰면 반드시 오해가 생깁니다. 수익률은 §3.3의 전용 면에서 기준과 함께 냅니다.

### 2.3 명사형과 완결문장을 섞지 않습니다

정본 §7.1이 이미 허용합니다. 문제는 일관성이었습니다 — 같은 면에서 두 문체가 섞이면 어색합니다.

| 자리 | 문체 | 예 |
|---|---|---|
| 슬라이드 불릿 | **개조식(명사형)** | "당산역 도보 5분 · 배후 아파트 5,000세대" |
| 표 캡션 | **개조식** | "· 건축물대장 층별개요 · 2026.08 조회" |
| 확인사항 | **완결문장** | "관리비 부담 주체가 확인되지 않았습니다." |
| 중개인 견해 | **완결문장** | "저희가 보기에 1층 약국은 대체가 어렵습니다." |

**경고와 견해만 완결문장입니다.** 나머지는 전부 명사형입니다. 이 두 가지는 사람이 책임지는 말이라 문장으로 끝맺어야 무게가 실립니다.

### 2.4 여백은 비용이 아닙니다

13면 덱에서 흔한 실수가 면을 꽉 채우는 것입니다. 정보 밀도가 높아 보이지만 읽히지 않습니다.

```
한 면에 표는 최대 2개
표만 있는 면이 3연속으로 오지 않게 합니다
사진 면 사이에는 내용 면을 최소 1개 둡니다
```

`im.pages.yaml` `rules`가 이것을 강제합니다.

## §3 면별 작성법

전제는 A등급 15면(`jsre_field_navy`)입니다.

### 3.1 표지

```
쓰는 것    물건 유형 · 소재지(동까지) · 매매가 · 한 줄 정의 · 외관 사진
안 쓰는 것 물건명 · 법인명 · 지번 · 임차인명 (불변조건 14 · 마스킹 규칙)
```

**한 줄 정의는 25자 이내**입니다. 실측 — 당산동 "당산역 380m · 대지 153평" (14자).

수식어를 쓰지 않습니다. "핵심 입지"·"프리미엄 입지"는 금지어입니다. 거리와 면적이 수식어보다 강합니다.

### 3.2 핵심 요약 (2면)

**3~5개 항목**입니다. 6개를 넘으면 핵심이 아닙니다.

A등급 당산동 예:

```
· 당산역(2·9호선) 380m · 도보 5분
· 1층 월세 비중 54.8% — 상층 공실 시 충격 완화
· 계약 8건 분산 · 단일 임차인 최대 비중 45%
· 용적률 여력 178.2%p — 준공업 400% 대비 현행 221.8%
· 공시지가 총액 대비 1.91배
```

각 항목에 **숫자가 하나씩** 들어갑니다. 숫자 없는 항목은 요약이 아니라 인상입니다.

"1층 월세 비중 54.8%"는 실측입니다 — 183만(A) + 883만(B · 1F+2F 통합계약 대표행) = 1,066만 ÷ 1,946만.

### 3.3 투자 분석 (8면)

**여기가 IM에서 가장 자주 틀리는 면입니다.**

#### 기준을 반드시 병기합니다

```
연 수익률 2.03%   ← 연 총임대료 ÷ 매매가
연 수익률 2.08%   ← 연 총임대료 ÷ (매매가 − 보증금)
```

두 숫자가 같은 면에 나옵니다. 기준 없이 하나만 쓰면 어느 쪽인지 알 수 없습니다. 불변조건 2입니다.

#### "순수익률"을 쓰지 않습니다

운영비를 모르면 gross 계열만 냅니다. 라벨은 "연 수익률"이고 "연 순수익률"이 아닙니다. 불변조건 3.

당산동 R2에서 `noi` 블록은 잠겨 있습니다 — *"운영비 미입력 — 연 순수입을 산출하지 않습니다"*.

#### 실투자금은 매매가에서 빼지 않습니다

```
총취득원가 = 115억 + 취득세 5.29억(4.6%) + 중개보수 1.035억(0.9%) = 121.325억
실투자금   = 총취득원가 − 보증금 2.9억 − 대출
```

무차입 실투자금이 118.425억입니다. **매매가 115억이 아닙니다.** 이 차이가 3.4억이고 ROE 계산을 눈에 띄게 바꿉니다.

#### 역레버리지를 숨기지 않습니다

당산동 LTV 3안 실측:

| LTV | 대출 | 실투자금 | 월 순현금 | ROE |
|--:|--:|--:|--:|--:|
| 0% | — | 118.4억 | +1,946만 | 1.97% |
| 40% | 46.0억 | 72.4억 | +221만 | 0.37% |
| 50% | 57.5억 | 60.9억 | **−210만** | **−0.41%** |

대출 금리(4.5%) > 무차입 수익률(1.97%)이므로 **대출을 늘릴수록 수익률이 떨어집니다.** 50%에서는 월 현금흐름이 음수로 뒤집힙니다.

이것을 표 아래 한 줄로 씁니다.

> 대출을 늘릴수록 자기자본 수익률이 낮아지는 구간입니다. 현금흐름을 목적으로 한 대출은 권하지 않습니다.

**감추면 매수인이 나중에 발견합니다.** 먼저 밝히는 편이 신뢰를 얻고, 실제로 이 물건은 임대 수익이 아니라 토지 가치로 사는 물건입니다 — 그것이 §3.5의 논지입니다.

### 3.4 임대 현황 (6면) — 전량 표기

불변조건 18. **상위 N행 요약을 쓰지 않습니다.** 8행이면 8행 전부 냅니다.

| 열 | 규칙 |
|---|---|
| 호실 | 그대로 |
| 업종 | **원문 그대로** — 추론하지 않습니다 (불변조건 6) |
| 임차인명 | **표기하지 않습니다** (불변조건 14) |
| 임대면적 | ㎡와 평 병기 |
| 보증금·월세 | 만원 단위 |
| 만료일 | 만료 경과 ▲ · 60일 내 임박 ● · 유효 |
| 상태 | 임대중 · 공실 · **자가사용** (공실과 구분 — 불변조건 8) |

통합계약은 대표 행에 금액을 적고 나머지 행에 "B그룹 · 금액은 1F 행"을 명시합니다. 금액을 나눠 적으면 합계가 두 배가 됩니다.

### 3.5 토지 가치 (12면) — A·B등급 전용

P2 이상에서만 열립니다. **당산동 같은 저수익 물건에서 이 면이 IM의 결론을 바꿉니다.**

```
대지면적       507.40㎡ (153.49평)
㎡당 공시지가  1,185만원 (2025)
공시지가 총액  60.13억
매매가         115억
─────────────────────────
공시지가 대비  1.91배

현행 용적률    221.8%
법정 상한      400% (준공업지역)
여력           178.2%p
```

임대 수익률이 2%대인 물건을 수익형 논리로만 설명하면 설득력이 없습니다. **용적률 여력 178.2%p가 진짜 소구점**입니다. `land_value_first` 프리셋은 이 면을 4번째로 끌어올립니다.

주의 — 여력이 있다고 개발 규모를 산출하지 않습니다. 가로구역별 최고높이 지정구역이고, 실제 가능 규모는 별도 검토입니다. **"여력 178.2%p"까지가 사실이고 "몇 층 더 올릴 수 있다"부터는 창작입니다.**

### 3.6 확인사항 (10면) — 어떤 등급에서도 생략하지 않습니다

결손은 사라지지 않고 여기로 모입니다(불변조건 13). 공개 단계에서도 마스킹하지 않습니다(불변조건 9).

당산동 R2 실측 결손 5건:

```
· 임대차계약 6건의 최초 계약일
· 관리비 부담 주체와 금액
· 임차인 대항력 요건 (사업자등록 여부)
· 운영비 내역
· 등기부등본 — 근저당·권리 제한
```

**이 면이 길다고 부끄러워할 일이 아닙니다.** 확인사항이 비어 있는 IM이 오히려 의심스럽습니다. 다만 A등급을 표방하면서 확인사항이 10건을 넘으면 등급 판정을 다시 봐야 합니다.

## §4 카피 원칙

### 4.1 문형 4종

| 코드 | 쓰는 자리 | 형태 |
|---|---|---|
| F3 | 사실 진술 | `{주어} {수치}{단위} · {출처}` |
| F4 | 비교 | `{기준} 대비 {배수}배` |
| F5 | 조건부 | `{조건} 시 {결과}` |
| OPINION | 중개인 견해 | `저희가 보기에 {서술}입니다.` |

**OPINION만 1인칭입니다.** 나머지는 주체를 쓰지 않습니다. 시스템이 낸 문장에 "저희"를 붙이면 책임 소재가 흐려집니다.

### 4.2 금지어 26종

`im.lexicon.yaml`이 정본입니다. 네 갈래입니다.

| 갈래 | 예 |
|---|---|
| 절대 | Zero · 제로 · 완벽 · 무결점 · 영구적 · 불패 · 100% · 전혀 없음 |
| 근거 없음 | 우량 · 최고 · 독보적 · 유일 · 극대화 · 초안정 · 희소성 |
| 광고 | 적극 추천 · 놓치면 후회 · 강력 추천 · 서두르 |
| 단정 | 리스크 없음 · 안전 보장 · 확실한 수익 · 확정적 |
| 과장 | 초역세권 · 급행 · 보장 |

문맥 예외가 있습니다 — "실제로"·"전제로" 속의 "제로", "가로구역별 최고높이"의 "최고"는 위반이 아닙니다. `context_exclude`가 이것을 다룹니다.

교정 예:

| 쓰지 않습니다 | 씁니다 |
|---|---|
| 우량 임차인 | 병원·약국 등 생활밀착 업종 |
| 입지 불패 | 당산역 도보 5분 · 배후 아파트 밀집 |
| 퇴거 리스크 완벽 헤징 | 6개 호실 분산 임차 |
| 유지보수 비용 Zero | 2002년 준공 · 주요 수선 이력 미확인 |

오른쪽이 항상 더 깁니다. **길어도 오른쪽이 낫습니다** — 왼쪽은 매수인이 실사에서 반박할 수 있는 말이고, 오른쪽은 반박할 수 없는 사실입니다.

### 4.3 물건 간 문장 재사용

`cross_property.py`가 두 물건에 같은 문장이 있는지 봅니다. 정책·방법론 문장은 같아도 되고 사실 주장은 달라야 합니다.

주의할 것은 **숫자 없는 사실 주장**입니다.

> "역세권 상권으로 배후 수요가 두텁습니다"

숫자가 없어 검사를 통과하지만, 두 물건에 똑같이 들어가면 템플릿으로 보입니다. **F3 문형으로 바꾸면 저절로 해결됩니다** — "당산역 380m · 배후 아파트 5,000세대"는 물건마다 다를 수밖에 없습니다.

## §5 발행 전 사람 심사 5항

규칙 검사가 통과해도 이것을 봅니다. **체크박스입니다 — 서술형 판정은 지켜지지 않습니다.**

```
□ 1. 첫 장에서 건물이 보이는가
□ 2. 3초 안에 가격과 수익률의 기준을 찾을 수 있는가
□ 3. 표만 있는 면이 3연속으로 오지 않는가
□ 4. 명사형과 완결문장이 자리별로 일관된가
□ 5. 이 면을 지우면 아쉬운 면만 남았는가
```

5번이 가장 어렵고 가장 중요합니다. 15면 중 지워도 아쉽지 않은 면이 있으면 그 면은 자리를 차지하고 있을 뿐입니다.

## §6 등급별 기대치

| 등급 | 면수 | 빠지는 면 | 표시 |
|---|--:|---|---|
| **A** | 15 | — | 상용 기본 |
| **B** | 13 | 임대차 상세 | 상용 가능 |
| C | 11 | + 시세비교 · 교차검증 · 토지가치 | **내부 검토용** 워터마크 |
