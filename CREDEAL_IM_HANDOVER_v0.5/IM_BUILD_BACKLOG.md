## §0 읽는 법

티켓 하나가 **하루 이내에 끝나는 크기**입니다. 그보다 크면 쪼갰습니다.

| 칸 | 뜻 |
|---|---|
| **선행** | 이것이 끝나야 시작할 수 있습니다 |
| **하는 일** | 무엇을 만드는가 |
| **수용 기준** | 무엇이 참이면 끝인가 — 기계로 확인 가능한 것 |
| **근거** | 어느 문서·어느 실측이 이것을 요구하는가 |

`FR` 접두는 기능 요구입니다. D22-1 §D13에서 `F`(Freshness)와의 충돌을 피해 개명한 것입니다.

### FR08 · 다필지·제척 코어  🔄 **개정 — 차단에서 지원으로**

**선행** FR01
**하는 일** `IMInput.parcels: Parcel[]` + `exclusions[]`를 받아 **유효 대지면적**으로 계산합니다. 구분등기는 대지 평당가를 내지 않습니다(D6 유지).

```
P01 유효 대지면적 = Σ(필지 × 지분) − Σ(제척 where affectsFAR)
P02 유효 용적률   = 용적률산정 연면적 ÷ 유효 대지면적
P03 제척 영향도   = 제척 ÷ 대장 대지면적
G12 제척 합계 ≤ 대지 합계
```

**수용 기준**

```
□ 잠원동 2필지 — 대장 616.1㎡ · 유효 603.6㎡ · 용적률 249.0% → 254.1%
□ 한시 완화 임계 250% 이탈이 경고로 뜸
□ 제척 > 대지 이면 G12 차단
□ 지분 없는 공유지분·미등록 제척 사유는 예외 (조용히 넘기지 않음)
□ X05 신설 — 필지 합 = 공부 대지면적 (±0.5%) · X01·X02·X04 는 대장 기준 유지
□ 구분등기에서 landPyeongPrice() 가 Absent 반환
```

**근거** **D22-1 §D5는 철회됐습니다.** 다필지는 `CATALOG_SLOTS` §2.1 · `CATALOG_RULES` P01~P03·G12·L10~L12에 이미 설계돼 있었고, 차단 결정은 그것을 모르고 내린 것입니다(D22-8). 참조구현은 `credeal/parcel.py`에 있습니다 — 자기검사 7항 통과.
