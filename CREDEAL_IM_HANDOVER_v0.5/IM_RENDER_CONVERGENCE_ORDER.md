## 1. 결론 — 한 문단

현행 시스템은 **템플릿 엔진**이고 목표 스펙은 **판정 파이프라인**입니다.
템플릿은 *칸이 있으니 채웁니다*. 파이프라인은 *근거가 있으니 칸을 엽니다*.

이 한 글자 차이가 산출물 전체를 갈랐습니다. 칸을 먼저 만들면 근거가 없을 때
칸이 비지 않고 **그럴듯한 것으로 메워집니다.** 실제로 그렇게 됐습니다 —
사진이 없으니 다른 물건 사진이 들어갔고, 렌트롤 원장이 없으니 요약 4줄이
들어갔고, 지도가 없으니 좌표 없는 장식 그래픽이 들어갔습니다.
**세 경우 모두 실패로 기록되지 않았습니다.**

### 2.1 L1 — 사진이 이 물건이 아닙니다

표지와 갤러리에 실린 건물은 **서초메디컬센터(SEOCHO MEDICAL CENTER)** 입니다.
건물 상단 사이니지에 그대로 찍혀 있습니다. 대상 물건은 영등포구 양평동4가
선유도역 인근 업무시설입니다. **다른 구, 다른 용도, 다른 건물입니다.**

부수 사실:

- 표지 사진 = 2면 "건물 외관" 과 **동일 파일** (sha256 `8567e419…`)
- 고유 이미지 **6장** 으로 7개 슬롯을 채웠습니다
- 주 출입구 사진에 인근 점포 상호가 **미마스킹** 노출 (불변조건 14·23)
- 4면 지도는 도로명·역명·축척·방위 **전무**. 선 두 개와 점 하나입니다

🔴 텍스트는 "선유도역 4번 출구 도보 1분(80m)" 이라고 단언하는데,
   그 옆의 지도는 **아무것도 입증하지 않습니다.** 없는 것보다 나쁩니다 —
   증거처럼 보이기 때문입니다.

**원인** `resolvePhotos()` 에 물건 동일성 검증이 없습니다. 사진은 URL 유무만
봅니다(`gallery-planner.ts` §6.1 "URL 없는 항목 제외"). URL이 있으면 통과합니다.

### 2.4 L4 — 값이 문장 안에서 태어납니다

`bindSectionData(doc, building)` 는 **LLM 마크다운을 파싱**합니다(§2.1 MD 파싱 모드).
값은 문장에서 뽑히고, 뽑힌 뒤 **재계산되지 않습니다.** 결과:

#### (a) 연 수익률의 기준이 사실과 다릅니다

라벨은 「연 수익률(Cap Rate, 기준: NOI)」이고 값은 **2.41%** 입니다.

```
월 임대료 5,017만 × 12 = 6.0204억
6.0204억 ÷ 250억        = 2.41%   ← 표시값과 정확히 일치
```

즉 표시된 2.41%는 **총 임대료(GPI) 기준**입니다. 운영비·재산세·보험·관리를
아무것도 빼지 않았습니다. NOI 기준이라면:

| 운영비 가정 | NOI | 연 수익률 |
|---|---:|---:|
| 10% | 5.42억 | **2.17%** |
| 15% | 5.12억 | **2.05%** |
| 20% | 4.82억 | **1.93%** |

🔴 **기준 표기가 값과 어긋납니다.** 정본 §6.4·G10 은 기준 병기를 요구하는데,
   병기는 됐고 **내용이 틀렸습니다.** 이건 미표기보다 나쁩니다.

#### (b) 자기자본수익률이 금리 1.01%를 가정합니다

```
실투자금 125억 × 3.85% = 순현금 4.8125억
대출 추정 250 − 5.35(보증금) − 125 = 119.65억
역산 금리 (6.0204 − 4.8125) ÷ 119.65 = 1.01%
```

실세 금리를 넣으면:

| 금리 | 실제 순현금 | 실제 ROE |
|---:|---:|---:|
| 4.0% | +1.23억 | **+0.99%** |
| 4.5% | +0.64억 | **+0.51%** |
| 5.0% | +0.04억 | **+0.03%** |

연 수익률 2.41% < 조달 금리 → **역레버리지**입니다. 레버리지를 쓸수록
자기자본수익률이 **떨어집니다.** 그런데 3면 핵심요약은 2.41% 옆에
**3.85%** 를 나란히 놓아, 레버리지가 수익률을 올린 것처럼 보이게 합니다.

🔴 §9.1 필수 요소 「역레버리지 경고」가 누락된 상태에서 이 배치가 나갔습니다.
   **이 지시서에서 가장 위험한 항목입니다.**

#### (c) 같은 자산에 두 진술이 공존합니다

| 면 | 진술 |
|:-:|---|
| 3면 | 11개 법인 분산 **만실** |
| 6면 | 공실 현황 **17.0%** |

문장이 서로 다른 섹션에서 태어나 서로를 모릅니다.
(이 모순은 `consistency_check.py` 도 놓쳤습니다 — §6.2 자기 지적 참조.)

#### (d) 소독 파이프라인이 결손 표시를 지웁니다

§2.2 소독 2단계 — *시스템 메시지 제거 ("건축물대장 조회 미완료", "임대차 상세 현황")*.

🔴 **"건축물대장 조회 미완료"를 지우면 조회가 안 됐다는 사실이 사라집니다.**
   불변조건 13(결손은 확인사항으로 표시) 정면 위반입니다.
   소독이 아니라 **은폐**입니다. 결손은 지울 대상이 아니라 옮길 대상입니다.

#### (e) 어휘·라벨

- 치환 사전 위반 **13건** — Cap Rate(4) · NOI(1) · 리스업(5) · 밸류애드(1) · 테넌트(1) · 초역세권(1)

### 2.5 L5 — 상자가 사진을 정합니다

D31에서 우리 산출물의 **크로핑**을 잡았습니다. 현행 시스템은 크로핑이 **0%** 입니다.
자르지 않습니다. 대신 **늘립니다.**

| 면 | 원본 비율 | 상자 비율 | 왜곡 |
|:-:|---:|---:|---:|
| 1면 gold | 1.491 | 1.778 | **19%** |
| 1면 obsidian | 1.491 | 0.644 | **57%** |
| 2면 ×4 | 1.491 | 2.386 | **60%** |
| 5면 | 1.489 | 1.312 | 12% |

🔴 **크로핑은 일부를 버립니다. 왜곡은 비율을 거짓말합니다.**
   10층 건물이 납작해지고 정방형 필지가 직사각형이 됩니다.
   부동산 자료에서 후자가 더 나쁩니다.

그 외:

- 1면 실효 dpi **95** (하한 150) — 1264×848 원본을 13.33in 폭에 폈습니다
- 5면 실효 dpi 126 — 600×403 원본
- 1면 제목 넘침 — 필요 1.33in > 상자 0.80in. 「투자설명서」가 상자 밖으로 나가 부제와 겹칩니다
- 5면 넘침 3건 — 필요 0.47 > 상자 0.44in
- obsidian 1면 장식 원이 **지면 이탈** (x=8.00 + w=6.00 = 14.00 > 13.33)
- 라벨 ↔ 값 겹침 19건(gold) / 8건(obsidian)

**원인** `imlib.ts` 가 상자를 먼저 정하고 사진을 그 안에 채웁니다.
`assertBounds()` (§7.2)는 상자가 지면 안에 있는지만 보고, 상자 안의
**내용이 온전한지는 보지 않습니다.**

## 3. 테마는 원인이 아닙니다

gold와 obsidian을 비교하면:

| | gold | obsidian |
|---|---|---|
| 텍스트 | 동일 | 동일 |
| 이미지 | 동일 6장 (sha256 일치) | 동일 6장 |
| 2면 왜곡 | 60.1% | 60.1% |
| 면수·시퀀스 | 11면 동일 | 11면 동일 |
| 색 토큰 | `#0A1128` `#B8862D` | `#09090B` `#0284A8` |
| 폰트 | Pretendard·Arial·Noto Serif KR | Pretendard·Arial |

🔴 **테마 층은 잘 만들어져 있습니다.** 토큰 격리(`withThemeIsolation`),
   프리셋 폴백, 5종 head 스타일 — 이 부분은 손대지 마십시오.

결함은 전부 **콘텐츠 층**에 있고, 두 테마에 **똑같이** 나타납니다.
그러므로 "프리셋을 더 만들면 나아진다"는 접근은 **효과가 없습니다.**
같은 결함이 색만 바뀌어 늘어납니다.

## 4. 작업 지시

### 차단 — 이것을 고치기 전에는 발행하지 않습니다

#### BL-1 · 사진 ↔ 물건 결속 검증

**파일** `resolvePhotos()` · `gallery-planner.ts`

사진 레코드에 `buildingId` 를 필수로 두고, 렌더 입력의 `buildingId` 와
불일치하면 **해당 슬롯을 비웁니다.** 스톡·타 물건 폴백을 금지합니다.

```ts
// 🔴 URL 유무가 아니라 소속을 봅니다.
const own = photos.filter(p => p.buildingId === input.buildingId);
if (own.length === 0) {
  // 채우지 않습니다. 갤러리 면을 열지 않고 확인사항에 기록합니다.
  checklist.push({ code: 'X-IMG-00', text: '물건 사진 미확보 — 현장 촬영 필요' });
}
```

수용: 타 물건 사진이 한 장이라도 들어가면 `G37` 로 차단.

#### BL-2 · 지도 슬롯 — 좌표 없으면 열지 않습니다

**파일** A06 Diagram 아키타입

지도는 **좌표 · 축척 · 방위 · 최소 1개 지명 라벨**을 모두 갖춘 캡처만
허용합니다. 넷 중 하나라도 없으면 슬롯을 비우고 「입지 도면 확보 예정」으로
표시합니다. 장식 그래픽을 지도 자리에 넣지 않습니다.

#### BL-3 · 값 확정 단계 신설 (D26 ⑤)

**파일** `data-binder.ts` — `bindFromIMCore(core)` 를 **기본 경로로 승격**

MD 파싱 경로(`bindSectionData`)를 파생값에 쓰지 않습니다. 문장에서 숫자를
뽑지 말고, ⑤단계에서 확정한 값을 문장이 **받아쓰게** 합니다.

확정 대상(최소): `capRate` · `noiBasis` · `roe` · `loanRate` · `ltv` ·
`평당가(대지)` · `평당가(연면적)` · `총취득원가` · `월 순현금` · `공실률`

```ts
// 🔴 yieldBasis 는 라벨이 아니라 계산 경로입니다.
type Yield = { value: number; basis: 'GPI' | 'NOI' | 'EGI'; deductions: string[] };
// basis 가 'NOI' 인데 deductions 가 비어 있으면 G38 차단.
```

수용: 라벨이 `NOI` 인데 공제 항목이 0개면 렌더 거부.

#### BL-4 · 역레버리지 경고

**파일** A02 Stat Grid · A16 Investment Structure

`capRate < loanRate` 이면 ROE를 **단독으로 표시하지 않습니다.**
같은 면에 다음을 함께 싣습니다.

```
연 수익률 2.41%  <  조달 금리 4.5%
→ 대출을 늘릴수록 자기자본수익률이 낮아집니다 (역레버리지)
   금리 4.0% ROE 0.99% · 4.5% 0.51% · 5.0% 0.03%
```

금리 미확정 시 **ROE 칸 자체를 열지 않습니다.** 가정 금리를 숨긴 채
단일 ROE를 내보내는 것을 금지합니다.

#### BL-5 · 폴백을 실패로 기록

**파일** `addFallbackContent()`

폴백이 발동하면 `warnings[]` 에 `{ archetype, slideIndex, reason }` 을 남기고,
**A03(Large Table) 계열에서 폴백이 발동하면 발행을 차단**합니다.
표가 있어야 할 자리에 불릿이 들어가는 것은 대체가 아니라 결손입니다.

#### BL-6 · 소독 2단계 — 삭제를 이관으로

**파일** `sanitizePersona()`

"건축물대장 조회 미완료" 류를 **지우지 않습니다.** 확인사항 배열로 옮깁니다.

```ts
// 🔴 결손 문구는 노이즈가 아니라 신호입니다.
const MISSING = /조회 미완료|확인 필요|미확보|자료 없음/;
if (MISSING.test(line)) { checklist.push(toChecklistItem(line)); continue; }
```

## 6. 검사기 자기 지적

지시서를 쓰는 과정에서 **내 검사기의 구멍 두 개**가 드러났습니다. 적어 둡니다.

### 6.1 종횡비 왜곡을 보지 못했습니다 — 해소

`layout_check` 는 크로핑만 봤습니다. 현행 산출물은 크로핑 0%라 ①을
**통과**했고, 60% 왜곡은 잡히지 않았습니다.

`aspect_distortion()` 을 ⑥으로 추가했습니다. 결과:

```
현행 gold      위반 6 → 12  (종횡비 6건 신규 검출)
현행 obsidian  위반 7 → 13
목표 3종       위반 0 → 0   ← fit_box 는 비율을 보존하므로 구조적으로 0
```

대조군에서 0, 표본에서 12건. **공허하지 않은 검사입니다.**

### 6.2 「만실」 ↔ 「공실 17%」를 놓쳤습니다 — 미해소

`consistency_check` 는 현행 gold를 **통과**시켰습니다. 같은 지표의 서로 다른
숫자는 잡지만, **서술어와 숫자의 모순**은 보지 않습니다.

→ 후속 과제로 남깁니다. 「만실 / 공실 없음 / 100% 임대」 류 어휘가
   `vacancyRate > 0` 과 공존하면 차단하는 규칙이 필요합니다.
   **오늘 이 문서로는 해소되지 않았습니다.**

## 9. 하지 말 것

- **프리셋을 추가하는 것으로 대응하지 마십시오.** §3에서 보였듯 두 테마의
  결함이 동일합니다. 콘텐츠 층을 고치기 전의 새 프리셋은 결함의 복제입니다.
- **폴백을 더 정교하게 만들지 마십시오.** 폴백이 정교해질수록 결손이
  더 잘 숨습니다. 폴백은 **보이게** 만들어야 합니다.
- **텍스트 예산(`TEXT_LIMITS`)을 늘려 넘침을 해결하지 마십시오.**
  넘침의 원인은 글자 수가 아니라 **손으로 적은 상자 높이**입니다.
- **소독 목록에 문구를 더 추가하지 마십시오.** 이미 결손 신호를 지우고
  있습니다. 추가는 은폐를 넓힙니다.
- 마스킹 자동화는 **DEC-IMG-01** 로 착수 대상이 아닙니다. 다만 승인 레코드
  (`approvedBy` · `approvedAt` · `maskedRegions`)는 유지됩니다.
