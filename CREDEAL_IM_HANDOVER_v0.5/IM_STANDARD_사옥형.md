## 0. 이 포스처가 답하는 질문

> **지금 내는 임차료와 비교해 얼마나 유리한가. 우리 인원이 들어가는가.**

수익형 매수자는 "얼마 버는가"를 묻고, 사옥형 매수자는 **"얼마 아끼는가"** 를 묻습니다.
비교 대상이 시장 수익률이 아니라 **자기가 지금 내고 있는 임차료**입니다.

```
자가 우위액 = 현 연 임차료 − (연 대출이자 + 관리·세금) + 지가 변동분
```

이 값이 IM의 Hero 지표입니다. 임대수익률을 앞세우면 **판단 기준을 잘못 심습니다** —
그래서 `yieldBasis` 가 `none` 입니다.

### 1.1 L이 R1로 낮은 이유

**현 임차료 하나만 있어도 비교가 성립합니다.** 사옥형 매수자는 자기 회사의 임차
조건을 알고 있고, 그것이 L축의 절반입니다. 물건 쪽 임대 현황은 잔여 임대 면적만
알면 됩니다.

### 2.1 통근 분석이 왜 §2에 붙는가

**사옥 이전의 최대 반대 요인은 직원 통근입니다.** 임원이 좋다고 해도 직원이
못 다니면 이전이 무산됩니다. 그래서 입지 섹션이 "역세권 도보 N분"에서 끝나지 않고
**노선 수·환승·주요 주거 권역에서의 소요 시간**까지 갑니다 (`R-OWN-03`).

## 3. 자가 vs 임차 비교 — 이 표준의 핵심

### 3.1 지가 시나리오 4종이 없으면 차단합니다 🔴

제약 `C27`입니다.

> **판정이 지가 가정에 지배됩니다.** 지가가 연 3% 오른다고 놓으면 자가가 압도적으로
> 유리하고, 0%면 비슷하고, 하락하면 불리합니다. **단일 값 제시는 사실상 투자 권유**입니다.

| 시나리오 | 필수 |
|---|:-:|
| 하락 | ◎ |
| 보합 | ◎ |
| 기준 | ◎ |
| 상승 | ◎ |

**하락 시나리오를 빼면 안 됩니다.** 대출을 끼면 지가 하락 시 손실도 같은 배수로
커집니다 (`M15`).

### 3.2 세후 효과는 일반화하지 않습니다

법인세 손금 처리, 감가상각, 부가세 환급의 효과는 **법인의 과세 상황에 따라
완전히 다릅니다.** 결손 법인은 손금 효과가 0입니다.

| 표기 | 판정 |
|---|---|
| "세후 연 N원 유리" | ✗ **금지** — 매수자 상황을 모릅니다 |
| "세전 기준 연 N원. 세효과는 법인 상황에 따라 달라집니다" | ○ |
| 세효과 산식만 제시하고 값은 비움 | ○ |

`IM_STANDARD_포스처확장.md` v3.0 §6B의 결론입니다.

### 3.3 회수 기간

```
회수 기간 = 초기 자기자본 ÷ 연 자가 우위액
```

`R-OWN-01`(자가 우위형)은 **우위액 > 0 ∧ 회수기간 ≤ 5년**입니다.
5년을 넘으면 우위형으로 부르지 않습니다 — 사업 계획의 시계가 그 정도입니다.

## 4. 층별 사용 계획

`occupancy_plan` 이 담습니다.

| 슬롯 | 왜 |
|---|---|
| `headcount` · `areaPerHead` | 현 인원이 들어가는가 |
| `floorAllocation` | 어느 층에 무엇을 두는가 |
| `currentLeaseCost` · `currentLeaseExpiry` | **비교 기준** — 없으면 §3이 성립 안 함 |
| `expansionHeadroom` | 몇 명까지 더 들어가는가 (`R-OWN-02`) |

**`currentLeaseExpiry` 가 실무의 급소입니다.** 현 임차 만기와 이 물건의 잔여 임대
명도 시점이 어긋나면 **이중 부담 기간**이 생깁니다. 그 구간을 IM에 명시합니다.

### 4.1 "사옥이니 임대차는 볼 것 없다"가 가장 자주 틀립니다 🔴

하층 상가가 임대 중인 경우가 흔하고, 그 명도 시점이 입주 계획을 좌우합니다.
그래서 게이트 `G13`(임대차 판정 정합)과 `G15`(적용 법령 확정)가
**사옥형에도 걸립니다.**

상가주택형 물건이면 호실별로 상임법·주임법이 갈립니다 — 갱신권이 10년과 4년으로
다르므로 명도 시점 추정이 최대 6년 어긋납니다.
