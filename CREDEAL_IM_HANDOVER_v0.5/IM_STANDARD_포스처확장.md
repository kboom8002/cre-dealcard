## 3. 개발형 블루프린트 — 잠원동 기준

### 3.1 v1.0에 없던 것 4가지

#### ① 명도비를 매매가에 포함해 comps 비교

```
강남대로 배후 일면부  1.7 ~ 2.3억/평
강남대로 안쪽 이면부  1.1 ~ 1.6억/평
▶ 본 자산          1.3억/평  (명도비 포함)
```

**"명도비 포함"이 결정적입니다.** 개발형에서 명도비를 빼고 비교하면 사과와 오렌지가 됩니다.

> **표준 규칙** — 개발형 comps는 **명도비 포함 기준**으로 통일하고, 포함 여부를 반드시 명기합니다.

#### ② comps를 위치 등급으로 층화

단일 Range가 아니라 **2~3개 층**으로 제시합니다.

| IM | 층화 방식 |
|---|---|
| 잠원동 | 강남대로 **배후 일면부** / **안쪽 이면부** |
| 당산동 | 입지&부지 **양호** / 입지 or 부지 **불리** |

**두 IM이 독립적으로 같은 방식을 씁니다.** 국내 실무 표준으로 보입니다.

#### ③ 준공 전 마케팅 플랜

잠원동 p18은 임차 유치 전략을 비율로 제시합니다.

| 타겟 | 비중 | 대상 |
|---|:-:|---|
| 1차 | 50% | F&B·업무·스튜디오 · 메디컬 과목별 세분화 |
| 2차 | 30% | 지역 거점형 (지사·보험·로펌·세무법인) |
| 3차 | 20% | GBD/CBD/YBD 대체 오피스·공유오피스 |

**"지을 수 있다"에서 끝나지 않고 "채울 수 있다"까지 답합니다.** 개발형 매수인의 가장 큰 불안이 공실이므로 이 페이지가 필요합니다.

#### ④ 규제 활용 근거 명시

```
본 자산 서울시 "소규모 건축물 한시적 용적률 상향" 대상으로
용적률 250% 미만으로 신축 가능
```

**제도명·적용 조건을 명기**합니다. "규제 완화 수혜지" 같은 막연한 표현과 다릅니다.

## 4. 🔴 최대 정정 — 개발형 최소 해상도가 R1로 내려갑니다

### 4.1 v1.0은 R3를 필수로 봤습니다

```
착공일 = max(호실별 명도 가능 시점)
명도 = f(적용법령, 최초계약일, 갱신요구권, 만료일)  → R3 필수
```

### 4.2 v3.0 조사 결과 — 매도인 명도가 관행입니다

잠원동 IM의 문구가 예외가 아니었습니다.

```
"다수 임차인임에도 매도인 명도 조건으로 매각 진행 가능"
```

> 매매하는 건물에 임차인이 있는 경우, **일정 시점까지 임차인 명도를 매도인이 책임지기로 하고 매매계약이 체결되는 경우가 많으며**, 계약 체결 후 2달 뒤를 잔금일로 정하고 그때까지 매도인 책임으로 임차인을 내보내는 것이 일반적입니다.

**매수인은 명도된 상태로 인수하므로 갱신요구권 판정이 불필요합니다.**

### 4.3 정정된 규칙

| 명도 책임 | 최소 해상도 | 예상 비중 | 근거 |
|---|:-:|:-:|---|
| **매도인 부담** | **R1** | **다수** | 명도 완료가 거래 조건 · 시점만 특약으로 |
| 매수인 부담 | R3 | 소수 | 착공일 산출에 갱신요구권 필수 |
| 미정 | R3 + 협의 필요 | — | 가장 위험 · 딜 구조 미확정 |

**"명도 책임"이 렌트롤보다 먼저 확인할 항목입니다.**

```ts
export function developmentMinResolution(d: DealTerms): Resolution {
  switch (d.vacateResponsibility) {
    case 'seller': return 'R1';   // 관행 · 명도 특약 조건만 명기
    case 'buyer':  return 'R3';   // 갱신요구권 판정 필수
    default:       return 'R3';   // 미정 → 보수적으로
  }
}
```

### 4.4 매도인 명도 조건일 때 IM에 담을 것

R1로 충분하지만 **특약 조건 4가지**는 반드시 명기합니다.

| # | 항목 | 예시 |
|:-:|---|---|
| 1 | 명도 완료 시점 | 잔금일까지 |
| 2 | **미이행 시 처리** | 잔금 유보 · 계약 해제 · 위약금 |
| 3 | 명도비 부담 주체 | 매도인 · 매매가 포함 여부 |
| 4 | 잔여 임차인 승계 여부 | 일부 승계 시 대상 명기 |

> **2번이 실무에서 가장 자주 빠집니다.** 명도가 안 되면 어떻게 되는지가 없으면 특약이 무의미합니다.

## 4A. 🔴 개발형 신규 축 — 용적률 완화 시한

### 4A.1 제도 실체

| 항목 | 내용 |
|---|---|
| 제도 | 서울시 소규모 건축물 한시적 용적률 완화 |
| 제2종일반주거 | 200% → **250%** |
| 제3종일반주거 | 250% → **300%** |
| **적용 기간** | **2025-05-19 ~ 2028-05-18 (3년 한시)** |
| 대상 | 건축허가·신고 · 자율주택정비 · 소규모재건축·재개발 |
| 주거용 조건 | 전용 85㎡ 이하 (오피스텔 포함) |

### 4A.2 잠원동에서 이 제도가 결정적인 이유

| 시나리오 | 용적률 | 지상 연면적 | 현재 대비 |
|---|--:|--:|--:|
| 현재 (1990년 준공) | **247.0%** | 1,521.7㎡ | — |
| **완화 없이 신축** | 200% | 1,232.2㎡ | **−19.0%** |
| **완화 적용 신축** | 250% | 1,540.2㎡ | +1.2% |
| 잠원동 신축 계획 | **249.0%** | 1,534㎡ | +0.8% |

**완화가 없으면 신축할수록 연면적이 19% 줄어듭니다.** 기존 건물이 이미 상한을 초과한 상태이므로, **완화는 사업의 부수 효과가 아니라 전제조건**입니다.

잠원동 계획 249%는 상한 250%에 **1.0%p 여유**로 정확히 맞춰 설계됐습니다.

### 4A.3 🔴 잠원동 IM에 없는 것 — 시한

| | |
|---|---|
| 완화 종료 | 2028-05-18 |
| IM 작성 | 2026-04 |

**IM에 기한 표기가 없습니다.** 매수인은 이 기간 안에 인허가를 받아야 하는데 그 사실을 모릅니다.

> **표준 규칙** — 한시 제도를 근거로 사업성을 제시할 때는 **종료일과 잔여 기간을 반드시 병기**합니다.

### 4B.2 잠원동 적용

| 기준 | 필요 자기자본 |
|:-:|--:|
| 2026년 (10%) | **32.09억** |
| 2027년 (15%) | 48.14억 |
| 2028년 (20%) | 64.19억 |

*총투입 320.95억 기준*

**개발형 IM에 "필요 자기자본"을 연도별로 제시해야 합니다.** 매수인이 자금 계획을 세우는 기준이며, 규제가 매년 강화되므로 착수 시점에 따라 달라집니다.

> 소형 개발은 브릿지론 의존도가 높아 실제 조달 구조가 규제와 다를 수 있습니다. **IM에는 규제 기준을 제시하고 실제 조달은 금융기관 협의 사항으로 표기**합니다.

### 4.4 나대지는 명도 자체가 없습니다

수택동은 **나대지**입니다.

```
현재 나대지 / 고밀도핵심개발부지 / 오피스텔부지추천
1,260% 용적율허가필 2,500평 / 평당 4,500만원
```

| 항목 | 값 | 검산 |
|---|---|:-:|
| 대지 651.2㎡ = 196.99평 · 89억 | 평당 **4,518만원** | ✓ (IM 4,500만) |
| 용적률 1,260% | 지상 8,205㎡ = **2,482평** | ✓ (IM 2,500평) |

> 🔑 **"1,260% 용적율허가필" — 인허가 완료가 개발형 최상위 정보입니다.** 인허가 리스크가 사라지므로 사업 확실성이 급상승합니다. 표준의 p3(물건 개요)에 **인허가 상태 슬롯**을 신설합니다.

| 인허가 상태 | 표기 |
|---|---|
| 허가 완료 | **○ 허가필 (용적률 N%)** |
| 심의 중 | △ 진행 중 · 예상 시점 |
| 미신청 | ✗ 미신청 · 리스크 |

### 4.5 수택동의 결손

| 항목 | 상태 |
|---|:-:|
| 사업수지 (총사업비·분양수입·이익률) | **✗ 전무** |
| comps | **✗** |
| **수익률 칸** | **공란** |

18페이지 중 14페이지가 사진·지적도·토지이용계획원입니다. **"토지 소개서"이지 개발형 IM이 아닙니다.**

## 6. 운영형 — 실증 근거 부족

에이치에비뉴호텔 IM은 **전체 2페이지**입니다.

```
이대역 도보 3분거리 / 신촌 대학가 호텔 / 객실수 94실 / 매각금액 300억원
```

| 산출 가능 | 값 |
|---|--:|
| 객실당 단가 | **3.19억/실** |
| ADR·OCC·RevPAR·GOP | **전무** |

**운영형 표준을 세울 실증 근거가 없습니다.** 정직하게 기록합니다.

### 6.1 v3.0 — 시장 지표로 벤치마크가 가능해졌습니다

| 지표 | 값 | 출처 시점 |
|---|--:|---|
| 서울 호텔 OCC | **79.2%** | 2025 |
| 서울 RevPAR | **207,345원** | 2025 |
| 2026 상반기 서울 호텔 거래액 | 약 1.1조 (전년비 **+71%**) | 2026 |
| 거래 중심축 | **3·4성급 도심** | 2026 |
| 보코 서울 명동 | 3,686억 · **객실당 6.4억** | 2025~26 |

### 6.2 에이치에비뉴호텔 벤치마킹

| | 값 |
|---|--:|
| 본건 | 300억 / 94실 = **객실당 3.19억** |
| 보코 명동 | 객실당 6.4억 |
| **상대 수준** | **50%** |

**객실당 단가 하나로 비교가 가능합니다.** 등급·입지가 달라도 CRE에서 가장 널리 쓰이는 지표입니다.

### 6.3 서울 평균 역산 — ◇가정 프레임

실적 자료가 없을 때 **상한 추정**을 제공합니다.

```
연 객실매출 = 94실 × 207,345원 × 365일 = 71.1억  (매매가 대비 23.7%)
```

| GOP 마진 | GOP | GOP Cap |
|:-:|--:|--:|
| 30% | 21.3억 | **7.11%** |
| 35% | 24.9억 | 8.30% |
| 40% | 28.5억 | 9.49% |

> ⚠️ **서울 평균은 4~5성급을 포함합니다.** 이대 대학가 3성급이면 실제는 상당히 낮습니다.
> 이 역산은 **상한 추정이며 실적 확인 전까지 ◇가정**입니다. IM에 확정치로 실으면 안 됩니다.

### 6.4 운영형 해상도

| 등급 | 필요 데이터 | 산출 |
|:-:|---|---|
| **O1** | 객실 수 · 매각가 | **객실당 단가** + 시장 comps 비교 |
| **O2** | + 월별 매출 12개월 · OCC · ADR | RevPAR · 시장 대비 지수 |
| **O3** | + 비용 명세 | **GOP · GOP Cap** + **실적 검증 수준** |

**호텔 IM은 O1(2p)입니다.** O1에서도 객실당 단가 비교는 가능하므로, 시장 지표만 붙이면 **최소한의 판단 근거**는 생깁니다.

### 6.5 🔑 운영형 고유 축 — 실적 검증 수준

다른 포스처에 없는 항목입니다.

| 수준 | 근거 |
|:-:|---|
| **검증됨** | 부가세 신고서 · 카드매출 조회 대조 |
| **부분** | POS 데이터만 |
| **미검증** | 매도인 구두·자체 장부 |

**현금 매출 비중이 높은 업종은 신고 실적과 실제가 다를 수 있습니다.** 이 축이 없으면 GOP 숫자가 의미를 잃습니다.

## 6B. 사옥형 — 세후 효과는 일반화 불가

### 6B.1 세제 구조

| 항목 | 처리 |
|---|---|
| **감가상각** | **건물분만** 대상 (토지 제외) · 법인세 절감 |
| 취득 **완료 후** 이자 | 손금 산입 |
| 취득 **완료 전** 이자 | **자산 취득원가에 가산(자본화)** · 즉시 손금 불가 |
| 임차료 | 전액 손금 |

### 6B.2 절세 효과 규모 (당산동 예시 ◇)

건물분 35% 가정 · 정액 40년.

| 법인세율 | 연 절세 | 월 환산 |
|:-:|--:|--:|
| 9% | 906만원 | 75만원 |
| 19% | 1,912만원 | 159만원 |
| 21% | 2,113만원 | **176만원** |

### 6B.3 🔑 표준 방침 — 세전으로 제시합니다

**월 실질 부담 −93만원에 절세 176만원을 더하면 +83만원으로 뒤집힙니다.** 판단이 완전히 달라지는 크기입니다.

그런데 **일반화가 불가능합니다.**

| 변수 | 왜 다른가 |
|---|---|
| 건물분 비중 | 감정평가·계약서 안분에 따라 20~50% |
| 내용연수 | 구조·용도별 상이 |
| 법인세 과세표준 | 9% / 19% / 21% 구간 |
| 취득 시점 이자 자본화 | 사업 일정에 따라 |

> **표준은 세전 기준으로 제시하고, "세후 효과는 세무 상담 필요"를 명기합니다.**
> 절세액을 IM에서 확정 제시하면 틀릴 가능성이 높고, 틀리면 신뢰가 무너집니다.
>
> 다만 **감가상각 대상이 건물분만이라는 사실**은 반드시 표기합니다. 매수인이 매매가 전액을 상각한다고 오해하는 경우가 흔합니다.

|---|--:|---|

| development | +3.0 | **규제 시한 슬롯**(+1.0) · **필요 자기자본**(+1.0) · 명도 특약 4항(+1.0) |
| operating | +1.0 | 시장 지표 벤치마크 · 역산 프레임 |

### 10.2 확장 순서 (v3.0 재배열)

| 순서 | 포스처 | 이유 |
|:-:|---|---|
| 2 | owner_occupied | 원장 v1.2 재사용 · 가장 저렴 |
| 3 | trading | comps 엔진 확장 · 세후 로직 추가 |
| 4 | **development** | **명도 관행이 R1이라 생산 가능 건수가 큼** · 실증 2건 |
| 5 | operating | 원장 신규 · **다만 시장 지표로 O1 벤치마크는 즉시 가능** |

> **v3.0에서 개발형의 매력이 올라갔습니다.** 매도인 명도가 관행이면 R1으로 발행 가능하므로, 예상 생산 건수가 v2.0 가정보다 훨씬 많습니다. 실제 수임 비중을 확인해 2·3순위와 재배열할 여지가 있습니다.

### 10.3 즉시 가능한 것

| 항목 | 공수 | 조건 |
|---|--:|---|
| **운영형 O1 벤치마크** | 0.5일 | 객실당 단가 + 시장 comps만 |
| 개발형 규제 시한 표기 | 0.5일 | 슬롯 2개 추가 |
| 매매형 세율표 | 0.5일 | 상수 테이블 |

**1.5일로 세 포스처에 최소 가치를 붙일 수 있습니다.**

## 11. 전이 실패 위험

| 위험 | 증상 | 방지 |
|---|---|---|
| **최종 숫자를 income에서 복사** | 사옥형에 "월 순현금"만 표기 | 포스처별 **타입 강제** |
| **렌트롤 해석 방향 오류** | 개발형에 "안정적 임대수익" 서술 | 포스처 오버레이 검증 |
| **명도 책임 미확인** | 개발형 R3를 일괄 강제 → IM 생산 불가 | **명도 책임을 먼저 묻기** |
| **comps 기준 불일치** | 명도비 포함/제외 혼재 | **포함 여부 명기 강제** |
| 원장 통합 과욕 | 운영형을 렌트롤에 억지 매핑 | 별도 원장 인정 |
| 공통 페이지 포스처 누수 | 개발형 입지에 "임대수요 풍부" | 공통 7p도 오버레이 |

### 11.1 최종 숫자 타입 강제

```ts
type Headline =
  | { posture: 'income';         monthlyNetCashFlow: number }
  | { posture: 'owner_occupied'; effectiveBurden: number; savedRent: number }
  | { posture: 'development';
      mode: 'sale' | 'hold';
      profitRate?: number;          // sale
      postDevYield?: YieldValue;    // hold ← 잠원동
      startDate: Date | null;
      vacateResponsibility: 'seller' | 'buyer' | 'undecided' }
  | { posture: 'operating';      gop: number; verificationLevel: VerifyLevel }
  | { posture: 'trading';        holdingCost: number; exitPrice: number };
```

## 12. 남은 확인 사항

v3.0에서 **명도 관행이 해소**되었습니다. 남은 것은 다음 넷입니다.

| # | 항목 | 왜 |
|:-:|---|---|
| 1 | 제이에스 수임 물건의 **포스처 분포** | 확장 순서 재배열 근거 |
| 2 | 개발형 중 **분양형 vs 보유형 비율** | 최종 숫자 우선순위 |
| 3 | 운영형(호텔·요양·주유소) 취급 여부 | 16일 투자 여부 |
| 4 | 매수 주체 **개인 vs 법인 비율** | 매매형 세율 분기 · 사옥형 수요 |

> **1번이 가장 중요합니다.** v3.0에서 개발형 진입 장벽이 낮아졌으므로, 수임 비중에 따라 2순위로 올릴 수 있습니다.

### 12.1 조사로 해결되지 않는 것

| 항목 | 이유 |
|---|---|
| 개별 물건의 명도 특약 실제 조건 | 계약서를 봐야 앎 |
| 호텔 실적 진위 | 부가세 신고서 대조 필요 |
| 법인별 세후 효과 | 과세표준·건물분 비중에 따라 상이 |
| 소형 개발 실제 PF 조달 조건 | 금융기관 개별 협의 |

**전부 결손으로 표시하는 것이 정답입니다.**
