### 2.2 실투자금 2개 — 같은 라벨로

| 위치 | 값 | 산출 |
|---|--:|---|
| p3 ① "실투자금 (내 돈)" | **54.6억** | 115 − 57.5(대출) − 2.9 ✓ |
| p3 하단 "실투자금(내 돈)" | **118.4억** | 총취득 121.33 − 2.9 ✓ |

**두 계산 모두 개별적으로는 맞습니다.** 문제는 **같은 라벨로 같은 페이지에 병존**한다는 것입니다.

더 나쁜 것은 118.4억 쪽 설명입니다.

> "실투자금(내 돈) 약 118.4억 원 — **대출·보증금 제외 필요자본**"

**대출을 제외했다면 54.6억이어야 합니다.** 설명과 값이 반대입니다.

### 2.3 자기자본수익률 2개 — 부호가 반대

| 위치 | 값 | 설명 |
|---|--:|---|
| p3 ③ | **−0.46%** | 실투자금 대비 연 순수익 |

**"대출 활용 시"라고 적힌 쪽이 양수입니다.** 실제로는 대출을 쓰면 −0.46%가 됩니다. **역레버리지 물건에서 정확히 반대 신호를 줍니다.**

> §1.3에서 개선으로 꼽은 "역레버리지 표시"가 **같은 페이지에서 무력화됩니다.**

## 3. 🔴 차단 2 — 데이터 파싱 오류 4건

| # | 항목 | 산출물 | **실측 / 판정** |

### 3.1 "주차 2,504대"가 가장 명백합니다

**5층 근생빌딩에 2,504대 주차장은 존재할 수 없습니다.** 건축물대장 파싱에서 다른 필드가 들어간 것으로 보입니다.

> **범위 검증(sanity check)이 없습니다.** "주차 대수 ≤ 연면적/30㎡" 정도의 상한만 걸어도 잡힙니다.

### 3.2 연면적 408.39㎡ — 세 번째 값

| 회차 | 값 |
|---|---|
| 실측 (층별 합) | 1,441.15㎡ |
| 실측 (표 계 행) | 1,141.15㎡ |
| v3 | 0㎡ |
| **v4** | **408.39㎡** |

**골든 G02가 가르치는 것은 "1,441.15와 1,141.15 중 어느 쪽이 정본인지 확인 필요"입니다.** 산출물은 매 회차마다 새 값을 냅니다.

## 4. 🔴 차단 3 — 시세 벤치마킹이 다른 기준끼리 비교합니다

p5 「권역 시세 벤치마킹」

| 항목 | 값 |
|---|--:|
| 본 자산 ㎡당 단가 | **28,159,357원/㎡** |
| 권역 평균 ㎡당 단가 | **6,028,226원/㎡** |
| 시세 대비 포지션 | **🔴 +367.1% 프리미엄** |
| 경쟁력 판정 | **고평가 — 협상 여지 검토** |

**산술은 정확합니다** (4.671배 → +367.1%). **문제는 분자와 분모의 기준이 다르다는 점입니다.**

```
분자 = 115억 ÷ 408.39㎡(연면적)  = 2,816만원/㎡   ← 연면적 단가
분모 = 실거래 비교사례 10건 평균                   ← 통상 토지 단가
```

**연면적 단가를 토지 단가와 비교하면 항상 몇 배로 나옵니다.**

### 4.1 이 오류가 매도인에게 직접 손해를 입힙니다

> "**고평가 — 협상 여지 검토**"

**근거 없는 고평가 판정입니다.** 매수인이 이 표를 근거로 가격 협상을 시작합니다. 게다가 §3의 연면적 408.39㎡ 자체가 틀린 값이므로 **틀린 면적 × 틀린 기준**입니다.

> **`CapRateBasis`처럼 단가에도 basis 표기가 필요합니다.** (D3 §2.2 확장)

### 10.1 3번이 가장 급합니다 — 매도인에게 직접 손해

**"+367.1% 프리미엄 · 고평가"는 가격 협상의 근거가 됩니다.** 연면적 단가와 토지 단가를 비교한 결과라면 **판정 자체가 성립하지 않습니다.**

```ts
export interface UnitPrice {
  value: number;
  basis: 'per_land_pyeong' | 'per_land_sqm' | 'per_gfa_pyeong' | 'per_gfa_sqm';
}

export function compareUnitPrice(subject: UnitPrice, market: UnitPrice) {
  if (subject.basis !== market.basis) {
    throw new Error(`단가 기준 불일치: ${subject.basis} vs ${market.basis}`);
  }
  return subject.value / market.value - 1;
}
```

**타입으로 막으면 이 오류는 컴파일 단계에서 걸립니다.**
