| 7 | A16 신설 · A03 표 | 렌더 | D7 §3·§5 | 중 |

### 4.1 1·3·4번이 같은 원리입니다

**셋 다 "이미 계산된 값을 화면에 연결"하는 작업입니다.**

```ts
// 게이트 결과가 있는데 화면이 안 봅니다
const violations = runDeterministicGates(core);   // ← 계산됨
const deficiencies = core.deficiencies;           // ← 계산됨

// 화면은 고정값을 씁니다
<Badge>✓ 확인됨</Badge>                            // ← 무조건
<Note>{FIXED_DISCLAIMER}</Note>                    // ← 무조건
```

**세 곳을 연결하면 당산동은 "확인 필요 4건", 양평동은 "확인 필요 6건 + 서류 교체 요망"이 자동으로 표시됩니다.**

### 4.2 회귀 방지 테스트 4종

```ts
it('RG-BADGE-01 결손이 있는 섹션에 "확인됨"을 표시하지 않는다', () => {
  const html = renderMobile(dangsanCore);
  expect(html).not.toMatch(/확인됨[\s\S]{0,400}갱신요구권\s*\d+\s*년/);
});

it('RG-TRUNC-01 절삭 후 괄호 짝이 맞는다', () => {
  for (const t of allPptxTexts()) expect(count(t,'(')).toBe(count(t,')'));
});

it('RG-FIXED-01 두 물건의 25자+ 문구가 겹치지 않는다', () => {
  const a = texts(dangsanPptx), b = texts(yangpyeongPptx);
  const shared = intersect(a,b).filter(x => x.length > 25 && !isDisclaimer(x));
  expect(shared).toHaveLength(0);
});

it('UT-ROE-02 ROE는 무차입 ROE를 넘지 않는다', () => {
  const max = rows.find(r => r.ltv === 0)!.roe!;
  for (const r of rows) expect(r.roe!).toBeLessThanOrEqual(max + 1e-9);
});
```

**`RG-FIXED-01`은 면책·출처 표기를 예외로 두되, 물건 설명 문구는 전부 잡습니다.**
