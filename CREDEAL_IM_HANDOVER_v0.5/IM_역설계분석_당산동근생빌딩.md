## 1. 잠원동과 무엇이 다른가

두 IM을 나란히 놓으면 자산군 Pack이 왜 필요한지가 드러납니다.

| | 잠원동 두원빌딩 | **당산동 근생빌딩** |
|---|---|---|
| 작성 | 히트리얼티 | **제이에스부동산중개법인** |
| 분량 | 19슬라이드 | **10슬라이드** |
| 자산군 | `development` | **`income`** |
| 밸류애드 축 | 신축 개발 | **임대료 현실화** |
| 임대차 | 명도 조건 → IM에 없음 | **현황 + 현실화 계획 2개 표** |
| 등기 | 단독 소유 | **층별구분등기 (형제 2인)** |
| 특이 | 2필지 · 제척 검증 필요 | **자가사용분 2개 층 혼재** |
| 수익률 표기 | 신축 후 참고치 | **기대 수익률 연 3.1%** |

**JS의 IM은 훨씬 간결합니다.** 19장 → 10장이고, 호재·현장사진 비중이 낮으며 **임대 분석에 2개 슬라이드를 할애**합니다. 수익형 브로커의 관심사가 그대로 드러납니다.

## 3. 수치 검산

### 3.1 일치 확인

| 항목 | IM 기재 | 검산 | 판정 |
|---|---|---|---|
| 건폐율 | 51.9% | 263.01 ÷ 506.8 = 51.9% | ✓ |
| 토지 평단가 | 약 75백만원/평 | 115억 ÷ 153.31평 = 75.0백만 | ✓ |
| 현재 보증금 계 | 290,000천원 | 층별 합산 | ✓ |
| 현재 월세 계 | 19,460천원 | 층별 합산 | ✓ |
| 현실화 보증금 계 | 370,000천원 | 층별 합산 | ✓ |
| 현실화 월세 계 | 28,670천원 | 층별 합산 | ✓ |
| 기대 수익률 | 연 3.1% | 28,670×12 ÷ (115억−3.7억) = **3.09%** | ✓ |

### 3.2 발견 1 — 연면적 300㎡ 오기

층별 임대면적을 합산하면 IM 기재 연면적과 맞지 않습니다.

```
층별 합계    317.22 + 78.39 + 105.60 + 252.09 + 252.09 + 169.06 + 83.03 + 183.67
           = 1,441.15㎡ (435.9평)

IM 기재      1,141.15㎡ (307.9평)     ← 물건개요 · 층별표 계 양쪽
차이            300.00㎡
```

**1441 → 1141 타이핑 오기로 보입니다.** 평 표기(307.9)도 함께 틀렸습니다 — 1,441.15㎡는 435.9평입니다.

### 3.3 발견 2 — 용적률 221.8%는 지상층 기준 (잠원동과 동일 패턴)

```
전체 연면적 기준   1,441.15 ÷ 506.8 = 284.4%
지상층 기준        1,123.93 ÷ 506.8 = 221.8%   ← IM 기재값
```

**잠원동에서 발견한 것과 정확히 같은 패턴입니다.** 서로 다른 두 중개법인이 독립적으로 같은 관행을 쓰고 있습니다.

> `aboveGroundArea` 슬롯의 필요성이 **두 번 독립 확인**되었습니다. 온톨로지 v0.3에 이미 반영했습니다 (`CATALOG_SLOTS.md` §2.2).

### 3.4 발견 3 — NOC 환산 방식 역산

슬라이드 7의 "환산평당가 (NOC/임대면적)" 산식이 명시되지 않아 역산했습니다.

```
NOC = 월세 + 보증금 × 5% ÷ 12        (보증금 운용수익률 5% 가정)
```

| 층 | 계산 | IM 기재 | 판정 |
|---|---|---:|---|
| B1 | (4,580 + 208) ÷ 96.0 | 49.9 | ✓ |
| 1F 약국 | (3,450 + 250) ÷ 23.7 | 155.9 | ✓ |
| 3F | (4,550 + 208) ÷ 76.3 | 62.4 | ✓ |
| 4F 와인 | (3,060 + 125) ÷ 51.1 | 62.4 | ✓ |
| 5F | (3,430 + 42) ÷ 55.6 | 62.4 | ✓ |

1F 내과는 2F와 합산 계약이라 별도입니다 — 합산 NOC 8,743천원을 1F(31.9평 × 124.7) + 2F(76.3평 × 62.4) = 8,739천원으로 안분한 값이 IM 표기와 일치합니다.

**기준단가는 3F 62.4천원/평/월**이고, 1F는 2~2.5배, B1은 80%로 계층화되어 있습니다.

### 3.5 발견 4 — "기대 수익률 3.1%"의 정의

네 가지 산식으로 역산한 결과입니다.

| 산식 | 값 |
|---|---:|
| **연 월세 ÷ 실투자금(매각가−보증금)** | **3.09%** ← IM 기재 |
| 연 월세 ÷ 매각가 | 2.99% |
| 연 NOC ÷ 매각가 | 3.15% |
| 연 NOC ÷ 실투자금 | 3.26% |

**우리 명세의 `broker_equity`(중개인형·실투자금 기준)와 정확히 일치합니다.** Cap Rate 4기준 체계가 실무 관행을 제대로 포착했음을 확인한 셈입니다.

## 4. 결정적 발견 — 임대료 현실화의 법적 제약

IM은 *"약국 & 병원 임대료 인상 추진 가능 예상됨. (약 10년간 임대료 인상 없었음)"* 이라고만 서술합니다. 정밀 모드에서 환산보증금과 갱신요구권을 계산하면 **경로가 호실마다 다릅니다.**

### 4.1 환산보증금 판정 (서울 9억)

| 호실 | 임차인 | 보증금 | 월세 | 환산보증금 | 법 적용 |
|---|---|---:|---:|---:|---|
| 101 | 고은약국 | 0.6억 | 183만 | **2.43억** | 전면 — 5% 상한 |
| 102·201 | 로뎀나무내과 | 1.4억 | 883만 | **10.23억** | 일부 — 상한 없음 |
| 301 | 헬쓰장 | 0.5억 | 455만 | **5.05억** | 전면 — 5% 상한 |
| 401 | 국제와인 | 0.3억 | 260만 | **2.90억** | 전면 — 5% 상한 |
| 501 | 로뎀나무내과 | 0.1억 | 165만 | **1.75억** | 전면 — 5% 상한 |

**5개 중 4개가 전면 적용 대상입니다.** 차임 인상률 5% 상한이 걸립니다.

### 4.2 그런데 5% 상한은 "갱신" 시에만 적용됩니다

IM의 *"임대 11년 경과"* 표기에서 역산하면 최초 계약이 2014년입니다. **계약갱신요구권 10년이 소진되었으므로 임대인이 갱신을 거절할 수 있고, 신규 계약에는 인상률 상한이 없습니다.**

| 호실 | 갱신권 잔여 | 계획 인상률 | 법적 가능 경로 | 실현 가능성 |
|---|---:|---:|---|---|
| B1 (자가) | — | 신규 | 자가 → 임대 전환 | **높음** |
| 101 약국 | **0년** | +88.5% | 갱신권 소진 → 갱신 거절 후 재계약 | 중간 |
| 102·201 내과 | **0년** | 안분 조정 | 갱신권 소진 + 환산보증금 초과 → 제한 없음 | **높음** |
| 301 헬쓰장 | 5.9년 | 0% (동결) | 전면 적용 · 갱신권 잔여 → 5% 상한 | — |
| 401 와인 | 7.0년 | +17.7% | 전면 적용 → **5% 상한 초과** | **낮음** |
| 402 (자가) | — | 신규 | 자가 → 임대 전환 | **높음** |
| 501 내과 | **0년** | +107.9% | 갱신권 소진 → 갱신 거절 후 재계약 | 중간 |

### 4.3 이것이 IM에 없던 분석입니다

**401 국제와인의 +17.7% 인상은 갱신 시 법적으로 불가능합니다.** 전면 적용 대상이고 갱신요구권이 7년 남았으므로 5% 상한(2,600 → 2,730천원)이 적용됩니다. 계획 3,060천원 대비 330천원 미달입니다.

반대로 **약국·내과는 갱신권이 소진되어 협상력이 임대인에게 있습니다.** IM이 "10년간 인상 없었음"이라고만 쓴 부분의 실질이 이것입니다 — 인상 여력이 아니라 **갱신 거절권**이 협상의 근거입니다.

다만 여기에 리스크가 따릅니다.

> **우량 임차인(병원·약국)을 잃으면 오히려 손해입니다.** IM의 제안 Point 3번이 *"우량 임차인(병원/약국)으로 인해 낮은 공실리스크"* 인데, 갱신 거절로 임대료를 올리려다 이탈시키면 그 강점이 사라집니다. 정밀 IM은 이 상충을 명시해야 합니다.

## 5. 신규 슬롯 제안 — 층별구분등기

이 물건은 **층별구분등기**이며 소유자가 형제 2인입니다. 현 온톨로지에 이를 표현할 슬롯이 없습니다.

```ts
// title_encumbrance 확장 제안
export const SectionalOwnership = z.object({
  isSectional: z.boolean(),
  units: z.array(z.object({
    unitNo: z.string(),
    level: z.string(),
    exclusiveArea: z.number(),
    landShareRatio: z.string(),        // 대지권 지분
    owner: z.string(),
    acquiredDate: z.string(),
    mortgageMax: Money.nullable(),
    jointCollateralGroup: z.string().nullable(),   // 공동담보 그룹
  })),
  ownerCount: z.number(),
  requiresAllOwnersConsent: z.boolean(),
  partialSaleFeasible: z.boolean(),
});
```

### 왜 필요한가

| 쟁점 | 영향 |
|---|---|
| 전체 매각에 **공유자 전원 동의** 필요 | 한 명이 반대하면 거래 불성립 |
| **일부 호실만 분할 매각** 가능 | 매수 구조가 달라짐 |
| **대지권 지분** 확인 필요 | 지분 합이 1.0이 아니면 누락 필지 존재 |
| **공동담보** 중복 계상 주의 | 채권최고액 단순 합산 시 실제의 2배가 됨 |

마지막 항목은 데이터셋 제작 중 실제로 겪었습니다. 101·102가 공동담보 9억, 301·401이 공동담보 7억인데 단순 합산하면 32억이 되어 실제(16억)의 두 배가 됩니다.

> **제약 C29 신설 제안** — 공동담보 그룹이 지정된 근저당은 그룹당 1회만 합산.

## 7. 온톨로지 개선 제안 3건

| # | 항목 | 근거 |

| 1 | `SectionalOwnership` 슬롯 (§5) | 구분등기 물건은 동의·분할매각·지분 확인이 전부 달라짐 |
