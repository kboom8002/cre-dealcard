## 7. 수익 구조 — 호텔은 GOP 기준

```
연 객실매출 = 94실 × RevPAR 74,100원 × 365일 = 25.42억
부대매출 (11%)                                =  2.80억
────────────────────────────────────────────────────
총매출                                        = 28.22억
GOP (마진 38%)                                = 10.72억
```

| 지표 | 값 |
|---|---:|
| **객실당 단가** | **3.19억/실** |
| **Cap Rate (GOP ÷ 매각가)** | **3.57%** |
| 매출 배수 | 10.6배 |
| GOP 배수 | 28.0배 |

> **이 Cap Rate를 수익형 부동산의 NOI 기준과 직접 비교하면 안 됩니다.** GOP는 운영 인건비·마케팅비를 차감한 뒤의 값이고, 임대차 NOI와 성격이 다릅니다. 제약 C31이 GOP 기준임을 반드시 표기하도록 강제합니다.
