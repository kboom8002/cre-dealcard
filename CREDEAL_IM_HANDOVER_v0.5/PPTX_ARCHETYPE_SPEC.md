**슬라이드 마스터를 쓰지 않고 절대 좌표로 렌더합니다.** 모든 신규 아키타입은 `M + CW = 12.713`과 `본문 끝 ≤ 6.75`를 만족해야 합니다.

```ts
export const M = 0.62, CW = 12.093, RIGHT = M + CW;      // 12.713
export const BODY_MAX_Y = 6.75, FOOTER_Y = 6.94;

export function assertBounds(el: { x: number; y: number; w: number; h: number }) {
  if (el.x + el.w > RIGHT + 1e-6) throw new Error(`우측 이탈: ${(el.x + el.w).toFixed(3)}`);
  if (el.y + el.h > BODY_MAX_Y + 1e-6) throw new Error(`Footer 침범: ${(el.y + el.h).toFixed(3)}`);
}
```

**CI에서 전 아키타입에 `assertBounds`를 돌립니다.**

```ts
  sub: core.deficiencies.slice(0, 2).map(d => d.label).join(' · ') }
```

**0건이면 "확인 필요 없음"이 아니라 "제출 자료 전량 확보"로 표기합니다.** 결손이 없다는 사실 자체가 강점입니다.

### 6.3 그리드 유지

**2×4를 2×2로 줄이지 않습니다.** SSoT v1.1의 "숫자 3개로 축소" 권고를 정정합니다. 문제는 개수가 아니라 지표 선택이었습니다.

## 7. A07 리스크 3구획 재설계

| 구획 | 내용 | 색 |
|:-:|---|---|
| 1 | **확인된 리스크** — 근거 있는 사실 | `C.ink2` |
| 2 | **확인 필요** — `Deficiency[]` | `C.amber` |
| 3 | **해당 없음** — 확인해서 문제없던 항목 | `C.slate` |

**3구획이 필요한 이유는 "빈칸"과 "확인해서 없음"이 다르기 때문입니다.** 현행은 둘 다 표시하지 않아 매수인이 구분할 수 없습니다.

```
❌ (아무것도 안 씀)
✅ 권리 제한: 확인 필요 — 등기부 미제출
✅ 권리 제한: 해당 없음 — 2026-08-20 등기부 확인
```

**"권리제한 없음"을 근거 없이 쓰는 것이 이번 진단에서 확인된 AI 생성 오류 6건 중 하나였습니다.** (게이트 G13)
