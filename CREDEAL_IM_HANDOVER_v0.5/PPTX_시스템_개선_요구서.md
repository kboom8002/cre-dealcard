## 1. 🔴 차단 5건

### 1.1 등급 체계가 세 벌 돌고 있습니다

| 체계 | 어디에 | 값 |
|---|---|---|
| 데이터 품질 등급 | `deck-sequencer` | **A / B / C / D** |
| 렌트롤 해상도 | `IM_RESOLUTION_TIERS` 정본 | **R0~R3** |
| **이중 해상도** | **D19 v2.0 §3.3** | **L(R0~R3) × P(P0~P3)** |

**같은 물건이 세 개의 등급을 갖습니다.** 시퀀서는 A~D로 슬라이드를 고르고, 정본은 R로 기능을 열고, D19는 L×P로 블록을 엽니다.

**조치** — A~D를 폐기하고 **L×P에서 유도**합니다.

```
등급 = f(L, P)
  A  L≥R2 & P≥P2      풀 기관투자 덱
  B  L≥R1 & P≥P2      공공 결합 표준 덱
  C  L≥R1 & P=P1      원장 기반 덱
  D  L=R0 또는 P=P0    최소 덱 (내부 검토용)
```

**당산동 ②는 L=R1 · P=P2 → B**입니다. 현행 시스템이 이 물건에 어떤 등급을 주는지 확인이 필요합니다.

### 1.2 슬라이드 단위 억제 — 블록 단위여야 합니다

현행은 **"빈 데이터 페이로드 슬라이드 자동 억제"** 입니다. 면 전체를 지웁니다.

| | 현행 | **D19 §8.2** |
|---|---|---|
| 단위 | 슬라이드 | **블록 (47종)** |
| 처리 | 억제(삭제) | **확인 필요 / 산출하지 않음 / 면 유지 + 안내** |
| 사유 | 경고 로그에만 | **화면에 노출** |

**면을 지우면 "없다"는 사실도 같이 사라집니다.** 정본 §4.2 ⑦ — "확인 필요 칸을 비우지 않습니다. 비어 있으면 오히려 의심받습니다."

**조치** — `input_spec.evaluate()`를 시퀀서 앞단에 넣고, 블록별 판정을 아키타입 빌더에 내려보냅니다.

### 1.3 출처 표기 슬롯이 없습니다

**토큰 53개 중 출처 관련이 0개입니다.** 표에 출처 열이 없고, 근거 칩 컴포넌트가 없습니다.

D19 §1은 모든 수치에 **S1 공부 / S2a 공공 원시 / S2b 공공+보강 / S3 원장 / S4 파생 / S5 가정** 중 하나를 요구합니다.

**조치** — 토큰 7종 신설 (§4.1) + `L.rows()`에 출처 열 인자 추가.

### 1.4 comps 보강 상태를 시스템이 모릅니다

A03이 `comps`를 렌더하지만 **원시(S2a)와 보강(S2b)을 구분하지 않습니다.**

**실거래 API는 지번을 마스킹하고(`1***`) 집합건물 대지면적을 주지 않습니다.** 보강 없이 만든 토지 평당가 비교는 성립하지 않습니다 (D19 §1.3).

**조치** — `comps_table` 블록을 `comp_identify` 등 5필드로 게이팅. 미보강이면 **"원시 자료 n건 조회됨 — 보강 필요"** 로 표기.

### 1.5 텍스트 예산이 라벨을 자릅니다

| 현행 | 값 |
|---|--:|
| `slideTitle` | 32자 |
| 테이블 셀 | **45자 절단** |
| `statLabel` | 18자 (동적 축소) |

**D17 §2.5 E01이 정확히 이 구조에서 나왔습니다** — `"현재 연 순수익률 (Cap R"` 로 끊긴 사고. 20자 예산이 라벨에 적용된 결과였습니다.

**조치** — **라벨·헤더·단위는 절삭 금지.** 넘치면 폰트를 줄이고, 그래도 안 되면 **다음 면으로 흘립니다.** 절삭은 자유서술 본문에만 허용합니다.

## 2. 중대 6건

### 2.1 분량 상한 24장 — 정본은 16장

| 기준 | 값 |
|---|---|
| 현행 하드캡 | **24장** |
| **정본 §3.1** | **필수 12p · 필수+권장 16p** · 30p+는 "과함 · 부티크 작성 불가" |

**24장은 정본이 "컨설팅사" 구간으로 분류한 쪽에 가깝습니다.** A등급 풀 덱이 24장이면 중개인이 90분에 검수할 수 없습니다.

**조치** — 프리셋별 상한을 두고 기본 16, 근거 특화 18로 제한합니다.

### 2.2 사진이 조건부입니다

| 위치 | 현행 | **국내 관행 (D19 §6A)** |
|---|---|---|
| A01 커버 | 커버 스타일 5종 중 사진 필수는 2종 | **표지 사진 기본** |
| A04 우측 | "사진 없으면 콜아웃 카드로 대체" | **개요 우측 사진 기본** |
| A14 갤러리 | 조건부(`hasPhotos`) | 외부·내부 각 1면 |

**실물 IM 3종을 분해한 결과, 사진 전진배치가 국내 IM의 기본형입니다.** 사진이 없으면 대체가 아니라 **"사진 미제출"을 남겨야** 합니다 — 그게 자료 요청서입니다.

### 2.3 매매가 강조가 규약화되어 있지 않습니다

프리셋 의미색에 `red`가 있지만 **"매매가 = 적색"** 이 어디에도 정해져 있지 않습니다.

**잠원동·당산동 실물 IM 모두 매매가를 적색으로 강조합니다.** 국내 IM의 사실상 표준입니다.

### 2.4 교차검증 X1~X4가 없습니다

공부값을 받아 **그대로 렌더합니다.** 이번에 당산동에서 **층별 합계 기재 오류(1,141.15 vs 1,441.15)** 를 용적률 역산으로 잡았습니다. 시스템에 같은 장치가 없으면 그 오류가 그대로 나갑니다.

### 2.5 IMCore가 환경변수 뒤에 있습니다

```
RENDER_PATH !== 'imcore'  →  레거시 마크다운 파싱 (기본값)
RENDER_PATH === 'imcore'  →  IMCore 직접
```

**기본값이 마크다운 파싱입니다.** D17 원인 H(동일 지표 중복 산출)와 E02(마크다운 미렌더)가 전부 이 경로에서 나왔습니다.

**조치** — IMCore를 기본으로 승격하고 마크다운 경로를 폴백으로 내립니다.

### 2.6 A11·A12가 살아 있습니다

D3 §6.1에서 **dead code로 판정해 타입에서 제외**했는데, 아키텍처 문서에는 17개로 남아 있습니다. **운용 15종**이 정본입니다.
