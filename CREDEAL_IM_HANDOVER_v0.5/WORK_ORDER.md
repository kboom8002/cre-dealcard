## 6. 차단 해제가 필요한 것 3건

**이 셋은 위 스프린트로 풀리지 않습니다.** 별도 의사결정이 필요합니다.

### B1 · 이미지 마스킹 — 검출 모델 🔴

| | |
|---|---|
| 무엇 | 임차인 상호 간판 · 차량 번호판 · 보행자 얼굴 |
| 실측 | 당산동 hero·front·ext1 전부 식별 가능. 보행자 4~5인 |
| 현 상태 | `G20` 게이트는 있고 **검출이 없습니다** |
| 제약 | 🔴 **마스킹 전 원본을 외부 API로 보내지 않습니다** — 그 사진에 상호가 있습니다 |
| 필요 | 온프레미스 검출 모델 도입 결정 · 예산 |
| 임시 | `G20`을 `warn`으로 두고 **사람이 확인**. 상용 발행 시 필수 절차로 |

**이것이 풀리지 않으면 상용 발행이 안 됩니다.** 불변조건 14 위반입니다.

### B2 · `QG01~QG16` 실제 정의

운영 게이트 16종의 내용이 이 레포에서 확인되지 않았습니다.
`quality-gates-v02.ts` 열람이 필요합니다 (`IM_QUALITY_GATES.md` §7.3 절차).

**개명 전까지 로그에 출처 접두를 붙입니다** — `publish:G07` / `runtime:G07`.

### B3 · `trading` 수집 경로

`holding_history` 슬롯은 정의됐으나 **등기부 파싱이 미구현**입니다.
입력란(S3-4)과 수집은 다른 일입니다.

**수요가 없으면 미루는 것이 정답입니다.** S2 30일 관측에서 `trading` 선택이
0이면 S3-4·S6-1을 빼고 62.5일이 **57일**이 됩니다.

## 9. 마지막 — 이 세트가 지키려는 것 하나

> **어떤 문서를 읽어도 같은 시스템이 보여야 합니다.**

문서가 많은 것이 문제가 아니었습니다. **같은 규칙이 두 곳에 다르게 적혀 있는 것**,
**규칙의 주인이 폐기 문서에 있는 것**이 문제였습니다. 다필지·제척이 통째로
유실된 사고가 그렇게 났고, `R-INC-02`가 두 뜻이었던 것도 같은 병입니다.

그래서 검사기를 붙였습니다. **검사기가 "정상"을 내는 것과 실제로 정상인 것은
다릅니다** — 결함을 주입해서 잡히는지 확인하지 않은 검사기는 이미 무력화된
것입니다. 실제로 이번에 `doc_integrity`가 그 상태였고, 감사에서 잡혔습니다.

**규칙을 늘리기 전에, 있는 규칙이 지켜지는지 기계가 말하게 하십시오.**
