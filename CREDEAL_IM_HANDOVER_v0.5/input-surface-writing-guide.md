## 1. 시스템 개요

### 1.1 3개 입력 표면

| 단계 | 입력 표면 | 용도 | 결과물 |
|:---:|:---|:---|:---|
| **①** | **딜카드 메모** | 카카오톡 메시지·음성 녹음을 붙여넣기 | 블라인드 딜카드 + SSoT Lite 초기 생성 |
| **②** | **Basic IM 바텀시트** | 메모에서 빠진 핵심 수치를 보완 입력 | Basic 모바일 IM (투자분석 보고서) |
| **③** | **Pro IM 바텀시트** | 관리비·대출·부수수입 등 심화 입력 | Pro 모바일 IM + DCF 민감도 분석 |

### 1.2 데이터 등급 체계 (Grade Engine)

입력한 데이터의 양과 출처 신뢰도에 따라 자동 산출됩니다.

| 등급 | 점수 | 해제되는 기능 | 제한 사항 |
|:---:|:---:|:---|:---|
| **A** | 85–100 | IM 전체 기능 + **DCF 10년 민감도 매트릭스** | 없음 |
| **B** | 65–84 | **Pro IM 생성 가능** | DCF 분석 잠김 |
| **C** | 40–64 | **Basic IM 생성 가능** | 총수익률·캡레이트 "검증 중" 표시 |
| **D** | 0–39 | 없음 | **IM 생성 및 딜카드 공개 차단** |

### 1.3 등급 산출 가중치 (기본값)

| 카테고리 | 가중치 | 해당 필드 예시 |
|:---|:---:|:---|
| 임대 현황 (`lease_roll`) | 25% | 월 임대료, 임차인 목록, 공실률 |
| 건물 기본 (`building_basic`) | 15% | 연면적, 사용승인일, 자산유형 |
| 토지 정보 (`land_parcel`) | 15% | 대지면적, 공시지가 |
| 재무 입력 (`financial_input`) | 15% | 매매희망가 |
| 용도지역 (`zoning`) | 10% | 용도지역, 지구단위계획 |
| 권리 분석 (`title_encumbrance`) | 10% | 등기부 근저당, 소유권 |
| 도로·접근 (`road_access`) | 5% | 접도, 주차 대수 |
| 시세 비교 (`market_comp`) | 5% | 실거래 비교, 감정평가 |
| **팩 슬롯** (`pack`) | 0~30% | 포스처·자산유형에 따라 동적 부여 |

> **팩 슬롯 보너스**: 개발형은 `development_plan +20`, `vacate_plan +10`, `permit_risk +10`이 추가되고 `lease_roll`은 ×0.4로 감소합니다. 운영형은 `hospitality_spec +30`이 추가되고 `lease_roll`은 ×0.0으로 비활성화됩니다.

## 2. 딜카드용 메모 작성 가이드

### 2.1 메모란 무엇인가?

카카오톡 대화방에서 복사한 매물 정보, 또는 음성 녹음을 텍스트로 변환한 내용을 그대로 붙여넣는 자유 형식 입력입니다. AI가 자동으로 구조화하여 딜카드와 SSoT를 생성합니다.

### 2.2 품질 게이트 — 최소 통과 조건

메모는 다음 4가지 카테고리 중 **최소 1가지 이상**의 패턴이 포함되어야 합니다:

| 카테고리 | 인식 키워드 예시 |
|:---|:---|
| 📍 위치 | 역명, 동명, 구명, 권역명, "~로", "~길" |
| 🏢 자산 유형 | 근생, 빌딩, 오피스텔, 물류, 호텔, 상가, 토지 등 |
| 💰 숫자·단위 | ~억, ~만, ~평, ~㎡, ~층 |
| 🤝 거래 유형 | 매각, 매매, 임대, 수익률, 매도, 투자 등 |

### 2.3 3단계 작성 기준

#### 🔴 최소 (Minimum) — "일단 등록"

> **목표**: 품질 게이트 통과 + 딜카드 생성 성공 (Grade D~C)

**필수 포함 요소** (3가지):
- 위치 (동명·구명·역명 수준)
- 자산 유형 (근생빌딩, 오피스텔 등)
- 가격 또는 면적 중 1가지

```
천안 동남구 근생빌딩 35.5억
```

| 항목 | 포함 여부 |
|:---|:---:|
| 위치 (동/구/역) | ✅ |
| 자산 유형 | ✅ |
| 가격 | ✅ |
| 면적/규모 | ❌ |
| 임대 현황 | ❌ |
| 브로커 코멘트 | ❌ |

> ⚠️ 최소 메모만으로는 Grade D(0–39)가 될 가능성이 높아 딜카드 공개가 차단될 수 있습니다. 가능하면 표준 이상을 권장합니다.

---

#### 🟡 표준 (Standard) — "쓸 만한 딜카드"

> **목표**: Grade C(40~64) 도달 → Basic IM 생성 가능

**필수 포함 요소** (6가지):
- 위치 (동명 + 가능하면 상세 주소)
- 자산 유형
- 매매희망가
- 연면적 또는 대지면적
- 층수·구조 (지상/지하)
- 임대 현황 (만실/공실/임대중 등 간략 언급)

```
마포구 합정동 근생빌딩 매물.
지하1층~지상5층, 연면적 약 380평.
매매가 65억, 현재 1층 카페 + 상층 사무실 임대 중.
일부 공실 있음. 건물 상태 양호.
```

| 항목 | 포함 여부 |
|:---|:---:|
| 위치 (동/구/역) | ✅ |
| 자산 유형 | ✅ |
| 가격 | ✅ |
| 면적/규모 | ✅ |
| 층수/구조 | ✅ |
| 임대 현황 | ✅ |
| 공실률 | ✅ (간략) |
| 브로커 코멘트 | ❌ |
| 사진 | ❌ |

---

#### 🟢 충분 (Sufficient) — "고품질 딜카드"

> **목표**: Grade B(65~84) 근접 → 딜카드 마케팅 효과 극대화

**필수 포함 요소** (10가지+):
- 위치 (정확한 주소 또는 번지)
- 자산 유형
- 매매희망가
- 연면적 + 대지면적
- 층수 · 구조 · 사용승인일
- 상세 임대 현황 (층별 임차인, 월 임대료, 보증금)
- 공실률
- 대출 정보 (선순위 근저당 등)
- 매도 사유 또는 특이사항
- 브로커 투자 포인트

```
성수동1가 근생빌딩 매각. 정확한 주소는 비공개 요청.

■ 기본정보
- 지하1층~지상6층 RC조, 연면적 520평, 대지 180평
- 사용승인 2004년, 엘리베이터 1기
- 매매가 82억 (평당 약 4,550만원)

■ 임대현황
- 1F: 카페 (보 5,000 / 월 380), 계약 잔여 2년
- 2F: IT기업 (보 3,000 / 월 280)
- 3~5F: 디자인사무소 (보 8,000 / 월 650)
- 6F: 공실
- 총 보증금 1.6억, 총 월세 1,310만원
- 공실률 약 15%

■ 투자포인트
- 성수 IT밸리 도보 5분, 2호선 성수역 7분
- 건물 외관 리모델링 완료 (2023년)
- 1층 카페 네임드 맛집으로 임차 안정적
- 선순위 근저당 40억 (3.8%)

■ 주의사항
- 6층 공실 장기화 (6개월+), 원상복구 필요
- 매도자: 해외 이주 예정으로 연내 매각 희망
```

| 항목 | 포함 여부 |
|:---|:---:|
| 위치 (동/구/역) | ✅ |
| 자산 유형 | ✅ |
| 가격 | ✅ |
| 연면적 + 대지면적 | ✅ |
| 층수/구조/사용승인 | ✅ |
| 층별 임대현황 | ✅ |
| 공실률 | ✅ |
| 대출/근저당 | ✅ |
| 매도 사유 | ✅ |
| 브로커 포인트 | ✅ |
| 사진 | ❌ (별도 첨부) |

## 3. Basic IM 바텀시트 작성 가이드

### 3.1 바텀시트란?

딜카드 생성 후, "📄 Basic IM 생성" 버튼을 누르면 나타나는 모바일 바텀시트입니다. 메모에서 자동 추출하지 못한 핵심 수치를 보완 입력합니다.

### 3.2 공통 필드 목록

| 필드명 | 설명 | 단위 | 등급 기여도 |
|:---|:---|:---:|:---:|
| 🎯 투자 포스처 | 임대수익·자가사용·개발형·운영형·단기매매 | 선택 | 가중치 동적 조정 |
| 🏠 주소·PNU | 건물 주소 검색 및 PNU 자동 연결 | 텍스트 | +25pt |
| 💰 월 임대료 합계 | 월세 총액 (보증금 제외) | 만원 | +20pt |
| 🔒 보증금 합계 | 임차 보증금 총액 | 만원 | 임대현황 |
| 💰 매매희망가 | 매도자 희망 매매가격 | 만원 | +10~20pt |
| 📊 공실률 | 0%, ~10%, ~20%, 직접입력 | % | +10pt |
| 📸 건물 사진 | 최대 12장 + 개별 캡션 | 파일 | +10pt |
| 📝 브로커 한줄 코멘트 | 이 매물의 핵심 투자 포인트 | 텍스트 | +5pt |
| 📋 층별 임대 현황 | RentRollImporter로 일괄 입력 | 테이블 | 임대현황 25% |

### 3.3 포스처별 추가 팩 슬롯 (Basic)

| 조건 | 추가 섹션 | 주요 필드 |
|:---|:---|:---|
| 포스처 = `development` | 🏗️ 개발 계획 | 목표용도, 목표규모(평), 예상분양가, 공사비 |
| 포스처 = `development` | 📋 명도 조건 | 명도책임(매도/매수/협의), 임차인수, 예상비용, 기간 |
| 포스처 = `development` | ⚖️ 인허가 | 허가상태, 예상소요기간, 허가종류 |
| 포스처 = `owner_occupied` | 🏢 사옥 계획 | 예상인원, 1인당면적, 희망층수, 현재임차료 |
| 자산유형 = 호텔/숙박 | 🏨 운영 사양 | 객실수, ADR, OCC, GOP마진, 운영모델 |
| 자산유형 = 물류 | 🏭 물류 사양 | 층고, 기둥간격, 바닥하중, 독, 냉동/냉장 |
| 자산유형 = 오피스텔/지산 등 | 📊 구분소유 | 구분소유자수, 토지지분, 관리단, 마스터리스 |
| 자산유형 = 다세대/상가주택 등 | 🏠 주거 사양 | 세대수, 전세/월세 비율, 전세보증금, 위반건축물 |

### 3.4 3단계 작성 기준

> **목표**: Grade B (70~84점) → Pro IM 업그레이드 자격 확보

## 4. Pro IM 바텀시트 작성 가이드

### 4.1 Pro IM이란?

Basic IM에서 Grade B(65점) 이상일 때 활성화되는 심화 IM입니다. 레버리지·DCF·세금 시뮬레이션 등 전문 투자 분석이 추가됩니다.

### 4.2 Pro 전용 추가 필드

| 필드명 | 설명 | 단위 | 등급 기여도 |
|:---|:---|:---:|:---:|
| 🏦 관리비 합계 | 월 관리비 총액 | 만원 | 운영비율 정밀화 |
| 💳 대출 상태 | 대출확정/미대출/미확인 | 선택 | 레버리지 분석 |
| 💰 대출 금액 | 선순위 대출 금액 | 만원 | LTV 산출 |
| 📊 부수수입 | 통신안테나·주차·간판·태양광 등 (연간 금액) | 원 | NOI 보완 |

## 6. 데이터 등급 ↔ 기능 잠금 해제 매핑표

```
                  메모 → 딜카드         Basic 바텀시트 → Basic IM       Pro 바텀시트 → Pro IM
                  ─────────────         ────────────────────────       ─────────────────────
Grade D (0-39)    ⚠️ 발행 차단          ❌ IM 생성 불가                 ❌ 접근 불가
Grade C (40-64)   ✅ 딜카드 발행         ✅ Basic IM 생성               ❌ 접근 불가
Grade B (65-84)   ✅ 딜카드 발행         ✅ Basic IM 생성               ✅ Pro IM 생성 (DCF 잠김)
Grade A (85-100)  ✅ 딜카드 발행         ✅ Basic IM 생성               ✅ Pro IM + DCF 10년 민감도
```

### 최적 워크플로우

```
① 메모 붙여넣기 (표준 수준)
    └─→ 딜카드 생성 (Grade C~D)
         └─→ ② Basic 바텀시트 (표준 수준)
              └─→ Basic IM 생성 (Grade C~B)
                   └─→ ③ Pro 바텀시트 (충분 수준)
                        └─→ Pro IM + DCF (Grade A)
```

### 7.3 데이터 출처(Provenance) 신뢰 계수

| 출처 | 계수 | 설명 |
|:---|:---:|:---|
| `public_data` | 1.00 | 건축물대장·토지이용계획 등 공공 데이터 |
| `expert_verified` | 0.95 | 전문가(감정평가사 등) 확인 |

| `broker_confirmed` | 0.85 | 외부 데이터를 중개인이 확인/승격 |

> 같은 필드라도 공공 데이터 출처이면 1.0, 브로커 입력이면 0.60 계수가 적용됩니다. 바텀시트에서 PNU를 연결하면 건축물대장·토지이용계획이 자동 수집되어 `public_data`(1.0) 계수로 반영되므로, **주소 검색(PNU 연결)이 등급 상승에 가장 효과적인 첫 단계**입니다.
