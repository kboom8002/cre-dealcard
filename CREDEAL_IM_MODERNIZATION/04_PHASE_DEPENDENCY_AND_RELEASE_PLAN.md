# 단계 의존관계와 릴리스 계획

## 1. 프로그램 의존그래프

```text
M0 기준선·정본
  ↓
M1 안전봉합 ───────────────┐
  ↓                        │
M2 실행·하네스 공통기반    │
  ├─ M3 딜카드             │
  └─ M4 IM CORE v1 ◀───────┘
       ├─ M5 모바일 L1/L1.5
       └─ M6 PPTX Studio
             ↓
       M7 변경영향·재생성
             ↓
       M8 병행전환·폐기
```

시험·관측·운영준비는 M0부터 M8까지 병행한다.

## 2. 단계별 진입·종료조건

| 단계 | 진입조건 | 종료조건 | 다음 단계 차단 |
|---|---|---|---|
| M0 | 프로그램 책임자 지정 | DEC-001~005 승인, DEC-006~018 책임자·기한, 기준자료, 정본소유권 | 미결정 핵심상태·산식 |
| M1 | 현행 호출경로 재현 | 빈 승인·허위 통과·P0 오표현 차단 | 차단급 오류 미봉합 |
| M2 | M1 설계 동결 | 재개·멱등·불변 산출물·7상태 실행 | 체크포인트·해시 없음 |
| M3 | M2 메모/발행 프로필 가능 | 블라인드 딜카드 카나리·무효화 | 정확주소·무단보완 노출 |
| M4 | M2 안정, D55 계약 승인 | Snapshot·Claim·Package와 CORE 검사 | 채널이 원시자료 필요 |
| M5 | M4 Package 안정 | 모바일 독립 L1/L1.5와 승인 | 의견·사진 추적 미완 |
| M6 | M4 + 채널중립 ContentUnit | 모바일 없이 PPTX 생성·파일검사 | 최종파일 관측 미실행 |
| M7 | M5·M6 발행버전 존재 | 변경 13종의 예상 무효화·최소 재생성 | 과잉·누락 무효화 |
| M8 | 자동시험·롤백 준비 | 카나리 100%, 구형 신규사용 0 | 중대 차이·복구 실패 |

## 3. 단계 릴리스 형태

### M0

코드 배포 없음. 결정·기준자료·소유권만 동결한다.

### M1

기존 경로에 안전패치를 배포한다. 기능깃발은 검사 강제여부만 제어하며 심각도를 바꾸지 않는다.

### M2

새 실행기와 하네스를 그림자 실행한다. 외부 결과는 구형 경로가 유지하되 차이는 기록한다.

### M3

내부 사용자→선정 중개인→일부 신규 딜카드 순서로 전환한다. 정확주소·재식별·중개인 확인 실패 시 즉시 중단한다.

### M4

CORE 결과를 그림자 생성하고 구형 결과와 값·단위·기준일·허용상태를 비교한다. 채널 외부발행은 아직 구형 또는 M5 전환정책을 따른다.

### M5·M6

채널별로 독립 카나리한다. 한 채널의 전환률이 다른 채널의 전환률을 강제하지 않는다.

### M7

처음에는 무효화계획을 제안만 하고 기존 승인을 자동 취소하지 않는 `shadow`로 검증한다. 예상 일치율이 승인기준에 도달한 뒤 강제한다.

### M8

1% → 10% → 50% → 100%로 신규 거래건 기본경로를 전환한다. 각 단계는 최소 관측창과 중단조건을 가진다.

## 4. 병렬 작업트랙

| 트랙 | 시작 | 외부 활성 조건 |
|---|---|---|
| 제품·도메인 정본 | M0 | 제품·도메인 승인 |
| 파이프라인 플랫폼 | M1 후반 | M2 종료 |
| 게이트 공통 실행기 | M1 | M2 종료 |
| 딜카드 | M2 계약 동결 | M3 종료 |
| IM CORE | M1 기준자료 후 설계 | M4 종료 |
| 모바일 UI | M4 계약 초안 | M5 종료 |
| PPTX Studio UI | M4 계약 초안 | M6 종료 |
| 품질·fixture | M0 | 각 단계 종료의 선행 |
| 관측·운영 | M1 | M8 종료의 선행 |

UI 뼈대와 렌더러 실험은 병렬 가능하지만, 임시 사실계약을 외부발행에 사용하지 않는다.

## 5. 관리 릴리스 게이트

| 관리 게이트 | 판정 질문 |
|---|---|
| MG-0 | 제품·도메인·상태·정본 결정이 승인됐는가 |
| MG-1 | 현재 경로의 차단급 허위 통과를 제거했는가 |
| MG-2 | 실행·산출물·검사결과를 중단 후 재현할 수 있는가 |
| MG-3 | 딜카드가 IM과 분리되어 안전하게 공개되는가 |
| MG-4 | CORE 패키지만으로 채널이 필요한 사실을 얻는가 |
| MG-5 | 모바일 L1/L1.5가 실무 품질과 추적성을 충족하는가 |
| MG-6 | PPTX 최종파일이 실제 관측·승인됐는가 |
| MG-7 | 변경별 무효화·재생성이 정확한가 |
| MG-8 | 카나리·복구·사용량 조건을 충족했는가 |

관리 게이트는 도메인 게이트 ID와 구분한다. 제품·기술·품질 책임자의 단계종료 결정이다.

## 6. 전환 중단조건

- 차단급 검사가 `NOT_RUN`인데 발행됨
- 동일 패키지의 모바일·PPTX 핵심값 불일치
- 정확주소·개인정보·승인되지 않은 사진 노출
- 기존 승인과 현재 해시 불일치인데 승인 재사용
- P50 이후 채널이 원시 공공자료를 직접 사용
- 변조시험이 검사기를 통과
- 복구 시 기존 발행본이나 사용자 편집이 소실
- 중개실무 품질평가 항목 중 3점 미만 발생

중단 시 신규 비율을 올리지 않고 원인 단계의 기능깃발만 되돌린다. 데이터는 삭제하지 않는다.
