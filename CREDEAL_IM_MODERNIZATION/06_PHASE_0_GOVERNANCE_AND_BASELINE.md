# M0 — 기준선 확정과 개발 통제

> 단계 ID: `CIM-M0` · 종료게이트: `MG-0`

## 1. 목적

D54·D54-A·D55를 업무 기준, D58과 세 개 하위 작업지시서를 설계 입력으로 확정한다. 현행 동작과 오류를 기록하여 개편 중 “개선처럼 보이는 회귀”를 막는다.

## 2. 실행 작업

1. 제품책임자는 문서 우선순위와 변경승인자를 확정한다.
2. 개발팀은 메모→딜카드, 바텀시트→모바일, 모바일→PPTX의 현행 호출·DB·파일·승인 흐름을 추적한다.
3. 대표 거래건을 최소 12건 선정한다.
   - 단일/다중 필지
   - 렌트롤 없음/최소/표준/완전
   - 임대차 합계 불일치
   - 사진 부족/중복/저해상도
   - L1/L1.5 후보
4. 현재 산출물, 입력, 로그, 검사 결과를 동일 실행묶음으로 보존한다.
5. 기존 URL·파일키·승인기록·재실행 동작을 기준선 표로 만든다.

## 3. 필수 산출물

- 현행 계통도와 데이터 소유권 표
- 기준 거래건 목록과 개인정보 비식별 확인
- 현행 오류목록과 재현 절차
- 구형 호환성 목록
- 요구사항 추적표 초판
- 기능깃발·관측·되돌리기 공통규칙

## 4. MG-0 통과조건

- 제품·도메인·기술·품질 책임자가 정본 우선순위에 서명했다.
- 각 현행 경로를 대표 거래건으로 재현할 수 있다.
- 주요 DB·객체저장소·작업큐의 소유 팀이 정해졌다.
- 기준선 산출물과 로그가 변경불가 위치에 보존됐다.
- 공개 전용 데이터와 내부 데이터의 경계가 문서화됐다.

## 5. 금지사항

- 기준선 없이 전면 재작성 시작
- 과거 발행본을 신형 스키마로 덮어쓰기
- D55 등급을 페이지 수 또는 템플릿 이름으로 축약
- “나중에 정한다”는 이유로 승인·해시·개인정보 항목을 비워두기
