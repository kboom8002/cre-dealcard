# M1 — 즉시 안전봉합

> 단계 ID: `CIM-M1` · 선행: M0 · 종료게이트: `MG-1`

## 1. 목적

신규 기능보다 먼저 현재의 허위통과, 조용한 생략, 승인표류, 임의 숫자 생성 경로를 막는다. 이 단계는 새 IM을 만드는 단계가 아니라 잘못된 IM의 외부발행을 차단하는 단계다.

## 2. 우선순위

| 순번 | 봉합대상 | 구현 |
|---:|---|---|
| 1 | 검사 미실행·판정불가·도구오류가 통과 | `NOT_RUN`, `INDETERMINATE`, `SYSTEM_ERROR`를 별도 상태로 보존하고 차단검사이면 발행 금지 |
| 2 | 승인 대상 불명확 | 승인을 `artifact_version_id + target_hash + actor + timestamp`에 결속 |
| 3 | 템플릿 잔존값 | 필수자리표시자·이전 매물 식별자·숨김개체 검사 |
| 4 | 임대차 산식 오류 | 원행·제외행·합계·정정내역 없이는 수익 주장 금지 |
| 5 | 다중필지 축약 | 필지별 원문과 합산 근거 없이는 통합 수치 차단 |
| 6 | 근거 없는 중개인 의견 | 사실·중개인제공·추정·가상보완 표시를 분리 |
| 7 | 원시 입력 직접 렌더 | 유효기준본/허용된 발행묶음 외 직접 참조 경로 차단 |

## 3. 최소 공통 상태

`PASS`, `FAIL`, `WARN`, `NOT_APPLICABLE`, `NOT_RUN`, `INDETERMINATE`, `SYSTEM_ERROR`

- `FAIL`은 관측 결과가 조건을 위반한 상태다.
- `NOT_APPLICABLE`은 적용조건이 없으며 사유가 필수인 상태다.
- `INDETERMINATE`는 자료 부족·모호성으로 판정할 수 없는 상태다.
- `SYSTEM_ERROR`는 검사 실행 자체를 신뢰할 수 없는 상태다.
- 예외승인은 상태값이 아니라 별도 승인사건이다.
- 차단급 `FAIL`, `NOT_RUN`, `INDETERMINATE`, `SYSTEM_ERROR`는 발행할 수 없다.

## 4. 승인 최소규칙

1. 승인 대상 객체가 실제 저장되어 있어야 한다.
2. 서버가 대상 바이트 또는 정규화 본문의 해시를 계산한다.
3. 요청 해시와 서버 해시가 다르면 거부한다.
4. 선행 게이트가 통과하지 않았으면 거부한다.
5. 대상 또는 의존 입력 변경 시 승인을 무효화한다.
6. 자기승인 허용 여부는 역할정책에 명시한다.

## 5. MG-1 통과조건

- 오류주입 시 `SYSTEM_ERROR`가 `PASS`로 변환되지 않는다.
- 대상 변경 후 이전 승인이 발행권한을 주지 않는다.
- 임대차·면적·가격 차단 오류가 외부발행을 막는다.
- 구형 경로도 동일한 최소 봉합을 적용받는다.
- 관측·경보·되돌리기가 실제 환경에서 검증됐다.
