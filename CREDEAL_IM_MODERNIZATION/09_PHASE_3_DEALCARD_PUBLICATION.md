# M3 — 블라인드 딜카드 세로절단 완성

> 단계 ID: `CIM-M3` · 선행: M2 · 종료게이트: `MG-3`

## 1. 목적

CREDEAL의 첫 산출물인 딜카드를 공통 실행기·검사·승인·발행원장에 완전히 올린다. 딜카드는 낮은 등급 IM이 아니라 메모에서 허용된 공개 사실만 선별한 독립 블라인드 티저다.

## 2. 입력과 경계

- 입력: 중개인 메모, 공개범위 설정, 대표 이미지 후보, 최소 거래식별자
- 메모 파싱 결과는 `관측값`이며 곧바로 사실정본이 아니다.
- 정확주소·소유자·임차인명·연락처·내부 협상정보는 기본 비공개다.
- 딜카드 본문을 모바일이나 PPTX의 사실 입력으로 재사용하지 않는다.

## 3. 처리흐름

1. 메모 원문 저장과 민감정보 탐지
2. 문장별 후보값·근거구간 추출
3. 공개허용·차단·일반화 판정
4. 중개인 확인이 필요한 항목 분리
5. 딜카드 내용묶음 조립
6. 렌더·검사·승인·발행

## 4. 차단검사

- 주소 역추론 위험과 금지 식별자
- 소유자·임차인·연락처 등 개인정보
- 원메모에 없는 가격·수익률·면적 생성
- 이전 매물 잔존값과 자리표시자
- 비공개 이미지·간판·문서의 식별정보
- 발행대상 해시와 승인해시 불일치

## 5. MG-3 통과조건

- 메모→딜카드의 전 단계가 한 실행묶음으로 재현된다.
- 비공개 항목을 심은 변조시험이 모두 차단된다.
- 승인 후 입력 변경 시 공개링크 갱신이 자동 차단된다.
- 기존 공개 URL 정책과 철회정책이 검증된다.
- 모바일·PPTX와 별도 승인·발행수명을 가진다.
