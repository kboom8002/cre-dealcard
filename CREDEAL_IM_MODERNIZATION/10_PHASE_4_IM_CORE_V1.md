# M4 — IM CORE v1

> 단계 ID: `CIM-M4` · 선행: M2, M3에서 검증된 공통틀 · 종료게이트: `MG-4`

## 1. 목적

바텀시트·공부·렌트롤·사진·중개인 의견을 증거와 함께 정규화하고, 상충·정정·계산·허용범위를 판정하여 채널 중립적인 발행묶음을 만든다.

## 2. 핵심 객체

| 객체 | 책임 |
|---|---|
| 자료원 | 파일·API·메모·사람입력의 원본과 출처 |
| 관측값 | 자료원에서 읽은 값과 근거위치 |
| 상충묶음 | 같은 항목의 서로 다른 관측값 |
| 정정사건 | 원값·정정값·사유·승인자·시각 |
| 유효기준본 | 특정 시점에 채택된 사실 |
| 산출항목 | 공식·입력·단위·반올림·결과 |
| 주장 | 문구·근거·성격·허용등급 |
| 중개인의견 | 제공자·원문·편집문·근거·승인 |
| 사진자산 | 원본·촬영/제공자·사용권·역할·민감도 |
| 발행자격 | L1/L1.5/L2 및 섹션별 허용여부 |
| 발행묶음 | 채널이 소비하는 버전 고정 입력 |

## 3. 렌트롤 처리

렌트롤은 정보량과 신뢰해상도를 별도로 기록한다.

- 없음: 임대수입·공실·수익률 확정주장 금지
- 최소: 층/호·용도·보증금·월세·점유현황 중심
- 표준: 최소 + 관리비·부가세 처리·합계근거
- 완전: 표준 + 계약기간·갱신·면제기간·세무계산에 필요한 항목

합계는 원행을 덮어쓰지 않는다. 제외행·공실·자가사용·보증금/월세 단위·부가세·관리비 포함여부를 명시한다. 불일치는 정정사건이 해결하기 전까지 차단 또는 보수적 축소한다.

## 4. 다중필지 처리

필지별 지번·면적·용도지역·권리·도로조건과 출처를 보존한다. 합산값은 참여 필지·단위·기준일·공식을 가진 산출항목으로만 만든다. 일부 필지 조회실패를 전체 성공으로 표시하지 않는다.

## 5. 중개인의견 처리

원문을 보존하고 사실서술·해석·제안·미확인으로 구분한다. 편집문은 의미를 키우지 않는다. L1.5는 최소한 제공자 확인, 근거연결, 과장·법률확정 표현 검사, 최종 사람승인을 요구한다.

## 6. 발행자격

- L1: 공부·제출자료 중심의 사실확인형
- L1.5: L1 + 근거 있는 중개인의견과 매각제안
- L2: 추가 조사·검증·분석이 충족된 투자검토형

높은 등급 미충족 시 문구만 약하게 바꾸는 것이 아니라 허용된 내용 단위로 재조립한다.

## 7. MG-4 통과조건

- 자료원에서 발행문구까지 양방향 계보가 조회된다.
- 상충·정정·다중필지·렌트롤 등급 사례를 모두 재현한다.
- 공식·단위·반올림 변경이 버전과 영향범위를 남긴다.
- 발행묶음은 불변이며 원시 입력을 포함하지 않는다.
- 채널이 사실·등급·허용범위를 재판정하지 못한다.
