# M6 — PPTX IM Studio

> 단계 ID: `CIM-M6` · 선행: M4, M5에서 검증된 발행묶음 · 종료게이트: `MG-6`

## 1. 목적

PPTX를 모바일 IM의 후처리가 아니라 같은 발행묶음에서 시작하는 별도 편집 산출물로 만든다. 중개인은 자동 초안을 바탕으로 사진·표·문구를 편집하고, 최종 파일 자체를 검사·승인한다.

## 2. Studio 책임

- 템플릿과 디자인 계열 선택
- 허용된 내용 단위의 슬라이드 배치
- 사진 역할·자르기·순서·캡션 편집
- 표의 행분할·글자크기·페이지 넘김 조정
- 중개인의견 편집 및 확인 요청
- 미리보기·파일렌더·검사·승인·발행

Studio는 공부값 정정, 임대차 합계 확정, 등급결정, 사실근거 생성의 정본이 아니다. 필요한 정정은 IM CORE로 되돌려 새 발행묶음을 받아야 한다.

## 3. 사진 배치 유형

| 유형 | 사용상황 | 대표 배치 |
|---|---|---|
| 개요병치형 | 일반적인 소형빌딩 | 물건개요 표 옆에 외관 대표사진 |
| 사진주도형 | 외관·리노베이션 가치가 큼 | 큰 대표사진 후 핵심수치 띠 |
| 지도주도형 | 입지 설명이 핵심 | 지도와 접근성을 먼저, 외관은 보조 |
| 자료제약형 | 사용 가능한 사진 부족 | 개요·지도 중심, 부족사진을 억지 확대하지 않음 |

## 4. 최종파일 검사

- 실제 PPTX 바이트 해시와 승인대상 일치
- 슬라이드 밖 개체·숨김 슬라이드·발표자 메모의 민감정보
- 자리표시자·이전 매물명·잘린 표·겹친 텍스트
- 지나치게 작은 글자·저해상도 사진·왜곡 비율
- 공부·가격·렌트롤·중개정보의 발행묶음 일치
- 가상보완·미확인·중개인의견 표기

## 5. 수정과 영향

- 배치·자르기·폰트 변경: PPTX 조립 이후만 재실행
- 내용 단위 선택 변경: PPTX 조립부터 재실행
- 사실·렌트롤·공부 정정: IM CORE 판정부터 재실행
- 템플릿 규칙 변경: 영향 템플릿의 PPTX만 재생성 후보

## 6. MG-6 통과조건

- 모바일을 생성하지 않아도 PPTX를 만들 수 있다.
- 모바일 문안 변경이 PPTX 승인을 자동으로 대체하지 않는다.
- 실제 파일 검사와 파일승인이 작동한다.
- 편집상태와 발행본이 분리되고 과거 발행본을 보존한다.
- 대표 사진배치 네 유형이 자료조건에 따라 정상 동작한다.
