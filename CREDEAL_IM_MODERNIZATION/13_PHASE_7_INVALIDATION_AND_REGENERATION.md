# M7 — 변경영향과 최소 재생성

> 단계 ID: `CIM-M7` · 선행: M5, M6 · 종료게이트: `MG-7`

## 1. 목적

입력·정정·규칙·템플릿·편집 변경이 어떤 산출물과 승인에 영향을 주는지 계산하고, 필요한 단계와 채널만 다시 만든다.

## 2. 의존성 모형

각 노드는 `type`, `id`, `version`, `hash`를 갖고 간선은 `derived_from`, `uses`, `renders`, `approved_as`, `published_as`를 갖는다. 영향계산은 변경 노드에서 하류로 진행하되 채널 경계와 단계 체크포인트를 존중한다.

## 3. 변경분류

| 변경 | 예상 영향 |
|---|---|
| 원자료 교체·공부 갱신 | 해당 관측값부터 CORE와 모든 소비채널 |
| 정정사건 추가 | 유효기준본·산출항목·주장·소비채널 |
| 공식/반올림 변경 | 관련 산출항목과 이를 표시한 산출물 |
| 중개인의견 편집 | 허용범위 판정과 이를 사용한 L1.5/PPTX |
| 사진 자르기 | 해당 채널 렌더 이후 |
| 모바일 배치 | 모바일만 |
| PPTX 템플릿 | 해당 PPTX만 |
| 게이트 규칙 | 재검사 및 필요 시 재승인, 사실 재계산은 하지 않음 |

## 4. 안전규칙

- 영향이 불명확하면 좁게 추정하지 않고 안전한 상위단계부터 재실행한다.
- 변경된 하류 산출물의 승인은 자동 무효화한다.
- 외부발행본은 덮어쓰지 않고 새 버전으로 낸다.
- 과거 발행 링크의 유지·철회 정책을 매체별로 적용한다.
- 재생성 미리보기에서 대상·이유·비용·예상시간을 보여준다.

## 5. MG-7 통과조건

- 20개 이상의 변경유형에 대해 기대 영향과 실제 영향이 일치한다.
- 모바일 배치 변경이 PPTX·CORE를 불필요하게 재실행하지 않는다.
- 렌트롤 정정이 관련 수익 문구·표·승인을 모두 무효화한다.
- 중단 후 영향범위 내 성공단계를 재사용한다.
- 변경 전후 계보와 승인상태를 감사로그로 설명할 수 있다.
