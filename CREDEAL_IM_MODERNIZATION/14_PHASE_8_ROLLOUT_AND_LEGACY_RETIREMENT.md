# M8 — 점진 전환과 구형 경로 폐기

> 단계 ID: `CIM-M8` · 선행: M7 · 종료게이트: `MG-8`

## 1. 목적

구형과 신형을 비교·관찰하며 점진 전환하고, 복구 가능성이 확인된 뒤 구형 신규 제작경로만 폐기한다. 과거 발행본과 감사기록은 보존한다.

## 2. 전환 순서

1. 그림자 실행: 사용자에게는 구형만 보이고 신형 결과를 비교한다.
2. 내부 사용자: 운영·품질·선정 중개인이 신형을 검수한다.
3. 카나리: 대상 거래건의 1% → 10% → 50% → 100%.
4. 채널별 기본값 전환: 딜카드, 모바일, PPTX 순으로 별도 결정한다.
5. 구형 신규쓰기 차단, 읽기·철회·감사는 유지한다.
6. 두 정규 릴리스 동안 구형 신규경로 사용량 0을 확인한 후 코드 제거를 승인한다.

## 3. 승격 기준

- 차단 오류율과 승인오류 0
- 계산·공부·개인정보 중대 불일치 0
- 재시도 포함 성공률이 목표 이상
- P95 처리시간과 단위비용이 예산 이내
- 사람 검수 부적합률이 기준선보다 악화되지 않음
- 중개인 완료시간과 수정횟수가 허용범위 이내

수치 목표는 M0 기준선 뒤 `release_gate_catalog.yaml`에서 확정한다.

## 4. 즉시 되돌리기 조건

- 개인정보 또는 블라인드 정보 유출
- 잘못된 승인대상 발행
- 가격·면적·렌트롤 계산의 체계적 오류
- 발행본 손실 또는 철회불능
- 장애가 임계시간 이상 지속

되돌리기는 기능깃발로 신규 진입만 구형 또는 안전중단 상태로 돌리며 이미 발행된 신형 파일을 삭제하지 않는다.

## 5. MG-8 통과조건

- 전체 카나리와 실제 되돌리기 훈련 완료
- 운영지침·당직·경보·사고보고 절차 인수
- 데이터 이전·호환성·보존 감사 완료
- 제품·도메인·기술·품질·운영·중개실무 승인
- 구형 신규경로 폐기와 과거 읽기경로 보존 계획 승인
