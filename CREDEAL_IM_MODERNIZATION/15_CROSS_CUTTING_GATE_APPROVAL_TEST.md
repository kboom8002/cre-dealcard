# 횡단 게이트·승인·시험 사양

## 1. 게이트 계층

1. `수집 게이트`: 파일·API·메모의 입수와 무결성
2. `사실 게이트`: 출처·기준일·상충·정정·다중필지
3. `산식 게이트`: 입력·단위·공식·반올림·합계
4. `허용범위 게이트`: 문서등급·자료등급·중개인의견
5. `내용 게이트`: 누락·과장·금지표현·민감정보
6. `표현 게이트`: 화면·PPTX·사진·표·가독성
7. `승인 게이트`: 사람역할·선행승인·대상해시
8. `발행 게이트`: 실제 저장파일·URL·버전·철회가능성

상위 계층은 하위 검사 결과를 요약할 수 있지만 원검사 상태를 덮어쓰지 않는다.

## 2. 검사 심각도

- `BLOCKER`: 발행 금지, 예외 불가 또는 제한된 이중승인만 허용
- `ERROR` 심각도: 발행 금지, 원인 수정 후 재검사
- `WARNING`: 발행 가능 여부를 정책이 결정, 사람확인 필요
- `INFO`: 정보 제공, 발행에 영향 없음

검사실패와 검사시스템 오류를 같은 값으로 표현하지 않는다.

## 3. 예외승인

예외에는 검사 ID·대상해시·사유·보완조치·승인자·만료·적용범위가 필요하다. 법정·개인정보·핵심수치 위반은 예외승인 불가 목록으로 관리한다. 규칙 또는 대상이 바뀌면 예외를 재평가한다.

## 4. 시험 묶음

각 차단규칙은 다음 네 시험을 갖는다.

- 양성: 정상 자료가 통과
- 음성: 명확한 위반이 차단
- 변조: 해시·본문·숨김정보·이전 매물값 조작을 발견
- 복구: 수정·재시도·승인무효화·재발행이 정상

## 5. 단계별 적용

- M1: 공통 상태, 허위통과 차단, 최소 승인결속
- M2: 공통 검사보고서와 실행기
- M3: 딜카드 프로필
- M4: CORE 사실·산식·허용범위 프로필
- M5: 모바일 내용·표현 프로필
- M6: PPTX 실제파일 프로필
- M7: 변경영향·승인무효화 시험
- M8: 오류주입·부하·철회·되돌리기·자체감사

## 6. 검사 정본

검사 ID·버전·심각도·적용산출물·판정식·필수관측기·예외가능성은 `knowledge/release_gate_catalog.yaml`에서 관리한다. 코드와 문서에 같은 규칙을 복제하지 않는다.
