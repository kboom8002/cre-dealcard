# 시험·인수·품질 계획

## 1. 시험 피라미드

- 단위: 정규화·산식·정책·문장/사진 규칙
- 계약: API·이벤트·스키마·발행묶음
- 통합: 자료원→CORE→채널→검사→승인→발행
- 시각: 모바일 주요 폭, PPTX 실제 렌더
- 계보: 출처→주장 및 주장→출처 양방향
- 오류주입: API 지연·부분실패·객체누락·검사기 오류
- 보안: 권한·서명URL·개인정보·악성파일·프롬프트 주입
- 사용자 인수: 중개인 업무시간·수정가능성·문장 자연스러움

## 2. 골든 사례군

최소 12건을 고정하고 다음 축을 조합한다.

- 단일/다중필지
- 건축물 있음/토지형/개발검토형
- 렌트롤 없음/최소/표준/완전
- 상충 없음/상충/정정완료
- 사진 충분/부족/민감정보 포함
- L1/L1.5 및 L2 미충족 축소

당산동 사례는 중개인형 L1/L1.5의 대표 회귀사례로 사용하되 가상보완값은 명시적으로 태깅한다.

## 3. 인수 기준

- 핵심 수치와 출처 일치 100%
- 차단검사 미실행 0건
- 잘못된 대상에 결속된 승인 0건
- 개인정보·블라인드 위반 0건
- PPTX 자리표시자·이전 매물 잔존 0건
- 예상 등급과 실제 자격판정 일치 100%
- 중대한 시각 결함 0건

성능·비용·작업시간 목표는 M0 기준선 후 확정한다.

## 4. 인수 역할

- 제품: 사용자 흐름과 범위
- 도메인: 공부·렌트롤·문구·등급
- 기술: 경계·복구·성능·호환
- 품질: 독립시험과 증적
- 운영: 계기판·경보·사고대응
- 중개실무: 실제 작성가능성·자연스러운 표현·편집성

## 5. 결함 등급

P0은 유출·오발행·핵심수치 체계오류·데이터손실, P1은 차단기능 우회·승인오류·주요 산출물 생성불능이다. P0/P1 미해결 상태에서는 다음 관리게이트를 통과할 수 없다.
