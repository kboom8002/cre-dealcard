# 레포 배치와 도입 안내

## 1. 권장 배치

이 문서 세트를 CREDEAL 저장소의 다음 위치에 그대로 넣는다.

`docs/impipe/modernization/CREDEAL_INTEGRATED_IM_MODERNIZATION_SDD_v1.0/`

`references/`는 검토 당시의 입력 스냅샷이며 새 정본으로 직접 수정하지 않는다. 팀의 살아 있는 정본은 D54·D54-A·D55 및 승인된 스키마·등록부다.

## 2. 첫 주 적용

1. README와 00~05를 제품·도메인·아키텍처·품질이 함께 검토한다.
2. 21번의 DEC-001~005를 등록한다.
3. 현행 감사결과를 06번 형식으로 기준선화한다.
4. `knowledge/work_item_catalog.yaml`을 이슈관리 도구로 가져온다.
5. M1 작업만 스프린트에 배정하고 M2 이후는 설계준비 상태로 둔다.

## 3. 이슈관리 도구 매핑

- 에픽: `CIM-M0`~`CIM-M8`
- 작업: `CIM-xxxx`
- 요구: `CIM-R-xxx`
- 관리게이트: `MG-x`
- 검사: `GATE-*`
- 결정: `DEC-*`

작업카드에는 상위 요구·단계·증적·기능깃발·되돌리기를 유지한다.

## 4. 기존 패키지와의 관계

- 파이프라인 패키지: M1·M2·M3·M7·M8의 상세구현 참고
- IM CORE 패키지: M4·M5·M6의 계약과 자료모형 참고
- 게이트 패키지: 모든 단계의 검사·승인·발행 통제 참고

내용이 충돌하면 `02_REQUIREMENTS_PRECEDENCE_AND_TRACEABILITY.md`의 우선순위를 적용하고 결정기록을 남긴다.

## 5. 커밋 전략

M0/M1은 현재 경로에 안전봉합을 먼저 넣는다. M2 이후 신형 컴포넌트는 기능깃발 아래 추가하고, 채널별 세로절단이 인수된 뒤 기본경로를 전환한다. 구형 코드는 M8 종료 전에 삭제하지 않는다.
