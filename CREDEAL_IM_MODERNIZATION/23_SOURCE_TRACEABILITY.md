# 입력 문서 추적표

## 1. 핵심 입력

| 입력 | 통합 문서 반영 |
|---|---|
| D54 | 중개인 현실 입력, 공부·렌트롤·상충·정정, 최소 실행원칙 |
| D54-A | 평가근거·참조·예외·추적성 |
| D55 | L1/L1.5/L2, 문장·사진·등급·사람승인 |
| D58 | IM CORE·모바일·PPTX Studio의 형제 채널 구조 |
| 파이프라인 개편 작업지시서 | 재개·멱등·단계·발행·무효화·점진전환 |
| IM CORE 고도화 패키지 | 자료모형·계약·자격·채널경계·이전 |
| 게이트 고도화 패키지 | 7상태·실측·승인결속·딜카드/모바일/PPTX 프로필 |

원문 스냅샷은 `references/`에 보존한다.

## 2. 통합판에서 새로 확정한 사항

- 게이트를 마지막 단계가 아닌 횡단 통제로 배치
- 공통 7상태·대상해시 승인·발행원장을 M1~M2에 선행
- CREDEAL 실제 사용자 순서에 맞춰 딜카드를 첫 세로절단으로 완성
- IM CORE 뒤 모바일 L1/L1.5를 먼저 외부채널로 인수
- PPTX Studio를 모바일의 후속변환이 아닌 형제 채널로 구현
- 두 채널이 존재한 뒤 전체 변경영향·최소 재생성 완성
- 채널별 카나리 후 구형 신규쓰기만 폐기

## 3. 추적 유지 방법

요구사항은 `CIM-R-*`, 작업은 `CIM-*`, 검사와 인수는 `MG-*` 및 `GATE-*`로 연결한다. 구현 중 원문 해석이 바뀌면 이 문서와 `knowledge/requirements_traceability.yaml`을 함께 개정한다.
