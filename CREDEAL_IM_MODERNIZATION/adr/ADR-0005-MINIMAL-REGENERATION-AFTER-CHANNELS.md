# ADR-0005 — 두 채널 인수 뒤 전체 최소 재생성 완성

- 상태: 채택
- 결정일: 2026-08-31

## 배경

초기부터 완전한 영향그래프를 만들면 실제 모바일·PPTX 의존성을 추측하게 된다. 반대로 승인무효화를 늦추면 오발행 위험이 생긴다.

## 결정

M1~M2에서 입력해시·버전·승인무효화의 최소 기반을 만든다. 모바일과 PPTX의 실제 의존성이 확정된 M7에서 전체 영향계산과 최소 재생성 계획기를 완성한다.

## 결과

안전한 보수적 무효화는 일찍 적용하고 비용·시간을 줄이는 정밀 재생성은 실제 채널 자료로 검증한다.
