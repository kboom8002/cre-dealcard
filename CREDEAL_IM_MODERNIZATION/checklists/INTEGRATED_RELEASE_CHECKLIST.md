# 통합 릴리스 점검표

- [ ] 대상 채널의 선행 관리게이트가 통과했다.
- [ ] 열린 P0/P1 결함이 없다.
- [ ] 모든 차단검사가 실행됐고 `FAIL/NOT_RUN/INDETERMINATE/SYSTEM_ERROR`가 없다.
- [ ] 승인대상 실제 객체와 서버 계산 해시가 일치한다.
- [ ] 개인정보·블라인드·권한·악성파일 시험을 통과했다.
- [ ] 핵심 수치·공부·렌트롤·다중필지 회귀가 통과했다.
- [ ] 모바일/PPTX 실제 렌더를 검수했다.
- [ ] 관측·경보·철회·되돌리기를 실제 환경에서 시험했다.
- [ ] 기존 URL·파일·감사기록 호환성을 확인했다.
- [ ] 카나리 승격 또는 보류 결정이 동일 해시에 승인됐다.
