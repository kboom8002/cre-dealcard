# 입력 스냅샷 안내

이 폴더는 통합안 작성에 사용한 D54·D54-A·D55·D58과 세부 작업지시서의 읽기 전용 스냅샷을 담는다.

- `methodology/`: 업무 방법론과 아키텍처 제안
- `upstream/pipeline/`: 제작 파이프라인 상세 패키지
- `upstream/im-core/`: IM CORE 상세 패키지
- `upstream/gate/`: 게이트·문서 하네스 상세 패키지

이 스냅샷을 새로운 살아 있는 정본으로 편집하지 않는다. 실제 레포의 정본이 바뀌면 변경결정과 요구사항 추적표를 갱신한 뒤 필요한 스냅샷 버전을 교체한다.
