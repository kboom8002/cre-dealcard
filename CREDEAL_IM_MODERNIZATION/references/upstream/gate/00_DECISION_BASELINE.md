# 의사결정 기준선

## D-01. 기존 게이트는 잎 검사로 재사용한다

기존 약 91개 검사를 한 번에 폐기하지 않는다. 다만 현재의 단일 `GateContext`와 단일 `PUBLISH_GATES` 실행기는 목표 구조의 정본으로 사용하지 않는다. 검출력이 있는 검사는 산출물별 검사 프로필의 잎 검사로 이전한다.

## D-02. 딜카드는 독립 발행물이다

딜카드는 불완전한 중개인 메모에서 제한된 사실만 공개하는 블라인드 안내물이다. IM의 낮은 등급이나 사실 정본으로 간주하지 않는다.

- 메모 파싱 결과는 `Observation`이다.
- 외부 딜카드에 표시한 사실은 원문 위치 또는 중개인 확인에 연결한다.
- 정확한 주소·PNU·임차인·소유자 정보는 내부 식별과 공개표시를 분리한다.
- 바텀시트나 공부에서 핵심값이 바뀌면 기존 딜카드를 자동으로 오래된 발행본으로 처리한다.

## D-03. 모바일과 PPTX는 형제 채널이다

모바일 본문을 PPTX가 다시 해석하지 않는다. 두 채널은 같은 `EffectiveSnapshot`, `ClaimEvaluationSet`, `PublicationPackage`를 사용하고 각각 독립적으로 조립·검사·승인한다.

## D-04. 근거상태와 외부사용 허가상태를 분리한다

- 근거상태: 미확인, 중개인확인, 조정완료, 상충, 오래됨, 자료없음
- 외부사용 허가: 허용, 주의표시 허용, 차단, 해당없음, 현 단계 미제공, 미판정

두 상태를 하나의 열거형으로 합치지 않는다.

## D-05. 미실행은 통과가 아니다

검사 결과는 `PASS`, `FAIL`, `WARN`, `NOT_APPLICABLE`, `NOT_RUN`, `INDETERMINATE`, `SYSTEM_ERROR`를 사용한다. 차단급 검사에서 마지막 세 상태는 외부발행을 차단한다.

## D-06. 심각도와 실행모드를 분리한다

검사 심각도는 정본 정책에서 고정한다. 개발·그림자·강제 실행 여부는 별도 `enforcementMode`로 관리하며 환경변수로 block을 warn으로 바꾸지 않는다.

## D-07. 사람승인은 사건이다

승인은 문서의 상태값을 덮어쓰는 동작이 아니다. 승인 대상 해시, 승인범위, 승인자, 일시, 정책버전을 갖는 사건으로 저장한다. 사실·문구·사진·정책·파일이 바뀌면 관련 승인을 자동 무효화한다.

## D-08. 품질과 권한을 분리한다

문서 품질검사, 사람승인, 공개정책, 구독권한, 열람동의를 서로 다른 정책 엔진으로 분리한다. 구독등급이 문서 품질을 통과시키거나 품질점수에 반영되어서는 안 된다.

## D-09. 한 실패에서 한 검사를 만든다

새 검사는 실제 발행물에서 관찰된 실패 또는 명확한 법적·운영상 불변조건에서만 추가한다. 모든 차단급 검사는 양성·음성 짝과 실제 변조방식을 가져야 한다.

## D-10. 외부 문서에 내부 제작용어를 노출하지 않는다

외부 IM에는 내부 단계, 검사코드, 가상값, 하네스 용어를 표시하지 않는다. 필요한 경우 `확인사항`, `자료기준일`, `미제출자료`, `중개인 의견`처럼 한국 중개 실무 용어로 변환한다.
