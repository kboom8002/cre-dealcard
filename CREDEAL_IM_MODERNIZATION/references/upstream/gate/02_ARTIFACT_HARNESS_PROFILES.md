# 산출물별 하네스 프로필

## 1. 공통 판정 상태

| 상태 | 뜻 | 차단급 검사 처리 |
|---|---|---|
| `PASS` | 관측값이 통과조건 충족 | 통과 |
| `FAIL` | 명시적 위반 | 차단 |
| `WARN` | 발행 가능하나 확인 필요 | 경고 |
| `NOT_APPLICABLE` | 적용조건 불충족 | 제외, 사유 필수 |
| `NOT_RUN` | 관측기 미실행 | 차단 |
| `INDETERMINATE` | 자료 부족·모호성으로 판정 불가 | 차단 |
| `SYSTEM_ERROR` | 실행 실패 | 차단 |

## 2. 프로필 목록

### P-MEMO-CANDIDATE

목적: 내부 파싱 후보 생성 가능 여부를 판단한다.

필수 검사:

- 입력 길이·문자열 유효성
- 부동산 관련 후보정보 존재
- 추출값별 원문 위치 존재
- 모호한 복수 후보 표시
- 추출기 실패 및 시간초과 기록

이 프로필 통과는 외부 딜카드 발행허가가 아니다.

### P-DEALCARD-BLIND

목적: 블라인드 딜카드 외부 공개 가능 여부를 판단한다.

필수 검사:

- 모든 표시사실의 관측값 연결
- 누락값 무단보완 없음
- 가격·수익률 밴딩 정합
- 직접식별자 마스킹
- 간접 재식별 위험
- 과장·확정 표현 없음
- 중요 모호성·상충정보 비노출
- 중개인 공개확인
- 원자료 변경 이후 최신성

### P-MOBILE-L1

목적: 사실확인형 모바일 IM의 발행 가능 여부를 판단한다.

- 매각범위·주소·가격·핵심면적
- 필지와 공부 확인상태
- 렌트롤 제출범위와 표시범위
- 표시한 모든 숫자의 산출항목 참조
- 기준일과 미확인사항
- 개인정보·사진 공개상태
- 모바일 제목·본문 자연스러움과 가독성

### P-MOBILE-L15

`P-MOBILE-L1` 전부에 다음을 추가한다.

- 공개승인 가능한 `ProposalUnit` 1건 이상
- 원문·근거·매수자·매수자 의미·성립조건·재검토조건
- 외부용 최종문구와 반영위치
- 자동 적격 통과
- 중개인 편집승인

### P-PPTX-DRAFT

목적: Studio 편집을 시작할 수 있는 안전한 초안인지 판단한다.

- 공통 발행묶음과 유효기준본 고정
- 페이지별 산출항목 참조
- 승인된 사진만 후보로 제공
- 모바일 문장 재사용 시 원문 참조 유지
- 중요한 편집결정 기록 시작

### P-PPTX-RELEASE

목적: 최종 PPTX 파일을 외부 배포할 수 있는지 판단한다.

- 표시 숫자와 공통 발행묶음의 오차 0
- 앞면과 근거부록 수치 오차 0
- 텍스트 넘침·잘림 0
- 의미 있는 겹침·가림 0
- 지면 이탈 0
- 사진 왜곡·타 매물 사진·개인정보 0
- 제목과 본문 내용 정합
- 내부 제작용어 노출 0
- 파일해시와 편집승인 일치

## 3. 적용성 규칙

검사의 적용성은 자산유형만으로 판단하지 않는다. 최소 차원은 다음과 같다.

```text
artifactType × documentEdition × assetPosture × claimPresence
× dataResolution × disclosureMode × photoAvailability × rentRollResolution
```

예시:

- `NOI`를 표시하지 않으면 관리비·운영비 검사는 `NOT_APPLICABLE`이다.
- `NOI`를 표시하려는데 관리비가 없으면 `INDETERMINATE` 또는 해당 산출항목 `BLOCKED`다.
- 사진이 없는 L1은 사진 수 검사 대신 무사진 레이아웃 검사를 적용한다.
- 임대기간이 없는 렌트롤은 현황표시는 가능하지만 만기분석 검사는 해당 산출항목을 차단한다.
