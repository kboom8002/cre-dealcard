# 모바일 L1·L1.5 하네스 사양

## 1. 목표

모바일 IM은 매수자가 휴대전화에서 2~4분 안에 매물의 기본사실, 확인사항, 중개인 관점, 다음 행동을 이해하도록 한다. 자동 생성 기본값은 사실확인형 L1이며, 중개인 의견 묶음과 사람 편집승인이 있으면 중개인 제안형 L1.5를 발행할 수 있다.

## 2. L1 필수 묶음

### 매물 기본사실

- 매각대상과 필지 범위
- 소재지 공개수준
- 매각희망가 또는 협의 여부
- 대지·연면적과 공부상 기준
- 주용도·규모·사용승인일
- 기준일

### 임대차

- 제출된 렌트롤의 범위와 호실 수
- 보증금·월 임대료의 제출값과 합계
- 공실을 확인할 수 있는 범위
- 관리비·계약기간 등 미제출항목

### 근거와 주의

- 공부/API/중개인자료의 출처
- 상충과 정정 결과
- 미확인사항
- 개인정보·사진 공개승인

## 3. 렌트롤 해상도별 허용범위

| 입력수준 | 표시 가능 | 차단 또는 조건부 |
|---|---|---|
| 없음 | 임대차 자료 미제출 안내 | 임대수입·공실률·수익률 |
| 최소 | 제출 호실·보증금·임대료 | 전체성 단정·만기·NOI |
| 표준 | 최소 + 관리비·공실 | 관리비 성격 불명확 시 NOI |
| 완전 | 계약기간·부가세·관리비 성격·운영비 | 산식·가정 승인 후 분석 가능 |

렌트롤 미제출은 문서 전체가 아니라 임대 의존 산출항목을 차단한다.

## 4. 사진 적응형 편성

| 사진상태 | 편성 |
|---|---|
| 대표 외관사진 있음 | 물건 개요 옆에 우선 배치 |
| 외관사진 여러 장 | 표지 1장, 개요 1장, 갤러리 선택 |
| 내부사진만 있음 | 외관사진 없음 표시 후 내부공간 중심 |
| 사진 없음 | 지도·공부·핵심정보 중심 무사진 레이아웃 |

사진 3매 미만을 일괄 차단하지 않는다. 다만 사용한 모든 사진은 물건 연결, 공개승인, 개인정보 검사를 통과해야 한다.

## 5. L1.5 ProposalUnit

```typescript
interface ProposalUnit {
  proposalId: string;
  brokerRawOpinion: string;
  evidenceRefs: string[];
  targetBuyer: string;
  buyerMeaning: string;
  conditions: string[];
  revisitIf: string[];
  publicCopy: string;
  placement: string[];
  autoEligibility: 'PASS' | 'FAIL' | 'NOT_RUN';
  editorialApprovalId?: string;
}
```

문구의 자연스러움, 한국 중개인이 고객에게 설명하는 방식, 문의·답사·자료요청으로의 연결은 사람 편집승인에서 확인한다. LLM 자기평가는 승인으로 인정하지 않는다.

## 6. 모바일 검사 묶음

### 사실검사

- 매각범위와 표시주소 정합
- 필지합·면적·가격·렌트롤 합계
- 수익률 산정기준과 라벨
- 기준일과 출처
- 미확인사항 은폐 없음

### 내용검사

- 중개인 원문과 외부문구 연결
- 만실·공실 서술과 수치 정합
- 보장·확정·저평가 단정 없음
- 내부 제작용어 미노출

### 모바일 지면검사

- 제목·표·숫자 잘림 없음
- 최소 글자 크기
- 버튼·상세요청 경로 표시
- 긴 표의 가로 넘침 없음
- 대표사진의 크롭과 가독성

## 7. 발행 판정

```text
L1 사실묶음 PASS
AND 모바일 차단검사 PASS
AND 중개인 최종발행 승인
=> 모바일 L1 발행

L1 조건 충족
AND ProposalUnit 자동 적격 PASS
AND 편집승인 APPROVED
AND 승인결속 해시 일치
=> 모바일 L1.5 발행
```

L1.5가 실패하면 L1 가능 여부를 재판정하되, 실패한 의견 문구를 L1에 우회 노출하지 않는다.
