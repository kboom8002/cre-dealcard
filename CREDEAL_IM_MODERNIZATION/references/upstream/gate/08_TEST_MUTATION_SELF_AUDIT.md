# 양성·음성·변조시험 및 하네스 자기감사

## 1. 시험 원칙

모든 차단급 검사는 다음 세 가지를 가져야 한다.

1. 양성 시험: 정상 자료와 산출물이 통과한다.
2. 음성 시험: 실제 반대조건이 실패한다.
3. 변조시험: 원자료 또는 최종 산출물을 고의로 바꾸면 검사기가 이를 잡는다.

완성된 `GateContext`의 boolean만 뒤집는 시험은 단위시험으로는 허용하지만 검출력 증명으로 계산하지 않는다.

## 2. 시험 계층

| 계층 | 대상 | 예시 |
|---|---|---|
| 규칙 단위시험 | 판정식 | 가격 0이면 실패 |
| 관측기 시험 | 원자료→관측값 | PPTX 숫자 토큰 추출 |
| 계약시험 | 정본→코드 | YAML 심각도와 코드 일치 |
| 변조시험 | 실제 입력·파일 | 렌트롤 한 행 변경 |
| 전구간 시험 | 메모→발행본 | 기준값 변경 시 승인 무효화 |
| 실물 회귀시험 | 실제 발행물 | 당산·양평 등 골든 사례 |

## 3. 필수 변조 시나리오

- 메모 가격 변경 후 딜카드 밴드 미갱신
- 바텀시트 면적 변경 후 기존 기준본 재사용
- 임대료 한 행 변경 후 합계·수익률 미갱신
- 관리비 삭제 후 NOI 계속 표시
- PPTX 숫자 텍스트 직접 수정
- 앞면과 부록의 같은 수치 다르게 수정
- 승인사진을 다른 이미지로 교체
- 대표사진 승인 후 크롭 변경
- 중개인 의견의 성립조건 삭제
- 승인 후 정책버전 변경
- 관측기 시간초과를 PASS로 흡수

## 4. 실패 흡수 경로

다음 경로를 정적분석과 실행로그에서 계수한다.

- 결측값 기본치
- 예외 후 정상값 반환
- 시간초과 후 skip
- block을 warn으로 변경
- 폴백 문구 생성
- 관측불가를 0으로 저장
- 테스트·정본 파일을 자체 검사대상에서 제외하지 않음
- 그림자 실행 결과를 승인에 사용

각 흡수 경로는 소유자·사유·만료일을 가져야 하며 무기한 허용하지 않는다.

## 5. 고정 계기판

| 지표 | 정의 |
|---|---|
| 통제 반증가능률 | 반대조건과 관측기가 있는 검사 비율 |
| 음성짝 비율 | 차단급 검사 중 실제 음성시험 보유 비율 |
| 변조 검출률 | 변조 중 기대 검사가 실패한 비율 |
| 실패흡수 건수 | 폴백·skip·기본통과 경로 수 |
| 배선율 | 선언검사 중 실제 프로필에서 실행되는 비율 |
| 산출물 위반밀도 | 카드 또는 페이지당 위반 수 |
| 문서 일관성 | 채널·페이지 간 같은 산출항목 일치율 |
| 미판정·죽은 검사 | NOT_RUN·고정값·실패불가 검사 수 |

추가 제품지표로 오래된 발행본, 승인 무효화 누락, 채널 간 숫자 불일치를 관리한다.

## 6. 정본 자기감사

- 검사 ID 중복 0
- 하나의 검사 ID에 심각도 1개
- 모든 차단급 검사에 관측기·반대조건·실패조치 존재
- 모든 차단급 검사에 양성·음성·변조 연결
- 코드 임계값 리터럴 0 또는 승인된 예외
- 고정 `true/false/0` 관측기 0
- `NOT_RUN`을 PASS로 바꾸는 경로 0
- 정본 변경 시 생성 코드·문서·시험의 차이 검출

## 7. 기준선 변경

골든 문서나 임계값을 바꿀 때는 변경사유, 실제 실패 사례, 영향을 받는 검사, 승인자, 변경 전후 변조검출률을 기록한다. 검사를 통과시키기 위한 기준완화는 허용하지 않는다.
