# 게이트 시스템 고도화 작업지시서

## 1. 작업 원칙

- 기존 외부발행을 즉시 중단하지 않고 새 하네스를 그림자 실행한다.
- P0 안전조치 완료 전 신규 검사 수를 늘리지 않는다.
- 각 작업은 코드, 정본, 시험, 운영관측을 함께 완료해야 종료한다.
- 제품책임자가 의사결정 기준선과 위험등급을 승인한다.

## 2. P0 - 허위 통과 제거

### P0-01 결과상태 확장

작업:

- boolean 결과를 7상태 모델로 교체
- 차단급 `NOT_RUN/INDETERMINATE/SYSTEM_ERROR` 외부발행 차단
- 기존 결과의 호환 변환기 작성

완료조건:

- 미입력 필드가 기본 PASS가 되는 경로 0
- 운영로그에서 7상태 구분 가능

### P0-02 승인 재수화

작업:

- 생성 당시 주장목록·산출항목 판정·검사보고서 저장
- 승인 API에서 저장객체 재수화
- 빈 Registry 승인 거부
- `expectedHash` 의무화

완료조건:

- 빈 주장목록 승인시험 실패
- 생성 후 값 변경 시 기존 승인 거부

### P0-03 죽은 검사 제거

대상:

- 무조건 통과하는 G23
- `pageCountExceeded=false`
- `foreignPhotoCount=0`
- 실제 판정 없이 0을 반환하는 제목·본문 정합 검사

작업:

- 실제 관측기 연결 또는 `NOT_RUN` 반환
- 관측기 없는 차단급 검사는 외부발행 프로필에서 제외하지 말고 차단상태로 표시

### P0-04 심각도 고정

- 환경변수의 block↔warn 전환 제거
- `severity`와 `enforcementMode` 분리
- 프로필별 심각도는 YAML 정본에서 생성

### P0-05 적용성 실행

- `artifactType`, `documentEdition`, `assetPosture`, `claimPresence`를 실행 요청에 포함
- `appliesWhen` 평가 결과와 사유 저장
- 모든 검사를 무조건 순회하는 실행기 교체

## 3. P1 - 딜카드 하네스

### P1-01 MemoObservationSet

- 원문 위치·신뢰도·모호성 저장
- 파싱 후보와 외부공개 상태 분리
- 메모 버전과 추출기 버전 저장

### P1-02 블라인드 공개검사

- 직접식별자·간접 재식별 검사
- 밴딩 변환 기록
- 무단보완·과장표현 차단
- 중개인 공개확인 UI

### P1-03 최신성·무효화

- 바텀시트 정정과 딜카드 필드 영향도 연결
- 핵심값 변경 시 PUBLISHED→STALE
- 재발행 전 전체 프로필 재실행

## 4. P2 - IM CORE와 모바일

### P2-01 불변 유효기준본

- 상충·정정·채택값 저장
- 한 발행본 한 기준본 강제
- 스냅샷 해시와 영향도 계산

### P2-02 산출항목 판정

- D55 산출항목 묶음 등록
- 근거상태와 외부허가상태 분리
- 자료 부족 시 종속 산출항목만 차단

### P2-03 모바일 L1/L1.5

- L1 자동 초안
- ProposalUnit 자동 적격
- 중개인 편집승인
- 사진·렌트롤 적응형 편성
- 모바일 독립 발행본과 해시

## 5. P3 - PPTX Studio

### P3-01 입력계약 교체

- 모바일 body/markdown 직접 참조 제거
- PublicationPackage 기반 바인딩
- 모든 숫자·표·카피에 참조 ID 부여

### P3-02 편집결정과 버전

- 중요 편집결정 기록
- 페이지·사진·문안 변경이력
- 편집승인과 파일승인 분리

### P3-03 실물 관측기

- PPTX/PDF 렌더링 기반 텍스트·레이아웃 검사
- 앞면·부록·공통 발행묶음 숫자 오차 0
- 사진 해시·왜곡·개인정보 검사

## 6. P4 - 하네스 성숙화

- 실제 문서 변조시험 CI
- 하네스 자기감사
- 고정 계기판
- 실제 발행물 누락오류 주간 회고
- 첫 30건 이중검수 후 표본검수 전환 판단

## 7. 작업 완료 증적

각 작업 티켓은 다음을 첨부한다.

- 변경된 정본 ID와 버전
- 코드 변경 위치
- 양성·음성·변조시험 ID
- 이전 오류 재현자료
- 실행 전후 검사보고서
- 운영 계기판 변화
- 제품책임자 또는 품질책임자 승인
