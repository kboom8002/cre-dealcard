# 완료조건 및 운영 실행서

## 1. 시스템 완료조건

- 외부 발행본의 모든 숫자·단정문이 산출항목 또는 승인된 중개인 의견에 연결된다.
- 차단급 `NOT_RUN`, `INDETERMINATE`, `SYSTEM_ERROR` 발행 0건이다.
- 죽은 검사와 고정 관측값이 0건이다.
- 모바일과 PPTX가 같은 산출항목을 표시할 때 값·단위·산정기준 차이가 0이다.
- 사실·문구·사진·정책·파일 변경 시 영향승인이 자동 무효화된다.
- 딜카드는 바텀시트 핵심정정 이후 자동으로 오래된 상태가 된다.
- 사진·렌트롤 부족은 축소 편성으로 이어지며 AI 임의보완으로 이어지지 않는다.
- 모든 차단급 검사가 실제 변조시험에서 실패한다.
- 구독·열람권한이 품질검사 결과에 영향을 주지 않는다.

## 2. 발행 전 운영 점검

### 딜카드

- 메모 원문과 표시정보 연결
- 공개 최소정보 충족
- 정확주소·건물명·임차인·소유자 비노출
- 밴딩·마스킹 정책 적용
- 중개인 공개확인
- 최신 메모·기준값 사용

### 모바일

- 유효기준본 고정
- 매각범위·가격·면적·임대차 확인
- 종속 산출항목만 허용
- 기준일·출처·미확인사항 표시
- L1.5 의견 자동 적격과 편집승인
- 모바일 해시 승인

### PPTX

- 공통 발행묶음 기반 조립
- 앞면·부록·CORE 숫자 오차 0
- 텍스트 넘침·가림·지면이탈 0
- 승인사진만 사용
- 내부 제작용어 노출 0
- 최종파일 해시 승인

## 3. 장애 대응

| 장애 | 기본 조치 | 발행 |
|---|---|---|
| 공부 API 실패 | 마지막 성공자료의 기준일 표시, 재조회 | 의존 산출항목 차단 |
| LLM 검사 실패 | 시스템오류 기록, 결정적 검사 유지 | 차단급이면 발행 중지 |
| PPTX 관측기 실패 | 파일 승인 금지, 재렌더 | 발행 중지 |
| 메모 파서 모호성 | 중개인 확인 요청 | 내부 후보만 허용 |
| 사진 개인정보 불명확 | 사진 제외 또는 사람 확인 | 미승인 사진 사용 금지 |
| 승인 해시 불일치 | 최신본 재검사·재승인 | 기존 승인 사용 금지 |

## 4. 운영 권한

- 제품책임자: 위험등급·발행정책·예외정책 승인
- 도메인책임자: 산출항목과 산식 승인
- 품질책임자: 검사·변조시험·기준선 승인
- 담당 중개인: 원자료 정정·의견·사진·최종문안 승인
- 운영자: 발행·철회·재발행 실행

개발자는 운영환경에서 심각도를 임의 변경하지 않는다.

## 5. 예외 승인

RC2 이상 차단검사는 일반 예외승인으로 우회할 수 없다. 예외가 필요한 경우 다음을 모두 요구한다.

- 예외 대상과 기간
- 고객·법적·품질 위험
- 대체 통제
- 승인자
- 만료시각
- 영향 발행본
- 사후검토 일정

예외는 만료되면 자동으로 차단상태로 돌아간다.
