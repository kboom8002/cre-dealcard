# ADR-0001 산출물별 하네스 프로필 채택

## 상태

채택 제안

## 맥락

현재 단일 발행검사 목록은 메모, 모바일, PPTX, 자산유형, 임대정보 해상도의 차이를 충분히 반영하지 못한다. 적용대상이 선언되어도 실행기에서 사용되지 않거나 결측값이 통과하는 문제가 있다.

## 결정

딜카드, 모바일 L1, 모바일 L1.5, PPTX 초안, PPTX 최종파일에 독립 검사 프로필을 사용한다. 공통 검사는 재사용하되 적용성 결과를 실행마다 저장한다.

## 결과

- 장점: 불필요한 전체차단 감소, 미실행 구분, D55 유연한 자료해상도 반영
- 비용: 프로필 정본과 적용성 평가기 개발 필요
- 금지: 하나의 거대한 GateContext를 모든 산출물에 재사용
