# P0 구현 점검표

## 결과상태

- [ ] 7상태 결과모델이 코드·DB·API·UI에 반영됨
- [ ] 차단급 NOT_RUN/INDETERMINATE/SYSTEM_ERROR가 실제 발행을 차단함
- [ ] 결측값 기본 PASS 패턴 제거됨
- [ ] 적용성 사유가 결과마다 저장됨

## 승인

- [ ] 승인 시 저장된 주장목록과 검사보고서를 재수화함
- [ ] 빈 주장목록 승인이 실패함
- [ ] expectedHash 없는 승인이 실패함
- [ ] 사실변경 뒤 기존 승인이 실패함
- [ ] 모바일과 PPTX 승인범위가 분리됨

## 죽은 검사

- [ ] 무조건 true 검사 0건
- [ ] 관측불가를 0/false로 초기화한 검사 0건
- [ ] 실패할 수 없는 검사 0건
- [ ] 검사 관측기가 실제 산출물을 읽음

## 심각도와 적용성

- [ ] 환경변수로 block↔warn 변경 불가
- [ ] enforcementMode와 severity 분리
- [ ] appliesWhen이 실행경로에서 평가됨
- [ ] NOT_APPLICABLE과 NOT_RUN이 구분됨

## 시험

- [ ] P0 차단검사 양성·음성 짝 존재
- [ ] 최소 5개 실제 변조시험 CI 연결
- [ ] 실패흡수 경로 계수 시작
- [ ] 미판정·죽은 검사 계기판 표시
