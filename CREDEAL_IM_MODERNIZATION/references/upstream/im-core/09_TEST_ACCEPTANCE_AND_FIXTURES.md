# 4. 단위시험 최소목록

## canonical/hash

- 객체 key 순서가 달라도 같은 해시
- 집합 배열 순서가 달라도 같은 해시
- 페이지 순서 배열은 순서가 바뀌면 다른 해시
- 숫자 1과 문자열 "1"은 다른 해시
- 시간대가 다른 같은 시각은 같은 정규시각

## conflict

- null 기존값은 최초관측
- 0과 null은 다름
- 숫자 허용오차 정책 경계
- 문자열 공백 정규화
- 다필지 subjectPath 분리

## formula

- RR-C01 행합계
- RR-C04 보증금합계
- RR-C05 공실률 분모별
- RR-C09 관리비 청구합계
- RR-C11 희망가/보증금차감 희망가 basis
- RR-C13/RR-C14 운영비 결손 차단
- 단위변환 ㎡/평·원/만원/억원

## state

- 모든 허용전이
- 금지전이
- 편집 후 승인무효
- 새 스냅샷 후 양 채널 무효

# 5. 통합시험

1. 기존 입력→Observation 변환→Snapshot
2. Snapshot→ClaimEvaluation→Package
3. Package→Mobile project→승인→공개 URL
4. Package→PPTX project→미리보기→승인→파일
5. 같은 package 교차채널 핵심값 대조
6. document_objects 호환 투영 왕복
7. 구문서 read-only 재다운로드
8. RLS 소유자·비소유자·서비스 역할
9. idempotency 같은 요청/다른 요청
10. 기능깃발 on/off

# 6. 실무 품질평가

평가자: 대한민국 소형 상업용 부동산 중개실무자 권장 5명 이상.

| 항목 | 질문 |
|---|---|
| 매물 이해 | 앞부분에서 무엇을 얼마에 파는지 아는가 |
| 매각 소구 | 왜 검토할 만한지가 자연스럽게 드러나는가 |
| 중개인 의견 | 실제 담당 중개인의 설명처럼 읽히는가 |
| 신뢰 | 숫자·출처·확인사항이 과하지 않게 구분되는가 |
| 사진 | 외관·입지·사용·확인사진이 적절한 위치에 있는가 |
| 행동유도 | 문의·답사·자료요청의 다음 행동이 분명한가 |
| 편집부담 | 중개인이 혼자 수정·승인 가능한가 |

통과:

- 평균 4.0/5 이상
- 개별항목 3.0 미만 없음
- 중대한 오표현 지적 0
- 의견 반영 누락 0
