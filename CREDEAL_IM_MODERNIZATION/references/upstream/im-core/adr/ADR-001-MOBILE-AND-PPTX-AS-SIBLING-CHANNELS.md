# ADR-001 모바일 IM과 PPTX IM을 형제 발행채널로 분리

- 상태: 제안
- 날짜: 2026-08-31
- 결정자: 제품·기술책임자 승인 필요

## 배경

현행 PPTX는 모바일 IM JSON과 섹션 마크다운을 입력으로 변환한다. 모바일용 축약·순서·문안과 PPTX의 페이지·사진·표 요구가 다르고, PPTX가 원자료를 다시 바인딩해 같은 사실이 달라질 위험이 있다.

## 결정

모바일과 PPTX는 동일 `PublicationPackage`에서 갈라지는 독립 채널로 만든다. 모바일 발행본은 PPTX의 사실 정본이 아니다. 이미 승인된 채널 중립 내용 단위는 편집초안으로 재사용할 수 있다.

## 결과

- 모바일 없이 PPTX 생성 가능
- PPTX 없이 모바일 발행 가능
- 채널 실패 격리
- 각 채널 별도 최종승인 필요
- 공통 패키지·콘텐츠 계약 구현비용 증가

## 폐기한 대안

1. 모바일 JSON을 계속 PPTX 입력으로 사용: 결합과 재해석 위험 때문에 폐기.
2. 모바일과 PPTX가 각각 CORE를 호출해 독립 평가: 같은 시점에도 판정·기준일이 달라질 수 있어 폐기.
