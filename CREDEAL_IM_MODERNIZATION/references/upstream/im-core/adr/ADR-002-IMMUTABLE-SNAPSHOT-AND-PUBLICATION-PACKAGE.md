# ADR-002 불변 유효기준본과 공통 발행묶음 채택

- 상태: 제안
- 날짜: 2026-08-31

## 배경

현재 생성과 승인 사이에 주장목록·근거·게이트가 완전하게 영속되지 않는다. 자료보완이 기존 문서 body를 덮어쓰면 과거 발행본을 재현하기 어렵다.

## 결정

원자료·불일치·정정을 반영한 `EffectiveSnapshot`과 산출항목·의견·위험·사진·정책을 담은 `PublicationPackage`를 불변 저장한다. 발행본은 정확히 하나의 package를 참조한다.

## 결과

- 생성·승인·감사의 재현성
- 모바일/PPTX 핵심값 일치
- 자료보완 시 새 버전과 무효화 필요
- 저장량 증가, 대신 v1은 JSONB 집합체로 완화

## 폐기한 대안

1. 최신 building body만 읽기: 과거 재현 불가.
2. 발행 시마다 외부 API 재조회: 기준일·응답 차이와 실패 의존성.
