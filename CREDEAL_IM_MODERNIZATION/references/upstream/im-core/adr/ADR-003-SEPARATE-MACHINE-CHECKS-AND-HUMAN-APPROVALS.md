# ADR-003 기계검사와 사람승인 분리

- 상태: 제안
- 날짜: 2026-08-31

## 배경

기계검사 `passed`는 입력과 규칙이 허용했다는 뜻이다. 중개인 승인은 특정 문안·사진·가림·파일에 책임을 갖는 행위다. 한 상태로 합치면 무엇을 누가 확인했는지 알 수 없다.

## 결정

기계검사는 `GateDecision/Report`, 사람승인은 불변 `ApprovalEvent`로 분리한다. 모든 승인은 targetHash를 요구하고 변경 시 무효화한다. 모바일과 PPTX 최종승인은 별도다.

## 결과

- 승인범위·행위자·버전 추적
- 오래된 문안·파일의 승인 재사용 방지
- 승인사건과 무효화 로직 추가 필요

## 폐기한 대안

1. document status 하나로 승인: 범위·해시 없음.
2. 모바일 승인으로 PPTX 승인 대체: 레이아웃·사진·파일 차이를 검토하지 못함.
