# 모바일 IM 제작 파이프라인

## 1. 제품역할

모바일 IM은 중개인이 가장 먼저 검토하고 빠르게 공유하는 기본 채널이다. 자동초안은 L1 사실확인형이며, 승인 가능한 중개인 제안이 있으면 L1.5 중개인 제안형을 제시한다.

## 2. 시작조건

- 유효한 `PublicationPackage`
- `targetLevel`이 `eligibleLevels` 안에 있음
- 공개범위와 가림정책 결정
- 대표사진 선택 또는 사진없음 명시
- 중개인 연락정보의 공개승인

## 3. 단계

### M00 요청

입력: 패키지, 목표등급, 공개범위, 언어, 선택 제안단위  
출력: `MobileBuildRequest`

L1.5를 요청했지만 승인 가능한 제안단위가 없으면 L1으로 자동 강등하지 않고 선택지를 반환한다. 사용자가 L1 진행을 명시하면 새 요청을 만든다.

### M10 내용구성

필수 독자질문:

1. 무엇을 얼마에 사는가
2. 어떤 토지·건물·권리를 포함하는가
3. 공부상 핵심현황은 무엇인가
4. 지금 어떻게 사용·임대되고 있는가
5. 입지와 접근성에서 확인된 사실은 무엇인가
6. 반드시 확인할 위험·보완자료는 무엇인가
7. 누구에게 어떻게 문의하는가

L1.5 추가질문:

- 중개인이 주목하는 매수포인트는 무엇인가
- 무엇을 어떤 조건에서 활용할 수 있는가
- 어떤 매수자에게 맞을 수 있는가

### M20 조립

구조화 카드 유형:

- 대표사진+물건개요
- 매각조건
- 매각대상·다필지 범위
- 토지·건물 공부
- 임대차·사용현황
- 입지·교통
- 중개인 추천포인트(L1.5)
- 활용제안과 성립조건(L1.5)
- 위험·확인사항
- 현장답사·자료요청·문의

대표사진은 별도 표지만 강제하지 않는다. 사진 품질과 정보량에 따라 개요카드 옆 또는 상단, 전체폭 표지형, 관련 카드 인접형을 선택한다.

### M30 모바일 검사

필수검사:

- 모든 수치 토큰이 패키지의 허용 산출항목을 참조
- 조건부 항목에 경고·기준일·산정기준 표시
- 중개인 의견의 원문·근거·성립조건·승인 연결
- 숨겨야 할 개인정보·정책어·내부등급 제거
- 대표사진 공개승인·해상도·가림처리
- 카드 길이·표 가로폭·모바일 줄바꿈
- 보완과제 3개 이내 우선순위 표시
- 연락처·면책·자료기준일

### M40 검토·승인

중개인이 확인하는 승인범위:

- 사실표시와 매각조건
- 중개인 의견·추천문구
- 사진·캡션·가림처리
- 공개범위·연락처
- 최종 화면문안 해시

승인 후 문안이나 사진이 바뀌면 기존 승인은 무효다.

### M50 발행

- 승인된 `MobilePublicationVersion`만 공개주소에 연결한다.
- 공개주소는 최신 승인본을 가리키되 과거 버전과 배포기록을 보존한다.
- 철회 시 410 또는 정책에 따른 안내화면을 제공한다.

## 4. L1.5 허가조건

제안단위마다 다음이 모두 있어야 한다.

| 항목 | 예 |
|---|---|
| 중개인 원문 | “자가사용 부분 임대 전환 검토 가능” |
| 사실근거 | 사용현황, 면적, 현장사진 |
| 매수자 의미 | 추가 임대수입 가능성 |
| 성립조건 | 인도시기, 수요, 시설공사 |
| 공개문구 | 과장 없이 조건부 표현 |
| 공개승인 | 승인자·시각·문구해시 |

하나라도 없으면 외부 L1.5 카드에 표시하지 않고 내부 보완과제로 남긴다.

## 5. AI 사용경계

AI 가능:

- 허용된 사실의 자연스러운 한국 중개실무 문장 후보
- 중복내용 축약
- 제목 후보 3개
- 중개인 원문의 공개문구 정리
- 카드 길이에 맞춘 요약

AI 금지:

- 새 수치·수익률·면적 계산
- 근거 없는 가치상승·임대수요 단정
- 법률·세무 상태 확정
- 차단항목을 자연스러운 문장으로 우회
- 내부 `L1.5`, `allowed_with_warning` 같은 정책어 노출

## 6. 현재 경로 전환

- 현행 `writer`는 당분간 새 패키지에서 구형 `sections`를 만드는 어댑터로 사용한다.
- 신규 모바일 조립기는 `document_objects.body.enrichment`를 읽지 않는다.
- 저장은 `MobilePublicationVersion`이 정본이고 `document_objects`는 공개화면 호환 투영이다.
- 편집이벤트는 마크다운 전체 차이뿐 아니라 `contentUnitId`, 변경종류, 사실토큰 영향 여부를 기록한다.

## 7. 완료조건

- L1/L1.5 등급별 필수 독자질문 누락 0건
- 중개인 의견 역추적 100%
- 사진 0/1/3/8/10장 초과 변종에서 빈 카드·중복사진 없음
- 모바일 문안 변경이 PPTX 승인과 CORE 실행을 건드리지 않음
- 핵심 수치의 패키지 대비 불일치 0건
