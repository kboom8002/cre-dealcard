# PPTX IM Studio 제작 파이프라인

## 1. 제품역할

PPTX IM Studio는 같은 검증자료로 한국 소형 상업용 부동산 매수자가 읽을 수 있는 면구성·카피·사진·표·지도를 편집하는 독립 제작제품이다. 모바일 문서를 변환하는 다운로드 기능이 아니다.

## 2. 프로젝트 모델

```yaml
projectId: STUDIO-UUID
caseId: CASE-UUID
packageId: PKG-UUID
targetLevel: L1.5
audienceBrief:
  buyerType: private_investor
  purpose: sale_proposal
  emphasis: [location, lease_stability, owner_use_conversion]
version: 4
status: editing
compositionPlanRef: ART-COMP-04
copyPlanRef: ART-COPY-04
mediaPlanRef: ART-MEDIA-04
layoutPlanRef: ART-LAYOUT-04
```

프로젝트는 편집가능하고, 각 버전은 불변이다. 최종승인은 특정 프로젝트 버전에만 적용된다.

## 3. 단계

### S00 프로젝트 생성

- 패키지와 가능한 문서등급 표시
- 독자·문서목적·강조점 입력
- 기본 테마·브랜드·연락정보 선택
- 모바일 발행본은 선택적 문안참고일 뿐 필수입력 아님

### S10 페이지 구성안

구성기는 다음을 함께 고려한다.

- 목표등급의 필수 독자질문
- 허용된 산출항목·제안·위험·실사정보
- 사진 수·종류·방향·해상도
- 표의 행 수와 다필지 복잡도
- 7~15면 권장 지면예산

고정면수를 채우지 않는다. 근거가 없는 분석면, 사진이 없는 갤러리, 한 줄짜리 빈 페이지를 만들지 않는다.

### S20 문안·표 계획

- 제목·본문은 한국 상업용 부동산 중개실무 어휘를 사용한다.
- 숫자는 `ClaimRef` 토큰으로 잠근다.
- 표 셀은 원 임대차행 또는 산출항목 참조를 가진다.
- 조건부 수치에는 기준일·산정기준·주의문구를 같은 면 또는 각주에 둔다.
- 중개인 의견은 객관적 사실과 시각적으로 구분한다.

### S30 사진·레이아웃

사진 배치는 역할 중심으로 결정한다.

- 대표외관: 개요 옆, 상단 넓은 영역, 표지형 중 품질에 맞게 선택
- 출입·도로·전면: 접근성·가시성 설명과 인접
- 층별 내부: 임대차·사용현황 또는 활용제안과 인접
- 노후·보수부위: 위험·현장확인과 인접
- 지도·지적: 위치·매각범위와 인접

한 사진을 여러 면에 반복할 때는 명확한 편집의도가 있어야 한다. 저해상도 확대, 인물·차량번호·임차인정보 노출을 검사한다.

### S40 미리보기

- 프로젝트 버전을 고정하고 PDF 또는 이미지 미리보기를 만든다.
- 미리보기의 각 면은 구성·문안·사진·레이아웃 산출물 해시를 가진다.
- 사용자의 수정은 새 프로젝트 버전을 만들고 이전 미리보기를 바꾸지 않는다.

### S50 지면·사실 교차검사

네 부류를 모두 통과해야 한다.

1. 사실: 허용 산출항목, 값·단위·기준일·산정기준
2. 문안: 과장·정책어·금지표현·의견구분
3. 사진: 공개승인·크롭·가림·근거연결
4. 지면: 넘침·겹침·잘림·저해상도·빈면·대비·폰트대체

### S60 최종승인

승인대상:

- `packageHash`
- `projectVersionHash`
- `copyPlanHash`
- `mediaPlanHash`
- `layoutPlanHash`
- `previewArtifactHash`
- 배포범위·워터마크·연락처

### S70 최종 렌더·배포

- 승인된 고정 버전으로만 렌더한다.
- 렌더러 버전과 테마 버전을 파일 이력에 기록한다.
- 파일 바이트 해시와 슬라이드 수·파일 크기·검사보고서를 저장한다.
- 내보내기 후 바이트가 바뀌면 새 파일버전과 승인범위를 판단한다.

## 5. 모바일 문안 재사용

모바일에서 승인된 `CopyUnit`은 Studio에서 가져올 수 있다. 다만 다음을 지킨다.

- 재사용 출처와 원 해시 표시
- PPTX 길이에 맞춘 수정은 새 CopyUnit 버전
- 수치토큰은 그대로 유지
- 모바일 최종승인이 PPTX 수정문구를 승인한 것으로 간주되지 않음

## 6. 현행 렌더러 전환

### 단기

- `MobileImPptxRenderer` 앞에 `PublicationPackage → LegacyMobileImPptxInput` 어댑터를 둔다.
- 어댑터는 허용된 구조화값만 채우고 원시 `enrichment`를 전달하지 않는다.
- 렌더 결과에 `packageId`, 상위해시, 렌더러 버전을 기록한다.

### 중기

- `PptxStudioRenderer` 입력을 `CompositionPlan + CopyPlan + MediaPlan + LayoutPlan`으로 전환한다.
- 공개 GET 요청에서 즉석 생성하지 않고 승인된 파일 또는 렌더 작업상태를 반환한다.

### 종료

- `doc.body.sections` 직접입력 중단
- `getTierAllowedSections` 신규호출 금지
- 구형 경로는 과거 파일 재다운로드만 제공

## 7. 완료조건

- 모바일 문서가 없는 패키지에서 PPTX 생성 성공
- PPTX 문안·사진·레이아웃 변경 시 CORE·모바일 재실행 0건
- 차단 산출항목 노출 0건
- 사실값을 텍스트로 바꾼 변조시험 100% 차단
- PowerPoint·LibreOffice·미리보기 PDF에서 치명 레이아웃 결함 0건
