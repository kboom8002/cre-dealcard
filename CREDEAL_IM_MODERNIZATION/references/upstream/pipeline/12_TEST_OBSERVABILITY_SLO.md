# 시험·운영관측·서비스 목표

## 1. 품질목표

우선순위는 정확성·추적성·복구성·가독성·속도 순서다. 빠르게 잘못된 IM을 만드는 것은 성공이 아니다.

## 2. 시험 피라미드

| 수준 | 대상 | 필수 |
|---|---|---|
| 단위 | 산식·상태전이·해시·변경분류 | 모든 규칙 정상/반대/미실행 |
| 스키마 | 명령·산출물·사건 | 예제와 오류표본 검증 |
| 계약 | 단계 입력·출력·오류 | 실행자 교체 가능성 |
| 통합 | DB·대기열·저장소·보관함 | 장애·중복전달·재개 |
| 채널 | 모바일·PPTX 조립·검사 | 패키지 대비 수치대조 |
| E2E | 접수→승인→배포 | L1/L1.5·다필지·자료등급 |
| 시각 | 모바일 뷰·PPTX 페이지 | 넘침·겹침·크롭·가독성 |
| 복구 | 작업자종료·공급자장애·되돌리기 | 체크포인트·구형전환 |

## 3. 필수 데이터 변종

- 임대차 없음
- 최소 임대차: 보증금·임대료·공실
- 표준 임대차: 관리비 포함
- 완전 임대차: 기간·부가세·수납·운영비
- 합계와 행합계 불일치
- 0/공란/미제공/해당없음 혼합
- 단일필지·다필지·일부필지 매각
- 사진 0/1/3/8/10장 초과
- 중개인 의견 없음/근거없음/조건없음/승인완료
- 공공 API 전부성공/일부실패/시간초과/오래된 캐시

## 4. 전환 차단시험

1. 공란이 0으로 바뀌지 않는다.
2. 관리비가 기본임대료·NOI에 자동합산되지 않는다.
3. 운영비가 없으면 NOI·Cap Rate가 차단된다.
4. 대표필지 값이 다른 필지에 전파되지 않는다.
5. 핵심 미해결 불일치를 사용한 문구·수치는 차단된다.
6. `not_evaluated` 규칙은 통과가 아니다.
7. 빈 판정집합으로 승인할 수 없다.
8. 승인대상 해시가 바뀌면 발행할 수 없다.
9. 모바일 없이 PPTX를 만들 수 있다.
10. PPTX 없이 모바일을 발행할 수 있다.
11. 한 채널 실패가 다른 채널과 CORE를 실패시키지 않는다.
12. PPTX 문안수정이 모바일을 다시 만들지 않는다.
13. 사실값 변경이 양 채널을 오래된 상태로 만든다.
14. 중단된 실행이 성공단계를 반복하지 않고 재개된다.
15. 중복 사건이 중복 승인·발행을 만들지 않는다.

## 5. 오류주입시험

| 주입 | 기대결과 |
|---|---|
| P10 중 작업자 종료 | 임대만료 후 해당 하위작업 재실행 |
| API 429+Retry-After | 공급자 정책대로 지연, 최대시도 준수 |
| DB 저장 성공·사건발행 실패 | 보관함에서 나중에 사건발행 |
| 사건 중복전달 | 소비자 결과 1회 |
| P30 산출물 본문 변조 | 해시 불일치, P40 시작차단 |
| LLM 숫자 삽입 | 구조화 수치대조 차단 |
| PPTX 저해상도 사진 | S50 차단·대체요청 |
| 승인 직후 프로젝트 수정 | 승인 무효, S70 차단 |
| 렌더 후 파일변조 | 파일해시 불일치, 배포차단 |

## 6. 계측

모든 로그·지표·추적에 `correlationId`, `runId`, `stageExecutionId`, 가능하면 `caseId`를 포함한다.

### 핵심 지표

- 실행 성공·부분성공·차단·실패율
- 단계별 대기·실행·재시도시간
- 공급자별 성공률·지연·캐시사용률
- 산출물 재사용률
- 사용자 보완까지 걸린 시간
- 산출항목 허가·조건부·차단·미판정 비율
- L1/L1.5 후보·승인·발행 전환율
- 모바일/PPTX 사실 불일치 건수
- 승인무효·재생성 원인
- 렌더 결함 유형과 재시도율
- 실행당 LLM 토큰·비용, 외부 API 비용

## 7. 서비스 목표

| 목표 | 초기 SLO |
|---|---:|
| 명령 수락 p95 | 1초 이하 |
| P00~P60 성공 p95(사용자보완 제외) | 120초 이하 |
| 부분 API 장애 시 L1 판단완료 p95 | 180초 이하 |
| 모바일 조립·검사 p95 | 60초 이하 |
| PPTX 미리보기 p95 | 120초 이하 |
| PPTX 최종렌더 p95 | 180초 이하 |
| 사건 보관함 발행 지연 p99 | 60초 이하 |
| 단계 성공 후 산출물 유실 | 0건 |
| 차단 산출항목 외부노출 | 0건 |
| 같은 패키지 핵심값 채널불일치 | 0건 |

속도 SLO는 4주간 기초선을 측정한 뒤 조정한다. 정확성 0건 목표는 완화하지 않는다.

## 8. 경보

- 5분간 실행 치명실패율 10% 초과
- 공급자 순환차단 열림
- 사건 보관함 미발행 5분 초과
- 단계 임대 만료 반복 3회
- 승인대상 해시 불일치 급증
- 채널 사실대조 불일치 1건 이상
- 차단 산출항목 노출 1건 이상 — 즉시 기능깃발 중단
- PPTX 손상파일 1건 이상 — 신규 내보내기 중단 검토

## 9. 당산동 기준실행

동일 입력으로 다음 결과를 보관한다.

- P00~P60의 각 산출물과 해시
- L1 모바일, L1.5 모바일
- L1.5 PPTX Studio 프로젝트와 최종파일
- 중개인 의견 반영표
- 사진 역할·반영면 표
- 모든 외부 수치의 계보표
- 구형 결과와 신규 결과의 값·누락·문안·제작시간 비교

가상보완 자료는 실제 입력과 명확히 분리하고 예시 산출물 부록에만 표시한다.
