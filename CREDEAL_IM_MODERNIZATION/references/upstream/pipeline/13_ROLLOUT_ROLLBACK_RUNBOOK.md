# 병행운영·전환·복구 실행서

## 1. 전환원칙

- 추가형 스키마와 이중기록으로 시작한다.
- 기능깃발은 거래건·중개인·채널별로 독립 적용한다.
- 정확성·승인·배포 문제가 1건이라도 발생하면 범위를 확대하지 않는다.
- 되돌리기는 코드를 되돌려도 신규 산출물과 사건을 삭제하지 않는다.

## 2. 기능깃발

| 깃발 | 기능 |
|---|---|
| `im_pipeline_v2_core` | P00~P60 신규 실행 |
| `im_pipeline_v2_mobile` | 신규 모바일 조립·승인 |
| `im_pipeline_v2_pptx_studio` | Studio 프로젝트·렌더 |
| `im_pipeline_v2_dual_write` | 구형 조회모델 투영 |
| `im_pipeline_v2_public_read` | 공개화면 신규 발행본 읽기 |
| `im_pipeline_v2_pptx_download` | 승인된 Studio 파일 다운로드 |

## 3. 단계별 전환

### R0 내부 그림자 실행

- 운영요청은 구형 결과를 제공
- 신규 CORE를 그림자로 실행해 값·상태·시간 비교
- 외부발행과 사람승인은 신규경로에서 하지 않음

진입: E0·E1·E2 시험통과  
종료: 100건 이상, 핵심값 불일치 0, 치명오류 원인해소

### R1 내부 사용자 1%

- 지정 중개인만 신규 모바일 초안 사용
- 구형 결과와 전환 가능
- PPTX는 구형과 Studio 병행생성, 외부배포는 하나만 승인

### R2 10%

- 신규 CORE+모바일을 기본
- Studio는 선택기능
- 일별 이중기록 대조와 주간 품질회의

### R3 50%

- 승인된 Studio 파일 다운로드 기본
- 구형 즉석 PPTX는 예외깃발로만
- 운영자 재개·철회 훈련 완료

### R4 100%

- 신규 진입 전부 v2
- 구형 생성·즉석렌더 종료
- 과거 파일 재다운로드만 유지

## 4. 각 단계 중단조건

- 차단 산출항목 외부노출 1건
- 승인되지 않은 의견·사진 외부노출 1건
- 모바일/PPTX 핵심값 불일치 1건
- 데이터 유실 또는 실행복구 불가 1건
- 치명오류율 5% 초과 15분 지속
- 공개주소가 승인되지 않은 버전을 가리킴
- 개인정보 가림 위반 1건

## 5. 30분 되돌리기

1. 신규 명령수락 깃발 중단
2. 공개읽기와 PPTX 다운로드를 마지막 안정경로로 전환
3. 실행중 자식 채널 작업 취소표식, CORE 작업은 안전 체크포인트까지 종료
4. 잘못된 배포레코드 철회
5. 구형 투영 최신상태 확인
6. 사건 보관함은 계속 발행하고 산출물은 보존
7. 사고번호·영향거래건·해시·시각을 기록
8. 데이터 복구보다 원인확인 전에는 신규범위 재개 금지

## 6. 장애별 대응

### 공공 API 전면장애

- 공급자 순환차단
- 캐시의 기준일과 사용여부 명시
- 핵심 식별자료 없으면 P20 차단
- 이미 생성된 승인본은 기준일 정책에 따라 유지 또는 오래됨 표시

### 작업대기열 장애

- 새 명령은 접수하되 `queued` 보존
- HTTP 요청 안에서 장시간 작업으로 우회하지 않음
- 복구 후 임대·예약 재구축

### 객체저장소 장애

- 산출물 DB 등록을 성공처리하지 않음
- 파일 없는 승인·배포 차단
- 이미 공개된 파일은 CDN 상태 점검

### 렌더러 결함

- PPTX 신규 내보내기 깃발 중단
- 모바일과 CORE는 계속 가능
- 이전 승인 파일 재다운로드 유지

### 잘못된 규칙배포

- 규칙버전 기능깃발 되돌림
- 영향받은 GateReport와 패키지 조회
- 발행본을 `stale_review_required` 또는 `stale_invalid`로 전환
- 재검사 계획 실행
