# CREDEAL IM 제작 파이프라인 개편 문서 세트

> 버전: 1.0.0  
> 기준일: 2026-08-31  
> 기준 문서: D58 `D55 적용 IM CORE 개편 및 PPTX IM Studio 분리 제안`  
> 대상: 제품책임자, 기술책임자, 백엔드·프론트엔드·AI·PPTX·품질보증·운영 담당자

## 1. 이 문서 세트의 목적

이 세트는 D58의 목표구조를 실제 개발 가능한 IM 제작 파이프라인 사양으로 변환한다. 핵심은 모바일 IM을 만든 뒤 PPTX로 변환하는 현행 연속생산을 다음 구조로 바꾸는 것이다.

```text
입력접수 → 근거수집 → 불일치조정 → 유효기준본 → 산출항목판정 → 공통 발행묶음
                                                                  ├─ 모바일 L1/L1.5
                                                                  └─ PPTX IM Studio
```

모바일과 PPTX는 같은 사실·계산·허가판정을 사용하되, 서로의 산출물을 사실정본으로 사용하지 않는다. 한 채널의 편집·렌더 실패는 다른 채널과 공통 CORE 실행을 실패시키지 않는다.

## 3. 개발팀이 먼저 해야 할 일

- 첫째, `im_generation_jobs`를 성공·실패 한 행으로만 쓰는 방식을 보조 조회모델로 내리고 단계 실행·산출물 등록·이벤트 보관소를 추가한다.
- 둘째, 생성 당시의 유효기준본·산출항목판정·기계검사 결과를 불변 산출물로 저장하고 승인 시 해시로 재확인한다.
- 셋째, `document_objects.body`와 모바일 마크다운을 PPTX 사실입력으로 사용하는 신규 경로를 금지한다.
- 넷째, 모바일과 PPTX를 `PublicationPackage`에서 갈라지는 독립 자식 실행으로 전환한다.
- 다섯째, 변경 종류에 따라 필요한 단계만 다시 실행하고 기존 승인과 발행본을 정확히 오래된 상태로 바꾼다.

## 5. 구현 불변조건 요약

1. 한 발행본은 하나의 `snapshotId`만 참조한다.
2. 단계는 입력 산출물 해시가 같을 때 같은 결과를 내거나 같은 결과를 재사용한다.
3. 실패한 외부자료 호출을 0 또는 사실처럼 대체하지 않는다.
4. `not_evaluated`와 `not_available_at_stage`는 발행허가가 아니다.
5. 기계검사 통과는 사람의 승인과 다르다.
6. 모바일 승인은 PPTX 최종파일 승인을 대신하지 않는다.
7. PPTX는 모바일 마크다운에서 수치를 추출해 새 산출항목을 만들지 않는다.
8. 채널 편집은 구조화 사실을 덮어쓰지 않는다.
9. 공통 발행묶음 이후의 채널 실패는 형제 채널과 CORE 성공을 되돌리지 않는다.
10. 원자료·정정·판정·문안·사진·렌더파일은 모두 해시와 상위 산출물 참조를 가진다.

## 6. 도입 완료의 최종 판정

다음이 모두 충족되어야 구형 연속생산 경로를 종료할 수 있다.

- 모바일 문서 없이도 공통 발행묶음으로 PPTX를 만들 수 있다.
- PPTX 없이도 모바일을 발행할 수 있다.
- 같은 발행묶음의 핵심 사실값·단위·기준일 불일치가 0건이다.
- 차단 산출항목의 외부노출이 0건이다.
- 생성·승인·발행의 입력해시와 규칙버전을 재현할 수 있다.
- 중단된 실행을 마지막 유효 체크포인트부터 복구할 수 있다.
- 기존 경로로 즉시 되돌릴 수 있고 신규 데이터는 보존된다.
