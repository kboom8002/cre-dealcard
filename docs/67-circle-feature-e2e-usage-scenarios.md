# 브로커 일간/주간 E-to-E 활용 시나리오 (서클 기능 통합)

> **문서 목적**: 이번 세션에서 신규 구현된 **Circle(서클) 팀 매칭** 기능을 포함한 CRE DealCard 시스템의 브로커 일간/주간 활용 시나리오를 MECE하게 도출하고, 루브릭 평가를 통해 개선점을 식별한다.
>
> **대상 페르소나**: 서울 상업용 부동산 전문 중개인 (5060 베테랑 + 3040 디지털 친숙 중개인)

---

## 1. 시스템 기능 인벤토리

### 1.1 Bottom Nav 기본 진입점

| 위치 | 라벨 | 경로 | 핵심 기능 |
|------|------|------|-----------|
| 좌1 | 홈 | `/broker` | 코크핏 대시보드 (인사, KPI, 알림, 액션큐, 파이프라인, ROI, 시장분석, 주간/월간 리포트, 모닝인텔리전스) |
| 좌2 | 딜카드 | `/broker/buildings` | 내 매물 목록, 딜카드 상세 |
| 중앙 | + (FAB) | 신규 생성 | 딜카드 등록, 매수자 등록, 메모 입력 |
| 우1 | 매칭 | `/broker/matching` | AI 자동매칭 결과 (개인/팀서클/전체) |
| 우2 | 더보기 | 바텀시트 | 업무 도구, 시장 인텔리전스, 설정 |

### 1.2 더보기 메뉴 구조

**업무 도구**: 메모함, 임장 일정 관리, **내 서클 (팀 매칭)** 🆕, 고객 CRM, 딜 파이프라인, 행동 퍼널 분석, 캠페인 카피 AI, 콘텐츠 스튜디오, AI 리싱 스튜디오

**시장 인텔리전스**: CRE 펄스, CRE 인사이트, 세금·DD 도구

**설정**: 프로필 관리, 이용 가이드

### 1.3 이번 세션 신규 기능 (Circle)

| 기능 | 설명 | 진입점 |
|------|------|--------|
| 서클 개설 | 신뢰 동료 그룹 생성 | 서클 목록 → 개설 버튼 |
| 서클 초대 | 카카오톡 딥링크 원클릭 초대 | 서클 상세 → 멤버 탭 |
| 서클 가입 | 딥링크 자동 가입 | 초대 링크 클릭 |
| 서클 탈퇴 | 멤버 자발적 탈퇴 | 서클 상세 → 설정 |
| 서클 공유 (딜카드) | 딜카드 → 서클 공유 시트 | 딜카드 상세 → 액션메뉴 |
| 서클 공유 (매수자) | 매수의향 → 서클 공유 | 매수자 상세 → 공유 버튼 |
| 서클 AI 매칭 | 공유 시 자동 팀 매칭 트리거 | 자동 (공유 이벤트 기반) |
| 서클 매칭 탭 | 매칭 결과 3번째 탭 | 매칭 페이지 → 팀 서클 탭 |
| Progressive Trust | 신뢰 단계별 정보 공개 (signal → basic → full) | 서클 공유 설정 |

## 2. 일간(Daily) E-to-E 시나리오 — MECE 분류

### 2.1 분류 프레임워크 (MECE)

```
브로커 일간 활용
├── A. 아침 루틴 (Morning Routine)
│   ├── A1. 대시보드 체크 & 액션큐 확인
│   ├── A2. 모닝 인텔리전스 확인
│   └── A3. 알림 피드 처리
│
├── B. 신규 정보 입력 (Data Capture)
│   ├── B1. 신규 딜카드 등록 (카톡 메모 붙여넣기)
│   ├── B2. 신규 매수자 의향 등록
│   ├── B3. 유니버설 메모 기록
│   └── B4. 기존 딜카드 정보 보강/수정
│
├── C. 매칭 & 서클 협업 (Matching & Circle) 🆕
│   ├── C1. 개인 AI 매칭 결과 확인 & 응답
│   ├── C2. 서클 공유 (딜카드/매수자 → 팀 공유)
│   ├── C3. 서클 매칭 결과 확인 & 응답
│   ├── C4. 서클 초대/가입 관리
│   └── C5. 서클 내 공유 자산 현황 확인
│
├── D. 고객 커뮤니케이션 (Outbound)
│   ├── D1. IM (투자보고서) 생성 & 공유
│   ├── D2. 카카오 딜카드 공유
│   ├── D3. 캠페인 카피 AI 생성 (인스타/블로그)
│   ├── D4. 매거진 발행
│   └── D5. 블라인드 티저 공유
│
├── E. 딜 진행 관리 (Pipeline)
│   ├── E1. 파이프라인 단계 이동
│   ├── E2. 임장 일정 관리 (슬롯/예약)
│   ├── E3. Gate 승인/거절 처리
│   └── E4. 행동 퍼널 전환율 확인
│
└── F. 인텔리전스 & 학습 (Intelligence)
    ├── F1. CRE 펄스 (시장 시그널) 확인
    ├── F2. CRE 인사이트 (롱폼 분석) 읽기
    └── F3. 세금/DD 시뮬레이터 활용
```

### 2.2 시나리오 상세

#### 🌅 A. 아침 루틴 (Morning Routine)

**A1. 대시보드 체크 & 액션큐 확인**

| 단계 | 사용자 행동 | 시스템 반응 | 화면 |
|------|-----------|-----------|------|
| 1 | 앱 실행 → 홈 대시보드 | 인사 + KPI 카드 로드 | `GreetingHeader` |
| 2 | KPI 스크롤 카드 확인 | 매매물건, 임대물건, S/A매칭, 관리고객, 매수고객 수 표시 | KPI 가로 스크롤 |
| 3 | 액션큐 탭 진입 | PipelineSnapshot + Hot Lead 알림 | `ActionQueue` |
| 4 | Hot Lead 카드 탭 | 해당 딜카드로 이동 | 딜카드 상세 |

**A2. 모닝 인텔리전스 확인**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 대시보드 '모닝 인텔리전스' 탭 | AI 시장 브리핑 표시 |
| 2 | 관심 기사 탭 → 상세 | 상세 분석 표시 |
| 3 | 시장 대응 전략 탭 | MarketBreakthroughMode 표시 |

**A3. 알림 피드 처리**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 홈 '개요' 탭 → 알림 피드 | Gate 요청, 매칭 알림, 파이프라인 변경 등 |
| 2 | 알림 카드 탭 | 해당 페이지로 네비게이션 |
| 3 | '전체 보기' → 소통 관리함 | `/broker/inbox` 전체 피드 |

---

#### 📥 B. 신규 정보 입력 (Data Capture)

**B1. 신규 딜카드 등록 (30초 등록)**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 홈 '딜카드 등록' 퀵액션 or FAB(+) | `/broker/deal-card/new` 이동 |
| 2 | 카카오톡 메모 붙여넣기 | AI 자동 파싱 (주소, 가격, 면적, 수익률 등) |
| 3 | 정보 확인/수정 후 저장 🆕 | Quality Gate 인라인 가이드(📍, 🏢, 💰, 📐)로 누락 정보 확인 |
| 4 | 저장/생성 실행 🆕 | 취소 버튼 및 30초 AbortController 타임아웃 제공 |
| 5 | 삭제 시나리오 🆕 | `archived_at` 소프트 삭제(Soft delete) 지원 |
| 6 | **🆕 서클 공유 옵션** | 등록 시 '서클에 공유' 시트 표시 가능 |
| 7 | AI 자동 매칭 트리거 | 개인 매칭 + 서클 매칭 동시 실행 |

**B2. 신규 매수자 의향 등록**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | FAB(+) → 매수자 등록 | buyer_intent_lite 생성 폼 |
| 2 | 고객 정보, 관심 지역, 예산 입력 | buyer_intent_lite 저장 |
| 3 | **🆕 서클 공유 옵션** | '서클에 공유' 시트 표시 |
| 4 | AI 매칭 트리거 | 적합 매물 자동 스캔 |

**B3. 유니버설 메모 기록**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 어디서든 FAB 메모 버튼 | `UniversalMemoFAB` 확장 |
| 2 | 텍스트/음성 메모 입력 | 메모 저장 → 추후 딜카드 연동 가능 |

**B4. 기존 딜카드 정보 보강**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 딜카드 목록 → 특정 딜카드 | 4탭 구조(개요│IM│매수자│분석) 딜카드 상세 페이지 🆕 |
| 2 | 정보 편집 (사진, 가격, 추가 데이터) | 모바일 호버 버튼 상시 노출(opacity-70) 지원 🆕 |
| 3 | 데이터 품질 배지 확인 | 입력 완성도 게이지 |

---

#### 🔗 C. 매칭 & 서클 협업 (Matching & Circle) 🆕

**C1. 개인 AI 매칭 결과 확인**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 하단 네비 '매칭' 탭 | AI 매칭 결과 리스트 (매매/임대) |
| 2 | S/A 등급 매칭 카드 확인 🆕 | 데모가 아닌 DB 연동 실제 데이터(Real data)로 매칭 결과 확인 |
| 3 | 매칭 카드 탭 → 상세 | 물건·고객 정보 + 연결 액션 |

**C2. 서클에 딜카드/매수자 공유 🆕**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 딜카드 상세 → 액션 메뉴 → '서클에 공유' | `ShareToCircleSheet` 바텀시트 표시 |
| 2 | 대상 서클 선택 + 공개 수준 설정 | `signal_only` / `basic_info` / `full_detail` 선택 |
| 3 | 공유 확인 🆕 | `circle_shared_assets` 생성 및 `notifyCircleMatch()` 알림톡 발송 트리거 |
| 4 | **자동 팀 매칭 트리거** | 서클 내 매수자 의향과 자동 매칭 실행 |

> 매수자 의향서에서도 동일 흐름 (`buyer-intent-header.tsx` → 서클 공유)

**C3. 서클 매칭 결과 확인 🆕**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 매칭 탭 → **'팀 서클' 3번째 탭** | 서클 내 공유 자산 기반 매칭 결과 |
| 2 | `CircleMatchCard` 카드 확인 | 매칭 등급, 상대방 공유 정보, 신뢰 수준 |
| 3 | 매칭 카드 탭 → 상세 진입 | 물건/고객 정보 (Progressive Trust 수준에 따른 공개) |

**C4. 서클 초대/가입/탈퇴 관리 🆕**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 더보기 → '내 서클' | 서클 목록 페이지 (`/broker/circles`) |
| 2a | '서클 개설' 버튼 | 서클 이름, 설명 입력 → 개설 완료 |
| 2b | '멤버 초대' 버튼 | 카카오톡 딥링크 생성 → 공유 |
| 3 | 초대받은 동료: 링크 탭 | 자동 가입 → 서클 목록에 표시 |
| 4 | 서클 상세 → 멤버 탭 | 멤버 목록, 역할 확인 |
| 5 | 서클 설정 → 탈퇴 | 자발적 탈퇴 처리 |

**C5. 서클 내 공유 자산 현황 확인 🆕**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 서클 상세 → '공유 물건' 탭 | 서클 내 공유된 딜카드/매수자 목록 |
| 2 | 공유 물건 카드 탭 | Progressive Trust 수준에 따른 정보 표시 |
| 3 | '매칭' 탭 | 해당 서클 내 매칭 결과 |

#### 📤 D. 고객 커뮤니케이션 (Outbound)

**D1. IM (투자보고서) 생성 & 공유**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 딜카드 상세 → 'IM 관리' | Basic/Pro 비교 카드(details 그리드) 제공 🆕 및 IM 미생성 시 친화적 안내 제공 🆕 |
| 2 | 'IM 생성' 버튼 🆕 | 4단계(분석→작성→검증→완료) 비동기 프로그레스 UI 표시 |
| 3 | IM 미리보기 → 발행 | 모바일 IM Lite 페이지 생성 |
| 4 | PPTX 프리셋 에디터 🆕 | DB 연동 커스텀 프리셋 편집, 실시간 토큰 및 SAMPLE_DATA 프리뷰 제공 |
| 5 | 카카오 공유 / 다운로드 🆕 | Blob 다운로드 방식 기반 진행 상태 토스트(Toast) 메시지 노출 |

| 1 | 딜카드 → '카카오 공유' | 블라인드 티저 + OG 이미지 카카오톡 공유 |

**D3. 캠페인 카피 AI**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 더보기 → 캠페인 카피 AI | AI 기반 마케팅 문구 생성 |
| 2 | 채널 선택 (인스타/블로그/문자) | 채널 최적화 카피 생성 |
| 3 | 히스토리 확인 🆕 | DB 저장된 과거 캠페인 카피 히스토리 탭 제공 |

**D4. 매거진 발행**

| 4 | 매거진 발행 → 구독자 배포 🆕 | 🚀 발행 버튼 클릭 시 activity_events(magazine_distributed) 기록 및 알림톡 |

**D5. 블라인드 티저 공유**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 딜카드 → 블라인드 티저 프리뷰 | 가격대/권역만 노출된 티저 |
| 2 | 카카오/링크 공유 | 수신자: 관심 표명 → Gate 신청 |

#### 📊 E. 딜 진행 관리 (Pipeline)

**E1. 파이프라인 단계 이동**

| 단계 | 사용자 행동 | 시스템 반응 |
|------|-----------|-----------|
| 1 | 더보기 → 딜 파이프라인 | 8단계 칸반/리스트 뷰 |
| 2 | 단계 필터링 🆕 | PIPELINE_STAGES 버튼 클릭하여 빌딩 리스트 필터링 |
| 3 | 딜 드래그 or 단계 변경 | 파이프라인 업데이트 → 이벤트 발생 |

**E2. 임장 일정 관리**

## 8. 결론

### 핵심 성과

1. **서클 기능이 기존 흐름에 자연스럽게 통합됨** — 딜카드/매수자 상세의 액션 메뉴에 서클 공유가 원클릭으로 내장되어, 별도 학습 없이 즉시 활용 가능
2. **3-Layer Trust Model이 정보 민감도를 효과적으로 관리** — signal_only → basic_info → full_detail의 단계적 공개가 중개인의 핵심 우려(정보 누출)를 해결
3. **Always-On 매칭 엔진이 공유 이벤트를 자동 트리거** — 수동 매칭 요청 없이 공유 시 자동 매칭되어 무마찰 경험 제공

### 최우선 개선 과제

1. **서클 진입 경로 단축** (홈 퀵액션 또는 Bottom Nav 통합)
2. **서클 매칭 푸시 알림** (카카오/FCM 연동)
3. **서클 활동 통계 대시보드** (공유/매칭/성사 트래킹)
