## 1. 누구를 위한 시스템인가?

### 1차 타깃: 꼬마빌딩 전문 중개사

**당신이 매일 겪는 고충:**

| 😫 현재 수작업 | ⏱️ 소요 시간 | ✨ CREDEAL 솔루션 |
|---|---|---|
| 정부24·세움터 접속해서 건축물대장·등기부 확인 | 30분~1시간 | **자동 공공데이터 연동** (주소 입력만으로 제원 자동 수집) |
| 엑셀로 렌트롤 정리하고 Cap Rate 수기 계산 | 1~2시간 | **결정론적 재무 엔진** (오류율 0%) |
| 파워포인트로 투자설명서(IM) 작성 | 3~5시간 | **1분 자동 생성** (300x 속도 향상) |
| 매수자·건물주·기관에 각각 다른 버전 작성 | 추가 2시간 | **5대 포스처별 자동 최적화 템플릿** |
| 매도인 주소 노출 걱정에 전전긍긍 | 상시 스트레스 | **3단계 정보 공개 게이트** (블라인드 → NDA → 전체) |
| "이 가격이 적정한가?" 스스로 확신 못함 | 정량화 불가 | **2대 감정평가 자동 산출** (사례비교법 + 수익환원법) |

### CREDEAL이 제공하는 핵심 가치

```
하루에 IM 5건 만들던 것 → 50건 가능
```

> [!TIP]
> **킬러 피처**: 카카오톡에 붙여놓은 매물 메모를 그대로 복사해서 붙이면, 1분 안에 투자설명서가 완성됩니다. 건축물대장도, 재무 계산도, 지적도도 전부 자동입니다.

## 2. 3분 퀵스타트 — 첫 딜카드 만들기

### Step 1: 카톡 메모 복사

카카오톡 단톡방에서 받은 매물 메모를 복사합니다:

```
성수동 000-00, 80억대 근생, 1층 A카페 월세 800,
2층 B사 월세 500, 대지 120평, 연면적 380평,
2019년 준공, 주차 6대, 엘리베이터 1기
```

### Step 2: 딜카드 생성

1. `/broker/deal-card/new` 접속
2. 복사한 메모를 입력창에 붙여넣기
3. **"딜카드 생성"** 버튼 클릭

### Step 3: 1분 후 결과 확인

시스템이 자동으로 수행하는 작업:

```
📋 메모 파싱 (AI가 구조화)
     ↓
🏢 공공데이터 보강 (건축물대장·지적도·공시지가 자동 수집)
     ↓
💰 재무 분석 (NOI·Cap Rate·실투자금 자동 계산)
     ↓
📊 투자설명서 자동 생성 (Basic IM)
     ↓
✅ 품질 검증 (9대 자동 게이트 통과)
```

> [!NOTE]
> 메모가 불완전해도 괜찮습니다. 주소만 있으면 나머지는 공공데이터에서 자동 보강합니다.

## 3. 핵심 워크플로우 6선

### 워크플로우 A: 카톡 매물 → 1분 딜카드

**용도**: 매일 들어오는 매물 메모를 빠르게 정리할 때

```
카톡 메모 복사 → /broker/deal-card/new → 붙여넣기 → 생성
```

**결과물**: 구조화된 딜카드 (재무 요약, 제원표, 등급 평가)

---

### 워크플로우 B: 딜카드 → 모바일 IM 공유

**용도**: 개인 자산가 매수 후보에게 빠르게 물건 소개할 때

```
딜카드 → "모바일 IM 생성" → 링크 복사 → 카톡으로 전송
```

**결과물**: 반응형 모바일 투자설명서 (카톡에서 바로 열림)

---

### 워크플로우 C: 딜카드 → PPTX Studio → 기관 IM

**용도**: 법인/기관 매수자에게 프로페셔널한 IM을 보낼 때

```
딜카드 → PPTX Studio → 테마 선택 → 편집 → S60 승인 → S70 릴리즈 → 다운로드
```

**결과물**: 16면 고품질 PPTX 투자설명서 (266 DPI 고해상도)

---

### 워크플로우 D: 바이어 의향 등록 → 매칭

**용도**: "50~80억, 강남, 사옥 겸 임대수익" 같은 매수 의향을 등록하고 자동 매칭

```
/broker/buyer-intents/new → 바이어 정보 입력 → AI 자동 매칭 → 적합 매물 추천
```

---

### 워크플로우 E: 건물주 리포트 생성

**용도**: 매도인(건물주)에게 전문적인 보고서를 제공하여 신뢰 구축

```
딜카드 → "건물주 리포트 생성" → 열람 이력·매수자 반응 포함 리포트 전달
```

---

### 워크플로우 F: "이 건물, 딜 될까?" (공개 서비스)

**용도**: 건물주/일반인이 자기 건물의 매각 가능성을 스스로 확인

```
/building-radar → 주소 입력 → AI 분석 결과 (권역, 거래 동향, 예상 가격대)
```

## 5. 모바일 IM 뷰어 — 투자설명서를 링크 하나로

### 모바일 IM이란?

카카오톡으로 보낼 수 있는 **모바일 최적화 웹 투자설명서**입니다.

### 핵심 특징

| 항목 | 설명 |
|---|---|
| **반응형** | iPhone 14 Pro(393px) ~ Galaxy S23(360px) ~ 데스크톱(1920px) 자동 최적화 |
| **단계별 공개** | Basic(가격대+권역) → Pro(정확한 주소+임차인) 단계적 정보 오픈 |
| **재무 자동 계산** | NOI, Cap Rate, 실투자금 결정론적 산출 (수기 계산 오류 0%) |
| **지적도 포함** | V-World 연동 지적도 자동 임베딩 |
| **공유 링크** | 고유 URL 생성, 열람 추적 가능 |

### Basic IM vs Pro IM 비교

| 정보 | Basic IM | Pro IM (NDA 후) |
|---|---|---|
| 매물 권역 | ✅ "강남 역세권" | ✅ "강남 역세권" |
| 가격대 | ✅ "50~100억대" | ✅ **정확한 금액** |
| 주소 | ❌ 비공개 | ✅ **정확한 주소** |
| 임차인 이름 | ❌ 비공개 | ✅ **전체 공개** |
| 단위 임대료 | ❌ 비공개 | ✅ **전체 공개** |
| 지도 위치 | ⚡ 대략적 (~150m 오프셋) | ✅ **정확한 위치** |

> [!IMPORTANT]
> **블라인드 보호**: Basic IM에서는 매도인의 정확한 주소와 임차인 정보가 완전히 보호됩니다. 매수자가 NDA에 서명해야만 Pro IM을 열람할 수 있습니다.

## 6. PPTX Studio — 기관급 투자설명서 5분 완성

### 6.1 PPTX Studio란?

법인·기관 매수자에게 보내는 **16면 프로페셔널 투자설명서(IM)**를 자동 생성하고, 인라인 편집할 수 있는 스튜디오입니다.

### 6.2 원클릭 자동 생성

1. 딜카드에서 **"PPTX Studio"** 클릭
2. 테마 선택 (5종 중 택 1)
3. **"원클릭 생성"** 버튼 → 16면 IM 자동 완성

### 6.3 자동 생성되는 슬라이드 구성

| 순서 | 슬라이드 | 내용 |
|---|---|---|
| 1 | 표지 | 건물명, 가격, 권역, 브로커 로고 |
| 2 | 투자 요약 | 핵심 지표 카드 (Cap Rate, NOI, 실투자금) |
| 3 | 물건 개요 | 3-Tier 제원표 (대상지·토지·건물) |
| 4-5 | 입지 분석 | 광역 교통 벡터맵 + 주변 인프라 |
| 6-7 | 임대 현황 | 렌트롤 다단 표 + 스태킹 플랜 |
| 8-9 | 가격 근거 | 사례비교법 + 수익환원법 2대 평가 |
| 10-11 | 투자 구조 | LTV, 대출 시뮬레이션, 자본수익률 |
| 12-13 | 건물 사진 | 외관·내부·로비 갤러리 |
| 14 | 배후 수요 | 주변 상권·업무지구 분석 |
| 15 | 밸류애드 기회 | 공실 정상화, 리모델링 잠재력 |
| 16 | 거래 절차 | LOI → 실사 → 본계약 안내 |
| 부록 | 지적도·상권 분석 | 16면 상한 별도 |

### 6.4 인라인 편집 기능

- **슬라이드 순서 변경**: 드래그 앤 드롭
- **슬라이드 숨김/표시**: 토글 스위치
- **텍스트 편집**: 클릭하여 직접 수정
- **이미지 교체**: 클릭하여 사진 업로드
- **실시간 프리뷰**: SVG 캔버스 100ms 이내 반영

### 6.5 5대 테마 프리셋

매물 유형에 맞는 최적 테마를 선택하세요:

| 테마 | 분위기 | 추천 매물 |
|---|---|---|
| 🌑 **딥 슬레이트** | 고급 기관급 (차콜+골드) | 강남 대형 수익형 빌딩 |
| 🖤 **다크 골드** | 인스티튜셔널 프리미엄 | 기관투자자 대상 코어 자산 |
| ⬜ **클린 화이트** | 깔끔한 기업형 | 사옥 용도 매물 |
| 🟦 **비주얼 그리드** | 시각적 다채로움 | 메디컬/근생/리테일 |
| 📐 **테크니컬 블루프린트** | 기술적 정밀함 | 개발부지/신축 프로젝트 |

> [!TIP]
> **실전 팁**: 수익형 매물은 **딥 슬레이트** 또는 **다크 골드**가, 사옥형은 **클린 화이트**가, 개발형은 **블루프린트**가 가장 효과적입니다.

## 7. 바이어 매칭 — AI가 적합 매수자를 찾아줍니다

### 7.1 작동 방식

1. **바이어 의향 등록**: `/broker/buyer-intents/new`에서 매수자 정보 입력
   ```
   예: "김대표, 50~80억, 성수나 강남, 사옥 겸 임대수익 원함"
   ```

2. **AI 자동 매칭**: 등록된 매물과 바이어 의향을 자동 비교
   - 예산 범위 매칭
   - 선호 권역 매칭
   - 투자 목적 매칭 (수익형/사옥형/개발형)
   - Cap Rate 선호도 매칭

3. **매칭 결과 확인**: 적합도 순으로 정렬된 매칭 리스트

### 7.2 매칭에 활용되는 7대 지표

| 지표 | 설명 |
|---|---|
| 매매가 | 바이어 예산 범위 내 여부 |
| 권역 | 선호 지역 일치도 |
| 용도 | 수익형/사옥형/개발형 |
| 연면적 | 규모 요건 충족 |
| Cap Rate | 수익률 기대치 |
| 공실률 | 밸류애드 기회 선호 |
| 준공연도 | 건물 노후도 선호 |

## 8. 건물주 리포트 — 매도인 신뢰 구축

### 왜 건물주 리포트가 중요한가?

매물을 맡긴 건물주(매도인)에게 **"당신의 물건이 전문적으로 관리되고 있다"**는 것을 입증하는 것은 중개인의 핵심 역량입니다.

### 리포트에 포함되는 정보

| 섹션 | 내용 |
|---|---|
| 열람 현황 | 몇 명이 투자설명서를 열람했는지 |
| 관심 표명 | NDA 서명/관심 표현한 매수자 수 |
| 공유 활동 | 딜카드 공유 링크 클릭 현황 |
| 시장 동향 | 해당 권역 최근 거래 사례 및 트렌드 |
| 가격 분석 | 사례비교법 기반 적정 가격대 피드백 |

> [!TIP]
> **실전 팁**: 건물주 리포트를 2주에 1회 정도 전달하면 매물 독점 계약 갱신에 큰 도움이 됩니다. 시스템이 자동으로 데이터를 집계하므로 추가 수작업이 거의 없습니다.

## 9. 정보 공개 게이트 — 단계별로 안전하게

### 3단계 게이트 시스템

CREDEAL은 매물 정보를 **3단계로 점진적으로 공개**하여, 매도인의 프라이버시를 보호하면서도 매수자에게 충분한 정보를 제공합니다.

```
🔒 G1: 블라인드 티저
    │  (권역 + 가격대만 공개)
    ▼
🔑 G2: Basic IM
    │  (건축 제원 + 재무 요약 / 주소·임차인 비공개)
    ▼
📋 G3: Pro IM (NDA 서명 후)
    │  (정확한 주소 + 임차인 + 단위 임대료 전체 공개)
    ▼
✅ PPTX Studio (승인 후 다운로드)
```

### 각 단계별 공개 범위

| 정보 | G1 티저 | G2 Basic | G3 Pro (NDA) |
|---|---|---|---|
| 권역 (예: "강남 역세권") | ✅ | ✅ | ✅ |
| 가격대 (예: "50~100억대") | ✅ | ✅ | ✅ (정확 금액) |
| 건축 제원 | ❌ | ✅ | ✅ |
| 렌트롤 합계 | ❌ | ✅ | ✅ (상세) |
| Cap Rate | ❌ | ✅ | ✅ |
| 정확한 주소 | ❌ | ❌ | ✅ |
| 임차인 이름 | ❌ | ❌ | ✅ |
| 단위 임대료 | ❌ | ❌ | ✅ |
| 지도 위치 | ❌ | ⚡ (~150m) | ✅ (정확) |

> [!IMPORTANT]
> **K-익명성 보호**: Basic IM의 지도는 실제 위치에서 약 150m 오프셋을 적용합니다. 강남/서초/성동 지역은 K=30 (같은 반경 내 30개 이상의 건물이 있어야 함), 기타 지역은 K=20을 보장합니다.

## 10. 5가지 매물 유형별 최적 활용법

### 10.1 수익형 매물 (income)

**특징**: Cap Rate, NOI, WALE이 핵심인 임대 수익 중심 물건

**최적 활용법**:
- 테마: **딥 슬레이트** 또는 **다크 골드**
- 중점 슬라이드: 렌트롤 다단 표, 스태킹 플랜, Cap Rate 비교
- 자동 산출: 정규화 NOI, 사례비교법/수익환원법 듀얼 평가
- 밸류애드: 공실 정상화 Pro-forma 시나리오 자동 포함

```
✅ 추천 CTA 순서: 카톡 문구 → 모바일 IM → PPTX Studio (기관)
```

### 10.2 사옥형 매물 (owner_occupied)

**특징**: 기업이 자가 사용 목적으로 매입하는 물건

**최적 활용법**:
- 테마: **클린 화이트**
- 중점 슬라이드: 총취득원가, 임대 vs 매입(vsLease) 비교, 간판 설치권
- 특화 기능: 사옥 전용 4대 슬라이드 자동 바인딩
- 참고: Gross Yield 비필수 (승인 게이트에서 제외)

```
✅ 추천 CTA 순서: PPTX Studio (법인) → 건물주 리포트
```

### 10.3 개발형 매물 (development)

**특징**: 신축·리모델링·용도변경 잠재력이 있는 토지/노후 건물

**최적 활용법**:
- 테마: **테크니컬 블루프린트**
- 중점 슬라이드: 다필지 대지면적, 3단 투입비(토지+시공+PF), 조례 완화 분석
- 특화 기능: 용적률 기존/법정 비교, 개발부지 부록 분리
- 참고: Cap Rate 대신 PF/시공비가 핵심 지표

```
✅ 추천 CTA 순서: PPTX Studio (개발사) → 전문가 코멘트 요청 (법률/인허가)
```

### 10.4 매매형 매물 (trading)

**특징**: 단순 매매 차익 중심, 거래 빈도가 높은 물건

**최적 활용법**:
- 테마: **딥 슬레이트**
- 중점 슬라이드: 사례비교법 평당가 밴드, 거래 이력, 시세 추이
- 특화 기능: 인근 실거래 3~5건 자동 벤치마킹

```
✅ 추천 CTA 순서: 카톡 문구 → 모바일 IM → 매수자 매칭
```

### 10.5 운영형 매물 (operating)

**특징**: 호텔, 의료시설, 교육시설 등 운영 수익이 핵심인 물건

**최적 활용법**:
- 테마: **비주얼 그리드**
- 중점 슬라이드: GOP(영업이익), RevPAR(객실당 수익), 가동률, 층별 업종 MD
- 특화 기능: 앵커 테넌트(약국/병원), 유동인구 입지 분석

```
✅ 추천 CTA 순서: PPTX Studio (운영사) → 건물주 리포트
```

## 13. 2단계 승인 프로세스 — 전문가답게

### 왜 2단계 승인이 필요한가?

기관급 투자설명서는 한번 발행되면 법적 책임이 따릅니다. CREDEAL은 **발행 전 2단계 검증**으로 오류와 리스크를 사전 차단합니다.

### 승인 흐름

```
Step 1: S60 — 에디토리얼 승인
    │  (내용 검토: 재무 수치, 제원, 텍스트 정확성)
    │  브로커가 슬라이드 내용을 확인하고 "내용 승인" 클릭
    ▼
Step 2: S70 — 바이너리 릴리즈
    │  (파일 무결성: SHA-256 해시 바인딩)
    │  시스템이 PPTX 파일의 해시를 생성하고 불변 원장에 기록
    ▼
✅ PUBLISHED — 다운로드 가능
    │  (불변 이벤트 로그에 기록됨)
```

### 승인 후 수정 시

> [!WARNING]
> 승인 후 1글자라도 수정하면 SHA-256 해시가 변경되어 즉시 **STALE(무효)** 상태로 전환됩니다. 수정된 내용으로 S60→S70 재승인이 필요합니다. 이는 문서 무결성을 보장하기 위한 장치입니다.

## 16. 자주 묻는 질문 (FAQ)

### Q1. 카톡 메모가 매우 짧아도 되나요?

**네.** 주소만 있으면 됩니다. 나머지 정보(건축 제원, 지적도, 공시지가 등)는 공공데이터에서 자동으로 수집합니다. 물론 메모에 임대료, 층별 정보가 포함되어 있으면 더 풍부한 IM이 생성됩니다.

### Q2. 매도인이 주소 노출을 걱정합니다. 어떻게 하나요?

CREDEAL은 **3단계 정보 공개 게이트**를 제공합니다. Basic IM에서는 주소가 완전히 비공개이고, 지도도 약 150m 오프셋 처리됩니다. 정확한 주소는 매수자가 NDA에 서명한 후에만 공개됩니다.

### Q3. 재무 계산이 정확한가요?

**모든 재무 계산은 결정론적 중앙 엔진**을 통해 수행됩니다. AI가 수치를 생성하는 것이 아니라, 확정된 입력값에서 수학적으로 정확하게 산출합니다. Cap Rate, NOI, 실투자금 등의 계산 공식은 감정평가 업계 표준을 따릅니다.

### Q4. 생성된 IM을 수정할 수 있나요?

**네.** PPTX Studio에서 텍스트, 이미지, 슬라이드 순서를 자유롭게 편집할 수 있습니다. 다만, 수정 후에는 S60→S70 재승인이 필요합니다.

### Q5. 오프라인에서도 사용할 수 있나요?

PPTX 파일을 다운로드하면 오프라인에서 마이크로소프트 파워포인트로 열어 사용할 수 있습니다. 단, IM 생성과 편집은 온라인 환경이 필요합니다.

### Q6. 한 건물에 여러 버전의 IM을 만들 수 있나요?

**네.** 같은 딜카드에서 다른 테마·포스처로 여러 PPTX를 생성할 수 있습니다. 예를 들어, 수익형 관점의 기관용 IM과 사옥 관점의 기업용 IM을 각각 만들 수 있습니다.

### Q7. 다필지(여러 필지) 물건도 처리되나요?

**네.** 복수 PNU(필지번호) 입력을 지원합니다. 각 필지의 대지면적이 자동 합산되고, 대표 필지를 기준으로 건축 제원이 통합됩니다.

### Q8. 공동중개 시에도 사용할 수 있나요?

**네.** 공유 링크를 통해 다른 중개인과 매물 정보를 공유할 수 있습니다. 정보 공개 레벨은 공유 시점의 게이트 레벨을 따릅니다.

## 18. 부록: 용어 사전

| 용어 | 설명 |
|---|---|
| **IM** | Investment Memorandum (투자설명서). 매물의 재무·물리·법률 정보를 종합한 세일즈 문서 |
| **딜카드** | 매물 정보를 구조화한 디지털 카드. IM의 기반 데이터 |
| **Cap Rate** | Capitalization Rate (자본환원율). NOI ÷ 매매가. 수익형 부동산의 핵심 수익률 지표 |
| **NOI** | Net Operating Income (순영업소득). 총 임대수입 − 운영비용 |
| **WALE** | Weighted Average Lease Expiry (가중평균 잔여 임대기간) |
| **LTV** | Loan to Value (담보인정비율). 대출금액 ÷ 자산가치 |
| **SSoT** | Single Source of Truth (단일 진실 원천). 모든 데이터의 기준이 되는 원본 |
| **포스처** | 투자 유형 분류 (수익형, 사옥형, 개발형, 매매형, 운영형) |
| **NDA** | Non-Disclosure Agreement (비밀유지협약). Pro IM 열람 전 서명 필수 |
| **PNU** | Parcel Number Unit (필지번호). 토지의 고유 식별번호 |
| **사례비교법** | 인근 유사 거래 사례를 비교하여 적정 가격을 산출하는 감정평가 방법 |
| **수익환원법** | NOI를 시장 Cap Rate로 나누어 적정 자산가치를 산출하는 방법 |
| **스태킹 플랜** | 건물의 층별 임대 현황을 시각화한 단면도 |
| **S60/S70** | 승인 단계. S60은 내용 승인, S70은 파일 무결성 승인 |
| **게이트** | 정보 공개 단계 (G1: 블라인드, G2: Basic, G3: Pro) |
| **밸류애드** | 공실 정상화, 리모델링 등을 통해 자산 가치를 높이는 전략 |
| **Pro-forma** | 공실을 만실로 정상화했을 때의 가정 재무 시나리오 |
| **K-익명성** | 위치 퍼지 시 같은 반경 내 최소 K개의 건물이 있어야 하는 프라이버시 기준 |
| **GOP** | Gross Operating Profit (총영업이익). 운영형 자산의 핵심 지표 |
| **RevPAR** | Revenue Per Available Room (이용 가능 객실당 수익). 호텔 운영 지표 |
