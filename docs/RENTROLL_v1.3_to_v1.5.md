### 2.3 수식 전후 (13행 기준, 13~112행 동일 패턴)

```text
# v1.5 신규
AE13 = IF(OR($A13="",C13=""),"",ROUND(C13*IF($G$9="평",3.305785,1),2))
AF13 = IF(OR($A13="",D13=""),"",ROUND(D13*IF($G$9="평",3.305785,1),2))

# Q·R  (v1.3/v1.4 → v1.5)
Q13  v1.3: IF(OR($A13="",C13=""),"",C13/3.305785)
     v1.5: IF(OR($A13="",C13=""),"",AE13/3.305785)
R13  v1.3: IF(OR($A13="",D13=""),"",D13/3.305785)
     v1.5: IF(OR($A13="",D13=""),"",AF13/3.305785)

# Y 전용평당 월비용
Y13  v1.3: IF(OR($A13="",O13<>"임대중",D13="",H13=""),"",
              ROUND((H13+IF(I13="",0,I13))/(D13/3.305785),0))
     v1.5: IF(OR($A13="",O13<>"임대중",H13=""),"",
              IF(B13="",
                 IF(D13="","",ROUND((H13+IF(I13="",0,I13))/(AF13/3.305785),0)),
                 IF(COUNTIFS($B$13:$B$112,B13,$D$13:$D$112,"")>0,"",
                    ROUND((H13+IF(I13="",0,I13))/(SUMIFS($AF$13:$AF$112,$B$13:$B$112,B13)/3.305785),0))))

# AC 만기 구간 (v1.4 신규)
AC13 = IF($A13="","",IF(O13="공실","공실",IF(O13="자가사용","자가사용",IF(L13="","만료일 없음",
         IF(L13<$C$6,"만료 경과",IF(L13<=EDATE($C$6,12),"12개월 내","12개월 초과"))))))

# AD 금액 판정 (v1.4 신규)
AD13 = IF(OR($A13="",O13<>"임대중"),"",
         IF(B13="",
            IF(H13="","월세 누락",IF(I13="","관리비 누락","OK")),
            IF(COUNTIFS($B$13:$B$112,B13,$H$13:$H$112,"<>")>1,"금액 중복",
            IF(COUNTIFS($B$13:$B$112,B13,$H$13:$H$112,"<>")=0,"월세 누락",
            IF(COUNTIFS($B$13:$B$112,B13,$I$13:$I$112,"<>")=0,"관리비 누락","OK")))))
```

`S`(전용률)·`S10`(가중 전용률)은 C·D의 **비율**이라 v1.5에서도 C·D를 그대로 씁니다. 단위가 같으면 결과가 같습니다.

### 2.4 통합계약(계약그룹) 규칙 — v1.4에서 명확해짐

- 같은 계약서로 여러 호실을 쓰면 해당 행들의 `B`에 같은 그룹명을 적는다.
- **보증금·월세·관리비(G·H·I)는 그룹 중 대표 행 1개에만** 적고 나머지 행은 비운다.
- 면적·호실·업종·임대상태·만료일·적용법령·최초 계약일·대항력·근거는 **행마다** 적는다.
- 그룹 판정은 `AD`열: 금액 행이 0개면 `월세 누락`, 2개 이상이면 `금액 중복`.
- v1.3에서는 R1 판정이 "임대중인 **모든 행**에 월세"를 요구해, 비대표 행 때문에 통합계약 렌트롤이 **R0 미달**로 잘못 판정됐다. v1.4부터는 `AD`열(계약 단위)로 판정한다.

## 6. 파서 계약 (구현 지침)

### 6.1 버전 판별

```ts
type RentrollVersion = '1.3' | '1.4' | '1.5' | 'unknown';

function detectVersion(ws): RentrollVersion {
  const title = String(ws['A1'] ?? '');
  const m = title.match(/v(1\.\d)/);
  if (m) return m[1] as RentrollVersion;
  // 제목이 지워진 경우 보조 판별
  if (String(ws['AE12'] ?? '').startsWith('임대면적(㎡')) return '1.5';
  if (String(ws['AD12'] ?? '').startsWith('금액 판정')) return '1.4';
  return 'unknown'; // 1.3과 동일하게 처리하되 경고
}
```

### 6.2 열 찾기 — 위치 우선, 머리글은 접두어로 검증

- v1.5에서 `C12`·`D12`는 수식이다. 캐시값은 `임대면적(㎡)` 또는 `임대면적(평)`이고, 계산되지 않은 파일에서는 수식 문자열이 그대로 보일 수 있다.
- **열은 고정 위치(A~AF)로 읽고**, 머리글은 검증용으로만 `startsWith('임대면적(')` · `startsWith('전용면적(')`처럼 **접두어**로 비교한다. `=== '임대면적(㎡)'` 완전 일치는 금지.

### 6.3 면적 정규화 — 직접 환산하고 AE·AF는 대조용

수식 캐시값이 없는 파일(수식을 계산하지 않는 도구로 저장된 파일)이 있을 수 있으므로, **파서가 같은 규칙으로 직접 환산**하고 AE·AF 캐시값이 있으면 대조한다.

```ts
const PYEONG_TO_SQM = 3.305785;

function readAreaUnit(ws, version): 'sqm' | 'pyeong' {
  if (version !== '1.5') return 'sqm';            // v1.3·v1.4는 항상 ㎡
  const v = String(ws['G9'] ?? '').trim();
  if (v === '평') return 'pyeong';
  if (v === '㎡' || v === '') return 'sqm';        // 빈 값 = 기본 ㎡ (경고 기록)
  throw new ParseWarning(`알 수 없는 면적 단위: ${v}`);
}

function toSqm(raw: number | null, unit): number | null {
  if (raw == null || raw === '') return null;
  const sqm = unit === 'pyeong' ? raw * PYEONG_TO_SQM : raw;
  return Math.round(sqm * 100) / 100;              // 엑셀 ROUND(…,2)와 동일
}

// 행마다
row.area_sqm           = toSqm(C, unit);
row.exclusive_area_sqm = toSqm(D, unit);
// 대조: AE·AF 캐시값이 있으면 |파서값 − 캐시값| > 0.01 → 경고
```

`gfa_sqm`(J4)은 **환산하지 않는다**(항상 ㎡).

### 6.4 판정 로직 갱신 (`resolveLedger()` 등)

1. **평가 기준일** = `C5`(렌트롤 기준일), 비면 오늘. v1.3처럼 무조건 오늘을 쓰지 않는다.
2. **R1:** 임대중 행 전부에 업종·만료일, **계약 단위**(그룹은 대표 행 1개)로 월세 존재, 그룹마다 금액 행 정확히 1개.
3. **R2:** R1 + 전 행 임대면적·적용법령 + 계약 단위 관리비.
4. **R3:** R2 + 임대중 행 전부(비대표 행 포함) 최초 계약일·대항력, 대항력 `미확인` 불가.
5. **NOC(전용평당 월비용):** 그룹이면 `(월세+관리비) ÷ (그룹 전용면적 합 ㎡ ÷ 3.305785)`. 그룹 중 전용면적 빈 행이 있으면 보류.
6. **면적 대조(V03):** `Σarea_sqm ÷ gfa_sqm`.
7. **단위 혼동(V12) — 발행 차단:** `Σarea_sqm ÷ gfa_sqm > 2` 또는 `< 0.45`면 `AREA_UNIT_MISMATCH`를 **차단(blocking) 이슈**로 낸다. `gfa_sqm`이 없거나 면적 합이 0이면 판정 보류(차단 아님, 경고).
   - **해제(override):** 일부 층·구분소유 매각처럼 비율이 정상적으로 낮은 경우가 있으므로, 중개인이 사유(`override_reason`, 필수 텍스트)를 적으면 해제한다. 해제 기록(사유·해제자·시각)은 업로드 로그에 남긴다.
   - 시스템이 단위를 바꿔 다시 계산해 주는 자동 보정은 하지 않는다. 중개인이 G9 또는 숫자를 고쳐 다시 올리거나, 사유를 적어 해제하는 두 길만 둔다.

   ```ts
   function checkAreaUnit(rows, gfaSqm): Issue | null {
     const sum = rows.reduce((a, r) => a + (r.area_sqm ?? 0), 0);
     if (!gfaSqm || sum === 0) return { code: 'AREA_UNIT_UNCHECKED', level: 'warning' };
     const ratio = sum / gfaSqm;
     if (ratio > 2 || ratio < 0.45)
       return { code: 'AREA_UNIT_MISMATCH', level: 'blocking', ratio, overridable: true };
     return null;
   }
   ```

### 6.5 v1.3 파일이 들어오면

- 그대로 받는다. 면적은 ㎡, 새 필드는 모두 `null`.
- 통합계약이 있는 v1.3 파일은 **v1.4 규칙으로 재판정**한다(v1.3 엑셀 안의 판정 결과를 믿지 않는다).

## 8. 하면 안 되는 것

- **C·D열 값을 무조건 ㎡로 가정하지 않는다.** v1.5에서는 G9를 먼저 읽는다.
- **J4(연면적)를 G9에 따라 환산하지 않는다.** 항상 ㎡.
- **시장 임대료 J5:J7(원/전용평)을 환산하지 않는다.** 면적 단위와 무관.
- **머리글 완전 일치로 열을 찾지 않는다** (C12·D12는 수식).
- **엑셀 안의 판정·계산 캐시값을 정본으로 쓰지 않는다.** 시스템은 같은 규칙으로 재계산하고, 캐시값은 대조용으로만 쓴다.
- **단위를 추측해 자동 보정하지 않는다.** V12에 걸리면 발행을 막고 중개인이 고치거나 사유를 적어 해제하게 한다(평↔㎡ 자동 전환 금지).
- **IM에서 면적 단위를 임의로 바꾸지 않는다.** `area_input_unit`이 평이면 평으로, ㎡이면 ㎡로 표기한다.
- 통합계약 비대표 행의 빈 금액을 `0원`으로 저장하지 않는다 — 그룹 대표 행 금액을 계약 1건으로 취급한다.

### 9.1 IM 표기 규칙 (결정 4)

- 계산은 항상 ㎡ 정본(`area_sqm`, `exclusive_area_sqm`)으로 한다. 표기만 입력 단위로 바꾼다.
- `area_input_unit = 'pyeong'`이면 렌트롤 표 머리글은 `임대면적(평)` · `전용면적(평)`, 값은 `area_sqm ÷ 3.305785`(소수 2자리)를 쓴다. 중개인이 적은 원래 숫자와 같아진다.
- `area_input_unit = 'sqm'`이면 머리글 `임대면적(㎡)` · `전용면적(㎡)`, 값은 `area_sqm`.
- 합계 행도 같은 단위로 표기한다.
- 전용평당 임대료·토지평당가처럼 **원래 평 기준인 지표**는 입력 단위와 상관없이 평 기준을 유지한다.
- 연면적·대지면적 등 공부 값은 IM 물건 개요에서 기존처럼 `㎡ (평)` 병기를 유지한다(렌트롤 입력 단위와 무관).
