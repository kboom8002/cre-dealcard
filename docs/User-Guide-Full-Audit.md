# 🏢 DealCard (크리딜) 종합 사용 가이드

**중개인을 위한 AI 상업용 부동산 솔루션, DealCard(크리딜)에 오신 것을 환영합니다!** 
이 문서는 크리딜의 핵심 기능부터 고급 AI 기능까지 100% 활용할 수 있도록 돕기 위해 작성되었습니다.

---

## 1. 🚀 시작하기 (Getting Started)

### 앱 개요
* **서비스명**: DealCard (크리딜)
* **슬로건**: 중개인을 위한 AI 상업용 부동산 솔루션
* **플랫폼**: 모바일 최적화 웹 앱 (데스크톱에서도 사용 가능)
* **테마**: 다크 모드 (기본), 라이트 모드 지원
* **URL**: [credeal.net](https://credeal.net)

### 회원가입 및 로그인
1. `credeal.net/login` 또는 `/signup`으로 이동합니다.
2. 이메일과 비밀번호를 입력하여 로그인합니다. ('이메일 기억하기' 체크박스 지원)
3. 로그인 성공 시 브로커 대시보드(`/broker`)로 자동 이동합니다.

> [!TIP]
> **알파 테스트 기간 안내**
> 알파 기간 중 가입하신 미배정 사용자는 로그인 시 자동으로 '브로커(broker)' 역할이 부여되어 모든 기능을 바로 체험하실 수 있습니다.

> [!WARNING]
> **접근 권한 오류**
> "인증이 필요합니다"라는 메시지(401 에러)가 뜬다면, 로그인 세션이 만료되었거나 보안 페이지에 직접 접근을 시도한 것입니다. 다시 로그인해 주세요.

### 온보딩 및 AI 바이브 명함
신규 브로커는 가입 직후 대화형 AI 오케스트레이터를 통한 온보딩(`/onboarding`)을 거치게 됩니다.
1. 전문성 있는 프로필 사진 1장을 업로드합니다.
2. AI가 자동으로 데이터 기반 신뢰 프로필인 **'바이브 AI 명함'**을 생성합니다.
*(관리자나 이미 브로커 역할이 있는 사용자는 이 단계를 건너뜁니다.)*

## 2. 📊 대시보드 활용법 (코크핏)

로그인 후 처음 만나는 대시보드(`/broker`)는 중개인의 '코크핏(조종석)'입니다. 15개의 복잡한 데이터가 백그라운드에서 병렬 처리되어 핵심 정보만 직관적으로 보여줍니다.

* **인사말 & 프로필**: "안녕하세요, {이름}님" 문구와 프로필 사진이 상단에 표시됩니다.
* **주요 KPI 카드**: 총 건물 수, 임대 공간, 매수자, 임차인, 고객 수 및 S/A급 매칭 건수를 한눈에 확인합니다.
* **ROI 카드**: 이번 달 예상되는 투자 수익률을 추적합니다.
* **시장 대응 전략**: AI가 분석한 현재 시장의 수요/공급 점수, 추세 방향, 가격 저항대 정보를 제공합니다.
* **주간/월간 리포트**: 기간별 활동 성과를 요약해 줍니다.
* **모닝 인텔리전스**: 매일 아침 브로커를 위해 요약된 일일 시장 브리핑입니다.
* **오늘의 일정**: 예정된 임장 및 미팅 스케줄을 시간순으로 보여줍니다.
* **통합 메모 FAB (플로팅 버튼)**: 화면 우측 하단에 떠 있는 버튼으로, 언제든 클릭해 메모를 남길 수 있습니다. AI가 메모 내용을 매매 딜카드, 임대 딜카드, 일반 문의 등으로 자동 분류합니다.

## 3. ⚡ 딜카드 생성 가이드

가장 핵심 기능인 **'1분 딜카드 만들기'**(`/broker/deal-card/new`)는 카카오톡에 대충 적어둔 메모만으로 정형화된 블라인드 티저를 생성합니다.

### 📝 Step-by-Step 생성 방법
1. 대시보드에서 **"1분 딜카드 만들기"** 버튼을 클릭합니다.
2. 매물에 대한 **카카오톡 메모를 복사해서 붙여넣습니다.** (테스트해보고 싶다면 "샘플 사용"을 클릭하세요.)
3. (선택사항) 현장 사진이 있다면 가로 스크롤 영역에 업로드합니다.
4. **'제출'** 버튼을 클릭합니다.
5. 화면에 프로그레시브 로딩 애니메이션이 나타납니다.
   *(메모 분석 중 → 기본 신호 생성 → 민감정보 블라인드 → 카카오 문구 생성)*
6. 생성이 완료되면 성공 화면이 나타나며, 카드를 확인/공유하거나 관련 일정을 즉시 추가할 수 있습니다.

> [!CAUTION]
> 메모 내용이 너무 짧거나(5자 미만) 핵심 정보(위치, 자산유형, 가격, 거래유형 등)가 부족할 경우 에러가 발생합니다. 화면의 안내에 따라 부족한 정보를 보충해 주세요.

> [!TIP]
> **자동 블라인드 처리 안내**
> 정확한 지번 주소, 임차인 상호명, 세부 임대료, 매도자의 민감한 개인 사정 등은 AI가 자동으로 인식하여 블라인드 처리합니다. 안심하고 텍스트를 붙여넣으세요.

### 🔎 딜카드 결과 페이지 활용 (`/broker/deal-card/[id]`)
* **상단 갤러리 & 헤더**: 생성된 블라인드 정보와 업로드한 사진을 스와이프하여 볼 수 있습니다.
* **건물 신호 요약**: 권역, 자산유형, 가격대, 현재 사용 용도, 적합한 매수자 타겟, 추가 확인 필요 사항이 카드 형태로 정리됩니다.
* **숨긴 정보 카드 (🔒)**: AI가 블라인드 처리한 원본 정보를 브로커만 확인할 수 있는 공간입니다.
* **인라인 에디터**: 생성된 딜카드의 내용을 직접 수정할 수 있습니다.
* **매칭 매수자**: 이 딜카드와 조건이 맞는 매수자 목록이 하단에 추천됩니다.
* **AI 딜 예측 & 페르소나**: 이 매물의 성사 확률 예측값과, 가장 이상적인 매수자 페르소나를 AI가 제시합니다.

## 4. 📱 투자설명서 (IM) 생성 가이드

가벼운 딜카드를 넘어, 진성 고객을 위한 **모바일 투자설명서(IM)**를 제작합니다.

### 🛠 모바일 IM 만들기
딜카드 결과 페이지 하단의 **"📱 투자설명서 만들기"** 버튼을 클릭하여 시작합니다.
바텀시트가 올라오며 상세 데이터를 입력하게 됩니다.

1. **주소 확정**: 주소를 검색하여 정확한 PNU(필지 고유번호)를 확정합니다.
2. **숫자 입력**: 매각가, 보증금, 관리비, 대출금 등을 입력합니다. 임대료 입력 시 Cap Rate(자본환원율)를 역산해 주는 계산기가 내장되어 있습니다.
3. **공실률**: 프리셋 버튼을 쓰거나 직접 입력합니다.
4. **사진 첨부**: 최대 12장(장당 최대 10MB)까지 업로드합니다.
5. **엑셀 렌트롤 임포트**: 엑셀 파일을 올리면 AI가 헤더를 탐지하고 단위를 변환하여 자동 입력합니다.
6. **(물류센터 전용)**: 물류센터의 경우 17개의 전용 상세 필드가 추가로 표시됩니다.
7. **게이지 확인**: 데이터 입력창 상단의 **충실도 게이지**가 40점을 넘어야(주황색/녹색) 생성이 가능합니다.

입력이 끝나고 생성 버튼을 누르면, 백그라운드에서 7개의 공공 API 데이터를 병렬로 수집하여 **AI가 7개의 IM 섹션을 자동 작성**합니다.

### ✅ IM 승인 워크플로 (`/broker/im-approval/[id]`)
생성 직후 승인 화면으로 이동합니다. 이곳에서 고객에게 발송하기 전 최종 검수를 진행합니다.
* 각 섹션의 내용을 마크다운으로 편집
* 카카오톡 등에 공유될 때 보일 **OG 메타데이터**(제목, 설명) 수정
* 최상단 Hero 영역 문구 수정 및 사진 순서/캡션 조정
* 특정 섹션을 **잠금(NDA 필요) 처리**하여 민감 정보 보호
* 검수 완료 후 **'승인'** 버튼을 누르면 상태가 변경되며 고유 링크가 발성됩니다.

### 👁‍🗨 공개 IM 뷰어 (`/im-lite/[buildingId]`)
고객이 링크를 클릭했을 때 보는 모바일 반응형 페이지입니다.
* 카카오 Static Map 기반 위치 지도
* 풀스크린을 지원하는 사진 라이트박스 갤러리
* **출처 배지 시스템**: 정보의 신뢰도를 나타내는 배지(✓공부확인 / 👤중개인입력 / ⚙AI추정)가 아코디언 카드마다 부착되어 있습니다.
* 투자 지표 요약(Hero Card) 및 DCF 히트맵, 가격 트렌드 차트 제공
* **Hot Lead Alert**: 고객이 IM을 열람하거나 바텀시트를 통해 문의를 남기면, 즉시 브로커의 카카오톡 알림톡으로 열람 사실이 통보됩니다.

## 5. 📰 매거진 활용법

잠재 고객과의 지속적인 접점을 만들기 위해 뉴스레터 형태의 **매거진**을 발행할 수 있습니다.

* **매거진 에디터** (`/broker/magazine-editor`):
  커버, 현장 노트, 테마&딜, 뉴스, AI 어시스트, 아웃리치, 발행 등 7개 탭으로 구성됩니다.
  * **시장 온도 설정**: 현재 시장 분위기(적극 매수, 관망 등)를 다이얼로 설정합니다.
  * **현장 노트**: 실제 현장에서 느낀 매도자/매수자의 반응을 기록합니다.
  * **뉴스 & 딜 쇼케이스**: 관련 뉴스 링크를 큐레이션하고, 추천할 딜카드를 첨부합니다.
  * **자동 저장**: 작성 중 날아가는 것을 방지하기 위해 30초마다 자동 저장됩니다.
* **매거진 뷰어** (`/magazine/[slug]`):
  발행된 매거진은 모바일에 최적화된 깔끔한 뷰어로 제공되며, 하단의 CTA를 통해 신규 고객의 구독을 유도할 수 있습니다.

## 6. 🤝 매수자 관리 및 매칭

매수자의 니즈를 꼼꼼히 관리하고 보유한 매물(딜카드)과 스마트하게 매칭합니다.

* **매수자 의향서 관리** (`/broker/buyer-intents`): 매수자가 원하는 예산, 지역, 용도 등의 요건을 등록합니다.
* **AI 매칭 시스템**: 등록된 의향서와 기존 딜카드를 분석하여 **S, A, B, C 등급으로 매칭 적합도**를 알려줍니다.
* **매수자 맞춤 메모**: AI가 해당 매물이 왜 이 매수자에게 적합한지(Fit), 어떤 점을 주의해야 하는지(Caution), 추가로 확인해야 할 사항은 무엇인지 브리핑 메모를 작성해 줍니다.
* **카카오톡 초안 생성**: 이 매물을 고객에게 제안하기 좋은 카카오톡 메시지 초안을 AI가 작성해주며, 모바일 프리뷰로 미리 확인할 수 있습니다.

## 7. 📅 일정 관리

* **일정 캘린더** (`/broker/schedule`): 임장, 미팅, 계약 등의 일정을 관리합니다. 'Hold(보류)'와 'Confirmed(확정)' 상태를 구분하여 관리할 수 있습니다.
* **AI 최적 시간 추천**: Schedule-advisor AI가 동선과 기존 스케줄을 분석해 최적의 미팅 시간을 추천해 줍니다.
* **알림 연동**: 확정된 일정은 고객과 브로커에게 카카오 알림톡으로 발송되어 노쇼를 방지합니다.

## 8. 🔗 공유 및 마케팅

크리딜의 모든 아웃풋(딜카드, 매거진, IM 등)은 외부 공유에 최적화되어 있습니다.

* **카카오톡 리치 공유**: 하단 고정 CTA 중 **'카톡으로 전송'** 버튼을 누르면, Kakao JS SDK를 통해 예쁜 썸네일과 설명이 포함된 리치링크 형태로 전송됩니다.
* **폴백(Fallback) 지원**: 카카오톡이 설치되어 있지 않거나 환경적인 이유로 SDK가 실패할 경우, 클립보드에 자동으로 URL이 복사되어 문자로 보낼 수 있습니다.
* **AI 카피라이팅**: 카카오톡으로 공유할 때 첨부되는 3~5줄 분량의 소개 문구를 AI가 매물/상황에 맞게 자동으로 작성하여 텍스트 상자에 채워줍니다.

## 9. 📋 건물주 매각 준비도 (Owner Readiness)

건물주(매도자) 미팅 시, 해당 건물이 매각 준비가 얼마나 되었는지 진단하고 설득하는 도구입니다.

* **진단 체크리스트** (`/owner-readiness`): 등기부등본, 도면, 렌트롤, 건축물대장, 세금신고서 등 필수 서류 10개 항목의 구비 여부를 체크합니다.
* **시각화 뷰어**: 0에서 100까지 차오르는 원형 게이지로 현재 준비 상태를 직관적으로 보여줍니다.
* **결과 판정**: 점수에 따라 "Teaser Ready(딜카드 제작 가능)" 또는 "Full IM Candidate(전체 투자설명서 제작 가능)"으로 판정합니다.
* **보안 핸드오프**: 100점 만점이 될 경우, 보안 토큰이 생성되며 외부의 고도화된 'Full IM Studio' 소프트웨어로 데이터를 즉시 연동할 수 있는 권한이 열립니다.

## 10. 💎 고급 기능

### ✨ 바이브 명함 (Vibe Card)
* **경로**: `/broker/vibe-card` (관리) / `/vibe-card/[slug]` (공개)
* AI가 브로커의 사진과 성향을 7가지 벡터(따뜻함, 에너지, 세련됨, 진정성, 전통, 미래지향, 위트)로 분석하여, 32개의 UI 템플릿 중 가장 잘 어울리는 명함 디자인을 자동 적용합니다.

### 🤖 AI 딜 예측 (로봇 이모지 🤖)
딜카드 페이지 하단에서 확인할 수 있습니다.
* 예상 거래 가격 대역(최저~최고)과 그에 대한 신뢰도(%)를 제공합니다.
* 거래 성사 확률을 0~100% 게이지로 표시합니다. (🟢 70% 이상: 높음 / 🟡 40~69%: 보통 / 🔴 40% 미만: 낮음)
* 성사에 기여하는 긍정적 요인(✅)과 리스크 요인(⚠️)을 AI가 짚어줍니다.

### 🔒 게이트 요청 (데이터 룸 & NDA)
고객이 IM 뷰어에서 자물쇠(🔒)가 걸린 잠금 섹션을 클릭하면 연락처 입력 폼(게이트 요청 폼)이 뜹니다. 
고객이 정보를 남기면 "요청이 접수되었습니다"라는 안내가 뜨며, 브로커는 대시보드 인박스에서 해당 요청을 확인 후 NDA 서명을 받고 접근 권한을 승인해 줄 수 있습니다.

### 🏛 아고라 커뮤니티 (`/agora`)
크리딜을 사용하는 다른 브로커들과 상업용 부동산 시장 동향을 토론하고 의견을 나눌 수 있는 익명/실명 혼합 커뮤니티 공간입니다.

## 11. ❓ FAQ 및 트러블슈팅 (에러 처리)

**Q. 화면 상단이나 입력창 밑에 빨간색 박스가 뜹니다.**
> 폼(Form) 입력 과정에서 필수 값이 누락되었거나 형식이 틀렸을 때 나타나는 '글로벌 폼 에러(bg-red-900/30)'입니다. 빨간색 경고 문구를 읽고 해당 입력창의 내용을 수정해 주세요.

**Q. 버튼을 눌렀는데 화면이 안 넘어가고 아무 반응이 없습니다.**
> 화면 하단의 토스트 알림(검은색 팝업 메시지)이나 바텀시트 알림을 확인해 주세요. 백그라운드에서 비동기 작업(AI 분석 등)이 진행 중이거나, 일시적인 네트워크 오류에 대한 메시지가 표시될 수 있습니다.

**Q. 카카오톡 공유가 안 됩니다.**
> 모바일 인앱 브라우저 등 특정 환경에서는 카카오톡 공유(SDK)가 제한될 수 있습니다. 이 경우 자동으로 'URL 클립보드 복사'가 진행되니, 카카오톡 입력창을 꾹 눌러 '붙여넣기'를 하시면 됩니다.

**Q. 딜카드 생성 시 'MEMO_QUALITY_INSUFFICIENT' 에러가 발생합니다.**
> 입력하신 카카오톡 메모에 AI가 딜카드를 만들기 위한 필수 정보가 너무 없습니다. 최소한 '대략적인 위치(예: 강남구 역삼동)', '자산유형(예: 꼬마빌딩)', '대략적인 가격'을 포함해서 다시 시도해 주세요.
