## 1. 홈 v2 (고도 3 - Action Queue)

**경로**: `/broker`
**목적**: 브로커가 하루를 시작하며 가장 먼저 해야 할 일(Hot Lead, 승인 대기, 태깅 부탁)을 인라인으로 처리.

```text
========================================================================
[ CREDEAL ]   [검색]                                🔔 3   👤 김지훈 님
========================================================================

⚡ 지금 처리 (3)
------------------------------------------------------------------------
[🔥 Hot Lead] 박성민 님이 어젯밤 '역삼동 상가 딜(Pro)'을 8분 정독함.
              (수익분석 섹션 3회 체류)
  [ 📞 전화하기 ]  [ 💬 스마트톡 답장 ]  [ 나중에 ]
------------------------------------------------------------------------
[🔑 Pro 요청] 이서연 님 — 성수 개발부지 (사유: 사옥 검토, 정합 87%)
  [ 승인 → NDA 발송 ]  [ 거절 ]  [ 프로필 보기 ]
------------------------------------------------------------------------
[🏷️ 태깅 부탁] 지난주 무산된 '논현동 꼬마빌딩', 사유가 무엇이었나요?
  [ 가격 차이 ] [ 대출 불가 ] [ 명도 실패 ] [ 단순 변심 ] [ 기타 ]
------------------------------------------------------------------------

📅 오늘 일정 (2)
- 14:00 역삼동 꼬마빌딩 임장
- 16:30 고객 미팅 (이서연 님)

📊 파이프라인 스냅샷                                      [ 딜 탭으로 → ]
 [발굴 2]  [분석 3]  [마케팅 4 (🔴1 정체)]  [협상 2]  [계약 1]

💡 오늘의 브리핑 (Morning Intel)
 역삼권 만실 매물 문의 증가 추세. 이번 주 반응이 좋은 소구점은 '코너 프리미엄'입니다.
========================================================================
                                                              [ + 메모 ]
```

## 2. 딜 워크스페이스 5-Tab (고도 1)

**경로**: `/broker/deal/{id}`
**목적**: 단일 딜에 대한 모든 정보, 데이터 편집, 문서 생성, 활동 내역을 통합.

```text
========================================================================
⬅️ 뒤로    🏢 역삼동 꼬마빌딩 (150억)          [ ⚙️ 설정 ] [ ▶ 다음 단계로 ]
========================================================================
[ 📊 개요 ] [ 📝 데이터 ] [ 📄 문서/발행 ] [ 👥 관계자 ] [ ⏱️ 활동 내역 ]
========================================================================

( 탭 1: 개요 Overview )
[ 뱃지: 🏛️ 안정수익형 ] [ 상태: 마케팅 중 ] [ Readiness: 85점 (Grade A) ]

- 연면적: 1,200m² / 건폐율 55% / 용적률 240%
- 현재 NOI: 5.5억/년 (Cap Rate: 3.6%)
- 다음 권장 액션: [ 티저 링크 복사하기 ]

------------------------------------------------------------------------
( 탭 2: 데이터 Data ) - 구 바텀시트 확장
[ 주소 및 토지 ] [ 건축물 ] [ 임대차 및 재무 ] [ 갤러리 ]

- 주소 입력 (API 자동 충전) : [ 역삼동 123-45 ] 🟢 연동 완료
- 대지 면적: [ 300 ] m²
- 희망 매각가: [ 150 ] 억 원  (평당 1.6억)
⚠️ 경고: Cap Rate가 권역 평균(4.0%)보다 다소 낮습니다. (C07)
[ 엑셀 렌트롤 업로드 ]
------------------------------------------------------------------------
( 탭 3: 문서/발행 Documents )
- Pitch 생성 (초기 제안용)   [ 웜 모드 생성 ] [ PDF 다운로드 ]
- Teaser v2 (익명 마케팅용)  [ 생성 및 배포 ] (상태: URL 활성)
- Basic IM (기본 정보)       [ 보기 ]
- Pro IM (NDA 완료자용)      [ 검토 및 생성 ]
------------------------------------------------------------------------
( 탭 4: 관계자 Parties )
- 매도인: 김개똥 (단독 소유)  [ 연락처 보기 ]
- 매수 의향자 (3명 대기 중)
  - 박성민 (Hot, Pro 열람 중)
  - 이서연 (NDA 대기)
------------------------------------------------------------------------
( 탭 5: 활동 내역 Activity )
- 2026.07.25 10:00 - 박성민, Pro IM 열람 시작
- 2026.07.24 15:30 - 티저 발행 (URL 생성됨)
- 2026.07.24 12:00 - 엑셀 렌트롤 임포트 완료
========================================================================
```

## 3. 인박스 통합 레이아웃 (Unified Inbox)

**경로**: `/broker/inbox`
**목적**: 모든 고객 커뮤니케이션, 문서 열람 요청, 시스템 알림을 단일 동선으로 처리.

```text
========================================================================
[ CREDEAL Inbox ]                            [ 필터: ▽ 전체 ] [ 돋보기 ]
========================================================================
[ 🔑 요청/열람 (2) ]  [ 💬 채팅/반응 (1) ]  [ 🔔 알림 (0) ]

------------------------------------------------------------------------
🔴 [Pro IM 열람 요청] 성수동 개발부지 딜 
   이서연 고객 (사옥 검토 목적) | 10분 전
   [ 승인 (NDA 발송) ] [ 거절 ] [ 상세 보기 ]

------------------------------------------------------------------------
🟢 [채팅/스마트톡] 역삼동 꼬마빌딩 관련 문의
   박성민 고객: "혹시 2층 임차인 명도 협의가 가능할까요?" | 30분 전
   [ 💬 답장하기 ] [ 📞 전화하기 ] [ 에스컬레이션 ]

------------------------------------------------------------------------
⚪ [열람 알림] 논현동 꼬마빌딩 
   익명(FP-8X92A) 고객이 티저를 조회했습니다. | 2시간 전
========================================================================
```
