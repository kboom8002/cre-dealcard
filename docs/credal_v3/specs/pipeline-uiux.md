# 🎛️ 무마찰 딜 파이프라인 — UI/UX 설계 및 사용자 시나리오

> **버전**: v1.0 (2026.07) · 정합: 기획안 v2.0(5탭 IA·딜 객체) · SDD v1.1(S1-T10/T11/T12·S2-T5) · GAP-5 와이어프레임의 설계 기준 문서
> **핵심 명제**: 브로커의 마찰은 4종이다 — **입력 마찰**(타이핑), **탐색 마찰**(어디 있지), **판단 마찰**(뭘 해야 하지), **기억 마찰**(뭐 하기로 했지). 무마찰 파이프라인이란 이 넷을 각각 자동충전·단일 동선·신호 기반 제안·액션 큐로 치환하는 것이다.
> **설계 헌법**: ① 시스템이 제안하고 브로커가 1탭 확정한다 ② 입력은 사진·음성·탭이 기본, 타이핑은 최후 ③ 모든 화면은 "다음에 할 일"로 끝난다 ④ 자동은 확실한 트리거에만, 나머지는 제안

## 1. 4대 마찰과 해소 장치 매핑

| 마찰 | 전형적 증상 | 해소 장치 |
|------|-------------|-----------|
| **입력** | "사무실 가서 정리해야지" → 유실 | 음성 메모→슬롯 확인 칩 · OCR · 공공 자동충전 60% · 잔여 필드만 노출 |
| **탐색** | 딜카드·IM·고객·일정이 딴 화면 | 딜 워크스페이스 5탭 단일 동선 · 어디서든 딜로 1탭 딥링크 |
| **판단** | "이 딜, 다음에 뭐 하지?" | 카드마다 **다음 액션 1개** 제안 · 신호 뱃지(반응·정체·만기) |
| **기억** | Hot Lead 놓침, 무산 사유 증발 | 홈 액션 큐(우선순위 정렬) · 결정적 순간 1탭 태깅 · 재알림 1회 규칙 |

## 2. 정보 구조 — 세 개의 고도(高度)

```
[고도 3] 홈 '오늘'         — 딜을 넘나드는 "할 일"의 평면   (아침·이동 중)
[고도 2] 딜 탭 파이프라인   — 딜 전체의 "상태"의 평면       (주간 점검)
[고도 1] 딜 워크스페이스    — 딜 하나의 "모든 것"의 평면    (집중 작업)
```

원칙: **위에서 아래로는 1탭, 아래에서 위로는 뒤로가기 1번.** 브로커는 하루의 90%를 고도 3에서 처리하고, 고도 1은 필요할 때만 내려간다.

## 3. 화면 설계

### 3.1 홈 '오늘' — 액션 큐 (고도 3)

```
┌────────────────────────────────────────────┐
│ 좋은 아침입니다, 김지훈 팀장님        🔔 3   │
│                                            │
│ ⚡ 지금 처리 (3)                            │
│ ┌────────────────────────────────────────┐ │
│ │ 🔥 Hot Lead — 박성민 님이 어젯밤 역삼동   │ │
│ │    딜 Pro를 8분 정독 (수익분석 3회)       │ │
│ │    [📞 전화]  [💬 답장]  [나중에]         │ │
│ ├────────────────────────────────────────┤ │
│ │ 🔑 Pro 요청 — 이서연 님 · 성수 개발부지    │ │
│ │    사유: "사옥 검토" · 매칭 정합 87%      │ │
│ │    [승인 →NDA 발송]  [거절]  [프로필]     │ │
│ ├────────────────────────────────────────┤ │
│ │ 🏷️ 30초 부탁 — 지난주 무산된 논현동 딜,   │ │
│ │    사유가 무엇이었나요?                   │ │
│ │    [가격][대출][명도][변심][기타]  [건너뜀] │ │
│ └────────────────────────────────────────┘ │
│                                            │
│ 📅 오늘 일정 (2)  14:00 역삼동 임장 · 16:30 …│
│                                            │
│ 📊 파이프라인 스냅샷                         │
│  발굴 2 · 분석 3 · 마케팅 4(🔴1 정체) ·      │
│  협상 2 · 계약 1        [딜 탭으로 →]        │
│                                            │
│ 💡 오늘의 브리핑: 역삼권 만실 매물 문의 ↑,    │
│    이번 주 반응 좋은 소구는 '코너 프리미엄'    │
└────────────────────────────────────────────┘
                                    [📝 메모 FAB]
```

**설계 규칙**
- 액션 큐 정렬: 수익 임박도 순 — ①리드 응대(Hot·Pro) ②승인 대기 ③태깅 부탁 ④정체 경고. 각 카드는 **인라인 처리**(화면 이동 없이 완료)가 기본
- 태깅 카드는 하루 1건만 노출, 건너뛰면 재노출 1회 후 소멸 (피로 방지)
- 브리핑은 접을 수 있는 1카드 — 집합 지식 환류의 접점

### 3.2 딜 탭 — 파이프라인 보드 (고도 2)

```
┌────────────────────────────────────────────┐
│ 내 딜 12  [칸반|리스트]  [필터: 자산군·권역]   │
│                                            │
│ 발굴(2)   분석(3)   마케팅(4)   협상(2) 계약(1)│
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐       │
│ │역삼동  │ │성수   │ │논현   │ │역삼   │  …   │
│ │꼬마 85 │ │부지 60│ │꼬마 42│ │꼬마 81│       │
│ │🏛️ A등급│ │🏗️ B  │ │🔴 21일│ │🔥 협상│       │
│ │──────│ │──────│ │ 정체  │ │ 중    │       │
│ │▶ 티저  │ │▶ 렌트롤│ │▶ 가격 │ │▶ 미팅 │       │
│ │  발행  │ │  OCR  │ │  재점검│ │  준비 │       │
│ └──────┘ └──────┘ └──────┘ └──────┘       │
└────────────────────────────────────────────┘
```

**카드 문법 (모든 카드 동일 4행)**: ①이름·가격 ②상태 뱃지(아키타입/등급/신호) ③구분선 ④**다음 액션 1개**(▶) — 탭하면 해당 작업 화면으로 직행. "카드를 보는 것"과 "일을 시작하는 것" 사이의 거리가 1탭.

**신호 뱃지 체계**: 🔥 리드 활동 중 · 🔴 N일 정체(단계별 임계: 마케팅 14일·협상 21일) · 🟡 만기 임박(티저 반응 수집 종료, Pro 만료 3일 전) · ✋ 내 확인 대기

**전이 규칙 (마찰의 최소화 지점)**
- 드래그 전이 허용하되, 특정 전이는 **모달 1개**가 따라온다: → `협상`(Pro 승인 시 자동 제안) / → `계약` / → `종결`(성사가 1필드) / → `무산`(사유 5택1)
- 자동 전이는 확실한 트리거만: Pro NDA 완료 → "협상으로 옮길까요?" 제안 배너 (자동 이동 아님)

### 3.3 딜 워크스페이스 (고도 1)

```
┌────────────────────────────────────────────┐
│ ← 역삼동 꼬마빌딩 85억   🏛️ 초안정 수익형 A등급│
│ [개요] [데이터] [문서] [관계자] [활동]         │
│                                            │
│ ▶ 다음 액션: 티저 반응자 5인에게 Basic 발송    │
│   [지금 발송]  [대상 조정]  [건너뛰기]         │
│ ────────────────────────────────────────── │
│ (개요 탭)                                   │
│  단계: 마케팅 D+4 · 열람 9 · 관심 3 · 질문 2  │
│  슬라이더 인사이트: 예산 중위 70억대 ⓘ         │
│  Cap 3.2~3.9% · 실투자금 36.5억 · WALT 2.8년 │
└────────────────────────────────────────────┘
```

- 상단 고정 **'다음 액션 바'**: 이 딜에서 지금 가장 가치 있는 행동 1개를 신호 기반으로 제안 — 워크스페이스의 존재 이유
- 데이터 탭: 자동 채움 필드는 접힌 상태(✓ 뱃지만), **비어 있는 A등급 필수 필드만 펼쳐서** "다음 등급까지 2개 남음"으로 표시. 입력 수단 우선순위: [📷 촬영] [🎤 말하기] [⌨ 입력]
- 문서 탭: 4종(티저·Basic/Pro·Pitch·카톡 문구) 각각 "생성→미리보기→발송" 3버튼 원라인

### 3.4 전환 모먼트 마이크로 UI (마찰이 데이터를 죽이는 지점의 방어)

| 모먼트 | UI | 탭 수 |
|--------|-----|------|
| 무산 처리 | 사유 5택1 + (선택)한 줄 메모 → 완료 | 2탭 |
| 종결 처리 | 성사가 1필드(숫자 키패드) → 완료 | 3탭 |

## 4. 무마찰 메커니즘 10선 (요약)

1. **다음 액션 1개 원칙** — 모든 카드·화면은 추천 행동 하나로 끝난다 (선택지 과잉 = 판단 마찰)
2. **인라인 처리** — 승인·거절·전화·태깅은 화면 이동 없이 그 자리에서
3. **1탭 확정 패턴** — 시스템 제안 + [확정]. 자동 실행은 확실한 트리거만
4. **입력 사다리** — 촬영 > 음성 > 탭 선택 > 타이핑 순으로 유도, 자동 채움은 접어서 숨김
5. **잔여만 보여주기** — "A등급까지 2개 남음" (전체 폼을 보여주지 않는다)
6. **결정적 순간 태깅** — 무산·거절·무시의 순간에만 1탭 질문, 하루 1건, 재요청 1회
7. **신호 뱃지 문법 통일** — 🔥🔴🟡✋ 네 개만, 전 화면 동일 의미
8. **아침 배치 처리** — 야간 발생분(응대 요약·요청·알림)을 홈 큐에 모아 10분 안에 소화되도록 정렬
9. **어디서든 1탭 귀환** — 알림·카톡·문서 어디서 눌러도 해당 딜 워크스페이스의 정확한 탭으로 딥링크
10. **끝나면 다음** — 액션 완료 시 큐의 다음 카드가 자동 승계 (빈 화면 없음)

## 5. 사용자 시나리오

### 시나리오 A — "아침 10분" (매일의 루틴, 고도 3에서만)

> 김 팀장, 08:40 사무실 도착. 커피 들고 폰만 본다.

1. 홈 열기 → 액션 큐 3건: ① Hot Lead(박성민 야간 정독) — [📞 전화] 탭, 통화 후 통화 메모 음성 입력(30초) → 타임라인 자동 기록 ② Pro 요청(이서연) — 프로필 힐끗 → [승인] 1탭 → NDA 자동 발송 ③ 무산 태깅 부탁 — [대출] 1탭
2. 파이프라인 스냅샷에 🔴 1건(논현 21일 정체) → 탭 → 카드의 다음 액션 "가격 재점검" → [슬라이더 인사이트 보기] → "예산 중위가 호가보다 12% 낮음" 확인 → 매도인 통화 일정 잡기 [내일 10시] 탭
3. 브리핑 카드 훑기 — "코너 프리미엄 소구 반응↑" 기억해둠
- **소요 9분 · 타이핑 0회 · 처리 5건** — 어제까지의 모든 미결이 소화됨

### 시나리오 B — "이동 중 포착" (현장, 한 손 조작)

> 14:00 역삼동 임장 후 주차장. 새 매물 정보를 들었다.

1. FAB 🎤 — "논현로 이면 4층 꼬마, 38억 얘기 나옴, 2층에 병원 임차, 명도 얘기는 아직" (22초)
2. 확인 칩 3개 뜸: [매각가 38억?] [자산군 꼬마빌딩?] [명도 미정?] → 탭·탭·탭
3. "딜 만들었습니다. 공공데이터 채우는 중…" → 3분 뒤 푸시: "자동충전 완료 — 2종일반주거, 용적률 여유 12%p, 위반건축물 없음. 다음 액션: 소유주 미팅용 콜드 Pitch 준비해둘까요?" → [준비해줘] 1탭
4. 15:10 미팅 직전, 폰에서 Pitch 미리보기 → 그대로 사용
- **딜 생성부터 제안서까지 총 조작 6탭·타이핑 0** — 이동 중 유실되던 매물이 자산이 됨

### 시나리오 C — "딜 12건 브로커의 금요일 오후" (고도 2 주간 점검)

> 주간 마감. 파이프라인 전체를 15분에 정리한다.

1. 딜 탭 칸반 — 열별 훑기. 마케팅 열 4건 중: 역삼동(🔥 반응 활발) 카드의 ▶ "Basic 발송" [지금 발송] / 서초(🟡 반응 수집 종료) ▶ "반응 리포트 확인" → 열람 4·관심 0 → 다음 액션 제안 "소구를 '자주식 주차'로 바꾼 티저 재발행" [적용]
2. 협상 열: 역삼 81억 딜을 계약 열로 드래그 → 모달 없음(계약 전이는 확인만) / 성수 딜 — 매수자 연락 두절 2주 → 무산으로 드래그 → [변심] 태깅 → 시스템: "이 딜, 3주 후 역매칭 재탐색을 켜둘까요?" [켜기]
3. 종결 열의 지난주 계약 건 — "성사가 입력이 남았습니다" 배너 → 81억 입력(3탭) → "호가 대비 −4.7%, 권역 평균과 일치합니다" 피드백
4. 나가기 전 주간 성과 카드 확인: 발송 IM 6·신규 리드 11·Pro 전환 2
- **15분 · 12건 전수 점검 · 데이터 유실 0** — 무산조차 자산(태깅+재탐색 예약)이 됨

## 6. 마찰 측정 지표 (UX의 정량 검증)

| 지표 | 목표 | 측정 |
|------|------|------|
| 아침 큐 소화 시간 | 10분 이내 (큐 5건 기준) | 세션 로그 |
| 핵심 액션 탭 수 | 승인 1 · 태깅 2 · 종결 3 · 발송 1 | 이벤트 추적 |
| 타이핑 발생률 | 일과 중 필드 입력의 20% 이하 | 입력 수단 로그 |
| 다음 액션 채택률 | 제안의 60%+ 실행 | 제안·실행 비교 — **에이전트 자율성(L2→L3)의 승격 데이터와 동일** |
| 태깅 응답률 | 60%+ (하루 1건 정책 하) | tacit_labels |
| 정체 딜 방치율 | 🔴 발생 후 48h 내 액션 80%+ | 이벤트 추적 |

> **요지**: 무마찰의 본질은 화면을 줄이는 것이 아니라 **판단을 대신 준비해주는 것**이다. 신호가 제안을 만들고, 제안이 1탭으로 실행되고, 실행의 순간마다 데이터가 떨어진다 — 그리고 '다음 액션 채택률'이라는 이 UX의 성공 지표는 그대로 2막(에이전트 자율성 승격)의 훈련 데이터가 된다. 무마찰 UI는 편의 기능이 아니라 에이전트로 가는 다리다.
