## 0. 진단 요약 — 세 효과의 현재 상태

| 효과 | 정의 | 크리딜 현재 | 공백 |

## 1. 데이터 네트워크 효과 — 보완 개발

### N1. Give-to-Get 접근 모델 (기여 비대칭 해소) `핵심`
- 현재 설계는 "모두에게 익명 집계 환류" — 무임승차가 합리적 선택이 된다
- 보완: 집합 지식의 **심화 계층**은 기여자만 접근 — 무산 사유를 태깅한 브로커만 권역 무산 사유 분포를, 성사가를 입력한 브로커만 호가-성사가 갭 통계를 본다
- 구현: `tacit_labels`·`outcome_price` 기여 스코어 → 인사이트 계층별 게이트. 기본 계층(얕은 집계)은 전원 공개 유지 — 콜드스타트 보호

### N2. 권역 벤치마크 자동 리포트
- "내 딜 vs 권역": 평균 대비 내 딜 사이클·열람 전환·Cap 포지션 — 월간 자동 생성
- 벤치마크는 참여자가 늘수록 정밀해짐을 명시("표본 N=23 — 참여 브로커가 늘면 더 정확해집니다") — 네트워크 가치의 가시화

### N3. 교차 관심 그래프 (매물-매물 연관)
- "이 티저를 본 매수자가 함께 본 딜" — 유사 딜 추천(티저 스펙 §4.4)의 데이터를 그래프화
- 브로커에게: "내 딜의 경쟁 딜은 무엇인가" / 매칭에: 협업 필터링 신호 추가

### N4. 공동중개 평판 그래프 (S5 확장)
- 성사 이력·응답 속도에 더해 **거래 상대 상호 평가의 누적 그래프** — 네트워크가 커질수록 "누구와 거래해도 되는가"의 답이 정확해짐. MLS의 신뢰 인프라

## 2. AI 데이터 플라이휠 — 보완 개발

### F1. 플라이휠 계기판 (기여의 가시화) `핵심`
- 브로커 개인 화면: "당신의 편집 {N}건이 골든셋 {M}개가 됐고, 이번 달 AI 초안 편집률이 {X}%p 내려갔습니다"
- 심리 설계: 내 기여→AI 개선→내 시간 절약의 인과를 **체감**시켜 diff 동의율·태깅 응답률을 끌어올림 — 플라이휠의 연료 공급 장치

### F2. 아웃컴 연결 학습 (팔리는 문서 학습)
- 현재 골든셋 기준은 Judge 점수+브로커 승인(품질) — **성사 여부(결과)와 미연결**
- 보완: 성사 딜의 문서·소구·반응 경로를 역추적해 "팔린 IM의 패턴"을 학습 라벨로 — 골든셋 선별에 outcome 가중 추가. 무산 딜 문서는 반면교사 세트
- 전제: 결과 회귀(성사가 입력)·무산 태깅의 응답률 — L2 수집 체계가 곧 학습 인프라

### F3. 발행 전 반응 시뮬레이터 `킬러 후보 → K2`

### F4. 임계값 자동 튜닝
- 아키타입 규칙(R01~10)·매칭 임계값을 브로커 토글 이력+거절 태깅으로 주기 보정 — 규칙 엔진 자체가 플라이휠 대상 (수동 규칙→학습 규칙의 점진 전환)

## 3. 양면 플랫폼 효과 — 보완 개발

### P1. 매수자 관계의 영속화 (익명→프로파일→자산)
- 현재: 방문자는 딜이 끝나면 소멸. 보완: 관심 등록 매수자에게 **딜 피드 계정**(내 조건 매칭 신규 티저 알림 — 단, 모든 접촉은 담당 브로커 경유. 리드 소유권 원칙 불변)
- 매수자에게 주는 가치: "조건에 맞는 검증된 매물을 가장 먼저" — 수요측이 머무를 이유

### P2. Buyer Passport (검증된 매수자) `킬러 후보 → K3`

### P3. 전문가 3면의 마켓화 (S6 확장)
- 전문가 기고 실적·평점의 공개 프로파일 → 브로커의 전문가 선택이 데이터 기반으로 — 전문가 유입이 IM 신뢰를 올리고, IM 신뢰가 딜을 늘리고, 딜이 전문가 수요를 늘리는 3면 순환

### P4. 자산 라이프사이클 순환 `킬러 후보 → K4`

## 4. 킬러 아이디어 5선 (식별·평가)

### K1. Give-to-Get 성사 데이터 풀 — "한국 CRE에 없는 데이터의 조합 시장"
- **무엇**: 호가-성사가 갭·무산 사유·딜 사이클의 심화 통계를 기여자 전용으로. 기여할수록 깊은 계층 접근(브론즈: 권역 평균 → 골드: 자산군×가격대 분해 → 플래티넘: 분기 추이·예측)
- **왜 킬러**: 이 데이터는 **딜 과정 안에서만 생성**되고 시장에 존재하지 않는다. 접근 욕구가 기여를 강제하고, 기여가 데이터를 강화하는 자기 강화 — 네트워크 효과의 엔진 그 자체
- **리스크·대응**: 격리 원칙 충돌 없음(익명 집계·N≥5 유지). 초기 표본 부족 → 기본 계층 전원 공개로 완충
- **효과 매핑**: 네트워크 ◎ · 플라이휠 ○ · 양면 △

### K2. 발행 전 반응 시뮬레이터 — "보내기 전에 시장의 답을 미리 본다"
- **무엇**: 티저·IM 발행 전, 축적된 반응 함수(아키타입×권역×소구별 열람·전환)로 예상 반응 점수 + 개선 제안("서브제목을 '리모델링 시나리오' 소구로 바꾸면 예상 열람 +40% — 이 권역 개발형 관심 비중이 높습니다")
- **왜 킬러**: 플라이휠을 **체감 가능한 마법의 순간**으로 번역 — 데이터 축적의 효용이 발행 버튼 옆에서 보인다. 카피 A/B(B4)·아웃컴 학습(F2)의 소비자 접점
- **리스크·대응**: 초기 표본 부족 시 과신 유발 → 신뢰구간 표시·표본 N 명시, 점수 아닌 등급(상/중/하)로 시작
- **효과 매핑**: 네트워크 ○ · 플라이휠 ◎ · 양면 △

### K3. Buyer Passport — "검증된 매수자"라는 새 화폐
- **무엇**: 매수자의 검증 이력(NDA 이행·미팅 노쇼 여부·자금 검증 뱃지[선택: 잔고·대출 사전심사 연계]) + 행동 프로파일(관심 아키타입·예산 신뢰도)을 담은 이동 가능한 신원. 브로커에겐 진성 필터("Passport 매수자의 Pro 요청은 미팅 전환 3배"), 매수자에겐 좋은 딜 우선 접근권
- **왜 킬러**: 양면 효과의 잠금 고리 — 검증된 매수자가 모이면 브로커가 좋은 딜을 먼저 올리고, 좋은 딜이 매수자를 모은다. 크로스 매칭(S5)에서 "상대 브로커의 매수자"를 신뢰하는 문제도 이것이 푼다
- **리스크·대응**: 개인정보·금융 연계 민감 → 전부 옵트인, 자금 검증은 제휴 기관 위임, 초기엔 행동 이력만으로 시작
- **효과 매핑**: 네트워크 ○ · 플라이휠 △ · 양면 ◎

### K4. 자산 라이프사이클 순환 — "오늘의 매수자가 내일의 매도인" `최우선 킬러`
- **무엇**: 성사 후 매수자(신규 건물주)에게 브로커 명의의 **자산 리포트 자동 발송**(분기: 권역 시세·유사 실거래·내 자산 포지션·공시지가 변동 — 전부 이미 있는 데이터·인프라 재사용). 5~7년 후 매도 검토 신호(리포트 정밀 열람·가격 문의) 감지 → 재수임 Pitch 자동 제안
- **왜 최우선 킬러**: ① 꼬마빌딩 보유 주기를 고려하면 **공급(매물) 획득이 자동화되는 유일한 구조** — 소싱 병목의 궁극 해법 ② 일회성 거래를 영속 관계로 바꿔 브로커 이탈을 막음(내 고객 자산 장부가 크리딜에 있음) ③ 경쟁사가 못 따라함 — 성사 데이터+자산 데이터+브로커 관계 3개를 모두 가진 자만 가능 ④ 추가 개발이 가장 적음(기존 데이터·매거진 인프라 재조합)
- **리스크·대응**: 브로커-고객 관계 소유권 → 리포트는 철저히 브로커 명의(화이트라벨), 플랫폼 직접 접촉 금지
- **효과 매핑**: 네트워크 ○ · 플라이휠 ○ · 양면 ◎ (수요가 공급으로 순환하는 제3의 효과)

### K5. 성사가능가 지수 (Credeal Index) — 데이터 자산의 대외 브랜드화
- **무엇**: 호가-성사가 갭·사이클 데이터 기반 권역별 "실제 팔리는 가격" 분기 지수. 대외 공개(요약)+기관 상품(상세)
- **왜 킬러**: 조회 플랫폼의 본진(밸류에이션)을 역공하는 깃발이자 PR 자산 — "호가는 밸류맵에, 성사가는 크리딜에"
- **주의**: 표본 충분 전 공개 금지(지수 신뢰가 곧 브랜드) — 3년차 과제
- **효과 매핑**: 네트워크 ◎ · 플라이휠 ○ · 양면 ○

## 6. 지키며 갈 것 (효과 극대화의 경계)

- **리드 소유권 불변**: P1·K3·K4 어디서도 플랫폼이 매수자·건물주와 직접 거래 관계를 맺지 않는다 — 브로커 편 포지션이 모든 효과의 전제
- **격리와 집계의 선**: K1·K5의 원료는 익명 집계뿐(N≥5) — 개인 데이터 상품화는 해자의 자살
- **표본 정직성**: K2·K5는 표본 부족 시 등급·구간·N 표시로 겸손하게 — 과신 유발이 신뢰를 태움
- **무임승차의 전략적 허용**: N1 기본 계층은 계속 무료 — 신규 브로커의 콜드스타트를 죽이면 네트워크도 죽는다

> **요지**: 세 효과는 별개가 아니라 하나의 순환이다 — **브로커가 딜을 돌리면(플라이휠 연료) 데이터가 쌓이고(네트워크), 데이터가 매수자를 검증·유지하며(양면), 그 매수자가 몇 년 뒤 매물이 되어 돌아온다(K4)**. 킬러는 화려한 신기능이 아니라 이 순환의 마지막 고리를 잇는 것 — 오늘의 매수자를 내일의 매도인으로.
