# 🎯 중개인 딜 파이프라인 시나리오 & 최적 활용 모델

> **버전**: v1.0 (2026.07.23) · 대상 도구: 메모 → 딜카드(티저) → IM-Basic → IM-Pro → Full IM (+수임 제안서·매칭·데이터룸)
> **정합**: 티저 스펙 · IM 이원화 스펙 · Full IM 스펙 · DEV_SPEC v2.0
> **용도**: 브로커 온보딩 플레이북의 뼈대 + 제품 팀의 UX 검증 기준

---

## 1. 총괄 모델 — 파이프라인 × 도구 매핑

```
파이프라인   발굴      분석      제안(수임)   마케팅        협상           계약·종결
            │         │         │           │             │              │
도구        메모      메모+     수임        딜카드(티저)   IM-Pro        데이터룸
            (포착)    자동충전   제안서      → IM-Basic    (+Full IM)    결과 회귀
                      (검증)    (Pitch)     (수요 탐지→설득) (검증→실사)   (암묵지)
```

### 1.1 도구별 역할 정의 (한 줄 원칙)

| 도구 | 역할 | 성공 기준 | 실패 신호 |
|------|------|-----------|-----------|
| **메모** | 딜의 포착 — 현장에서 1분 안에 기록 | 슬롯 자동 충전 시작 | 사무실 복귀 후 기억 의존 |
| **수임 제안서** | 매물 확보 — "저에게 맡기면" | 전속 수임 + 강화IM 일괄 위임 | 구두 약속만 받음 |
| **딜카드(티저)** | 수요 탐지 — 익명으로 시장 반응 측정 | 열람·슬라이더·CTA 데이터 | 반응 측정 없이 바로 IM 배포 |
| **IM-Basic** | 설득 — 사고 싶게 만들기 | 열람 10인+ · Gate/Pro 요청 발생 | 무차별 대량 살포 |
| **IM-Pro** | 검증 — 사도 되는지 확인시키기 | NDA 후 정밀 열람 → 미팅 | 요청 없는 선제 발급 |
| **Full IM** | 기관 관문 — 투심 통과 지원 | 기관 내부 보고 채택 | 소형 딜에 남발 |
| **데이터룸** | 실사 — 원본 교환 | 계약 진행 | 카톡으로 원본 전송 |

### 1.2 전환 트리거 규칙 (판단을 데이터로)

| 전환 | 트리거 신호 | 시스템 지원 |
|------|------------|-------------|
| 메모 → 딜 생성 | 매물 정보 감지 | AI 분류 + 슬롯 자동 충전 (60%) |
| 딜 → 티저 발행 | grade C 이상 + 재식별 게이트 통과 | 밴드 자동 제안 |
| 티저 → Basic 발송 | ①티저 CTA 반응자 ②매칭 S/A 후보 | "반응자 5인에게 Basic 보내기" 1탭 |
| Basic → Pro 승인 | 매수자의 Pro 요청 (스코어 +40) | 인박스 인라인 승인 + 매도인 동의 체인 |
| Pro → 미팅/협상 | 60초+ 정밀 열람 · 개인화 모듈 조작 | Hot Lead 알림 + 파이프라인 전이 제안 |
| Pro → Full IM | 기관 매수자·100억+·물류/NPL | 발동 카드 자동 표시 (기본은 미발동) |
| 협상 → 데이터룸 | LOI/미팅 확정 | grant 체계 연장 |

**핵심 원칙: 사다리는 건너뛰지 않되, 머무르지도 않는다.** 각 단계는 다음 단계의 리드 품질을 검증하는 필터다.

## 2. 시나리오 A — 강남 꼬마빌딩 85억 (표준 경로)

> 매도인: 개인(상속 매물) · 매수 타깃: 개인 자산가 · 아키타입: STABLE_INCOME

**D+0 (임장)** — 매도인 미팅 직후 차 안에서 음성 메모 1분: "역삼동 5층 꼬마빌딩, 85억 희망, 1층 카페 월 300, 만실, 대출 45억". → AI가 딜 생성 + 공공 API 자동 충전(대장·용도지역·공시지가·도로접면). 도구: **메모**

**D+1 (수임)** — 자동 충전된 데이터로 수임 제안서 생성: 비교 실거래 3건(선정 근거 표기) + "이 권역 평균 성사 9.1개월, 무산 1위 대출 — 저는 열람 추적으로 검증된 매수자만 데려옵니다" + 강화IM 일괄 위임 조항. → **전속 수임 + 위임 확보**. 도구: **수임 제안서**

**D+2 (렌트롤 충전)** — 임대차계약서 5장 촬영 → OCR 렌트롤 자동 파싱 → grade A 달성. 도구: **딜 워크스페이스**

**D+3 (수요 탐지)** — 티저 발행: "🏛️ 초안정 수익형 · 역삼권 · 80억대 · Cap 4%대 · 만실". 재식별 게이트 통과(후보 27필지). 매칭 S급 2인 + 기존 고객 12인에게 카톡 발송. 도구: **딜카드**

**D+3~7 (반응 수집)** — 열람 9인 · 슬라이더 조작 4인(예산 중위 70억대 — 호가 조정 근거 확보) · 관심 등록 3인 · 질문 채팅 2건(자동응답: 검증 슬롯 인용, 명도 질문은 에스컬레이션). 도구: **티저 인사이트 + 스마트톡**

**D+7 (설득)** — 반응자 5인 + 신규 매칭 1인에게 IM-Basic 발송(B2C 렌더). 위반건축물 없음이 리스크 섹션에 명기. 열람 추적: 2인이 수익 분석 섹션 3분+. 도구: **IM-Basic**

**D+10 (검증)** — 매수자 K가 Pro 요청(사유: "실입주 겸 투자 검토"). 승인 → NDA → 정밀 렌트롤·등기 요약·대출 시뮬레이션(K의 슬라이더 값 초기값) 열람. 파이프라인 → 협상 전이 확정. 도구: **IM-Pro**

**D+12~30 (협상·실사)** — 슬라이더 분포 데이터로 매도인 호가 조정 설득(85→81억). 미팅 2회 → LOI → 데이터룸(등기·계약서 원본, 워터마크). **D+45 계약.** 종결 시 성사가 81억 입력 → 결과 회귀. 무산됐다면 1탭 사유 태깅.

**축적된 암묵지**: 호가-성사가 갭(-4.7%), 반응 함수(수익분석 체류→Pro 전환), K의 매수 프로파일.

## 3. 시나리오 B — 성수 개발부지 60억 (명도 이슈 · 시행사 매수)

> 아키타입: 잠정 HQ_READY(명도 진행 중) · 매수 타깃: 소형 시행사·사옥 수요 법인

**포착·검증**: 메모 "성수 대지 70평, 구옥 2층, 60억, 세입자 1명 협의 중" → 자동 충전: 용도지역(준공업)·**용적률 여유 210%p**·도로접면(소로각지)·토지거래허가구역 아님. 명도 3속성 입력: 상태=협의중·조건=전체명도·점유자=대항력 없는 임차인(risk LOW). → 아키타입: SAFE_EVICTION_DEV.

**차별 포인트 1 — 규모검토 소비**: 브로커가 디스코에서 뽑은 규모검토 PDF 업로드 → "신축 시 연면적 약 480평" 슬롯 충전 → 사업수지 요약(A등급 조건부).

**티저**: "🏗️ 명도 안전 개발 후보 · 성수권 · 60억대 · 준공업 · 용적률 여유 200%p+ · 코너". curiosity_slot=정밀 위치·규모검토. 시행사 풀에 발송.

**Basic(B2B 렌더)**: 개발 시나리오 중심 — 신축 연면적·예상 임대수익 밴드·명도 리스크 등급 명기. "임대수익률" 소구는 금지(아키타입 소구 사전 — 개발형에 현 수익률은 불리).

**Pro**: 시행사 2곳 요청 — 개발 모듈(사업수지 상세)·명도 합의서 진행 상황·기부채납 검토. 세무사 기고(양도 구조)가 있으면 expert_verified 뱃지.

**변곡점 — 무산과 재생**: 시행사 A가 이탈 → 1탭 태깅 "대출". 3주 후 매칭 엔진이 신규 등록된 사옥 수요 법인을 역매칭으로 발견 → 티저 재발송 → 성사. **교훈: 태깅과 역매칭이 죽은 딜을 살린다.**

## 4. 시나리오 C — 이천 물류센터 380억 (기관 매수 · Full IM 발동)

> 아키타입: INSTITUTIONAL_LOGI (마스터리스·WALT 6.2년) · 매수 타깃: 운용사·리츠

**포착~Basic**: 메모 → 물류 특화 슬롯(층고 10.5m·도크 24기·저온 40%·수전 3,000kW) 입력(OCR+직접) → 티저(물류 대표 슬롯 세트: 층고·도크 밴드·IC 거리) → Basic(B2B 렌더 기본).

**Full IM 발동**: 운용사 M이 Pro 열람 후 "내부 투심용 IM 요청" → 트리거 충족(기관+380억+물류) → Full IM 카드 발동. 코어 7섹션은 Basic/Pro 승인본 자동 상속(작업 0), 확장 섹션 선별: 시장 동향·비교 거래·CAPEX 계획·법률(전문가 패치)·세무 구조(전문가 패치)·증빙 인덱스.

**전문가 패치**: 법무사(권리분석)·세무사(취득 구조) 섹션 배정 → 패치 제출 → 실명·자격 뱃지. 축약 Gate(자동 4종 통과 → reviewer 1회) → buyer_ready pptx 익스포트(워터마크: 운용사 M 각인).

**소요**: 전통 3주 → **3일** (코어 상속 + 전문가 대기 포함). 데이터룸으로 실사 이행, Q&A Pack 동봉.

## 5. 시나리오 D — 수임 경쟁전 (도구의 역방향 활용)

> 상황: 강남 꼬마빌딩 매도인이 중개사무소 3곳에 매물을 뿌림 (전속 없음)

- **1수**: 주소만으로 자동 충전 → 10분 만에 수임 제안서 완성. 경쟁사가 명함을 놓고 갈 때, 크리딜 브로커는 비교 실거래·아키타입 분석·마케팅 계획이 담긴 문서를 놓고 간다
- **2수**: 제안서에 열람 추적 데모 — "매물을 뿌리면 끝이 아니라, 누가 몇 분 봤는지 매주 보고드립니다" → 일반 수임이라도 **주간 리포트 자동 발송**으로 신뢰 축적
- **3수**: 첫 주 티저 반응 데이터(열람 14인·슬라이더 예산 분포)를 들고 재방문 → "시장이 말하는 가격은 78억대입니다" → 호가 조정 + **전속 전환**
- 교훈: 파이프라인 도구는 매수자 대상만이 아니라 **매도인 획득·유지 무기**다. 티저는 가격 발견 도구, 추적은 보고 도구.

## 6. 최적 활용 모델 요약

### 6.1 표준 케이던스 (꼬마빌딩 기준)

```
D+0  메모 (1분)          D+7   Basic 발송 (반응자만)
D+1  수임 제안서          D+10~ Pro (요청 기반)
D+2  OCR·grade A        D+30~ 협상·데이터룸
D+3  티저 발행           종결   결과 회귀·태깅
     └ 반응 수집 3~4일이 Basic 발송 품질을 결정
```

### 6.2 자산군별 변주

| | 꼬마빌딩 | 개발부지 | 물류(기관) |
|---|---|---|---|
| 기본 렌더 | B2C | B2B | B2B |
| 티저 강조 | Cap·만실·코너 | 용적률 여유·명도·허가 | 층고·도크·마스터리스 |
| 종착 문서 | IM-Pro | IM-Pro(개발 모듈) | **Full IM** |
| 전문가 개입 | 선택 (세무) | 권장 (건축·법무) | 필수 (법무·세무) |

### 6.3 안티패턴 (하지 말 것)

1. **티저 생략 후 IM 대량 살포** — 수요 탐지 없는 배포는 리드 데이터도, 희소성도 잃는다
2. **처음부터 Pro/정밀값 공개** — 커밋 없는 공개는 유출이며, 리드 검증 신호를 버리는 것
3. **반응 없는 대상에게 반복 발송** — 관심 프로파일에 없는 매물 강요는 구독 이탈
4. **소형 딜 Full IM** — 2~3일 공수 낭비 + 매수자 마찰
5. **무산 딜 방치** — 태깅 없는 무산은 암묵지 0, 역매칭 기회 상실
6. **결과 미입력** — 성사가 미기록이면 가격 감각 캘리브레이션 불가

### 6.4 브로커의 하루 (도구가 만드는 루틴)

```
08:30 홈 브리핑 — 야간 스마트톡 요약·Hot Lead·태깅 요청 1건 처리
09:00 액션 큐 — Pro 요청 승인 2건(인박스 인라인), 임장 일정 확인
10:30 임장 → 음성 메모 → 새 딜 자동 생성
13:00 어제 티저 반응 확인 → 반응자 4인에게 Basic 발송 (1탭)
15:00 슬라이더 분포 들고 매도인 미팅 (호가 조정 설득)
17:00 매칭 결과 검토 — 거절 1건 태깅(입지)
```

> **요지**: 최적 모델의 본질은 "더 많은 문서"가 아니라 **단계마다 시장의 응답을 수집하고, 그 응답이 다음 단계의 대상과 내용을 결정하게 하는 것**이다. 메모는 딜을 만들고, 티저는 수요를 재고, Basic은 설득하고, Pro는 검증하고, Full은 기관 관문을 연다 — 그리고 그 모든 단계의 데이터가 다음 딜을 더 쉽게 만든다.
