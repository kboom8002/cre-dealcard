## E2E-2. 개발부지·무산 재생 (플레이북 B)

명도 3속성 입력→SAFE_EVICTION_DEV 판정→규모검토 PDF 파싱→B2B 렌더(개발 소구·현수익률 미강조)→무산 태깅[대출]→역매칭 재탐색 켜기→신규 intent 등록 시 재부상. 검증: 아키타입 근거 표시·massing 슬롯 충전·tacit_labels 기록·역매칭 알림.

## E2E-3. 기관 물류·Full IM (플레이북 C — Stage 4)

물류 슬롯 입력→INSTITUTIONAL_LOGI→IC 거리맵 삽입(S4-MI4)→Full IM 발동 카드(트리거: 기관+380억)→코어 7섹션 상속(**재작성 diff=0 검증**)→축약 Gate→pptx 산출(grant 배포). 검증: 발동 조건 미충족 딜에는 카드 미표시.

## E2E-4. 수임 경쟁·콜드 (플레이북 D)

주소만 입력→콜드 Pitch **10분 타이머 검증**·**가격 의견 블록 부재 검증**→발송→매도인 열람(블록 체류 이벤트)→웜 전환→[✍ 전속] 탭→mandate+위임 자동 기록.

## E2E-5. 아침 10분 루틴 (UX-A)

큐 5건 픽스처(Hot Lead·Pro 요청·태깅·정체·일정)→인라인 전수 처리. 검증: **소요 ≤10분(스크립트 타이머)·화면 이동 없이 처리 4/5·타이핑 이벤트 0**·태깅 응답 기록.

## E2E-6. 이동 중 포착 (UX-B)

음성 22초→칩 3탭→충전 푸시→[콜드 Pitch 준비] 1탭. 검증: **총 조작 ≤6탭·타이핑 0**.

## E2E-7. 금요일 파이프라인 점검 (UX-C)

칸반 12딜 픽스처→드래그 전이(계약=무모달·무산=사유 모달 강제)→성사가 미입력 배너→입력. 검증: 무산 딜 태깅 없이 종결 불가·역매칭 예약 토글.

## E2E-8. 매거진 주간 사이클 (Stage 4)

월요일 크론→초안 대기→음성 필드노트 5문답→원스크린 확인→발행(**5분 타이머**)→구독자 열람→매물 카드(티저 규격·좌표 부재)→클릭 2회→intent 초안 제안. 검증: 집합 지식 N 표기·needs_review 미발생(마스크 구간).

## E2E-9. 유출 방어 종합 (보안 회귀 — 매 릴리스)

티저·Basic·매거진 카드·/agora 피드의 응답 페이로드 전수 스캔: 정확 좌표·정밀값·임차인 실명·외관 사진 URL **검출 0**. 재식별 게이트 우회 발행 시도 → 전부 409. Pro grant URL 무인증 접근 → 403.

## E2E-10. 주소 폴백 신뢰도 (v1.3 — 데이터 공급 감사 D6)

주소 미확정 딜 픽스처(raw_input에 동 이름만) → 3차 폴백(`"서울시 {area_signal}"` 조합)으로 자동충전 발생 → 검증: ①해당 public_data 슬롯에 "주소 확인 필요" 배지 표시 ②티저·IM 발행 시 C13 경고 노출 ③주소 확정(PNU) 후 재충전 시 배지 해제·confidence 승격. 오건물 데이터가 ✓ 배지로 무경고 발행되는 케이스 = 실패.

> 운영 규칙: E2E-1·9는 머지 게이트(필수), 나머지는 nightly. 탭 수·타이머 상한은 무마찰 지표의 테스트화 — 완화하려면 UX 문서 개정 선행.
