# 📘 따라하기 튜토리얼 Part 1 — 딜카드 만들기 & AI 매수자 매칭

> **대상:** 제이에스부동산중개(주) 소속 중개사님  
> **소요시간:** 약 20분  
> **준비물:** PC 또는 태블릿, 크레딜(credeal.net) 로그인 계정  
> **목표:** 매물 정보를 입력하면 AI가 자동으로 매수자를 찾아주는 과정을 처음부터 끝까지 직접 체험합니다.

---

## 🎯 이 튜토리얼에서 배우는 것

1. 매물 메모를 입력하면 AI가 **딜카드(매물 정보 카드)**를 자동 생성하는 방법
2. 매수자 조건을 입력하면 AI가 **매수의향서**를 자동 정리하는 방법
3. 딜카드와 매수의향이 만나면 AI가 자동으로 **S/A/B/C 등급 매칭**을 해주는 과정
4. AI가 추천하는 **이상적 매수자 페르소나 3종** 확인하기

---

## 📌 시작하기 전에

1. 브라우저(크롬 권장)에서 **https://credeal.net** 에 접속합니다.
2. 발급받은 아이디/비밀번호로 **로그인**합니다.
3. 로그인 후 대시보드 화면이 보이면 준비 완료입니다.

> 💡 **팁:** 글씨가 작으면 키보드 `Ctrl` + `+` 를 누르면 화면이 커집니다.

---

## 실습 1: 딜카드(매물 카드) 만들기

### 📝 무엇을 하나요?
평소에 메모장이나 카톡에 적어두시는 매물 정보를 그대로 붙여넣으면, AI가 자동으로 깔끔한 매물 카드를 만들어 줍니다.

### 따라하기

**① 딜카드 만들기 페이지로 이동**

- 왼쪽 메뉴에서 **"딜카드"** 를 찾아 클릭합니다.
- **"새 딜카드"** 또는 **"+ 새로 만들기"** 버튼을 클릭합니다.
- 주소창에 `credeal.net/broker/deal-card/new` 가 보이면 맞습니다.

**② 매물 메모 입력**

아래 내용을 **그대로 복사**해서 메모 입력란에 붙여넣으세요:

```
역삼동 테헤란로 인근 꼬마빌딩 매물 접수.
대지 85평, 연면적 320평, 지하1층~지상5층.
2003년 준공, 근린생활시설 및 업무시설.
현재 만실 상태. 보증금 총 8억, 월세 총 2,800만원.
매도 희망가 80억 (감정가 대비 약 10% 할인).
1층 카페, 2~3층 사무실, 4~5층 공유오피스 임차 중.
리모델링 이력 있음 (2019년 외벽+엘리베이터 교체).
위반건축물 해당 없음. 단독소유. 명도 불필요(만실).
```

> 💡 **실무 팁:** 실제 매물 접수 시에도 이런 식으로 핵심만 메모해서 붙여넣으시면 됩니다. 형식은 자유입니다.

**③ AI 분석 시작**

- **"AI 분석 시작"** 버튼을 클릭합니다.
- 화면에 로딩 표시가 나오면서 AI가 분석을 시작합니다.
- **10~30초** 정도 기다리시면 됩니다.

**④ AI 분석 결과 확인**

AI가 메모를 분석해서 아래 항목들을 자동으로 정리해 줍니다:

| 항목 | 기대 결과 |
|------|----------|
| **지역** | `역삼동` 또는 `강남구 역삼동` |
| **자산유형** | `꼬마빌딩` |
| **가격대** | `80억` 또는 `80억대` |
| **공실 상태** | `만실` |
| **적합성 요약** | AI가 투자 매력 포인트를 정리한 문장 |
| **주의사항** | AI가 리스크 포인트를 정리한 문장 |

> ✅ **확인 포인트:** 지역이 `역삼동`, 가격이 `80억대`, 공실 상태가 `만실`로 나오면 정상입니다.

**⑤ 저장하기**

- 내용을 확인한 후 **"저장"** 버튼을 클릭합니다.
- 저장이 완료되면 **딜카드 상세 페이지**로 자동 이동합니다.
- 🎉 첫 번째 딜카드가 만들어졌습니다!

> ⚠️ **중요:** 저장하는 순간, AI가 백그라운드에서 기존에 등록된 모든 매수의향과 자동 매칭을 시작합니다. 이것은 눈에 보이지 않지만 알아서 진행됩니다.

## 실습 2: 이상적 매수자 페르소나 확인하기

### 📝 무엇을 하나요?
방금 만든 딜카드를 보고, AI가 "이 매물을 살 만한 사람은 이런 유형이다"를 3가지로 추천해 줍니다.

### 따라하기

**① 딜카드 상세 페이지에서 아래로 스크롤**

- 실습 1에서 저장한 딜카드 상세 페이지에 있으면 그대로 아래로 스크롤합니다.
- **"이상적 매수자 페르소나"** 라는 섹션을 찾습니다.

**② 페르소나 생성**

- **"페르소나 생성"** 버튼이 보이면 클릭합니다.
- AI가 5~15초 정도 분석한 후 **3장의 카드**가 나타납니다.

**③ 결과 확인**

예를 들어 이런 결과가 나올 수 있습니다:

| 페르소나 | 유형 | 설명 |
|---------|------|------|
| 페르소나 1 | **수익형 투자자** | 안정적 임대수익을 추구하는 법인 투자자 |
| 페르소나 2 | **사옥 실사용 기업** | 교통 편리한 사옥을 매입하려는 IT 기업 |
| 페르소나 3 | **밸류애드 디벨로퍼** | 리모델링 및 증축으로 가치를 높이려는 개발사 |

> 💡 **활용 팁:** 이 페르소나를 보고 어떤 유형의 매수자에게 연락할지 우선순위를 정할 수 있습니다.

## 실습 3: 매수의향(매수자 조건) 등록하기

### 📝 무엇을 하나요?
매수 상담을 받은 고객의 조건을 입력하면, AI가 구조화된 매수의향서로 정리해 줍니다.

### 따라하기

**① 매수의향 만들기 페이지로 이동**

- 왼쪽 메뉴에서 **"매수의향"** 을 찾아 클릭합니다.
- **"새 매수의향"** 또는 **"+ 새로 만들기"** 버튼을 클릭합니다.
- 주소창에 `credeal.net/broker/buyer-intents/new` 가 보이면 맞습니다.

**② 매수 조건 메모 입력 (S등급 매칭 테스트용)**

아래 내용을 **그대로 복사**해서 붙여넣으세요:

```
법인 매수자, 예산 60~100억.
강남·서초·역삼 권역 꼬마빌딩 선호.
임대수익형 투자 목적. 만실 또는 90% 이상 점유 매물 희망.
필수조건: 위반건축물 불가, 명도 불필요한 만실 매물.
수익률 4% 이상 기대. 대출 비율 50% 이내 예정.
리스크 허용도: 보수적.
```

**③ AI 분석 실행**

- **"AI 분석"** 버튼을 클릭합니다.
- 10~30초 대기합니다.

**④ 분석 결과 확인**

| 항목 | 기대 결과 |
|------|----------|
| **매수자 유형** | `법인` |
| **예산 범위** | `60억 ~ 100억` |
| **선호 지역** | `강남`, `서초`, `역삼` |
| **자산 유형** | `꼬마빌딩` |
| **매수 목적** | `임대수익` 관련 |
| **필수조건** | `위반건축물 불가`, `만실` 관련 |
| **리스크 허용도** | `보수적` |

**⑤ 저장**

- **"저장"** 을 클릭합니다.
- 🎉 매수의향이 등록되었습니다!

> ⚠️ **자동 매칭:** 저장하는 순간 AI가 이 매수의향에 맞는 매물을 자동으로 찾기 시작합니다. 실습 1에서 만든 역삼동 80억 매물과 높은 등급(S 또는 A)으로 매칭될 것입니다.

## 실습 4: AI 매칭 결과 확인하기

### 📝 무엇을 하나요?
AI가 매물과 매수의향을 자동으로 비교해서 등급을 매긴 결과를 확인합니다.

### 따라하기

**① 딜카드 상세 페이지로 이동**

- 실습 1에서 만든 딜카드 상세 페이지로 이동합니다.
- 아래로 스크롤하여 **"매칭된 매수자"** 섹션을 찾습니다.

**② 매칭 결과 확인**

| 확인 항목 | 설명 |
|----------|------|
| **등급 뱃지** | `S`, `A`, `B`, `C` 중 하나 (S가 최고) |
| **점수** | 0~100점 (85점 이상이면 S등급) |
| **매칭 사유** | AI가 왜 이 등급을 줬는지 설명 |

> 💡 **등급 의미:**
> - **S등급** (85점 이상): 즉시 연락 권장! 조건이 아주 잘 맞습니다.
> - **A등급** (70~84점): 높은 적합도. 적극 검토 대상입니다.
> - **B등급** (50~69점): 참고 가능. 조건이 일부만 맞습니다.
> - **C등급** (50점 미만): 부적합. 조건이 안 맞습니다.

**③ AI 매칭 센터에서 전체 확인**

- 왼쪽 메뉴에서 **"AI 매칭 센터"** 를 클릭합니다.
- 주소창에 `credeal.net/broker/matching` 이 보입니다.
- 여기서 모든 매칭 결과를 한눈에 볼 수 있습니다.
- **등급 필터 (S/A/B/C)** 를 클릭하면 원하는 등급만 걸러서 볼 수 있습니다.

## 실습 5: 다양한 매수의향으로 매칭 차이 체험하기

### 📝 무엇을 하나요?
조건이 다른 매수의향을 추가로 등록해서, AI 매칭 등급이 어떻게 달라지는지 직접 비교합니다.

### 5-A: 지역 불일치 매수의향 (C등급 예상)

아래 내용으로 새 매수의향을 만들어 보세요:

```
개인 매수자, 예산 50~80억.
마포·홍대·합정 권역 꼬마빌딩 선호.
임대수익형 투자 목적.
수익률 5% 이상 기대.
```

> **예상 결과:** 역삼동 매물과 매칭하면 **C등급**이 나옵니다. 이유: 매수자가 원하는 지역(마포)과 매물 위치(역삼)가 다르기 때문입니다.

### 5-B: 예산 부족 매수의향 (C등급 예상)

```
개인 매수자, 예산 20~30억.
강남 권역 꼬마빌딩 선호.
사옥용 자가사용 목적.
```

> **예상 결과:** **C등급**. 이유: 매물 가격이 80억인데 매수자 예산이 30억이라 맞지 않습니다.

### 5-C: 개발형 매수의향 (B등급 예상)

```
디벨로퍼 법인, 예산 70~120억.
강남·서초 권역 토지 또는 노후 건물 선호.
철거 후 신축 개발 목적. 공실 또는 명도 가능 매물 선호.
필수조건: 단독소유, 대지 100평 이상.
리스크 허용도: 공격적.
```

> **예상 결과:** **B 또는 C등급**. 이유: 지역과 예산은 맞지만, 만실 매물을 개발 목적으로 사려면 목적이 안 맞습니다.

### 5-D: 증여/상속형 매수의향

```
자산가 가족 법인, 예산 50~80억.
서초·강남 권역 근린생활시설 선호.
증여·상속 세무 전략 목적.
안정적 임대 수익보다 세무 효율성 우선.
```

> **예상 결과:** AI가 `증여` 전용 가중치를 적용하여 매칭합니다. 세무 효율 관점에서 평가하므로 일반적인 임대수익형과 다른 점수가 나옵니다.

### 결과 비교

등록 후 딜카드 상세 페이지의 "매칭된 매수자" 섹션에서 다양한 등급의 매칭 결과를 비교해 보세요:

| 매수의향 | 지역 | 예산 | 목적 | 예상 등급 |
|---------|------|------|------|----------|
| 실습 3 (법인 임대수익) | 강남 ✅ | 60~100억 ✅ | 임대수익 ✅ | **S/A** |
| 5-A (마포 선호) | 마포 ❌ | 50~80억 ✅ | 임대수익 ✅ | **C** |
| 5-B (예산 부족) | 강남 ✅ | 20~30억 ❌ | 사옥 ⚠️ | **C** |
| 5-C (개발형) | 강남 ✅ | 70~120억 ✅ | 개발 ⚠️ | **B/C** |
| 5-D (증여형) | 강남 ✅ | 50~80억 ✅ | 증여 🔄 | **등급 확인** |

> 💡 **핵심 교훈:** AI 매칭은 **지역**, **예산**, **자산유형**, **매수목적**을 종합적으로 판단합니다. 하나라도 크게 어긋나면 낮은 등급이 나옵니다.

## 🎓 Part 1 정리

| 배운 내용 | 핵심 |
|----------|------|
| 딜카드 만들기 | 메모 붙여넣기 → AI 분석 → 저장 |
| 매수자 페르소나 | AI가 매물에 맞는 매수자 유형 3가지 추천 |
| 매수의향 등록 | 매수 조건 메모 → AI 정규화 → 저장 |
| AI 자동 매칭 | 딜카드/매수의향 저장 시 자동 매칭 시작 |
| 매칭 등급 | S(최고) → A(높음) → B(보통) → C(부적합) |
| 매칭 요소 | 지역, 예산, 자산유형, 매수목적 종합 판단 |
