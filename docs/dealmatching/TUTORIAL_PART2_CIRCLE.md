# 📘 따라하기 튜토리얼 Part 2 — 서클(공동중개 팀) 만들고 함께 매칭하기

> **대상:** 제이에스부동산중개(주) 소속 중개사님  
> **소요시간:** 약 25분  
> **준비물:** Part 1 완료 (딜카드 + 매수의향 등록 완료), 함께 할 중개사님 1분  
> **목표:** 다른 중개사님과 '서클'을 만들어 매물/매수의향을 공유하고, AI가 자동으로 교차 매칭을 해주는 과정을 체험합니다.

---

## 🎯 이 튜토리얼에서 배우는 것

1. **서클(공동중개 팀)** 만들기
2. 다른 중개사님을 **초대 링크**로 서클에 초대하기
3. 서클에 **매물과 매수의향을 공유**하기
4. AI가 서클 안에서 **교차 매칭**을 자동으로 해주는 과정 이해하기
5. **양측 승인** 후 공동중개 딜이 자동 생성되는 과정 이해하기
6. **프로그레시브 디스클로저**: 단계별로 정보가 공개되는 보안 체계

---

## 📌 시작하기 전에

### 이 실습에서 쓰는 역할

| 역할 | 설명 | 보유 자산 |
|------|------|----------|
| **대표님 (브로커 A)** | 매물을 보유한 중개사 | Part 1에서 만든 역삼동 80억 딜카드 |
| **파트너 중개사 (브로커 B)** | 매수자를 보유한 중개사 | Part 1에서 만든 법인 매수의향 (60~100억) |

> 💡 **혼자 실습하시는 경우:** 브라우저 2개(크롬 + 시크릿 모드)를 열어서 각각 다른 계정으로 로그인하시면 혼자서도 양쪽 역할을 할 수 있습니다.

## 실습 1: 서클 만들기

### 📝 무엇을 하나요?
같은 지역, 같은 관심사를 가진 중개사님들과 매물/매수자를 안전하게 공유하는 '팀(서클)'을 만듭니다.

### 따라하기 (브로커 A = 대표님)

**① 서클 페이지로 이동**

- 왼쪽 메뉴에서 **"서클"** 을 찾아 클릭합니다.
- 서클 대시보드가 표시됩니다.

**② 새 서클 만들기**

- **"새 서클 만들기"** 버튼을 클릭합니다.
- 주소창에 `credeal.net/broker/circles/new` 가 보입니다.

**③ 서클 정보 입력**

| 입력란 | 입력할 내용 |
|--------|-----------|
| **서클 이름** | `강남 꼬마빌딩 공동중개팀` |
| **서클 설명** | `강남·서초 권역 꼬마빌딩 매물과 매수자를 공유하는 팀입니다.` |

**④ 생성 버튼 클릭**

- **"생성"** 버튼을 클릭합니다.
- 서클 상세 페이지로 이동합니다.
- 멤버 목록에 **대표님 1명**이 보입니다.

> ✅ **확인:** 서클 이름이 "강남 꼬마빌딩 공동중개팀"으로 표시되고, 멤버가 1명이면 성공입니다.

---

## 실습 2: 파트너 중개사 초대하기

### 📝 무엇을 하나요?
서클에 함께 일할 중개사님을 초대 링크로 초대합니다.

### 따라하기 (브로커 A = 대표님)

**① 멤버 초대 버튼 클릭**

- 서클 상세 페이지에서 **"멤버 초대"** 버튼을 클릭합니다.
- 초대 시트가 화면 아래에서 올라옵니다.

**② 초대 링크 생성**

- **"초대 링크 생성"** 을 클릭합니다.
- 링크가 생성됩니다. 예: `credeal.net/broker/circles/join?token=abc123...`

**③ 링크 복사 & 전달**

- **"링크 복사"** 버튼을 클릭합니다.
- 이 링크를 **카카오톡, 문자, 이메일** 등으로 파트너 중개사님에게 보내주세요.

> 💡 **보안:** 초대 링크는 일회용이며, 해당 서클에만 가입할 수 있습니다.

### 따라하기 (브로커 B = 파트너 중개사)

**④ 초대 링크 클릭**

- 전달받은 링크를 브라우저에 붙여넣습니다.
- 로그인되어 있지 않으면 먼저 로그인합니다.
- 서클 정보(이름, 설명)가 표시됩니다.

**⑤ 가입하기**

- **"가입하기"** 버튼을 클릭합니다.
- 서클 상세 페이지로 이동합니다.
- 멤버 목록에 **2명**(대표님 + 파트너 중개사)이 보입니다.

> ✅ **확인:** 양쪽 모두 서클 상세 페이지에서 멤버 2명이 보이면 성공입니다.

## 실습 3: 서클에 매물 공유하기

### 📝 무엇을 하나요?
내 딜카드(매물)를 서클 멤버들에게 공유합니다. 처음에는 최소한의 정보만 공개됩니다.

### 따라하기 (브로커 A = 매물 보유 중개사)

**① 딜카드 상세 페이지로 이동**

- Part 1에서 만든 **역삼동 80억 꼬마빌딩** 딜카드를 열어주세요.

**② 서클에 공유 클릭**

- 딜카드 상세 페이지에서 **액션 메뉴** (⋯ 또는 점 세 개 메뉴)를 클릭합니다.
- **"서클에 공유"** 를 선택합니다.
- 가입한 서클 목록이 나타납니다.

**③ 서클 선택 → 공유**

- **"강남 꼬마빌딩 공동중개팀"** 을 선택(체크)합니다.
- **"공유"** 버튼을 클릭합니다.
- "공유 완료" 메시지가 나타납니다.

**④ 파트너 중개사 관점에서 확인 (브로커 B)**

- 파트너 중개사가 서클 상세 → **"공유 자산"** 탭을 열어봅니다.
- 매물이 보이지만, **최소 정보만** 표시됩니다:

| 보이는 정보 ✅ | 보이지 않는 정보 ❌ |
|--------------|------------------|
| 지역: 역삼동 | 상세 주소 |
| 자산유형: 꼬마빌딩 | 소유자 정보 |
| 가격대: 80억대 | 적합성/주의사항 요약 |

> 💡 **이것이 "시그널 온리" 모드입니다.** 매칭이 잘 되면 단계별로 더 많은 정보가 공개됩니다. 매수자 신원을 보호하면서도 매칭 기회를 놓치지 않는 안전 장치입니다.

---

## 실습 4: 서클에 매수의향 공유하기

### 따라하기 (브로커 B = 매수자 보유 중개사)

**① 매수의향 상세 페이지로 이동**

- Part 1에서 만든 **법인 60~100억 임대수익형** 매수의향을 열어주세요.

**② 서클에 공유**

- 액션 메뉴 → **"서클에 공유"** → 서클 선택 → **"공유"** 클릭
- 공유 완료!

**③ 대표님 관점에서 확인 (브로커 A)**

- 서클 상세 → 공유 자산 탭: 이제 **매물 1건 + 매수의향 1건**이 보입니다.
- 매수의향도 최소 정보만 보입니다:

| 보이는 정보 ✅ | 보이지 않는 정보 ❌ |
|--------------|------------------|
| 예산: 60~100억 | 매수자 이름/연락처 |
| 선호 지역: 강남·서초 | 매수자 유형 상세 |
| 자산 유형: 꼬마빌딩 | 필수조건, 리스크 허용도 |

> ⚠️ **이 순간!** 매수의향이 공유되면 AI가 자동으로 서클 안의 매물과 매수의향을 교차 매칭합니다.

---

## 실습 5: AI 교차 매칭 결과 확인하기

### 📝 무엇을 하나요?
AI가 서클 안에서 매물과 매수의향을 자동으로 비교한 결과를 확인합니다.

### 따라하기

**① 30초 정도 기다립니다**

- AI가 백그라운드에서 교차 매칭을 진행합니다.

**② 서클 상세 → "매칭 결과" 탭**

- 서클 상세 페이지에서 **"매칭 결과"** 탭을 클릭합니다.
- 매칭 결과 카드가 표시됩니다.

**③ 결과 확인**

| 항목 | 기대 결과 |
|------|----------|
| **등급** | S 또는 A (역삼 80억 × 강남 60~100억 = 조건 일치) |
| **매물측 브로커** | 대표님 (브로커 A) |
| **매수측 브로커** | 파트너 중개사 (브로커 B) |
| **점수** | 70점 이상 |

> 🔔 **알림:** 양쪽 모두에게 **"⚡ 서클 S등급 팀 매칭 발견!"** 알림이 옵니다.

**④ 정보 업그레이드 확인**

S/A 등급 매칭이 발생하면, 공유된 자산의 공개 수준이 자동으로 한 단계 올라갑니다:

| 매물 — 추가로 보이는 정보 | 매수의향 — 추가로 보이는 정보 |
|------------------------|--------------------------|
| + 규모 (85평/320평) | + 매수자 유형 (법인) |
| + 공실 상태 (만실) | + 매수 목적 (임대수익) |
| + 적합성 요약 | + 필수조건 |

## 실습 6: 전체 매칭 수동 실행

### 📝 무엇을 하나요?
서클 안의 모든 매물과 매수의향을 한꺼번에 매칭합니다.

### 따라하기

**① 서클 상세 페이지에서 "전체 매칭 실행" 클릭**

- **"전체 매칭 실행"** 버튼이 있으면 클릭합니다.
- 서클 안의 공유된 매물 전부 × 매수의향 전부를 AI가 한꺼번에 매칭합니다.

**② 결과 확인**

- `S등급 N건, A등급 N건` 같은 요약이 표시됩니다.
- 매칭 결과 탭에서 등급별로 필터링할 수 있습니다.

> 💡 **팁:** "내 매칭만" 토글을 켜면 내가 관련된 매칭만 볼 수 있습니다.

## 실습 7: 양측 승인 → 신원 공개 → 공동중개

### 📝 무엇을 하나요?
S등급 매칭이 나오면, 양쪽 중개사가 모두 승인해야 매수자/매물 상세 정보가 공개됩니다. 이것이 공동중개의 시작입니다.

### 🔐 왜 양측 승인이 필요한가요?
매수자 정보는 중요한 고객 정보입니다. 한쪽이 마음대로 공개하면 안 되기 때문에, **양쪽 모두 동의해야** 정보가 공개되는 안전 장치가 있습니다.

### 따라하기 — 1단계: 한쪽 먼저 승인 (브로커 A)

**① S등급 매칭 카드 클릭**

- 서클 매칭 결과에서 S등급 카드를 클릭합니다.
- 매칭 상세 정보가 나타납니다.

**② "신원 공개 승인" 클릭**

- **"신원 공개 승인"** 버튼을 클릭합니다.
- 확인 다이얼로그가 나타납니다.
- **"승인"** 을 클릭합니다.

**③ 상태 확인**

| 항목 | 상태 |
|------|------|
| 대표님 승인 | ✅ 완료 |
| 파트너 승인 | ⏳ 대기 중 |
| 신원 공개 | ❌ 아직 안 됨 |

> 🔔 파트너 중개사에게 **"🔒 매칭 승인 요청 — 상대 중개사가 신원 공개를 승인했습니다"** 알림이 갑니다.

### 따라하기 — 2단계: 상대방도 승인 (브로커 B)

**④ 파트너 중개사가 매칭 카드 → "신원 공개 승인" 클릭**

- 알림을 클릭하거나, 서클 매칭 결과에서 해당 카드를 열어서 승인합니다.

**⑤ 양측 승인 완료! 🎉**

이제 정보가 완전히 공개됩니다:

| 매물 — 전체 공개 ✅ | 매수의향 — 전체 공개 ✅ |
|--------------------|---------------------|
| 모든 SSoT Lite 상세 | 매수자 유형, 예산, 목적 전체 |
| 적합성/주의사항 요약 | 필수조건, 리스크 허용도 |

**⑥ 공동중개 딜 자동 생성**

- 양측에게 **"🤝 자동 공동중개 파이프라인 생성!"** 알림이 갑니다.
- 왼쪽 메뉴 → **"파이프라인"** 에서 확인하면, 새로운 공동중개 딜이 자동으로 생성되어 있습니다.
- 이제 양쪽이 협력하여 매수자 미팅, 계약 등을 진행할 수 있습니다.

## 실습 8: 정보 공개 3단계 정리

### 📝 프로그레시브 디스클로저란?
처음에는 최소 정보만 보여주고, 매칭이 잘 될수록 단계별로 더 많은 정보를 공개하는 보안 체계입니다.

| 단계 | 이름 | 언제? | 공개 수준 |
|------|------|------|----------|
| 1단계 | **시그널 온리** | 처음 공유 시 | 지역·자산유형·가격대만 |
| 2단계 | **기본 정보** | S/A등급 매칭 발생 시 | + 규모, 공실, 매수목적 등 |
| 3단계 | **전체 공개** | 양측 승인 완료 시 | 모든 상세 정보 |

> 🔒 **중요:** 한번 올라간 공개 수준은 다시 내려갈 수 없습니다. 정보 보안을 위해 "다운그레이드 불가" 규칙이 적용됩니다.

## 실습 9: 서클 관리하기

### 9-A: 공유 해제

- 서클 → 공유 자산에서 내가 공유한 매물의 **"공유 해제"** 를 클릭하면, 해당 매물의 공유가 취소됩니다.
- 이미 생성된 매칭 결과는 유지되지만, 새로운 매칭은 더 이상 발생하지 않습니다.

### 9-B: 서클 탈퇴

- 서클 상세 페이지에서 **"서클 탈퇴"** 를 클릭하면 서클에서 나갈 수 있습니다.
- 탈퇴 후에는 해당 서클의 매칭 결과를 볼 수 없습니다.

### 9-C: 미승인 자동 만료 (7일)

- S등급 매칭이 발생했는데 **7일 동안 양측 모두 승인하지 않으면**, 해당 매칭은 자동으로 만료됩니다.
- 만료된 매칭은 더 이상 승인할 수 없습니다.
- 필요하면 "전체 매칭 실행"으로 다시 매칭을 돌릴 수 있습니다.

> ⏰ **팁:** S등급 매칭 알림이 오면 빨리 확인하고 승인하세요! 7일이 지나면 기회가 사라집니다.
