# 제1부. 먼저 이해해야 할 것

## 0. 이 백서의 결론

### 0.1 좋은 소형 부동산 매각안내서와 투자검토서란

좋은 문서는 페이지가 많거나 수익률이 화려한 문서가 아니다. 매수자가 짧은 시간 안에 다음 다섯 질문에 답할 수 있는 문서다.

1. 정확히 무엇을 사는가?
2. 얼마이며 그 가격은 어떤 기준인가?
3. 현재 무엇이 확인됐는가?
4. 무엇이 틀릴 수 있는가?
5. 다음에 무엇을 확인하고 어떤 조건으로 협상해야 하는가?

> **핵심 원칙:** 없는 정보를 전문가처럼 채우지 말고, 확인된 범위에서 가장 유용한 의사결정자료를 만든다.

### 0.2 표준 목표

중개인 단독 작성의 기본 목표는 `중개인 제안형 매각제안서`다. 임대차·가격·시장자료가 충분하면 `표준 검토형 매각안내서`로 확장한다.

- 공부와 공공자료는 시스템이 최대한 자동 수집한다.
- 중개인은 매각범위·현장·매도인 자료·시장판단을 확인한다.
- 실제 운영비(Operating Expenses, OPEX)가 없으면 순영업소득(Net Operating Income, NOI)과 자본환원율(Capitalization Rate, Cap Rate)을 만들지 않는다.
- 계약서가 없으면 계약확인이라고 쓰지 않는다.
- 자료가 부족하면 현재 가능한 낮은 등급으로 먼저 발행한다.
- 자료가 보완되면 이전 문서를 덮어쓰지 않고 새 버전으로 승급한다.

### 0.3 구현 원칙

긴 장기모델을 한꺼번에 구현하지 않는다.

- 지금 확인된 오표현 방화벽부터 적용한다.
- 1차 구현은 일반건물·나대지와 수익현황·가치개선(Value-add)·개발검토만 다룬다.
- 매수자 검토조건·사업포함 거래·특수자산은 실증 전 보류한다.
- 신규 정책 정본은 최대 두 개다.
- 임계값은 검증 전 `잠정`이다.

### 0.4 이 백서의 언어 원칙

외부 문서와 중개인 입력화면에서는 D56의 한국어 권장어를 사용한다. 이 백서에서는 국제적으로 통용되는 전문용어가 처음 정식으로 정의될 때만 한글 뒤 괄호 안에 영문명과 필요한 경우 약어를 병기한다. 이후에는 한글 표준어를 사용한다.

예를 들어 이 백서에서 임대차 현황표(Rent Roll)를 처음 설명할 때만 영문을 병기하고, 이후 본문과 매수자용 문서에서는 `임대차 현황표`로 쓴다.

| 사용 위치 | 표기 원칙 | 예 |
|---|---|---|
| 매수자용 문서 | 한국어 표준어 | `임대차 현황표`, `가격 수준 검토` |
| 중개인 입력화면 | 한국어 + 현장 동의어 검색 | `월 기본임대료(월세)` |
| 관리자 화면 | 한국어 상태명 + 내부코드 병기 가능 | `사용차단(BLOCKED)` |
| 데이터베이스·API | 기존 영문 키 유지 가능 | `monthly_base_rent` |

`골디락스`, `클레임`, `에비던스`, `게이트`, `렌즈`, `스냅샷`, `포스처`는 외부 문서 제목과 사용자 안내문에 쓰지 않는다. 이 백서에서 내부코드를 제시하는 코드 블록은 구현 호환성을 위해 영문 키를 유지한다.

영문 병기는 교육·개발 문서인 이 백서에만 적용한다. 실제 매수자용 매각안내서·매각제안서에는 영문을 반복 병기하지 않는다. 공부·건축물대장·토지이용계획확인서·채권최고액처럼 대한민국 법정·실무 의미가 중심인 용어는 억지로 영문화하지 않는다.

### 0.5 v1.1 개정사항

- 모든 단계명과 장 제목을 D56 한국어 권장어로 통일했다.
- 임대차 자료등급과 정보 상세도를 분리하고, 자료 없음·미제공·해당없음을 구분했다.
- 가격·면적·임대료·수익률·거리의 표기 꼬리표와 금지표현을 추가했다.
- 비교사례를 실거래사례·매물사례·임대사례로 나눴다.
- 가치개선·개발검토를 현재 사실이 아닌 실행방안과 분석가정으로 표시하도록 강화했다.
- AI 금지규칙을 가격·임대차·등기·개발·비교사례·과장표현까지 확대했다.
- 개발용 내부코드는 코드 블록에 유지하되 외부 문서와 중개인 화면에는 한국어만 표시하도록 했다.

### 0.6 v1.2 개정사항 — 안전하지만 읽히지 않는 문서 방지

v1.1은 오표현 차단과 근거관리에는 강하지만, 안전규칙이 중개인의 매각 논리를 지우거나 내부 심사보고서 문체를 만들 수 있다는 문제가 있었다. v1.2는 다음을 추가한다.

- 중개인 매각논리의 원문·정규화문·최종문구·반영면을 연결하는 `중개인 의견 기록`
- 외부 문서에서 내부 등급명·정책용어·가상값 안내를 감추는 노출규칙
- 한국 소형 상업용 부동산 중개인이 실제 사용하는 제목·본문 문장 계약
- 매물 장점과 확인사항의 화면 위계를 분리하는 규칙
- 사실 정확성뿐 아니라 매물 설명력·자연스러움·문의 유도력을 검사하는 독자품질검사
- 당산동 사례의 중개인 입력 반영표와 외부용 카피 예시

> **두 축 원칙:** `사실 정확성`과 `매물 설명력` 중 하나라도 부족하면 좋은 매각안내서가 아니다.

### 0.7 v1.3 개정사항 — 중개인의 실제 기본형과 사진 근거화

- L1과 L2 사이에 L1.5 중개인 제안형 매각제안서를 추가했다.
- L1.5를 임대·시장 분석이 부족한 문서가 아니라 중개인의 현장지식과 매각논리를 중심으로 하는 독립 기본형으로 정의했다.
- 실무 기본 골디락스는 L1.5, 임대·가격·시장 검토가 가능한 분석 확장형은 L2로 구분했다.
- 물건 개요 옆 대표 외관사진을 기본으로 하고 사진을 관련 주장 가까이에 분산 배치하도록 했다.
- 사진수·품질·역할에 따라 페이지를 조절하며 독립 현장사진 페이지를 선택사항으로 바꿨다.
- 한국어 전문용어의 최초 정의에만 통용 영문명·약어를 병기하도록 했다.

## 1. 매각안내서와 투자검토서는 무엇이 다른가

### 1.1 매각안내서

매각안내서(Offering Memorandum, OM)는 매도 대상과 거래조건을 알리는 자료다. 소형 부동산에서는 다음 역할을 한다.

- 물건과 매각범위를 정확히 알린다.
- 공부·현장·매도인 제시정보를 한곳에 모은다.
- 가격·임대차 현황·위험요인을 빠르게 이해시킨다.
- 문의·현장답사·추가자료 요청을 유도한다.

매각안내서는 최종 실사(Due Diligence, DD) 보고서가 아니다. 그러나 ‘광고물’이라는 이유로 틀린 숫자를 허용해서도 안 된다.

### 1.2 매각제안서

매각제안서는 매각안내서의 확인된 사실에 담당 중개인의 추천과 활용 제안을 더한 문서다. 매수자에게 단순히 “무엇을 파는가”뿐 아니라 “왜 검토할 만하고 누구에게 적합한가”를 설명한다.

- 중개인이 확인한 현장 장점과 가격·입지 판단을 표시한다.
- 각 의견을 사실·사진·현장관찰과 연결한다.
- 적합한 매수자와 활용방향을 제시한다.
- 의견의 성립조건과 추가 확인사항을 짧게 붙인다.

매각제안서는 투자수익을 보장하거나 법률·세무·건축 가능성을 확정하는 투자자문서가 아니다.

### 1.3 투자검토서

투자검토서(Investment Memorandum, IM)는 매각안내서보다 한 단계 더 나아가 다음을 설명한다.

- 현재 수익이 어떻게 구성되는가
- 임대차 만기·공실·시장임대료가 무엇을 의미하는가
- 어떤 개선행위가 가능한가
- 가격이 비교사례·수익과 어떤 관계인가
- 무엇을 실사하고 계약조건에 반영해야 하는가

### 1.4 중개인형 투자검토서의 경계

중개인은 다음을 할 수 있다.

- 비교사례의 실무적 유사성 판단
- 현장 사용·가시성·접근·주차 관찰
- 임대료 수준·공실원인·목표업종에 대한 시장의견
- 자료요청·현장실사·협상조건 제안

중개인이 확정해서는 안 되는 것은 다음과 같다.

- 권리의 법적 유효성과 우선순위
- 실제 건축·용도변경 허가 가능성
- 구조·소방·설비의 적합성
- 세금·대출·감정가의 확정값
- 공사비와 투자수익 보장

## 2. 발행등급

| 등급 | 명칭 | 독자 질문 | 허용내용 |
|---|---|---|---|
| L0 | 내부검토본 | 무엇이 빠지고 서로 맞지 않는가 | 내부 점검·자료요청 |
| L1 | 사실확인형 매각안내서 | 무엇을 얼마에 파는가 | 공부·가격·현장·현재상태 |
| L1.5 | 중개인 제안형 매각제안서 | 왜 검토할 만하며 누구에게 맞는가 | L1 + 근거 있는 중개인 추천·활용방안 |
| L2 | 표준 검토형 매각안내서 | 검토·답사할 가치가 있는가 | L1.5 + 허용 임대·가격·시장·위험·실사 |
| L3 | 중개분석형 투자검토서 | 어떻게 개선·협상할 수 있는가 | 만기·비교·실행방안·승인 시나리오 |
| L4 | 전문가 협업형 투자검토서 | 최종 투심이 가능한가 | 쟁점별 전문가 검토 |

### 2.1 L1이 부실문서라는 뜻은 아니다

임대차 현황표가 없거나 중대한 불일치가 남은 물건은 L1이 정직한 결과다. 빈칸을 추정해 L2로 보이게 만드는 것이 더 낮은 품질이다.

### 2.2 L1.5가 실무 기본형인 이유

L1.5는 축소된 L2가 아니다. 주소·공부·현장·최소 임대정보와 중개인 의견으로 만들 수 있으며, 다음 질문에 답한다.

- 담당 중개인이 이 매물을 추천하는 이유는 무엇인가
- 확인된 사실이 그 추천을 어떻게 뒷받침하는가
- 어떤 매수자와 활용방향에 적합한가
- 추천이 성립하려면 무엇을 추가 확인해야 하는가

임대수익률·조정 비교사례·미래 시나리오는 L1.5의 필수요건이 아니다. 중개인 의견의 근거와 공개승인이 없으면 L1로 발행하고, 임대·가격·시장 묶음이 충족되면 L2로 승급한다.

### 2.3 L3가 항상 더 좋은 것은 아니다

운영비·계약·시장자료가 없는 L3는 가정이 많은 문서일 뿐이다. 허용 산출항목이 없으면 해당 분석페이지를 만들지 않는다.

## 3. 초심자 핵심용어

| 용어 | 쉬운 뜻 | 주의 |
|---|---|---|
| 공부(公簿) | 국가·지자체가 관리하는 토지·건물 공식자료 | 실제 사용과 다를 수 있음 |
| 임대차 현황표 | 층·호실별 임차인·임대차보증금·월 기본임대료·월 관리비 현황표 | 계약서·입금자료와 같지 않음 |
| 기준일 | 그 정보가 유효하다고 보는 날짜 | 파일 받은 날짜와 다름 |
| 임대차보증금 | 임차인이 맡긴 반환의무가 있는 돈 | 매도 희망가·매매계약금과 분리 |
| 관리비 | 임차인에게 청구하는 비용 | 전부 임대인 수익이 아님 |
| 단순 임대수익률(Gross Rental Yield) | 연 기본임대료 등을 가격으로 나눈 비용 차감 전 지표 | 순영업소득 기준 자본환원율이 아님 |
| 유효총수입(Effective Gross Income, EGI) | 공실·연체 등을 반영한 유효총수입 | 근거가 필요 |
| 운영비 | 임대운영에 반복적으로 발생하는 비용 | 자본적 지출(Capital Expenditure, CAPEX)과 구분 |
| 순영업소득 | 운영비를 차감한 순영업소득 | 실제 운영비 없으면 금지 |
| 자본환원율 | 순영업소득을 가격 또는 가치로 나눈 수익률 | 단순 임대수익률과 구분 |
| 가중평균 잔여 임대차기간(Weighted Average Lease Expiry, WALE) | 임대료·면적으로 가중한 평균 잔여기간 | 계약기간 완비 필요 |
| 실사 | 매입 전 권리·물리·임대·수입 등을 확인하는 절차 | 확인주체와 범위를 구체화 |
| 매입의향서(Letter of Intent, LOI) | 주요 매입조건을 제시하는 문서 | 매매계약과 구분 |
| 가치개선 | 임대·공간·운영 개선으로 자산가치를 높이는 접근 | 확정 수익으로 표현 금지 |
| 자본적 지출 | 장기 효익을 위한 시설·공사 투자 | 반복 운영비와 구분 |
| 매수인 요구조건(Buyer Mandate) | 매수자의 예산·용도·수익·기간 등 검토조건 | 일반 공개 매각자료와 구분 |
| 산출항목 | 문서가 외부에 말하려는 사실·계산·판단 | 전제를 충족해야 허용 |
| 근거자료 | 산출항목을 뒷받침하는 원본·자료·관찰 | 위치·기준일 필요 |
| 불일치 | 같은 항목에 서로 양립하기 어려운 값이 존재하는 상태 | 임의로 유리한 값을 선택하면 안 됨 |
| 분석가정 | 미래 분석을 위한 가정 | 사실 핵심지표와 분리 |
| 발행검사 | 산출항목·등급·발행을 허용·차단하는 규칙 | 실행되지 않으면 통과가 아님 |

## 4. 14대 원칙

1. **매각범위를 먼저 확정한다.** 주소 하나가 거래대상 전체라는 보장은 없다.
2. **원본을 덮어쓰지 않는다.** 틀린 입력도 관측기록으로 남긴다.
3. **공란은 0이 아니다.** 모름과 없음은 다르다.
4. **상세함과 신뢰도를 혼동하지 않는다.** 매도인 C3 자료도 미검증일 수 있다.
5. **산출항목마다 전제를 둔다.** 등급 하나로 모든 수치를 열지 않는다.
6. **단순 임대수익률과 순영업소득 기준 자본환원율을 분리한다.** 지표명과 산식을 함께 쓴다.
7. **관리비 청구액은 순수익이 아니다.** 수납·지출을 함께 확인한다.
8. **채권최고액은 대출잔액이 아니다.** 등기상 사실만 표시한다.
9. **의견을 사실로 계산하지 않는다.** 승인된 분석가정만 시나리오에 사용한다.
10. **검토관점은 정확성규칙을 완화하지 않는다.** 설명의 강조점과 사실의 사용허가는 별개다.
11. **자료가 없으면 빈 페이지를 만들지 않는다.** 확인사항으로 전환한다.
12. **현재 가능한 문서를 먼저 발행한다.** 보완 후 새 버전으로 승급한다.
13. **중개인 의견을 근거와 함께 보존한다.** 사실·현장관찰·사진과 연결되지 않은 의견은 L1.5 외부문구로 쓰지 않는다.
14. **사진은 주장 가까이에 둔다.** 사용 가능한 대표 외관은 물건 개요에 배치하고, 사진 부족을 가상 이미지로 채우지 않는다.

# 제2부. 어떤 자료를 어떻게 준비하는가

## 5. 역할분담

### 5.1 시스템이 할 일

- 주소·지번·토지 고유번호(PNU) 후보 찾기
- 건축물대장·토지·규제 자료 조회
- 단위·날짜·금액 표기 통일
- 행합계·요약·면적·기준일 불일치 탐지
- 계산·산출항목·발행검사 실행
- 출처·위험·확인사항 조립

### 5.2 중개인이 할 일

- 실제 매각대상 확인
- 현장사진·실제 사용·공실 확인
- 매도인 자료의 기준일 확인
- 비교사례·시장판단 승인
- 미확인·공개범위·최종문구 승인

### 5.3 매도인에게 받을 것

- 매도 희망가격·일정·포함범위
- 최신 임대차 현황표와 기준일
- 알려진 공실·연체·만료·분쟁
- 관리비 처리
- 거래단계에 따른 계약·수납·운영비 자료

### 5.4 전문가에게 넘길 것

‘전문가 검토 필요’라고만 쓰지 않는다. 질문을 구체적으로 넘긴다.

나쁜 예:

> 건축사 확인 필요

좋은 예:

> 3필지 중 진입로 역할 필지의 대지 편입 여부와 법정도로 조건이 실제 건축가능 연면적에 미치는 영향을 확인해 주십시오.

## 6. 최소 입력자료

### 6.1 L1 필수

- 도로명·지번 주소
- 매각대상 필지·건물
- 매도 희망가격
- 토지·건물 핵심 공부
- 작성 기준일
- 외관·접근 사진 또는 미제공 상태
- 실제 사용상태
- 알려진 위험·미확인
- 중개인·사무소·연락처

### 6.2 L1.5 추가

- 중개인 추천 포인트 1건 이상, 권장 3~5건
- 추천 이유를 뒷받침하는 사실·현장관찰·사진
- 적합한 매수자 또는 활용방향
- 의견의 성립조건·추가 확인사항
- 중개인 원문·외부문구·반영면·공개승인
- 대표 외관사진 지정과 사진별 외부공개 승인

### 6.3 L2 추가

- 층·호실별 사용현황·임대차 현황 또는 임대 해당없음
- 임대차보증금·월 기본임대료·월 관리비의 산정기준
- 시장사례 또는 구조화된 중개인의견
- 가격 산정기준
- 매수 검토논거·반대근거
- 구체적 실사·자료요청·매입의향서 조건

### 6.4 L3 추가

- 계약기간·만기·인상·해지
- 임대료·매매 비교사례
- 실행방안 카드
- 승인된 비용·기간·임대 가정
- 운영비가 필요한 산출항목이면 실제 운영비

## 7. 수집경로와 정보영역

### 7.1 수집경로

| 코드 | 경로 | 예 |
|---|---|---|
| S-A | 공부·공공시스템 | 대장·토지이용·공시지가 |
| S-B | 현장 | 사진·점유·주차·외관 |
| S-C | 매도인 진술 | 가격·임대차 현황표·공실 설명 |
| S-D | 원본 문서 | 계약서·입금자료·운영비 |
| S-E | 시장 | 실거래·임대사례·중개경험 |
| S-F | 전문가 | 법률·세무·건축·감정·기술 |

수집경로는 누가 채울지 정한다. 산출항목을 직접 허가하지 않는다.

### 7.2 정보영역

| 코드 | 영역 | 핵심질문 |
|---|---|---|
| D-ID | 자산식별 | 무엇을 파는가 |
| D-LD | 토지·계획 | 필지·면적·용도지역·도로는 무엇인가 |
| D-BL | 건물·물리 | 어떤 건물이며 실제 상태는 어떠한가 |
| D-RT | 권리·제약 | 알려진 권리·신탁·위반·분쟁은 무엇인가 |
| D-RR | 사용·임대 | 누가 어디를 어떤 조건으로 쓰는가 |
| D-OP | 운영·비용 | 운영비·수선비·자본적 지출이 무엇인가 |
| D-MK | 시장 | 무엇과 비교할 수 있는가 |
| D-TX | 거래조건 | 가격·일정·명도·협상조건은 무엇인가 |
| D-BJ | 중개판단 | 왜 검토하고 무엇을 해야 하는가 |

한 값은 한 정보영역에 속하되 여러 수집경로의 근거자료를 가질 수 있다.

### 7.3 수집준비도는 자료요청 배정용이다

| 경로 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| S-A 공부 | 주소만 | 대표 토지·건물 | 포함필지·건물 핵심공부 | 관련지번·집합·위반·규제 대조 |
| S-B 현장 | 없음 | 외관·접근 | 층별 사용·공실·주차 | 상태·설비·동선 기록 |
| S-C 진술 | 총액만 | 호실·임대차보증금·월 기본임대료 | 면적·기간·월 관리비 | 운영비·특약·연체 |
| S-D 원본 | 없음 | 주요 계약 일부 | 핵심 계약·고지 | 수납·세금·운영원장 |
| S-E 시장 | 없음 | 구조화 의견 | 식별 사례·채택이유 | 조정 비교그리드 |
| S-F 전문가 | 없음 | 특정 쟁점 의견 | 정식 보고서 | 다분야 통합검토 |

이 표는 누구에게 무엇을 요청할지 보여 주는 진단표다. `S-C3`이라고 계약확인 산출항목을 허용하거나 `S-F1`이라고 L4를 자동 허용하지 않는다.

## 8. 근거수준과 상태

### 8.1 근거수준

| 등급 | 의미 |
|---|---|
| E0 | 아이디어·추정 |
| E1 | 식별된 실물 또는 수동 관측 |
| E2 | 정상·실패 짝과 실행결과 |
| E3 | 복수 실물 재현과 오탐·미탐 측정 |

### 8.2 사용자에게 보여 줄 상태

내부 코드를 그대로 보여 주지 않는다.

나쁜 예:

> D-RR G2-H2 / cov 0.91 / aging / material-conflict

좋은 예:

> 임대차 현황표는 월 기본임대료 기준 91%가 확인됐습니다. 기준일은 2026-08-30이며, 요약금액과 호실별 합계의 중대한 불일치 1건 때문에 단순 임대수익률은 현재 표시하지 않습니다.

### 8.3 최소 상태값

```text
ClaimInputState = {
  applicability,
  coverage: { value, basis },
  asOf,
  openConflictIds,
  verification
}
```

9개 영역마다 7개 상태칸을 미리 만들지 않는다. 실행하는 산출항목에 필요한 값만 파생한다.

화면과 문서에는 다음 상태만 사용한다.

| 표시어 | 뜻 |
|---|---|
| 확인됨 | 정한 근거와 대조가 완료됨 |
| 일부 확인 | 일부 요소는 확인됐으나 필수 요소가 남음 |
| 미확인 | 확인 절차가 완료되지 않음 |
| 미제공 | 자료 보유자에게서 받지 못함 |
| 해당없음 | 자산·거래에 적용되지 않음 |
| 불일치 | 같은 항목의 자료값이 서로 맞지 않음 |

`미확인`, `미제공`, `해당없음`, `0`은 서로 바꿔 쓸 수 없다.

### 8.4 신선도 후보정책

아래 값은 시범운영용 `잠정/E0` 초기값이다. 검증된 법칙이 아니며 §33으로 조정한다.

| 정보 | 최신 후보 | 경과 후보 | 오래됨 후보 |
|---|---:|---:|---:|
| 매각가격·일정 | 30일 이내 | 31~90일 | 90일 초과 |
| 임대·점유 | 90일 이내 | 91~180일 | 180일 초과 |
| 현장사진·상태 | 90일 이내 | 91~180일 | 180일 초과 |
| 공부 | 30일 이내 발급 | 31~90일 | 90일 초과 |
| 시장사례 | 180일 이내 | 181~365일 | 365일 초과 |
| 운영비 | 최근 연속 12개월 | 6~11개월 또는 오래된 12개월 | 그 외 |

공실·신규계약·가격변경·증개축·위반사항 같은 중대 이벤트가 있으면 날짜와 무관하게 재확인한다.

## 9. 원자료·불일치·정정

### 9.1 여섯 객체

1. 원자료값: 공부·계약서·진술·현장에서 수정 없이 읽은 값
2. 근거자료 위치: 그 값의 위치
3. 표기·단위 통일: 만원·원, ㎡·평, 날짜 형식 등을 통일
4. 불일치: 서로 맞지 않는 값
5. 정정기록: 사람의 채택·기각 결정
6. 유효기준본: 계산·문서가 사용할 유효값

### 9.2 정정과 가정의 차이

| 구분 | 의미 | 예 |
|---|---|---|
| 정정 | 과거 입력오류 수정 | 월 기본임대료 3,049만원→2,964만원 |
| 현실변경 | 현실상태의 새 변경 | 신규 임차계약 체결 |
| 분석가정 | 미래 분석 가정 | 임대면적 3.3㎡당 월 기본임대료 10만원 |

### 9.3 정정등급

| 등급 | 예 | 승인 |
|---|---|---|
| CR0 | 만원→원, 날짜표기 | 자동 가능·로그 필수 |
| CR1 | 합계·산술 | 시스템 제안·중개인 승인 |
| CR2 | 월 기본임대료·임대차보증금·계약기간 | 근거자료·중개인 승인 |
| CR3 | 필지·면적·지분·위반 | 외부발행 차단 후 권위자료·사람승인 |

## 10. 다필지

### 10.1 필지가 기본단위다

주소 한 줄이 아니라 토지 고유번호(PNU)별 필지를 만든다.

필수:

- PNU·지번
- 면적
- 소유지분
- 매각포함 여부
- 역할: 건축대지·진입·주차·나대지·제외
- 용도지역·공시지가·도로
- 건물 연결

### 10.2 네 면적을 섞지 않는다

| 면적 | 사용 |
|---|---|
| 매각대상 토지면적 | 토지 3.3㎡당 가격 |
| 공부상 건축대지 | 현재 건폐율·용적률 |
| 개발검토 유효면적 | 이론 개발규모 |
| 임대가능·기재면적 | 공실률·임대단가 |

### 10.3 다필지 금지

- 대표 필지의 용도지역을 전체에 복제
- 대표 필지 공시지가로 가중 공시지가 계산
- 매각제외 필지를 토지 3.3㎡당 가격의 분모에 포함
- 건축물 관련지번 확인 없이 현황 용적률 확정

## 11. 임대차 현황표

### 11.1 표시등급

| 등급 | 내용 |
|---|---|
| RR-N/A | 나대지·완전 자가사용 등 임대가 적용되지 않음 |
| RR0 | 임대차 자료 미제공 또는 판독 불가 |
| RR1 | 층·호실·사용상태·임대차보증금·월 기본임대료 |
| RR2 | RR1 + 월 관리비·면적·계약기간 일부 |
| RR3 | RR2 + 계약서·입금자료·부가가치세·운영비 연계 |

RR 등급은 자료요청과 화면표시를 위한 요약등급이다. RR3이라도 기준일이 오래됐거나 금액 불일치가 남아 있으면 관련 수익 산출항목을 차단한다.

### 11.2 행 상태

```text
occupancy   = leased | vacant | owner_occupied | free_use | unknown
leaseStatus = active | expired_holdover_verified | expired_unverified | terminated | unknown
payment     = collected_verified | seller_reported_current | delinquent | unknown
mgmtFee     = billed | collected | pass_through | net_income_verified | unknown
```

### 11.3 공란과 0

- 공란: 미확인 또는 미제공
- 0: 실제 값이 0임을 확인
- 해당없음: 자산·거래에 적용되지 않음

0을 사용하려면 `zeroConfirmed=true`가 있어야 한다.

### 11.4 확인범위율 분모

1. 확인된 임대가능면적
2. 공부·도면과 대조된 임대대상 면적
3. 전체 임대차 현황표 행 수

행 수 분모이면 면적기준 공실률·임대단가를 만들지 않는다.

### 11.5 임대차 현황표 정보 상세도

| 정보 상세도 | 단위 | 가능한 질문 |
|---|---|---|
| H1 | 자산 전체합계 | 총 임대차보증금·월 기본임대료가 얼마인가 |
| H2 | 층·호·임차인 | 어느 층에서 수입·공실이 발생하는가 |
| H3 | 계약·수납·이벤트 | 언제 만료되고 실제로 무엇이 수납되는가 |

등급과 정보 상세도는 자료요청에 유용하지만 산출항목 허가를 대신하지 않는다. 예를 들어 H3라도 기준일이 오래됐거나 금액 불일치가 남아 있으면 수익률을 차단한다.

## 12. 시장·비교사례

### 12.1 좋은 비교사례의 조건

- 대상을 식별할 수 있다.
- 실거래사례와 매물사례가 구분된다.
- 발생일과 수집일이 있다.
- 토지·연면적 등 가격분모가 명확하다.
- 입지·용도·연식·규모를 비교할 수 있다.
- 채택·제외 이유가 있다.
- 조정했으면 조정근거가 있다.

사례 3건이라는 숫자만으로 품질을 판단하지 않는다.

### 12.2 비교표 최소열

| 열 | 내용 |

| 식별 | 주소·건물·필지 |

| 시점 | 계약일·매도 희망가 기준일·자료 수집일 |
| 가격 | 총액과 분모별 단가 |
| 물리 | 토지·연면적·연식·층수 |
| 입지 | 역·도로·상권 |
| 차이 | 우위·열위 |
| 결정 | 채택·참고·제외와 이유 |

## 13. 중개인 의견

### 13.1 의견은 빼는 것이 아니라 표시한다

중개인만 아는 시장정보를 버리면 문서는 공부요약이 된다. 다만 의견을 사실처럼 쓰지 않는다.

필수:

- 화자
- 작성일·대상·기간
- 관찰·판단
- 식별 가능한 근거
- 값이면 범위
- 반증·철회조건
- 공개승인

### 13.2 좋은 예

> 중개인은 1층 신규 임대료가 현 수준보다 높은 범위에서 협상될 가능성이 있다고 봅니다. 근거는 최근 6개월 반경 500m 내 유사면적 임대사례 3건과 문의 5건입니다. 목표범위는 ㎡당 월 9.2만~10.5만원이며, 6개월 이상 유효문의가 없으면 이 의견을 재검토합니다.

### 13.3 금지

- 확실한 수익
- 안전한 투자
- 개발 확정
- 세금 문제 없음
- 대출 가능
- 명도 문제 없음
- 근거 없는 점추정

### 13.4 중개인 의견을 지우지 않는 방법

안전하게 쓴다는 이유로 중개인 의견을 전부 위험문구로 바꾸면 문서는 공부 요약본이 된다. 의견은 다음 네 단계로 처리한다.

1. **원문 보존**: 중개인이 입력한 표현을 그대로 저장한다.
2. **사실·의견 분리**: 공부·계약·현장 사실과 중개인의 판단을 나눈다.
3. **과장만 완화**: `수익 보장`은 삭제하되 `병원·약국이 장기간 영업 중인 임대구성`은 남긴다.
4. **반영위치 승인**: 추천 포인트·입지·임대·가격·활용방안 중 어디에 쓸지 중개인이 확인한다.

| 원문 | 외부 문구 | 짧은 확인사항 |
|---|---|---|
| 우량 임차인으로 공실리스크가 낮음 | 병원·약국이 장기간 영업 중인 임대구성 | 계약 갱신상태는 별도 확인 |
| 인근 대비 토지평당가 저렴 | 원본 비교 매물 기준 대상 토지단가가 낮은 편 | 비교사례는 매도 희망가 기준 |
| 임대료 현실화 가능 | 자가사용 공간 임대 전환과 기존 임대료 조정 여지 | 임차인 협의·신규 임대 필요 |

중요 의견을 제외할 때는 이유를 중개인에게 보여 준다. 시스템이 조용히 생략하거나 `실사 필요` 한 줄로 대체해서는 안 된다.

## 14. 의견에서 시나리오로

```text
중개인 의견
→ 분석가정 제안
→ 중개인 승인
→ 승인된 분석가정
→ 시나리오 계산기
→ 시나리오 산출항목(현재 사실 지표와 분리)
```

1차 구현은 승인된 분석가정 저장까지 구현한다. 승인누락·변조 실패시험이 E2가 되기 전에는 외부 시나리오에 연결하지 않는다.

실행방안 카드는 다음을 가진다.

- 대상 층·호·필지
- 현재상태
- 실행방안
- 선행조건
- 기간
- 비용근거
- 효과와 산정기준
- 위험·철회조건
- 담당자·다음행동

## 17. 수익률 공식

### 17.1 매도 희망가 기준

```text
연 기본임대료(부가가치세·관리비 제외) ÷ 매도 희망가
```

### 17.2 임대차보증금 차감 매도 희망가 기준

```text
연 기본임대료(부가가치세·관리비 제외)
÷ (매도 희망가 - 승계 임대차보증금)
```

### 17.3 반드시 표시할 것

- 매도인 제시·계약확인·수납확인 중 어느 기본임대료인가
- 승계 임대차보증금을 차감했는가
- 부가가치세·관리비를 제외했는가
- 자가사용·공실·연체를 어떻게 처리했는가
- 기준일은 언제인가

### 17.4 금지

- 단순 임대수익률을 자본환원율로 표기
- 관리비 청구액을 임대수입에 자동 합산
- 운영비 없이 순영업소득·자본환원율 산출
- 분모가 불명확한 평당가·수익률

### 17.5 가격 수준 검토 작성

가격을 근거 없는 ‘적정가’ 한 점으로 확정하지 않는다. 다음을 병렬로 보여 준다.

- 매도 희망가와 협상조건
- 매각대상 토지면적 기준 3.3㎡당 가격
- 공부상 연면적 기준 3.3㎡당 가격
- 식별된 매매 비교사례 범위
- 허용된 임대수익률
- 중개인의견 범위와 철회조건
- 각 범위가 성립하는 전제

비교사례나 임대자료가 부족하면 가격판단 페이지를 만들지 않고 ‘어떤 사례·자료가 있어야 판단 가능한가’를 제시한다.

## 18. 만료계약

만료는 계약서상 날짜가 지났다는 뜻이다. 즉시 공실이라는 뜻은 아니다.

| 상태 | 처리 |
|---|---|
| 만료 없음 | 일반규칙 |
| 점유·납부 확인 | 제시/수납 산정기준 허용 가능, 계약만기·가중평균 잔여 임대차기간 제한 |
| 소액 만료 미확인 | 경고부 허용 후보, 금액·영향 공개 |
| 중대한 만료 미확인 | 현재수입·수익률 차단 |
| 최대임차인 만료 미확인 | 비중과 무관하게 안정성·시나리오 차단 |

10% 같은 비중은 검증된 법칙이 아니라 잠정 정책이다.

## 19. 자산형태와 검토관점

### 19.1 1차 자산형태

| 화면 표시어 | 내부코드 | 의미 |
|---|---|---|
| 일반건물 | `whole_building` | 일반 단일·복합 건물 거래 |
| 나대지 | `vacant_land` | 거래범위상 건물이 없는 토지 |
| 별도검토 필요 | `requires_review` | 혼합·집합·특수자산 또는 범위 불명 |

근생·업무·주거는 `legalUseTags[]`에 기록한다. 실증 전 행동분기를 만들지 않는다.

### 19.2 1차 검토관점

| 화면 표시어 | 내부코드 | 질문 | 분석항목 |
|---|---|---|---|
| 수익현황 | `yield` | 현재 임대수입이 얼마나 지속되는가 | 수입·만기·공실·안정성 |
| 가치개선 | `value_add` | 무엇을 어떻게 개선할 수 있는가 | 임대료 격차·공실원인·실행방안 |
| 개발검토 | `redevelop` | 신축검토 가치가 있는가 | 필지·도로·이론규모·명도질문 |

최대 2개는 초기 검증범위 제한이다. 세 번째 검토관점 요청을 기록해 정책을 검토한다.

### 19.3 이번 단계에서 보류하는 항목

- 실사용자용 매입·임차 비교
- 보존·승계 목적 분석
- 부동산과 사업을 함께 거래하는 분석
- 집합건물·특수자산 전용 판정기

### 19.4 보류가 ‘삭제’를 뜻하지는 않는다

| 기존 표현 | 1차 구현 처리 | 향후 승격조건 |
|---|---|---|
| 사옥형 | 일반 공간·접근·주차·명도 가능성만 사실/의견으로 표시 | 특정 매수자 검토조건과 정상·실패 표본 확보 후 매입·임차 비교 |
| 운영형 | 부동산만 거래하면 일반 매각안내서, 사업이 포함되면 전문가 이관 | 월별 운영자료·사업/부동산 경계·전문검토 |
| 단기매매형 | 매도사유·보유이력은 내부 공개금지 | 특정 매수자 검토조건이 있을 때 제한적 매각 시나리오 분석 |
| 자산이전 | 내부 관심 표시값만 | 세무·법률 전문가 협업 |
| 구분상가 | 별도검토 필요 | 전유·공용·대지권·관리단 산출항목의 E2 근거자료 |
| 특수자산 | 별도검토 필요 | 자산종류별 규제·설비·운영 산출항목의 E2 근거자료 |

즉, 현행 5분법을 새로운 `작성 태도` 이름으로 계속 확장하지 않는다. 자산사실, 거래범위, 검토관점, 특정 매수자 요구, 내부정보를 분리해 필요한 분석항목만 단계적으로 승격한다.

### 19.5 가치개선 검토관점

가치개선은 ‘임대료를 올릴 수 있다’는 한 문장이 아니다.

필수 질문:

- 어떤 층·호실의 현재 임대료가 시장과 다른가
- 차이가 계약·시설·면적·업종 중 무엇 때문인가
- 언제 실행할 수 있는가
- 공실기간·비용·임차인 협의가 무엇인가
- 실패하면 어떤 손실이 발생하는가

운영비·견적이 없으면 순영업소득 상승이나 가치상승액을 확정하지 않는다. 정성 실행방안은 허용한다.

### 19.6 개발검토 관점

```text
이론 건축면적 상한 = 공부상 적용 대지면적 × 법정 건폐율
이론 용적률 연면적 = 공부상 적용 대지면적 × 법정 용적률
```

반드시 함께 표시한다.

> 위 값은 공부상 비율을 단순 적용한 이론값입니다. 도로·높이·일조·주차·지구단위계획·구조·설계·인허가를 반영한 실제 건축 가능규모가 아닙니다.

실제 가능규모, 용도변경, 주차완화, 구조보강, 공사비 확정이 가격판단의 핵심이면 전문가에게 이관한다.

## 20. 발행등급 판정

### 20.1 L1 묶음

- 자산·매각범위
- 가격·단위
- 핵심 공부
- 현장·사진상태
- 기준일·출처
- 위험·미확인
- 개인정보·발행승인

### 20.2 L1.5 묶음

L1 + 다음:

- 공개 승인된 중개인 추천의견 1건 이상, 권장 3~5건
- 각 의견의 사실·현장관찰·사진 중 하나 이상의 근거
- 매수자에게 갖는 의미와 적합한 매수자 또는 활용방향
- 의견의 성립조건 또는 추가 확인사항
- 중개인 원문·외부문구·반영면·승인상태 추적

단순 임대수익률·비교사례·시나리오는 필수조건이 아니다. 공개승인만 있고 근거 또는 매수자 의미가 없으면 L1.5로 발행하지 않는다.

### 20.3 L2 묶음

L1.5 + 다음:

- 현재 사용·임대상태 또는 해당없음
- 가격 산정기준
- 시장근거 또는 공개승인 의견
- 핵심 검토요약
- 구체적 실사·자료요청·매입의향서 조건
- 수익현황 검토이면 RR-C01 또는 임대 해당없음
- 개발검토이면 필지 확인범위율·이론값 경고

### 20.4 판정절차

```text
if identityUnknown or piiFailure or releaseApprovalMissing:
    return L0

snapshot = materializeApprovedSnapshot()
claims = evaluateApplicableClaims(snapshot, mvpContext)

for tier in [L2, L1P, L1]:
    if requiredBundle(tier) satisfied and gates pass:
        return tier

return L0
```

### 20.5 위험·실사·매입의향서 연결

위험을 일반적인 경고문으로 끝내지 않는다.

```yaml
risk:
  id: RISK-RR-001
  issue: "최대 임차인 계약만료 후 갱신상태 미확인"
  status: unknown
  affectedClaims: [RR-C07, RR-C08, RR-C11]
  impact: [income, timing]
  evidenceRefs: [OBS-LEASE-END]
  ddRequest: "갱신합의서와 최근 3개월 수납 확인"
  loiCondition: "자료확인과 수입 재산정을 가격협의 선행조건으로"
  owner: broker-017
```

작성순서:

1. 확인된 위험 또는 미확인
2. 가격·수입·일정에 미치는 영향
3. 필요한 자료·현장점검
4. 매입의향서·계약에 반영할 조건
5. 담당자·기한

# 제4부. 실제 문서를 어떻게 작성하는가

## 21. 공통 페이지 계약

외부 페이지는 다음 다섯 요소를 갖는다. 다만 모든 요소를 같은 크기로 드러내지 않는다.

1. 질문
2. 결론 또는 판단불가
3. 근거자료 하나
4. 출처·기준일·산정기준
5. 다음 행동

한 페이지에 서로 다른 질문을 여러 개 넣지 않는다.

### 21.1 페이지의 읽기 순서

매수자가 보는 순서는 다음과 같아야 한다.

1. **무엇이 좋은가 또는 무엇을 알아야 하는가**
2. **그 근거가 되는 숫자·사진·지도·표**
3. **매수자에게 어떤 의미가 있는가**
4. **필요한 경우에만 짧은 확인사항**

검증과정·정책판정·자료처리 상태를 본문 첫 문장으로 시작하지 않는다. `자료 확인현황`과 `위험요인`은 필요한 페이지이지만, 문서 전체의 주인공이 되어서는 안 된다.

### 21.2 제목 작성규칙

한국형 매각안내서 제목은 다음 세 형식을 우선한다.

- **매물특징형**: `당산역 도보 5분, 병원·약국 장기 영업 중인 수익형 빌딩`
- **핵심숫자형**: `매매가 115억원｜대지 153.3평｜연면적 435.9평`
- **행동기회형**: `자가사용 공간 임대 전환 및 기존 임대료 조정 여지`

다음 형식은 사용하지 않는다.

- `검토의 핵심은 …이다`
- `…로 정리한다`
- `…을 같은 무게로 검토한다`
- 페이지마다 완결된 장문 결론을 억지로 붙이는 방식
- 외부 독자가 모르는 내부 등급·정책·처리상태를 제목에 넣는 방식

### 21.3 본문 작성규칙

- `~입니다·~로 확인됩니다·~할 수 있습니다`를 자연스럽게 섞는다.
- 한 문장은 가급적 하나의 사실 또는 하나의 의견만 전달한다.
- `검토 논거·반대근거·산출항목·현재본·표시 제한·사용차단`은 외부 본문에서 쓰지 않는다.
- `우량·안전·확정·저평가`는 근거 없이 쓰지 않되, 근거가 있는 매물 장점 자체는 삭제하지 않는다.
- 중요한 숫자는 표나 큰 숫자로 먼저 보여 주고, 산정기준은 각주에서 설명한다.
- 면책문구는 마지막 문장이 아니라 각주 또는 자료 유의사항에 둔다.

### 21.4 외부 문서에서 숨길 제작정보

다음 정보는 시스템·시험·내부검토 화면 또는 마지막 시험부록에만 둔다.

- L0·L1·L1.5·L2·L3 등급코드
- 사실확인형·중개인 제안형·표준 검토형 같은 제품 분류명
- 골든 예시·가상 보완값·발행검사·산출항목 상태
- 원자료 처리과정·정책코드·개발자용 경고

외부 표지는 `매각안내서`, `매각제안서`, `매각안내서 · 매수 검토자료 포함`, `투자검토서`처럼 독자가 이해하는 이름을 사용한다.

### 21.5 사진은 페이지가 아니라 근거자료다

사진은 별도의 장식 섹션에 모으기보다 사진이 설명하는 사실·의견·확인사항 가까이에 둔다.

- 대표 외관은 표지와 물건 개요에 우선 배치한다.
- 도로 전면·접근로는 입지, 임차인 간판·출입구는 임대현황, 자가사용·공실 공간은 활용방안, 주차·설비·보수대상은 확인사항과 연결한다.
- 사진이 충분하지 않으면 독립 현장사진 페이지를 생략한다.
- 대표사진 지정과 공개범위는 담당 중개인이 최종 승인한다.

## 22. L1 사실확인형과 L1.5 중개인 제안형 블루프린트

### 22.1 L1 사실확인형 매각안내서

| 순서 | 페이지 | 질문 |
|---:|---|---|
| 1 | 표지 | 어떤 자산인가 |
| 2 | 대표 외관을 포함한 물건 개요 | 무엇을 얼마에 파는가 |
| 3 | 매각대상 범위 | 어떤 필지·건물이 포함되는가 |
| 4 | 공부 확인내용 | 공부상 토지·건물은 어떠한가 |
| 5 | 입지 및 접근 | 어디에 있고 어떻게 접근하는가 |
| 6 | 사용현황 | 현재 어떻게 사용되는가 |
| 7 | 관련 사실 옆 현장사진 또는 미제공 표시 | 실제로 무엇이 관찰되는가 |
| 8 | 위험요인 및 미확인사항 | 무엇이 확인되지 않았는가 |
| 9 | 담당자 및 자료 유의사항 | 다음 연락과 문서경계는 무엇인가 |

자료가 적으면 7면까지 통합한다.

L1은 추천의견이 필수는 아니다. 외부 화면 권장순서는 `표지 → 대표 외관을 포함한 물건 개요 → 입지 → 토지·건물 → 사용현황 → 매수 전 확인사항 → 문의`다. 사진은 관련 페이지에 분산하고, 추가 확인용 사진이 남을 때만 사진 부록을 만든다.

### 22.2 L1.5 중개인 제안형 매각제안서

| 순서 | 페이지 | 핵심 질문 |
|---:|---|---|
| 1 | 대표 외관 중심 표지 | 어떤 매물인가 |
| 2 | 매물 추천 포인트 | 왜 검토할 만한가 |
| 3 | 대표 외관을 포함한 물건 개요 | 무엇을 얼마에 파는가 |
| 4 | 매각대상·토지·건물 | 어떤 자산이 포함되는가 |
| 5 | 입지 및 접근 | 위치와 접근성이 어떤가 |
| 6 | 층별 사용·임대현황 | 현재 어떻게 사용되는가 |
| 7 | 중개인 제안·활용 포인트 | 어떤 활용 여지가 있는가 |
| 8 | 허용된 가격 참고정보 | 가격을 어떻게 참고할 것인가 |
| 9 | 매수자 유형별 적합성 | 누구에게 적합한가 |
| 10 | 매수 전 확인사항 | 무엇을 추가 확인해야 하는가 |
| 11 | 문의·자료 유의사항 | 다음 행동은 무엇인가 |
| 12 | 추가 사진 부록 | 본문 밖의 확인사진이 있는가 |

9~13면을 목표로 하되 빈 페이지를 만들지 않는다. 임대차 현황이 부족하면 수익분석 페이지를 억지로 만들지 않고, 확인된 사용현황과 중개인 추천·활용 제안에 집중한다.

## 23. L2 표준 검토형 매각안내서 블루프린트

| 순서 | 페이지 | 핵심내용 |
|---:|---|---|
| 1 | 표지 및 핵심조건 | 자산명·위치·매도 희망가·기준일 |
| 2 | 핵심 검토요약 | 논거·조건·위험·다음행동 |
| 3 | 자료 확인현황 | 무엇이 확인·진술·미확인인가 |
| 4 | 매각대상 범위 | 필지·건물·포함범위 |
| 5 | 입지 및 시장 | 접근·상권·시장맥락 |
| 6 | 층별 구성 및 사용현황 | 층별 사용·점유 |
| 7 | 임대차 현황표 | 사용가능한 임대차 현황 |
| 8 | 임대수입 산정기준 | 허용된 합계·단순 임대수익률 |
| 9 | 가격 수준 검토 | 매도 희망가·단가·비교근거 |
| 10 | 중개인 검토의견 | 수익현황·가치개선·개발검토 판단 |
| 11 | 위험요인 및 반대근거 | 무엇이 틀릴 수 있는가 |
| 12 | 실사사항 및 매입의향 조건 | 확인자료·현장·계약조건 |
| 13 | 필요한 경우 추가 사진 부록 | 본문 미사용 보조 근거자료 |
| 14 | 담당자 및 자료 유의사항 | 연락처·자료범위·유의사항 |

모든 페이지를 만들 필요는 없다. 자료가 없는 분석면은 삭제하고 위험·확인사항에 반영한다.

외부 화면에서는 `핵심 검토요약`을 `매물 추천 포인트`, `중개인 검토의견`을 `임대수입 개선방안` 또는 `매입 후 운용 포인트`, `위험요인 및 반대근거`를 `매수 전 확인사항`으로 바꿔 쓴다. 내부 분류명은 작성도구에서만 유지한다.

### 23.1 L3 선택 분석항목

| 분석항목 | 생성조건 | 금지조건 |
|---|---|---|
| 임대차 만기 | 계약기간 산출항목 사용가능 | 최대임차인 기간 미확인 |
| 임대료 격차 | 대상·시장 임대단가 산정기준 일치 | 식별 사례 없음·면적배분 미해결 |
| 차이조정 비교사례 | 사례 식별·채택·조정근거 | 매물사례만으로 실거래 결론 |
| 가치개선 실행방안 | 대상·행위·조건·기간·위험 | 근거 없는 가치상승 확정 |
| 시나리오 | 승인된 분석가정·계산격리 | 승인누락·사실 핵심지표 혼합 |
| 순영업소득·자본환원율 | 유효총수입·12개월 운영비·가격 산정기준 | 운영비 미제공 |
| 보수 시나리오 | 핵심 가정의 불리한 변화 | 기본값·범위 비공개 |
| 금융조건 참고 | 사용자가 승인한 대출조건 | 대출가능·승인 확정표현 |

L3는 위 분석항목이 사용가능할 때만 L2에 추가한다. 빈 L3 페이지를 맞추기 위해 추정값을 생성하지 않는다.

## 24. 작성문장과 시각화

### 24.1 문장구조

```text
확인된 사실
→ 담당 중개인 의견 또는 추천
→ 매수자에게 갖는 의미
→ 성립조건·짧은 확인사항
→ 다음 확인·행동
```

### 24.2 나쁜 문장

> 우량 임차인으로 안정적인 수익이 보장됩니다.

### 24.3 좋은 문장

> 매도인 제시 기준 현재 월 기본임대료 합계는 2,964만원입니다. 다만 계약기간이 지난 임대차의 기본임대료 비중이 커 현재수입으로 확정하지 않았습니다. 갱신상태와 최근 입금내역을 확인하면 단순 임대수익률 분석을 다시 수행할 수 있습니다.

위 문장은 내부 검토문에는 적절하지만 외부 매각안내서의 첫 문장으로는 방어적이다. 외부용은 장점과 사실을 먼저 쓰고 확인사항을 짧게 붙인다.

> 현재 월 기본임대료는 매도인 제시 기준 2,964만원입니다. 병원·약국 등 생활밀착 업종이 영업 중이며, 계약 갱신상태와 최근 수납내역은 매수 검토 시 확인이 필요합니다.

### 24.3.1 외부 카피 변환식

```text
사실: 병원·약국이 1·2·5층을 사용
의견: 장기 영업 중인 의료 임차구성
의미: 생활권 수요에 기반한 기존 임대수입
확인: 계약 갱신상태는 매수 전 확인

외부 문장:
병원·약국이 장기간 영업 중이며 생활권 수요에 기반한 임대수입이 형성돼 있습니다.
계약 갱신상태는 매수 검토 시 확인이 필요합니다.
```

확인사항은 사실과 의견을 무효화하는 문장처럼 쓰지 않는다. `장점 → 의미 → 확인` 순서를 지킨다.

### 24.4 시각화 선택

| 질문 | 권장 시각화 |
|---|---|
| 어떤 필지가 포함되는가 | 지적도 + 포함/제외 색상 |
| 층별 사용은 어떠한가 | 층별 구성도 |
| 임대료는 어디서 나오는가 | 층별 임대차 현황표 |
| 만기는 언제 몰리는가 | 임대차 만기 일정표 |
| 가격은 어디에 위치하는가 | 비교사례 범위도표 |
| 무엇을 먼저 해야 하는가 | 실행방안 카드 |

장식용 그래프를 만들지 않는다.

### 24.5 사진 선택·배치·설명

#### 대표 외관 선정

건물 전체와 도로 접면을 식별할 수 있고 해상도·노출·왜곡이 양호한 사진을 우선한다. 시스템은 후보를 추천할 수 있지만 대표사진은 중개인이 승인한다.

물건 개요의 기본 레이아웃은 `대표 외관 35~45% + 핵심제원 55~65%`다. 사진 종횡비와 정보량에 따라 조정하되, 사진 때문에 가격·토지·연면적·용도지역 등 핵심값이 작아지지 않게 한다.

#### 사진수별 조립

| 사용가능 사진 | 권장 구성 |
|---:|---|
| 0장 | 지도·공부·도식 중심, 사진 미제공 표시 |
| 1~2장 | 표지와 물건 개요에 목적별로 다르게 크롭 |
| 3~5장 | 물건 개요·입지·사용현황·확인사항에 분산 |
| 6~10장 | 각 사실·의견과 근거사진을 인접 배치 |
| 10장 초과 | 의사결정에 중요한 사진만 본문, 잔여분은 부록 |

#### 사진별 권장 위치

| 사진 | 권장 위치 |
|---|---|
| 건물 외관 | 표지·물건 개요 |
| 도로 전면·접근로 | 입지 및 접근 |
| 임차인 간판·출입구 | 사용·임대현황 |
| 자가사용·공실 공간 | 활용방안 |
| 공용부·승강기 | 관리상태 의견 |
| 주차·설비·보수대상 | 매수 전 확인사항 |

동일 사진의 동일 크롭은 본문에서 한 번만 사용한다. 사진이 1~2장뿐이면 표지와 개요에서 목적이 다른 크롭을 허용한다. 가상 생성사진·다른 건물 사진·출처 불명 사진은 사용할 수 없다.

의사결정에 중요한 사진에는 `촬영대상｜제공자｜촬영일 또는 자료 기준일`을 표시한다. 예: `건물 전면 및 주출입구｜담당 중개인 촬영｜2026.08`.

### 24.6 숫자 각주

핵심 숫자에는 다음을 짧게 붙인다.

- 공부확인
- 매도인 제시
- 계약확인
- 수납확인
- 중개인 현장확인
- 중개인 의견
- 계산값
- 분석가정
- 미확인

숫자 종류별로 다음 꼬리표를 추가한다.

| 숫자 | 반드시 함께 적을 내용 | 예시 |
|---|---|---|
| 가격 | 가격 성격·기준일·포함범위·부가가치세 | `매도 희망가 50억원, 건물분 부가가치세 별도` |
| 면적 | 면적 종류·근거자료·㎡ 원값·평 환산 | `건축물대장상 연면적 825.40㎡(249.68평)` |
| 임대료 | 기본임대료·관리비 분리, 부가가치세, 확인수준 | `계약상 월 기본임대료 900만원, 관리비 100만원, 부가가치세 별도` |
| 수익률 | 지표명·분자·분모·임대차보증금·운영비 처리 | `매도 희망가 기준 단순 임대수익률 2.16% = 연 기본임대료 1.08억원 ÷ 50억원` |
| 거리·도로 | 출발·도착·경로 또는 도로명·너비·접면, 조회일 | `○○역 2번 출구에서 보행경로 약 380m` |

`매매가`, `면적`, `임대료`, `수익률`, `평당가`, `역세권`을 위 설명 없이 단독으로 쓰지 않는다.

### 24.7 공개·가림처리

- 임차인 개인명·연락처·계좌·서명·주민등록정보는 외부 공개 금지다.
- 상호는 공개정책에 따라 가림처리하고 업종은 분석에 필요한 범위에서 유지한다.
- 계약서 원문은 부록으로 자동 포함하지 않는다.
- 사진의 얼굴·번호판·전화번호·출입정보·민감 상호를 확인한다.
- 매도사유·협상하한·관계정보는 기본적으로 내부전용이다.
- 사진 가림처리와 외부공개는 중개인의 별도 승인을 남긴다.

## 26. 중개인 입력화면

1차 구현의 추가 의사결정은 세 묶음이다.

1. 매각범위·자산형태 확인
2. 검토관점 최대 2개 승인
3. 위험·미확인·공개범위 포함 최종승인

예외질문:

> 부동산 외 운영사업·영업권·주식·수익권도 거래대상에 포함됩니까?

‘예’이면 자동 L1.5/L2/L3를 중단하고, 공개 가능한 L1 범위와 전문가 이관을 별도 결정한다.

### 26.1 매각논리와 사진 입력

중개인은 다음 질문에 답한다.

1. 이 매물을 한 문장으로 어떻게 소개하는가
2. 매수자에게 먼저 말할 장점 3~5개는 무엇인가
3. 그 장점을 뒷받침하는 사실·현장관찰·사진은 무엇인가
4. 어떤 매수자에게 적합하며 그 이유는 무엇인가
5. 임대 또는 활용가치를 높일 현실적인 방법은 무엇인가
6. 추천과 함께 알려야 할 조건·약점·확인사항은 무엇인가

사진별로 `대표사진 여부·촬영대상·층 또는 공간·촬영일·제공자·공개 가능 여부·연결 의견`을 확인한다. 시스템은 권장 페이지와 크롭 후보를 제시하되 대표사진과 외부공개는 중개인이 승인한다.

### 26.2 보완과제 최대 3개

다음 순서로 정렬한다.

1. P0 오표현·공개위험 해소
2. 목표 발행단계 필수 산출항목 해제
3. 매수자 핵심질문 영향

표시:

- 무엇을 확인할지
- 누구에게 요청할지
- 무엇이 열리는지
- 예상 노력
- 최소조합

| 출력물 품질검사 | 수치·개인정보·사진역할·출력물 검사 |

AI 금지:

- 누락 숫자 추정입력
- 원자료 불일치 자동채택
- 산출항목·발행단계·최종발행 승인
- 면책을 이유로 차단 산출항목 포함
- 채권최고액을 실제 대출잔액으로 변환
- 관리비를 근거 없이 임대수입에 합산
- 운영비 없이 순영업소득·자본환원율 계산
- 법정 용적률과 현황 용적률 차이만으로 증축 가능면적 확정
- 매물사례를 실거래사례로 표시
- 매도인 진술을 공부·계약 확인사실로 변경
- `우량·안전·확정·저평가` 같은 평가어를 근거 없이 추가
- 자료 유의사항으로 잘못된 계산이나 과장을 정당화
- 중개인 의견을 일반 위험문구로 자동 치환하거나 반영이력을 남기지 않고 누락
- 외부 표지·제목에 L등급·발행검사·산출항목·가상값 같은 내부 제작어 노출
- 모든 제목을 `~이다·~한다`형 장문 결론으로 기계적으로 생성
- 매물의 장점보다 검증과정·면책문구를 앞세우는 문서 조립
- 사진이 부족하다는 이유로 가상 이미지나 다른 건물 사진 생성·삽입
- 사진의 대상을 확인하지 않고 중개인 의견의 근거로 자동 연결
- 사용자가 지정한 대표사진을 승인 없이 변경
- 외부공개 승인이 없는 사진을 본문 또는 부록에 포함

AI는 최종 작성 전에 `중개인 의견 반영표`를 생성하고, 최종 작성 뒤 각 의견이 어느 페이지의 어떤 문장으로 반영됐는지 역대조해야 한다.

## 29. 발행검사

### 29.1 세 축

| 구분 | 내부 필드 | 질문 |
|---|---|---|
| 조치 | `effect` | 실패하면 무엇을 하는가 |
| 위험등급 | `riskClass` | 얼마나 엄격한 반증·승인이 필요한가 |
| 관측유형 | `observationType` | 무엇을 관측하는가 |

### 29.2 조치

| 내부코드 | 뜻 |
|---|---|
| `BLOCK_RELEASE` | 문서 전체 외부발행 차단 |
| `DOWNGRADE` | 발행단계 하향 |
| `BLOCK_CLAIM` | 해당 산출항목 사용차단 |
| `WARN` | 주의표시와 함께 조건부 사용 |
| `PASS` | 검사 통과 |
| `NOT_RUN` | 검사 미실행이며 통과가 아님 |

### 29.3 위험등급

| 등급 | 대상 | 기록 |
|---|---|---|
| RC0 | 형식·출력물 | 기대결과·실제결과 |
| RC1 | 산출항목·발행단계 | 실패 판정조건·허용되기 위한 조건 |
| RC2 | 외부발행·개인정보·법적경계·핵심수치 | 반대상황·관리책임자·예외승인 정책 |

- 합성·변종으로 14개를 모두 실행한다.
- 판정조건의 참·거짓 경우를 모두 실행한다.
- 처리조건의 쌍 조합 확인범위율을 보고한다.
- 금액·권리·개인정보 상호작용은 전수검증하거나 세 요소 조합검증으로 올린다.
- 합성통과를 실물 E2/E3로 보지 않는다.

3. 후보별 오류행렬
4. 표본수·자산형태·결측 보고
5. 윌슨 신뢰구간
6. 기대손실·안전조건 평가
7. 부족하면 잠정·확인 전 차단 유지

실패 0건일 때 95% 상한은 대략 `3/n`이다. 이는 출시건수가 아니라 주장 가능한 정밀도의 한계다.

# 제7부. 사례로 이해하기

## 35. 당산동 사례

### 35.1 관측

- 건물 요약면적과 층별 합계 차이
- 오래된 임대차 현황표 기준일
- 다수 계약만기
- 운영비 없음
- 시장근거 부족

### 35.2 안전한 판정

- 면적 불일치 해소 전 토지·연면적 3.3㎡당 가격과 임대단가 차단
- 만료·점유·수납 확인 전 현재수입 확정 금지
- 순영업소득·자본환원율 금지
- 면적 등 핵심 사실 정정 후 중개인 의견묶음이 충족되면 L1.5 우선

### 35.3 승급경로

1. 면적 정정
2. 최신 기준일·점유·수납 확인
3. 중개인 추천의견·근거사진·매수자 의미 승인
4. L1.5 매각제안서 생성
5. 최신 임대·수납·시장사례 보완 후 L2 생성

### 35.4 검토관점

`수익현황 + 가치개선`

현재 수익률을 미화하지 않고 만기·임대격차·재계약 실행방안을 강조한다.

### 35.5 중개인 입력 반영표

| 중개인 입력 | 외부 문서 반영 | 표시 위치 |
|---|---|---|
| 깨끗하게 관리된 건물 | 관리상태가 양호한 외관·공용부 | 매물 추천 포인트·물건 개요 옆 외관·공용부 사진 |
| 당산역 및 간선도로 접근 | 당산역 도보 5분, 국회대로·올림픽대로 접근 | 표지·입지 |
| 병원·약국 장기 임차 | 병원·약국이 장기간 영업 중인 임대구성 | 추천 포인트·임대현황·임차인 출입구 사진 |
| 인근 대비 낮은 토지 평당가 | 원본 매물사례 기준 대상 토지단가가 낮은 편 | 가격 경쟁력 |
| 준공업지역 규제완화 수혜 | 준공업지역 입지와 향후 제도변화 검토가치 | 토지이용·활용 포인트 |
| 임대료 현실화 | 자가사용 121.1평 임대 전환 및 기존 임대조건 조정 여지 | 임대수입 개선방안 |

위 의견들은 핵심 사실이 정정되고 사진 공개승인이 완료되면 L1.5 매각제안서에 반영할 수 있다. 현재 임대수입·조정안·가격검토의 산출항목이 모두 허용되면 L2로 확장한다.
