# D56 대한민국 소형 상업용 부동산 중개 전문 어휘 사전

> **부제** 매각안내서·투자검토서·중개상담·자료입력에 함께 쓰는 한국어 표준 용어집  
> **문서 성격** D52/D55 용어 현지화 사양 · 중개인용 실무 사전 · 시스템 표시어 사전  
> **적용 대상** 꼬마빌딩, 근린생활시설, 상가주택, 구분상가, 소형 업무시설, 소형 숙박·운영형 자산, 개발검토용 토지  
> **기준일** 2026-08-30  
> **원칙** 공식용어 우선 · 현장어 병기 · 모호한 단어 분해 · 영문은 필요한 약어만 보조 표기

---

## 0. 이 사전의 목적

이 사전은 영문 부동산금융 용어를 기계적으로 번역한 목록이 아니다. 대한민국 소형 상업용 부동산 중개인이 실제로 다음 업무를 할 때 **같은 뜻을 같은 말로 표현하도록 만드는 작성 기준**이다.

1. 매도인에게 자료를 요청하고 매물 정보를 입력한다.
2. 공부·현장·임대차 자료를 서로 대조한다.
3. 매수자가 이해할 수 있는 매각안내서와 투자검토서를 작성한다.
4. 수입·가격·수익률의 산식과 한계를 표시한다.
5. 확인된 사실, 매도인 진술, 중개인 의견, 분석가정을 구분한다.
6. AI가 과장하거나 자료가 없는 내용을 만들어 내지 못하게 한다.

이 문서에서 `공부`는 공부방의 공부가 아니라 **토지대장·건축물대장·등기사항증명서·토지이용계획확인서와 같은 공적 장부 및 증명자료**를 뜻한다.

## 1. 표준 용어를 고르는 다섯 가지 원칙

### 1.1 공식 명칭과 현장어를 분리한다

- 외부 문서의 표 제목과 사실 기재에는 공식 명칭을 쓴다.
- 중개인 검색·대화에 필요한 현장어는 동의어로 보존한다.
- 예: `등기사항증명서(현장어: 등기부등본)`.

### 1.2 같은 말로 다른 숫자를 부르지 않는다

- `매매가` 대신 `매도 희망가`, `계약금액`, `실거래 신고금액`을 구분한다.
- `임대료` 대신 `월 기본임대료`, `월 관리비`, `월 임대수입 합계`를 구분한다.
- `면적` 대신 `토지면적`, `대지면적`, `건축면적`, `연면적`, `전용면적`, `임대면적`을 구분한다.
- `수익률` 대신 산식에 맞는 이름을 쓴다.

### 1.3 법률용어와 투자분석용어를 섞지 않는다

- `차임`은 법률·계약 설명에서, `월 기본임대료`는 임대차 현황표에서 쓴다.
- `권리금`은 건물 매매대금이나 임대보증금과 별개의 임차영업 관련 개념이다.
- `감정평가액`, `시세`, `매도 희망가`, `추정가치`는 서로 대체할 수 없다.

### 1.4 영문 약어는 한국어 다음에 한 번만 쓴다

- 권장: `순영업소득(NOI)`, `자본환원율(Cap Rate)`, `담보인정비율(LTV)`.
- 비권장: 제목과 표 전체를 `NOI`, `CAP`, `LTV`, `WALE`, `DD`만으로 구성.
- 중개인이 산식을 설명할 수 없는 지표는 외부 문서에 넣지 않는다.

### 1.5 외부 문서어와 시스템 내부어를 구분한다

- 매수자에게는 `근거자료`, `불일치`, `정정기록`, `발행검사`라고 쓴다.
- 데이터베이스나 프로그램 안의 영문 필드명은 유지할 수 있으나 화면·보고서에는 한국어 표시어를 사용한다.

## 3. 문서 전체에서 우선 바꿀 영문·외래어

### 3.1 문서와 분석 수준

| 기존 표현 | 권장 한국어 | 사용 방법 |
|---|---|---|
| OM | **매각안내서** | 처음 한 번만 `매각안내서(OM)`로 병기 가능 |
| IM | **투자검토서** | 업계 관행상 `투자설명서(IM)`도 가능하나, 검토자료라는 성격을 드러낼 때 `투자검토서` 권장 |
| Teaser | **요약 매각안내서** | 주소 비공개 자료이면 `비공개 요약 매각안내서` |
| Broker Fact OM | **사실확인형 매각안내서** | 공부·현장·가격·현재 상태 중심 |
| Broker Goldilocks OM | **표준 검토형 매각안내서** | `골디락스`를 외부 표준명으로 쓰지 않음 |
| Broker Analysis IM | **중개분석형 투자검토서** | 중개인이 근거와 한계를 밝히고 가격·임대·활용을 분석한 단계 |
| Expert Collaboration IM | **전문가 협업형 투자검토서** | 법무·세무·건축·감정평가·운영 전문가가 쟁점별로 검토한 단계 |
| Golden reference | **표준 모범본** | 시험용이면 `표준 정답본`도 가능 |
| Goldilocks | **표준 검토형** 또는 **적정형** | 문서 단계명에는 `표준 검토형` 권장 |
| Posture | **작성 태도** | 문서의 주장 강도라면 `서술 태도`, 발행 단계라면 `작성 단계`로 구체화 |
| Tier | **발행 단계** | 자료 품질이면 `자료등급`, 문서 수준이면 `작성단계`로 구분 |
| Resolution | **정보 상세도** | `해상도`는 지도·영상 외에는 사용하지 않음 |

## 4. MECE 분류체계

아래 분류는 한 용어가 들어갈 **주된 자리**를 기준으로 중복을 최소화했다. 실제 문서에서는 서로 연결되지만, 사전에서는 한 항목을 한 분류에만 배치한다.

| 코드 | 분류 | 답하는 질문 |
|---|---|---|
| A | 문서·중개업무·당사자 | 누가 어떤 문서를 왜 만드는가 |
| B | 거래조건·가격·대금 | 무엇을 얼마에 어떤 조건으로 거래하는가 |
| C | 대상 식별·매각범위 | 정확히 어느 필지와 건물이 포함되는가 |
| D | 토지·도시계획·도로 | 토지의 법정 상태와 이용조건은 어떠한가 |
| E | 건물·면적·시설 | 건물의 물리적·공부상 상태는 어떠한가 |
| F | 소유권·담보·법적 제한 | 누가 어떤 권리를 가지며 무엇이 제한하는가 |
| G | 임대차·점유·임대차 현황표 | 누가 어느 공간을 어떤 조건으로 쓰는가 |
| H | 임대수입·운영비 | 현재 운영에서 얼마가 들어오고 나가는가 |
| I | 수익률·투자지표 | 어떤 산식으로 경제성을 판단하는가 |
| J | 입지·상권·시장·비교사례 | 주변 수요와 가격 근거는 무엇인가 |
| K | 가치개선·개발·용도전환 | 무엇을 바꾸면 가치가 달라질 수 있는가 |
| L | 실사·협상·계약조건 | 거래 전 무엇을 확인하고 조건화할 것인가 |
| M | 자료출처·검증·불일치 | 그 말은 무엇에 근거하고 얼마나 믿을 수 있는가 |
| N | 문서작성·발행·AI 운영 | 무엇을 어떤 상태에서 밖으로 내보낼 것인가 |
| O | 특수자산·운영형 지표 | 일반 임대형과 다른 자산은 무엇을 추가로 보는가 |

# 제1부. 현장·공부·거래 용어

## A. 문서·중개업무·당사자

| 권장 표기 | 등급 | 현장 동의어·약어 | 뜻 | 사용상 주의 |
|---|---|---|---|---|
| 매각안내서 | 실무권장 | OM, 매물소개서, 매각제안서 | 매도 대상, 가격, 공부, 현황, 임대차, 위험요인을 정리해 초기 검토와 답사를 돕는 문서 | 법정 서식인 `중개대상물 확인·설명서`를 대신하지 않음 |
| 투자검토서 | 실무권장 | IM, 투자설명서 | 가격·임대수입·시장·위험·개선방안까지 연결해 매수 검토를 지원하는 문서 | 증권의 투자설명서와 혼동될 수 있어 문서 첫머리에 부동산 매각자료임을 명시 |
| 요약 매각안내서 | 실무권장 | 티저, Teaser | 핵심 가격·규모·입지·임대정보만 담은 짧은 자료 | 주소·임차인 정보 비공개 여부를 명시 |
| 중개대상물 확인·설명서 | 공식 | 확인설명서 | 개업공인중개사가 법정 확인·설명사항을 적어 거래당사자에게 교부하는 서식 | 매각안내서와 별개이며, 비주거용 건축물 서식을 확인 |
| 거래계약서 | 공식 | 매매계약서, 임대차계약서 | 거래당사자, 물건, 금액, 지급, 인도, 권리이전, 특약 등을 정하는 문서 | 초안·체결본·수정본을 구분 |
| 중개 | 공식 | 알선 | 중개대상물의 매매·교환·임대차 등 권리의 득실변경을 거래당사자 사이에서 알선하는 행위 | 감정평가·법률·세무 자문과 업무범위를 혼동하지 않음 |
| 개업공인중개사 | 공식 | 대표 공인중개사 | 중개사무소 개설등록을 하고 중개업을 하는 자 | `중개업자`라는 구표현보다 공식 명칭 권장 |

## 6. 숫자 표기의 필수 꼬리표

숫자는 값 자체보다 **무슨 값인지**가 중요하다. 다음 꼬리표가 없으면 문서 자동발행을 막는 것이 원칙이다.

|---|---|---|
| 가격 | 가격 성격·기준일·포함범위·부가세 | `매도 희망가 50억원(건물분 부가가치세 별도, 2026-08-30)` |
| 면적 | 면적 종류·출처·㎡·평 환산 | `건축물대장상 연면적 825.40㎡(249.68평)` |

| 보증금 | 계약별 유효금액·합계기준일 | `임대차보증금 합계 3억원(유효계약 5건 기준)` |
| 수익률 | 지표명·분자·분모·기간·보증금/비용 처리 | `매도 희망가 기준 단순 임대수익률 2.16% = 연 기본임대료 1.08억원 ÷ 50억원` |
| 거리 | 출발·도착·경로·측정자료·조회일 | `○○역 2번 출구~대상물 보행경로 약 380m(지도 조회 2026-08-30)` |
| 도로 | 도로명·너비 출처·접면 | `북측 폭 약 12m 도로에 약 18m 접함(지적도·지도 추정)` |
| 공실률 | 기준일·공실면적·임대가능면적·산식 | `공실률 20.0% = 40㎡ ÷ 임대가능면적 200㎡` |
| 법정한도 | 법령·조례·계획·기준일·인센티브 여부 | `법정 용적률 상한 검토값 ○%; 지구단위계획 세부검토 전` |
| 공사비 | 범위·견적일·부가세·설계·예비비 | `공용부 개선비 약 1억원(2026-08 견적 1건, 부가세 별도, 설계비 미포함)` |

# 제3부. 문서 작성 규칙

## 7. 같은 사실을 네 가지 상태로 쓰는 법

### 7.1 공부·계약서로 확인된 사실

> `건축물대장상 주용도는 제2종근린생활시설이며, 사용승인일은 2017-05-18이다.`

### 7.2 매도인 진술

> `매도인 진술에 따르면 3층은 2026년 7월부터 공실이다. 임대차 종료합의서는 미제공 상태다.`

### 7.3 중개인 현장확인

> `2026-08-28 현장확인 시 3층 출입문은 잠겨 있었고 영업 표시는 확인되지 않았다. 내부 점유상태는 미확인이다.`

### 7.4 분석가정과 의견

> `3층을 월 기본임대료 250만원으로 신규 임대하고 공실기간 4개월을 가정하면 연 기본임대료는 현재 대비 3,000만원 증가한다. 목표임대료는 인근 임대사례 추가 확인이 필요하다.`

한 문단에 네 상태를 섞지 않는다. 표나 문단 머리표시로 `공부확인`, `계약서확인`, `매도인 진술`, `현장확인`, `중개인 의견`, `분석가정`을 구분한다.

## 8. 자료가 없을 때의 표준 표현

| 상황 | 권장 표기 | 금지 표기 |
|---|---|---|
| 자료를 받지 못함 | 미제공 | 없음, 0 |
| 자료는 있으나 확인하지 않음 | 미확인 | 이상 없음 |
| 일부만 확인함 | 일부 확인: ○○ 확인, △△ 미확인 | 확인 완료 |
| 항목이 적용되지 않음 | 해당없음 | 미제공 |
| 문서 단계상 분석하지 않음 | 현 단계 미제공 | 분석 결과 0 |
| 서로 다른 값이 존재 | 불일치: A자료 ○○, B자료 △△ | 최신 것으로 임의 덮어쓰기 |
| 전문가 판단 필요 | 전문가 검토필요: 분야·질문 기재 | 중개인 추정으로 확정 |

## 9. 중개인 의견의 권장 문장 구조

중개인 의견은 다음 다섯 칸으로 작성한다.

| 순서 | 내용 | 질문 |
|---|---|---|
| 1 | 관찰사실 | 무엇이 확인됐나 |
| 2 | 해석 | 왜 매수자에게 의미가 있나 |
| 3 | 반대근거 | 무엇 때문에 해석이 틀릴 수 있나 |
| 4 | 확인과제 | 무엇을 더 확인해야 하나 |
| 5 | 거래조건 | 확인 전 어떤 조건을 붙여야 하나 |

**예시**

> 1층 월 기본임대료는 비교한 인근 1층 임대사례보다 3.3㎡당 약 12% 낮다. 갱신 시 임대료 조정 여지가 있을 수 있으나, 현 임차인의 계약갱신요구권 행사 가능기간과 매출 영향은 미확인이다. 임대차계약서 원본과 최근 12개월 입금내역을 확인하고, 매입의향서에는 임대차 조건 및 연체내역 확인을 실사조건으로 둘 것을 제안한다.

## 10. 영문 약어 사용 허용표

| 처리 | 용어 | 표기 예시 |
|---|---|---|
| 처음 한 번 병기 허용 | OM, IM | `매각안내서(OM)`, `투자검토서(IM)` |
| 전문지표에서 병기 허용 | NOI, Cap Rate, LTV, DSCR, IRR, WALE | `순영업소득(NOI)` 후 해당 절에서는 약어 사용 가능 |
| 계약문서에서 병기 허용 | LOI, NDA | `매입의향서(LOI)`, `비밀유지약정(NDA)` |
| 내부 기술문서에서만 허용 | Claim, Gate, Manifest, Snapshot, Fixture, Namespace | 사용자 화면·외부 문서에는 한국어 표시어 사용 |
| 외부 제목에서 사용 금지 | Goldilocks, Broker Lens, Price Position, Evidence Status | `표준 검토형`, `중개인 검토의견`, `가격 수준 검토`, `자료 확인현황` 사용 |

## 11. 외래어를 남겨도 되는 경우

다음 조건을 모두 만족할 때만 외래어를 보조적으로 남긴다.

1. 국내 상업용 부동산·금융 실무에서 약어가 널리 통용된다.
2. 정확한 한국어 명칭을 먼저 제시했다.
3. 산식 또는 계약상 정의를 문서 안에서 설명했다.
4. 중개인이 매수자의 질문에 그 뜻과 한계를 설명할 수 있다.
5. 한국어로 바꾸면 오히려 다른 법정 용어와 혼동되는 경우다.

`골디락스`, `렌즈`, `스냅샷`, `포스처`, `게이트`, `클레임`, `에비던스`는 위 조건을 충족하기 어렵기 때문에 외부 문서에서 사용하지 않는다.

## 15. 문장 현지화 예시

### 예시 1

- 변경 전: `Broker Goldilocks OM의 Decision Snapshot에서 Evidence Status와 Price Position을 제시한다.`
- 변경 후: `표준 검토형 매각안내서의 핵심 검토요약에서 자료 확인현황과 가격 수준 검토결과를 제시한다.`

### 예시 2

- 변경 전: `Rent Roll H2이면 Gross Yield Claim을 allow한다.`
- 변경 후: `임대차 현황표에 기본임대료·관리비와 필요한 합계 근거가 있으면, 산식을 표시한 단순 임대수익률을 사용할 수 있다.`

### 예시 3

- 변경 전: `Critical Conflict가 open이면 Gate에서 fail-closed한다.`
- 변경 후: `가격·면적·권리·보증금에 중대한 불일치가 남아 있으면, 발행검사에서 관련 내용과 계산을 확인 전 차단한다.`

### 예시 4

- 변경 전: `value_add Lens에서 rent gap과 capex action을 도출한다.`
- 변경 후: `가치개선 검토에서는 현 임대료와 비교 가능한 시장 임대료의 격차를 확인하고, 필요한 시설개선 항목·비용·기간을 제시한다.`

### 예시 5

- 변경 전: `DD/LOI에 handoff item을 연결한다.`
- 변경 후: `실사사항과 매입의향 조건에 전문가 검토필요 항목을 연결하고, 검토 분야·질문·필요자료를 명시한다.`

### 예시 6

- 변경 전: `PublicationManifest에 owner, consumer, version을 기록한다.`
- 변경 후: `발행이력표에 관리책임자, 사용모듈, 문서 버전을 기록한다.`

### 16.2 내부코드와 외부어의 일대일 대응 원칙

내부 코드가 영문이어도 다음 조건을 지킨다.

1. 하나의 내부 코드는 하나의 한국어 표시어만 가진다.
2. `rent` 하나로 기본임대료·관리비·월수입을 함께 담지 않는다.
3. `price` 하나로 호가·계약가·신고가를 함께 담지 않는다.
4. `area` 하나로 토지·대지·연면적·임대면적을 함께 담지 않는다.
5. `yield` 하나로 단순수익률·자본환원율·투자수익률을 함께 담지 않는다.
6. 미확인값을 숫자 0이나 빈 문자열로 저장하지 않는다.
7. 원자료값과 유효기준본 값을 서로 다른 필드·기록으로 보존한다.

## 18. AI 작성 금지규칙

AI는 다음 행위를 해서는 안 된다.

1. `미제공·미확인` 값을 0 또는 없음으로 바꾸기.
2. 채권최고액을 실제 대출잔액으로 쓰기.
3. 관리비를 근거 없이 임대수입에 전액 합산하기.
4. 계약만료일이 없는데 가중평균 잔여 임대차기간을 계산하기.
5. 운영비가 없는데 순영업소득·자본환원율을 계산하기.
6. 법정 용적률과 현황 용적률 차이만으로 증축 가능면적을 확정하기.
7. 지도 직선거리로 `도보 ○분`을 확정하기.
8. 매물사례를 실거래사례로 표시하기.
9. 매도인 진술을 공부확인 사실로 바꾸기.
10. 불일치 값 중 문서에 유리한 값만 선택하기.
11. `우량·핵심·확정·안전·저평가·무위험` 같은 평가어를 근거 없이 붙이기.
12. 자료 유의사항으로 잘못된 계산이나 과장표현을 정당화하기.

## 22. 문서 관리규칙
