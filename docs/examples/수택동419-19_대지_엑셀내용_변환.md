# 3. 정밀 모드

## 3.1 P01_필지_제척 — 필지 및 제척

> **가상 증강·테스트용:** 필지별 면적 배분과 제척 조건은 원본 IM의 확정값이 아니다. 합계 651.2㎡만 IM 기재값이다.

| 지번 | 대장 면적(㎡) | 제척 사유 | 제척 면적(㎡) | 용적률 산정 제외 | 유효 면적(㎡) |
|---|---:|---|---:|---|---:|
| 구리시 수택동 419-19 | 412.5 | 해당 없음 | 0.0 | — | 412.5 |
| 구리시 수택동 419-12 | 158.3 | 도시계획도로 저촉 | 9.8 | 예 | 148.5 |
| 구리시 수택동 419-96 | 80.4 | 해당 없음 | 0.0 | — | 80.4 |
| **합계** | **651.2** |  | **9.8** |  | **641.4** |

> 419-12 필지에 도시계획도로 저촉 9.8㎡를 가정하면 유효 대지는 **641.4㎡**가 되며, 개발 가능 연면적은 약 **1.5% 감소**한다.

**산정식**

```text
유효 면적 = 대장 면적 - 제척 면적
합계 = 각 필지 값의 합
```

## 3.2 P02_개발규모 — 개발 가능 규모 시나리오

**기준:** 유효 대지면적 641.4㎡

| 시나리오 | 용적률 | 개발 가능 연면적(㎡) | 연면적(평) | 토지비 부담(원/연면적평) | 비고 |
|---|---:|---:|---:|---:|---|
| 상업 800% | 800% | 5,131.20 | 1,552.18 | 5,733,867 | 기본 |
| 상업 1,000% | 1,000% | 6,414.00 | 1,940.23 | 4,587,094 | 중간 |
| 허가 목표 1,260% | 1,260% | 8,081.64 | 2,444.69 | 3,640,551 | IM 기재 |
| 상업 1,500% | 1,500% | 9,621.00 | 2,910.34 | 3,058,063 | 낙관 |

### 기준값

| 항목 | 값 |
|---|---:|
| 유효 대지면적 | 641.4㎡ |
| 매매가 | 8,900,000,000원 |
| 토지 평단가 | 약 45,180,620원/평 |

> 대지형 자산의 핵심 비교 지표는 단순 토지 평단가보다 **토지비 부담(원/연면적평)**이다. 용도지역이 서로 다른 물건을 토지 평단가만으로 비교해서는 안 된다.

**산정식**

```text
개발 가능 연면적(㎡) = 유효 대지면적 × 용적률
연면적(평) = 개발 가능 연면적(㎡) ÷ 3.3058
토지비 부담(원/연면적평) = 매매가 ÷ 연면적(평)
토지 평단가 = 매매가 ÷ (651.2㎡ ÷ 3.3058)
```

## 3.4 P04_취득원가

> **가상 증강·표준 요율:** 취득세율, 중개보수, 법무비 및 실사비는 실제 거래 구조와 적용 법령에 따라 달라질 수 있다.

| 구분 | 금액 | 산정 근거 |
|---|---:|---|
| 매매가 | 8,900,000,000원 | IM 기재 |
| 취득세(4.6%) | 409,400,000원 | 나대지 표준세율 |
| 중개보수(0.9% 이내) | 80,100,000원 | 법정 상한 내 협의 |
| 등록면허세·법무비 | 20,000,000원 | 추정 |
| 감정평가·실사 | 15,000,000원 | 추정 |
| **총취득원가** | **9,424,500,000원** | 합계 |

**산정식**

```text
취득세 = 매매가 × 4.6%
중개보수 = 매매가 × 0.9%
총취득원가 = 매매가 + 취득세 + 중개보수 + 등록면허세·법무비 + 감정평가·실사
```
