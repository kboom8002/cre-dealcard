# 실매물 골든 데이터 기반 전 주기 풀루프 휴먼 클릭스루 검수 가이드 (2선 완주)

- **인터랙티브 실행 워크벤치 경로**: `/qa-full-loop` (운영 환경 접속 시 `?qaKey=<발급키>` 포함)
- **대상 범위**: 내 사무소 프로필(`/broker/profile`) → 딜카드(`/broker/w/dealcards`) → IM·발표자료(`/broker/w/im`, `/broker/basic-im-studio/[buildingId]`, `/broker/im-approval/[buildingId]`) → 뉴스레터(`/broker/w/newsletter`) → 매수자 카톡·시크릿 열람(`/magazine/...`, `/dc/...`, `/im-lite/...`) → 고객 소통(`/broker/w/inbox`) → 공용 PC 로그아웃 소거
- **목표 소요시간**: 총 **36분** (`Loop 1` 17분 + `Loop 2` 19분, 총 14개 핵심 스텝)

---

## 1. 시작 전 물리적 3-창 세팅 (필수)

같은 브라우저 창에서 탭만 전환하면 로그인 세션 쿠키가 공유되어 **비로그인 매수자의 블라인드 마스킹이나 열람 링크 잠금(회수)**을 정확히 검증할 수 없습니다. 반드시 아래 3개 화면을 분리해 시작합니다.

| 창 구분 | 기기 / 브라우저 | 담당 역할 | 핵심 검증 목적 |
|:---:|:---|:---|:---|
| **창 A** | PC 크롬 일반 창 (로그인) | 중개사 본인 | 딜카드·IM·뉴스레터 발행, 고객 소통 자료 승인 및 링크 잠그기 |
| **창 B** | 실제 스마트폰 카카오톡 (`360~390px`) | 매수자 1 (원장 · 패밀리오피스) | 카톡 썸네일 지번 비노출, 모바일 한 손 조작, 자료 요청 제출 및 열람 해제 |
| **창 C** | PC 크롬 시크릿 창 (`Ctrl+Shift+N`) | 매수자 2 (경쟁 자산운용사) | Loop 2에서 매수자 1 링크만 닫았을 때 매수자 2 링크는 유지되는지(직교성) 대조 |

## 3. Loop 1 실행 순서 (17분 · 7단계)

1. **`L1-S1` 프로필 & 큰 글씨(`21px`) 확인 (`창 A`, 2분)**: `/broker/profile` 5대 법정 표기 확인 후 `/broker/w/dealcards`에서 `21px` 모드 전환 시 좌측 목록·하단 버튼 잘림이 없는지 확인합니다.
2. **`L1-S2` 동아빌딩 메모 입력 & 블라인드 딜카드 발행 (`창 A`, 3분)**: `/qa-full-loop`에서 `[현장 메모 원문 복사]` 후 붙여넣기 → 공개 티저에 `349-10`·`동아빌딩` 비노출 확인 → 발행 링크를 우측 코파일럿 ①번 칸에 기록합니다.
3. **`L1-S3` 비서울 대장 조회 · 억/원 입력 · 17행 임대 현황 · PPT 검수 (`창 A`, 4분)**:
   - `/broker/w/im`에서 부천 주소 조회(`535.60㎡ / 2,758.21㎡`) → 상단 파란 **`[억 단위]`** 칸에 **`58`**(또는 하단 `['원' 직접 입력]` 칸에 `5800000000`) 입력 후 `= 58억 원` 확인.
   - 17행 TSV 붙여넣기(주차타워 월 198만원 연면적 비왜곡 + 201호 임대 전환 시 수익률 상승 확인) → 사진 4장 첨부 후 **실제 PowerPoint에서 6~7면 2장 분할 및 스태킹 여백 육안 확인**.
4. **`L1-S4` 주간 뉴스레터 추천 연결 · F5 보존 · 링크·인사말 복사 (`창 A`, 3분)**:
   - `/broker/w/newsletter`에서 동아빌딩 딜카드 연결 + 제목·브리핑 작성 후 `F5` 새로고침 시 초기화되지 않고 보존되는지 확인합니다.
   - **`[구독자에게 보내기]`**(또는 `[발행하기]`) 완료 후 **`[링크 복사]`**로 공개 URL을 ④번 칸에 기록하고, **`[인사말 + 링크 복사]`**로 1,000자 이하·5대 법정 표기 포함 전달문을 확인합니다.
5. **`L1-S5` 스마트폰 카톡 인앱 클릭스루 · 자료 요청 · 구독 신청 (`창 B`, 2분)**:
   - 내 카톡에 링크 전송 → 썸네일 지번(`349-10`) 비노출 확인 → 뉴스레터 → 딜카드 → 모바일 IM 이동.
   - 자료 요청 창에 개별 복사 칩 4개(`정수빈 원장`, `010-5501-2389`, `sb.jung@example.kr`, 문의 내용)로 제출 후 뉴스레터 구독 폼에서도 연락처와 확인용 이메일(`sb.jung@example.kr`)로 구독 신청을 완료합니다.
6. **`L1-S6` 고객 소통함 승인 & 모바일 상세 열람 해제 (`창 A ↔ 창 B`, 2분)**: `/broker/w/inbox` 도착 확인 → **`[자료 보내기(승인)]`** 클릭 → 발급된 열람 링크를 ②번 칸에 넣고 스마트폰(`창 B`)에서 상세 임대 현황 열람 해제를 확인합니다.
7. **`L1-S7` 자동 오라클 프로브 1클릭 마감 (`창 A`, 1분)**: 우측 `[🔍 1초 자동 오라클 & 블라인드 프로브 실행]` 클릭 후 면적·블라인드·링크·구독자 인입 통과를 확인합니다.

## 4. Loop 2 실행 순서 (19분 · 7단계)

1. **`L2-S1` 법정 2중 차단 게이트(`400` 저장 차단 + `422` 발행 차단) 체험 후 복원 (`창 A`, 2분)**:
   - **1차 방어(`400`)**: `/broker/profile` 개설등록번호에 샘플값(`11680-2024-00123`) 입력 후 저장 → 저장 단계에서 즉시 `400` 차단 확인.
   - **2차 방어(`422`)**: 개설등록번호 칸을 비우고 저장한 뒤 딜카드/뉴스레터 발행 시도 → `422 STATUTORY_DISCLOSURE_INCOMPLETE` 차단 확인.
   - **복구**: 정상 등록번호(`11680-2025-04821`) 입력·저장 완료.
2. **`L2-S2` 3필지 합산(`1,452.20㎡`) · `1조 500억` 스모크 · 21행 통합계약 · `1,900억` 수익률 연동 (`창 A`, 4분)**:
   - `/broker/w/im`에서 역삼동 648-23 입력 시 총 대지 `1,452.20㎡` 확인.
   - 상단 파란 **`[억 단위]`** 칸에 **`10500`**을 잠시 넣어 `"1조 500억대"` 표기 확인 후 **`2000`**(`2,000억`) 복원 → 21행 TSV 붙여넣기(0원 합산행·자가사용 포함 `점유율 100.0%` / `2.50%`) 확인.
   - 이어서 **`[억 단위]`** 칸을 **`1900`**(`1,900억`)으로 낮춰 **`2.50% → 2.63%`** 실시간 수익률 연동 및 `F5` 보존을 확인합니다.
3. **`L2-S3` 발표자료 꾸미기(PPT 구성) · 검수/승인 화면(`/broker/im-approval`) 서버 숨김 (`창 A`, 3분)**:
   - `/broker/basic-im-studio/[buildingId]`에서 지도 영속화, `1180px` 2행 슬라이드 제목, PPT 출력용 `[포함/제외]` 토글을 확인합니다.
   - 외부 `/im-lite` 화면에서 민감 섹션을 서버 수준으로 숨기려면 `/broker/im-approval/[buildingId]`에서 섹션 숨김을 켜고 저장합니다.
4. **`L2-S4` 딜카드 발행 & 강남권역(GBD) 월간 뉴스레터 편입 (`창 A`, 3분)**: 블라인드 딜카드 발행(①번 칸 기록) 후 월간 뉴스레터에 연결·`[구독자에게 보내기]`(④번 칸 기록)하여 `648-23` 지번 노출 0건을 확인합니다.
5. **`L2-S5` 경쟁 매수자 2인(`창 B` vs `창 C`) 자료 요청 & 독립 승인 (`창 A ↔ 창 B·C`, 3분)**:
   - `창 B`(윤지혜 매니저, `010-2849-7105`)와 `창 C`(박매수 상무, `010-8888-7777`)에서 개별 복사 칩으로 각각 자료 요청 후 모두 `[자료 보내기(승인)]` 처리해 ②번·③번 칸에 각각 기록합니다.
6. **`L2-S6` 스레드 단건 잠금 vs 건물 전체 잠금 직교성 검증 (`창 A ↔ 창 B·C`, 3분)**:
   - **1단계(단건)**: 매수자 1(`창 B`) 스레드만 `[보낸 링크 잠그기]` → 확인창 체크박스 없이 바로 **`[잠그기]`** 실행 → **`창 B`는 차단되고 `창 C`(매수자 2)는 정상 열람 유지** 확인(프로브 ②=잠김 / ③=열림 동시 확인).
   - **2단계(건물 전체)**: 박매수 상무 스레드에서 `[보낸 링크 잠그기]` → **`☑ 이 건물 전체 열람 잠금 (모든 수신자 차단)` 체크 → `[잠그기]`** 실행 → `창 C`까지 100% 차단 확인.
7. **`L2-S7` 직접 등록 고객 삭제 · 공용 PC 잔여 키 소거 · 최종 Sign-off 제출 (`창 A`, 1분)**:
   - `/broker/w/inbox` `[+ 고객 직접 등록]`으로 등록한 테스트 고객의 우측 요약 카드 **`[고객 삭제]`**로 정상 삭제 확인 후 로그아웃.
   - `[🧹 공용 PC 브라우저 잔여 키 점검]`으로 임시 키 `0`건 확인 → 상단 `[📋 Sign-off]` 탭에서 `.md` 다운로드 및 `[☁️ 서버 최종 제출]` 완료.

## 5. 최종 승인(Go / No-Go) 판정 기준

- **즉시 출시 승인 (`GO`)**: 14개 스텝 중 `S0`/`S1` 결함 `0`건 + 우측 자동 오라클 프로브(면적·다필지·지번 블라인드·직교 링크 잠금·공용 PC 소거) 전 항목 통과
- **당일 핫픽스 후 재검증 (`HOLD`)**: 수치 왜곡, 지번 유출, 법정 표기 누락 통과, 단건 회수 시 타 고객 링크 동반 차단 등 `S0`/`S1` 결함 1건 이상 발생 시
