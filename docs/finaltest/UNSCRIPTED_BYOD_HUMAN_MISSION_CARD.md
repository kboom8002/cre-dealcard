## PART 2 · 이상덕 테스터 전용 10분 스팟 재확인 체크리스트 (V3 20건 + 핫픽스 확인)

> 새로 V4 전체를 반복할 필요 없이, **이전에 지적해 주신 핵심 8개 포인트만 10분 내 스팟 확인**해 주세요.

- [ ] **1. 딜카드 재생성·목록**: 기존 매물에서 새 메모로 재생성 시 면적·층수·특징이 새 매물로 덮어써지고, 1열 목록에 `방금` 대신 실제 시각과 슬림 고스트 아이콘(복제·삭제)만 깔끔히 뜨는지
- [ ] **2. 주소 `동N가` & 다크 OG**: `양평동4가`·`당산동5가`가 `양평동가`로 짤리지 않고, 카톡 공유 OG 썸네일(`kakao-v2` 포함) 글자 겹침이 없는지
- [ ] **3. IM 링크 시크릿 창 열람 (`P0-4`)**: IM `[🔗 IM 링크 복사]`로 복사한 주소를 **시크릿 창**에 붙여넣으면 매수자에게 바로 열리고 PPTX/스튜디오 버튼은 숨겨져 있는지 + 법정 대표자(`차상혁`)와 담당자가 구분되는지
- [ ] **4. IM 1천원 단위·렌트롤 미리보기**: 만원 입력칸 `0` 커서 걸림 없이 입력되고, 엑셀 적용 전 미리보기 단계부터 파란색 적용 버튼 + 예상 수익률이 뜨는지 + 기대수익률 미입력 시 비차단 안내로 바로 통과되는지
- [ ] **5. 뉴스레터 `?new=1` · `[×]` 지우기 · 4탭 유지**: 새로 쓰기 시 전 회차 문구가 남지 않고, 44px `[×]` 지우기 및 **4단계(`4. 발송·수신확인`)**에 실제 발송·열람 내역이 뜨는지 + `F5` 후 현재 탭 유지
- [ ] **6. 뉴스레터 발송 모드 일치**: 분할화면(`900px`)에서도 `웹 링크만 먼저 발행·복사` 또는 `예약` 선택이 하단 주 버튼과 100% 일치 동작하는지 + 추천 딜카드 폭이 300px로 좁아지지 않는지
- [ ] **7. 소통함 소속 배지·가짜 링크 제거**: 고객 이름 옆 `🏢 소속` 선명 노출, 미승인 `익명 열람객`에 가짜 초록색 링크 카드가 뜨지 않는지, 승인 시 토스트가 1개만 깔끔히 뜨는지
- [ ] **8. 큰글씨(`아주 크게`) · 분할화면(`900px`) 레이아웃**: 1열 목록 높이와 제목 폭이 깨지지 않고, 분할화면에서 상단/하단 메뉴 바가 이중으로 겹치지 않는지
