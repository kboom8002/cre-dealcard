### 1.2 🗺️ 한눈에 보는 시스템 화면 구조도 (처음 접속 시 길 찾기)

`https://credeal.net`에 로그인하면 상단 네비게이션 바(GNB)를 통해 **4개의 핵심 워크스페이스(작업실)**로 이동할 수 있습니다. 길을 잃으셨을 때는 아래 주소를 브라우저 주소창에 직접 입력하셔도 됩니다.

```
[상단 메뉴바 (GNB) - 4대 워크스페이스]
 ├─ ① 딜카드 쇼케이스 (/broker/w/dealcards) : 고객에게 카톡/문자로 보낼 요약형 1페이지 딜카드 제작 및 공유(/d/[id])
 ├─ ② IM 스튜디오     (/broker/w/im)        : [오늘의 주 무대!] 10장짜리 정식 PPTX IM 제작 및 웹 IM-Lite(/im-lite/[id]) 발행
 ├─ ③ 뉴스레터 매거진 (/broker/w/newsletter): 여러 매물을 묶어 VIP 고객용 매거진 뉴스레터로 편집·발행
 └─ ④ 고객 인박스     (/broker/w/inbox)     : 고객이 딜카드에서 신청한 '상세 정보 열람 요청(Gate)'을 확인하고 [승인/거절]하는 수신함
```

#### 🖥️ `② IM 스튜디오 (/broker/w/im)` 화면 안의 3단 구성
IM 스튜디오에 들어가면 화면이 크게 3단계(또는 좌우 패널)로 나뉩니다:
1. **왼쪽 사이드바 (`매물 목록` & `+ 새 매물` 버튼)**: 내가 만든 매물 리스트가 보이며, 상단의 **`+ 새 매물`** 버튼을 눌러 새 빌딩 작업을 시작합니다. (모바일에서는 상단 **`‹ 목록`** 버튼을 누르면 열립니다.)
2. **가운데 작업 영역 (3단계 탭)**:
   - **`① 기본정보 / 주소 조회`**: 지번이나 도로명 주소를 입력해 건축물대장·토지대장·공시지가를 자동으로 불러오고, 매매가와 투자 포스처(관점)를 설정합니다.
   - **`② 내용 채우기 (메모 · 렌트롤 · 섹션 편집)`**: 현장 중개 메모를 붙여넣고, 층별 임대현황(렌트롤) 표를 입력하며, AI가 작성한 투자 포인트 문구를 다듬습니다.
   - **`③ 미리보기 / 내보내기`**: 완성된 IM 슬라이드를 미리 보고 **`PPTX 다운로드`** 또는 **`웹 IM-Lite 공유 링크 복사`**를 실행합니다.

### 1.3 ⏱️ 스톱워치 측정 규칙 (왜 시간을 재나요?)
> **🔍 [왜 측정하나요?]**  
> 아무리 기능이 많아도 현업 중개사가 IM 하나 만드는 데 1시간씩 걸리면 상용 서비스로 실패합니다. 우리 시스템의 목표는 **"자료가 준비된 상태에서 8분 안에 10장짜리 컨설팅급 IM 완성하기"**입니다.

테스터 A는 각 매물(#1, #2, #3)을 시작할 때 스마트폰 스톱워치를 켜고 아래 3가지를 가볍게 체크해 주세요 (PART 7 채점표에 기록합니다):
1. **`TTF-IM (초안 완성 소요시간)`**: **`+ 새 매물`** 버튼을 누른 순간부터 → 주소 입력 → 메모/렌트롤 붙여넣기 → **첫 번째 `PPTX 다운로드` 파일이 내 PC에 저장된 순간까지의 시간** *(합격 기준: 매물당 **8분 이내**)*
2. **`망설임 횟수 (Hesitation)`**: *"어? 다음엔 어디를 눌러야 하지?"* 하고 **5초 이상 마우스를 멈추고 화면을 찾아 헤맨 횟수** *(합격 기준: 매물당 **2회 이하**)*
3. **`오작동/되돌리기 횟수 (Misclick)`**: 버튼을 눌렀는데 생각과 다르게 동작해서 취소하거나 다시 입력한 횟수 *(합격 기준: 매물당 **1회 이하**)*
