## 0. 시작 전 1분 화면 세팅 (가장 편한 듀얼 창 배치)

이번 테스트는 긴 글씨를 직접 타이핑하는 테스트가 아닙니다. **`credeal.net/testguide` 화면에 준비된 버튼들을 클릭해 복사(Ctrl+V)하고, 사진·CSV 파일을 내려받아 첨부**하면서 시스템이 빠르고 정확하게 작동하는지 확인하는 테스트입니다.

1. **모니터 왼쪽 절반(50%)**에 **[https://credeal.net/testguide](https://credeal.net/testguide)** 를 띄웁니다. (이미 열려 있다면 **`F5` 새로고침**을 한 번 눌러주세요.)
2. `/testguide` 화면 우측 상단의 파란색 **`[🚀 ② IM 스튜디오 열기]`** 버튼을 클릭합니다.
3. 새로 열린 **IM 스튜디오 창을 모니터 오른쪽 절반(50%)**에 배치하고, **중개사 계정 #1**로 로그인합니다.

│  • 상단 스톱워치 [▶ 타이머 시작]           │  • 좌측 목록 [+ 새 IM] 클릭               │

### ▶ Step 1. 상단 스톱워치 `[▶ 타이머 시작]` 누르기
1. `/testguide` 상단 검은색 바의 드롭다운이 현재 진행할 매물(예: `매물 #1 (동교동 77억)`)로 되어 있는지 확인합니다.
2. 초록색 **`[▶ 타이머 시작]`** 버튼을 누르고 오른쪽 IM 스튜디오에서 작업을 시작합니다.
3. **작업 중 카운터 기록 규칙**:
   - 화면에서 *"다음에 어디를 눌러야 하지?"* 하고 **3초 이상 멈칫**하면 상단 바의 **`망설임 [+1]`** 버튼을 누릅니다.
   - 버튼을 눌렀는데 반응이 없거나 에러가 나면 **`오작동 [+1]`** 버튼을 누릅니다.

### ▶ Step 2. IM 스튜디오 `① 건물 기본 정보` 탭 입력 (클릭 복사 → 붙여넣기)

2. 왼쪽 `/testguide`의 **Step X-1. 기본 정보 입력값 원클릭 복사** 구역에서 아래 순서대로 **`[📋 클릭 복사]`**를 눌러 오른쪽 IM 스튜디오에 `Ctrl+V`로 붙여넣습니다:
   - **① 건물 주소 (지번)**: 복사해서 IM 스튜디오 주소창에 붙여넣고 바로 옆의 **`[주소로 건물 정보 자동 채우기]`** 버튼을 클릭합니다! (대지면적·연면적·용도지역·층수·사용승인일이 자동으로 채워지는지 확인하세요.)
   - **② 표지 제목 (건물명)**: 복사해서 표지 제목란에 붙여넣습니다.
   - **③ 희망 매매가 ('억' 입력란)**: 복사해서 매매가 `'억'` 입력란에 붙여넣습니다 (`77`처럼 억 단위로 넣어도 되고 `770000`처럼 만원 단위로 붙여넣어도 자동으로 77억으로 인식됩니다).

     - 매물 #2 부천: **`58`** (= 58억 원)
     - 매물 #3 역삼동: **`2000`** (= 2,000억 원)
   - **④ 명도 및 인도 조건**: 복사해서 붙여넣습니다.
   - **⚠️ 매물 #3 (역삼동 여삼빌딩) 확인 포인트**:
     - 대장 자동 채움 직후 **3필지 합산 대지면적 `1452.2㎡`와 연면적 `14256.64㎡`**가 자동으로 채워지는지 확인합니다.

- **방법 A (1초 엑셀 복붙 — 가장 빠름)**:
  1. 왼쪽 `/testguide` **Step X-2** 우측 상단의 파란색 **`[📋 방법 A: 엑셀 붙여넣기용(TSV) 원클릭 복사]`** 버튼을 클릭합니다.
  2. 오른쪽 IM 스튜디오 `② 층별 임대 현황` 탭 아래쪽 표 우측 상단의 파란색 **`[📋 복사한 렌트롤 붙여넣기 (Ctrl+V)]`** 버튼을 클릭하거나, 화면에서 바로 **`Ctrl+V`**를 누르면 전체 호실이 1초 만에 채워집니다!

- **합계 확인**:
  - 렌트롤 표가 채워지면 표 맨 아래 합계줄의 **총 보증금 / 월 임대료 / 점유율**이 `/testguide` 노란색 안내 박스의 **📌 기대 합계**와 일치하는지 확인합니다.

## 3. Wave C: 테스터 B와의 합동 미션 (`/testguide` 탭 ④)

매물 3건의 IM 생성이 끝나면 `/testguide` 상단 탭에서 **`[🤝 4. Wave C 합동·보안 미션]`**을 클릭합니다. 상단 우측의 워크스페이스 바로가기 버튼(`① 딜카드`, `③ 뉴스레터`, `④ 인박스`)을 활용해 테스터 B와 호흡을 맞춰 진행합니다.

1. **[미션 C-1] 딜카드(`① 딜카드`) 생성 및 블라인드 공유 링크 전달**:
   - 상단 바의 **`[🃏 ① 딜카드]`** 버튼을 눌러 딜카드 워크스페이스를 엽니다.
   - 방금 만든 매물 3건의 딜카드를 확인하고 **블라인드 티저 공유 링크(`/d/...`)**를 복사해 **테스터 B**에게 메신저로 전달합니다.
2. **[미션 C-2] 인박스(`④ 인박스`) 열람 요청 1·2단계 승인**:
   - 테스터 B가 시크릿 창에서 주소·실명 공개 요청(관심 등록)을 보내면, 상단 바의 **`[📥 ④ 인박스]`** 버튼을 눌러 인박스를 엽니다.
   - 테스터 B의 요청 건을 찾아 **[1단계 승인 (주소·Lite IM 공개)]** → **[2단계 승인 (Pro IM·데이터룸 공개)]**을 차례로 클릭합니다.
3. **[미션 C-3] 뉴스레터(`③ 뉴스레터`) 매물 3건 묶음 발송**:
   - 상단 바의 **`[📰 ③ 뉴스레터]`** 버튼을 눌러 뉴스레터 편집기를 엽니다.
   - 오늘 등록한 매물 3건(동교동, 부천, 역삼동)을 뉴스레터 큐레이션에 담고 AI 마켓 브리핑을 생성한 뒤 발행 링크를 **테스터 B**에게 전달합니다.
4. 각 미션이 정상 동작하면 `/testguide` 탭 ④의 미션 카드에서 **`[PASS]`**를 클릭합니다.
