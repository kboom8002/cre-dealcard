# CreDeal IM 작성 매뉴얼 — 공통편

> **대상 독자**: CreDeal 시스템을 처음 사용하는 상업용 부동산 중개인
> **목적**: 투자보고서(IM) 작성의 기본 원리를 이해하고, CreDeal 시스템을 활용하여 전문적인 IM을 작성할 수 있도록 안내

---

## 1. IM(Investment Memorandum)이란?

IM(투자보고서)은 매수 희망자에게 부동산 투자 기회를 체계적으로 전달하는 전문 문서입니다.
잘 작성된 IM은 매수자의 의사결정 속도를 높이고, 중개인의 전문성을 보여줍니다.

### CreDeal이 지원하는 IM의 종류

| 산출물 | 설명 | 형식 |
|--------|------|------|
| **Mobile IM** | 카카오톡으로 즉시 공유할 수 있는 웹 뷰어 형태 IM | 웹 (마크다운) |
| **PPTX IM** | 대면 프레젠테이션 또는 이메일 첨부용 슬라이드 IM | PowerPoint |

---

## 2. 투자 관점(포스처)의 이해

**"이 건물을 사는 사람은 왜 사는가?"** — 이 질문에 대한 답이 바로 **포스처(투자 관점)**입니다.

CreDeal은 매물의 특성과 매수자의 목적에 따라 5가지 포스처를 제공합니다.
포스처에 따라 IM의 섹션 구성, 강조 포인트, 슬라이드 레이아웃이 자동으로 달라집니다.

| 포스처 | 매수자가 묻는 핵심 질문 | 대표 매물 예시 |
|--------|------------------------|---------------|
| 🏢 **임대수익형** (income) | "임대수익률이 얼마야?" | 역삼동 오피스, 건대입구 근생 |
| 🏠 **자가사용형** (owner_occupied) | "우리 회사 사옥으로 쓸 수 있어?" | 중소기업 사옥, 병원 건물 |
| 🏗️ **개발형** (development) | "허물고 새로 지으면 얼마나 남아?" | 노후 건물, 나대지, 재건축 대상 |
| 🏨 **운영형** (operating) | "운영해서 수익이 나와?" | 호텔, 요양시설, 물류센터 |
| 📈 **단기매매형** (trading) | "지금 사서 나중에 비싸게 팔 수 있어?" | 시세 대비 저평가 매물 |

> 💡 **팁**: 포스처를 잘못 선택하면 매수자가 원하는 정보가 빠지고, 불필요한 정보가 들어갑니다.
> 예를 들어 사옥 매수 희망자에게 렌트롤 분석을 상세히 보여줄 필요는 없습니다.

## 3. 발행 등급의 이해

입력한 데이터의 양과 질에 따라 **산출물의 종류 자체**가 달라집니다.

```
📊 데이터가 많을수록 → 더 깊은 분석이 가능한 IM이 생성됩니다

  ┌──────────────┐
  │ 내부 초안     │ ← 주소·가격만 → "이 정도론 외부 배포 불가"
  ├──────────────┤
  │ 사실형 OM     │ ← +공부·사진 → "사실 기반 매물소개서"
  ├──────────────┤
  │ 분석형 IM     │ ← +렌트롤/비교사례 → "수익 분석 포함 투자보고서"
  ├──────────────┤
  │ 의사결정 IM   │ ← +시나리오·기준일·B등급↑ → "매수 의사결정 지원"
  └──────────────┘
```

> ⚠️ **중요**: "데이터가 부족하면 수준을 낮춰서 발행"하는 것이지, 없는 데이터를 추측해서 채우지 않습니다.
> 이것이 CreDeal의 **책임 표시 원칙**입니다.

## 4. 데이터 출처 표시 (프로베넌스 뱃지)

IM의 모든 숫자에는 **"이 숫자가 어디서 왔는지"**를 표시합니다.

| 표시 | 의미 | 신뢰도 | 예시 |
|------|------|--------|------|
| ✓ 공부 확인 | 등기부·건축물대장 등 공적 서류에서 확인 | ★★★★★ | 대지면적, 연면적, 준공연도 |
| ✓ 계약서 확인 | 임대차 계약서에서 확인 | ★★★★ | 보증금, 월임대료 |
| ▲ 매도인 고지 | 매도인이 말한 내용 (서류 미확인) | ★★★ | 리모델링 이력 |
| ● 중개인 현장확인 | 중개인이 직접 현장에서 확인 | ★★★ | 공실 현황, 건물 상태 |
| ● 중개인 시장의견 | 중개인의 시장 경험에 기반한 의견 | ★★ | 예상 임대료 수준 |
| = 계산값 | 입력 데이터에서 산식으로 도출 | ★★★★ | Cap Rate, NOI |
| ◇ 분석가정 | 일반적 시장 가정 적용 | ★ | 공실률 가정, 관리비 추정 |
| ? 미확인 | 데이터 없음 | — | — |

> 💡 **팁**: "◇ 분석가정" 또는 "? 미확인"이 많으면 IM의 신뢰도가 낮아집니다.
> 가능한 한 "✓ 공부 확인"이나 "● 중개인 현장확인" 수준으로 데이터를 확보해 주세요.

## 5. 공통 섹션 설명

모든 포스처에 공통으로 들어가는 섹션들입니다.

### 5.1 자산 개요 (Property Overview)

**목적**: 매수자가 "이 건물이 무엇인지" 30초 안에 파악할 수 있게 합니다.

**포함 항목**:
- 건물 명칭 및 주소 (지번/도로명)
- 매매 희망가
- 대지면적 / 연면적 / 전용면적
- 용도지역 (일반상업, 준주거 등)
- 준공연도, 층수, 주차 대수
- 건폐율 / 용적률

**CreDeal 자동 처리**:
- 건축물대장·토지대장에서 면적·층수·준공일 자동 조회
- 공시지가 자동 조회 및 평당가 환산
- 토지이용계획 조회 (용적률·건폐율 법정 상한)

**직접 작성 시 주의**:
- 면적 단위는 ㎡ 기준으로 입력하고, 시스템이 평으로 자동 환산합니다
- 가격은 만원 단위로 입력합니다 (예: 250억 → 2,500,000만원)

---

### 5.2 입지 분석 (Location & Access)

**목적**: "이 건물이 어디에 있고, 얼마나 접근이 좋은지" 설명합니다.

**포함 항목**:
- 최근접 지하철역 및 도보 소요시간
- 주요 도로 접근성 (간선도로, 고속도로 IC)
- 주변 인프라 (상업시설, 학교, 병원 등)
- 권역 정보 (CBD/GBD/YBD 등)

**CreDeal 자동 처리**:
- 카카오맵 API로 최근접 지하철역·도보시간 자동 조회
- 주변 POI(편의시설) 자동 집계
- 광역교통 다이어그램 자동 생성 (YBD/GBD/CBD 권역)
- 지적도 이미지 자동 조회 (V-World WMS)

---

### 5.3 등기부 권리관계 (Title & Rights)

**목적**: 매수 시 법적 장애물이 있는지 확인합니다.

**포함 항목**:
- 소유권 현황 (개인/법인, 지분 구조)
- 근저당 설정 현황 (채권최고액, 설정일)
- 전세권, 지상권, 가등기 유무
- 압류, 가압류, 경매 진행 여부

**CreDeal 자동 처리**:
- 등기정보광장 API에서 등기 요약 자동 조회
- 근저당 채권최고액 자동 산출
- 위험 항목(압류, 가등기) 자동 경고

---

### 5.4 리스크 (Risk Check)

**목적**: 매수 전 반드시 확인해야 할 위험 요소를 정리합니다.

**포함 항목**:
- 법적 리스크 (토지거래허가구역, 용도 위반 등)
- 물리적 리스크 (건물 노후, 구조 안전 등)
- 시장 리스크 (공실률 상승, 임대료 하락 등)
- 재무 리스크 (대출 조건, 이자율 변동 등)

**CreDeal 자동 처리**:
- 토지거래허가구역 자동 판정
- 건물 연식 기반 물리적 리스크 자동 분류
- Cap Rate 범위 이탈 경고

---

### 5.5 투자 포인트 (Investment Thesis)

**목적**: "왜 이 건물을 사야 하는가?" 3대 핵심 매력을 요약합니다.

**포함 항목**:
- 3대 핵심 투자 매력 (Pillar)
- 차별적 가치 제안
- 타 매물 대비 강점

**CreDeal 자동 처리**:
- AI가 전체 섹션 분석 결과를 종합하여 3대 투자 논거 자동 생성
- 중개인이 수동으로 수정 가능

---

### 5.6 실사 체크리스트 (Checklist)

**목적**: 매수자가 실사(Due Diligence)에서 반드시 확인해야 할 사항을 정리합니다.

**CreDeal 규칙**:
- 모든 포스처에 필수 포함 (누락 시 발행 차단)
- 포스처별로 강조 체크 항목이 다름

---

### 5.7 거래 일정 (Next Steps)

**목적**: 매수 의향 표시 후 실제 거래까지의 절차를 안내합니다.

**포함 항목**:
- 매도인 조건 (거래 희망 시기, 특이 조건)
- 예상 일정 (LOI → 실사 → 계약 → 잔금)
- 필요 서류 목록

## 7. CreDeal 시스템 활용 가이드

### 7.1 데이터·정보 입력 방법

#### Step 1: 딜카드 생성
1. CreDeal 대시보드에서 **"새 딜카드"** 클릭
2. 기본 정보 입력:
   - **주소** (지번 또는 도로명) — 입력하면 공공데이터 자동 조회 시작
   - **매매 희망가** (만원 단위)
   - **자산 유형** (오피스, 근린생활시설, 상가 등)
   - **투자 관점(포스처)** 선택

#### Step 2: 보강 정보 입력 (Supplemental Input)
딜카드 생성 후, IM 품질을 높이기 위해 추가 정보를 입력합니다:

| 입력 항목 | 설명 | 입력 예시 | 해당 포스처 |
|-----------|------|----------|------------|
| **월임대료 총액** | 전체 층 월세 합계 (원) | 15,000,000 | income |
| **공실 현황** | 현재 비어있는 층/호실 | "3층 전체 공실" | income |
| **공실률** | 전체 대비 공실 비율 (%) | 15 | income |
| **보증금 합계** | 전 층 보증금 합계 (만원) | 50,000 | income |
| **관리비 합계** | 월 관리비 총액 (만원) | 800 | 공통 |
| **융자(채권최고액)** | 근저당 설정액 (만원) | 150,000 | 공통 |
| **연간 운영비** | 실측 운영비 총액 (원) | 120,000,000 | income |
| **브로커 한줄 코멘트** | 핵심 투자 포인트 1줄 | "역세권 5분 만실 빌딩" | 공통 |
| **예상 수익률** | 중개인 판단 수익률 (%) | 4.5 | income |

#### Step 3: 층별 임대 데이터 입력 (렌트롤)
임대수익형(income) 매물의 핵심 데이터입니다:

```
층 | 업종/임차인 | 전용면적(평) | 보증금(만원) | 월세(만원) | 관리비(만원) | 계약만기
---|-----------|------------|------------|---------|------------|--------
B1 | 주차장     | 50         | -          | -       | -          | -
1F | 약국       | 15         | 5,000      | 250     | 50         | 2027-03
2F | 이비인후과  | 30         | 10,000     | 400     | 80         | 2026-12
3F | 공실       | 30         | -          | -       | -          | -
```

> 💡 **팁**: 렌트롤 데이터가 정확할수록 Cap Rate·NOI 계산이 정확해지고,
> 발행 등급이 "분석형 IM" 이상으로 올라갑니다.

#### Step 4: 사진 업로드
- **대표 사진 1장** (히어로 이미지) — 표지 및 요약 슬라이드에 사용
- **건물 사진 최대 12장** — 갤러리 슬라이드에 사용
- 카테고리: 외관 전면/측면, 로비, 엘리베이터, 주차장, 옥상, 층별 내부 등

#### Step 5: 유사 거래 사례 입력 (Pro IM용)
비교사례 분석 강화를 위한 수동 입력:

| 항목 | 설명 |
|------|------|
| 주소 | "서교동 395-12" |
| 거래금액 (만원) | 850,000 |
| 연면적 (㎡) | 450 |
| 거래년월 | 2025년 8월 |

### 7.2 IM 생성 및 검토 흐름

```
① 딜카드 생성    ② 보강 정보 입력    ③ IM 생성 요청
     ↓                  ↓                  ↓
  주소·가격         렌트롤·사진      "IM 생성" 버튼 클릭
     ↓                  ↓                  ↓
  공공데이터        데이터 등급(A~D)    ← 자동 → Mobile IM + PPTX IM
  자동 조회         자동 산출                     생성 (약 30~90초)
```

**생성 후 확인 사항**:
1. **발행 등급** 확인 → "사실형 OM"이면 데이터 보강 권장
2. **경고 메시지** 확인 → "? 미확인" 항목 보완
3. **수치 정합성** 확인 → Cap Rate, NOI가 실제와 맞는지 확인

### 7.3 PPTX 스튜디오 편집 방법

CreDeal PPTX 스튜디오는 **8단계 파이프라인**으로 운영됩니다:

```
S00 초기화 → S10 편성 → S20 카피 → S30 레이아웃
     → S40 미리보기 → S50 품질검수 → S60 편집 승인 → S70 파일 승인
```

#### 편집 가능 항목

| 항목 | 편집 방법 | 주의사항 |
|------|----------|---------|
| **슬라이드 순서** | 드래그 앤 드롭으로 재배치 | 표지·마감은 이동 불가 |
| **슬라이드 숨김** | 슬라이드 우클릭 → "숨기기" | 필수 슬라이드는 숨길 수 없음 |
| **텍스트 수정** | 토큰 에디터에서 직접 수정 | 수정 이력 자동 기록 |
| **색상 변경** | 스타일 피커에서 테마 컬러 선택 | |
| **슬라이드 미리보기** | SVG 미리보기로 실시간 확인 | |

#### 승인 프로세스

1. **S60 편집 승인**: 내용이 정확한지 중개인이 최종 확인 → "편집 승인" 버튼
2. **S70 파일 승인**: PPTX 파일 다운로드 후 실제 열어서 확인 → "파일 승인" 버튼
3. 승인 완료 후 **정본 다운로드** 가능 (파일 해시값으로 위변조 방지)

### 7.5 활용 시 주의사항

> [!CAUTION]
> **반드시 숙지해야 할 사항**

#### ① 투자자 페르소나 노출 금지
- ❌ "60대 자산가를 위한 투자" — 이런 표현은 IM에 절대 포함하면 안 됩니다
- ✅ "안정적 임대수익을 원하는 투자자" — 이렇게 중립적으로 표현합니다

#### ② 한국 실무 용어 사용
- ❌ "네이밍 라이츠", "캡레이트" (외래어 직역)
- ✅ "간판 설치권", "연 순수익률 (Cap Rate)" (한국 실무 표현)

#### ③ 수치의 출처 확인
- CreDeal이 "◇ 분석가정"으로 표시한 수치는 **실제 데이터가 아닙니다**
- 매수자에게 전달 전, 반드시 실제 데이터로 교체하거나 가정임을 명시하세요

#### ④ 면책조항 유지
- IM 마감 면의 면책조항은 **절대 삭제하면 안 됩니다**
- 법적 분쟁 발생 시 중개인을 보호하는 중요한 장치입니다

#### ⑤ 발행 전 최종 확인
- "내부 초안" 등급의 IM은 **외부 배포 금지**입니다
- 발행 전 반드시 PPTX 스튜디오의 S60/S70 승인을 완료하세요
