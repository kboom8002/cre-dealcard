# CreDeal IM 작성 매뉴얼 — 🏢 임대수익형 (Income)

> **포스처**: 임대수익형 (income)
> **적용 대상**: 임대 중인 오피스·근생·상가 등 **월세 수익**이 핵심인 매물
> **매수자의 핵심 질문**: "이 건물의 임대수익률이 얼마야?"

---

## 1. 이 포스처는 언제 선택하나요?

다음 조건에 해당하면 **임대수익형**을 선택합니다:

- ✅ 현재 임차인이 있고 월세를 받고 있는 건물
- ✅ 매수 후에도 계속 임대하여 수익을 얻을 목적
- ✅ Cap Rate(수익환원율)이 투자 판단의 핵심 기준
- ✅ 앵커 임차인(장기 안정 임차인)이 있는 건물

**선택하면 안 되는 경우**:
- ❌ 전체 공실이고 매수자가 직접 사용할 예정 → **자가사용형**
- ❌ 노후 건물을 허물고 신축할 예정 → **개발형**
- ❌ 호텔·요양시설 등 직접 운영 수익 → **운영형**

---

## 2. Income 아키타입 — "같은 수익형이라도 이야기가 다르다"

CreDeal은 임대수익형을 6가지 세부 아키타입으로 분류합니다.
아키타입에 따라 PPTX의 핵심 슬라이드가 달라집니다.

| 아키타입 | 설명 | 이런 매물에 해당 |
|---------|------|-----------------|
| **임대 안정형** (R-INC-01) | 장기 임차인 확보, 안정적 현금흐름 | 만실 오피스, 앵커 임차인 빌딩 |
| **가치 상승 여력형** (R-INC-02) | 용적률 여유, 증축/리포지셔닝 가능 | 저층 건물 with 높은 법정 용적률 |
| **임대료 정상화형** (R-INC-04) | 현재 임대료가 시세보다 낮음 | 오래된 계약, 갱신 시 인상 가능 |
| **공실 해소형** (R-INC-05) | 공실이 있지만 유치 전략이 있음 | 부분 공실 빌딩, 리테넌팅 기회 |
| **리모델링형** (R-INC-06) | 리모델링으로 임대료·자산가치 상승 | 노후 but 구조 양호한 빌딩 |
| **기본** (기타) | 위에 해당하지 않는 일반 수익형 | 일반적인 임대 수익 건물 |

> 💡 **팁**: CreDeal이 데이터를 분석하여 자동으로 아키타입을 추천합니다.
> 중개인이 수동으로 변경할 수도 있습니다.

## 3. 섹션별 작성 가이드 (12섹션)

### 📌 섹션 1: 자산 개요 (Property Overview)
> 필수 ✅ | 공통 섹션

**작성 목표**: 30초 안에 "어떤 건물인지" 파악

**필수 기재 항목**:

| 항목 | 작성 예시 | CreDeal 자동 처리 |
|------|----------|-------------------|
| 소재지 | 서울시 강남구 역삼동 xxx-xx | ✓ 주소 정규화 |
| 매매 희망가 | 250억 원 | 입력값 사용 |
| 대지면적 | 452.3㎡ (136.8평) | ✓ 건축물대장 자동 조회 |
| 연면적 | 2,816.4㎡ (851.9평) | ✓ 건축물대장 자동 조회 |
| 용도지역 | 일반상업지역 | ✓ 토지이용계획 자동 조회 |
| 준공연도 | 2005년 | ✓ 건축물대장 자동 조회 |
| 층수 | 지하 2층 / 지상 10층 | ✓ 건축물대장 자동 조회 |
| 주차 | 자주식 30대 | 중개인 입력 |
| 건폐율 / 용적률 | 59.8% / 789.3% | ✓ 건축물대장 자동 조회 |
| 엘리베이터 | 승용 2기 | ✓ 건축물대장 자동 조회 |

**직접 작성 시 CreDeal 적용 규칙**:
- 면적은 ㎡ 기준이 원본이고, 평은 환산값입니다 (1평 = 3.305785㎡)
- 가격 표기: "250억 원" (한국 실무 표현)
- 용도 분류: 건축물대장의 주용도 그대로 사용

### 📌 섹션 2: 입지 분석 (Location & Access)
> 공통 섹션

**작성 목표**: 건물의 위치적 가치와 접근성 설명

**기재 항목**:
- 최근접 역: "2호선 역삼역 도보 3분 (250m)"
- 버스 정류장: "역삼역 정류장 도보 1분"
- 간선도로: "테헤란로 직접 접면"
- 주변 환경: "강남 테헤란로 오피스 밀집 지구"

**CreDeal 자동 처리**:
- 카카오맵 POI 조회 (지하철, 버스, 편의시설)
- YBD/GBD/CBD 권역 자동 분류
- 광역교통 다이어그램 자동 생성 (PPTX A06 슬라이드)

---

### 📌 섹션 3: 등기부 권리관계 (Title & Rights)
> 공통 섹션

**작성 목표**: 매수에 법적 장애물이 없는지 확인

**기재 항목**:
- 소유자: "○○법인 (단독 소유)"
- 근저당: "NH농협은행, 채권최고액 120억 원"
- 기타: "전세권 설정 없음, 가등기 없음"

**CreDeal 자동 처리**:
- 등기정보광장 API 자동 조회 (있을 경우)
- 근저당 → 예상 융자금 역산 (채권최고액의 약 77~83%)
- 위험 항목(압류, 가처분) 자동 경고

---

### 📌 섹션 4: 토지 상세 (Land Detail)
> 공통 섹션

**작성 목표**: 토지의 법적 조건과 가치 분석

**기재 항목**:
- 공시지가: "2025년 기준 ㎡당 12,500,000원 (평당 41,322,000원)"
- 법정 용적률: "일반상업지역 1,300%"
- 현재 사용 용적률: "789%"
- 용적률 여유: "511%p (39.3% 미사용)"
- 토지이용계획: "일반상업지역, 방화지구"

**CreDeal 자동 처리**:
- V-World 공시지가 조회
- 토지이용계획 조회 (용도지역, 용도지구, 용도구역)
- 토지거래허가구역 판정
- 용적률 여유(FAR Headroom) 자동 계산

### ⭐ 섹션 5: 임대차 현황 (Lease Status) — 강조 섹션
> 필수 ✅ | 강조 ⭐ | **이 섹션이 income IM의 핵심입니다**

**작성 목표**: 임차인 구성과 임대 안정성을 한눈에 파악

**렌트롤 작성 항목** (층별):

| 항목 | 설명 | 입력 예시 |
|------|------|----------|
| 층 | 층수 표기 | "B1", "1F", "2F~3F" (병합 가능) |
| 업종/임차인 | 임차인명 또는 업종 | "NH농협캐피탈(주)", "약국" |
| 전용면적 | 평 기준 | 30 |
| 보증금 | 만원 단위 | 10,000 |
| 월임대료 | 만원 단위 | 400 |
| 관리비 | 만원 단위 | 80 |
| 계약 시작일 | YYYY-MM-DD | 2024-01-01 |
| 계약 종료일 | YYYY-MM-DD | 2026-12-31 |
| 공실 여부 | 체크박스 | ☑ |

**핵심 파생 지표** (CreDeal 자동 계산):

| 지표 | 설명 | 계산 방법 |
|------|------|----------|
| **WALE** | 가중평균잔여임대기간 | Σ(면적 × 잔여기간) / Σ면적 |
| **공실률** | 전체 대비 공실 면적 비율 | 공실면적 / 전체임대면적 × 100 |
| **앵커 비율** | 앵커 임차인 면적 비율 | 앵커면적 / 전체면적 × 100 |
| **환산보증금** | 보증금의 월세 환산액 | 보증금 × 환산율(2.5%) / 12 |
| **실효임대료** | 실제 수취 가능 임대료 | 월세 + 환산보증금 월세 |

**직접 작성 시 CreDeal 적용 규칙**:
- 공실인 층은 반드시 `is_vacant: true`로 표시
- 매출연동 임대료는 `rent_type: 'revenue_linked'`로 구분
- 임대료 유형: 고정(fixed), 매출연동(revenue_linked), 단계적 인상(stepped), 기본+매출연동(base_plus_percentage)

### ⭐ 섹션 6: 수익 분석 (Income Analysis) — 강조 섹션
> 필수 ✅ | 강조 ⭐

**작성 목표**: 투자수익률을 정밀하게 분석

**핵심 지표**:

| 지표 | 설명 | 계산 방법 |
|------|------|----------|
| **연 임대수입** | 연간 총 임대 수입 | (월세 합계 + 관리비 합계) × 12 |
| **NOI (순영업소득)** | 운영비 차감 후 순수입 | 연 임대수입 − 연간 운영비 |
| **Cap Rate** | 연 순수익률 | NOI / 총매입가 × 100 |
| **레버리지 수익률** | 대출 후 자기자본 수익률 | (NOI − 이자비용) / 자기자본 × 100 |
| **자기자본 소요** | 실제 필요 투자금 | 매매가 − 융자금 − 보증금 승계 |

**CreDeal 적용 규칙**:
- Cap Rate 산정 기준: `gross_price_deposit` (총매입가 = 매매가 − 보증금 승계)
- 운영비 실값이 없으면 → "◇ 분석가정"으로 업종별 표준 운영비 적용
- NOI가 음수이면 자동 경고
- Cap Rate가 1% 미만 또는 15% 초과이면 이상치 경고

**직접 작성 시 주의**:
- **수익률만으로 매입 판단을 하지 마십시오** — 이런 훈계성 문구는 IM에 넣지 않습니다 (CreDeal 품질 규칙)
- 가정에 기반한 수치는 반드시 출처를 "◇ 분석가정"으로 표기합니다

### 📌 섹션 7: 리스크 (Risk Check)
> 공통 섹션

**income 포스처 중점 리스크**:

- 📋 금리 상승 리스크 (레버리지 수익률 영향)
- 📋 건물 노후 리스크 (대수선 비용)

### 📌 섹션 8: 비교 매물 (Comparables)
> 선택 섹션

**작성 목표**: 유사 건물의 실거래가를 비교하여 적정 가격 판단

**기재 항목** (거래 사례별):
- 소재지, 거래금액, 연면적, 거래시점
- 평당가 비교: "대상 물건 2,935만원/평 vs 비교사례 평균 3,100만원/평"

**CreDeal 자동 처리**:
- 국토부 실거래가 API 자동 조회 (반경 500m 내 유사 거래)
- 거래사례비교법(Sales Comparison) + 수익환원법(Income Capitalization) 이중 밸류에이션
- 중개인이 수동으로 비교 사례 추가 가능

## 4. PPTX 슬라이드 구성 (Income)

전체 슬라이드 시퀀스 (아키타입 R-INC-01 기준):

|------|---------|---------|------|
| 1 | 표지 | A01 | 건물명, 주소, 매매가, 대표 사진 |
| 2~3 | 갤러리 | A14 | 건물 사진 (사진 있을 때) |
| 4 | 핵심 지표 | A02 | Cap Rate, NOI, 자기자본, 레버리지 수익률 |
| 5 | 입지 | A06 | 지도 + 교통 접근성 다이어그램 |
| 6 | 토지 | A04 | 대지면적, 공시지가, 용적률 |
| 7 | 건물 | A04 | 연면적, 층수, 준공일, 구조 |
| 8 | 렌트롤 | A03 | 층별 임차인·면적·임대료 테이블 |
| 9 | 스태킹플랜 | A22 | 건축 입면 셋백 (데이터 있을 때) |
| 10 | 임대안정성 | A04 | WALE, 앵커 비율, 만기 분포 |
| 11 | 수익구조 | A05 | NOI 워터폴, Cap Rate 비교 |
| 12 | 비교사례 | A03 | 실거래 비교 테이블 |
| 13 | 투자 논거 | A15 | 3대 투자 매력 Pillar |
| 14 | 리스크 | A07 | 3대 리스크 카테고리 |
| 15 | 체크리스트 | A18 | 실사 확인 항목 |
| 16 | 진행 절차 | A09 | LOI → 실사 → 계약 타임라인 |
| 17 | 마감 | A10 | 면책조항, 연락처 |

## 5. Income IM 작성 시 자주 하는 실수

| 실수 | 올바른 방법 |
|------|------------|
| 공실 층을 렌트롤에서 빼고 입력 | 공실도 반드시 포함 (is_vacant 체크) |
| 관리비를 월세에 합산하여 입력 | 월세와 관리비를 분리 입력 |
| 보증금 없는 층을 0이 아닌 빈칸으로 둠 | 0으로 명시 입력 |
| Cap Rate를 직접 계산하여 기재 | 시스템이 자동 계산 — 입력값이 정확하면 됨 |
