# CreDeal IM 작성 매뉴얼 — 🏠 자가사용형 (Owner Occupied)

> **포스처**: 자가사용형 (owner_occupied)
> **적용 대상**: 매수자가 **직접 사옥/사무실로 사용**할 목적의 매물
> **매수자의 핵심 질문**: "우리 회사가 쓰기에 적합해? 임차보다 나아?"

---

## 1. 이 포스처는 언제 선택하나요?

- ✅ 매수자가 법인 또는 개인사업자로, 직접 사용 목적
- ✅ 사옥·클리닉·학원·연구소 등 자가 운영
- ✅ 임대수익이 아닌 **공간 활용**이 핵심 가치
- ✅ 자가소유 vs 임차의 비용 비교가 의사결정의 핵심

**선택하면 안 되는 경우**:
- ❌ 매수 후 임대하여 수익을 얻을 목적 → **임대수익형**
- ❌ 일부만 자가 사용하고 나머지는 임대 → 상황에 따라 임대수익형 또는 자가사용형

---

## 2. 섹션별 작성 가이드 (9섹션)

### 📌 섹션 1: 자산 개요 (Property Overview)
> 필수 ✅

**자가사용형 중점 기재 항목**:

| 항목 | 왜 중요한가 | 작성 예시 |
|------|------------|----------|
| 전용률 | 실제 사용 면적 비율 | "전용률 62.4% (전용 532평 / 연면적 852평)" |
| 엘리베이터 | 직원 동선 효율 | "승용 2기, 비상 1기 (10층 기준 적정)" |
| 주차 대수 | 직원·방문객 주차 | "자주식 30대 (직원 50명 기준 60% 충족)" |
| 천장고 | 사무 환경 쾌적성 | "2.7m (표준) / 1층 로비 4.5m" |
| 단독 사용 가능 여부 | 브랜딩·보안 | "전체 단독 사용 가능 (간판 설치권 포함)" |

**CreDeal 적용 규칙**:
- "네이밍 라이츠" ❌ → "**사옥 단독 명칭 표기(간판 설치권)**" ✅
- "브랜딩 라이츠" ❌ → "**기업 단독 브랜딩**" ✅

---

### 📌 섹션 2: 입지 분석 (Location & Access)
> 공통 섹션

**자가사용형 중점 포인트**:
- **직원 통근 접근성**: "2호선 역삼역 도보 3분 → 강남 거주 직원 통근 최적"
- **대중교통 밀집도**: 지하철, 버스 노선 수
- **주차 편의성**: 주차장 출입 동선, 기계식/자주식
- **주변 편의시설**: 식당가, 카페, 은행, 병원

---

### 📌 섹션 3: 등기부 권리관계 (Title & Rights)
> 공통 섹션

**자가사용형 추가 확인**:
- 소유권 이전에 장애 되는 요소 (가등기, 전세권)
- 기존 임차인 명도 필요 여부
- 용도 변경 필요 여부 (예: 근생 → 업무시설)

---

### ⭐ 섹션 4: 사옥 적합성 (Occupancy Fit) — 강조 섹션
> 필수 ✅ | 강조 ⭐ | **이 섹션이 자가사용형의 핵심입니다**

**작성 목표**: "이 건물이 우리 회사에 맞는지" 판단 근거 제공

**기재 항목**:

| 항목 | 설명 | 작성 예시 |
|------|------|----------|
| **공간 배치 적합성** | 필요 면적 대비 여유 | "직원 80명 기준 1인당 3.3평, 전용 264평 필요 → 전용 532평으로 여유" |
| **층별 활용 계획** | 어떤 층을 어떻게 쓸지 | "1F 로비·접견실, 2~5F 사무실, 6F 회의실·임원실" |
| **간판 설치·브랜딩** | 건물 외관 활용 | "전면 간판 설치 가능, 건물 전체 단독 브랜딩" |
| **IT·통신 인프라** | 서버실, 네트워크 | "전기 300kW, 통신실 B1 별도 구획" |
| **리모델링 용이성** | 인테리어 변경 가능성 | "라멘 구조, 내부 자유 레이아웃 변경 가능" |

**CreDeal 적용 규칙**:
- 자가사용형에서는 렌트롤이 비활성화됩니다 (suppress)
- 기존 임차인이 있는 경우에도, 분석 초점은 "명도 후 자가 사용"에 맞춥니다

---

### ⭐ 섹션 5: 비용 비교 (Cost Comparison) — 강조 섹션
> 강조 ⭐

**작성 목표**: 자가소유 vs 계속임차의 TCO(총소유비용) 비교

**비교 항목**:

| 비용 항목 | 자가소유 (연간) | 임차 유지 (연간) |
|-----------|----------------|-----------------|
| 건물 취득비 (분할 상환) | 12억 원 | — |
| 취득세·등록세 | 1.2억 원 (1회성 ÷ 10년) | — |
| 관리비·유지보수 | 1.8억 원 | 포함 |
| 감가상각 절세 효과 | △0.8억 원 | — |
| 임대료 | — | 4.8억 원 |
| 보증금 기회비용 | — | 0.3억 원 |
| **연간 순비용** | **14.2억 원** | **5.1억 원** |
| **10년 누적 비용** | **142억 원** | **51억 원** |
| **자산 잔존가치** | **+200억 원 (예상)** | **0원** |

**CreDeal 적용 규칙**:
- 자기자본 대비 절감 효과 자동 계산
- 손익분기 기간(Breakeven Years) 자동 산출
- 대출 이자를 반영한 실질 비용 비교

---

### 📌 섹션 6: 리스크 (Risk Check)
> 공통 섹션

**자가사용형 중점 리스크**:
- 📋 건물 노후에 따른 대수선 비용
- 📋 용도 변경 인허가 리스크
- 📋 기존 임차인 명도 소요기간·비용
- 📋 자산 가치 하락 리스크

---

### 📌 섹션 7: 투자 포인트 (Investment Thesis)

**자가사용형 핵심 논거 예시**:
1. **임차 대비 비용 절감**: "10년 기준 연평균 2.1억 원 절감, 8.5년 손익분기"
2. **자산 가치 확보**: "강남 역세권 자산, 10년 후 예상 잔존가치 200억 원"
3. **기업 브랜딩 효과**: "건물 전체 단독 사용, 기업 이미지 제고"

---

### 📌 섹션 8: 실사 체크리스트 (Checklist)
> 필수 ✅

**자가사용형 체크 항목**:
- [ ] 기존 임차인 명도 가능 시점 확인
- [ ] 용도 변경 필요 여부 및 인허가 기간
- [ ] 리모델링·인테리어 비용 견적
- [ ] 주차장 직원 배정 계획
- [ ] IT 인프라 구축 비용 (전기, 통신, 냉난방)

## 4. 자가사용형 작성 시 자주 하는 실수

| 실수 | 올바른 방법 |
|------|------------|
| 렌트롤·수익률 분석을 넣음 | 자가사용형에서는 suppress됨 — 비용 비교에 집중 |
| "사옥으로 최적" 같은 주관적 판단만 기재 | 구체적 수치(전용률, 주차비율, 통근시간)로 근거 제시 |
| 기존 임차인 명도 비용을 무시 | 명도 비용·시간을 리스크에 반드시 포함 |
| 취득세를 비용 비교에서 누락 | 자가소유 총비용에 취득세·등록세 포함 |
