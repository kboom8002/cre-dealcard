# CreDeal IM 작성 매뉴얼 — 🏗️ 개발형 (Development)

> **포스처**: 개발형 (development)
> **적용 대상**: 기존 건물을 **철거·신축** 또는 **대규모 리모델링**할 목적의 매물
> **매수자의 핵심 질문**: "허물고 새로 지으면 얼마나 남아?"

---

## 1. 이 포스처는 언제 선택하나요?

- ✅ 노후 건물을 철거하고 신축할 계획
- ✅ 나대지(빈 토지) 매입 후 개발
- ✅ 용적률 여유가 크고 증축/재건축이 유리한 입지
- ✅ 사업수지(투입비 vs 분양/임대 수입)가 핵심 판단 기준

**선택하면 안 되는 경우**:
- ❌ 기존 건물을 그대로 두고 임대할 예정 → **임대수익형**
- ❌ 인테리어만 바꾸고 용적률 변동 없이 리모델링 → **임대수익형 (R-INC-06 리모델링형)**

> ⚠️ **CreDeal 특칙**: 개발형은 전문가 검토 없이 "의사결정 IM" 발행이 불가합니다.
> "분석형 IM(Screening)" 수준까지만 시스템이 자동 생성합니다.

## 2. 섹션별 작성 가이드 (10섹션)

### 📌 섹션 1: 자산 개요 (Property Overview)
> 필수 ✅

**개발형 중점 기재 항목**:

| 항목 | 왜 중요한가 | 작성 예시 |
|------|------------|----------|
| 대지면적 | 개발 규모의 기본 | "495.3㎡ (149.8평)" |
| 현재 건물 현황 | 철거 대상 파악 | "1978년 준공, RC조 3층, 노후 심각" |
| 접도 조건 | 인허가·시공 핵심 | "12m 도로 접면 (남서향)" |
| 도시계획 | 개발 가능 밀도 | "준주거지역, 건폐율 60%·용적률 400%" |

---

### 📌 섹션 2: 입지 분석 (Location & Access)
> 공통 섹션

**개발형 중점 포인트**:
- 개발 후 상품성을 결정하는 입지 요소
- 주변 신축 사례 및 분양가 수준
- 배후 수요 (오피스 수요, 주거 수요, 상가 수요)

---

### 📌 섹션 3: 등기부 권리관계 (Title & Rights)
> 공통 섹션

**개발형 추가 확인**:
- 지상권 설정 여부 (철거 장애)
- 분쟁 이력 (인접지 경계, 일조권 분쟁)
- 토지 지분 구조 (공동 소유 시 합의 필요)

---

### 📌 섹션 4: 토지 상세 (Land Detail)
> 공통 섹션 (개발형에서 특히 중요)

**기재 항목**:

| 항목 | 설명 | 작성 예시 |
|------|------|----------|
| **법정 용적률** | 건축 가능 최대 밀도 | "준주거지역 400%" |
| **법정 건폐율** | 대지 점유 상한 | "60%" |
| **토지이용계획** | 용도지역·지구·구역 | "준주거, 방화지구, 미관지구" |
| **도로 접면** | 접도 조건 | "12m 도로 남서측 접면" |
| **토지 형상** | 정형/부정형 | "정방형, 접도 대비 깊이 1:1.3" |
| **토지거래허가구역** | 거래 제한 여부 | "비해당" |
| **공시지가** | 토지 가치 기준 | "2025년 ㎡당 8,500,000원" |

---

### ⭐ 섹션 5: 대지 분석 (Site Analysis) — 강조 섹션
> 필수 ✅ | 강조 ⭐ | **이 섹션이 개발형의 핵심 1입니다**

**작성 목표**: "이 토지에 무엇을 얼마나 지을 수 있는가"

**기재 항목**:

| 항목 | 설명 |
|------|------|
| **건축 가능 규모** | 용적률 소화 시 예상 연면적 |
| **일조권 영향** | 인접지 건물 높이, 일조 사선 |
| **지형 조건** | 지반, 경사, 지하수위 |
| **인접지 관계** | 합필 가능성, 맹지 여부 |
| **인허가 예상 기간** | 건축허가 ~ 착공까지 예상 소요 |

**CreDeal 자동 처리**:
- 법정 용적률에서 현재 용적률을 빼 **용적률 여유(FAR Headroom)** 자동 계산
- 토지이용계획에서 특별 구역(문화재보호, 군사시설보호 등) 자동 경고
- 지적도 자동 조회로 토지 형상 시각화

---

### ⭐ 섹션 6: 사업 수지 (Development Feasibility) — 강조 섹션
> 필수 ✅ | 강조 ⭐ | **이 섹션이 개발형의 핵심 2입니다**

**작성 목표**: 투입비 대비 사업 수입을 분석하여 개발 이익 산출

**사업수지표 구성**:

```
[투입비]
├─ 토지비         : 매매가 + 취득세 + 중개수수료
├─ 철거·명도비     : 철거 비용 + 명도 보상비
├─ 건축비         : 연면적 × 평당 건축비
├─ 설계·인허가비   : 설계비 + 감리비 + 인허가 비용
├─ 금융비         : PF 이자 (공사기간 × 이자율)
├─ 기타           : 분양대행, 마케팅, 예비비
└─ 합계           : 총 투입비

[사업수입]
├─ 분양 수입      : 분양면적 × 예상 분양가
├─ 임대 수입      : 임대면적 × 예상 임대료 (PV)
└─ 합계           : 총 사업수입

[사업성]
├─ 개발이익       : 총수입 − 총투입비
├─ 개발이익률     : 개발이익 / 총투입비 × 100
└─ 자기자본수익률  : 개발이익 / 자기자본 × 100
```

**직접 작성 시 주의**:
- 건축비 단가는 **용도별 표준** 적용 (오피스: 평당 600~800만 원, 근생: 500~700만 원)
- 공사기간은 규모별 표준 적용 (5층 이하 12개월, 10층 이하 18개월, 15층 이상 24개월)
- PF 금리는 현재 시장 금리 반영 (2025년 기준 6~8%)

**CreDeal 적용 규칙**:
- ⚠️ 사업수지의 가정 항목은 모두 "◇ 분석가정" 표시 필수
- CreDeal은 개발 사업의 **Screening(사전 검토)** 수준의 분석만 제공
- 본격적인 사업타당성(Feasibility Study)은 전문가 검토 필요

---

### 📌 섹션 7: 리스크 (Risk Check)
> 공통 섹션

**개발형 중점 리스크**:
- 📋 **인허가 리스크**: 건축 허가 불확실성, 조건부 허가
- 📋 **명도 리스크**: 기존 임차인 명도 소요 기간·비용
- 📋 **공사 리스크**: 공사비 상승, 공기 지연
- 📋 **시장 리스크**: 준공 시점의 분양/임대 시장 변동
- 📋 **금융 리스크**: PF 금리 변동, 대출 실행 불확실성

---

### 📌 섹션 8: 투자 포인트 (Investment Thesis)

**개발형 핵심 논거 예시**:
1. **용적률 여유**: "법정 400% 대비 현재 120% → 280%p 추가 개발 가능"
2. **입지 프리미엄**: "역세권 도보 2분, 주변 신축 오피스텔 분양가 평당 2,800만 원"
3. **개발이익**: "예상 개발이익률 18.5%, 자기자본 수익률 32%"

---

### 📌 섹션 9: 실사 체크리스트 (Checklist)
> 필수 ✅

**개발형 체크 항목**:
- [ ] 인허가 사전 검토 (구청 건축과 확인)
- [ ] 기존 임차인 명도 가능 시점·비용 확인
- [ ] 지반 조사 보고서 확인 (지하수위, 암반 깊이)
- [ ] 인접지 일조권·조망권 분쟁 가능성
- [ ] PF 대출 가능 여부 사전 탐색
- [ ] 주변 신축 공급 계획 확인

---

### 📌 섹션 10: 거래 일정 (Next Steps)

**개발형 특화 일정**:
```
매매계약 → 잔금 → 명도(3~6개월) → 설계·인허가(6~12개월) → 착공 → 준공(12~24개월) → 분양/임대
```

## 4. 개발형 작성 시 자주 하는 실수

| 실수 | 올바른 방법 |
|------|------------|
| 명도 비용·시간을 과소평가 | 최소 3~6개월, 명도 보상비 별도 산정 |
| 건축비를 너무 낮게 잡음 | 시장 표준 단가 적용 + 예비비 10% |
| 인허가를 확정으로 기재 | "인허가 사전 검토 필요" ◇ 분석가정 표시 |
| 분양가를 낙관적으로만 산정 | Base/Upside/Downside 3시나리오 제시 |
| 금융비를 빠뜨림 | PF 이자(공사기간 전체)를 투입비에 포함 |
