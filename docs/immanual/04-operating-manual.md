# CreDeal IM 작성 매뉴얼 — 🏨 운영형 (Operating)

> **포스처**: 운영형 (operating)
> **적용 대상**: 호텔·모텔·요양시설·물류센터 등 **직접 운영**으로 수익을 내는 매물
> **매수자의 핵심 질문**: "운영해서 실제로 얼마나 벌어?"

---

## 1. 이 포스처는 언제 선택하나요?

- ✅ 호텔, 모텔, 펜션 등 숙박시설
- ✅ 요양원, 실버타운 등 복지시설
- ✅ 물류센터, 창고 (자가운영)
- ✅ 매출(Revenue)과 GOP(실질 영업이익)가 핵심 지표
- ✅ 운영사(위탁운영 또는 자가운영) 역량이 수익을 결정

**선택하면 안 되는 경우**:
- ❌ 건물을 통째로 임대하고 운영은 임차인이 → **임대수익형**
- ❌ 물류센터를 3PL에 통임대 → **임대수익형**

### ⭐ 섹션 5: 운영 개요 (Operation Overview) — 강조 섹션
> 필수 ✅ | 강조 ⭐ | **이 섹션이 운영형의 핵심 1입니다**

**작성 목표**: 현재 운영 실태와 운영사 역량 평가

**기재 항목**:

| 항목 | 설명 | 작성 예시 |
|------|------|----------|
| **운영사 정보** | 위탁/자가, 운영사명, 경력 | "자가운영, ○○호텔&리조트(주), 업력 12년" |
| **운영 계약** | 위탁 조건 (수수료, 기간) | "위탁 수수료 매출의 5%, 잔여 계약 3년" |
| **인력 현황** | 직원 수, 인건비 비중 | "정규직 45명, 인건비 비중 35%" |
| **객단가 (ADR)** | 평균 객실 판매 가격 | "ADR 12만 원 (2024년 평균)" |
| **가동률 (OCC)** | 객실 점유율 | "연평균 78.5%" |
| **RevPAR** | 가용객실당 수입 | "RevPAR 9.4만 원" |

**CreDeal 적용 규칙**:
- 용어: "GOP" ❌ → "**실질 영업이익 (GOP)**" ✅
- KPI 지표(ADR, OCC, RevPAR)는 반드시 기준 기간 명시 (연간/월간)
- 운영사 변경 가능성은 리스크 섹션에서 다룸

---

### ⭐ 섹션 6: GOP 분석 (GOP Analysis) — 강조 섹션
> 필수 ✅ | 강조 ⭐ | **이 섹션이 운영형의 핵심 2입니다**

**작성 목표**: 실질 영업이익을 기반으로 투자 수익률 분석

**GOP 산출 구조**:

```
[매출 (Revenue)]
├─ 객실 매출     : 객실수 × ADR × OCC × 365
├─ F&B 매출     : 식음 매출 (레스토랑, 바, 룸서비스)
├─ 기타 매출     : 연회, 스파, 주차 등
└─ 총매출       : ─────────────────────

[운영비 (Operating Expense)]
├─ 인건비       : 직원 급여·복리후생
├─ 식자재비     : F&B 원가
├─ 수선유지비   : 시설 유지보수
├─ 수수료       : 예약 채널 수수료, 위탁 수수료
├─ 유틸리티     : 전기·수도·가스·냉난방
├─ 기타 운영비  : 마케팅, 소모품, 보험
└─ 총운영비     : ─────────────────────

[GOP (실질 영업이익)]
= 총매출 − 총운영비
GOP 마진 = GOP / 총매출 × 100

[투자 지표]
GOP Cap Rate = GOP / 매매가 × 100
```

**핵심 지표 요약**:

| 지표 | 설명 | 일반 기준 |
|------|------|----------|
| **GOP 마진** | 매출 대비 영업이익률 | 호텔 30~45%, 요양 25~35% |
| **GOP Cap Rate** | 매매가 대비 GOP 수익률 | 6~10% |
| **ADR** | 평균 객실 단가 | 시장 경쟁력 판단 |
| **OCC** | 가동률 | 시장 수요 판단 |
| **RevPAR** | 가용객실당 수입 (ADR × OCC) | 종합 운영 효율 |

**CreDeal 적용 규칙**:
- GOP는 감가상각, 법인세, 금융비용 **차감 전** 영업이익
- 계절성 분석: 월별 매출 변동 패턴 시각화 (PPTX에서 자동)
- 운영비 실값이 없으면 업종별 표준 비율 적용 + "◇ 분석가정" 표시

### 📌 섹션 7: 리스크 (Risk Check)
> 필수 ✅

**운영형 중점 리스크**:
- 📋 **용도 적법성**: 관광숙박업 허가 조건, 용도 위반 가능성
- 📋 **운영사 리스크**: 운영사 변경 시 매출 변동
- 📋 **시장 리스크**: 관광 수요 변동, 경쟁 시설 공급
- 📋 **계절성 리스크**: 비수기 매출 급감 가능성
- 📋 **인력 리스크**: 인건비 상승, 숙련 인력 확보 난이도

> ⚠️ **특별 아키타입 R-OPR-04 (용도 리스크형)**: 용도 적법성에 문제가 있는 매물은
> 자동으로 `legality_warning` 섹션이 삽입되고, 리스크가 강조됩니다.

### 📌 섹션 8: 투자 포인트 (Investment Thesis)

**운영형 핵심 논거 예시**:
1. **안정적 GOP**: "GOP 마진 38%, 연 GOP 18억 원, GOP Cap Rate 7.2%"
2. **시장 성장**: "강남 MICE 수요 연 8% 성장, ADR 상승 여력"
3. **운영 효율화 기회**: "객실 리노베이션으로 ADR 15% 인상 → GOP 22억 원 예상"

## 4. 운영형 작성 시 자주 하는 실수

| 실수 | 올바른 방법 |
|------|------------|
| 월세 기반 Cap Rate로 분석 | 운영형은 **GOP 기반** 분석 (월세 아님) |
| 매출만 보고 운영비를 무시 | GOP = 매출 − 운영비, 반드시 운영비 파악 |
| 성수기 매출만 기준으로 산정 | **연평균** 매출로 산정, 비수기 반영 |
| 허가 조건을 확인 안 함 | 관광숙박업 허가 조건 위반 시 영업정지 리스크 |
| OTA 평점·리뷰를 무시 | 매출에 직접 영향 — 실사에서 반드시 확인 |
