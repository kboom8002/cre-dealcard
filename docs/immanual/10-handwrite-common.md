# 상업용 부동산 IM 수기 작성 매뉴얼 — 공통편

> **목적**: IM(Investment Memorandum, 투자보고서)을 처음 작성하는 중개인이
> 개념·용어·방법론을 이해하고, 수기로도 전문적인 IM을 작성할 수 있도록 교육
>
> **대상**: IM 작성 경험이 없는 상업용 부동산 중개인

---

## 제1장. IM이란 무엇인가

### 1.1 IM의 정의

IM(Investment Memorandum)은 한국에서 **"투자보고서"** 또는 **"투자안내서"**로 불리며,
매도인(또는 중개인)이 매수 희망자에게 부동산의 투자 가치를 체계적으로 전달하는 전문 문서입니다.

단순 매물 광고와 IM의 차이:

| 구분 | 매물 광고 | IM (투자보고서) |
|------|----------|----------------|
| 목적 | 매물 존재를 알림 | 투자 의사결정을 지원 |
| 내용 | 주소, 가격, 사진 | 수익 분석, 리스크, 비교사례, 시장 분석 |
| 분량 | 1~2장 | 12~20페이지 |
| 독자 | 불특정 다수 | 구체적인 매수 검토자 |
| 효과 | 관심 유도 | **의사결정 근거 제공** |

### 1.2 IM의 종류

| 종류 | 분량 | 용도 | 누가 쓰는가 |
|------|------|------|------------|
| **OM (Offering Memorandum)** | 5~10p | 사실 기반 매물 소개 | 중개인 |
| **Analysis IM** | 12~16p | 수익·리스크 분석 포함 | 중개인 + 분석가 |
| **Decision IM** | 16~25p | 매수 의사결정 완전 지원 | 자산운용사, IB |

> 💡 초심자는 **OM → Analysis IM** 순서로 학습하면 됩니다.

### 1.3 좋은 IM의 조건

1. **사실에 기반** — 모든 수치의 출처가 명확
2. **구조적** — 정해진 섹션 순서대로 체계적으로 구성
3. **수치 정합** — 한 곳에 적은 숫자가 다른 곳에서도 일치
4. **편향 없음** — 장점만 나열하지 않고, 리스크도 공정하게 기재
5. **매수자 관점** — "중개인이 말하고 싶은 것"이 아니라 "매수자가 알고 싶은 것"

## 제2장. 핵심 용어 사전

### 2.1 면적 관련

| 용어 | 정의 | 단위 환산 |
|------|------|----------|
| **대지면적** | 건물이 앉은 토지의 면적 (등기부 기재) | 1평 = 3.305785㎡ |
| **건축면적** | 건물의 바닥 면적 (건폐율 계산 기준) | |
| **연면적 (GFA)** | 모든 층 바닥면적의 합계 | |
| **전용면적** | 임차인이 독점 사용하는 면적 | |
| **임대면적** | 전용면적 + 공유면적 배분분 | 계약서 기준 |
| **전용률** | 전용면적 ÷ 임대면적 × 100 | 60~70%가 일반적 |

**면적 환산 공식**:
```
평 → ㎡ : 평수 × 3.305785 = ㎡
㎡ → 평 : ㎡ ÷ 3.305785 = 평수

예시: 100평 = 100 × 3.305785 = 330.58㎡
예시: 1,000㎡ = 1,000 ÷ 3.305785 = 302.50평
```

### 2.2 가격 관련

| 용어 | 정의 | 계산 |
|------|------|------|
| **매매가 (총액)** | 건물 매수 총 금액 | |
| **평당가** | 연면적 1평당 가격 | 매매가 ÷ 연면적(평) |
| **㎡당가** | 연면적 1㎡당 가격 | 매매가 ÷ 연면적(㎡) |
| **토지 평당가** | 대지 1평당 가격 | 매매가 ÷ 대지면적(평) |
| **공시지가** | 정부가 매년 공시하는 토지 단가 | 국토부 발표 |

**가격 표기 관례**:
```
만원 단위: 2,500,000만원 = 250억 원
억원 단위: 250억 원 (가장 일반적)
원 단위  : 25,000,000,000원 (계산용)
```

### 2.3 수익률 관련

| 용어 | 정의 | 공식 |
|------|------|------|
| **총수입** | 연간 임대 수입 합계 | (월세 합계 + 관리비 수입) × 12 |
| **NOI** | 순영업소득 (Net Operating Income) | 총수입 − 운영비 |
| **Cap Rate** | 연 순수익률 (Capitalization Rate) | NOI ÷ 총매입가 × 100 |
| **레버리지 수익률** | 대출 활용 후 자기자본 수익률 | (NOI − 이자) ÷ 자기자본 × 100 |
| **총수익률 (IRR)** | 투자 전체 기간 수익률 | 현금흐름 + 매도차익 종합 |

### 2.4 임대 관련

| 용어 | 정의 |
|------|------|
| **렌트롤 (Rent Roll)** | 전 층 임차인·면적·보증금·월세를 정리한 표 |
| **보증금** | 임대 시작 시 임차인이 맡기는 금액 |
| **월세 (월임대료)** | 매월 임차인이 지급하는 임대료 |
| **관리비** | 공용부분 유지비 (전기, 수도, 경비, 청소 등) |
| **환산보증금** | 보증금을 월세로 환산한 값 |
| **실효임대료** | 월세 + 환산보증금의 월 환산액 |
| **WALE** | 가중평균잔여임대기간 (Weighted Average Lease Expiry) |
| **공실률** | 전체 임대 가능 면적 중 비어있는 비율 |
| **앵커 임차인** | 건물의 핵심 장기 임차인 (보통 가장 큰 면적 점유) |

### 2.5 토지·건축 관련

| 용어 | 정의 |
|------|------|
| **용도지역** | 토지의 이용 목적 분류 (일반상업, 준주거, 일반주거 등) |
| **건폐율** | 대지면적 대비 건축면적 비율 (대지를 얼마나 채우는가) |
| **용적률** | 대지면적 대비 연면적 비율 (얼마나 높게 짓는가) |
| **접도** | 건물 부지가 접한 도로의 폭과 방향 |
| **근저당** | 은행이 건물에 설정한 담보권 |
| **채권최고액** | 근저당으로 설정된 최대 채무 금액 |

### 2.6 금융 관련

| 용어 | 정의 |
|------|------|
| **LTV** | 매매가 대비 대출 비율 (Loan to Value) |
| **DSR / DSCR** | 원리금상환 비율 (수익 대비 이자 부담) |
| **자기자본** | 매매가 − 대출금 − 승계 보증금 |
| **PF (프로젝트 파이낸싱)** | 개발 사업 목적 대출 |
| **DCF** | 미래 현금흐름 할인법 (Discounted Cash Flow) |

## 제3장. IM 작성 전 준비 — 자료 수집

### 3.1 필수 수집 서류

| 순번 | 서류 | 어디서 구하나 | 필수/선택 |
|------|------|-------------|----------|
| 1 | **등기부등본** (갑구·을구) | 인터넷등기소 (iros.go.kr) | 필수 |
| 2 | **건축물대장** | 정부24 (gov.kr) 또는 세움터 | 필수 |
| 3 | **토지대장** | 정부24 | 필수 |
| 4 | **토지이용계획확인서** | 토지이음 (eum.go.kr) | 필수 |
| 5 | **공시지가** | 부동산공시가격알리미 | 권장 |
| 6 | **실거래가 내역** | 국토부 실거래가 공개시스템 | 권장 |
| 7 | **임대차 계약서** | 매도인·임차인 요청 | 필수(수익형) |
| 8 | **관리비 정산 내역** | 관리사무소 요청 | 권장 |
| 9 | **건물 사진** | 직접 촬영 | 권장 |
| 10 | **현장 실사 메모** | 직접 조사 | 권장 |

### 3.2 현장 실사 체크 항목

```
□ 건물 외관 상태 (균열, 누수 흔적, 도장 상태)
□ 로비·공용부 상태 (청결, 조명, 엘리베이터 작동)
□ 주차장 (자주식/기계식, 실사용 가능 대수, 높이 제한)
□ 옥상 (방수 상태, 태양광·통신장비 유무)
□ 지하층 (침수 이력, 기계설비 상태)
□ 주변 환경 (소음, 혐오시설, 유동인구)
□ 도로 접면 (차량 진입 가능 여부, 도로 폭)
□ 공실 층 직접 확인 (상태, 임대 가능성)
```

## 제4장. 수기 IM 기본 구성 (공통 섹션)

### 4.1 전체 구성 틀

```
[ 표지 ]        ← 건물명, 주소, 매매가, 대표 사진
[ 핵심 요약 ]    ← 1페이지에 핵심 수치와 투자 포인트
[ 자산 개요 ]    ← 건물 기본 정보
[ 입지 분석 ]    ← 위치, 접근성
[ 포스처별 본문 ] ← 포스처에 따라 다른 핵심 분석
[ 리스크 ]       ← 위험 요소
[ 투자 포인트 ]  ← 왜 사야 하는가
[ 체크리스트 ]   ← 매수 전 확인 사항
[ 거래 일정 ]    ← 향후 절차
[ 면책조항 ]     ← 법적 보호 문구
```

### 4.2 표지 작성법

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    INVESTMENT MEMORANDUM

    [건물명 또는 주소]
    서울시 강남구 역삼동 xxx-xx

    매매 희망가: 250억 원

    [건물 대표 사진]

    작성일: 2025년 8월
    작성자: ○○부동산중개법인
    중개사: 홍길동 (02-xxxx-xxxx)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 4.3 핵심 요약 (Executive Summary) 작성법

1페이지에 매수 희망자가 가장 먼저 보는 숫자를 정리합니다.

```
┌───────────────────────────────────────┐
│        핵심 투자 지표 요약             │
├───────────────────────────────────────┤
│ 매매가      250억 원                   │
│ 연면적      2,816㎡ (852평)            │
│ 대지면적    452㎡ (137평)              │
│ 용도지역    일반상업지역                │
│ 준공연도    2005년 (건물연식 20년)       │
├───────────────────────────────────────┤
│ 연 임대수입  18.6억 원                 │  ← 수익형에만
│ NOI         15.2억 원                  │
│ Cap Rate    6.08%                     │
│ 자기자본    120억 원                   │
│ 레버리지 수익률  9.5%                  │
├───────────────────────────────────────┤
│ 핵심 투자 매력:                        │
│ 1. 역삼역 도보 3분 만실 오피스          │
│ 2. WALE 4.2년, 앵커 임차인 비중 65%    │
│ 3. 주변 시세 대비 5.3% 할인 매수 기회   │
└───────────────────────────────────────┘
```

### 4.4 자산 개요 작성법

건축물대장과 등기부에서 가져온 데이터를 정리합니다.

**작성 템플릿**:

```
■ 소재지:  서울시 강남구 역삼동 xxx-xx (도로명: 테헤란로 xxx)
■ 매매가:  250억 원 (평당 2,935만원)
■ 대지면적: 452.3㎡ (136.8평)  [출처: 토지대장]
■ 연면적:  2,816.4㎡ (851.9평) [출처: 건축물대장]
■ 용도지역: 일반상업지역        [출처: 토지이용계획확인서]
■ 건폐율:  59.8% (법정 80%)    [출처: 건축물대장]
■ 용적률:  789.3% (법정 1,300%) [출처: 건축물대장]
■ 구조:    철근콘크리트 (RC)    [출처: 건축물대장]
■ 층수:    지하 2층 / 지상 10층 [출처: 건축물대장]
■ 준공일:  2005. 06. 15        [출처: 건축물대장]
■ 주차:    자주식 30대          [출처: 현장확인]
■ 승강기:  승용 2기, 비상 1기   [출처: 건축물대장]
```

> 💡 **원칙**: 모든 숫자 옆에 `[출처]`를 명기합니다. 이것이 전문 IM과 아마추어 광고의 차이입니다.

### 4.5 입지 분석 작성법

```
■ 교통
  - 최근접 지하철: 2호선 역삼역 3번 출구 도보 3분 (약 250m)
  - 버스: 역삼역 정류장 도보 1분 (146번, 341번, 360번 외 12개 노선)
  - 차량: 테헤란로 직접 접면, 강남대로 차량 5분

■ 주변 환경
  - 권역: GBD (강남업무지구) 핵심
  - 식당가: 도보 3분 이내 음식점 200여 개
  - 금융: 주요 은행 지점 도보 5분 이내
  - 편의: GS25, CU 편의점 1분, 스타벅스 2분

■ 입지 장점
  - 테헤란로 대로변 접면으로 가시성 우수
  - GBD 핵심 입지, 오피스 임대 수요 풍부
```

### 4.6 리스크 작성법

4가지 카테고리로 구분하여 작성합니다:

```
■ 법적 리스크
  - 근저당 설정: 채권최고액 120억 원 (매도 시 말소 조건 확인 필요)
  - 토지거래허가구역: 비해당
  - 용도 위반: 없음

■ 물리적 리스크
  - 건물 연식 20년 → 향후 5~10년 내 대수선 발생 가능
  - 방수, 외벽, 엘리베이터 교체 비용 예상: 약 5~8억 원
  - 소방 검사 결과: 적합 (2024년 12월 기준)

■ 시장 리스크
  - GBD 권역 오피스 공실률 4.2% (2025.06 기준) — 안정적
  - 인근 대형 오피스 공급 예정 없음 (2025~2027)

■ 재무 리스크
  - 금리 1%p 상승 시 레버리지 수익률 9.5% → 7.8%로 하락
  - 앵커 임차인(NH농협캐피탈) 이탈 시 공실률 0% → 35%
```

### 4.7 면책조항 작성법 (필수)

> ⚠️ **절대 빠뜨리면 안 됩니다.** 법적 분쟁 시 중개인을 보호하는 핵심 장치입니다.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

본 투자보고서는 일반적인 정보 제공을 목적으로 작성되었으며,
특정 투자 결정을 권유하거나 보장하는 것이 아닙니다.

본 보고서에 포함된 정보는 공공 기록, 매도인 제공 자료, 중개인
현장 확인 등을 기반으로 작성되었으나, 그 정확성과 완전성을
보장하지 않습니다.

투자 결정은 반드시 매수자 본인의 독립적인 판단과 전문가
자문(법률, 세무, 감정평가 등)을 거쳐 이루어져야 합니다.

작성일: 2025년 8월 XX일
```

## 제5장. 공통 계산법

### 5.1 평당가 계산

```
평당가(만원/평) = 매매가(만원) ÷ 연면적(평)

예시:
  매매가: 250억 원 = 2,500,000만원
  연면적: 851.9평
  평당가: 2,500,000 ÷ 851.9 = 2,935만원/평
```

### 5.2 토지 평당가 계산

```
토지 평당가(만원/평) = 매매가(만원) ÷ 대지면적(평)

예시:
  매매가: 250억 원 = 2,500,000만원
  대지면적: 136.8평
  토지 평당가: 2,500,000 ÷ 136.8 = 18,275만원/평 (약 1.83억/평)
```

### 5.3 건폐율·용적률 확인

```
건폐율(%) = 건축면적 ÷ 대지면적 × 100
용적률(%) = 연면적(지상) ÷ 대지면적 × 100

예시:
  건축면적: 270.5㎡, 대지면적: 452.3㎡
  건폐율: 270.5 ÷ 452.3 × 100 = 59.8%

  연면적(지상): 3,569.2㎡, 대지면적: 452.3㎡
  용적률: 3,569.2 ÷ 452.3 × 100 = 789.3%
```

### 5.4 용적률 여유 계산

```
법정 용적률(도시계획): 1,300% (일반상업지역)
현재 용적률: 789.3%
용적률 여유: 1,300% − 789.3% = 510.7%p

→ "법정 용적률의 60.7%만 사용 중, 39.3% 여유"
→ 증축 또는 재건축 시 추가 연면적 확보 가능
```

## 제6장. 수기 작성 시 주의사항

### 6.1 수치 정합성 원칙

같은 숫자가 IM 내 여러 곳에 나오면 반드시 일치해야 합니다.

```
❌ 나쁜 예:
  표지에서 "250억", 본문에서 "252억", 요약에서 "248억"

✅ 좋은 예:
  모든 곳에서 "250억 원" (한 곳만 수정하면 다른 곳도 동시 수정)
```

> 💡 **팁**: 작성 후 검수 시, 매매가·면적·수익률 등 핵심 숫자를 Ctrl+F로 검색하여 일관성 확인

### 6.2 출처 표기 원칙

```
✅ "대지면적 452.3㎡ [건축물대장]"
✅ "공시지가 12,500,000원/㎡ [국토부 2025년]"
✅ "월세 400만원 [임대차계약서 2024.01.01]"
✅ "공실 현황: 3층 전체 공실 [현장확인 2025.08.15]"
⚠️ "예상 임대료 350만원/평 [중개인 시장의견]" ← 가정임을 명시
❌ "연면적 약 850평" ← 출처 없음, 부정확
```

### 6.3 용어 표기 원칙

| ❌ 잘못된 표기 | ✅ 올바른 표기 |
|---------------|---------------|
| 캡레이트 | 연 순수익률 (Cap Rate) |
| 네이밍 라이츠 | 사옥 단독 명칭 표기(간판 설치권) |
| GOP | 실질 영업이익 (GOP) |
| TI | 인테리어 지원금 (TI) |
| Rent Free | 렌트프리(무상임대) |
| NOI | 순영업소득 (NOI) |
| WALE | 가중평균잔여임대기간 (WALE) |

> **원칙**: 영문 약어를 쓸 때는 반드시 **한국어 풀이를 먼저** 쓰고 괄호 안에 영문을 넣습니다.

### 6.4 절대 넣으면 안 되는 표현

| ❌ 금지 표현 | 이유 |
|-------------|------|
| "60대 자산가에게 추천" | 특정 연령/계층 직접 지칭 금지 |
| "반드시 수익이 납니다" | 수익 보장 불가 |
| "이 가격에 못 삽니다" | 과장 광고 |
| "세금 걱정 없습니다" | 세무 조언 금지 (전문가 영역) |
| "수익률만으로 매입 판단을..." | 훈계성 문구 금지 (중개인 IM은 정보 제공) |
