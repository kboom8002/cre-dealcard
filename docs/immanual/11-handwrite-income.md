## 제1장. 임대수익형 IM의 핵심 — "이 건물의 돈 버는 구조"

임대수익형 IM의 존재 이유는 단 하나입니다:

> **"이 건물을 사면 임대료로 연 몇 %의 수익을 얻을 수 있는가?"**

이 질문에 답하려면 다음을 순서대로 분석해야 합니다:

```
① 렌트롤 정리 → ② NOI 산출 → ③ Cap Rate 계산 → ④ 레버리지 분석 → ⑤ 리스크 점검
```

## 제2장. 렌트롤 (Rent Roll) 작성법

### 2.1 렌트롤이란

렌트롤은 건물의 **"월세 장부"**입니다. 모든 층의 임차인·면적·보증금·월세·계약기간을 한눈에 보여줍니다.

### 2.2 렌트롤 수기 작성 템플릿

### 2.3 렌트롤에서 읽어내야 할 지표

작성한 렌트롤에서 아래 5가지 핵심 지표를 계산합니다:

#### ① 공실률

```
공실률(%) = 공실 면적 ÷ 전체 임대 가능 면적 × 100

예시:
  공실: 5F (45평)
  임대 가능 면적: 615평 − 140평(주차장+기계실) = 475평
  공실률 = 45 ÷ 475 × 100 = 9.47%
```

#### ② WALE (가중평균잔여임대기간)

```
WALE = Σ(각 임차인 면적 × 잔여기간) ÷ Σ(임차 중 면적)

예시 (기준일 2025.08):
  1F GS25:  25평 × 1.6년 = 40.0
  2F 이비인후과: 45평 × 1.3년 = 58.5
  3F 법률사무소: 45평 × 1.8년 = 81.0
  ... (전 층 합산)
  
  WALE = 합산 / 임차 중 면적 = ○○ / 430 = 약 X.X년
```

#### ③ 앵커 비율

```
앵커 임차인 비율(%) = 앵커 면적 ÷ 임차 중 면적 × 100

예시:
  앵커: 1F GS25(25평) + 8F 투자증권(90평) = 115평
  임차 중 면적: 430평
  앵커 비율 = 115 ÷ 430 × 100 = 26.7%
```

#### ④ 환산보증금 (월 환산)

보증금이 많으면 실질 수입이 더 높습니다. 보증금을 월세로 환산합니다.

```
환산보증금 월 환산액 = 보증금 합계 × 연 환산율 ÷ 12

환산율: 한국은행 기준금리 또는 상가건물임대차보호법 기준 (통상 연 2.5%)

예시:
  보증금 합계: 108,000만원 = 10.8억 원
  환산보증금 월 환산액: 108,000 × 2.5% ÷ 12 = 225만원/월
```

#### ⑤ 실효임대료

```
실효 월 임대료 = 계약 월세 합계 + 환산보증금 월 환산액

예시:
  월세 합계: 3,760만원
  환산보증금: 225만원
  실효 월 임대료: 3,985만원
```

## 제3장. NOI (순영업소득) 계산법

### 3.1 NOI란

NOI(Net Operating Income)는 **건물이 실제로 벌어들이는 순수한 영업 수익**입니다.
세금, 대출이자, 감가상각은 제외합니다.

### 3.2 NOI 계산 단계

```
┌──────────────────────────────────┐
│  [1단계] 잠재총수입 (PGI)        │
│  = 모든 층 만실 시 연간 임대수입   │
│  = (월세 합계 + 관리비 수입) × 12  │
├──────────────────────────────────┤
│  [2단계] 공실 차감               │
│  = PGI × (1 − 공실률)            │
│  = 유효총수입 (EGI)              │
├──────────────────────────────────┤
│  [3단계] 운영비 차감              │
│  = EGI − 연간 운영비             │
│  = NOI (순영업소득)              │
└──────────────────────────────────┘
```

### 3.3 NOI 계산 예시

```
■ 잠재총수입 (PGI)
  월세 합계(만실 가정): 4,110만원/월 (공실층 예상 월세 350만원 포함)
  관리비 수입: 950만원/월
  PGI = (4,110 + 950) × 12 = 60,720만원/년 = 약 6.07억/년

■ 유효총수입 (EGI)  
  현재 공실률: 9.47%
  EGI = 60,720 × (1 − 0.0947) = 54,972만원/년 = 약 5.50억/년

■ 연간 운영비
  - 건물 관리비 지출: 6,000만원 (관리인 인건비, 공용전기, 수선)
  - 재산세·종합부동산세: 3,500만원
  - 보험료: 500만원
  - 수선 적립금: 2,000만원
  - 합계: 12,000만원 = 1.20억/년

■ NOI
  NOI = 54,972 − 12,000 = 42,972만원/년 = 약 4.30억/년
```

> ⚠️ **운영비를 모를 때**: 운영비 실값을 구하지 못하면, 업종별 표준 비율을 적용합니다.
> - 오피스: 유효총수입의 15~25%
> - 근생·상가: 유효총수입의 10~20%
> - 반드시 "[추정]" 또는 "[가정]"으로 표기

## 제4장. Cap Rate (연 순수익률) 계산법

### 4.1 Cap Rate란

Cap Rate는 **"이 건물을 사면 연 몇 %의 순수익을 올리는가"**를 나타내는 지표입니다.
주식의 배당수익률과 비슷한 개념입니다.

### 4.2 Cap Rate 계산

```
Cap Rate(%) = NOI ÷ 총매입가 × 100
```

**총매입가의 정의** — 여러 기준이 있습니다:

| 기준 | 산식 | 사용 상황 |
|------|------|----------|
| **총액 기준** | 매매가 그대로 | 가장 단순 (보수적) |
| **순투자액 기준** | 매매가 − 승계 보증금 | 보증금 승계 시 (한국 관행) |
| **취득가 포함** | 매매가 + 취득세 등 | 실투자 기준 (가장 정확) |

### 4.3 Cap Rate 계산 예시

```
■ 총액 기준
  Cap Rate = 42,972만원 ÷ 2,500,000만원 × 100 = 1.72%
  → 이 수치가 너무 낮다면, 운영비나 공실 가정을 재확인

■ 순투자액 기준 (보증금 승계)
  순투자액 = 250억 − 10.8억(보증금) = 239.2억 = 2,392,000만원
  Cap Rate = 42,972 ÷ 2,392,000 × 100 = 1.80%

■ 단순 수익률 (운영비 미차감, 초보용 간편 계산)
  연 임대수입 = 3,760만원 × 12 = 45,120만원
  단순 수익률 = 45,120 ÷ 2,500,000 × 100 = 1.80%
```

### 4.4 Cap Rate의 해석

| Cap Rate | 의미 | 비유 |
|----------|------|------|
| 2% 이하 | 매우 낮음 — 가격이 높거나 수입이 적음 | 정기예금보다 낮음 |
| 3~4% | 강남 오피스 일반적 수준 | 안정적이나 수익 제한적 |
| 4~6% | 양호 — 서울 중소형 빌딩 평균 | 적정 투자 수익 |
| 6~8% | 높음 — 수익 좋으나 리스크 확인 필요 | 높은 수익, 공실·입지 리스크? |
| 8% 이상 | 매우 높음 — 반드시 이유를 확인 | 위치·임차인·건물 상태 문제? |

## 제5장. 레버리지 분석 (대출 활용 시 수익률)

### 5.1 왜 레버리지를 분석하나?

대부분의 상업용 부동산 매수는 **대출을 동반**합니다.
대출을 활용하면 자기자본 대비 수익률이 달라집니다.

### 5.2 자기자본 계산

```
자기자본 = 매매가 − 대출금 − 승계 보증금

예시:
  매매가: 250억 원
  대출금: 120억 원 (LTV 48%)
  보증금 승계: 10.8억 원
  자기자본 = 250 − 120 − 10.8 = 119.2억 원
```

### 5.3 레버리지 수익률 계산

```
연간 이자 비용 = 대출금 × 이자율

레버리지 수익률(%) = (NOI − 이자) ÷ 자기자본 × 100

예시:
  NOI: 4.30억 원
  대출금: 120억, 이자율 4.5%
  연간 이자: 120 × 0.045 = 5.40억
  
  레버리지 수익률 = (4.30 − 5.40) ÷ 119.2 × 100 = −0.92%
  
  → ⚠️ 마이너스! 이자가 NOI보다 크면 대출이 독이 됩니다.
  → 이럴 때는 대출 비율을 낮추거나 이자율 협상이 필요합니다.
```

### 5.4 레버리지 효과 비교표 (IM에 넣으면 좋은 표)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  구분        | 무차입   | LTV 40%  | LTV 60%
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  대출금      | 0        | 100억    | 150억
  자기자본    | 239.2억  | 139.2억  | 89.2억
  이자(연4.5%)| 0        | 4.50억   | 6.75억
  순수익      | 4.30억   | −0.20억  | −2.45억
  수익률      | 1.80%    | −0.14%   | −2.75%
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 제6장. 섹션 작성 순서 (임대수익형 12섹션)

```
1.  자산 개요      ← 공통편 참조
2.  입지 분석      ← 공통편 참조
3.  등기부 권리관계 ← 공통편 참조
4.  토지 상세      ← 공통편 참조
5.  임대차 현황 ⭐  ← 본 매뉴얼 제2장 (렌트롤)
6.  수익 분석 ⭐    ← 본 매뉴얼 제3~5장 (NOI, Cap Rate, 레버리지)
7.  리스크         ← 공통편 참조 + 임대 리스크 추가
8.  비교 매물      ← 아래 제7장 (비교사례)
9.  투자 포인트    ← 아래 제8장
10. 실사 체크리스트 ← 아래 제9장
11. 거래 일정      ← 공통편 참조
12. 마감(면책조항)  ← 공통편 참조
```

## 제7장. 비교 매물(Comparables) 작성법

### 7.1 비교사례를 왜 넣는가

"이 가격이 비싼지 싼지"를 객관적으로 보여주기 위해, 주변 유사 건물의 실거래가를 비교합니다.

### 7.2 비교사례 선정 기준

| 조건 | 기준 |
|------|------|
| **위치** | 같은 구(區) 또는 반경 1km 이내 |
| **용도** | 같은 용도 (오피스 vs 오피스) |
| **규모** | 연면적 ±30% 이내 |
| **시점** | 최근 2년 이내 거래 |
| **건수** | 최소 3건 이상 |

### 7.3 비교표 작성


### 7.4 비교 시 보정해야 할 요소

| 요소 | 보정 방법 |
|------|----------|
| 시점 | 거래 시점이 오래되면 물가 상승률 반영 |
| 규모 | 소형은 평당가가 높은 경향 → 규모 차이 언급 |
| 층수·연식 | 신축일수록 프리미엄 → 연식 차이 언급 |

## 제8장. 투자 포인트 작성법

### 8.1 원칙: 3대 핵심 매력

투자 포인트는 **딱 3가지**로 요약합니다. 매수자가 기억할 수 있는 분량입니다.

```
1. [수익 안정성] — 임대 관련 강점
   "WALE 4.2년, 앵커 임차인 비중 65%, 현재 공실률 0%"

2. [가격 매력] — 가격 관련 강점
   "주변 비교사례 평균 대비 13.8% 할인된 매수 기회"

3. [가치 상승 여력] — 향후 가치 증가 요인
   "법정 용적률 39.3% 미사용, 증축 시 추가 수익 창출 가능"
```

### 8.2 작성 시 주의

- 사실과 수치에 기반 (주관적 의견 최소화)
- 장점을 과장하지 않음 (리스크 섹션에서 균형)
- 매수자의 질문에 답하는 형태로 작성

## 제9장. 실사 체크리스트 작성법

매수자가 실사(Due Diligence)에서 확인해야 할 항목을 정리합니다.

```
━━━ 임대수익형 실사 체크리스트 ━━━

□ 임대차 계약서 원본 대조 (보증금, 월세, 계약기간)
□ 관리비 정산 내역 확인 (최근 12개월)
□ 실제 입금 내역 확인 (월세 연체 여부)
□ 공실 층 현장 확인 (상태, 원상복구 여부)
□ 앵커 임차인 재계약 의향 확인
□ 건물 대수선 이력 (방수, 엘리베이터, 외벽)
□ 소방·안전 점검 결과
□ 주변 신축 오피스 공급 계획
□ 주차장 실사용 대수 확인 (기계식 고장 여부)
□ 관리사무소 인수인계 사항
```

## 제10장. 완성된 IM 검수 방법

작성을 마친 후, 아래 순서로 검수합니다:

```
[검수 1] 수치 정합성
  → 매매가, 면적, 임대료가 모든 섹션에서 일치하는가?
  → Cap Rate = NOI ÷ 매매가 계산이 맞는가?

[검수 2] 출처 완전성
  → 모든 숫자에 출처가 있는가?
  → 가정/추정 항목에 [가정] 표시가 있는가?

[검수 3] 균형성
  → 장점만 나열하지 않았는가?
  → 리스크 섹션이 충실한가?

[검수 4] 면책조항
  → 마감 면에 면책조항이 포함되어 있는가?

[검수 5] 읽기 검수
  → 매수자의 입장에서 처음부터 끝까지 통독
  → "이 IM만 보고 투자 검토할 수 있는가?"
```
