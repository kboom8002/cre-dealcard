# 상업용 부동산 IM 수기 작성 매뉴얼 — 🏠 자가사용형 (Owner Occupied)

> **교육 목표**: 사옥·자가사용 목적 매물의 IM을 직접 작성할 수 있다
> **선행 학습**: [공통편](./10-handwrite-common.md) 필독

---

## 제1장. 자가사용형 IM의 핵심 — "임차보다 자가소유가 나은가?"

자가사용형 IM의 존재 이유:

> **"이 건물을 사서 직접 쓰는 게 계속 임차하는 것보다 유리한가?"**

임대수익형과의 근본 차이:

| 항목 | 임대수익형 | 자가사용형 |
|------|-----------|-----------|
| 핵심 질문 | "수익률이 몇 %?" | "임차보다 나은가?" |
| 핵심 분석 | NOI, Cap Rate | TCO(총소유비용) 비교 |
| 렌트롤 | 필수 핵심 | 불필요 (자가사용) |
| 가치 판단 | 연 수익률 | 10~15년 TCO + 잔존자산가치 |

## 제2장. 사옥 적합성 분석법

### 2.1 공간 적합성 판단

```
■ 필요 면적 산정
  직원 수 × 1인당 필요 면적 = 필요 전용면적

  [업종별 1인당 기준]
  일반 사무직: 3.0~3.5평/인
  IT·크리에이티브: 3.5~4.0평/인
  콜센터·밀집형: 2.0~2.5평/인
  연구소·실험실: 5.0~8.0평/인

예시:
  직원 80명, 일반 사무직
  필요 면적 = 80 × 3.3평 = 264평 (전용)
  건물 전용면적 = 532평
  → 여유: 268평 (확장 여력 있음, 또는 일부 임대 가능)
```

### 2.2 물리적 적합성 체크리스트

```
□ 전용률: ____% (60% 이상이면 양호)
□ 엘리베이터: __기 (직원 50명당 1기 이상 권장)
□ 주차: __대 (직원의 50~70% 수용 가능?)
□ 천장고: __m (2.7m 이상이면 쾌적)
□ 기둥 간격: 기둥 없는 오픈 플랜 가능?
□ 전기 용량: __kW (서버실 운용 가능?)
□ 냉난방: 개별/중앙, 시간외 사용 가능?
□ 간판 설치: 전면/측면 설치 가능?
□ 독립 출입구: 별도 출입 동선 확보 가능?
```

## 제3장. TCO(총소유비용) 비교 분석법

### 3.1 TCO 비교란

**"10년 동안 자가소유할 때의 총비용 vs 계속 임차할 때의 총비용"**을 비교하는 분석입니다.

### 3.2 자가소유 TCO 계산

```
■ 취득 비용 (1회성)
  매매가:                         250억 원
  취득세 (4.6%):                  11.5억 원
  중개수수료 (0.4%):               1.0억 원
  법무사·등기비:                    0.3억 원
  취득 비용 소계:                  12.8억 원

■ 연간 보유 비용
  재산세·종합부동산세:              3,500만원/년
  건물 보험:                       500만원/년
  유지보수·수선:                   2,000만원/년
  관리비(공용):                    6,000만원/년
  연간 보유 비용 소계:             1.20억원/년

■ 10년 TCO (자가소유)
  취득 비용:       12.8억
  보유 비용 (10년): 12.0억
  매매가:          250.0억
  합계:            274.8억 원

■ 10년 후 잔존 자산가치 (예상)
  연 2% 상승 가정: 250 × (1.02)^10 = 304.8억 원
  실질 TCO: 274.8 − 304.8 = △30.0억 (자산가치 포함 시 이득)
```

### 3.3 임차 TCO 계산

```
■ 현재 임차 조건 (또는 유사 물건 시세)
  보증금:        30억 원
  월 임대료:     8,000만원
  월 관리비:     2,000만원
  
■ 연간 임차 비용
  임대료: 8,000만 × 12 =           9.60억/년
  관리비: 2,000만 × 12 =           2.40억/년
  보증금 기회비용: 30억 × 3% =      0.90억/년
  연간 소계:                       12.90억/년

■ 10년 TCO (임차)
  연간 비용 × 10:                  129.0억 원
  (임대료 연 3% 인상 반영 시:       약 148.0억 원)
  잔존 자산:                        0원

■ 보증금 회수: +30억 원
  실질 TCO: 148.0 − 30.0 = 118.0억 원
```

### 3.4 비교 요약표 (IM에 넣는 표)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  항목              | 자가소유   | 계속 임차
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  초기 투자         | 262.8억   | 30.0억(보증금)
  10년 누적 비용    | 274.8억   | 148.0억
  10년 후 자산가치  | 304.8억   | 0원
  실질 10년 TCO     | △30.0억  | 118.0억
  연환산 실질 비용  | △3.0억   | 11.8억
  손익분기 시점     | 약 8.5년  | -
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  → 8.5년 이상 사용하면 자가소유가 유리
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 3.5 손익분기점 계산

```
손익분기(년) = (취득 총비용) ÷ (연간 임차비 절감액 − 연간 보유비)

예시:
  취득 총비용: 262.8억 (매매가 + 취득세 등)
  연간 임차비: 12.9억
  연간 보유비: 1.2억
  연간 절감: 12.9 − 1.2 = 11.7억
  
  보증금 차이: 262.8 − 30 = 232.8억 (추가 투자금)
  손익분기 = 232.8 ÷ 11.7 = 약 19.9년
  
  ※ 자산가치 상승(연2%)을 반영하면 약 8.5년으로 단축
```

> ⚠️ **주의**: 손익분기 계산의 핵심 가정은 "자산가치 상승률"입니다.
> 가정을 반드시 명시하고, 보수적(0%)/중립적(2%)/낙관적(4%) 3가지 시나리오를 제시하면 좋습니다.

## 제4장. 자가사용형 IM 구성 (9섹션)

```
1. 자산 개요       ← 전용률, 주차, 엘리베이터 강조
2. 입지 분석       ← 직원 통근 접근성 중심
3. 등기부 권리관계  ← 명도 필요 여부
4. 사옥 적합성 ⭐   ← 본 매뉴얼 제2장
5. 비용 비교 ⭐     ← 본 매뉴얼 제3장
6. 리스크          ← 노후도, 용도변경, 명도 비용
7. 투자 포인트     ← 절감액, 자산가치, 브랜딩
8. 실사 체크리스트  ← 명도·리모델링·IT인프라
9. 거래 일정       ← 명도→리모델링→입주 일정
```

## 제5장. 자가사용형 작성 시 핵심 주의점

| # | 주의사항 |
|---|---------|
| 1 | **렌트롤 분석을 넣지 않습니다** — 자가 사용이므로 임대 수익 분석은 불필요 |
| 2 | **비용 비교의 가정을 반드시 명시** — 자산 상승률, 임대료 인상률, 금리 |
| 3 | **명도 비용·시간을 빠뜨리지 않습니다** — 기존 임차인이 있다면 명도 계획 필수 |
| 4 | **정성적 가치도 기재** — 기업 브랜딩, 직원 만족도, 독립 공간 확보 |
| 5 | **취득세를 반드시 포함** — 상업용 부동산 취득세 4.6%는 큰 금액 |
