# 상업용 부동산 IM 수기 작성 매뉴얼 — 📈 단기매매형 (Trading)

> **교육 목표**: 시세 차익 실현 목적 매물의 IM을 직접 작성할 수 있다
> **선행 학습**: [공통편](./10-handwrite-common.md) 필독

---

## 제1장. 단기매매형 IM의 핵심 — "지금이 살 때인가?"

단기매매형 IM의 존재 이유:

> **"이 건물을 지금 매수하면, 보유 후 매도했을 때 얼마의 차익을 얻을 수 있는가?"**

다른 포스처와의 차이:

| 항목 | 임대수익형 | 단기매매형 |
|------|-----------|-----------|
| 수익 원천 | 임대료 (운영 수익) | **매도 차익** (시세 상승) |
| 보유 기간 | 장기 (5~10년+) | **단기 (1~3년)** |
| 핵심 분석 | Cap Rate, NOI | **시세 비교, 가격 추이** |
| 리스크 초점 | 공실, 임대료 하락 | **유동성, 가격 하락, 세금** |

## 제2장. 시세 분석 방법론

### 2.1 평당가 비교법

**"주변 유사 건물의 평당가와 비교하여 얼마나 싸게(또는 비싸게) 사는가"**

```
■ 평당가 산정
  매매가 ÷ 연면적(평) = 평당가

  예시: 250억 ÷ 852평 = 2,935만원/평

■ 비교사례 평균
  사례 3건의 평균 평당가 = 3,407만원/평

■ 시세 대비 할인율
  할인율(%) = (비교사례 평균 − 대상 평당가) ÷ 비교사례 평균 × 100
  = (3,407 − 2,935) ÷ 3,407 × 100 = 13.8%

  → "주변 시세 대비 13.8% 할인된 가격"
```

### 2.2 비교사례 선정과 보정

비교사례를 선정할 때 **4가지 보정**을 고려합니다:

| 보정 요소 | 보정 방법 | 예시 |
|-----------|----------|------|
| **시점 보정** | 과거 거래가에 물가·시세 상승률 적용 | 2023년 거래 → +6% (연 3% × 2년) |
| **규모 보정** | 소형 건물은 평당가 프리미엄 | 300평 미만 → 평당가 +10~15% |
| **연식 보정** | 신축은 프리미엄, 노후는 디스카운트 | 5년 이내 → +5~10%, 30년 이상 → −10% |
| **입지 보정** | 대로변/이면도로, 역 거리 | 대로변 → +5~15%, 도보 10분+ → −10% |

**보정 적용 예시**:

```
사례 1: 역삼동, 2023년 3월 거래, 평당 3,000만원
  시점 보정: +6% (2년)     → 3,180만원
  규모 보정: 비슷 (보정 없음) → 3,180만원
  연식 보정: 5년 신축 → +7% → 3,403만원
  입지 보정: 비슷 (보정 없음) → 3,403만원

  → 보정 후 평당가: 3,403만원
```

### 2.3 가격 추이 분석 작성법

해당 권역의 **과거 3~5년 거래가 추이**를 정리합니다.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  연도 | 거래 건수 | 평균 평당가 | 전년 대비
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  2021 |    8     | 2,450만    | -
  2022 |   12     | 2,680만    | +9.4%
  2023 |    6     | 2,750만    | +2.6%
  2024 |    9     | 2,920만    | +6.2%
  2025 |    5     | 3,150만    | +7.9%
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  4년 CAGR (연평균성장률): 6.5%
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**CAGR (연평균성장률) 계산**:

```
CAGR = (최종값 ÷ 초기값)^(1÷기간) − 1

예시:
  CAGR = (3,150 ÷ 2,450)^(1÷4) − 1
       = 1.2857^0.25 − 1
       = 1.0648 − 1
       = 6.48% ≒ 6.5%/년
```

## 제3장. 투자 수익률 (HPR) 분석법

### 3.1 HPR (Holding Period Return)이란

**보유기간 수익률**: 매수~매도까지 전체 기간의 총 수익률입니다.

### 3.2 HPR 계산

```
HPR(%) = (매도가 − 매수가 − 거래비용 + 보유기간 순수입) ÷ 자기자본 × 100

항목별:
  매수가: 250억
  취득세 (4.6%): 11.5억
  총 매수비용: 261.5억

  대출금: 120억 (LTV 48%)
  보증금 승계: 10.8억
  자기자본: 250 − 120 − 10.8 = 119.2억

  보유기간: 3년
  연간 임대순수익 (NOI): 4.3억 → 3년 합계: 12.9억
  연간 이자: 5.4억 → 3년 합계: 16.2억
  보유기간 순수입: 12.9 − 16.2 = △3.3억

  예상 매도가 (3년 후, 연 6.5% 상승): 250 × 1.065^3 = 302억
  양도소득세 (예상): (302 − 250) × 세율 → 약 15.6억
  중개수수료 (0.4%): 1.2억
  매도비용: 16.8억

  순매도수입: 302 − 120(대출상환) − 10.8(보증금반환) − 16.8 = 154.4억

  HPR = (154.4 − 119.2 + △3.3 − 11.5) ÷ 119.2 × 100
      = 20.4 ÷ 119.2 × 100
      = 17.1% (3년 보유)
      = 5.4%/년 (연환산)
```

### 3.3 시나리오별 HPR 비교표

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  시나리오    | 연 상승률 | 3년 후 매도가 | HPR(3년)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  보수적      | 0%       | 250억        | −12.4%
  중립        | 3%       | 273억        | 3.8%
  기대        | 6.5%     | 302억        | 17.1%
  낙관        | 10%      | 333억        | 43.2%
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

> ⚠️ **핵심 포인트**: 가격이 오르지 않으면(0% 시나리오) **마이너스**입니다.
> 단기매매는 "반드시 가격이 오른다"는 전제가 필요하며, 이것이 최대 리스크입니다.

## 제4장. 세금 분석 (양도소득세)

단기매매에서 세금은 수익률에 결정적 영향을 미칩니다.

### 4.1 양도소득세 기본 구조

```
양도차익 = 양도가 − 취득가 − 필요경비
과세표준 = 양도차익 − 기본공제(250만원)
세액 = 과세표준 × 세율

■ 보유기간별 세율 (2025년 기준, 법인 아닌 개인)
  1년 미만: 70%
  1~2년:   60%
  2년 이상: 기본세율 (6~45% 누진)

■ 법인의 경우
  법인세 기본세율 + 추가세율 20% (2년 미만 보유)
  법인세 기본세율 + 추가세율 10% (2년 이상 보유)
```

### 4.2 세후 수익률 계산 예시

```
양도차익: 302억 − 261.5억 = 40.5억
필요경비: 1.2억 (중개수수료)
과세표준: 40.5 − 1.2 − 0.025 = 39.275억

세액 (2년 이상 보유, 누진세율 적용):
  → 약 15.6억 (실효세율 약 39.7%)

세전 차익: 40.5억
세후 차익: 40.5 − 15.6 = 24.9억

세전 HPR: 33.9% → 세후 HPR: 17.1%
  → 세금으로 수익의 38%가 사라짐
```

> 💡 **IM에 반드시 포함**: "세전 수익률"과 "세후 수익률"을 모두 기재하세요.
> 세금을 빠뜨리면 매수자가 과대평가합니다.

## 제5장. 유동성 (매도 난이도) 분석

### 5.1 유동성이란

**"이 건물을 팔고 싶을 때 얼마나 빨리 팔 수 있는가"**

### 5.2 유동성 판단 지표

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  지표               | 데이터         | 판단
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  연간 거래 건수      | 해당 권역 9건   | 보통
  평균 매물 소화기간  | 4.2개월        | 양호
  매물/거래 비율     | 15:9 = 1.67    | 양호(2 미만)
  가격대 수요       | 200~300억 매수자 | 보통
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

| 소화기간 | 유동성 판단 |
|---------|-----------|
| 3개월 이내 | 높음 (매도 용이) |
| 3~6개월 | 보통 |
| 6~12개월 | 낮음 (주의) |
| 12개월 이상 | 매우 낮음 (출구 리스크 높음) |

## 제6장. 단기매매형 IM 구성 (8섹션)

```
1. 자산 개요       ← 평당가, 거래 이력 강조
2. 입지 분석       ← 가격 상승 동인, 개발 호재
3. 등기부 권리관계  ← 전매 제한, 규제
4. 시장 포지셔닝 ⭐ ← 본 매뉴얼 제2장
5. 비교사례 분석 ⭐ ← 본 매뉴얼 제2장
6. 리스크          ← 유동성, 가격 하락, 세금
7. 실사 체크리스트  ← 세금 시뮬레이션, 출구
8. 거래 일정       ← 매수~목표 매도 시점
```

## 제7장. 단기매매형 작성 시 핵심 주의점

| # | 주의사항 |
|---|---------|
| 1 | **"반드시 오른다"고 기재하지 않음** — 시나리오 3가지(보수/중립/낙관) 제시 |
| 2 | **세후 수익률을 반드시 기재** — 세전만 보면 수익이 과대 평가됨 |
| 3 | **유동성 분석 필수** — 팔리지 않으면 수익률은 의미 없음 |
| 4 | **비교사례를 유리한 것만 골라 넣지 않음** — 최소 3건, 평균으로 비교 |
| 5 | **보유 기간 중 현금흐름도 분석** — 대출 이자가 NOI보다 크면 보유 자체가 손실 |
| 6 | **렌트롤·수익 분석은 넣지 않음** — 단기매매형 IM은 시세 분석에 집중 |
| 7 | **출구 전략(Exit Strategy) 명시** — 언제, 어떤 조건에서 매도할 것인가 |

## 제8장. 종합 검수 체크리스트 (수기 IM 완성 후)

모든 포스처에 공통으로 적용되는 최종 검수 단계입니다.

```
━━━ 수기 IM 최종 검수 (14항목) ━━━

[수치]
□ 매매가가 모든 섹션에서 일치하는가?
□ 면적(대지·연면적·전용면적)이 건축물대장과 일치하는가?
□ 핵심 지표(Cap Rate/GOP/평당가 등) 계산이 정확한가?
□ 합계를 역산했을 때 세부 항목과 일치하는가?

[출처]
□ 모든 숫자에 출처가 명기되어 있는가?
□ 가정/추정 항목에 [가정] 또는 [추정]이 표시되어 있는가?
□ 공적 서류(등기부, 건축물대장) 발급일이 최근 3개월 이내인가?

[내용]
□ 리스크 섹션이 장점 섹션과 균형을 이루는가?
□ 특정 연령/계층/성별을 직접 지칭하는 표현이 없는가?
□ 영문 약어에 한국어 풀이가 병기되어 있는가?
□ 면책조항이 마지막 페이지에 포함되어 있는가?

[형식]
□ 전체 분량이 적정한가? (OM: 5~10p, IM: 12~16p)
□ 표지에 건물명, 주소, 매매가, 작성일, 작성자가 있는가?
□ 제3자(매수 검토자)가 이 문서만으로 투자 판단을 시작할 수 있는가?
```
