# CreDeal 시스템 활용 가이드 — 제1부: 사전 데이터 준비

> **목적**: IM 생성 버튼을 누르기 **전에** 무엇을 준비해야 하는지 안내
> **원칙**: 준비한 데이터가 많을수록 등급이 올라가고, 더 깊은 분석이 포함된 IM이 나옵니다

---

## 제1장. 공통 준비물 — 모든 포스처에 필요

### 1.1 필수 3종 (없으면 IM 생성 불가)

| # | 준비물 | 왜 필요한가 | 어디서 구하나 | 입력 위치 |
|---|--------|------------|-------------|----------|
| 1 | **정확한 주소** (지번 또는 도로명) | 공공데이터 자동 조회의 시작점. PNU(필지번호) 확정 → 건축물대장, 토지이용계획, 공시지가 자동 조회 | 등기부·건축물대장 | 딜카드 생성 시 주소 입력란 |
| 2 | **매매 희망가** (만원 단위) | 평당가, Cap Rate, 자기자본 등 모든 재무 분석의 분모 | 매도인 확인 | 보강정보 > 매매가 |
| 3 | **자산 유형** + **투자 관점(포스처)** | 섹션 구성, 슬라이드 순서, 강조 포인트가 완전히 달라짐 | 중개인 판단 | 딜카드 생성 시 선택 |

> ⚠️ 주소만 입력해도 IM 생성은 가능하지만, **C~D등급** 수준의 간략한 산출물만 나옵니다.

### 1.2 권장 5종 (등급 향상에 결정적)

| # | 준비물 | 등급 영향 | 설명 |
|---|--------|----------|------|
| 4 | **건물 사진** (최소 1장, 최대 12장) | 표지·갤러리 슬라이드 생성 | 외관 전면, 로비, 주차장, 옥상, 내부 등 카테고리별 촬영 |
| 5 | **등기부등본** (갑구·을구) | 권리관계 분석, 근저당→융자 역산 | 인터넷등기소 (iros.go.kr) |
| 6 | **건축물대장** | 자동 조회되지만, 수동 교차 확인용 | 정부24 (gov.kr) |
| 7 | **토지이용계획확인서** | 용적률·건폐율 법적 상한 확인 | 토지이음 (eum.go.kr) |
| 8 | **현장 실사 메모** | 브로커 코멘트, 리스크 판단 근거 | 직접 현장 방문 |

### 1.3 시스템이 자동으로 가져오는 데이터

주소(PNU)가 확정되면 CreDeal이 **자동으로 조회**하는 항목입니다.
중개인이 별도로 입력할 필요가 없습니다.

| 자동 조회 항목 | 출처 API | 용도 |
|---------------|---------|------|
| 건축물대장 (대지면적, 연면적, 층수, 준공일, 구조, 엘리베이터) | 공공데이터포털 | 자산 개요 |
| 토지이용계획 (용도지역, 건폐율, 용적률) | 토지이음 | 토지 상세 |
| 공시지가 (㎡당, 평당) | V-World | 토지 가치 |
| 지적도 이미지 | V-World WMS | 토지 형상 시각화 |
| 최근접 지하철역, 도보시간 | 카카오맵 | 입지 분석 |
| 주변 POI (편의시설) | 카카오맵 | 입지 분석 |
| 광역교통 다이어그램 | 자체 생성 | PPTX 입지 슬라이드 |
| 실거래가 (주변 유사 건물) | 국토부 | 비교사례 |

## 제2장. Income (임대수익형) 추가 준비물

### 2.1 핵심 준비물 — 등급 B↑ 필수

| # | 준비물 | 필수/선택 | 등급 영향 | 상세 |
|---|--------|----------|----------|------|
| 1 | **층별 임대차 계약서** | 🔴 핵심 | C→B 결정적 | 전 층의 보증금·월세·계약기간 필요. 1층이라도 빠지면 렌트롤 불완전 |
| 2 | **월 임대료 총액** | 🔴 핵심 | C→B 결정적 | 층별 내역이 없을 때 최소한 총액이라도 입력 |
| 3 | **공실 현황** | 🟡 권장 | 정확도 향상 | "3층 전체 공실", "5층 반 공실" 등 구체적으로 |
| 4 | **보증금 합계** | 🟡 권장 | 자기자본 산출 | 만원 단위 |
| 5 | **관리비 합계** | 🟡 권장 | 수익 정확도 | 월 관리비 수입 총액 |
| 6 | **융자 내역** | 🟡 권장 | 레버리지 분석 | 채권최고액(만원), 융자 은행 |

### 2.2 고급 준비물 — 등급 A 달성

| # | 준비물 | 등급 영향 | 상세 |
|---|--------|----------|------|
| 7 | **연간 실측 운영비** | B→A | 관리비 지출, 재산세, 보험, 수선비 합계 (원 단위) |
| 8 | **부가수입 내역** | A 보강 | 통신장비 임대, 주차수입, 간판광고, 자판기, 태양광, EV충전 등 |
| 9 | **유사 거래 사례 3건+** | 비교사례 강화 | 주소, 거래금액, 연면적, 거래시점 |
| 10 | **예상 수익률** | 참고용 | 중개인이 판단하는 기대 수익률 (%) |

### 2.3 준비물 → 시스템 입력 필드 매핑

```
임대차 계약서 → floor_leases[] (층별 입력)
  ├─ 각 층: floor, tenant_type, area_pyeong, deposit_manwon,
  │        rent_manwon, mgmt_fee_manwon, lease_start, lease_end,
  │        is_vacant, rent_type
  └─ 매출연동: revenue_linked_pct, base_rent_manwon, estimated_rent_range

월임대료 총액 → monthly_rent_total_krw
공실률 → vacancy_pct (%) 또는 vacancy_status (텍스트)
보증금 합계 → total_deposit_manwon
관리비 합계 → mgmt_fee_total_manwon
융자 → loan_amount_manwon, loan_bank
운영비 → opex_total_krw
부가수입 → ancillary_incomes[] (type, label, annualAmountKrw)
비교사례 → manual_comps[] (address, dealAmount, area, dealYear, dealMonth)
```

## 제3장. Owner Occupied (자가사용형) 추가 준비물

| # | 준비물 | 필수/선택 | 상세 |
|---|--------|----------|------|
| 1 | **매수자 직원 수** | 🟡 권장 | 공간 적합성 분석의 기준 (1인당 3.3평 기준 필요 면적 산출) |
| 2 | **매수자 업종** | 🟡 권장 | 용도 적합성 판단 (사무실/클리닉/학원/연구소) |
| 3 | **현재 임차 비용** | 🟡 권장 | TCO 비교의 기준 (현재 월세·보증금·관리비) |
| 4 | **건물 전용률** | 🟡 권장 | 건축물대장에 없으면 중개인 확인 필요 |
| 5 | **주차 실사용 대수** | 🟡 권장 | 건축물대장 법정 대수 vs 실제 가용 대수 |
| 6 | **기존 임차인 명도 계획** | 🟡 권장 | 임차인 있으면 명도 시기·비용 추정 |

> **특이사항**: 자가사용형은 월세·렌트롤이 불필요합니다. 매매가 + 건물 규모가 핵심입니다.
> 시스템에서 `lease_status`, `income_analysis` 섹션이 자동으로 비활성화(suppress)됩니다.

## 제7장. 데이터 등급과 준비물의 관계

### 7.1 등급 결정 구조

CreDeal은 **2축 등급 시스템**으로 데이터 품질을 평가합니다:

```
■ P축 (Property — 물건 해상도)
  5개 슬롯: 토지정보, 건물기본, 용도지역, 접도, 권리관계
  
  P0 (30% 미만) → P1 (30~60%) → P2 (60~80%) → P3 (80%+)

■ L축 (Lead — 리드 해상도, 포스처별 다름)
  income:    렌트롤, 재무입력
  operating: 운영실적, 숙박사양, 재무입력
  development: 개발계획, 명도계획, 인허가리스크
  owner_occupied: 사용계획, 물리사양
  trading:   시장비교, 보유이력

  L0 → L1 → L2 → L3

■ 종합 등급
  D (40점 미만) → C (40~65) → B (65~85) → A (85+)
```

### 7.2 포스처별 "다음 한 단계" 등급 향상 로드맵

#### Income: D→A 로드맵

```
[D등급] 주소만 입력
  ↓ +매매가 입력 (+20점)
[C등급] 주소 + 매매가
  ↓ +월임대료 총액 입력 (+15점)
  ↓ +층별 렌트롤 입력 (+25점, 가장 큰 영향)
[B등급] 주소 + 매매가 + 렌트롤
  ↓ +융자 입력 (+15점)
  ↓ +운영비 실값 입력 (+10점)
  ↓ +사진 업로드 (+10점)
[A등급] 전체 데이터 완비 → DCF, 민감도 분석 해금
```

#### Owner Occupied: D→A 로드맵

```
[D등급] 주소만 입력
  ↓ +매매가 (+25점)
[C등급] 주소 + 매매가
  ↓ +공공데이터 자동 조회 성공 (+20점)
  ↓ +건축 연면적 확인 (+20점)
[B등급] 주소 + 매매가 + 연면적
  ↓ +사진 (+15점)
[A등급] 사옥 매입 검토 가능
```

#### Development: D→A 로드맵

```
[D등급] 주소만 입력
  ↓ +공공데이터(대지면적, 용도지역) (+35점)
[C등급] 주소 + 공공데이터
  ↓ +매매가 (+15점)
[B등급] 개발 입지 분석
  ↓ +개발 목표 용도·규모 (+10점)
  ↓ +사진 (+10점)
[A등급] 개발 수지 검토 가능
```

#### Operating: D→A 로드맵

```
[D등급] 주소만 입력
  ↓ +매매가 또는 월매출 입력
[C등급] 기본 정보
  ↓ +매출 + 매매가 (+40점)
[B등급] 운영 현황 분석
  ↓ +객실수 (+5점)
  ↓ +ADR (+5점)
[A등급] 운영 수익 검토 가능
```

#### Trading: D→A 로드맵

```
[D등급] 주소만 입력
  ↓ +공공데이터 (+15점)
[C등급] 기본 정보
  ↓ +매매가 (+25점)
[A등급] 비교사례 분석 가능 (최소 데이터로 A 달성)
```

### 7.3 등급별 잠기는 콘텐츠

| 콘텐츠 | D등급 | C등급 | B등급 | A등급 |
|--------|-------|-------|-------|-------|
| 자산 개요 | ✅ | ✅ | ✅ | ✅ |
| 입지 분석 | ✅ | ✅ | ✅ | ✅ |
| 렌트롤 | ❌ | ❌ | ✅ | ✅ |
| 수익 분석 (NOI/Cap Rate) | ❌ | ❌ | ✅ | ✅ |
| 총수익률 (Total Return) | ❌ | ❌ | ❌ | ✅ |
| DCF 분석 | ❌ | ❌ | ❌ | ✅ |
| 수익률 민감도 | ❌ | ❌ | ❌ | ✅ |
| 재무 확장 슬라이드 (6면) | ❌ | ❌ | 2면 | 6면 |
| **발행 가능** | ❌ 차단 | ✅ 내부초안 | ✅ 분석형IM | ✅ 의사결정IM |

### 7.4 데이터 출처별 신뢰 가중치

같은 데이터라도 **출처에 따라 등급 점수 기여가 다릅니다**:

| 출처 | 계수 | 의미 |
|------|------|------|
| 등기부·건축물대장 (registry) | 1.00 | 최고 신뢰 |
| 공공 API (public_api) | 0.95 | |
| 전문가 검증 (expert) | 0.95 | |
| 중개인 보강 (broker_aug) | 0.80 | |
| 계약서 확인 (ledger) | 0.70 | |
| 매도인 고지 (seller) | 0.65 | |
| 중개인 입력 (broker) | 0.60 | |
| 분석 가정 (assumed) | 0.30 | 최저 — 이 수준이 많으면 등급이 안 올라감 |

> 💡 **팁**: "분석가정(0.30)" 항목을 "중개인 현장확인(0.60)" 또는 "계약서 확인(0.70)"으로 교체하면
> 같은 데이터라도 등급이 향상됩니다. **출처를 명확히 하는 것이 등급 향상의 지름길**입니다.

## 제8장. FAQ — 데이터 준비 관련

**Q: 주소를 입력했는데 건축물대장이 조회되지 않아요.**
A: 신축 건물(준공 1년 미만), 미등기 건물, 주소 오류 시 발생합니다. 정확한 지번 주소로 재입력하거나, 건축물대장을 직접 발급받아 정보를 수동 입력하세요.

**Q: 매매가가 아직 확정되지 않았어요.**
A: 개발형은 매매가 없이도 생성 가능합니다. 다른 포스처는 매매가가 없으면 수익률 계산이 불가하여 C등급 이하로 제한됩니다. 호가 또는 예상 가격을 우선 입력하고, 확정 후 수정하세요.

**Q: 렌트롤 자료를 구할 수 없어요. 월세 총액만 알아요.**
A: `monthly_rent_total_krw` 필드에 총액만 입력해도 됩니다. 다만 층별 렌트롤(floor_leases)이 없으면 WALE, 앵커 비율, 스태킹플랜 분석이 생략되고 B등급 달성이 어렵습니다.

**Q: 사진이 없어도 IM을 만들 수 있나요?**
A: 가능합니다. 다만 표지에 대표 사진 없이 텍스트만 나오고, 갤러리 슬라이드가 생략됩니다. 최소 외관 사진 1장은 권장합니다.

**Q: 등기부를 안 떼도 되나요?**
A: 시스템은 등기부 없이도 IM을 생성합니다. 그러나 권리관계 섹션이 "? 미확인"으로 표시되며, 매수자의 신뢰도가 크게 떨어집니다. 실무적으로 등기부는 필수입니다.
