# DEC-002: 기존 공개 URL 보존 정책 (Legacy Public URL Preservation)

- **상태**: 승인 (Approved)
- **결정일**: 2026-09-03
- **결정권자**: 제품기획팀, 운영보안팀

## 1. 배경
중개인이 카카오톡, 문자, 이메일로 바이어들에게 공유한 기존 모바일 IM URL(`/im-lite/[id]`)과 딜카드 공유 링크가 존재합니다.
신규 파이프라인 도입 시 URL이 변경되거나 301/302 리디렉션 처리될 경우, 외부 메신저 인앱 브라우저에서 링크 깨짐이나 보안 경고가 발생할 수 있습니다.

## 2. 결정
1. 기존 공개 URL 패턴(`/im-lite/[id]`, `/dealcard/[id]`)은 영구 보존하며 리디렉션하지 않습니다.
2. 해당 엔드포인트는 내부 프록시 어댑터를 통해 과거 생성 바이트를 그대로 서빙하거나, 승인된 최신 `release_records`의 내용을 투영 서빙합니다.
3. 신규 파이프라인 전용 URL(`/m/[slug]`, `/pptx/[slug]`)은 신규 기능에서 점진적으로 활성화하되 구형 URL과 병행 지원합니다.

## 3. 결과 및 영향
- 외부 유통 링크의 파손 0건 보장.
- 바이어 관점에서의 끊김 없는 열람 경험 유지.
