# DEC-003: 스토리지 보존 및 파기 정책 (Storage Retention & Disposal Policy)

- **상태**: 승인 (Approved)
- **결정일**: 2026-09-03
- **결정권자**: 보안인프라팀, 법무팀

## 1. 배경
단계별 중간 산출물(임시 렌더 캐시, 원시 이미지 등)과 최종 승인된 발행 파일이 누적됨에 따라 스토리지 비용과 개인정보 파기 의무가 대두되었습니다.

## 2. 결정
1. **최종 승인 발행물 (PDF, PPTX) 및 감사 원장 (`approval_events`, `release_records`)**: 영구 보존.
2. **원시 공부 API 응답 (`source_artifacts`)**: 5년 보존 (중개사고 및 법적 분쟁 소멸시효 기준).
3. **임시 렌더링 캐시 및 미리보기 이미지**: 생성일로부터 14일 후 만료 및 자동 파기 (Lifecycle Policy).
4. **철회된 매물 (`WITHDRAWN`)**: 비공개 상태로 감사 DB에 암호화 보관, 외부 다운로드 즉시 차단.
