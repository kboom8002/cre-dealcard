# DEC-004: 승인 역할 및 자기승인 허용 범위 (Approval Roles & Self-Approval Scope)

- **상태**: 승인 (Approved)
- **결정일**: 2026-09-03
- **결정권자**: 제품기획팀, 부동산 도메인팀, 보안팀

## 1. 배경
중개인이 혼자 문서를 작성하고 즉시 발행하는 사용성과, 잘못된 정보나 과장 광고가 나가는 것을 방지하는 무결성 간의 균형이 필요합니다.

## 2. 결정
1. **L1 사실확인형 모바일 IM**: 작성 중개인의 1인 단독 승인(`self_approval`) 허용. 단, 기계검사(Gate)가 100% `PASS`여야 함.
2. **L1.5 매각제안형 모바일 IM**: 중개인 단독 승인 불가. 중개인 의견 확인(`broker_confirmed`) 후 자문사/플랫폼 검수자 또는 수석 중개인의 2차 확인(`reviewer_confirmed`) 필수.
3. **PPTX IM Studio 최종 파일 배포**: 편집 승인(`editorial_approval`)과 최종 파일 해시 승인(`artifact_approval`)의 2단계 승인 의무화.

## 3. 결과 및 영향
- L1 발행 속도 극대화(당일 즉시 발행).
- L1.5 및 PPTX 고위험 문서의 법적·윤리적 리스크 0화.
