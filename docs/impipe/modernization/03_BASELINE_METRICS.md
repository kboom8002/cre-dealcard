## 2. 수치 계산 및 4대 면적 분모 기준선

1. **평형 환산 계수**: `1평 = 3.305785 ㎡` (고정)
2. **4대 면적 분모 (Rule 4)**:
   - `대지면적`: 토지 평당가 분모 (`pricePerPyeongLand = 매매가 / (대지면적 / 3.305785)`)
   - `연면적`: 연면적 평당가 분모 (`pricePerPyeongGross = 매매가 / (연면적 / 3.305785)`)
   - `임대면적`: 임대 평당 임대료 분모 (`rentPerPyeongLeasable = 월세 / (임대면적 / 3.305785)`)
   - `전용면적`: 전용 평당 임대료 분모 (`rentPerPyeongExclusive = 월세 / (전용면적 / 3.305785)`)
3. **오차 허용치 (Tolerance)**:
   - 카나리 및 섀도우 비교 허용 오차: `<= 0.1%`
   - 상충 탐지 임계값: `> 0.5%` (초과 시 명시적 충돌 기록)
   - 렌트롤 총액 불일치 임계값: `> 1.0%` (초과 시 발행 차단)
