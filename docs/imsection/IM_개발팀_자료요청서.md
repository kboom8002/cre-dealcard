## 0. 요청 원칙 3가지

### 0.1 파일이 아니라 답을 받습니다

각 항목에 **답을 얻어야 할 질문**을 명시했습니다. 소스 파일만 받으면 다시 추정하게 됩니다.

### 0.2 🔴 답을 못 하는 것 자체가 정보입니다

| 질문 | 답이 없으면 |
|---|---|
| "0.85의 산출 근거는?" | **임의 상수 확정** → 즉시 제거 대상 |
| "Judge 자동 승격 Golden이 몇 건?" | 추적 부재 → **오염 규모 미상** |
| "생성 1건당 비용은?" | 계측 부재 → 개선 효과 측정 불가 |

**"모릅니다"도 유효한 답변**입니다. 그대로 회신해 주십시오.

### 0.3 이미 확보된 것은 재요청하지 않습니다

`00_architecture_overview` ~ `07_guardrails_quality` 8종은 수령했습니다. 아래는 **그 문서로 판단할 수 없었던 것**만 담았습니다.
