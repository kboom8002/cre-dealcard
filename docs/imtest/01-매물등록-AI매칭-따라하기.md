# 📘 튜토리얼 1편 — 매물 메모 한 줄이면 딜카드가 뚝딱!

> **소요시간**: 약 20분  
> **난이도**: ⭐ (처음 사용하는 분도 따라할 수 있습니다)  
> **준비물**: credeal.net 로그인 계정, 매물 메모 1건  
> **기반 테스트**: [01-memo-to-dealcard.md] TC-M01~M11

---

## 🎯 이번 편에서 하는 것

카톡방에 올리셨던 매물 문구를 **그대로 복사-붙여넣기**하면,  
AI가 자동으로 **딜카드**(건물 분석 카드)를 만들어줍니다.

5가지 매물 유형별로 실습합니다:
- 🏢 **수익형** (월세 받는 건물)
- 🔨 **개발형** (철거·신축 예정)
- 🏠 **사옥형** (직접 입주할 건물)
- 💹 **단기매매형** (되팔 건물)
- 🏨 **운영형** (호텔·숙박)

---

## STEP 1. 로그인하기

1. 크롬 브라우저에서 **credeal.net** 에 접속합니다
2. 카카오 로그인 또는 이메일 로그인합니다
3. **브로커 대시보드** 화면이 보이면 준비 완료입니다

> 💡 **팁**: 첫 로그인이시면 프로필(이름·소속·연락처)을 입력하세요.  
> 나중에 투자설명서(IM) 표지에 자동으로 들어갑니다.

---

## STEP 2. 수익형 매물 등록해보기

### 📋 아래 메모를 복사해서 붙여넣으세요

```
매물 접수
당산동5가 11-47 근생빌딩
매매가 115억, 연면적 345평
1층 약국 월세 350만, 2층 내과 월세 280만
3층 헬스장 월세 250만, 4~5층 사무실 월세 각 200만
보증금 총 2.9억, 월세 총 1,946만
주차 8대, 엘베 1대, 2002년 준공
만실
```

### ▶️ 입력 방법

1. 대시보드 메모 입력란에 위 텍스트를 **붙여넣기** 합니다
2. **「분석 시작」** 버튼을 누릅니다
3. AI가 5~10초간 분석합니다
4. **딜카드 페이지**가 자동으로 열립니다

### ✅ 이렇게 나오면 정상입니다

| 확인 항목 | 나와야 하는 값 |
|:---|:---|
| 📍 주소 | 당산동5가 11-47 |
| 💰 매매가 | **115억원** |
| 📊 데이터 등급 | **B** 이상 |
| 🏢 투자 성격 | **수익형** (income) |
| 💵 총보증금 | 약 **2.9억** |
| 📈 월세 총액 | 약 **1,946만원** |

> ⚠️ **확인 포인트**: AI가 "수익형(income)"으로 분류했는지 반드시 확인하세요.  
> 만실이고 월세가 있으니 "수익형"이 맞습니다.

---

## STEP 3. 딜카드 페이지 살펴보기

딜카드 페이지에서 아래 4가지를 확인합니다:

### 3-1. 4개 탭이 보이나요?

| 탭 이름 | 들어 있는 내용 |
|:---|:---|
| **Overview** | 건물 기본 정보, 시그널 카드 |
| **IM** | 투자설명서(IM) 관리 패널 |
| **Buyers** | AI 매칭된 매수자 목록 |
| **Analytics** | 시장 분석 자료 |

### 3-2. 화면 아래 Sticky CTA 버튼 3개

| 버튼 | 역할 |
|:---|:---|
| **⚡ 기본 IM** | 투자설명서 만들기 (2편에서 실습) |
| **카카오 공유** | 카카오톡으로 공유 |
| **매칭** | AI 매수자 매칭 |

---

## STEP 4. 4가지 매물 유형 더 등록해보기

같은 방식으로 나머지 4유형도 등록합니다. **한 개씩** 해보세요:

### 📋 개발형 메모 (복사-붙여넣기)

```
잠원동 26-14, 16번지 2필지 개발 검토 요청
매매가 242억, 토지 186.6평 (616.1㎡)
현황: 5층 근생 (1990년 준공) — 철거 후 신축 예정
신축 규모: B1~6F RC조, 연면적 1,530평
예상 건축비 평당 1,200만
용도: 근생/의원/업무시설 복합
명도는 매도인 책임
기존 임차인 11호실 — 보증금 10.3억, 월세 3,335만
제2종일반주거지역, 건폐율 49.76%, 용적률 247%
```

> ✅ 확인: 투자 성격이 **"개발형(development)"**으로 나오는지  
> ✅ 확인: 2필지 정보, 신축 규모 1,530평이 파싱되었는지

---

### 📋 사옥형 메모 (복사-붙여넣기)

```
서초동 1364-28 사옥 매물 안내
매매가 230억, 연면적 637평
2005년 준공, 지하1~지상7층
주차 20대, 엘리베이터 1대
현재 2층, 4층, 5층 공실 (사옥용 즉시 입주 가능)
IT기업 50인 규모 사옥 적합
지하철 교대역 도보 7분
제3종일반주거지역
```

> ✅ 확인: **"자가사용형(owner_occupied)"** 분류  
> ✅ 확인: 공실률 약 37.5%가 감지되었는지

---

### 📋 단기매매형 메모 (복사-붙여넣기)

```
신사동 590 매물 정보
매매가 760억, 토지 321평 (1,061.9㎡)
1998년 준공, 지하2~지상6층
제3종일반주거, 용적률 237.2%
비교사례: 신사동 586-6 (550억), 559-6 (680억)
단기 매매차익 가능 — 최근 1년 인근 거래가 상승 추세
주차 26대
```

> ✅ 확인: **"단기매매형(trading)"** 분류  
> ✅ 확인: 비교사례 2건이 파싱되었는지

---

### 📋 운영형 메모 (복사-붙여넣기)

```
대현동 56-1 관광호텔 매물
매매가 300억, 연면적 1,163평
2016년 준공, B2~12F
총 94실 (스탠다드 74, 디럭스 14, 스위트 6)
ADR 9.5만, 객실가동률 78%
연매출 28.2억, GOP 마진 38%
운영사: 에이치에비뉴 (MC 계약, 2029년 만료)
관광호텔업 3급, 외국인비율 45%
주차 18대, 엘리베이터 2대
```

> ✅ 확인: **"운영형(operating)"** 분류  
> ✅ 확인: 객실수 94실, ADR 9.5만원, GOP 38%가 파싱되었는지

---

## STEP 5. 잘못된 입력도 해보기 (에러 테스트)

시스템이 엉뚱한 입력을 잘 막아주는지 확인합니다:

| # | 해볼 것 | 이렇게 되어야 정상 |
|:---:|:---|:---|
| 1 | 아무것도 안 쓰고 「분석 시작」 누르기 | ❌ "메모를 입력해주세요" 에러 |
| 2 | 로그아웃 후 분석 시도 | ❌ "로그인이 필요합니다" 에러 |
| 3 | 같은 글자를 1만자 넘게 반복 입력 | ❌ 글자수 초과 에러 |

> 💡 이 에러들이 정상적으로 나오면 **시스템이 안전하게 동작**하고 있다는 뜻입니다.
