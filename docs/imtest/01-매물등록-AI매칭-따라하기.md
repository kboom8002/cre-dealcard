# 📘 튜토리얼 1편 — 매물 등록부터 AI 매수자 매칭까지

> **소요시간**: 약 20분  
> **난이도**: ⭐ (처음 사용하는 분도 따라할 수 있습니다)  
> **준비물**: 크레딜(credeal.net) 로그인 계정, 매물 메모 1건

---

## 🎯 이 튜토리얼에서 배우는 것

카톡이나 메모장에 적어둔 매물 정보를 시스템에 붙여넣으면, **AI가 자동으로**:

1. 건물 정보를 정리해서 **딜카드**를 만들어줍니다
2. 이 매물에 적합한 **매수자 유형 3종**을 추천합니다
3. 등록된 매수 고객과 **자동 매칭**해서 S/A/B/C 등급을 알려줍니다

---

## 1단계: 로그인하기

1. 크롬 브라우저에서 **credeal.net** 에 접속합니다
2. 카카오 로그인 또는 이메일 로그인을 합니다
3. **브로커 대시보드** 화면이 나오면 준비 완료입니다

> 💡 **팁**: 처음 로그인하면 프로필 정보(이름, 소속, 연락처)를 입력하는 화면이 나올 수 있습니다. 입력해두면 나중에 투자설명서(IM)에 자동으로 들어갑니다.

---

## 2단계: 매물 메모 입력하기

브로커 대시보드 화면에서 **메모 입력 영역**을 찾습니다.

### 📝 실습용 매물 메모 (복사해서 붙여넣기)

아래 내용을 **그대로 복사**해서 메모 입력란에 붙여넣으세요:

```
매물 접수
당산동5가 11-47 근생빌딩
매매가 115억, 연면적 345평
1층 약국 월세 350만, 2층 내과 월세 280만
3층 헬스장 월세 250만, 4~5층 사무실 월세 각 200만
보증금 총 2.9억, 월세 총 1,946만
주차 8대, 엘베 1대, 2002년 준공
만실
```

> 💡 **팁**: 평소 카톡방에 올리시는 매물 문구 그대로 넣으시면 됩니다. AI가 알아서 분석합니다.

### ▶️ 분석 시작

1. 메모를 붙여넣은 후 **「분석 시작」** 버튼을 클릭합니다
2. AI가 5~10초 정도 분석합니다
3. 분석 완료 메시지가 나오면 자동으로 **딜카드 페이지**로 이동합니다

---

## 3단계: 딜카드 확인하기

AI가 만든 딜카드 페이지에서 다음 항목이 정확한지 확인합니다:

| 확인 항목 | 이렇게 보여야 합니다 |
|:---|:---|
| 📍 주소 | 당산동5가 11-47 |
| 💰 매매가 | **115억원** |
| 📊 데이터 등급 | **B** 이상 (A가 나오면 더 좋습니다) |
| 🏢 투자 성격 | **수익형** (income) |
| 📋 4개 탭 | Overview, IM, Buyers, Analytics |

### 데이터 등급이란?

| 등급 | 의미 | 기본 IM 생성 |
|:---:|:---|:---:|
| **A** (85~100점) | 매우 충분한 정보 | ✅ 가능 |
| **B** (60~84점) | 적정 수준 | ✅ 가능 |
| **C** (30~59점) | 최소 정보 | ✅ 가능 (기본) |
| **D** (0~29점) | 정보 부족 | ❌ 불가 |

> 💡 **D등급이 나왔다면**: 매물 메모에 면적, 가격, 층수 등 기본 정보를 더 추가해주세요.

---

## 4단계: 이상적 매수자 페르소나 보기

딜카드 페이지 아래쪽에 **「이상적 매수자」** 섹션이 있습니다.

AI가 이 매물에 딱 맞는 **매수자 유형 3종**을 추천합니다. 예를 들면:

| # | 추천 매수자 유형 | 예상 투자 목적 |
|:---:|:---|:---|
| 1 | 강남권 법인 투자자 | 임대수익 (월세 수입) |
| 2 | IT기업 사옥 매입 | 자가사용 (사무실) |
| 3 | 자산관리 법인 | 장기 보유 + 운영 |

> 이 정보는 매수 고객 미팅 시 **어떤 포인트로 설명할지** 참고 자료로 활용하세요.

---

## 5단계: 매수 고객 정보 등록하기 (매수의향)

이제 반대편 — **매수를 원하는 고객**의 요구조건도 등록합니다.

### 📝 실습용 매수 고객 메모 (복사해서 붙여넣기)

```
법인 매수자, 예산 60~100억.
강남·서초·역삼 권역 꼬마빌딩 선호.
임대수익형 투자 목적. 만실 희망.
위반건축물 불가. 목표수익률 4% 이상.
```

### 등록 방법

1. 상단 메뉴에서 **「매수의향」** 탭을 클릭합니다
2. **「새 매수의향 등록」** 또는 **「매수자 메모 입력」** 버튼을 클릭합니다
3. 위 메모를 붙여넣고 **「등록」**을 클릭합니다
4. AI가 자동으로 구조화합니다:

| 항목 | AI가 파싱한 결과 |
|:---|:---|
| 매수자 유형 | 법인 |
| 예산 | 60억 ~ 100억 |
| 선호 지역 | 강남, 서초, 역삼 |
| 투자 목적 | 임대수익형 |
| 필수 조건 | 만실, 위반건축물 불가 |

> 💡 **팁**: 손님이 카톡으로 보내주신 요구조건 그대로 붙여넣으시면 됩니다.

---

## 6단계: AI 매칭 결과 확인하기

매수의향이 등록되면 AI가 **자동으로** 기존 매물과 매칭을 실행합니다.

### 매칭 결과 보는 법

1. 딜카드 페이지 → **「매칭된 매수자」** 섹션을 확인합니다
2. 또는 **AI 매칭 센터** (`/broker/matching`) 에서 전체 결과를 볼 수 있습니다

### 매칭 등급 읽는 법

| 등급 | 점수 | 의미 | 추천 행동 |
|:---:|:---:|:---|:---|
| **S** | 85점 이상 | 🟢 완벽한 궁합 | **즉시 연결** |
| **A** | 70~84점 | 🔵 높은 적합도 | **적극 추천** |
| **B** | 50~69점 | 🟡 참고 가능 | 조건 조율 가능 |
| **C** | 50점 미만 | ⚪ 부적합 | 패스 권장 |

### 매칭 3단계 과정 (AI가 자동으로 합니다)

1. **1단계 — 기본 필터**: 지역, 예산, 건물 유형이 맞는지 확인합니다
   - 하나라도 안 맞으면 → C등급 (탈락)
2. **2단계 — AI 유사도**: 매물과 매수 조건의 텍스트를 AI가 비교합니다
3. **3단계 — 투자 목적 가중치**: 수익형/개발형/사옥형 등 목적에 따라 점수를 매깁니다
