# 📘 튜토리얼 2편 — 데이터 보완하고 모바일 IM 만들기

> **소요시간**: 약 25분  
> **난이도**: ⭐⭐ (1편을 완료한 분이 따라할 수 있습니다)  
> **준비물**: 1편에서 만든 딜카드 (당산동 수익형)  
> **선행 학습**: [1편 — 매물 메모 한 줄이면 딜카드가 뚝딱](01-매물등록-AI매칭-따라하기.md)  
> **기반 테스트**: [02-bottomsheet-mobile-im.md] TC-BS01~BS29

---

## 🎯 이번 편에서 하는 것

1편에서 AI가 메모를 분석해 딜카드를 만들었지만, 아직 빈 칸이 있을 수 있습니다.  
**바텀시트**에서 숫자와 사진을 보완하면 **모바일 투자설명서(IM)**가 자동 생성됩니다.

---

## STEP 1. 바텀시트 열기

1. 1편에서 만든 **당산동 딜카드 페이지**로 이동합니다
2. 화면 아래 **「⚡ 기본 IM」** 버튼을 누릅니다
3. 아래에서 **바텀시트**(입력 패널)가 올라옵니다

### 자동으로 채워지는 항목 (AI가 미리 넣어줌)

바텀시트가 열리면 1편에서 입력한 메모의 데이터가 **자동으로 채워져** 있습니다:

| 항목 | 자동 입력값 | 어디서 왔나 |
|:---|:---|:---|
| 매각희망가 | 115억 | 메모의 "매매가 115억" |
| 총보증금 | 2.9억 | 메모의 "보증금 총 2.9억" |
| 월세 | 1,946만 | 메모의 "월세 총 1,946만" |
| 투자 포스처 | 수익형 (income) | AI 자동 분류 |

> 💡 **자동으로 채워진 값**이 메모와 다르면 직접 고치시면 됩니다.

---

## STEP 2. 수익형(income) 데이터 보완하기

자동으로 안 채워진 빈 칸을 채웁니다:

### 📝 아래 값을 하나씩 입력하세요

| 입력 항목 | 입력할 값 | 입력 방법 |
|:---|:---|:---|
| 투자 포스처 | **수익형 (income)** | 이미 선택됨 → 확인만 |
| 매각희망가 | **115억** (11500000 만원) | 이미 채워짐 → 확인만 |
| 총보증금 | **29000 만원** | 이미 채워짐 → 확인만 |
| 월세 | **1946 만원** | 이미 채워짐 → 확인만 |
| 🆕 관리비 | **380 만원** | ← 직접 입력! |
| 🆕 대출 상태 | **미확인** | ← 선택! |
| 공실률 | **만실 (0%)** | 「만실」 버튼 클릭 |
| 🆕 브로커 한줄평 | **당산역 도보 5분 만실 수익형 빌딩** | ← 직접 입력! |

### ✅ 확인 포인트

- 바텀시트 **하단에 데이터 등급**이 표시됩니다
- **B등급 이상**이면 **「IM 생성하기」** 버튼이 활성화됩니다
- D등급(30점 미만)이면 버튼이 비활성화됩니다

---

## STEP 3. 공실률 입력 실습

공실률 입력은 여러 방식이 있습니다. 모두 해보세요:

| # | 해볼 것 | 이렇게 되어야 정상 |
|:---:|:---|:---|
| 1 | **「만실」** 버튼 클릭 | 버튼이 하이라이트, 공실률 0% |
| 2 | **「~10%」** 버튼 클릭 | "⚠️ 공실률 10% 반영" 경고 메시지 |
| 3 | **「직접입력」** → 25 입력 | 입력 필드 활성화, 25% 표시 |
| 4 | 「만실」 선택한 채로 메모에 "공실" 단어가 있으면 | 💡 **"메모와 충돌합니다"** 경고 표시 |
| 5 | 30% 선택한 채로 메모에 "만실" 단어가 있으면 | 💡 **"메모와 충돌합니다"** 경고 표시 |

> 💡 실습 후 다시 **「만실」**로 되돌리세요 (당산동 빌딩은 만실이므로).

---

## STEP 4. 사진 관리 실습

### 사진 업로드하기

1. 바텀시트의 **「사진」** 영역을 찾습니다
2. **「사진 추가」** 버튼을 눌러 건물 사진을 올립니다 (최대 12장)

### 사진 기능 실습

| # | 해볼 것 | 결과 |
|:---:|:---|:---|
| 1 | 사진 올리기 | 썸네일 미리보기 표시 |
| 2 | 사진에 **★ (별)** 클릭 | 노란 별 활성화 → **대표 사진** 지정 |
| 3 | 사진에 **🏢 (건물)** 클릭 | 파란 아이콘 활성화 → **외관 사진** 지정 |
| 4 | 사진 분류 드롭다운 변경 | 8종: 외관/로비/실내/주차장/옥상/출입구/기계/도면 |
| 5 | 사진 **× (삭제)** 클릭 | 목록에서 제거 |

> 💡 **대표 사진(★)**은 투자설명서 표지에 들어갑니다. 가장 좋은 사진을 골라주세요!

---

## STEP 5. 포스처 변경 체험하기

투자 포스처를 바꾸면 입력해야 할 항목이 달라집니다:

### 개발형으로 바꿔보기

포스처 셀렉터에서 **「개발형 (development)」**을 선택합니다.

새로 나타나는 입력 항목:

| 항목 | 입력할 값 | 설명 |
|:---|:---|:---|
| 개발 목표 용도 | 업무시설 (office) | 신축 후 용도 |
| 개발 목표 규모 | 1530 평 | 신축 연면적 |
| 예상 건축비/평 | 1200 만원 | — |
| 명도 책임 | 매도인 (seller) | 누가 비워주나 |
| 명도 임차인 수 | 11 | — |
| 명도 예상 비용 | 5000 만원 | — |
| 명도 예상 기간 | 6 개월 | — |
| 인허가 종류 | 건축허가 | — |
| 인허가 상태 | 진행중 | — |

> ✅ **확인**: 명도·인허가 섹션이 새로 나타나는지 확인하세요.  
> ✅ **등급**: 이 정도 입력하면 **A등급**이 나옵니다.

### 다른 포스처도 해보세요

| 포스처 | 나타나는 전용 항목 | 기대 등급 |
|:---|:---|:---:|
| **자가사용형** | 사용 인원, 1인당 면적, 희망 층수, 현 임대료 | A |
| **운영형(호텔)** | 객실수, ADR, 가동률, GOP, 운영사, 연매출 | B |
| **단기매매형** | 취득일, 취득가, 보유기간, 전매횟수, 매도 사유 | A |

> 💡 실습 후 다시 **「수익형 (income)」**으로 되돌리세요.

---

## STEP 6. IM 생성하기

데이터 보완이 끝났으면:

1. 바텀시트 하단의 데이터 등급이 **B 이상**인지 확인합니다
2. **「IM 생성하기」** 버튼을 누릅니다
3. AI가 투자설명서(IM)를 자동 생성합니다

---

## STEP 7. 모바일 IM 확인하기

생성된 모바일 IM을 확인합니다:

### 표시되는 정보

| 항목 | 내용 |
|:---|:---|
| 건물 블라인드명 | 당산동 근생빌딩 |
| 지역 시그널 | 영등포·당산 |
| 가격대 | 100~200억 |
| 자산유형 | 근린생활시설 |
| 데이터 점수 | 72점 (예시) |
| 브로커 정보 | 내 이름, 소속, 연락처 |

### IM 섹션 확인 (7개)

| # | 섹션 | 들어 있는 내용 |
|:---:|:---|:---|
| 1 | 건물 개요 | 기본 스펙 요약 |
| 2 | 입지 분석 | 역세권·상권·교통 |
| 3 | 임대차 현황 | 층별 임대 내역 |
| 4 | 투자 분석 | 수익률·현금흐름 |
| 5 | 리스크 요인 | 법적·물리적 위험 |
| 6 | 투자 논거 | 이 매물을 사야 하는 이유 |
| 7 | 다음 단계 | 임장·미팅 안내 |

---

## STEP 8. 등급별 차이 체험하기

등급에 따라 IM이 달라집니다. 아래 시나리오를 시도해보세요:

| # | 시나리오 | 기대 등급 | 결과 |
|:---:|:---|:---:|:---|
| 1 | 당산동 수익형 (렌트롤 + 사진 다수) | **B** | IM 생성 가능 (7~9면) |
| 2 | 잠원동 개발형 (렌트롤 + 개발스펙 + 다필지) | **A** | IM 생성 가능 (9~11면) |
| 3 | 주소만 입력하고 나머지 전부 공란 | **D** | ❌ IM 생성 **불가** (차단) |
| 4 | 주소 + 매매가만 입력 | **C** | IM 생성 가능 (7면 최소) |

> 💡 **데이터를 많이 넣을수록 등급이 올라가고, 페이지가 풍성해집니다!**
