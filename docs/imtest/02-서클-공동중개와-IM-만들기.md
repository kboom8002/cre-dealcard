# 📘 튜토리얼 2편 — 동료 중개사와 서클 공동중개 + 기본 IM 만들기

> **소요시간**: 약 25분  
> **난이도**: ⭐⭐ (1편을 완료한 분이 따라할 수 있습니다)  
> **준비물**: 1편에서 만든 딜카드, 함께 공동중개할 동료 중개사 1명  
> **선행 학습**: [1편 — 매물 등록부터 AI 매칭까지](01-매물등록-AI매칭-따라하기.md)

---

## 🎯 이 튜토리얼에서 배우는 것

1. 동료 중개사와 **비밀 공동중개 팀(서클)**을 만들고 초대합니다
2. 서로의 매물과 매수 고객을 **주소와 이름은 숨긴 채** 공유합니다
3. AI가 **교차 매칭**해서 S등급이면 양측 동의 후 정보가 열립니다
4. 1편에서 만든 딜카드로 **기본 투자설명서(IM)**를 제작합니다

---

# 파트 A: 서클 공동중개

## 1단계: 서클(공동중개 팀) 만들기

> 📌 이 단계는 **매물을 가지고 있는 중개사(나)**가 진행합니다.

1. 상단 메뉴에서 **「서클」** 탭을 클릭합니다
2. **「새 서클 만들기」** 버튼을 클릭합니다
3. 아래 정보를 입력합니다:

| 입력 항목 | 입력값 |
|:---|:---|
| 서클 이름 | `강남 꼬마빌딩 공동중개팀` |
| 설명 | `강남·서초 권역 꼬마빌딩 매물과 매수자를 공유하는 팀입니다.` |

4. **「생성」** 버튼을 클릭합니다
5. 서클 상세 페이지가 나타납니다 — 현재 멤버는 **나 1명**입니다

---

## 2단계: 동료 중개사 초대하기

1. 서클 상세 페이지에서 **「멤버 초대」** 버튼을 클릭합니다
2. **초대 코드** 또는 **초대 링크**가 생성됩니다
3. 이 초대 링크를 **카카오톡으로** 동료 중개사에게 보냅니다

### 동료 중개사가 하는 일

1. 카카오톡에서 받은 초대 링크를 클릭합니다
2. credeal.net에 로그인합니다
3. **「서클 가입하기」** 버튼을 클릭합니다
4. 서클 멤버가 **2명**이 됩니다

> 💡 **확인**: 서클 상세 페이지에서 멤버 목록에 **나(owner)** + **동료(member)** = 2명이 보여야 합니다.

---

## 3단계: 매물 공유하기 (내 매물 → 서클)

> 📌 **주소와 소유자 정보는 숨겨집니다!** 동료에게는 "역삼동 · 꼬마빌딩 · 80억대" 정도의 **시그널만** 보입니다.

1. 1편에서 만든 딜카드 상세 페이지로 이동합니다
2. 액션 메뉴 → **「서클에 공유」** 클릭합니다
3. 방금 만든 **「강남 꼬마빌딩 공동중개팀」**을 선택합니다
4. **「공유」** 클릭합니다

### 동료 중개사에게 보이는 정보

| 보이는 정보 ✅ | 보이지 않는 정보 ❌ |
|:---|:---|
| 지역 (역삼동 권역) | ❌ 상세 주소 |
| 자산 유형 (꼬마빌딩) | ❌ 소유자 정보 |
| 가격대 (80억대) | ❌ 층별 임대 상세 |

이것을 **"시그널 전용(signal only)"** 모드라고 합니다.

---

## 4단계: 동료가 매수 고객 공유하기

> 📌 이 단계는 **매수 고객을 가지고 있는 동료 중개사**가 진행합니다.

동료 중개사가 자신의 매수의향을 서클에 공유합니다:

1. 매수의향 상세 페이지 → **「서클에 공유」** 클릭
2. **「강남 꼬마빌딩 공동중개팀」** 선택 → **「공유」** 클릭

### 나에게 보이는 정보

| 보이는 정보 ✅ | 보이지 않는 정보 ❌ |
|:---|:---|
| 예산 (60~100억) | ❌ 매수자 이름/연락처 |
| 선호 지역 (강남·서초) | ❌ 매수자 유형 상세 |
| 자산 유형 (꼬마빌딩) | ❌ 리스크 허용도 |

---

## 5단계: 교차 매칭 확인하기

매수의향이 공유되면 AI가 **자동으로 교차 매칭**을 실행합니다.

1. 서클 상세 페이지 → **「매칭 결과」** 탭을 클릭합니다
2. 매칭 카드가 표시됩니다:

| 내 매물 | 동료의 매수자 | 등급 | 점수 |
|:---|:---|:---:|:---:|
| 역삼동 꼬마빌딩 | (강남 60~100억 임대수익형) | **A** 또는 **S** | 70점+ |

> 💡 **S/A 등급**이 나오면 자동으로 추가 정보(면적, 임대 현황 등)가 공개됩니다.

---

## 6단계: 양측 승인 → 정보 공개

매칭 등급이 높아서 거래를 진행하고 싶다면, **양측이 모두 승인**해야 합니다.

### 내가 먼저 승인

1. 매칭 카드 클릭 → **「신원 공개 승인」** 버튼 클릭
2. 확인 다이얼로그에서 **「승인」** 클릭
3. 이 시점에서는 아직 **정보가 열리지 않습니다** (일방 승인)
4. 동료에게 알림이 갑니다: "상대 중개사가 승인했습니다"

### 동료도 승인하면

1. 동료가 자신의 매칭 카드에서 **「신원 공개 승인」** 클릭
2. **양측 승인 완료!** 🎉
3. 이제 다음 정보가 열립니다:

| 항목 | 변경 전 | 변경 후 |
|:---|:---|:---|
| 내 매물 | 역삼동 · 80억대 | **전체 주소 + 상세 정보** |
| 동료의 매수자 | 60~100억 · 강남 | **매수자 유형 + 상세 조건** |
| 딜 파이프라인 | — | **공동중개 딜 자동 생성** |

4. **「파이프라인」** 메뉴를 확인하면 공동중개 딜이 만들어져 있습니다

> ⚠️ **중요**: 한번 열린 정보는 다시 숨길 수 없습니다. 승인 전에 신중하게 판단해주세요.

---

# 파트 B: 기본 투자설명서(IM) 만들기

## 7단계: 바텀시트에서 데이터 보완하기

이제 1편에서 만든 딜카드를 **기본 투자설명서(IM)**로 만들어봅니다.

1. 딜카드 상세 페이지로 이동합니다
2. 화면 아래 **「⚡ 기본 IM」** 버튼을 클릭합니다
3. **바텀시트**가 올라옵니다 — 핵심 숫자를 확인하고 보완합니다

### 📝 바텀시트 입력 항목 확인

AI가 메모에서 뽑아낸 데이터가 **자동으로 채워져** 있습니다. 빈 칸만 채우세요:

| 입력 항목 | 자동 입력값 | 직접 수정이 필요하면 |
|:---|:---|:---|
| 투자 포스처 | 수익형 (income) | 다른 유형이면 변경 |
| 매각희망가 | 115억 | 정확한 금액 확인 |
| 총보증금 | 2.9억 | — |
| 월세 | 1,946만 | — |
| 관리비 | (빈칸) | **입력 필요**: 380만원 |
| 대출금액 | (빈칸) | 아시면 입력 |
| 공실률 | 0% (만실) | — |
| 브로커 한줄평 | (빈칸) | **입력 권장**: "당산역 도보 5분 만실 수익형 빌딩" |

4. 하단에 **데이터 등급**이 표시됩니다 (B 이상이면 OK)
5. **「IM 생성하기」** 버튼을 클릭합니다

> 💡 **팁**: 데이터를 많이 채울수록 등급이 올라가고, 투자설명서 내용이 풍성해집니다.

---

## 8단계: 기본 IM PPTX 다운로드

모바일 IM이 생성되면 **PPTX(파워포인트) 파일**로 다운로드할 수 있습니다.

### 다운로드 방법 1: 딜카드에서 바로

1. 딜카드 상세 → **IM** 탭 클릭
2. **「PPTX 다운로드」** 버튼 클릭
3. 7~11페이지짜리 파워포인트 파일이 저장됩니다

### 다운로드 방법 2: 링크로 공유

- 링크를 카카오톡으로 매수 고객에게 보내면, 고객이 직접 다운로드할 수 있습니다
- 시간당 10회까지 다운로드 가능합니다

### PPTX 구성 (수익형 기준 최대 11페이지)

| 순서 | 페이지 내용 | 확인 포인트 |
|:---:|:---|:---|
| 1 | **표지** | 건물명, 매각가, 브로커 프로필 |
| 2 | **핵심 지표** | Cap Rate, NOI, 평당가, 연면적 |
| 3 | **건물 개요** | 사진, 층수, 준공년도 |
| 4 | **입지 분석** | 네이버 지도, 역세권 정보 |
| 5 | **토지 정보** | 지적도, 용도지역, 건폐율/용적률 |
| 6 | **층별 렌트롤** | 임차인, 면적, 보증금/월세 |
| 7 | **현장 사진** | 4분할 갤러리 |
| 8 | **투자 구조** | 수익률, 현금흐름 |
| 9 | **리스크 분석** | 법적/물리적 리스크 |
| 10 | **투자 논거** | 4대 핵심 장점 |
| 11 | **면책 고지** | 법적 고지 사항 |

> 💡 **확인**: 파일을 열어서 금액이 **"115억"**으로 나오는지, **"{{미입력}}"**이나 **"undefined"** 같은 오류 문구가 없는지 꼭 확인하세요!

---

## 9단계: IM Studio에서 직접 편집하기 (선택)

더 세밀하게 수정하고 싶다면 **Studio**를 사용합니다:

1. 딜카드 상세 → IM 탭 → **「Studio에서 편집」** 클릭
2. 왼쪽에 **슬라이드 목록**, 오른쪽에 **편집 패널**이 나타납니다
3. 수정할 수 있는 항목:

| 슬라이드 | 편집 가능 항목 |
|:---|:---|
| 표지 | 제목 문구 변경 (예: "프리미엄 수익형 오피스") |
| 핵심 지표 | 수치 직접 입력/수정 |
| 건물 개요 | 설명 문구 변경 |
| 사진 갤러리 | 사진 순서 변경 (드래그) |
| 투자 논거 | 4대 포인트 직접 작성 |
| 면책 고지 | 추가 특약 사항 입력 |

4. 수정 후 상단 **「PPTX 다운로드」** → 수정된 버전이 다운로드됩니다

> ⚠️ 같은 시간에 다른 사람이 수정하면 **"이미 수정되었습니다"** 경고가 나옵니다. 이때는 새로고침 후 다시 수정하세요.
