## 🎯 이 튜토리얼에서 배우는 것

기관투자자나 대형 법인 매수자에게 보내는 **대외비 전문 투자설명서(Pro IM)**을 만듭니다.

기본 IM(7~11페이지)과 달리:
- **30~40페이지** 분량의 심화 보고서입니다
- **NDA(비밀유지계약) 전자서명** 후에만 열람 가능합니다
- **다운로드 횟수 제한** + **워터마크 추적**으로 유출을 방지합니다

---

## 기본 IM vs Pro IM — 한눈에 비교

| 항목 | 기본 IM (2편에서 만든 것) | Pro IM (이번 편) |
|:---|:---|:---|
| 📄 분량 | 7~11페이지 | **30~40페이지** |
| 🔓 열람 권한 | 링크만 있으면 누구나 | **NDA 서명 후에만** |
| 💰 현금흐름 | 단순 1개년 수치 | **5~10년 정밀 프로젝션** |
| 📊 민감도 분석 | 없음 | **금리 × Cap Rate 2D 매트릭스** |
| 💳 금융 시나리오 | 대출금 1건 | **LTV·금리 복수 시나리오** |
| 🏛️ 세무 분석 | 없음 | **취득세/재산세/종부세/양도세** |
| 🔒 워터마크 | 선택 (기본 텍스트) | **필수** (이름+전화+시각 추적) |
| ⬇️ 다운로드 한도 | 시간당 10회 | **총 10회** (Grant당) |

---

## 1단계: Pro IM 제작 요청하기

1. 딜카드 상세 페이지로 이동합니다
2. **IM** 탭 클릭 → **「Pro 전문 IM 요청」** 버튼을 클릭합니다
3. 시스템이 자동으로 **30~40페이지짜리 Pro IM** 초안을 생성합니다

### Pro IM 5대 챕터 구성

| 챕터 | 내용 | 페이지 수 |
|:---:|:---|:---:|
| **1장** | 📋 **Executive Summary** — 딜 개요, 핵심 투자 하이라이트, KPI | 5~7면 |
| **2장** | 🏢 **Property Analysis** — 입지, 개발 호재, 건물 스펙, 사진 | 6~10면 |
| **3장** | 💰 **Financial Analysis** — 전층 렌트롤, 다년도 현금흐름, 민감도 분석, 대출 시나리오 | 8~12면 |
| **4장** | ⚠️ **Risk & Market** — 시장 동향, 실거래가 비교, 공실 리스크 | 4~6면 |
| **5장** | 📎 **Appendix** — 세금 시뮬레이션, 법적 검토, 면책 조항 | 3~5면 |

---

## 2단계: 매수자에게 Grant(열람 권한) 발급하기

Pro IM은 아무나 볼 수 없습니다. **특정 매수자에게만 열람 권한**을 발급합니다.

1. 딜카드 상세 → IM 탭 → **「Pro IM Grant 발급」** 클릭
2. 매수자 정보를 입력합니다:

| 입력 항목 | 예시 |
|:---|:---|
| 매수자 이름 | 김기업 대표 |
| 연락처 | 010-1234-5678 |
| 이메일 | kim@company.co.kr |
| 유효 기간 | 30일 (기본값) |

3. **「Grant 발급」** 클릭합니다
4. 시스템이 **전용 열람 링크**를 생성합니다

> 💡 이 링크는 **이 매수자 전용**입니다. 다른 사람에게 공유해도 NDA를 서명하지 않으면 열 수 없습니다.

---

## 3단계: 매수자의 NDA 서명 → Pro IM 열람

### 매수자가 하는 일

1. 카톡이나 이메일로 받은 **전용 링크**를 클릭합니다
2. **NDA(비밀유지계약)** 화면이 나타납니다
3. 내용을 확인하고 **「동의 및 서명」**을 클릭합니다
4. NDA 서명이 완료되면 Pro IM 웹 페이지가 열립니다

### 매수자가 할 수 있는 것

| 기능 | 설명 |
|:---|:---|
| 📱 웹으로 보기 | A4 인쇄 규격의 HTML 웹 페이지 |
| 📥 PPTX 다운로드 | 30~40페이지 파워포인트 다운로드 (최대 10회) |
| 🖨️ 인쇄 | 웹 페이지에서 A4 인쇄 가능 |

---

## 4단계: 보안 기능 확인하기

### 🔒 5단계 보안 게이트

매수자가 Pro IM을 다운로드할 때 **5가지 검증**을 통과해야 합니다:

| 단계 | 검증 내용 | 실패 시 |
|:---:|:---|:---|
| 1 | Grant가 존재하고 활성 상태인가? | "열람 권한이 없습니다" |
| 2 | NDA를 서명했는가? | "비밀유지계약 서명이 필요합니다" |
| 3 | 내보내기가 허용된 Grant인가? | "내보내기 불허" |
| 4 | 유효 기간이 지나지 않았는가? | "열람 기간이 만료되었습니다" |
| 5 | 다운로드 횟수를 초과하지 않았는가? | "다운로드 횟수 초과" |

### 🔍 워터마크 추적

모든 페이지에 **투명 워터마크**가 삽입됩니다:

```
김기업 · 5678 · 2026-09-22 14:30
김기업 · 5678 · 2026-09-22 14:30
김기업 · 5678 · 2026-09-22 14:30
```

- **매수자 이름** + **전화 뒷 4자리** + **발급 시각**
- 유출 시 **누가 언제 받은 자료인지** 추적할 수 있습니다

## 5단계: 포스처별 Pro IM 특화 내용 확인하기

2편에서 선택한 투자 포스처에 따라 Pro IM 내용이 달라집니다:

### 수익형 (income) — 당산동 빌딩 실습 예시

| Pro IM 특화 분석 | 내용 |
|:---|:---|
| 📈 5년 현금흐름 표 | 연도별 임대 수입, 비용, 순수익 프로젝션 |
| 💵 레버리지 효과 | 대출 활용 시 자기자본 수익률(IRR) 비교 |
| 📊 민감도 매트릭스 | Cap Rate(4~6%) × 금리(3~5%) 조합별 가치 변동 |
| 💳 대출 3개 시나리오 | LTV 50%/60%/70% × 금리 3.5%/4.0%/4.5% |
| 🏛️ 세금 시뮬레이션 | 취득세 4.6%, 재산세, 종부세(해당 시), 양도세 |

### 다른 포스처라면?

| 포스처 | Pro IM 특화 분석 |
|:---|:---|
| **개발형** | 총사업비 수지표, 공정표, 분양 시나리오, PF 조달 |
| **사옥형** | 10년 TCO(총소유비용), 임차 vs 매입 비교, 사옥 ROI |
| **운영형** | GOP 시나리오, RevPAR 민감도, 위탁운영 구조 |
| **매매형** | 실거래 비교사례 상세, 손바뀜 주기, 회전율 |

## 6단계: Pro IM 다운로드 & 활용

### PPTX 다운로드 (매수자가)

1. Pro IM 웹 페이지 상단 **「PPTX 다운로드」** 클릭
2. 30~40페이지 파워포인트 저장 완료

### 열어서 확인할 사항

| ✅ 확인 항목 | 기대 결과 |
|:---|:---|
| 5대 챕터 간지(구분 페이지) | 있어야 함 |
| 전층 렌트롤 표 | 실제 층별 데이터 |
| 현금흐름 프로젝션 표 | 5~10년 수치 |
| 민감도 2D 매트릭스 | 금리 × Cap Rate |
| 워터마크 | 모든 페이지에 이름+전화+시각 |
| 오류 문구 없음 | "undefined", "null", "{{" 없어야 함 |

### 활용 팁

- 📧 **이메일**: PPTX 파일을 직접 첨부하여 매수자 투자심의위원회에 전달
- 🖨️ **인쇄**: 웹 페이지(HTML)에서 A4 인쇄하여 대면 미팅 시 제출
- 📱 **카카오톡**: 전용 링크를 공유하여 매수자가 직접 열람하도록 안내
