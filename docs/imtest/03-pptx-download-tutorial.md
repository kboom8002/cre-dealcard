# 실전 따라하기 3탄: 클릭 한 번으로 브리핑용 PPT(파워포인트) 다운로드하기

제이에스부동산중개(주) 중개사님, 2탄에서 만든 모바일 소개서(IM)는 잘 확인하셨나요? 
모바일로 보내는 것도 좋지만, VIP 고객님을 사무실에서 모실 때나 큰 화면으로 브리핑할 때는 아무래도 **파워포인트(PPT) 보고서**가 필요하죠. 

우리 시스템은 방금 입력한 자료를 예쁜 PPT 파일로 알아서 만들어 줍니다. 자, 마지막 실습을 시작해 보겠습니다!

---

## 1단계: 완성된 모바일 IM 페이지 열기
2탄 마지막에서 보셨던 완성된 **[모바일 IM 페이지]** 화면을 띄워주세요. 
(또는 공유하신 링크를 직접 누르셔도 됩니다.)

## 2단계: [PPT 다운로드] 버튼 찾기
화면 메뉴 중에 **[PPT 다운로드]** 혹은 **[보고서 다운로드]** 버튼을 찾아 클릭해 주세요.

> 💡 **주의 사항 (Rate Limit)**
> 많은 분들이 동시에 너무 많이 다운로드하는 것을 방지하기 위해, 한 자리(같은 IP)에서 **1시간에 10번까지만** PPT를 만드실 수 있습니다. 만약 너무 많이 누르시면 "Rate limit exceeded(횟수 초과)" 메시지가 뜰 수 있으니 주의해 주세요!

## 3단계: AI가 문서를 만드는 시간 기다리기 (최대 3~5분)
버튼을 누르면 화면에 "문서를 생성하고 있습니다"라는 안내가 나옵니다. 
이때 시스템 뒤에서는 똑똑한 AI가 7~11장짜리 예쁜 PPT 슬라이드를 순서대로 척척 구성하고 있습니다. 

* 1탄에서 '수익형'을 고르셨다면 -> 임대 수익 분석과 자산 평가 내용 위주로 나옵니다.
* 1탄에서 '개발형'을 고르셨다면 -> 신축 시 예상되는 규모와 건축비 내용 위주로 나옵니다.

조금만 여유를 갖고 기다려 주세요!

## 4단계: PPT 파일 열어서 확인하기
생성이 완료되면 컴퓨터나 핸드폰으로 `.pptx` 파일이 자동으로 다운로드됩니다. 
파일을 열어서 아래 내용들이 꼼꼼하게 잘 만들어졌는지 확인해 보세요.

1. **표지:** 건물 이름과 매매가가 깔끔하게 들어갔나요?
2. **요약(Overview):** 건물의 핵심 장점들이 잘 정리되어 있나요?
3. **투자 포인트:** 왜 이 건물을 사야 하는지 설득력 있는 문구로 적혀있나요?
4. **재무 분석 (수익형의 경우):** 월세와 수익률 계산이 보기 좋게 표로 들어가 있나요?

> 💡 **에러가 나요! (G30 등급 제한)**
> 혹시 "PPTX 다운로드 불가"라는 에러가 나면서 다운로드가 안 되나요? 
> 이것은 1탄에서 매물 메모를 너무 부실하게 적어서(데이터 점수가 30점 미만), 텅 빈 PPT가 만들어지는 것을 방지하기 위한 안전장치입니다! 다시 1탄으로 돌아가서 매물 정보를 조금 더 상세하게 적어주시면 다운로드가 가능해집니다.
