## 3. 투자 자세 5가지 — 중개인 말로

**"이 물건을 사는 사람이 무엇을 하려는가"** 입니다. 건물 종류가 아닙니다.

| 고를 것 | 이런 손님 | 최종 숫자 |
|---|---|---|
| **수익형** | 월세 받으려는 개인·법인 | **월에 얼마 남는가** |
| **사옥형** | 본인 회사가 들어가려는 법인 | **지금 임차료보다 싼가** |
| **개발형** | 헐고 새로 지으려는 분 | **언제 착공 · 얼마 남는가** |
| **운영형** | 숙박·요양 등 직접 운영 | **영업이익 · 자료 신뢰도** |
| **매매형** | 몇 년 뒤 되팔 목적 | **버티는 비용 · 파는 값** |

### 3.1 같은 건물도 손님에 따라 다릅니다

당산동 5층 건물 하나를 예로 들면.

| 손님 | 렌트롤을 이렇게 읽습니다 |
|---|---|
| 자산관리 법인 | 월세 합계 = **수입** |
| 법인 대표 | 3층을 비워 **본인이 입주** |
| 디벨로퍼 | 월세 합계 = **명도 비용의 크기** |

**같은 표인데 해석이 정반대입니다.** 그래서 먼저 여쭤보게 됐습니다.

### 3.2 모르겠으면

**손님이 정해지기 전이면 "수익형"으로 두셔도 됩니다.** 나중에 바꿔도 처음부터 다시 입력하지 않습니다. 부족한 칸만 추가로 물어봅니다.

## 4. 자세별 필수 칸

| 자세 | 반드시 필요 |
|---|---|
| **수익형** | 매각 희망가 · **월 임대료** |
| 사옥형 | 매각 희망가 |
| **개발형** | 매각 희망가 · **용도지역** |
| 운영형 | 매각 희망가 · **영업이익률** |
| 매매형 | 매각 희망가 · **비교 사례** |

**자세를 고르면 화면의 칸이 바뀝니다.** 개발형을 고르면 월 임대료 칸이 사라지고 용도지역 칸이 나타납니다.

### 4.1 용도지역이 왜 필수인가

용도지역을 모르면 **몇 평까지 지을 수 있는지 모릅니다.** 예전에는 400%로 일괄 가정했는데, 실제 물건은 2종일반주거 250%였습니다.

| | 지을 수 있는 면적 |
|---|--:|
| 400%로 가정 | 745평 |
| **실제 (250%)** | **466평** |

**279평 차이입니다.** 분양수입이 1.6배로 부풀려집니다. 그래서 모르면 아예 계산하지 않도록 바꿨습니다.

## 5. 렌트롤 엑셀 — 어디부터 채우나

**15칸 전부 채우실 필요 없습니다.** 6칸이면 IM이 나옵니다.

### 5.1 1단계 — 이것만 있으면 발행됩니다 (6칸)

| 칸 | 예 |
|---|---|
| 호실/층 | 3F |
| **업종/상호** | 사무실 |
| 보증금 | 50,000,000 |
| 월세 | 4,500,000 |
| **현 계약 만료일** | 2027-03-31 |
| 임대상태 | 임대중 |

### 5.2 2단계 — 여기까지 하면 임대료 비교가 됩니다 (+5칸)

계약그룹 · 임대면적 · **적용법령** · 관리비 · 현 계약 시작일

### 5.3 3단계 — 여기까지 하면 명도 시점이 나옵니다 (+3칸)

**최초 계약일** · **갱신요구권 행사** · 대항력 요건

### 5.4 🔴 "다음 한 칸"

화면이 **가장 이득인 칸 하나**를 알려드립니다.

```
다음 한 칸: 최초 계약일
→ 채우시면 임차인별 명도 가능 시점이 나옵니다
```

**한 번에 다 채우려 하지 마시고, 알려주는 칸부터 채우시면 됩니다.**

## 6. 🔴 상가와 주택은 다르게 물어봅니다

| | 상가 | 주택 |
|---|---|---|
| 갱신요구권 | **10년** | **1회 · 2년** |
| 기준 | **최초 계약일** | 현 계약 만료일 |
| 필요한 칸 | 최초 계약일 | **갱신요구권 행사 여부** |

### 6.1 주택은 최초 계약일로 계산이 안 됩니다

주택 임차인은 **갱신요구권을 한 번 쓰면 2년이 붙습니다.** 이미 썼는지 안 썼는지를 모르면 언제 비는지 알 수 없습니다.

| 임차인 | 실제 | 상가 방식으로 계산했다면 | 차이 |
|---|---|---|--:|
| 301호 | 2027-06 | 2029-04 | **1년 10개월** |
| 401호 | 2026-11 | 2029-08 | **2년 9개월** |

**개발형에서는 착공 시점이 통째로 어긋납니다.** 그래서 주택 칸에는 "갱신요구권 행사 — 있음/없음/모름"을 따로 여쭤봅니다.

**"모름"을 고르셔도 됩니다.** 그러면 숫자를 만들어내지 않고 "확인 필요"로 남깁니다.

## 7. 확인사항은 흠이 아닙니다

### 7.1 예전

```
권리 제한: (빈 칸)
```

**매수인은 자료가 없는 건지 문제가 없는 건지 알 수 없었습니다.**

### 7.2 이제

| 표시 | 뜻 |
|---|---|
| **확인 필요** — 등기부 미제출 | 아직 안 봤습니다 |
| **해당 없음** — 2026-08-20 등기부 확인 | **봤는데 문제 없습니다** |

**둘을 구분해서 보여줍니다.** "확인해서 문제없음"은 오히려 강점입니다.

### 7.3 확인사항은 공개 링크에서도 가리지 않습니다

주소나 임차인 상호는 공개 단계에서 가리지만, **확인사항은 그대로 보여줍니다.** 없는 걸 없다고 말하는 게 신뢰를 만듭니다.

## 8. 발행이 막혔을 때

| 메시지 | 무슨 뜻 | 하실 일 |
|---|---|---|
| **표지 월세 합계와 원장 합계가 다릅니다** | 요약 숫자와 렌트롤이 안 맞음 | **어느 쪽이 맞는지 골라주세요** |
| 임대면적 합과 표기 연면적이 다릅니다 | 층별 합 ≠ 연면적 | 공부 확인 |
| **첨부 서류 소재지가 다릅니다** | **다른 물건 서류가 붙음** | 서류 교체 |
| 대항력 근거 없이 "없음" 표기 | 근거 없는 단정 | 문구 수정 또는 자료 첨부 |
| 만료 계약이 절반을 넘습니다 | 재계약 리스크 | 갱신 예정 표기 |

### 8.1 실제로 있었던 일

양평동 IM에 **강남구 논현동 다른 물건의 토지이용계획원**이 붙어 있었습니다. 사람 눈으로는 못 잡았습니다. 이제는 주소를 비교해서 막습니다.

### 8.2 막는 게 아니라 물어보는 겁니다

**시스템은 어느 쪽이 맞는지 모릅니다.** 표가 자기모순일 때 한쪽을 임의로 고르면 틀린 IM이 나갑니다. 그래서 여쭤봅니다.

## 9. IM 화면이 달라지는 곳

### 9.1 첫 화면 숫자 4개

| 예전 | 이제 |
|---|---|
| Cap Rate | **매매가** |
| 예상 매각가 | **평당가** |
| 대지 지분 비중 | **월 임대료** |
| WALE | **확인 필요 n건** |

**매수인이 직접 검산할 수 있는 숫자만 남겼습니다.** Cap Rate는 계산 근거가 표기되지 않았고, 예상 매각가는 비교사례 없이 만들어진 값이었습니다.

### 9.2 새 페이지 — 투자 구조

| 왼쪽 | 오른쪽 |
|---|---|
| 매매가 | LTV 0% |
| 취득세 (4.6%) | LTV 40% |
| 중개보수 (0.9%) | **LTV 50%** |
| **총취득원가** | |

**매매가 250억 물건이면 실제로는 263.75억이 듭니다.** 취득세 11.5억 + 중개보수 2.25억입니다. 손님이 반드시 묻는 숫자입니다.

### 9.3 🔴 대출을 넣으면 월 현금이 나옵니다

양평동 기준 (금리 4.5% 가정).

| 대출 | 월 임대료 | 월 이자 | **월 남는 돈** |
|---|--:|--:|--:|
| 없음 | 4,657만 | 0 | **+4,657만** |
| 40% | 4,657만 | 3,750만 | **+907만** |
| **50%** | 4,657만 | 4,688만 | **−30.5만** |

**수익률 2.24%가 대출금리 4.5%보다 낮으면, 대출을 늘릴수록 손에 남는 게 줄어듭니다.** 이 물건은 절반 대출에서 마이너스가 됩니다.

> 예전 IM에는 "레버리지 활용 시 수익 극대화" 같은 문구가 들어갔습니다. **사실과 반대**라 손님이 계산해보면 신뢰를 잃습니다.

### 9.4 렌트롤이 전부 나옵니다

| 물건 | 행수 | 예전 | 이제 |
|---|--:|--:|---|
| 당산동 | 8 | 8 | 1장 |
| **양평동** | **12** | **8 (4행 누락)** | **1장 · 전부** |
| **잠원동** | **18** | **8 (10행 누락)** | **2장 · 전부** |

**"외 N건은 별첨 참조"가 없어집니다.**

### 9.5 전화 버튼이 맨 앞으로

```
예전  [공유] [PDF] [PPTX] [모드전환] [신청]
이제  [📞 전화] [신청] [공유] [···]
```

**50~60대 손님은 전화를 겁니다.** 눌러서 바로 걸리게 했습니다. PDF·PPTX는 중개인용이라 `···` 안으로 옮겼습니다.

## 10. 자주 나올 질문

**Q. 자료가 부족하면 IM을 못 만드나요**
아닙니다. 6칸이면 나옵니다. 부족한 부분은 "확인 필요"로 표시됩니다.

**Q. 확인 필요가 많으면 손님이 안 좋게 보지 않나요**
숨기는 것보다 낫습니다. 나중에 다르게 드러나면 그때 신뢰를 잃습니다.

**Q. 운영비를 모르면 순수익률은 어떻게 나오나요**
안 나옵니다. **모르는 숫자를 만들지 않습니다.** 예전에는 월세의 85%를 순수익으로 잡았는데 근거가 없었습니다.

**Q. 300억 넘는 물건은 왜 비교사례가 안 뜨나요**
실거래가 자동 조회가 **300억 초과를 제외**하고 있습니다. 주력 상단(300~500억)이 여기 해당합니다. **비교사례를 직접 입력**하시면 가격 근거가 나옵니다. 상한 자체를 올리는 작업은 개선 2개월차에 예정돼 있습니다.

**Q. 예전에 만든 IM은요**
그대로 있습니다. 다시 만드시면 새 방식으로 나옵니다.

**Q. 투자 자세를 잘못 골랐으면**
바꾸시면 됩니다. 부족한 칸만 추가로 여쭤봅니다.
