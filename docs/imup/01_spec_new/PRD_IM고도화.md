# 경영진 파트

## 1. 왜 지금인가

### 1.0 전제 — 주력 거래 대역

**30억~500억 상업용 부동산이 주력입니다.** 모든 진단·목표·커버리지 판단이 이 대역을 기준으로 합니다.

| 밴드 | 구간 | 매수 주체 (통상) |
|:-:|---|---|
| B1 | 30~80억 | 개인 자산가 · 소형 법인 |
| B2 | 80~150억 | 개인 자산가 · 법인 사옥 |
| B3 | 150~300억 | 법인 · 자산관리회사 |
| **B4** | **300~500억** | **법인 · 기관 · 시행사** |

> **밴드가 올라갈수록 매수 주체가 개인에서 법인·기관으로 이동합니다.** 어휘·근거 수준·실사 자료 요구가 함께 달라집니다.

### 1.1 실증 — 실매물 5건에서 확인된 것

제이에스 실매물 IM 5건을 역설계해 전 수치를 검산했습니다.

| # | 발견 | 수치 |
|:-:|---|--:|
| 1 | **Golden Set 오염** | **93.9%** (154/164) |
| 2 | **개발형 용적률 과대** | **+60%** |
| 3 | **실투자금 과소** | **11.6%** |

**① Golden Set 93.9% 오염** — AI가 참조하는 예시 164건 중 154건에 이모지·페르소나가 섞여 있고, **사람이 검증한 건은 0건**입니다. 이 예시가 다음 IM에 주입되어 같은 문제를 재생산합니다.

**② 개발형 용적률 +60% 과대** — 시스템이 용도지역과 무관하게 400%를 적용합니다. 제2종일반주거 물건(실제 250%)에 적용하면 신축 연면적이 745평으로 나오는데 실제는 466평입니다. **분양수입과 사업이익률이 1.6배 부풀려집니다.**

**③ 실투자금 11.6% 과소** — 취득세 4.6%와 중개보수가 빠져 있습니다. 115억 물건이면 **6.33억**을 덜 계산합니다. 매수인이 자금 계획을 세우는 바로 그 숫자입니다.

### 1.2 방치 비용

| 항목 | 현황 |
|---|---|
| 월 생성 시도 | **44건** (7월 18건 → 8월 44건, 2.4배) |
| Golden 오염 | 154건 · **매 생성마다 참조** |
| 입력 누락으로 미완료 | **36.4%** |

**생성량이 2.4배로 늘고 있습니다.** 오염된 예시를 참조하는 IM이 매달 늘어나고, 발행된 IM은 회수할 수 없습니다.

### 1.3 무엇이 문제가 아닌지

과잉 진단을 피하기 위해 명시합니다.

| | 판정 |
|---|---|
| **시스템 오류** | **0건** — 런타임·API·타임아웃 실패 없음 |
| 타임아웃 | 실제 장애 아님 (156초도 완료) |
| ~~사실 오류가 Golden에 축적~~ | **정정** — Golden은 **합성 데이터**라 사실 오류를 판정할 수 없습니다 (D16 §0.1) |
| 아키텍처 재설계 | **불필요** — 골격은 우수 |

**고쳐야 할 것은 값과 소수의 배치이지 구조가 아닙니다.**
