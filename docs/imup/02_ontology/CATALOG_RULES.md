## 1. R — 아키타입 규칙 (투자관점별)

> **v0.4 변경.** R 규칙군의 기준축이 `AssetClass`에서 **`investmentPosture`** 로 바뀌었습니다.
> 접두는 유지됩니다 — `INC`=`income` · `OWN`=`owner_occupied` · `DEV`=`development` · `OPR`=`operating` 🆕 · `TRD`=`trading` 🆕.
> 기존 `R-LND-xx`(대지)는 **`R-DEV-xx`로 흡수**됩니다 — 대지는 자산 유형이지 투자 관점이 아니었습니다.
> 기존 `R-LOG-xx`(물류)도 마찬가지로 `assetType`으로 이동하며, 물류 특유 판정은 `physical_spec` Pack이 담당합니다.

**기존 `R01~R09`는 `R-INC-01~09`로 개명**되었고 원 코드는 폐기입니다.

## 2. T · P — 임대차 · 필지 규칙

### 2.1 T — 임대차 법적 지위 (v0.4에서 **상가·주택 분기**)

> **v0.4 파괴적 변경.** v0.2~v0.3의 `T01~T06`은 상가건물임대차보호법만 가정했습니다.
> 다가구·상가주택·주거용 오피스텔은 **주택임대차보호법**이 적용되며 판정이 전혀 다릅니다.
> `T01~T06` → **`T-C-01~06`** 으로 개명하고 **`T-R-01~07`** 을 신설합니다.

법령 선택은 `buildingUse`가 결정합니다 (`CATALOG_ASSET_TYPES.md` §1.2). 혼합 물건은 **호실별로 분기**합니다.

#### 2.1.1 `T-C` — 상가건물임대차보호법

| 코드 | 판정 | 근거 조항 |
|---|---|---|
| T-C-01 | 환산보증금 = 보증금 + 월세×100, 지역 기준 대조 | 제2조·시행령 |
| T-C-02 | **대항력** — 인도 + **사업자등록** 시 성립. **기본값 `true`** | 제3조 |
| T-C-03 | 계약갱신요구권 — 최초 계약일부터 **10년 범위 내 수차례** | 제10조 |
| T-C-04 | 우선변제권 — 환산보증금 이하 + 확정일자 | 제5조 |
| T-C-05 | 차임 인상률 **5% 상한** — 환산보증금 이하만 | 제11조 |
| T-C-06 | **권리금 회수기회 보호** — 환산보증금 무관 적용 | 제10조의3~7 |

지역별 환산보증금 기준 — **서울 9억 · 과밀억제권역 등 6.9억 · 그 외 광역시 5.4억.**

#### 2.1.2 `T-R` — 주택임대차보호법 🆕

| 코드 | 판정 | 근거 조항 |
|---|---|---|
| T-R-01 | **환산보증금 개념 없음** — 전 임차인에게 법 전면 적용 | 제2조 |
| T-R-02 | **대항력** — 인도 + **주민등록(전입신고)** 시 성립. **기본값 `true`** | 제3조 |
| T-R-03 | 계약갱신요구권 — **1회 한정 · 갱신 후 2년** (최장 4년) | 제6조의3 |
| T-R-04 | 우선변제권 — 대항요건 + 확정일자 | 제3조의2 |
| T-R-05 | 차임 인상률 **5% 상한** — 갱신 시 | 제7조 |
| T-R-06 | **권리금 보호 없음** — 주택에는 제도 자체가 없음 | — |
| T-R-07 | **임대인 직접거주 갱신거절 가능** — 상가에는 없는 사유 | 제6조의3 제1항 제8호 |

#### 2.1.3 두 법의 차이가 만드는 결과

| 항목 | T-C (상가) | T-R (주택) | IM에 미치는 영향 |
|---|---|---|---|
| 갱신요구권 | **10년** | **4년** | 명도 가능 시점이 최대 **6년** 어긋남 |
| 대항요건 | 사업자등록 | 주민등록 | 확인해야 할 서류가 다름 |
| 환산보증금 | 있음 | 없음 | 5% 상한 적용 범위가 다름 |
| 권리금 | 보호 | 없음 | 명도 비용 추정이 달라짐 |
| 직접거주 거절 | 불가 | **가능** | 매수자의 활용 선택지가 다름 |

> **원룸건물을 상가 기준으로 판정하면 명도 가능 시점을 6년 과대평가합니다.** `development` posture에서 이 오차는 사업 일정 전체를 무너뜨립니다. 분기가 선택이 아닌 이유입니다.

#### 2.1.4 대항력 기본값 — 두 규칙군 공통

```ts
export function opposingPower(unit: LeaseUnit, basis: 'commercial' | 'residential'): boolean {
  const rule = basis === 'commercial' ? 'T-C-02' : 'T-R-02';
  const requirement = basis === 'commercial' ? '사업자등록 미신청' : '전입신고 미이행';
  // 반증이 없으면 true. false 표기에는 근거를 요구한다.
  if (unit.opposingPowerOverride === false && !unit.opposingPowerEvidence) {
    throw new OntologyViolation(rule, `대항력 부정 표기에는 근거가 필요합니다 (${requirement} 등).`);
  }
  return unit.opposingPowerOverride ?? true;
}
```

> **기본값 `true`가 핵심 설계 결정입니다.** 매수자에게 불리한 쪽을 기본값으로 두어, 유리하게 표기하려면 근거를 대게 만듭니다. v0.2 이래 유지합니다.

#### 2.1.5 법령 판정 불가 시

오피스텔(업무시설 × 주거 사용)처럼 자동 판정이 불가능한 경우입니다.

```ts
if (legalBasisOf(buildingUse) === 'ambiguous' && !unit.legalBasisConfirmed) {
  emit(Warning('T-AMB-01',
    '오피스텔은 실제 사용 용도에 따라 적용 법령이 달라집니다. 호실별 확인이 필요합니다.'));
}
```

**차단하지 않고 경고합니다.** 확인 전까지는 보수적으로 `T-R`(주택, 갱신 4년)을 적용하되 IM에 미확정임을 표기합니다.

```ts
export function renewalRemaining(firstContract: Date, basis: 'commercial' | 'residential',
                                 renewalExercised: boolean): number {
  const elapsed = yearsSince(firstContract);
  if (basis === 'commercial') return Math.max(0, 10 - elapsed);        // T-C-03
  if (renewalExercised) return 0;                                       // T-R-03 — 1회 소진
  return Math.max(0, 4 - elapsed);                                      // 최초 2년 + 갱신 2년
}
```

> **주택은 경과년수만으로 판정할 수 없습니다.** **묵시적 갱신은 갱신요구권을 소진시키지 않습니다** — 4년을 넘겨 거주 중이어도 갱신요구권이 그대로 남아 있을 수 있습니다.
> 따라서 `renewalExercised`는 **반드시 별도로 확인**해야 하며, 미확인 시 산출값을 표시하지 않고 "확인 필요"로 둡니다. 경과년수로 추정하면 매수자에게 유리한 쪽으로 틀립니다.

```ts
if (basis === 'residential' && unit.renewalExercised === undefined) {
  return { state: 'unknown', message: '갱신요구권 행사 이력 확인 필요 (묵시적 갱신은 권리를 소진하지 않음)' };
}
```

> **C32는 당산동 실증에서 나왔습니다.** 층별 구분등기 물건에서 공동담보가 설정되면 호실마다 같은 채권최고액이 등기되어 있어, 단순 합산하면 실제의 두 배가 나옵니다. 초안에서 32억으로 계산했다가 16억으로 정정한 사례입니다.
>
> **C31은 호텔 실증에서 나왔습니다.** GOP 기준 3.57%를 임대차 NOI 기준 Cap Rate 옆에 나란히 놓으면 매수자가 같은 지표로 오독합니다.

> **C21·C22가 가장 중요한 안전장치입니다.** 계산값에 실제보다 높은 신뢰 등급을 붙이는 것을 구조적으로 막습니다. 사람의 선의에 맡기면 반드시 새어 나갑니다.
>
> **C27은 사옥형 전용이지만 성격은 C17과 같습니다.** 판정이 지가 가정에 지배되므로 단일 값 제시는 사실상 투자 권유가 됩니다.
