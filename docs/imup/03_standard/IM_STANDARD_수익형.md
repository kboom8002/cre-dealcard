# 한국 소형상업용부동산 표준 IM — 수익형 포스처

> 개인·부티크 규모 중개인이 **실제로 만들 수 있는** 수준에서, 50~60대 매수인이 **판단할 수 있는** IM 표준.
> 제이에스부동산중개(주) 실매물 IM 5건 역설계와 국내외 모범 사례를 근거로 도출했습니다.

| | |
|---|---|
| **적용 범위** | 수익형(`income`) · **매매 30억~500억 상업용** (주력 대역) |
| **산출물** | PPTX IM (배포·인쇄) · 모바일 IM (카톡 공유) |
| **작성 주체** | 개인·부티크 중개인 (컨설팅사 아님) |
| **작성 시간 목표** | PPTX 90분 / 모바일 30분 |
| **최종 수정** | 2026-08-23 |

---

## 0. 이 표준이 답하는 하나의 질문

**"이 건물 사면, 내 돈 얼마 들어가고 매달 얼마 남습니까?"**

역설계한 실매물 IM 5건 중 **이 질문에 답한 IM은 없었습니다.** 전부 매매가·임대료·면적만 나열합니다.

두 물건을 실제로 계산해 봤습니다.

| | 당산동 115억 | 양평동 250억 |
|---|--:|--:|
| 총임대료 기준 수익률 | 2.03% | 2.24% |
| LTV 40% 월 순현금 | +221만 | +907만 |
| **LTV 50% 월 순현금** | **−210만** | **−30만** |
| LTV 60% 월 순현금 | −642만 | −968만 |

*대출금리 4.5% · 취득세 4.6% · 중개보수 0.9% 가정*

**두 물건 모두 대출을 절반 끼면 매달 적자입니다.** 매수인이 계약 후에 알게 되면 딜이 깨지고 중개인 신뢰도 무너집니다. IM에서 먼저 말하는 것이 결과적으로 유리합니다.

> 이 표준의 핵심은 화려한 편집이 아니라 **매수인이 손으로 검산할 수 있는 숫자 6개를 정확히 주는 것**입니다.

### 1.2 국제 관행 대조

해외 CRE Offering Memorandum의 표준 구성은 executive summary · property description · investment opportunity · financial analysis · market overview · rent roll · photos · **risks**입니다. 모범 사례 지침은 *"독자에게 낯선 전문용어와 업계 은어를 피할 것"* 을 명시합니다.

국내 실무와의 결정적 차이는 두 가지입니다.

| | 해외 OM | 국내 실매물 IM |
|---|:-:|:-:|
| Executive Summary | 필수 | **없음** |
| Risks | 필수 | **없음** |

**이 둘을 채우는 것만으로 국제 수준에 근접합니다.** 나머지는 이미 하고 있습니다.

## 2. 매수인 프로파일 — 50~60대 개인 및 법인

### 2.1 판단 순서

이 세대는 **아래 순서대로** 봅니다. IM 구성이 이 순서를 따라야 합니다.

| # | 질문 | 필요 숫자 |
|:-:|---|---|
| 1 | 얼마짜리인가 | 매매가 · **평당가** |
| 2 | 실제로 얼마 들어가나 | **총취득원가 · 실투자금** |
| 3 | 매달 얼마 남나 | **월 순현금** |
| 4 | 대출 끼면 나아지나 | **레버리지 방향** |
| 5 | 세입자는 안정적인가 | 렌트롤 · **만료일** |
| 6 | 비싼 건 아닌가 | **인근 매물 비교** |
| 7 | 나중에 팔리나 | 입지 · 거래 사례 |
| 8 | 뭐가 위험한가 | **리스크 · 확인사항** |

**2·3·4·8이 실매물 IM에 전무합니다.** 매수인 판단의 절반이 비어 있습니다.

### 2.2 이 세대의 행동 특성

| 특성 | 설계 반영 |
|---|---|
| **인쇄해서 본다** | A4 흑백 출력에서 판독 가능해야 · 색으로만 구분하지 않음 |
| **손으로 검산한다** | 합계는 반드시 맞아야 함 · 단위 통일 |
| **세무사·자녀와 상의한다** | 파일 그대로 전달 가능 · 근거 자립 |
| **노안** | 본문 최소 11pt · 표 최소 9pt · 회색 글씨 금지 |
| **영어 약어에 반감** | Cap Rate · NOI · CapEx 사용 금지 |
| **"다 좋다"를 믿지 않는다** | **결손을 표시하는 것이 신뢰를 만든다** |
| 전화로 연락한다 | 표지·마지막 장에 전화번호 |

### 2.3 🔴 결손 표시가 왜 신뢰를 만드는가

이 표준의 가장 반직관적인 원칙입니다.

```
❌ "권리제한사항 없는 깨끗한 권리관계 확인"   ← 등기부 없이 쓴 문장
✅ "등기부 미확보 — 계약 전 확인 필요"        ← 사실
```

50~60대 매수인은 **의심이 많고 검증합니다.** 확인되지 않은 것을 확인된 것처럼 쓰면 한 군데만 걸려도 전체를 불신합니다. 반대로 "이건 아직 확인 안 됐습니다"가 한 줄 있으면 **나머지를 믿습니다.**

부티크 중개인에게 특히 중요합니다. 자료가 완비되지 않는 것이 정상이므로, **결손을 정직하게 표시하는 형식**이라야 실제로 쓸 수 있습니다.

### 4.2 p2 한 장 요약 — 설계 상세

**가장 중요한 페이지입니다.** 매수인의 60%는 여기서 진행 여부를 정합니다.

#### 레이아웃 (13.33 × 7.5 in)

```
┌──────────────────────────────────────────────────────┐
│  ① 한 줄 정의 (24pt)                                  │
│     "당산역 도보 5분 · 병원·약국 임차 · 대지 153평"      │
├────────────────┬────────────────┬────────────────────┤
│  ② 매매가       │  ③ 실투자금     │  ④ 월 순현금        │
│    115억        │    60.9억       │    −210만          │
│  평당 7,500만   │  LTV 50% 기준   │  ⚠ 대출 시 적자     │
├────────────────┴────────────────┴────────────────────┤
│  ⑤ 시나리오 표 (LTV 0/40/50%)                         │
├──────────────────────────┬───────────────────────────┤
│  ⑥ 임대 요약              │  ⑦ 확인 필요 (3~5줄)       │
│   6호실 · 공실 0          │   · 건축물대장 연면적       │
│   자가사용 2              │   · 최초계약일 · 근저당      │
├──────────────────────────┴───────────────────────────┤
│  ⑧ 한 줄 코멘트 — 중개인 견해임을 명시                  │
└──────────────────────────────────────────────────────┘
```

#### ③ 실투자금 — 계산 공식 (반드시 명시)

```
총취득원가 = 매매가 + 취득세(4.6%) + 중개보수 + 기타비용
실투자금   = 총취득원가 − 보증금 − 대출금
```

> **취득세 4.6%** = 취득세 4.0% + 지방교육세 0.4% + 농어촌특별세 0.2% (상가·업무시설 표준세율)

#### ④ 월 순현금 — 계산 공식

```
월 순현금 = 월 임대료 − 월 대출이자 − 월 운영비
```

운영비를 모르면 **차감하지 않되 "운영비 미반영"을 반드시 병기**합니다. 임의 추정 금지.

#### ⑦ 확인 필요 — 이 칸을 비우지 않습니다

자료가 완비된 딜은 없습니다. **비어 있으면 오히려 의심받습니다.** 3~5줄이 적정합니다.

### 4.3 p6 투자 구조 — 설계 상세

#### 필수 표 ①  총취득원가 (당산동 예시)

| 항목 | 금액 |
|---|--:|
| 매매가 | 115.00억 |
| 취득세 4.6% | 5.29억 |
| 중개보수 0.9% | 1.03억 |
| **총취득원가** | **121.33억** |

**매매가보다 6.33억(5.5%)이 더 듭니다.** 이 표가 없으면 매수인은 115억만 준비합니다.

#### 필수 표 ②  레버리지 시나리오

| LTV | 대출금 | 실투자금 | 월 이자 | 월 순현금 | 자기자본 수익률 |
|:-:|--:|--:|--:|--:|--:|
| 0% | — | 118.4억 | — | 1,946만 | 1.97% |
| 40% | 46.0억 | 72.4억 | 1,725만 | 221만 | 0.37% |
| 50% | 57.5억 | 60.9억 | 2,156만 | **−210만** | **−0.41%** |

**전제 표기 필수** — 금리 4.5% · 원리금 중 이자만 · 운영비 미반영 · 대출 가능액은 은행 감정 결과에 따름

#### 🔴 역레버리지 경고 규칙

```
수익률 < 대출금리  →  "대출을 늘릴수록 자기자본 수익률이 낮아집니다" 문구 강제
```

두 물건 모두 해당합니다. **숨기면 안 됩니다.**

#### 대출 가능액 주의 문구 (필수)

> 은행은 매매가가 아니라 **감정가**를 기준으로 대출한도를 산정하며, 감정가가 매매가보다 낮게 나오는 경우가 있습니다. 잔금 일정 확정 전에 대출 승인을 받으시길 권합니다.

이 한 줄이 **잔금 미납 사고를 막습니다.** 실무에서 반복되는 사고 유형입니다.

#### 🔴 대상물건이 비교군보다 쌀 때 — 이유를 반드시 씁니다

당산동은 75백만원/평으로 비교군 최저(89)보다도 낮습니다. **이유를 안 쓰면 "뭔가 하자가 있나"로 읽힙니다.**

실제 이유는 검증됩니다.

| | 건물/토지 비율 |
|---|--:|
| 비교군 4건 | 4.26 ~ 6.48배 |
| **대상물건** | **2.84배** |

용적률 221.8%의 저밀 개발이라 연면적이 적고, 그래서 토지 평당가가 낮게 형성됩니다. **동시에 용적률 여유 178%p라는 장점이기도 합니다.**


**운영비를 차감하지 않았으면 '순'을 쓸 수 없습니다.** 현재와 미래를 비교할 때는 **같은 기준**을 씁니다.
