## `lease_status`

**명도 책임이 매도인에게 있습니다.**

매도인 명도 조건에서는 임차인별 상세 원장이 필수가 아닙니다. 다만 다음 4항을 계약서에 명기해야 합니다.

1. 명도 완료 기한
2. 기한 초과 시 위약 책임과 산정 방식
3. 잔금 지급과 명도 완료의 선후 관계
4. 명도 미완료 시 계약 해제 요건

> **매수인이 명도를 부담하는 조건이라면 임차인별 최초 계약일·갱신요구권 행사 이력·대항력 요건이 전부 필요합니다.** 명도 책임이 필요한 자료의 수준을 결정합니다.

신축 후 층별 임대 계획(stacking plan) 기준 월 임대료 합계는 9,717만원, 연 임대료는 **11.66억원**입니다.

| 기준 | 값 |

| 연 수익률 (보증금 차감) | 3.77% |

**총 투입비 기준 3.51%가 매수인이 볼 숫자입니다.**

## `investment_thesis`

**보유·임대형 개발입니다** — 분양이 아니라 신축 후 임대 운영을 전제로 합니다. 따라서 최종 판단 기준은 개발이익이 아니라 **개발 후 수익률 3.51%** 입니다.

**명도 리스크가 매도인에게 있습니다** — 매수인이 임차인을 직접 정리할 필요가 없습니다. 다만 명도 완료 기한과 지체 시 책임을 계약서에 명기하지 않으면 실익이 없습니다.

**규제 시한이 사업 일정을 제약합니다** — 주의. 용적률 완화는 2028년 5월 18일 종료되며 잔여 634일입니다. **인허가 완료 시점이 이 기한 안에 들어오는지**를 건축사와 먼저 확인하시기 바랍니다. 완화가 적용되지 않으면 지상 연면적이 줄고 수익률 전제가 바뀝니다.
