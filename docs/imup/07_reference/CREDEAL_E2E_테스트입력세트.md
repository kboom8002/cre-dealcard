# CREDEAL E2E 테스트 입력 세트

> 딜카드 · 모바일 IM 생성 검증용 **최소 · 표준 · 충분** 3단계 입력.
> 작성 기준은 `input-surface-writing-guide.md`, 물건은 이번 세션에서 역설계한 실매물 5건입니다.

| | |
|---|---|
| **테스트 케이스** | 물건 5건 × 3단계 = **15** |
| **입력 표면** | 딜카드 메모 · Basic 바텀시트 · Pro 바텀시트 |
| **등급 기준** | 가이드(구현) — A 85+ / B 65+ / C 40+ / D 0~39 |
| **최종 수정** | 2026-08-04 |

> ⚠️ 실매물 정보 기반이며 일부 수치는 테스트용 가상 증강입니다. 대외 배포용이 아닙니다.

---

## 1. 이 문서의 사용법

가이드의 3개 입력 표면에 대해 물건마다 3단계 세트를 만들었습니다. **한 세트가 하나의 테스트 케이스**입니다.

```
물건 5건  ×  3단계(최소·표준·충분)  =  15 테스트 케이스

각 케이스 =  ① 딜카드 메모      (자유 텍스트 · 붙여넣기)
             ② Basic 바텀시트   (필드 입력)
             ③ Pro 바텀시트     (심화 필드)
```

### 1.1 3단계의 목적

| 단계 | 목표 | 확인하는 것 |
|---|---|---|
| 🔴 **최소** | 일단 등록 · 생성 성공 | 게이트 통과 · 결손 상태의 동작 · **차단이 걸리는가** |
| 🟡 **표준** | 쓸 만한 산출물 | Grade C~B 경계 · **포스처별 편성이 갈리는가** |
| 🟢 **충분** | 고품질 · 상위 등급 | Grade B 상위 · 팩 슬롯 전부 · 계산 정합 |

### 1.2 ⚠️ 등급 컷이 기존 명세와 다릅니다

첨부 가이드(구현 기준)와 레포 명세의 **B·C 하한이 어긋납니다.** 이 문서는 가이드를 따릅니다.

| 등급 | 가이드 (구현) | 레포 명세 | 해제 기능 |
|:-:|:-:|:-:|---|
| A | 85~100 | 85~100 | DCF 10년 민감도 |
| **B** | **65~84** | 70~84 | Pro IM 생성 |
| **C** | **40~64** | 50~69 | Basic IM 생성 |
| D | 0~39 | 0~49 | 생성·공개 차단 |

> 이 문서의 예상 등급은 **가이드 기준**입니다. 실행 후 어느 쪽으로 동작하는지 확인하고 한쪽으로 통일해야 합니다.

### 1.3 등급 가중치 (가이드 §1.3)

| 카테고리 | 가중 | 포스처별 조정 |
|---|:-:|---|
| 임대 현황 `lease_roll` | 25% | **개발형 ×0.4 · 운영형 ×0.0** |
| 건물 기본 `building_basic` | 15% | 나대지는 해당 없음 |
| 토지 정보 `land_parcel` | 15% | — |
| 재무 입력 `financial_input` | 15% | — |
| 용도지역 `zoning` | 10% | — |
| 권리 분석 `title_encumbrance` | 10% | — |
| 도로·접근 `road_access` | 5% | — |
| 시세 비교 `market_comp` | 5% | — |
| **팩 슬롯** `pack` | **0~30%** | **개발형 +40 · 운영형 +30** |

## 2. 테스트 케이스 매트릭스

| # | 물건 | 포스처 | 자산유형 | 매각가 | 최소 | 표준 | 충분 |
|:-:|---|:-:|:-:|--:|:-:|:-:|:-:|
| 1 | 잠원동 26-14·16 두원빌딩 | **개발형** | 근생빌딩 | 242억 | C | B | **B** |
| 2 | 당산동5가 11-47 근생빌딩 | **임대수익형** | 근생빌딩 | 115억 | C | B | **B** |
| 3 | 수택동 419-19 외 2필지 | **개발형** | 나대지 | 89억 | D~C | C | **B** |
| 4 | 양평동4가 117 더레드빌딩 | **임대수익형** | 사무용빌딩 | 250억 | C | B | **B** |
| 5 | 에이치에비뉴호텔 (이대점) | **운영형** | 호텔 | 300억 | D | C | **B** |

> 5번 호텔의 최소 세트는 **Grade D로 차단이 정상 동작**입니다. 실패가 아니라 기대 결과입니다.

### 2.1 케이스별 핵심 확인 사항

| # | 단계 | 무엇을 잡는가 |
|:-:|:-:|---|
| 1 | 🔴 최소 | 포스처 미선택 시 개발형 물건에 수익률 문항이 생성되는지 확인 |
| 1 | 🟡 표준 | lease_roll ×0.4 감쇠와 development_plan +20 가산이 적용되는지 |
| 1 | 🟢 충분 | 지상 연면적 기준 247.0%와 공부상 325.6%가 2기준으로 병기되는지 |
| 2 | 🔴 최소 | 포스처 미선택이 우연히 맞는 경우 — 경고 없이 통과하는지 |
| 2 | 🟡 표준 | 층별 합계와 연면적 불일치(원본 300㎡ 오기)가 C19로 잡히는지 |
| 2 | 🟢 충분 | 401호 시세(3,060천)가 아니라 상한(2,730천)으로 계획이 잡히는지 · C32 공동담보 |
| 3 | 🔴 최소 | 나대지 × income은 차단 조합 — 포스처 선택을 강제하는지 |
| 3 | 🟡 표준 | building_basic이 not_applicable로 재배분되는지 |
| 3 | 🟢 충분 | 1,260%가 ◇가정 배지 + 전제 조건과 함께 표기되는지 (C22) |
| 4 | 🔴 최소 | 공실률 버튼값(~20%)과 실제(17.0%)의 차이가 어떻게 반영되는지 |
| 4 | 🟡 표준 | 용적률 지상 398.8% / 전체 480.2% 병기 |
| 4 | 🟢 충분 | DCF 잠김 (A 미달) · 안정성 문항이 인상 여력 문항을 대체하는지 |
| 5 | 🔴 최소 | 차단 시 "무엇을 몇 분 채우면 되는지"가 함께 나오는지 |
| 5 | 🟡 표준 | ADR·OCC 미입력 시 시장 기본값(12만/65%/25%)이 ◇가정으로 표기되는지 |
| 5 | 🟢 충분 | C31 — GOP 3.57%가 NOI 기준과 나란히 놓이지 않는지 |

둘 다 확정 단계는 아니지만 방향은 잡혔다.

신축은 지하1~지상6층으로 근생·의원·업무 복합으로 보고 있다.

## 8. 실행 체크리스트

### 8.1 단계별 진행

| 순서 | 작업 | 확인 |
|:-:|---|---|
| 1 | 물건 1~5의 **최소 메모**를 순서대로 투입 | 전부 딜카드가 생성되는가 (5번은 차단이 정상) |
| 2 | 최소 Basic 바텀시트 입력 | 등급 산출값이 예상 범위인가 |
| 3 | 포스처 미선택 케이스 확인 | 1·3번에서 기본값 `income`이 오분류를 만드는가 |
| 4 | **표준 세트** 전체 투입 | 포스처별 문항 구성이 실제로 갈리는가 |
| 5 | **충분 세트** 전체 투입 | 팩 슬롯이 전부 활성화되는가 |
| 6 | Pro 진입 시도 | Grade B 미만에서 차단되는가 |
| 7 | 등급 컷 대조 | 가이드(B65) / 명세(B70) 중 어느 쪽으로 동작하는가 |

### 8.2 반드시 확인할 것

| 구분 | 확인 항목 |
|---|---|
| 생성 | 최소 메모가 4종 게이트(위치·유형·숫자·거래) 중 1개만으로 통과하는가 |
| 생성 | 5번 호텔 최소 세트가 Grade D로 차단되고 **부족 항목이 안내**되는가 |
| 포스처 | 1·3번(개발형)에서 `lease_roll`이 ×0.4로 감쇠하는가 |
| 포스처 | 5번(운영형)에서 `lease_roll`이 ×0.0으로 비활성화되는가 |
| 포스처 | 미선택 시 기본값 `income`이 나대지·호텔에 적용되어 **조합 오류**를 내는가 |
| 팩 | 개발형 3종(`development_plan`·`vacate_plan`·`permit_risk`)이 가산되는가 |
| 팩 | 5번 ADR·OCC 미입력 시 시장 기본값이 **◇가정**으로 표기되는가 |
| 계산 | 2번 층별 합계와 연면적 불일치가 감지되는가 |
| 계산 | 2번 401호 인상 계획이 **법정 상한(5%)으로 잘리는가** |
| 계산 | 3번 1,260% 용적률에 **전제 조건**이 붙는가 |
| 계산 | 4번 용적률이 **지상/전체 2기준**으로 병기되는가 |
| 표기 | 1·4번에서 지상 연면적 기준임이 명시되는가 |
| 등급 | 충분 세트에서 Grade A(85+)에 도달하는 물건이 있는가 |
| 등급 | A 미달 시 DCF가 잠기는가 |

### 8.3 알려진 원본 오류 — 재현되면 실패

| 물건 | 오류 | 기대 |
|---|---|---|
| 2 당산동 | 연면적 1,441.15 → 1,141.15 (300㎡) | 합계 불일치 감지 |
| 2 당산동 | 401호 +17.7% 인상 (상한 5% 초과) | 상한으로 절삭 · 경고 |
| 1 잠원동 | 2F 월임대료 40,000원 셀 오차 | 층별 합계 불일치 |
| 3 수택동 | 용적률 1,260%를 확정처럼 기재 | ◇가정 + 전제 조건 |
| 공통 | 대항력 전 호실 "무" | 기본값 ○ · 근거 없으면 차단 |

### 8.4 커버리지 공백

실매물 5건에 없는 조합입니다. 해당 경로를 테스트하려면 별도 케이스가 필요합니다.

| 미커버 | 필요한 물건 유형 |
|---|---|
| `residential_spec` | 다가구 · 상가주택 · 오피스텔 |
| `sectional_spec` (단독) | 지식산업센터 · 집합상가 |
| **T-R (주택임대차)** | 주거가 섞인 물건 — **갱신 4년 vs 10년 분기 미검증** |
| `owner_occupied` · `trading` | 사옥 · 단기매매 목적 |
| `physical_spec` | 물류창고 · 공장 |

> 연남동 상가주택(가상 골든)을 6번 케이스로 추가하면 앞의 셋이 한 번에 덮입니다.
