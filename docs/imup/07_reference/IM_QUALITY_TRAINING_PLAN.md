# IM 품질 오류 분류 및 AI 활용 교육 훈련 방안

> 실전 IM **5건 역설계**에서 확인된 오류·결손을 분류하고, 중개인이 AI 챗봇으로 **스스로 IM을 개선**하도록 훈련하는 프로그램을 설계합니다.
> 중개인이 실제로 쓰는 프롬프트는 `IM_SELF_REVIEW_PROMPTS.md`가 소유합니다.

| | |
|---|---|
| **표본** | 잠원동 두원빌딩 · 당산동 근생빌딩 · 양평동 더레드빌딩 · 수택동 419-19 · 에이치에비뉴호텔 |
| **작성 주체** | 제이에스부동산중개 · Genesis Asset (서로 다른 3개 법인) |
| **훈련 대상** | JS 중개인 400명 |
| **최종 수정** | 2026-08-03 |

---

## 0. 이 방안의 전제

**중개인은 IM을 못 만들어서 문제가 아닙니다.** 5건 모두 실제로 매수자에게 발송된 완성된 문서입니다. 문제는 다른 데 있습니다.

1. **검산할 시간이 없습니다** — 당산동 연면적 300㎡ 오기는 5분이면 찾지만, 아무도 5분을 쓰지 않았습니다
2. **모르는 것을 모릅니다** — 401호 +17.7% 인상 계획이 법적으로 불가능하다는 것을 알 방법이 없었습니다
3. **무엇이 빠졌는지 보이지 않습니다** — 5건 전부 최초 계약일이 없는데, 없다는 사실 자체가 인식되지 않았습니다

AI는 1·3번에 강하고 **2번에는 위험합니다.** 훈련 설계의 핵심은 이 구분입니다.

## 1. 오류 분류 — 실증 기반

### 1.1 5개 층위

| 층위 | 정의 | 발견 방법 | AI 적합도 |
|---|---|---|:-:|
| **L1 산술** | 문서 안에서 숫자가 안 맞음 | 재계산 | **높음** |
| **L2 기준 미명시** | 값은 맞으나 어느 기준인지 없음 | 정의 대조 | **높음** |
| **L3 결손** | 있어야 할 항목이 없음 | 체크리스트 | **높음** |
| **L4 법적 판정** | 법령상 불가능한 것을 가능하다고 씀 | 법령 대조 | **낮음 — 위험** |
| **L5 가정의 확정화** | 조건부 수치를 확정처럼 제시 | 근거 추적 | 중간 |

### 1.2 실제 발견 사례

| # | 물건 | 층위 | 내용 | 영향 |
|---:|---|:-:|---|---|
| 1 | 당산동 | **L1** | 연면적 1,441.15㎡ → **1,141.15㎡** 오기. 평 표기(307.9)도 함께 틀림 (정답 435.9평) | 평단가·수익률 계산 근거가 전부 어긋남 |
| 2 | 잠원동 | **L1** | 2F 월임대료 18,934,000 → **18,894,000** (−40,000). 합계는 맞음 | 층별 표와 합계가 불일치 |
| 3 | 잠원동 | **L2** | "실질 용적률 247%" — 산출 근거 없음 (지상 연면적 기준) | 매수자가 건축법상 용적률로 오독 |
| 4 | 당산동·양평동 | **L2** | 용적률 221.8% · 398.8% — 기준 미표기 | 동일 |
| 5 | 양평동 | **L2** | 수익률 칸 **공란** | IM에 수익률이 없음 |
| 6 | 5건 전부 | **L3** | 최초 계약일 · 환산보증금 판정 · 취득 부대비용 · 운영경비 · 제척 면적 | 임대차 법적 지위 판정 불가 |
| 7 | 당산동 | **L4** | 401호 국제와인 **+17.7% 인상 계획** — 환산보증금 2.90억(전면 적용) · 갱신권 7년 잔여 → **5% 상한 초과** | 매수 후 실현 불가능한 수익 제시 |
| 8 | 수택동 | **L5** | "1,260% 용적률 허가 필 2,500평" — **지구단위계획 전제 미고지** | 18개월 절차·기부채납 가능성 은폐 |
| 9 | 호텔 | **L3** | 2슬라이드 티저 — 소재지·연면적·준공·ADR·OCC 전부 없음 | 자료등급 4.58점(D) |

### 1.3 빈도

```
L2 기준 미명시   ████████████████████  5/5   전 건
L3 결손          ████████████████████  5/5   전 건 (항목 수만 다름)
L1 산술          ████████              2/5
L5 가정 확정화   ████                  1/5
L4 법적 판정     ████                  1/5   (확인 가능했던 건 중)
```

**L2와 L3이 전 건에서 나옵니다.** 그리고 이 둘이 AI로 가장 잘 잡히는 층위입니다 — 훈련의 투자 대비 효과가 여기에 있습니다.

### 1.4 심각도 대 발견 난이도

```
심각도
  높음  │  ⑦ L4 법적판정        ⑧ L5 가정확정화
        │  (실현 불가 수익)      (절차 은폐)
        │
        │  ① L1 연면적 오기
  중간  │                      ③④ L2 기준 미명시
        │  ⑥ L3 결손
        │
  낮음  │  ② L1 40,000원 오차
        └──────────────────────────────────────
           쉬움              어려움
                    발견 난이도
```

**우상단(⑦⑧)이 가장 위험합니다.** 심각한데 찾기 어렵고, 하필 AI가 가장 못 미더운 영역입니다. 훈련에서 **"AI 답변을 검증하는 법"** 을 따로 다뤄야 하는 이유입니다.

## 2. AI가 하는 것과 하면 안 되는 것

### 2.1 경계

| AI에게 맡김 | 사람이 해야 함 |
|---|---|
| 문서 내 숫자 재계산 (L1) | 공부 원본과 대조 |
| 기준 표기 누락 지적 (L2) | 어느 기준이 맞는지 결정 |
| 체크리스트 대조 (L3) | 빠진 값을 실제로 확보 |
| 법적 쟁점 **후보 제시** (L4) | **법적 판정 확정** |
| 가정·확정 구분 요구 (L5) | 가정의 타당성 판단 |
| 문장 다듬기 | 사실 확정 |

### 2.2 가장 큰 위험 — AI가 숫자를 만들어 냅니다

IM에 없는 값을 물으면 AI는 **그럴듯한 숫자를 채워 넣습니다.** 그 숫자가 IM에 들어가면 원래 오류보다 나쁩니다 — 출처가 없는데 확정처럼 보이기 때문입니다.

```
❌  "이 물건의 적정 임대료를 알려줘"
     → AI가 시세를 지어냅니다

✓   "이 IM에 임대료 근거가 제시되어 있는지 확인하고,
     없으면 '근거 없음'이라고만 답해줘. 추정하지 마."
```

모든 프롬프트에 **환각 방지 문구를 고정 헤더로 넣습니다** (`IM_SELF_REVIEW_PROMPTS.md` §1).

### 2.3 법령은 특히 위험합니다

AI는 상가건물임대차보호법과 주택임대차보호법을 **자주 섞습니다.** 갱신요구권을 주택 4년인데 10년으로, 또는 그 반대로 답하는 일이 흔합니다.

훈련에서 다음을 명시합니다.

> **AI의 법적 답변은 "확인해야 할 쟁점 목록"으로만 씁니다. 결론으로 쓰지 않습니다.**
> 조문 번호를 답하게 하고, 그 조문을 직접 확인하는 것까지가 한 세트입니다.

## 3. 훈련 프로그램 설계

### 3.1 구성

| 차수 | 시간 | 내용 | 산출물 |
|---|---|---|---|
| **1차 — 진단** | 60분 | 오류 주입 IM에서 오류 찾기 (AI 없이 → AI 사용) | 개인별 발견율 |
| **2차 — 실습** | 90분 | 8단계 프롬프트 실행 · 단계별 시연 | 본인 물건 IM 1건 개선 |
| **3차 — 검증** | 60분 | AI 답변 중 **틀린 것 찾기** | 오답 판별 능력 |
| **자율** | — | 본인 물건 3건 적용 · 결과 공유 | 개선 전후 비교 |

**3차가 핵심입니다.** 1·2차만 하면 AI를 맹신하는 중개인이 늘어나며, 이는 훈련 전보다 나쁜 상태입니다.

### 3.2 교보재 — 오류 주입판

골든 IM(`CREDEAL_투자설명서_Pro_골든.pptx`)에 **실제 발견된 오류 유형을 심어** 훈련용 IM을 만듭니다. 정답이 있으므로 채점이 됩니다.

| 주입 오류 | 원본 사례 | 층위 | 배점 |
|---|---|:-:|---:|
| 연면적 합계 300㎡ 불일치 | 당산동 | L1 | 15 |
| 층별 임대료 1개 셀 −40,000 | 잠원동 | L1 | 10 |
| 용적률 기준 미표기 | 3건 공통 | L2 | 15 |
| 수익률 기준 미표기 | 당산동·양평동 | L2 | 15 |
| 최초 계약일 누락 | 5건 공통 | L3 | 10 |
| 취득 부대비용 누락 | 5건 공통 | L3 | 10 |
| **5% 상한 초과 인상 계획** | 당산동 401호 | **L4** | **15** |
| **지구단위계획 전제 미고지** | 수택동 | **L5** | **10** |
| | | | **100** |

L4·L5에 배점을 높게 둡니다. 나머지는 도구가 잡아 주지만 이 둘은 사람이 알아야 합니다.

### 3.3 진단(1차) 설계

같은 IM을 두 번 봅니다.

```
1단계  AI 없이 15분        → 발견율 A
2단계  AI 사용 15분        → 발견율 B
3단계  정답 공개 · 해설    → B − A 가 AI의 기여
```

**A가 낮다고 지적하지 않습니다.** 5건을 만든 3개 법인 전부가 놓쳤던 것들입니다. 개인의 문제가 아니라 **검산 절차가 없다는 구조의 문제**임을 먼저 말합니다. 그러지 않으면 방어적이 되어 훈련이 안 됩니다.

### 3.4 검증(3차) 설계 — 오답 판별

AI가 실제로 자주 내는 틀린 답을 미리 수집해 제시하고, 어느 것이 틀렸는지 찾게 합니다.

| 제시할 AI 답변 | 판정 | 왜 틀렸는가 |
|---|:-:|---|
| "상가 갱신요구권은 1회 2년입니다" | **오답** | 주택 규정. 상가는 10년 범위 내 수차례 |
| "환산보증금 = 보증금 + 월세 × 12" | **오답** | ×100이 맞음 |
| "주택 임차인도 권리금을 보호받습니다" | **오답** | 권리금 보호는 상가만 |
| "4년 넘게 거주했으니 갱신권이 소진되었습니다" | **오답** | 묵시적 갱신은 권리를 소진하지 않음 |
| "용적률은 지하를 포함한 연면적 기준입니다" | 부분 오답 | 건축법상은 맞으나 실무 IM은 지상 기준을 병용 |
| "이 지역 평균 임대료는 평당 12만원입니다" | **오답** | 출처 없이 생성된 수치 |

마지막 항목이 가장 중요합니다. **틀린 게 아니라 근거가 없는 것**인데, 문장만 보면 구분되지 않습니다.

### 3.5 평가 지표

| 지표 | 측정 | 목표 |
|---|---|---|
| 오류 발견율 (AI 사용) | 주입 오류 8종 중 발견 수 | 6/8 이상 |
| L4·L5 발견율 | 고난도 2종 | 1/2 이상 |
| **AI 오답 판별율** | 6개 중 오답 지목 | **5/6 이상** |
| 실물 적용 | 본인 IM 3건 개선 완료 | 100% |

**AI 오답 판별율을 가장 높게 잡습니다.** 이것이 낮으면 나머지 지표가 높아도 위험합니다.

### 3.6 확산 순서

```
파워브로커 10명 (1기)  →  피드백 반영  →  30명 (2기)  →  전사 400명
```

파워브로커를 먼저 하는 이유는 두 가지입니다. 이들이 **IM을 가장 많이 만들고**, 이들이 쓰지 않으면 나머지도 쓰지 않습니다. v3.1에서 수임서 대신 PPTX IM으로 방향을 튼 것도 이들의 의견이었습니다.

## 4. 프롬프트 세트 개요

상세 문안은 `IM_SELF_REVIEW_PROMPTS.md`에 있습니다. 여기서는 **왜 이 순서인가**만 정리합니다.

| 단계 | 목적 | 잡는 층위 |
|---|---|:-:|
| 0 | 자료 투입 · 역할 설정 | — |
| 1 | 숫자 재계산 | L1 |
| 2 | 기준·정의 점검 | L2 |
| 3 | 결손 점검 | L3 |
| 4 | 법적 쟁점 **후보** 도출 | L4 |
| 5 | 가정 대 확정 구분 | L5 |
| 6 | 매수자 반론 (Red Team) | 전 층위 |
| 7 | 문장 다듬기 (사실 불변) | — |
| 8 | 최종 체크리스트 | 전 층위 |

### 4.1 단계를 나누는 이유

한 프롬프트에 전부 넣으면 AI가 **각 항목을 얕게 훑고 지나갑니다.** 특히 재계산은 다른 작업과 섞이면 거의 수행되지 않습니다. 당산동 300㎡ 오기는 "이 IM을 검토해줘"로는 잡히지 않고, "층별 면적을 전부 더해서 기재 연면적과 비교해줘"로만 잡힙니다.

### 4.2 순서를 바꾸면 안 되는 이유

**1단계(재계산)가 반드시 먼저입니다.** 숫자가 틀린 상태에서 6단계(반론)를 돌리면 AI가 틀린 숫자를 전제로 그럴듯한 분석을 만들어 내고, 그 분석이 IM에 들어갑니다.

**7단계(문장)는 반드시 마지막입니다.** 먼저 다듬으면 이후 수정에서 문장이 다시 어긋납니다.

## 5. 시스템과의 관계

CREDEAL이 자동으로 잡는 것과 훈련이 필요한 것을 구분합니다.

| 층위 | CREDEAL 자동 | 훈련 필요 |
|---|---|---|
| L1 산술 | **C01~C32가 전부 차단** | 시스템 밖 문서일 때만 |
| L2 기준 | **G10이 차단** (Cap Rate) · 용적률 2기준 병기 | — |
| L3 결손 | **등급 엔진이 표시** | 실제로 값을 확보하는 것 |
| L4 법적 | T-C/T-R 규칙군이 판정 | **판정 결과를 이해하는 것** |
| L5 가정 | C22가 `assumed` 강제 | **가정의 타당성 판단** |

> **훈련의 장기 목표는 훈련이 필요 없게 만드는 것입니다.** L1·L2는 시스템이 구조적으로 막으므로 훈련 항목에서 점차 빠집니다. 남는 것은 L3의 "값 확보"와 L4·L5의 판단 — 사람만 할 수 있는 부분입니다.

### 5.1 그래도 훈련이 필요한 이유

1. CREDEAL 도입 전 **기존 IM 재고**가 있습니다
2. 다른 경로로 만든 IM (매도인 제공 자료 등)이 계속 들어옵니다
3. **시스템의 판정을 이해하지 못하면 무시하게 됩니다** — 게이트가 막았을 때 왜 막혔는지 알아야 고칩니다
4. 중개인이 AI를 이미 쓰고 있습니다. 잘못 쓰는 것을 방치하는 것보다 낫습니다
