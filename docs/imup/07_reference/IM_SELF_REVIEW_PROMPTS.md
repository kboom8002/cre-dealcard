## 0단계 — 준비

### 0.1 자료 넣는 법

| 방법 | 권장도 | 주의 |
|---|:-:|---|
| **PPTX를 PDF로 변환 후 업로드** | **◎** | 표·숫자 인식이 가장 정확 |
| PPTX 그대로 업로드 | ○ | 표가 깨져 읽히는 경우 있음 |
| 표를 텍스트로 붙여넣기 | ○ | 숫자 검산에는 오히려 정확 |
| 화면 캡처 이미지 | △ | 숫자 오독 위험. 검산에는 부적합 |

> **1단계(재계산)만큼은 표를 텍스트로 함께 붙여넣으세요.** 이미지로만 주면 AI가 숫자를 잘못 읽고, 잘못 읽은 채로 "이상 없음"이라고 답합니다.

### 0.2 고정 헤더 — 매 단계 맨 앞에 붙입니다

```
[반드시 지킬 것]
1. 내가 제공한 자료에 없는 숫자·고유명사를 절대 만들어내지 마.
2. 자료에 없으면 "자료에 없음"이라고만 답해. 추정하거나 일반적인 시세를 대지 마.
3. 확실하지 않으면 "확인 필요"라고 표시해.
4. 법령을 인용할 때는 법률 이름과 조문 번호를 함께 써.
5. 표로 답하고, 각 항목에 근거(자료의 어느 부분인지)를 적어.
```

**이 헤더를 빼면 AI가 숫자를 지어냅니다.** 지어낸 숫자가 IM에 들어가면 원래 오류보다 나쁩니다 — 출처가 없는데 확정처럼 보이기 때문입니다.

### 0.3 역할 설정 (대화 시작 시 1회)

```
너는 상업용 부동산 투자설명서(IM)를 검토하는 실사 담당자야.
매수자 측에서 이 문서를 검증하는 입장이고, 틀린 것을 찾아내는 것이 네 일이야.

내가 IM을 단계별로 검토할 건데, 각 단계에서 요청한 것만 해줘.
요청하지 않은 분석을 덧붙이지 마. 특히 내가 주지 않은 정보로 판단하지 마.

준비됐으면 "준비됨"이라고만 답해.
```

## 1단계 — 숫자 재계산 ⭐ 가장 중요

> **이 단계를 건너뛰면 이후 전부가 무의미합니다.** 틀린 숫자를 전제로 분석하면 그럴듯한 오답이 나옵니다.

```
[고정 헤더 붙이기]

첨부한 IM에서 아래 항목을 하나씩 직접 계산해서, 문서에 적힌 값과 비교해줘.
암산하지 말고 계산 과정을 다 보여줘.

1. 층별 면적을 전부 더한 값 vs 문서에 적힌 연면적
2. 층별 보증금 합계 vs 문서의 보증금 합계
3. 층별 월임대료 합계 vs 문서의 월임대료 합계
4. 각 층: 면적 × 평당 단가 = 월임대료가 맞는지 (층별로 전부)
5. 건축면적 ÷ 대지면적 = 건폐율이 맞는지
6. 연면적 ÷ 대지면적 = 용적률이 맞는지
7. 매매가 ÷ 대지평수 = 토지 평단가가 맞는지
8. 매매가 ÷ 연면적평수 = 건물 평단가가 맞는지
9. 연 임대료 ÷ 매매가 = 표기된 수익률이 맞는지
10. 연 임대료 ÷ (매매가 − 보증금) = 표기된 수익률이 맞는지

결과를 이렇게 표로:
| 항목 | 문서 기재값 | 내가 계산한 값 | 차이 | 판정 |

차이가 0.5% 이내면 "반올림", 그 이상이면 "확인 필요"로 표시해줘.
```

### 실제로 잡힌 사례

| 물건 | 발견 | 원인 |
|---|---|---|
| 당산동 근생빌딩 | 층별 합계 1,441.15㎡ vs 기재 1,141.15㎡ | **300㎡ 타이핑 오기** (평 표기도 함께 틀림) |
| 잠원동 두원빌딩 | 2F 계산값 18,934,000 vs 기재 18,894,000 | 셀 오기 −40,000원 |

> 두 건 다 **합계는 맞았습니다.** 그래서 눈으로는 안 보입니다. 층별로 하나씩 계산해야만 나옵니다.

### 1-보충 — 여러 필지일 때

```
[고정 헤더]

이 물건이 여러 필지로 되어 있으면:
1. 필지별 면적이 각각 적혀 있는지, 합계만 있는지 알려줘
2. 필지별 면적의 합 = 기재된 대지면적 합계가 맞는지 계산해줘
3. 필지마다 용도지역이 같은지 다른지 확인해줘
4. 도로에 저촉되는 면적(제척)이 언급되어 있는지 확인해줘

없으면 "자료에 없음"이라고 해줘.
```

**실전 IM 5건 중 3건이 다필지였습니다.** 필지별 면적이 없으면 유효 대지면적을 알 수 없고, 신축 규모 계산이 전부 어긋납니다.

## 2단계 — 기준·정의 점검

> 값은 맞는데 **어느 기준인지 안 적힌** 경우입니다. 5건 전부에서 나왔습니다.

```
[고정 헤더]

첨부한 IM에서 아래를 확인해줘.

1. 용적률이 몇 %로 적혀 있어? 그게 어느 기준인지 문서에 적혀 있어?
   - 전체 연면적 기준(지하 포함)인지
   - 지상층 연면적 기준인지
   - 용적률 산정 연면적 기준(주차장 등 제외)인지
   문서에 기준이 안 적혀 있으면 "기준 미표기"라고 지적해줘.

2. 수익률(Cap Rate)이 몇 %로 적혀 있어? 어떻게 계산한 건지 적혀 있어?
   - 연 임대료 ÷ 매매가 인지
   - 연 임대료 ÷ (매매가 − 보증금) 인지
   - NOI(운영경비 차감 후) ÷ 매매가 인지
   기준이 안 적혀 있으면 지적해줘.

3. 면적이 "계약면적"인지 "전용면적"인지 구분되어 있어?

4. 관리비가 임대료에 포함인지 별도인지 적혀 있어?

각각 "명시됨 / 미표기 / 해당없음"으로 답하고, 미표기면 어떻게 고쳐야 하는지 문장을 제안해줘.
```

### 왜 중요한가

같은 건물의 용적률이 **기준에 따라 이만큼 다릅니다.**

| 물건 | 전체 연면적 기준 | 지상층 기준 | IM 기재 |
|---|---:|---:|---|
| 양평동 더레드빌딩 | 480.2% | **398.8%** | 398.8% (기준 미표기) |
| 당산동 근생빌딩 | 284.4% | **221.8%** | 221.8% (기준 미표기) |
| 잠원동 두원빌딩 | 329.9% | **247.0%** | "실질 용적률 247%" (근거 없음) |

서로 다른 세 중개법인이 독립적으로 지상층 기준을 씁니다. 실무 관행입니다. **다만 기준을 안 적으면 매수자는 건축법상 용적률로 읽습니다.**

수익률도 마찬가지입니다. 양평동은 기준에 따라 **2.00% ~ 2.46%** 로 갈립니다.

## 3단계 — 결손 점검

```
[고정 헤더]

첨부한 IM에 아래 항목이 있는지 하나씩 확인해줘.
있으면 "있음 + 어디에", 없으면 "없음"으로만 답해. 없는 값을 추정하지 마.

[임대차]
1. 각 임차인의 최초 계약일
2. 각 임차인의 현재 계약 만료일
3. 임차인별 업종
4. 계약면적과 전용면적 구분
5. 공실 여부·공실 면적
6. 관리비 수입

[금융·비용]
7. 취득세·중개보수 등 취득 부대비용
8. 운영경비 내역 (관리비·수선비·보험료·세금)
9. 기존 대출 잔액·금리·만기
10. 매수 시 대출 가능 조건

[권리]
11. 등기부상 근저당 채권최고액
12. 공동담보 여부
13. 가압류·가처분 등 기타 권리
14. 위반건축물 등재 여부

[토지·건물]
15. 공시지가
16. 도로 접면 상황 (몇 면, 폭)
17. 토지이용계획상 제한사항
18. 주차 대수

[시장]
19. 인근 실거래 비교사례
20. 권역 임대료 시세

마지막에 "없음"인 항목만 모아서, 매수자가 판단하는 데
얼마나 중요한지 상·중·하로 표시해줘.
```

### 실전 IM 5건에서 전부 없었던 것

| 항목 | 5건 중 누락 | 없으면 못 하는 것 |
|---|:-:|---|
| **최초 계약일** | **5/5** | 갱신요구권 잔여·명도 시점 판정 **전부 불가** |
| 환산보증금·법 적용 판정 | 5/5 | 임대료 인상 가능 폭 판정 불가 |
| 취득 부대비용 | 5/5 | 실제 투자수익률 계산 불가 |
| 운영경비 내역 | 5/5 | NOI 기준 수익률 계산 불가 |
| 제척 면적 | 5/5 | 유효 대지면적·신축 규모 판정 불가 |

**최초 계약일 하나가 없어서 임대차 관련 판단이 통째로 막힙니다.** 채우는 데 임차인당 1분이면 됩니다.

## 4단계 — 법적 쟁점 ⚠️ 결론으로 쓰지 마세요

> **이 단계의 답은 "확인할 목록"입니다. 판정이 아닙니다.**
> AI는 상가임대차보호법과 주택임대차보호법을 자주 섞습니다.

```
[고정 헤더]

첨부한 IM의 임대차 내용을 보고, 확인이 필요한 법적 쟁점을 목록으로 뽑아줘.
결론을 내리지 말고, "확인이 필요한 것"만 알려줘.

먼저 이것부터 확인해줘:
- 이 건물의 각 호실이 상가인지 주택인지
  (상가건물임대차보호법과 주택임대차보호법은 내용이 완전히 다름)

그 다음, 각 임차인에 대해:
1. 환산보증금(보증금 + 월세 × 100)이 얼마인지 계산
2. 그 금액이 해당 지역 기준(서울 9억 / 과밀억제권역 6.9억 / 그 외 광역시 5.4억) 이하인지
3. 이하라면 차임 인상률 5% 상한이 적용되는지
4. 계약갱신요구권이 얼마나 남았는지 (계산에 필요한 정보가 있는지부터)
5. 권리금 회수기회 보호 대상인지

만약 IM에 임대료 인상 계획이나 "임대료 현실화" 같은 내용이 있으면:
6. 그 인상률이 법적 상한을 넘는지 확인해줘

각 항목에 인용한 법률명과 조문 번호를 적어줘.
정보가 없어서 판단할 수 없으면 "정보 부족"이라고 해줘.
```

### 반드시 직접 확인해야 하는 것

AI 답변을 받은 뒤 **아래를 사람이 확인**합니다.

| 확인 항목 | 방법 |
|---|---|
| 상가인지 주택인지 | 건축물대장 용도 + 실제 사용 용도 |
| 인용한 조문이 실제 존재하는지 | 국가법령정보센터에서 조문 번호 직접 조회 |
| 지역별 환산보증금 기준액 | 시행령 최신 개정 확인 |
| 최초 계약일 | **계약서 원본** |

### 실제로 걸린 사례 — 당산동 401호

```
IM의 계획      월세 2,600천원 → 3,060천원  (+17.7%)

확인 결과      환산보증금 2.90억 → 서울 9억 이하 → 상임법 전면 적용
               최초 계약 2019년 → 갱신요구권 약 7년 잔여
               → 갱신 시 5% 상한 적용 → 최대 2,730천원

결론           계획 3,060천원은 갱신 시 법적으로 불가능 (330천원 초과)
```

**매수 후 실현할 수 없는 수익을 제시한 것**이 됩니다. 나중에 문제가 됩니다.

### AI가 자주 내는 오답

| AI 답변 | 판정 |
|---|:-:|
| "상가 갱신요구권은 1회 2년입니다" | **오답** — 주택 규정. 상가는 10년 범위 내 |
| "환산보증금 = 보증금 + 월세 × 12" | **오답** — ×100 |
| "주택 임차인도 권리금을 보호받습니다" | **오답** — 상가만 |
| "4년 넘게 거주했으니 갱신권이 소진되었습니다" | **오답** — 묵시적 갱신은 권리를 소진하지 않음 |

## 5단계 — 가정과 확정 구분

```
[고정 헤더]

첨부한 IM에서 "확정된 사실"이 아니라 "가정·계획·전망"인 내용을 전부 찾아줘.

특히 이런 것들:
1. 신축 가능 규모·용적률 — 실제로 허가받은 건지, 계획인지
2. 임대료 인상 계획·"현실화" 수치
3. 예상 수익률·미래 현금흐름
4. "개발 가능", "용도변경 가능" 같은 표현
5. 인허가 관련 서술

각각에 대해:
- 문서에 전제 조건이 적혀 있는지
- 그 전제가 충족되는 데 얼마나 걸리는지 적혀 있는지
- 확정된 것처럼 읽힐 위험이 있는지

확정처럼 읽히는데 전제가 안 적힌 항목은 어떻게 고쳐 써야 하는지 문장을 제안해줘.
```

### 실제 사례 — 수택동 419-19

```
IM 표기     "1,260% 용적률 허가 필 2,500평"

빠진 것     상업지역 법정 상한을 넘는 수치
            → 지구단위계획 수립 필요 (약 18개월)
            → 기부채납 조건 발생 가능
            → 연면적 2,500평이면 교통영향평가 대상 (6개월 추가)

용적률에 따른 차이   800%   → 토지비 부담 573만원/평
                   1,260%  → 토지비 부담 364만원/평   (57% 차이)
```

**2,500평이 확정인 것처럼 읽히면 매수자는 그 전제로 가격을 계산합니다.** 나중에 안 나오면 거래가 깨지거나 분쟁이 됩니다.

고쳐 쓰는 방법:

```
❌  1,260% 용적률 허가 필, 2,500평 규모 개발 가능

✓   용도지역 상 상업지역. 지구단위계획 수립 시 최대 1,260%까지 검토 가능하며,
    이 경우 연면적 약 2,500평 규모입니다.
    (지구단위계획 수립 약 18개월 예상 · 기부채납 조건 발생 가능 · 확정 아님)

    현행 기준 800% 적용 시 약 1,552평입니다.
```

## 6단계 — 매수자 반론 (Red Team)

> 1~5단계를 마친 뒤에만 실행하세요. **숫자가 틀린 상태에서 하면 그럴듯한 오답이 나옵니다.**

```
[고정 헤더]

이제 너는 이 물건을 검토하는 매수자의 실사 담당자야.
이 IM을 읽고 "사지 말아야 할 이유"를 최대한 찾아줘.

내가 제공한 자료 안에서만 판단해. 없는 정보로 추측하지 마.

이런 관점으로:
1. 이 수익률이 유지되지 않을 위험은?
2. 임차인이 나가면 어떻게 되나? 대체 임차 수요가 있나?
3. 이 가격이 비싸다고 볼 근거는?
4. 매도인이 팔려는 이유가 뭘 것 같은가? (자료에서 추론 가능한 범위만)
5. IM에서 의도적으로 강조하지 않은 것처럼 보이는 부분은?
6. 내가 매수자라면 반드시 추가로 요구할 자료는?

각 항목에 자료의 어느 부분을 근거로 했는지 적어줘.
```

### 쓰는 법

**여기서 나온 지적을 IM에 그대로 반영하지 않습니다.** 두 갈래로 나눕니다.

| 지적 유형 | 처리 |
|---|---|
| 사실이고 IM에 없음 | **IM에 추가** — 어차피 실사에서 나옵니다 |
| 사실이나 오해 소지 | **설명을 보강** |
| 자료 부족에서 온 오해 | **자료를 추가** |
| 근거 없는 추측 | 무시 |

먼저 나온 약점을 먼저 설명하는 IM이 신뢰를 얻습니다. 숨긴 약점은 실사에서 반드시 나오고, 그때는 신뢰까지 함께 잃습니다.

## 7단계 — 문장 다듬기 (반드시 마지막)

```
[고정 헤더]

첨부한 IM의 문장을 다듬어줘. 단, 절대 지켜야 할 것:

1. 숫자를 하나도 바꾸지 마
2. 고유명사(지명·임차인명·업종)를 바꾸지 마
3. 없는 사실을 추가하지 마
4. "예상", "전망", "유망" 같은 단정적 표현을 새로 넣지 마

다듬을 방향:
- 한 문장이 길면 나눠줘
- 같은 말이 반복되면 정리해줘
- 매수자가 바로 이해되지 않는 전문용어는 짧은 설명을 괄호로 붙여줘

수정 전후를 표로 보여주고, 바뀐 부분에 표시해줘.
```

### 약점을 강점으로 뒤집지 마세요 — 관점을 바꾸는 것은 다릅니다

같은 사실이라도 물건 성격에 따라 맞는 서술이 있습니다.

```
물건 상황   2018년 준공 · 용적률 398.8% (상한 400%) · 임대료 5% 상한 · 갱신권 2~7년 잔여

❌ 감추기   (증축·인상 이야기를 아예 안 씀)
❌ 억지     "향후 리모델링을 통한 가치 상승이 기대됩니다"   ← 근거 없음
✓ 정확     "2018년 준공, 용적률 398.8%로 상한에 근접합니다.
            추가 자본 투입 없이 현재 수익이 유지되는 구조입니다."
```

세 번째가 정확합니다. **손댈 것이 없다는 것은 예측 가능성**이고, 안정 수익을 찾는 매수자에게는 이것이 강점입니다.

## 8단계 — 최종 체크리스트

```
[고정 헤더]

수정을 마친 IM을 다시 첨부했어. 발송 전 최종 점검을 해줘.

1. 1단계에서 지적한 계산 오류가 전부 고쳐졌는지
2. 용적률·수익률에 기준이 표기되었는지
3. 가정·계획인 수치에 전제 조건이 붙었는지
4. 법적으로 불가능한 내용이 남아 있는지
5. 숫자가 두 곳 이상에 나오는 경우 서로 일치하는지
   (예: 표지의 연면적과 층별표 합계, 개요의 수익률과 분석의 수익률)
6. 오탈자·단위 오류 (㎡ / 평, 만원 / 천원 / 억원)

"통과 / 수정 필요"로 답하고, 수정 필요한 항목만 구체적으로 알려줘.
```

### 사람이 마지막으로 확인할 것

AI가 못 하는 것들입니다.

- [ ] 건축물대장·토지대장 **원본과 대조**
- [ ] 등기부등본 **발급일이 최근인지**
- [ ] 임대차계약서 **원본으로 최초 계약일 확인**
- [ ] 인용된 법 조문을 **국가법령정보센터에서 직접 확인**
- [ ] 매도인에게 받은 정보와 **공부가 일치하는지**
- [ ] 사진·도면이 **현재 상태인지**
