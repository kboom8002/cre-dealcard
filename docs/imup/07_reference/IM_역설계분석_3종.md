## 2. 수택동 419-19 외 2필지 — 대지형의 완벽한 실증

### 2.1 "Building Report" 양식의 빈칸

제이에스부동산중개의 표준 양식인데, **건물정보 칸이 전부 공란**입니다.

```
토지정보  면적 651.2㎡ · 196.98평 · 도시지역,상업지역
건물정보  연면적 ___  건폐율 ___  용적률 ___  규모 ___  준공년도 ___  승강기 ___
금융정보  보증금 ___  임대료 0  관리비 ___  융자금 ___  매매가 89억  수익률 ___
```

**이것이 `not_applicable` 상태의 실물 증거입니다.** 양식이 수익형 건물을 전제로 만들어져 있어, 나대지에서는 절반이 비어 버립니다. 우리 시스템이 자산군을 태그가 아닌 **스키마 분기점**으로 승격한 이유가 여기 있습니다.

### 2.2 검산

| 항목 | IM 기재 | 검산 | 판정 |
|---|---|---|---|
| 면적 | 196.98평 | 651.2 ÷ 3.3058 = 196.99 | ✓ |
| 평단가 | 4,500만원 | 89억 ÷ 196.98 = 4,518만원 | ✓ |
| 개발 규모 | 2,500평 | 651.2 × 12.60 ÷ 3.3058 = 2,482평 | ✓ |

### 2.3 토지비 부담 — 대지형의 진짜 비교 지표

평단가만으로는 용도지역이 다른 물건을 비교할 수 없습니다. 유효 대지 641.4㎡ 기준으로 —

| 시나리오 | 용적률 | 개발 가능 연면적 | **토지비 부담** |
|---|---:|---:|---:|
| 상업 800% | 800% | 1,552평 | 5,733,867원/평 |
| 상업 1000% | 1,000% | 1,940평 | 4,587,094원/평 |
| **허가 목표 1,260%** | **1,260%** | **2,445평** | **3,640,551원/평** |
| 상업 1500% | 1,500% | 2,910평 | 3,058,063원/평 |

**용적률이 800%냐 1,260%냐에 따라 토지비 부담이 57% 차이납니다.** 평단가 4,518만원은 이 차이를 전혀 담지 못합니다.

### 2.4 최대 리스크 — 1,260%의 근거

IM은 *"1,260% 용적률 허가 필 2,500평"* 이라고만 씁니다. 상업지역 법정 상한을 크게 넘는 수치이므로 **지구단위계획 수립 등 별도 절차가 전제**됩니다.

정밀 데이터셋에서는 이를 `permit_risk`로 정량화했습니다.

| 항목 | 상태 | 소요 |
|---|---|---:|
| **지구단위계획 수립** | **constraint** | **18개월** |
| 교통영향평가 | check_required | 6개월 |
| 개발행위허가 | clear | 2개월 |
| 기부채납 | check_required | 조건부 |

> **지구단위계획이 임계 경로입니다.** 확정 전에 2,500평을 확정 수치로 제시하면 안 됩니다. 제약 C23(신축 산정 용적률 ≤ 인허가 상한)이 이를 경고합니다.

## 3. 에이치에비뉴호텔 — 신규 자산군 `hospitality`

### 3.1 2슬라이드가 말해주는 것

확인 가능한 정보가 **네 개뿐**입니다.

```
물건명   에이치 에비뉴호텔 (이대점)
입지     이대역 도보 3분 · 신촌 대학가
객실 수   94실
매각가    300억원
```

소재지·대지면적·연면적·준공·용도지역·운영형태·ADR·OCC 전부 미기재입니다.

**자료등급 4.58점 → D → 발행 불가.** 우리 시스템은 이 상태에서 IM을 만들지 않습니다. 정직한 결과이고, 이것이 등급 게이트의 존재 이유입니다.

### 3.2 호텔은 왜 별도 Pack이 필요한가

| | 수익형 부동산 | **호텔** |
|---|---|---|
| 매출 근거 | **임대차 계약** | **영업 성과** |
| 수익 지표 | NOI ÷ 매각가 | **GOP ÷ 매각가** |
| 단위 지표 | 평당 임대료 | **객실당 단가 (per-key)** |
| 핵심 변수 | 공실률 · WALT | **ADR · OCC · RevPAR** |
| 리스크 | 임차인 이탈 | **운영 성과 · 계절성 · 관광 수요** |
| 법 체계 | 상가임대차보호법 | **관광진흥법 · 공중위생관리법** |

**Cap Rate를 NOI 기준 수익형과 직접 비교할 수 없습니다.** GOP는 운영 인건비·마케팅비를 차감한 뒤의 값이고, 임대차의 NOI와 성격이 다릅니다.

### 3.3 `hospitality_spec` 슬롯군 제안

```ts
export const HospitalitySpec = z.object({
  keyCount: z.number(),
  roomTypes: z.array(z.object({
    type: z.string(), count: z.number(), exclusiveArea: z.number(),
  })),
  adr: Money.nullable(),                    // 평균 객실 단가
  occupancy: z.number().nullable(),         // 점유율
  revpar: Money.nullable(),                 // 파생 — ADR × OCC
  ancillaryRevenueShare: z.number().nullable(),
  gopMargin: z.number().nullable(),
  operationType: OperationType,             // direct | management_contract | lease | franchise
  brandAffiliation: z.string().nullable(),
  operatorContractRemainingYears: z.number().nullable(),
  tourismRegistrationGrade: z.string().nullable(),
  seasonality: z.string().nullable(),
  foreignGuestShare: z.number().nullable(),
  areaPerKey: z.number().nullable(),        // 객실당 연면적 — 벤치마크 35~45㎡
});
```

## 4. 양평동 117 더레드빌딩 — 초안정 수익형

### 4.1 검산

| 항목 | IM 기재 | 검산 | 판정 |
|---|---|---|---|
| 대지 | 157평 | 518.7 ÷ 3.3058 = 156.91 | ✓ |
| 평단가 | 15,923만원 | 250억 ÷ 156.91 = 15,933만원 | ✓ |
| 건폐율 | 58.4% | 302.94 ÷ 518.7 = 58.4% | ✓ |
| 공시지가 | 3,135만원/평 | 9,484,000 × 3.3058 = 3,135만원 | ✓ |
| **용적률** | **398.8%** | 2,490.88 ÷ 518.7 = **480.2%** | **✗** |

### 4.2 지상 연면적 기준 용적률 — 세 번째 확인

```
전체 연면적 기준   2,490.88 ÷ 518.7 = 480.2%
지상층 기준        2,068.60 ÷ 518.7 = 398.8%   ← IM 기재값
지하 추정             422.28㎡ (127.7평)
```

| 물건 | IM 기재 용적률 | 기준 |
|---|---:|---|
| 잠원동 두원빌딩 | 247.0% | 지상 연면적 |
| 당산동 근생빌딩 | 221.8% | 지상 연면적 |
| **양평동 더레드빌딩** | **398.8%** | **지상 연면적** |

**서로 다른 세 중개법인이 독립적으로 같은 관행을 씁니다.** `aboveGroundArea` 슬롯은 선택이 아니라 필수입니다. 온톨로지 v0.3에 이미 반영되어 있습니다.

### 4.3 밸류애드 여지가 없는 물건

| 요소 | 상태 |
|---|---|
| 용적률 여유 | **1.2%p** (준공업 400% 대비 398.8%) — 증축 불가 |
| 건물연령 | 8년 (2018.09 준공) — 리모델링 불필요 |
| 임대료 인상 | 11개 호실 전원 환산보증금 9억 이하 → **5% 상한** |
| 유일한 여지 | **지하 1층 공실** (127.7평 · 공실률 17.0%) |

**아키타입 `R-INC-01 초안정 수익형`**이 맞습니다. 당산동(임대료 정상화형)과 정반대 성격이며, 같은 `income` 자산군 안에서도 IM 편성이 완전히 달라야 합니다.

### 4.4 Cap Rate 4기준

| 기준 | 값 |
|---|---:|
| 중개인형 (실투자금) | **2.46%** |
| 중개인형 (매각가) | 2.41% |
| 표준형 (NOI/매각가) | 2.12% |
| 회계사형 (NOI/총취득원가) | **2.00%** |

격차 **0.46%p**. 당산동(0.89%p)·잠원동(0.86%p)보다 작은데, 보증금 비중이 낮아 실투자금과 매각가 차이가 작기 때문입니다.

지하 1층을 임대하면(평당 5만원 가정) 월 638만원이 추가되어 중개인형 Cap이 **2.46% → 2.77%** 로 개선됩니다.

## 5. 누적 5건 종합

### 5.1 자료등급 — 전 건이 표준→정밀에서 등급 상승

| 물건 | 자산군 | 표준 | 정밀 | 상승폭 |
|---|---|---|---|---:|
| 잠원동 두원빌딩 | development | 72.67 **B** | 81.75 **B** | +9.08 |
| 당산동 근생빌딩 | income | 64.59 **C** | 83.30 **B** | +18.71 |
| 수택동 419-19 | land | 44.70 **C** | 83.25 **B** | +38.55 |
| **에이치에비뉴호텔** | **hospitality** | **4.58 D** | **79.90 B** | **+75.32** |
| 양평동 더레드빌딩 | income | 52.35 **C** | 79.25 **B** | +26.90 |

**5건 중 4건이 표준 모드에서 C 이하입니다.** 실무 IM이 부실해서가 아니라, **우리 등급 체계가 요구하는 항목이 실무 IM에 없기 때문**입니다.

이것이 정밀 모드의 존재 이유이자, 동시에 **경고**이기도 합니다.

> **경고 — 등급 기준이 지나치게 엄격할 수 있습니다.**
> 실무에서 통용되는 IM 5건 중 4건이 C 이하라면, 중개인은 시스템이 자기 자료를 부당하게 낮게 평가한다고 느낍니다. 자산군별 IM 20건이 쌓인 뒤 **등급 컷(A 85 / B 65 / C 40)을 재검토**해야 합니다.

### 5.2 반복 확인된 패턴 3가지

| # | 패턴 | 확인 횟수 |
|---:|---|---:|
| 1 | **용적률 = 지상 연면적 기준** | 3/3 (잠원·당산·양평) |
| 2 | **Cap Rate = 연 임대료 ÷ 실투자금** (`broker_equity`) | 2/2 (당산·양평) |
| 3 | **다필지 물건** | 3/5 (잠원 2필지 · 수택 3필지 · 양평 3필지) |

3번이 특히 중요합니다. **5건 중 3건이 다필지입니다.** v0.2에서 슬롯을 배열화한 결정이 옳았음을 실물로 확인했습니다. 스칼라로 두었다면 60%의 물건을 표현할 수 없었습니다.

### 5.3 실무 IM의 공통 결손

| 결손 항목 | 5건 중 누락 |
|---|---:|
| 최초 계약일 (갱신요구권 기산점) | **5/5** |
| 환산보증금 · 상임법 판정 | **5/5** |
| 취득 부대비용 | **5/5** |
| 운영경비 내역 | **5/5** |
| 계약면적 vs 전용면적 구분 | 4/5 |
| 권리·등기 상세 | 4/5 |
| 제척 면적 | 5/5 |

**최초 계약일이 5건 전부 누락된 것이 가장 큽니다.** 이 값 없이는 T 규칙군(임대차 법적 지위) 전체가 판정 불가이고, 명도 계획·임대료 인상 가능성을 논할 수 없습니다.

> `IM_DATA_PIPELINE.md` §2.5에서 *"`firstContractDate`는 OCR로 나오지 않으므로 정밀 모드 최우선 입력 필드로 배치"* 라고 한 판단이 실물로 검증되었습니다.

## 6. 온톨로지 개선 제안

### 6.1 신규 자산군 `hospitality`

`ASSET_CLASS_EXTENSION_PLAN.md`의 5종에 **여섯 번째**를 추가합니다.

```ts
export const AssetClass = z.enum([
  'income', 'owner_occupied', 'development', 'land', 'logistics',
  'hospitality',   // 🆕 숙박 — 호텔 · 생활형숙박시설 · 게스트하우스
  'mixed',
]);
```

**등급 가중치 프로파일**

| 슬롯군 | hospitality |
|---|---:|
| `hospitality_spec` | **30** |
| building_basic | 15 |
| land_parcel | 15 |
| financial_input | 15 |
| zoning | 10 |
| title_encumbrance | 10 |
| road_access | 5 |
| **합계** | **100** |

`lease_roll`·`market_comp`가 없습니다 — 호텔은 임대차가 없고, 비교사례는 객실당 단가로 별도 관리합니다.

**아키타입 `R-HTL-xx`**

| 코드 | 판정 | 조건 |
|---|---|---|
| R-HTL-01 | 안정 운영형 | OCC ≥ 75% ∧ 운영사 계약 잔여 ≥ 3년 |
| R-HTL-02 | 운영 개선형 | OCC < 70% ∨ ADR < 권역 중앙값 |
| R-HTL-03 | 용도전환 검토형 | 객실당 연면적 ≥ 45㎡ ∧ 주거·오피스텔 전환 가능 용도지역 |
| R-HTL-04 | 단일 브랜드 의존형 | 프랜차이즈 계약 만료 ≤ 2년 |

**제약**

| 코드 | 제약 | 위반 시 |
|---|---|---|
| C30 | ADR · OCC 중 하나라도 없으면 GOP 기반 Cap Rate 산출 불가 | 억제 |
| C31 | 호텔 Cap Rate는 반드시 GOP 기준임을 표기 | 차단 |
| C32 | 계절성 있는 물건은 연평균 OCC와 성수·비수 편차를 병기 | 경고 |
