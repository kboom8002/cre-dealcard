### 2.2 H1이 왜 발생했나 — 근본 원인

원본 PPTX는 **7p 중 5p가 이미지**입니다. 렌트롤·건축물대장·토지이용계획원이 전부 PNG입니다.

```
CREDEAL이 읽은 것    →  p2 텍스트 (표지 요약)
CREDEAL이 못 읽은 것  →  p5 렌트롤 이미지 (업종·계약기간·호실별 금액)
```

**데이터가 없는 자리를 빈칸으로 두는 대신 그럴듯한 값으로 채웠습니다.** 업종을 못 읽으니 "오피스 빌딩이면 이런 임차인이 있겠지"로 생성한 것입니다.

> 이것은 `IM_QUALITY_TRAINING_PLAN.md`의 **L5 가정 확정화** 오류 유형이며, 실무 IM에서 렌트롤이 이미지인 것은 예외가 아니라 **표준**입니다.

### 2.3 H3 — 검증 가능했던 사실

선유도역은 9호선 **급행 미정차역**입니다. 급행 이용 시 김포공항 방면은 염창역, 반대 방향은 당산역에서 환승해야 합니다.

원본은 `선유도역(9호선) 4번출구 도보 1분`이라고만 씁니다. **"급행"은 생성물이 추가했습니다.**

매수인이 지하철 앱 하나만 열어도 확인되는 사실이라, 발견 시 IM 전체의 신뢰가 무너집니다.

### 3.3 basis 오표기

생성물은 이렇게 씁니다.

```

```

**"순수익률"은 NOI 기준을 뜻하는데 실제로는 총 임대료(gross)입니다.** 운영비·공실손실·관리비를 하나도 차감하지 않았습니다.

| 온톨로지 `CapRateBasis` | 이 계산의 실체 |
|---|---|
| 생성물 라벨이 암시하는 것 | `noi_price_deposit` |
| **실제** | **`gross_price`** |

7종 basis 중 가장 후한 값을 골라 가장 엄격한 이름을 붙인 셈입니다.

특히 **"Zero"** 는 위험합니다. 2018년 준공이면 2026년 기준 **8년차**이고, 승강기 정밀안전검사와 **기계식 주차장(22대) 정기검사** 대상입니다. 기계식 주차는 오히려 대표적인 유지비·사고 리스크 항목입니다.

### 7.2 단점을 장점으로 전환

```
용적률 여유 1.2%p: 용적률이 398.8%로 채워져 있어
증축 등의 공사 리스크 없이 순수 임대 운영에만 집중 가능
```

**"증축 여력이 없다"는 사실을 "리스크가 없다"로 바꿔 읽었습니다.** 용적률 소진은 밸류애드 옵션의 부재이며, 매수인에게는 중립이거나 부정 요인입니다.

### 10.2 P0 — 이미지 렌트롤 판독

**실무 IM에서 렌트롤이 이미지인 것은 표준입니다.** 텍스트만 읽는 파이프라인은 구조적으로 환각을 유발합니다.

```
현재:  PPTX → 텍스트 추출 → 슬롯 매핑 → (빈 슬롯을 AI가 추론) → 생성
개선:  PPTX → 텍스트 + 이미지 OCR → 슬롯 매핑 → (빈 슬롯은 빈 채로) → 생성
```

| 판독 대상 | 획득 슬롯 |
|---|---|
| 렌트롤 표 | 호실 · 업종 · 보증금 · 월세 · 관리비 · **계약기간** |
| 건축물대장 | 건축면적 · **건폐율** · 용적률산정용 연면적 · 사용승인일 |
| 토지이용계획원 | **소재지** · 지목 · 면적 · **용도지역** · 공시지가 |

**판독 실패 시 반드시 미입력으로 남깁니다.** 추론으로 채우지 않습니다.

### 10.3 P0 — 환각 차단 게이트 (신규 G17~G21)

| 코드 | 조건 | 동작 |
|:-:|---|---|
| **G17** | 임차인 업종이 원본에 없음 | **업종 추론 금지** · "미상" 또는 원문 그대로 |
| **G18** | 최초 계약일 없이 갱신요구권 산출 시도 | **차단** → "확인 필요" |
| **G19** | 표지 합계 ≠ 렌트롤 합계 | **발행 차단** · 어느 쪽이 정본인지 질의 |
| **G20** | 역세권 등급(급행/일반) 자동 판정 | **역 DB 대조 필수** · 미대조 시 등급 표기 금지 |
| **G21** | 첨부 공부의 소재지 ≠ 본건 소재지 | **발행 차단** |

```ts
// G19 — 합계 불일치는 조용히 한쪽을 고르지 않습니다
export function gateG19(cover: Totals, roll: Totals): GateResult {
  const diff = (['deposit','rent','mgmt'] as const)
    .filter(k => Math.abs(cover[k] - roll[k]) > 0);
  if (diff.length === 0) return { pass: true };
  return {
    pass: false,
    block: true,
    ask: `표지와 렌트롤 합계가 다릅니다 (${diff.join('·')}). 어느 쪽이 정본입니까?`,
    detail: diff.map(k => ({ slot: k, cover: cover[k], roll: roll[k] })),
  };
}
```

### 10.4 P0 — basis 강제 라벨링

**`CapRateBasis` 없이는 수익률을 렌더할 수 없게** 만듭니다.

| 금지 | 강제 |
|---|---|
| `순수익률 (Cap Rate): 2.41%` | `총임대료 기준 수익률: 2.24%` + `gross_price` 배지 |

```ts
export function renderYield(y: YieldValue): string {
  if (!y.basis) throw new Error('C-BASIS 위반 — basis 없는 수익률은 렌더 불가');
  const NET = ['noi_price','noi_price_deposit','noi_equity','noi_total_cost'];
  const label = NET.includes(y.basis) ? '순수익률' : '총임대료 기준 수익률';
  return `${label} ${y.value.toFixed(2)}% (${BASIS_LABEL[y.basis]})`;
}
```

**gross 계열에는 "순수익률"·"Cap Rate" 라벨을 물리적으로 붙일 수 없게 합니다.**
