## 3. 먼저 확인해 주실 3가지

**문서로 판단한 것이라 코드 확인이 필요합니다.** 이번 개선의 정정 7건 중 3건이 "코드를 안 보고 문서로 판단"해서 생긴 오류였습니다.

| # | 확인 | 방법 | 영향 |
|:-:|---|---|---|
| **1** | **퓨샷이 실제로 Golden을 조회하는가** | `buildIMFewShotBlock()` 호출 로그 | **조회 안 하면 D16 폐순환 판단이 무효** |
| **2** | **호텔 Opex 35% ↔ GOP 마진 35%** | `sed -n '132p;421p' src/lib/financials.ts` | **운영형 GOP가 약 2배일 가능성** |
| **3** | **comps 상한 300억의 근거** | `price-prediction.ts` 주변 주석·이력 | **주력 상단 B4가 통째로 막혀 있음** |

### 3.1 1번을 가장 먼저 해주십시오

D16 전체가 **"Golden이 퓨샷으로 재주입된다"** 는 전제 위에 있습니다. 실제로 조회하지 않는다면 재구축 우선순위가 내려갑니다.

## 4. 검증 스크립트 — 지금 바로 돌려보실 수 있습니다

```bash
cd 05_data
python3 build_fixtures.py          # 픽스처 6개 재생성
python3 fixtures/selfcheck.py      # 58항 자기검산
python3 build_golden_source.py     # 원천 5건 + 파생값 14항 검산
python3 golden/verify_golden.py    # 골든 10항 × 8건
```

**패키지 상태에서 4개 전부 통과 확인했습니다.** 생성 스크립트는 자기 디렉터리 기준으로 경로를 잡으므로 `05_data`에서 실행하십시오. 엑셀 생성기(`06_scripts/`)는 실행 위치에 파일을 만듭니다.

**전부 종료 코드 0이어야 합니다.** 하나라도 실패하면 그 데이터를 쓰지 마십시오.

| 스크립트 | 검사 | 항목 |
|---|---|--:|
| `selfcheck.py` | 픽스처 내부 정합 (합계·수익률·LTV·ROE) | **58** |
| `build_golden_source.py` | ㎡↔평·평당가·공시지가 배수·상승률 | **14** |
| `verify_golden.py` | 섹션7·금지어·이모지·마스킹·결손·출처 | **10 × 8** |
