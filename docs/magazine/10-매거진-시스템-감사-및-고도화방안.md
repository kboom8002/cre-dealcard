> 에디터 L1338에서 `/magazine/{slug}` 링크를 제공 중이나 **실제 페이지가 없어 404**입니다. 활성 버그입니다.

- **신규 파일**: `src/app/(public)/magazine/[brokerId]/page.tsx`
- **내용**: `magazine_editions` WHERE `status='published'` → 카드 그리드 (제목, 날짜, 시장온도 뱃지, 조회수)
- **효과**: SEO 유입, 브로커 브랜딩, 과거 에디션 열람 경로 확보

#### 개선 2: 완독 시간 & 매크로 Pulse 카드

- **내용**:
  - `⏱ {n}분 완독` 배지 (콘텐츠 길이 기반 자동 산출)

- **데이터 소스**: `cre_pulses` 테이블 + 외부 매크로 지표

### 🟡 High Impact (2~4주, 신규 섹션/기능)

#### 개선 4: 인터랙티브 1-Click 투표(Poll) 섹션

> SOTA 뉴스레터의 핵심 참여 요소. 매수 의향 파악에도 직결

- **에디터**: `publish` 탭에 투표 질문 + 선택지 3개 설정 UI
- **뷰어**: 1-Click 투표 → 실시간 응답 비율(%) 프로그레스 바
- **DB**: `magazine_poll_responses` (subscriber_id, edition_id, choice, created_at)
- **CRM 연동**: 투표 응답 → `interest_tags` 자동 반영 → 매수 성향 프로파일링
- **예시**: *"현재 강남 꼬마빌딩 평당 1.2억, 적정하다고 보십니까?"*

#### 개선 5: 세무/법률 클리닉 섹션

> 5대 페르소나 중 4곳이 "절세"를 최우선 정보 요구로 지목

- **신규 섹션 ID**: `tax_legal_clinic`
- **뷰어**: "💰 이번 주 세무·법률 클리닉" 카드 — 1문1답 포맷
- **AI 생성**: 주간 이슈 기반 세무 Q&A 자동 생성 (`callLLM`)
- **데이터**: 국세청 예규, 조세심판원, 부동산 세법 변경사항

#### 개선 6: 에디터 섹션 순서 커스터마이저

- **에디터 UI**: `publish` 탭에 드래그&드롭 섹션 순서 설정기
- **DB**: `magazine_editions.section_order` JSONB 컬럼 추가
- **뷰어**: `section_order` 우선 → 없으면 `?target=` 기본 순서 fallback
- **효과**: "이번 주는 시장 데이터가 핵심" → 브로커가 최상단 배치

### 🔵 Strategic (1~2개월, 차별화 기능)

#### 개선 7: 수지분석 인터랙티브 계산기 위젯

> 고소득 전문직·법인 대표의 최대 Pain Point 직격

- **기능**: 매입가/대출비율/금리/보증금·월세 슬라이더 → 실시간 Cap Rate, Cash-on-Cash Return, 월 순현금흐름 산출
- **공실 스트레스 테스트**: 1층 공실 시 Cap Rate 변동 시각화
- **CRM**: 계산기 사용 이벤트 → `buyerTemperature` 점수 가산

#### 개선 8: 추천 레퍼럴 시스템 & 성장 루프

> Beehiiv/Morning Brew의 핵심 성장 엔진. 현재 전무

- **구조**:
  - 구독자별 고유 추천 링크 (`credeal.net/r/{subscriber_id}`)
  - 마일스톤 리워드 프로그레스 바:
    - 1명 초대: 비공개 시장 분석 리포트
    - 3명: 엑셀 수지분석기 다운로드
    - 5명: 비공개 딜 시트 열람권
    - 10명: 브로커 1:1 전화 자문 30분
- **DB**: `magazine_referrals` (referrer_id, referred_id, milestone_reached)
- **효과**: 페이드 광고 없이 유기적 구독자 풀 확대
