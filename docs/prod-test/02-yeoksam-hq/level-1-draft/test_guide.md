## 1. 테스트 목적
- 사옥형(`owner_occupied`) 포스처 자산의 약식 매물 브리핑 입력 시, 시스템이 임대 수익률 산출을 강제하지 않고 **사옥 특화 메트릭(대지/연면적 단가, 신축 경과년수, 자주식 주차)**을 정확히 추출하는지 검증합니다.
- 임대료 정보 부재 시에도 정상 딜카드가 생성되고 명도 확약 필요성 안내가 출력되는지 점검합니다.

## 2. 웹 UI 테스트 절차
1. **딜카드 생성**:
   - `/broker/deal-card/new`에서 `memo.txt` 붙여넣기.
2. **공개 범위**:
   - `보안형 블라인드 딜카드 (blind)` 선택 후 생성.
3. **결과 확인**:
   - 강남구 역삼동, 업무시설(사옥), 매매가 120억, 연면적 237.72평 추출 확인.

## 3. 검증 체크리스트 (Expected Output)
- [ ] **사옥형 자동 인식**: 포스처 `owner_occupied`, 용도 `office`
- [ ] **물리 지표 추출**:

  - 대지면적: 86.15평 (토지 평당 1억 3,929만원)
  - 연면적: 237.72평 (연면적 평당 5,048만원)
  - 준공: 2023년 (신축 3년차)
- [ ] **사옥 단독 명칭 표기(간판 설치권)** 등 실무 용어 준수 확인 (Rule 2)
