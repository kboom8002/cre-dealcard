# 01. 딜카드 생성 파이프라인 — 프로덕션 E2E 테스트
> 문서 버전: v1.0 | 최종 수정: 2026-08-10
> 대상 환경: Production (https://cre-dealcard.vercel.app)
> 테스터 요구사항: 브로커 계정 (Pro 티어 이상)

## 테스트 목적 및 범위
본 문서는 CREDEAL 플랫폼의 핵심 기능인 AI 기반 딜카드 생성 파이프라인을 검증하기 위한 E2E 테스트 절차를 정의합니다. 메모 입력부터 최종 산출물 도출까지의 각 단계가 50대 CRE 중개인, 40대 대기업 건물자산관리자, 60대 전문 매수자 등 타겟 사용자 층의 눈높이와 전문성을 만족하는지, 비즈니스 로직과 가드레일이 정상적으로 동작하는지 확인합니다.

## A1. 매각 딜카드 3단계 체인

### 1. 사전 조건
- Pro 티어 이상 브로커 계정으로 로그인되어 있을 것
- AI 모델: Sol 또는 Terra 선택 가능 상태

### 2. 테스트 절차
1. 딜카드 생성 메뉴로 이동 (`/deal-card/create`)
2. 입력창에 **Fixture 1 (당산동 근생빌딩)** 메모 붙여넣기 후 '생성' 버튼 클릭
3. 네트워크 탭(혹은 화면)에서 3단계 체인(MemoParser → MiniTruth → BlindTeaser) 동작 확인
4. PII 마스킹(정확한 주소 노출 방지) 처리 확인
5. 동일한 절차로 **Fixture 2 (성수동 오피스빌딩)** 테스트 반복

### 3. API 호출 예시
```bash
curl -X POST https://cre-dealcard.vercel.app/api/broker/deal-card/from-memo \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <SUPABASE_TOKEN>" \
  -d '{"memo": "당산동5가 근생빌딩 대지 120평..."}'
```

### 4. 기대 결과
- 주소가 마스킹됨 (예: "당산동5가" -> "영등포구 당산동")
- 25개 법적 안전 언어 가이드라인이 준수된 문구 도출 (과장 광고 금지 등)
- 건물 정보, 재무 정보(캡레이트 추정치 등), 투자 포인트가 명확히 분리되어 표시됨

### 5. 검증 체크리스트
| 레벨 | 항목 | 배점 | 판정 기준 |
|:---|:---|:---:|:---|
| L1 | 생성 버튼 클릭 시 3단계 로딩 UI 표시 여부 | 5 | 로딩 상태 정상 노출 (Pass/Fail) |
| L2 | 대지면적, 연면적, 수익률 데이터 추출 정확도 | 10 | Memo 데이터와 100% 일치 |
| L3 | PII 마스킹 및 25종 가드레일 통과 여부 | 15 | 상세 주소 미노출, 금지어 미포함 |
| L4 | 중개인/매수자 대상 어조 및 가독성 (BlindTeaser) | 10 | 전문적 어조 유지 |
