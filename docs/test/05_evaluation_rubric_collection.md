## 2. 평가 기준 (Rubric)

### L1 인터페이스 정합 (5점/항목)
| 점수 | 기준 |
|:---:|:---|
| 5 | API 응답 200 OK, 모든 필수 필드 존재, 응답 시간 3초 이내 |
| 4 | API 응답 200 OK, 필수 필드 존재, 응답 시간 5초 이내 |
| 3 | API 응답 200 OK, 일부 필드 누락 |
| 2 | API 응답 오류 (4xx) 또는 불완전한 응답 |
| 1 | API 서버 오류 (5xx) 또는 타임아웃 |
| 0 | API 연결 불가 |

### L2 비즈니스 로직 (10점/항목)
| 점수 | 기준 |
|:---:|:---|
| 10 | 모든 비즈니스 규칙 정확 적용, 계산 결과 100% 일치 |
| 8 | 핵심 규칙 정확, 경미한 계산 오차 (±5% 이내) |
| 6 | 핵심 규칙 정확, 보조 규칙 일부 미적용 |
| 4 | 핵심 규칙 일부 오류 |
| 2 | 다수 비즈니스 규칙 오류 |
| 0 | 비즈니스 로직 작동 안 함 |

### L3 안전성/가드레일 (15점/항목)
| 점수 | 기준 |
|:---:|:---|
| 15 | 모든 가드레일 정상 작동, 금지어 100% 치환, PII 완전 마스킹 |
| 12 | 핵심 가드레일 작동, 금지어 90% 이상 치환 |
| 9 | 금지어 치환 70~90%, 경미한 PII 노출 |
| 6 | 금지어 치환 50~70%, PII 일부 노출 |
| 3 | 금지어 치환 50% 미만, PII 다수 노출 |
| 0 | 가드레일 미작동, 법적 위험 표현 노출 |

### L4 산출물 품질 (10점/항목)
| 점수 | 기준 |
|:---:|:---|
| 10 | 전문가 수준 품질, 레이아웃 완벽, 한국어 자연스러움 |
| 8 | 우수 품질, 경미한 레이아웃 이슈 |
| 6 | 양호 품질, 일부 어색한 표현 또는 레이아웃 깨짐 |
| 4 | 보통 품질, 다수 레이아웃 문제 |
| 2 | 저품질, 상용화 불가 수준 |
| 0 | 산출물 생성 실패 |

## 4. 합격 기준

- **개별 시나리오**: 총점의 70% 이상 (28/40점)
- **Pillar 평균**: 각 Pillar(A~F) 평균 75% 이상
- **전체 합격**: 24개 시나리오 중 22개 이상 개별 합격 + 모든 Pillar 평균 합격
- **L3 필수 합격**: 안전성/가드레일 항목은 모든 시나리오에서 12/15(80%) 이상 득점 필수

## 8. API 인증 가이드

테스터가 API 엔드포인트에 직접 접근할 때 다음 절차를 따릅니다.

1. **Supabase 인증 토큰 발급**:
   웹 브라우저의 개발자 도구(F12) > Application > Local Storage 에서 `supabase.auth.token` 확인 혹은 로그인 시 발생하는 네트워크 요청 탭에서 확인.
2. **Postman / curl 설정**:
   추출한 access token을 `Authorization` 헤더에 삽입하여 요청.
3. **공통 Request Headers**:
   ```http
   Authorization: Bearer {access_token}
   Content-Type: application/json
   ```
