# 07. 인간 테스터용 화면 기반 E2E 테스트 — 포스처별 풀 파이프라인

> 문서 버전: v1.0 | 최종 수정: 2026-08-10  
> 대상 환경: Production (https://cre-dealcard.vercel.app)  
> 대상 조직: 제이에스부동산중개(주)  
> 테스트 방식: **브라우저/모바일 UI 직접 조작** (API 호출 없음)  
> 필요 장비: iPhone 15 또는 Galaxy S24, PC Chrome 브라우저, MS PowerPoint 또는 Google Slides

---

## 1. 테스트 목적

이 문서는 **인간 테스터가 실제 화면(입력 폼, 바텀시트, xlsx 업로드, 버튼 클릭)을 직접 조작**하여 5개 투자 포스처별 풀 파이프라인을 검증하는 테스트 스크립트입니다.

> ⚠️ 본 문서는 API curl 호출이 아닌, **실제 사용자가 보는 화면 그대로** 테스트합니다.

### UI 입력 채널 4종

| # | 입력 채널 | 화면 위치 | 설명 |
|:---:|:---|:---|:---|
| 📝 | **메모 텍스트 입력** | `/broker/deal-card/new` 텍스트영역 | 카톡 메모 붙여넣기 |
| 📸 | **사진 첨부** | `/broker/deal-card/new` 파일 업로드 | 건물 외관/내부 사진 |
| 📊 | **xlsx 렌트롤 업로드** | `/broker/buildings/{id}/studio/lease` 파일 임포트 | 엑셀 렌트롤 |
| 📋 | **바텀시트 보충 데이터** | `/broker/deal-card/{id}` IM 데이터 바텀시트 | 추가 재무/물류 정보 |

**복사할 메모 텍스트** (테스터가 복사해서 붙여넣을 원문):

```

공실 1층만 비어있고 나머지 만실 월 수입 3200만원
1층 카페 보증금 3000만 월 180만, 2층 학원 보증금 5000만 월 250만
3-4층 사무실 보증금 각 3000만 월 200만, 5-6층 주거 보증금 각 2000만 월 150만
매도 호가 80억 협의 가능 급매
건물주 해외이민 계획으로 급매
```

| 단계 | 화면 | 조작 | 📸 캡처 |
