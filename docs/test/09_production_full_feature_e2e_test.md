## 사전 준비

### 테스트 계정

| 역할 | 이메일 | 비밀번호 | 용도 |
|:---|:---|:---|:---|
| 기존 중개사 | `broker-senior@credeal-test.com` | `Test!2026Sr` | 대부분의 인증된 기능 테스트 |
| 신규 가입용 | `newuser-{날짜}@credeal-test.com` | (가입 시 생성) | A, B 파이프라인 전용 |
| 공개 사용자 | (미로그인) | — | 공개 페이지, 구독, 게이트 요청 |
| 서클 동료 | `broker-circle@credeal-test.com` | `Test!2026Cr` | J 서클 테스트 상대방 |

### 결과 기록 규칙

각 테스트 항목에 대해 아래 중 하나를 기록합니다:
- ✅ **PASS** — 기대 결과와 일치
- ❌ **FAIL** — 기대 결과와 불일치 (스크린샷 첨부)
- ⚠️ **WARN** — 동작하지만 UX 개선 필요
- ⏭️ **SKIP** — 환경 제약으로 생략 (사유 기록)

## curl API 보조 검증 스크립트

> 아래 curl 명령은 UI 테스트를 보완하는 API 직접 검증용입니다.  
> `TOKEN`은 로그인 후 브라우저 DevTools → Application → Cookies → `sb-*-auth-token`에서 추출합니다.

```bash
# ─── 환경 설정 ───
BASE="https://cre-dealcard.vercel.app"
TOKEN="<로그인_토큰>"

# ─── A. 인증 검증 ───
# 미인증 접근 차단 (401 예상)
curl -s -o /dev/null -w "%{http_code}" $BASE/api/broker/profile
# → 401

curl -s -o /dev/null -w "%{http_code}" $BASE/api/broker/memo -X POST \
  -H "Content-Type: application/json" -d '{}'
# → 401

# ─── C. 프로필 조회 ───
curl -s $BASE/api/broker/profile \
  -H "Authorization: Bearer $TOKEN" | jq '.display_name, .slug'

# ─── D. 메모 저장 ───
curl -s -X POST $BASE/api/broker/memo/save \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"rawText":"강남역 오피스빌딩 매각 165억 연면적 450평"}'

# ─── E. 모닝 인텔리전스 ───
curl -s "$BASE/api/broker/morning-intelligence?region=gbd" \
  -H "Authorization: Bearer $TOKEN" | jq '.briefing[0:2]'

# ─── F. 매거진 구독자 목록 ───
curl -s $BASE/api/broker/magazine/subscribers \
  -H "Authorization: Bearer $TOKEN" | jq '.subscribers | length'

# ─── G. 공유링크 생성 ───
curl -s -X POST $BASE/api/broker/share-link \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"buildingId":"<BUILDING_ID>","type":"im_lite"}'

# ─── H. 고객 목록 ───
curl -s "$BASE/api/broker/clients?type=buyer&grade=vip" \
  -H "Authorization: Bearer $TOKEN" | jq '.clients | length'

# ─── I. 임대카드 목록 ───
curl -s $BASE/api/broker/lease-card \
  -H "Authorization: Bearer $TOKEN" | jq '.[0:3]'

# ─── J. 서클 목록 ───
curl -s $BASE/api/broker/circles \
  -H "Authorization: Bearer $TOKEN" | jq '.circles'

# ─── K. 스케줄 내보내기 ───
curl -s $BASE/api/broker/schedule/export \
  -H "Authorization: Bearer $TOKEN" -o schedule.ics

# ─── L. 게이트 요청 ───
curl -s -X POST $BASE/api/gate-requests \
  -H "Content-Type: application/json" \
  -d '{"buildingId":"<BUILDING_ID>","level":"G1"}'

# ─── M. 공개 마켓 리포트 ───
curl -s $BASE/api/public/market-report/gangnam | jq '.summaryStats'

# ─── 크론 인증 검증 (401 예상) ───
for ep in consistency-check data-hygiene hold-expiry morning-briefing weekly-magazine; do
  echo -n "$ep: "
  curl -s -o /dev/null -w "%{http_code}" $BASE/api/cron/$ep
  echo
done
```
