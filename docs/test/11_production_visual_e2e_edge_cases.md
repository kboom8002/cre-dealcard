**육안 검증 체크리스트:**

| # | 검증 항목 | 기대 결과 | 결과 |

> **검증 목표**: 비용비교 표가 없는 최소 사옥 메모에서 포스처가 정확히 `owner_occupied`로 추론되고, A08 자가비교 슬라이드가 적절히 처리되는지 확인합니다.

**복붙용 메모:**

````
사옥 이전 목적 매입 검토 건

판교 알파돔타워 15층~17층 3개층 전층
매매가 350억
전용 3,200평
2019년 준공 판교 테크노밸리 핵심 입지

현재 당사 강남 사옥 임대료 연 42억 지출 중
판교 이전 시 직원 통근 셔틀 운영 예정
IT 기업 특화 인프라 — 서버룸, UPS 완비
구내식당 2개소, 피트니스, 어린이집 운영

리스크: 판교 오피스 공급 증가, 통근 거리 이슈
````

**육안 검증 체크리스트:**

| # | 검증 항목 | 기대 결과 | 결과 |
|:---:|:---|:---|:---:|
| E5-1 | 포스처 추론 | `사옥형` ("사옥 이전 목적 매입" 키워드) | ☐ |
| E5-2 | 딜카드 생성 | 최소 정보로 성공 **또는** 품질 부족 안내 | ☐ |
| E5-3 | 임대차 섹션 | **미생성** (사옥형 suppress) | ☐ |
| E5-4 | A08 자가비교 | 비용비교 표 없으므로 → suppress 또는 텍스트 기반 렌더링 | ☐ |
| E5-5 | 빈 슬라이드 없음 | 데이터 없는 슬라이드가 빈 채로 남지 않음 | ☐ |
| E5-6 | 허위 데이터 없음 | "서초대로 25m", "대지 142.5평" 등 미표시 | ☐ |
| E5-7 | 슬라이드 수 | Basic: 7~10장 | ☐ |

### EC-O-2: 포스처 모호 신호 (수익형 + 사옥형 혼합)

> [!WARNING]
> **검증 목표**: 임대차 정보와 사옥 매입 의도가 동시에 존재할 때, 포스처 추론이 하나로 확정되고 해당 포스처에 맞는 슬라이드가 생성되는지 확인합니다.

**복붙용 메모:**

````
[매물정보]
물건: 서울시 강남구 삼성동 159-8 삼성동타워
매매가: 420억원
연면적: 8,500㎡ (약 2,571평)
층수: 지하2층 ~ 지상12층
준공: 2016년
용도지역: 일반상업지역

[임대차현황]
- 1-2F 당사 직영 (현재 사옥 용도 사용 중)
- 3F 한화손해보험: 보증금 3억, 월세 1,400만, 만기 2028.06
- 4F SK텔레콤: 보증금 4억, 월세 1,800만, 만기 2029.03
- 5-8F 당사 직영 (R&D 센터 + 임직원 교육장)
- 9F 네이버클라우드: 보증금 2억, 월세 1,100만, 만기 2028.12
- 10-12F 당사 직영 (경영지원본부)

[사옥 활용 현황]
현재 1-2층, 5-8층, 10-12층 총 9개층을 자사 사옥으로 사용 중
3-4층, 9층은 외부 임대 운영으로 관리비 상쇄
자가사용률: 75% (9개층/12개층)

[비용 분석]
- 외부 임대수입: 월 4,300만 (연 5.16억)
- 자가사용 환산 임대료 절감: 연 28억 (시세 기준)
- 순 자가사용 비용 절감 효과: 연 약 33억

[투자포인트]
1. 🏢 삼성동 코엑스 인접 프라임 사옥 — 기업 대표성 확보
2. 🎯 자가사용 75% + 임대수입 25% 하이브리드 구조
3. 💰 외부 임대로 관리비 100% 상쇄 + α 수익
4. 🚇 삼성역 도보 5분, 코엑스몰 직결

[리스크체크]
1. 건물: 2016년 준공 양호, A등급
2. 혼합 용도 리스크: 사옥+임대 혼합 시 관리 복잡성
3. 임차인: 3개 외부 임차인 모두 대기업 — 안정적
4. 통근: 삼성역 5분 — 전 직원 접근성 우수
5. 자가사용 확장: 외부 임차 해지 시 전층 사옥 전환 가능
````

**육안 검증 체크리스트:**

| # | 검증 항목 | 기대 결과 | 결과 |
|:---:|:---|:---|:---:|
| E6-1 | 포스처 추론 | `사옥형` 또는 `수익형` — **하나로 확정** (모호하더라도) | ☐ |
| E6-2 | 추론된 포스처 일관성 | IM 섹션 구성이 추론된 포스처에 맞게 생성됨 | ☐ |
| E6-3 | 사옥 추론 시 | 사용계획(A04) + 자가비교(A08) 슬라이드 존재, 렌트롤 suppress | ☐ |
| E6-4 | 수익 추론 시 | 렌트롤(A03) + 수익분석(A05) 슬라이드 존재 | ☐ |
| E6-5 | 자가사용률 표시 | "75%" 또는 "9개층" 정보가 IM에 반영 | ☐ |
| E6-6 | 하이브리드 구조 반영 | 임대+사옥 혼합 분석이 어딘가에 표현됨 | ☐ |
| E6-7 | NaN/이모지/페르소나 | 전 슬라이드 무결 | ☐ |

### EC-O-3: 숫자 오염 + 특수 표기 메모

> [!WARNING]
> **검증 목표**: 비표준 숫자 표기("약 100억대", "3~4천평", "미정"), 특수문자(%, ㎡, ~, +), 비정상 가격 표기가 NaN을 유발하지 않는지 확인합니다.

**복붙용 메모:**

````
[매물정보]
물건: 경기도 성남시 분당구 정자동 불정로 6 NAVER 그린팩토리 인근 사옥 후보지
매매가: 약 200억~250억대 (협의 가능)
대지면적: 미확인 (약 400평+)
연면적: 약 3천~4천평 추정
층수: 지하2 ~ 지상10 (추정)
준공: 2020년경
용도지역: 제2종일반주거지역 (추정)

사옥 이전 용도 검토 중
현재 본사 판교 임대료 연 35억+ 지출
신축급 건물 선호, 전용률 85% 이상 희망
주차 최소 200대 이상 필요
구내식당 설치 가능 여부 확인 필요

향후 IPO 대비 본사 이미지 제고 목적
직원 수 약 500~600명 수용 필요
회의실 20개+ 설치 가능한 평면 구성 선호

리스크: 정자동 오피스 수급, 용도변경 가능 여부, 주차 대수 불확실
````

**육안 검증 체크리스트:**

| # | 검증 항목 | 기대 결과 | 결과 |
|:---:|:---|:---|:---:|
| E7-1 | 매매가 파싱 | "200억~250억대" → "200억" ~ "250억" 범위 또는 "200억대" — NaN 아님 | ☐ |
| E7-2 | 면적 파싱 | "3천~4천평" → "3,000평" ~ "4,000평" 또는 "약 3,500평" — NaN 아님 | ☐ |
| E7-3 | "미확인" 처리 | "대지면적: 미확인" → 빈 칸 또는 "-" 표시 (NaN 아님) | ☐ |
| E7-4 | "추정" 표기 | "(추정)" 접미사가 적절히 처리됨 | ☐ |
| E7-5 | "+" 표기 | "400평+", "35억+", "200대 이상" → 정상 파싱 | ☐ |
| E7-6 | 포스처 추론 | `사옥형` ("사옥 이전 용도") | ☐ |
| E7-7 | NaN/undefined | **전 슬라이드에 NaN 절대 없음** (이 케이스의 핵심 검증) | ☐ |
| E7-8 | 허위 데이터 없음 | 면적/가격 미확인 부분에 가짜 수치 미표시 | ☐ |
