# CREDEAL E2E 테스트 스크립트: 01. 잠원동 두원빌딩 (개발형)

## 1. 테스트 개요
* **물건 정보**: 서초구 잠원동 26-14, 26-16번지 근생빌딩 (잠원동 두원빌딩)
* **포스처 (Posture)**: 개발형 (Development)
* **매매가**: 2,422,680만원 (242억)
* **대지 / 연면적**: 186평(616.1㎡) / 615평(2,032.6㎡)
* **기대 등급**: 최소(C), 표준(B하한), 충분(B상위)
* **핵심 검증**: 명도 조건(매도인 책임) 처리, 용적률 이중 기준 병기, 개발형 포스처에 따른 섹션 구성 및 수익률 문항 억제

## 2. 3단계 입력 세트별 시나리오

### 🔴 1단계: 최소 (Minimum) 입력
* **포커스**: 필수 항목만 입력 시의 시스템 방어 로직 확인 및 포스처 미선택 시 기본 동작 확인

**딜카드 메모 (복사-붙여넣기용)**
```text
서초구 잠원동 근생빌딩 242억
```

**Basic IM 바텀시트 입력 필드값**
* 주소검색: ✅ (잠원동 26-14 → PNU 자동 연동)
* 매매가: 2,422,680만 (242억)
* 월임대료: 0
* 공실률: 0%
* 포스처: 미선택 (None)

**예상 결과 (Expected Grade)**
* Readiness 점수: 42~48점 (C하한)
* 생성 가능 IM: Basic 생성 가능, Pro 차단
* 주요 현상: 포스처 미선택으로 인해 개발형 물건임에도 연 순수익률 (Cap Rate) 및 렌트롤 문항이 기본 생성됨

---

### 🟡 2단계: 표준 (Standard) 입력
* **포커스**: 명도 조건 및 개발계획 입력 시의 점수 가산 로직 확인

**딜카드 메모 (복사-붙여넣기용)**
```text
서초구 잠원동 26-14, 26-16번지 근생빌딩 매물.
지하1층~지상6층, 대지 186평 연면적 615평.
매매가 242억. 1990년 준공이라 노후하고, 매도인 명도 조건이다.
현재 임차인 있지만 잔금 전 전부 비워주는 조건.
신축 부지로 보고 있다. 강남대로 바로 이면, 신사역 4분.
```

**Basic IM 바텀시트 입력 필드값**
* 주소검색: ✅ (잠원동 26-14, 26-16)
* 매매가: 2,422,680만 (242억)
* 월임대료: 0
* 보증금: 0
* 공실률: 100% (명도 후 기준)
* 포스처: Development (개발형)
* 사진: 3장 업로드
* 브로커 코멘트: ✅ 입력 완료
* 개발계획: 목표 용도(근생+업무), 예상 연면적(465평)
* 명도조건: ✅ 매도인 책임, 11호실, 6개월 소요

**예상 결과 (Expected Grade)**
* Readiness 점수: 65~72점 (B하한)
* 생성 가능 IM: 개발형 Basic IM
* 주요 현상: `lease_roll` 가중치 ×0.4 감쇠 적용, `development_plan` +20점 가산 적용, 렌트롤 문항 억제 및 신축 규모 문항 활성화

### 🟢 3단계: 충분 (Sufficient) 입력
* **포커스**: 다수 필지 PNU 처리, 상세 개발계획, Pro IM 바텀시트 입력 시의 최고 등급 달성 확인

**딜카드 메모 (복사-붙여넣기용)**
```text
서초구 잠원동 26-14, 26-16번지 2필지 근생빌딩.
대지 186평(616.1㎡). 용적률 지상 연면적 기준 247.0%, 공부상 325.6%.
지하1층~지상6층, 승강기 1대. 1990년 준공.
매매가 242억 (평당 1.3억).
현재 임차인 11명 있으나 매도인 책임 명도 조건(명도비 5억, 6개월 소요).
명도 후 철거 조건으로 매각.
개발계획: B1~6F 근생+의원+업무시설, 예상 연면적 465평, 예상 공사비 평당 750만.
서울시 임시 용적률 인센티브 상향 가능성 있음 (인허가 4개월 예상).
```

**Basic IM 바텀시트 입력 필드값**
* 주소검색: ✅ (PNU 2필지 모두 연동)
* 매매가: 2,422,680만 (242억)
* 월임대료: 0
* 보증금: 0
* 공실률: 100%
* 포스처: Development (개발형)
* 사진: 7장 업로드
* 브로커 코멘트: ✅ 입력 완료
* 층별임대현황: ✅ 11호실 모두 명도 대상으로 체크
* 개발계획: ✅ 근생+의원+업무, 465평, 공사비 750만/평
* 명도조건: ✅ 매도책임, 11호실, 명도비용 5억, 6개월
* 인허가: ✅ 용적률 상향 예상, 4개월 소요

**Pro IM 바텀시트 입력 필드값**
* 관리비: 320만
* 대출: 미대출 (0원)
* 부수수입: 간판 연 240만
* 권리분석: 근저당 채권최고액 96억, 실잔액 80억
* 사진: 추가 업로드 (총 12장)

**예상 결과 (Expected Grade)**
* Readiness 점수: 78~84점 (B상위)
* 생성 가능 IM: Pro IM 생성 가능 (DCF 잠김, A등급 미달)
* 주요 현상: 사업수지 문항 활성화, 지상 연면적 기준(247.0%)과 공부상(325.6%) 용적률 2개 기준 병기 처리 확인

## 3. 검증 체크리스트

### 메모 파서 검증 (슬롯 추출 정확성)
- [ ] `askingPrice` 242억 추출 정확도
- [ ] `address` 잠원동 26-14 (및 26-16) 추출 및 PNU 연동
- [ ] `buildYear` 1990년 추출 정확도
- [ ] `floors` B1~6F 추출 정확도

### 데이터 등급 검증 (Readiness)
- [ ] 최소 입력: 42~48점 (C하한) 도달 여부
- [ ] 표준 입력: 65~72점 (B하한) 도달 및 `lease_roll` 감쇠, `development_plan` 가산 확인
- [ ] 충분 입력: 78~84점 (B상위) 도달 및 DCF 잠김(A등급 미달) 확인

### IM 섹션 내용 검증
- [ ] 개발형 포스처 선택 시 `property_overview`, `site_analysis`, `development_feasibility` 등 적절한 섹션으로 구성되는가?
- [ ] (최소 입력 시) 포스처 미선택으로 인해 연 순수익률 (Cap Rate) 등 렌트롤 관련 문항이 생성되는가?
- [ ] (충분 입력 시) 사업수지 문항이 올바르게 활성화 및 작성되는가?

### PPTX 렌더링 검증
- [ ] **A01 Cover**: 제목 및 기본 정보 레이아웃 확인
- [ ] **A02 Stat Grid**: 요약 통계 숫자 (242억, 186평 등) 정확성
- [ ] **A03 Rent Roll**: 명도 후 공실 100% 처리로 인해 관련 필드가 "N/A" 또는 비워져 표현되는가?
- [ ] **A04/A05 Investment Points**: 개발형 투자 포인트(명도 조건, 신축 부지 등) 텍스트 오버플로 방지 및 레이아웃 유지
- [ ] **A07 Location Analysis**: 위치분석(강남대로 이면, 신사역 4분) 지도/텍스트 정상 렌더링 여부

### 카톡 공유 문구 검증
- [ ] 포스처별 클로징 문구 확인: "토지 대장 및 신축 수지 검토 자료가 필요하시면 전달드리겠습니다." 문구가 포함되는가?

## 4. 엣지 케이스 확인 포인트
- [ ] **FAR (용적률) 이중 기준 병기**: 지상 연면적 기준 247.0% 와 공부상 325.6% 가 모두 누락 없이 병기되어 노출되는지 확인
- [ ] **명도 조건 처리**: 매도인 책임 명도 조건과 임차인 11명의 명도 대상 여부가 렌트롤 및 개발 수지에 정확히 반영되는지 확인
- [ ] **Rent=0 시의 개발형 포스처 처리**: 개발형 포스처에서 렌트롤(월임대료=0)로 인해 발생할 수 있는 연 순수익률 (Cap Rate) 등 계산 시 Infinity/NaN 수익률 오류 방지 여부 확인

## 5. 기대되는 실패/차단 시나리오
- [ ] **알려진 버그 방어**: 소스 시스템에서 2층 월세가 40,000원으로 잘못 입력된 셀 오류(floor total mismatch)가 감지되어 경고/차단되는지 확인
- [ ] **등급 미달 차단**: 최소 입력 세트(C등급) 상태에서 Pro IM 생성을 시도할 경우 정상적으로 차단 및 안내 메시지가 표시되는지 확인
