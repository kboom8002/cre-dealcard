# E2E Test Script: Property 2 - 당산동5가 근생빌딩 (Income)

## 1. 테스트 개요
- **물건 정보**: 서울특별시 영등포구 당산동5가 11-47 근생빌딩
- **포스처 (Posture)**: 임대수익형 (`income`)
- **자산 유형**: 근린생활시설 (근생빌딩)
- **핵심 특징**: 의원+약국 안정 조합, 11년 미인상, 임대료 정상화 시 47% 갭, 공동담보 및 구분등기, 연면적 오기 존재
- **기대 등급**:
  - 최소 (Minimum): **C** (48~55점)
  - 표준 (Standard): **B하한** (66~72점)
  - 충분 (Sufficient): **B상위** (80~84점)

---

## 2. 3단계 (최소/표준/충분) 입력 세트

### 🔴 최소 (Minimum)
*최소한의 정보만 주어졌을 때 시스템이 기본 값을 추론하고 통과시키는지 테스트.*

**딜카드 메모 (복사-붙여넣기)**
```text
영등포 당산동 근생빌딩 115억 임대중
```

**Basic IM 바텀시트 입력 필드값**
- 주소: `주소검색 ✅`
- 매매가: `1,150,000만` (115억)
- 월임대료 (총액): `1,946만`
- 공실률: `0%`
- 포스처: `미선택` (시스템 기본값 `income`으로 추론 예상)

**기대 결과**
- **Expected Grade**: C (48~55)
- **생성 산출물**: Basic IM
- **특이사항**: 연 순수익률 (Cap Rate) "검증 중" 표시 (보증금 누락으로 정확한 계산 불가)
- **Key Check**: 포스처 미선택 상태이나, '임대중' 키워드를 통해 경고 없이 `income`으로 정상 통과되는지 확인.

### 🟡 표준 (Standard)
*일반적인 브로커 메모가 주어졌을 때의 정상 파싱 및 베이직 IM 생성 테스트.*

**딜카드 메모 (복사-붙여넣기)**
```text
영등포구 당산동5가 11-47 근생빌딩.
당산역 2·9호선 도보 5분. 배후에 아파트 단지가 밀집해 있다.
지하1층~지상5층, 대지 153평 연면적 436평. 2002년 준공.
매매가 115억. 현재 월세 총 1,946만원, 보증금 2.9억.
1F 고은약국, 2F 로뎀나무내과 등 의원+약국 조합으로 임차 구성이 안정적이다.
공실은 없는데 임대료가 시세 대비 낮다. 11년간 인상이 없었다.
```

**Basic IM 바텀시트 입력 필드값**
- 주소: `주소검색 ✅`
- 매매가: `1,150,000만`
- 보증금 (총액): `29,000만`
- 월임대료 (총액): `1,946만`
- 공실률: `0%`
- 포스처: `income` 선택
- 첨부자료: `사진 3장`
- 브로커 코멘트: `입력 ✅`

**기대 결과**
- **Expected Grade**: B하한 (66~72)
- **생성 산출물**: Basic IM (Pro 진입 가능 상태)
- **Key Check**: 메모상의 연면적(436평)과 공적장부 연동 시 발생할 수 있는 불일치(건축물대장상 1,141.15㎡ 오기)가 `C19` 경고(면적 불일치)로 잡히는지 확인. 임대료 상승 여력(11년 미인상) 관련 문항 생성.

### 🟢 충분 (Sufficient)
*상세 임대조건, 법률적 제약, 담보 등이 모두 포함된 상태에서의 Pro IM 생성 테스트.*

**딜카드 메모 (복사-붙여넣기)**
```text
영등포구 당산동5가 11-47 근생빌딩 임대수익형.
당산역 2·9호선 도보 5분, 배후에 아파트 단지 밀집, 준공업지역 제도개선 수혜지.
지하1층~지상5층, 대지 153평(506.8㎡) 연면적 436평(1,441.15㎡). (건축물대장상 1,141.15㎡(307.9평) 오기 존재)
용적률 221.8% (법정 284.4%). 2002년 준공.
매매가 115억 (토지 평당 75백만). 현재 월세 총 1,946만원, 보증금 2.9억. 공실 없음.
1F 고은약국, 1F/2F/5F 로뎀나무내과, 3F 헬스장, 4F 국제와인(401호).
의원+약국 조합으로 임차 구성 매우 안정적, 11년간 임대료 인상 없어 시세 대비 낮음 (임대료 정상화 시 47% 상승 여력).
단, 401호 국제와인은 갱신요구권 7년 남아 5% 상한 적용 (시세 3,060천원 불가, 2,730천원 적용).
형제 2인 구분등기 (소유자 2인), 공동담보 근저당 존재.
```

**Basic IM 바텀시트 입력 필드값**
- 주소: `주소검색 ✅`
- 매매가: `1,150,000만`
- 보증금 (총액): `29,000만`
- 월임대료 (총액): `1,946만`
- 공실률: `0%`
- 포스처: `income` 선택
- 첨부자료: `사진 6장`
- 브로커 코멘트: `입력 ✅`
- 층별임대현황: `입력 ✅` (총 8호실, 자가사용 2 포함, 최초계약일 기입)
- 구분소유: `입력 ✅` (소유자 2인, 토지지분 기입)

**Pro IM 바텀시트 입력 필드값**
- 관리비 (총액): `180만`
- 대출확정: `540,000만` + `300,000만` (공동담보 2그룹)
- 부수수입: `연 360만` (옥상 통신안테나)
- 권리분석: `확인 ✅` (채권최고액 그룹별, 소유자 2인 매각 동의)
- 첨부자료: `사진 9장`

**기대 결과**
- **Expected Grade**: B상위 (80~84)
- **생성 산출물**: Pro IM
- **Key Check**: 401호 임대료 정상화 시 시세(3,060천원)가 아닌 법정 5% 상한액(2,730천원)으로 재무 모델링이 적용되는지 확인. `C32` 경고(공동담보) 발생 확인.

- [ ] `totalDepositKrw`: 2.9억 (290,000,000) 추출
- [ ] `monthlyRentKrw`: 1,946만 (19,460,000) 추출
- [ ] `buildYear`: 2002 추출
- [ ] `posture`: income (또는 임대수익형) 추출

### 데이터 등급 검증
- [ ] 🔴 최소: Readiness 점수 산출 및 등급 판정 (C) 확인
- [ ] 🟡 표준: Readiness 점수 상승 및 등급 판정 (B하한) 확인
- [ ] 🟢 충분: Readiness 점수 및 등급 판정 (B상위) 확인
- [ ] 연 순수익률 (Cap Rate) 2.03% 산출 확인: `(1,946만 × 12) / 115억`

### IM 섹션 내용 검증 (`income` 포스처)
- [ ] `property_overview`: 기본 물건 개요 및 건축 정보
- [ ] `location_access`: 당산역 접근성 및 배후 아파트 단지 정보
- [ ] `lease_status`: 의원+약국 등 현재 임차인 구성 (층별)
- [ ] `income_analysis`: 현재 수익률(2.03%) 및 임대료 정상화 시(47% 상승 예상) 수익률 시뮬레이션
- [ ] `risk_check`: 건축물대장상 연면적 오기 건, 공동담보 사항 포함 여부
- [ ] `investment_thesis`: 우량 임차인(병의원) 장기 안정성, 준공업지역 제도개선 수혜
- [ ] `next_steps`: 투자 검토를 위한 다음 단계 안내

### PPTX 렌더링 검증
- [ ] `A01`: 표지 정상 렌더링
- [ ] `A02`: 스탯 그리드 (매매가, 연 순수익률 2.03%, 대출, NOI 포함) 정상 렌더링
- [ ] `A03`: 렌트롤 (8호실 상세) 표 레이아웃 및 텍스트 오버플로 없음
- [ ] `A04` / `A05`: 투자 포인트 슬라이드 (임대료 갭 47%, 의원/약국 안정성) 구성
- [ ] `A07`: 위치 및 입지 슬라이드 (당산역, 배후 단지 표시) 렌더링

### 카톡 공유 문구 검증

## 4. 엣지 케이스 확인 포인트
- [ ] **연면적 오기 처리**: 실면적(1,441.15㎡) vs 공적장부(1,141.15㎡, 약 300㎡ 차이)가 시스템에서 단순 면적 불일치가 아닌 위반/오기로 정상 감지되는지.
- [ ] **법정 상한액 적용**: 401호 갱신요구권 잔존에 따른 임대료 정상화 시뮬레이션 시, 단순 시세가 아닌 상한(5%)이 적용된 금액(2,730천원)이 재무 분석에 강제되는지.
- [ ] **공동담보 합산 방지**: 대출확정 입력 시 공동담보로 인한 채권최고액이 중복 합산되지 않고 1개의 그룹으로 묶여 리스크 체크(C32)로 표출되는지.
- [ ] **구분소유 다수**: 소유자가 형제 2인으로 설정되었을 때, 매각 동의 및 권리분석 단계에서 2인 모두의 정보/동의 상태가 요구되는지.

## 5. 기대되는 실패/차단 시나리오
- [ ] **월세 누락 시**: 포스처가 `income`임에도 월임대료가 `0`이거나 미입력 시, 재무 분석 자체가 불가능하므로 시스템이 Basic IM 생성을 차단하거나 강력한 에러 발생 (수익률 산출 불가).
- [ ] **수익률 오계산**: 401호 인상분을 5% 상한이 아닌 시세(47% 인상 등)로 임의 적용하여 미래 예상 연 순수익률이 과다 계상되는 경우.
- [ ] **권리분석 미동의**: 구분소유자 2인 중 1인만 매각 동의 상태로 Pro IM 진입 시도 시, 권리 관계 불확실(C33 등)로 Pro 등급 생성이 거절되거나 경고 발생.
