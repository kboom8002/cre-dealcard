# E2E Test Script: 수택동 419-19 외 2필지 나대지 (개발형)

## 1. 테스트 개요
- **소재지**: 경기도 구리시 수택동 419-19, 419-12, 419-96 (3필지)
- **포스처**: 개발형 (development)
- **자산유형**: 나대지
- **매매가**: 890,000만원 (89억)
- **대지면적**: 196.98평(651.2㎡), 필지별: 419-19 412.5㎡, 419-12 158.3㎡, 419-96 80.4㎡
- **건물현황**: 없음 (나대지)
- **용도지역**: 도시지역 상업지역
- **핵심 포인트**: 구리역 380m 도보 5분, 경의중앙선+8호선별내선 역세권, 삼면접도(12m/6m/4m)
- **주의 사항**: 419-12 도시계획도로 저촉 9.8㎡, 용적률 1,260% 주장은 지구단위계획 전제 필요

## 2. 3단계 입력 세트 (최소 / 표준 / 충분)

### 🔴 최소 입력 (Minimum)
- **딜카드 메모**:
```text
구리 수택동 나대지 89억
```
- **Basic IM 바텀시트 입력 필드값**:
  - 주소검색: ✅ 완료
  - 매매가: 890,000만
  - 월임대료: 0
  - 공실률: N/A
  - 포스처: 미선택 (income 기본값으로 폴백)
- **기대 등급**: D~C경계 (36~44)
- **Key Check**: 나대지 자산과 income 포스처의 조합이 차단되는지, 사용자에게 포스처 선택을 강제하거나 경고를 노출하는지 확인.

### 🟡 표준 입력 (Standard)
- **딜카드 메모**:
```text
경기도 구리시 수택동 419-19, 419-12, 419-96번지 나대지.
3필지 합쳐 651.2㎡(196.98평). 건물 없이 바로 개발 가능하다.
구리역 380m 도보 5분. 경의중앙선에 8호선 별내선이 들어와 이용객 하루 3만.
도로가 12m·6m·4m 세 면 접한다. 삼면 접도라 건축 자유도가 높다.
도시지역 상업지역. 매매가 89억, 평당 4,500만원.
저층 상가·중층 오피스텔·상층 업무 복합개발을 추천한다.
```
- **Basic IM 바텀시트 입력 필드값**:
  - 주소검색: ✅ 완료 (PNU 3필지 인식)
  - 매매가: 890,000만
  - 월임대료: 0
  - 공실률: N/A
  - 포스처: development (개발형)
  - 사진: 3장 첨부
  - 브로커 코멘트: ✅ 작성
  - 개발계획: 목표용도 복합, 목표규모 미확정
  - 인허가: ❌ 미기재
- **기대 등급**: C상위 (58~64)
- **Key Check**: `building_basic` 슬롯이 `not_applicable` 처리되어 나대지 특성상 관련 점수가 다른 슬롯으로 재배분되는지 확인. 건물 슬라이드가 억제되는지 확인.

### 🟢 충분 입력 (Comprehensive)
- **딜카드 메모**:
```text
경기도 구리시 수택동 419-19, 419-12, 419-96 (총 3필지) 나대지 매각.
대지면적 총 651.2㎡(196.98평). (419-19: 412.5㎡, 419-12: 158.3㎡, 419-96: 80.4㎡)

구리역 380m(도보 5분), 경의중앙선과 8호선 별내선 환승역으로 하루 역 이용객 3만명 풍부한 상권.
도로는 12m, 6m, 4m 삼면 접도로 건축 및 진출입이 매우 유리함.
용도지역: 도시지역 상업지역. 
주의: 매도자는 용적률 최대 1,260%를 주장하나, 이는 지구단위계획 수립(약 18개월 소요 및 기부채납 조건)이 전제되어야 함.
개발규모 연면적 2,500평 이상 시 교통영향평가 대상(약 6개월 추가 소요)에 해당.
공사비는 평당 750만 예상되며, 복합용도(상가/오피스텔/오피스) 시나리오(800%, 1000%, 1260%, 1500%) 검토 가능.
[인근 실거래 비교]
1. 인근 142평, 61억 (평당 4,296만)
2. 인근 188평, 88억 (평당 4,681만)
3. 인근 221평, 95억 (평당 4,299만)
본 물건은 평당 4,518만으로 적정 시세임.
```
- **Basic IM 바텀시트 입력 필드값**:
  - 주소검색: ✅ 완료 (PNU 3필지, 필지별 면적 확인)
  - 매매가: 890,000만
  - 월임대료: 0
  - 공실률: N/A
  - 포스처: development
  - 사진: 5장 첨부
  - 브로커 코멘트: ✅ 작성
  - 개발계획: ✅ 작성 (복합, 시나리오 4종 800/1000/1260/1500%, 공사비 750만/평)
  - 인허가: ✅ 작성 (지구단위 18개월, 교통영향평가 6개월, 기부채납 미확정)
- **Pro IM 바텀시트 입력 필드값**:
  - 관리비: 0
  - 대출: 미대출
  - 부수수입: ❌ 없음
  - 권리분석: ✅ 작성 (제척 9.8㎡ 확인 중, 근저당 없음)
  - 사진: 8장 첨부
  - 시세비교: ✅ 작성 (인근 실거래 3건 매핑)
- **기대 등급**: B (72~80)
- **Key Check**: 최고 용적률 1,260%가 ◇가정 배지 및 전제 조건(지구단위계획 등)과 함께 표기되는지(C22 규칙), 토지비 부담 지표 및 인허가 로드맵이 정상적으로 나타나는지 확인.

## 3. 검증 체크리스트

- [ ] `address` '수택동 419-19' 등 3필지가 모두 PNU로 매핑 및 인식되는가?
- [ ] `landArea` 196.98평(651.2㎡)이 추출되는가?

### 데이터 등급 검증
- [ ] **최소 입력**: 36~44점 사이로 산출되며, 나대지×income 조합에서 차단/에러 처리가 발생하는가?
- [ ] **표준 입력**: 58~64점 사이로 산출되며, `building_basic`이 `not_applicable`로 재배분되는가?
- [ ] **충분 입력**: 72~80점 사이로 산출되는가?

### IM 섹션 내용 검증
- [ ] 나대지 특수 처리로 건물 관련 슬롯 및 섹션이 비활성화되는가?
- [ ] `site_analysis` 섹션에서 삼면접도(12m/6m/4m) 및 역세권 정보가 누락 없이 노출되는가?

- [ ] C22 규칙에 따라 1,260% 용적률이 ◇가정 배지와 함께 노출되는가?

### PPTX 렌더링 검증

- [ ] **A02 토지 스펙**: 3필지 정보와 도시계획도로 저촉(9.8㎡), 유효대지면적이 올바르게 표시되는가?
- [ ] **A03 렌트롤**: 건물/임대차 슬라이드가 완전히 생략되었는가?
- [ ] **A04/A05 개발포인트**: 복합용도 시나리오, 공사비 추정, 인근 실거래 비교(평당 4,518만 vs 4,296만/4,681만/4,299만)가 잘 표기되는가? 텍스트 오버플로우가 없는가?

### 카톡 공유 문구 검증
- [ ] 클로징 문구가 개발형(development) 포스처에 맞게 생성되었는가?
  - 예: "구리역 역세권 삼면접도 나대지로, 복합개발 시 높은 사업성이 기대되는 물건입니다."

## 4. 엣지 케이스 확인 포인트
- [ ] **나대지 × Income 포스처 충돌**: 물리적 건물이 없는 나대지에서 임대수익형(Income) 포스처를 선택했을 때 강제 차단 및 올바른 유도 흐름이 발생하는가?
- [ ] **조건부 주장 지표 표기**: 매도자의 1,260% 용적률 주장이 확정된 팩트처럼 보이지 않고, 기부채납/지구단위계획 수립 등의 조건과 함께 렌더링되는가?
- [ ] **대지 제척 면적 처리**: 공부상 면적(651.2㎡)과 유효대지면적(641.4㎡)의 차이가 명확히 구분되어 토지단가(평당가) 산정에 혼란을 주지 않는가?

## 5. 기대되는 실패/차단 시나리오
- 나대지 상태에서 포스처 미선택 시 기본값인 'income'으로 분류되어 파이프라인에서 건물 정보 누락으로 인한 치명적 오류 또는 유효성 검사 차단(에러 코드: `ERR_INVALID_POSTURE_ASSET_MATCH`) 발생 예상.
- 평당가 계산 시 총 면적이 아닌 유효대지면적 기준으로 계산될 경우, 매매가 대비 평당가 4,518만원과 오차가 발생할 수 있으므로 이에 대한 계산 로직 예외 처리 확인 필요.
