# CREDEAL E2E 테스트 스크립트: 양평동4가 117 더레드빌딩 (임대수익형)

## 1. 테스트 개요
- **물건 정보**: 영등포구 양평동4가 117, 134, 125-2 (3필지) / 더레드빌딩
- **자산유형**: 사무용빌딩
- **포스처**: 임대수익형 (income)
- **기대 등급**: C ~ B상위 (입력 수준에 따라 차등)
- **핵심 컨셉**: 선유도역 9호선 도보1분 초역세권, 2018년 신축, 밸류애드 여지 없음(상임법+용적률+신축), 초안정 수익형
- **재무 정보 요약**:
  - 매매가: 2,500,000만원 (250억)
  - 보증금: 5억 3,500만원
  - 월세: 5,017만원
  - 관리비: 648만원
  - 예상 연 순수익률 (Cap Rate): 현재 2.41% → 지하 1층 공실 리스업 시 2.71%

## 2. 3단계(최소/표준/충분) 입력 세트

### 🔴 최소 입력 세트 (Minimum)
**목표**: 필수값만 입력하여 파서 동작 및 기본 상태 생성 확인
**딜카드 메모**:
```text
영등포 양평동 사무용빌딩 250억
```
**Basic IM 바텀시트 입력 필드값**:
- 주소검색: 완료✅
- 매매가: 2,500,000만
- 월임대료: 5,017만
- 공실률: ~20% (버튼 선택)
- 포스처: 미선택
**기대 결과**:
- Readiness 점수: C (46~52점)
- 생성 문서: Basic IM 생성 완료
- 연 순수익률 (Cap Rate): "검증 중" (데이터 부족)
- 주요 확인: 공실률 버튼값(~20%)과 실제(17.0%)의 차이

### 🟡 표준 입력 세트 (Standard)
**목표**: 핵심 정보가 포함된 메모 파싱, 포스처 지정 후 Basic IM 생성 및 Pro IM 진입 조건 달성 확인
**딜카드 메모**:
```text
영등포구 양평동4가 117, 134, 125-2번지. 3필지 합쳐 518.7㎡(157평).
선유도역 9호선 4번출구에서 도보 1분. 대로변 초역세권이다.
2018년 9월 준공. 신축이라 내외관이 수려하고 손볼 데가 없다.
지하1층~지상10층, 업무시설. 승강기 1대, 주차 옥외 1 + 기계식 22.
매매가 250억. 보증금 5억 3,500만, 월 임대료 5,017만, 관리비 648만.
현재 지하1층만 공실이다. 준공업지역, 공시지가 ㎡당 948만원.
```
**Basic IM 바텀시트 입력 필드값**:
- 주소검색: 완료✅ (PNU 3필지)
- 매매가: 2,500,000만
- 월임대료: 5,017만
- 보증금: 53,500만
- 공실률: 17%
- 포스처: income (임대수익형)
- 사진: 3장 첨부
- 브로커 코멘트: 완료✅
**기대 결과**:
- Readiness 점수: B하한 (65~70점)
- 생성 문서: Basic IM 생성 완료 및 Pro IM 진입 가능 상태
- 주요 확인: 용적률 지상 398.8% / 전체 480.2% 병기

### 🟢 충분 입력 세트 (Sufficient)
**목표**: 모든 상세 데이터 입력 후 고도화된 Pro IM 및 최적화된 안정형 서사 확인
**딜카드 메모**:
```text
영등포구 양평동4가 117, 134, 125-2번지 (3필지). 대지 518.7㎡(157평).
연면적 전체 2,490.88㎡, 지상만 2,068.60㎡. 용적률 지상 398.8% / 전체 480.2%로 준공업지역 상한(400%) 대비 여유 1.2%p에 불과함.
선유도역 9호선 4번출구 도보 1분. 2018년 9월 준공 신축으로 밸류애드 불필요.
매매가 250억, 보증금 5억 3,500만, 월세 5,017만.
지하1층(127.7평)만 공실로 공실률 17.0%.
임차인은 디자인스튜디오, IT스타트업, 회계법인 등 11개 호실에 업종 분산됨.
상임법 전면 적용 대상(환산보증금 9억 이하 전원 해당)이며, 갱신요구권 2~7년 잔여.
지하공실 리스업 시 월 임대료 638만(12.7%) 증가 예상.
```
**Basic IM 바텀시트 입력 필드값**:
- 주소검색: 완료✅
- 매매가: 2,500,000만
- 월임대료: 5,017만
- 보증금: 53,500만
- 공실률: 17.0%
- 포스처: income (임대수익형)
- 사진: 6장 첨부
- 브로커 코멘트: 완료✅
- 층별임대현황: 완료✅ (11호실, 최초계약일 포함)

**Pro IM 바텀시트 입력 필드값**:
- 관리비: 648만
- 대출상태: 미확인
- 부수수입: 완료✅ (기계식주차 연 1,200만)
- 권리분석: 완료✅ (등기확인)
- 사진: 10장 첨부
- 층별임대현황: 완료✅ (완전 상세 입력)

**기대 결과**:
- Readiness 점수: B상위 (78~83점)
- 생성 문서: Pro IM 생성 완료
- 초안정형 서사 출력 (밸류애드 여지 없음을 강점으로 승화)
- 주요 확인: DCF 잠김(A 미달), 안정성 문항이 인상 여력 문항을 대체하는지 확인

## 3. 검증 체크리스트

### 메모 파서 검증
- [ ] `askingPrice` 슬롯에 250억 추출 여부 확인
- [ ] `monthlyRent` 슬롯에 5,017만 추출 여부 확인
- [ ] `totalDeposit` 슬롯에 5.35억 추출 여부 확인
- [ ] `buildYear` 슬롯에 2018년 추출 여부 확인
- [ ] `vacancyPct` 슬롯에 17% 추출 여부 확인

### 데이터 등급 검증
- [ ] 최소 세트: Readiness 점수 46~52점(C등급) 판정 확인
- [ ] 표준 세트: Readiness 점수 65~70점(B등급 하한) 판정 확인
- [ ] 충분 세트: Readiness 점수 78~83점(B등급 상위) 판정 확인

### IM 섹션 내용 검증
- [ ] 임대수익형(income) 표준 7개 섹션 정상 구성 확인
- [ ] 연 순수익률 (Cap Rate) 현재 2.41% 및 리스업 후 2.71% 계산값 노출 여부
- [ ] 용적률 지상 398.8% / 전체 480.2% 병기 표시 확인
- [ ] 안정성(초안정형) 문항이 인상 여력 문항을 대체하여 투자포인트로 강조되었는지 확인

### PPTX 렌더링 검증
- [ ] 총 A01 ~ A15 슬라이드 생성 확인
- [ ] A03 (렌트롤): 11개 호실 업종 분산 데이터의 레이아웃 및 텍스트 오버플로 없음 확인
- [ ] A04/A05: 안정성 중심의 투자포인트 배치 및 텍스트 짤림 없음 확인

### 카톡 공유 문구 검증
- [ ] 포스처(income)에 맞는 클로징 문구(초안정 수익형 등) 생성 확인

## 4. 엣지 케이스 확인 포인트
- [ ] 상임법 5% 상한 적용 여부 및 환산보증금 분석 결과 정확성
- [ ] 용적률 여유 1.2%p: 증축 등 밸류애드 불가 논리 변환 확인
- [ ] 공실률: 대략적 구간(~20%) 입력과 17.0% 정밀값 입력의 차이 반영 및 충돌 여부
- [ ] 초안정형 서사: '밸류애드 불가'를 '무결점 자산' 강점으로 치환 여부

- [ ] 데이터 부족 상태에서 '연 순수익률(Cap Rate) 검증 중' 출력 및 섣부른 계산 차단 여부
