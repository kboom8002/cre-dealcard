# CREDEAL E2E Test Script: Property 5 - 에이치에비뉴호텔 이대점

## 1. 테스트 개요
- **물건 정보**: 서울시 서대문구 대현동 비즈니스호텔
- **자산 유형**: 호텔
- **포스처 (Posture)**: 운영형 (operating)
- **매매가**: 3,000,000만원 (300억 원)
- **기대 등급**: 
  - 최소: D (18~30) ⛔ IM 생성 차단
  - 표준: C 상위 (56~62) ✅ Basic 생성
  - 충분: B 상위 (76~82) ✅ Pro 생성

## 2. 입력 세트별 테스트 시나리오

### 🔴 1단계: 최소 입력 (Minimum) - 차단 기대
**딜카드 메모 (복사-붙여넣기용):**
```text
이대역 호텔 94실 300억
```
**Basic IM 바텀시트 입력 필드값:**
- 주소 검색: ❌ (지번 미상 → PNU 매핑 불가)
- 매매가: 3,000,000만
- 월임대료: N/A
- 공실률: N/A
- 포스처: 미선택

**기대 결과:**
- 데이터 등급: D (18~30)
- ⛔ IM 생성 차단 (부족 항목 안내 모달 노출)
- 핵심 확인 포인트: 차단 시 "무엇을 몇 분 채우면 되는지" 명확히 안내되는지 확인.

---

### 🟡 2단계: 표준 입력 (Standard) - Basic IM 기대
**딜카드 메모 (복사-붙여넣기용):**
```text
서대문구 대현동 비즈니스호텔 매물. 이대역 도보 3분, 신촌 대학가.
객실 94실. 대지 486.2㎡(147평), 연면적 3,842.6㎡(1,162평).
지하2층~지상12층, 2016년 4월 준공. 일반상업지역.
매각가 300억. 객실당 3.19억이다.
운영은 위탁이고 에이치 에비뉴 브랜드 국내 체인이다.
```
**Basic IM 바텀시트 입력 필드값:**
- 주소 검색: ✅ (PNU 연결 정상)
- 매매가: 3,000,000만
- 월임대료: N/A (lease_roll × 0.0)
- 공실률: N/A
- 포스처: operating
- 사진: 3장 첨부
- 브로커 코멘트: ✅ 입력됨
- 운영사양 (GOP 등): 객실수 94 입력. ADR / OCC 미입력 (→ 기본값 12만 / 65% 적용)

**기대 결과:**
- 데이터 등급: C 상위 (56~62)
- ✅ Basic IM 생성
- 핵심 확인 포인트: 렌트롤 문항 완전 억제 여부, ADR·OCC 미입력 시 시장 기본값(12만 / 65% / GOP 25%)이 '◇가정'으로 표기되는지 확인.

---

### 🟢 3단계: 충분 입력 (Sufficient) - Pro IM 기대
**딜카드 메모 (복사-붙여넣기용):**
```text
서대문구 대현동 비즈니스호텔 매물. 이대역 도보 3분, 신촌 대학가.
객실 94실 (스탠다드더블 46, 트윈 28, 디럭스 14, 스위트 6). 대지 486.2㎡(147평), 연면적 3,842.6㎡(1,162평).
지하2층~지상12층, 2016년 4월 준공. 일반상업지역, 용적률 654.1%.
매각가 300억. 객실당 3.19억.
운영은 위탁운영, 에이치에비뉴 브랜드. 계약 2029년 만료 (잔여 4년).
ADR: 95,000원, OCC: 78%, RevPAR: 74,100원.
계절성: 대학가 3~5월, 9~11월 성수, 1~2월 비수기 60% 이하.
외국인 비중: 45% (중국/일본/동남아).
연 총매출: 28.22억, GOP 마진 38% → 10.72억, GOP 기준 연 순수익률 (Cap Rate) 3.57%.
주의: 2016년 준공으로 객실 리뉴얼 주기(7~10년) 도래.
```
**Basic & Pro IM 바텀시트 입력 필드값:**
- 주소 검색: ✅ (PNU 연결 정상)
- 매매가: 3,000,000만
- 월임대료: N/A
- 공실률: N/A
- 포스처: operating
- 사진: 6장 첨부
- 브로커 코멘트: ✅ 입력됨
- 운영사양: ✅ (객실수 94, ADR 95,000, OCC 78%, GOP 38%, 위탁운영 입력)
- **Pro 추가 입력:**
  - 관리비: N/A (운영비 포함)
  - 대출 상태: 미확인
  - 부수 수입: ✅ (부대매출 11% - 조식/라운지)
  - 숙박팩 전체: ✅ (객실타입 4종, 계절성, 외국인 45%, 운영사 잔여 3-4년)
  - 권리 분석: ✅
  - 사진: 11장 첨부

**기대 결과:**
- 데이터 등급: B 상위 (76~82)
- ✅ Pro IM 생성
- 핵심 확인 포인트: C31 - GOP 기준 연 순수익률 (Cap Rate) (3.57%) 명시 시 일반 임대차 NOI 연 순수익률 (Cap Rate)과 병렬 배치되지 않는지 확인.

## 3. 검증 체크리스트

### 메모 파서 검증
- [ ] `askingPrice` 슬롯이 300억으로 정상 추출되는가?
- [ ] `roomCount` 슬롯이 94로 정상 추출되는가?
- [ ] `buildYear` 슬롯이 2016으로 정상 추출되는가?
- [ ] `address` 슬롯에 '대현동'이 포함되어 정상 추출되는가?

### 데이터 등급 검증
- [ ] 단계별 Readiness 점수가 각각의 기대 등급(D, C상위, B상위) 구간에 맞게 판정되는가?

### IM 섹션 내용 검증
- [ ] 렌트롤 섹션(A03)이 **완전 억제(생략)**되는가? (lease_roll 가중치 0 적용 확인)
- [ ] 운영 지표(ADR, OCC, RevPAR, GOP) 중심의 문항이 정상 노출되는가?
- [ ] 재무 계산식 정상 적용 확인:
  - RevPAR: 95,000 × 0.78 = 74,100원
  - GOP: 28.22억 × 0.38 = 10.72억
  - GOP 연 순수익률 (Cap Rate): 10.72억 / 300억 = 3.57%
- [ ] GOP 기준 연 순수익률 (Cap Rate) (3.57%)가 NOI 기준 연 순수익률 (Cap Rate)과 명확히 구분되어 나란히 배치되지 않는가?
- [ ] ADR/OCC 미입력 시(2단계) 시장 기본값(12만 / 65% / 25%)이 '◇가정' 마커와 함께 표기되는가?

### PPTX 렌더링 검증
- [ ] 슬라이드 구성: A01 커버, A02 호텔 스테이터스 그리드, A04/A05 운영 포인트, A07 위치(이대역).
- [ ] A03 렌트롤 슬라이드가 PPTX에서 완전히 생략되었는가?
- [ ] 레이아웃 및 텍스트 오버플로 없이 데이터가 깔끔하게 렌더링되는가?

### 카톡 공유 문구 검증
- [ ] 포스처(operating)에 맞는 클로징 문구가 생성되는가?
  - 기대 문구: "운영 지표(KPI/GOP) 및 위탁운영 조건 자료가 필요하시면 말씀해 주세요."

## 4. 엣지 케이스 확인 포인트
- [ ] 주소 미입력 시 PNU 맵핑 불가로 IM 생성이 차단되는지?
- [ ] `lease_roll` 가중치가 × 0.0 으로 반영되는지?
- [ ] GOP 기준 연 순수익률 (Cap Rate)과 NOI 연 순수익률 (Cap Rate)의 표기가 분리되는지?
- [ ] ADR/OCC 미입력 시 기본값이 '가정(◇)'으로 잘 들어가는지?
- [ ] 운영사 위탁 계약 만료(2029년) 내용이 반영되는지?
- [ ] **객실 리뉴얼**: 2016년 준공이므로 7~10년 주기 리뉴얼 비용 발생 가능성에 대한 경고 또는 언급이 적절히 들어가는지?
- [ ] **외국인 비중 및 계절성**: 외국인 45%로 인한 환율 리스크 및 1~2월 비수기(OCC 60% 이하) 계절성 이슈가 리스크 요인으로 잘 다루어지는지?

## 5. 기대되는 실패/차단 시나리오
- 주소 검색 시 지번 정보 누락으로 PNU 추출 실패 (1단계 최소 입력에서 차단 발생).
- ADR/OCC 입력 없이 포스처를 operating으로 선택했으나, 관련 기본 가정치를 받아들이지 않아 신뢰도(Readiness) 부족으로 생성 불가.
- 렌트롤 정보를 강제 입력하려고 시도할 때, 시스템상 입력 필드가 숨겨지거나, 입력해도 가중치/렌더링에서 배제(×0.0)되는지 확인(UI 상에서 혼란 방지 필요).
