# E2E 테스트 — 주택임대차(T-R) 분기 검증

> 실매물 5건이 전부 상가 임대차라 **T-R 경로가 한 번도 실행되지 않는** 공백을 메웁니다.
> 갱신요구권 **10년(상가) vs 1회·2년(주택)** 분기가 정확히 갈리는지 검증합니다.

|---|---|
| **대상 규칙** | `T-C-03` · `T-R-03` · `T-R-02` · `G13` · `G15` · `C20` |
| **테스트 케이스** | 물건 1건 × 3단계 + 경계 케이스 8종 |
| **기준일** | 2026-08-04 |
| **최종 수정** | 2026-08-04 |

## 0. 🔴 이 문서를 만들다 규칙 오류를 발견했습니다

테스트 케이스를 설계하면서 **제가 작성한 `CATALOG_RULES.md`의 T-R 산식이 틀렸다는 것**을 확인했습니다.

### 0.1 원안 (틀림)

```ts
// CATALOG_RULES.md §3.4 — C20 갱신요구권
if (renewalExercised) return 0;
return Math.max(0, 4 - elapsed);      // ← 경과 7년이면 0 반환
```

### 0.2 무엇이 틀렸나

**갱신요구권은 "총 4년 상한"이 아니라 "1회 행사 시 +2년"입니다.**

묵시적 갱신은 갱신요구권을 소진하지 않으므로, **7년째 거주 중인 임차인도 갱신권이 그대로 살아 있을 수 있습니다.** 이때 원안대로 계산하면 `max(0, 4−7) = 0` → "즉시 명도 가능"으로 나옵니다.

| 사례 | 원안 산출 | 실제 | 오차 |
|---|---|---|---|
| 204호 · 최초 2019-08 · 묵시적 갱신 3회 · **미행사** | 잔여 0년 | 만료(2027-07) + 2년 = **2029-07** | **2년 9개월** |

**매수인이 명도를 2년 9개월 빠르게 봅니다.** 개발형 딜이라면 사업 일정 전체가 무너집니다.

### 0.3 올바른 모델

```ts
export function residentialVacatePoint(u: LeaseUnit): VacateVerdict {
  if (u.renewalExercised === undefined)
    return { state: 'unknown', reason: '갱신요구권 행사 이력 확인 필요' };   // G15
  return u.renewalExercised
    ? { state: 'determined', at: u.currentExpiry }                      // 소진 → 만료 시
    : { state: 'determined', at: addMonths(u.currentExpiry, 24) };      // 미행사 → +2년
}
```

| 필요 입력 | 상가(T-C) | 주택(T-R) |
|---|:-:|:-:|
| 최초 계약일 | **필수** (10년 기산) | **불필요** |
| 현 계약 만료일 | 참고 | **필수** |
| 갱신요구권 행사 이력 | 불필요 | **필수** |

> **주택은 최초 계약일로 갱신권을 계산할 수 없습니다.** 상가와 정반대입니다. 이 차이가 T-R을 별도 규칙군으로 분리한 진짜 이유입니다.

## 1. 법령 사실 확정

### 1.1 확인된 현행 규정

| 항목 | 상가 (상임법) | 주택 (주임법) |
|---|---|---|
| 갱신요구권 | 전체 10년 범위 내 **수차례** | **1회 한정 · 갱신 후 2년** |
| 기산 | 최초 계약일 | 현 계약 만료일 |
| 대항 요건 | 인도 + **사업자등록** | 인도 + **주민등록(전입신고)** |
| 환산보증금 | 있음 (서울 9억 등) | **개념 없음** |
| 소액임차인 | 별도 기준 | **서울 보증금 1.65억 이하 → 최대 5,500만 최우선변제** |
| 권리금 보호 | **있음** | **없음** |
| 임대인 직접거주 갱신거절 | **불가** | **가능** |
| 차임 인상률 상한 | 5% (환산보증금 이하) | 5% (갱신 시) |

### 1.2 ⚠️ "3+3년 개정" — 확인 결과 **시행되지 않았습니다**

검색 중 *"2026년 3월 시행 개정 주택임대차보호법 — 3+3년 제도"* 라는 내용이 나왔습니다. **사실이면 이 테스트의 근간이 바뀝니다.**

추적 결과:

| 확인 | 내용 |
|---|---|
| 출처 | 개인 블로그 2곳 (`stoen12`, `dotorynet`) |
| 재검색 | **확인되지 않음** |
| 실체 | **박광온 의원 발의 개정안** — 4년(2+2) → 6년(3+3) 확대안 |
| 상태 | **발의 단계** · 시행 아님 |
| 자기모순 | 같은 블로그 안에서 "최초 2년 + 갱신 2년 = 총 4년"이라고도 서술 |

**따라서 이 문서는 현행 1회·2년을 기준으로 합니다.**

> 이것이 `IM_QUALITY_TRAINING_PLAN.md` §2.3에서 경고한 상황 그대로입니다 — **AI의 법적 답변은 결론이 아니라 확인 목록.** 하마터면 블로그를 근거로 핵심 규칙을 바꿀 뻔했습니다.
>
> **국가법령정보센터·법제처는 JS 렌더링이라 자동 조회가 실패합니다.** 법령 변경 검증은 사람이 직접 조문을 열어 확인하는 절차로 남겨야 합니다.

## 2. 테스트 물건 — 성수동 상가주택 (합성)

### 2.1 왜 합성 데이터인가

T-R 판정에 필요한 **임차인별 갱신요구권 행사 이력은 어떤 공개 데이터에도 없습니다.** 실거래가 공개시스템은 거래 금액만 제공하고, 임대차 상세는 개인정보입니다.

그래서 이렇게 만들었습니다.

| 요소 | 근거 |
|---|---|
| 물건 골격 (면적·층수·가격대) | 서울 상가주택 실거래 통상 범위 |
| 법정 기준 (1.65억/5,500만) | 검색 확인 (§1.1) |
| **임대차 상세** | **분기가 갈리도록 의도 설계** |

**실제 물건을 흉내 내는 것이 목적이 아니라, 판정 경로를 전부 밟는 것이 목적입니다.**

### 2.2 물건 개요

| 항목 | 값 |
|---|---|
| 물건명 | 성수동2가 000-00 상가주택 |
| 법정 용도 | 제2종근린생활시설 + 단독주택 (`nbhd_2` + `house_single`) |
| 물건 유형 | 상가주택 (`mixed_shop_house`) |
| 투자 관점 | 개발형 (`development`) |
| 매각 희망가 | 38억 (380,000만원) |
| 대지 | 264.5㎡ (80.01평) |
| 연면적 | 611.2㎡ (184.89평) |
| 규모 | 지하1층 ~ 지상4층 · 2001년 준공 |
| 필수 팩 | `residential_spec` · `development_plan` · `vacate_plan` |

> **투자 관점을 `development`로 둔 것이 핵심입니다.** 개발형은 명도 시점이 사업 일정을 결정하므로, T-R 오판의 대가가 가장 큽니다. `income`이면 오판해도 수익률만 틀리지만 개발형은 딜 자체가 무너집니다.

## 5. 경계 케이스 8종

물건 데이터와 별개로, **판정 경로를 전부 밟는** 최소 단위 케이스입니다.

| # | 조건 | 기대 판정 | 검증 규칙 |
|:-:|---|---|:-:|
| B1 | 상가 · 최초 2019-04 | 잔여 2.7년 | `T-C-03` |
| B2 | 상가 · 최초 2015-02 (11.5년) | **소진** | `T-C-03` |
| B3 | 주택 · 갱신 이력 `undefined` | **"확인 필요"** · 숫자 미표기 | `T-R-03` · `G15` |
| B4 | 주택 · 갱신 `true` | 소진 → 현 계약 만료 시 | `T-R-03` |
| B5 | 주택 · 갱신 `false` · 경과 1.4년 | 만료 + 2년 | `T-R-03` |
| B6 | **주택 · 갱신 `false` · 경과 7.0년** | **만료 + 2년** (0년 아님) | `T-R-03` ★ |
| B7 | 주택 · 대항력 ✗ · 근거 없음 | **발행 차단** | `G13` |
| B8 | 오피스텔 · 주거 사용 여부 미확인 | **경고 + 보수적으로 주임법** | `T-AMB-01` |

### 5.1 B6가 핵심입니다

원안 산식이 유일하게 틀리는 지점이고, **오차가 2년 9개월로 가장 큽니다.**

```
입력   최초 2019-08 · 현 계약 만료 2027-07 · 갱신요구권 미행사
원안   max(0, 4 − 7.0) = 0년        → "즉시 명도 가능"
정답   2027-07 + 24개월 = 2029-07   → 2년 9개월 차이
```

### 5.2 B8 — 오피스텔

업무시설이지만 **주거용으로 쓰면 주택임대차보호법이 적용**됩니다. 건축물대장으로는 판정할 수 없습니다.

```
자동 판정 불가 → 경고 표시 → 확인 전까지 보수적으로 T-R(4년) 적용
```

**보수적 = 매수인에게 불리한 쪽**입니다. 명도가 어려운 쪽으로 가정해야 나중에 뒤집히지 않습니다.
