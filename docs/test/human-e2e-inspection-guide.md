## 1. 핵심 검수 원칙 및 금기 사항

인간 검수자는 다음 **3대 CRE 무결성 원칙**과 **편집 디자인 규칙**을 엄격히 준수하여 검수를 진행합니다. 위반 시 즉시 결함(P0~P1)으로 판정합니다.

### 🚫 1) 페르소나 격리 원칙 (Implicit Persona Principle)
- 페르소나(예: 60대 자산가, 법인 대표, 디벨로퍼 등)는 **내부 톤앤매너 조절용**으로만 격리되어야 합니다.
- **금기**: 모바일 IM 웹 뷰어, PPTX 슬라이드 제목/본문/헤드라인에 `"60대 자산가를 위한"`, `"법인 대표 맞춤"` 등 **특정 연령/계층/성별을 직접 지칭하는 문구가 단 1글자라도 노출되면 즉시 P1 결함**입니다.

> ⚠️ **Phase 1 실제 발견**: `sanitizePersona()`가 미적용되어 "60대 자산가를 위한" 문구가 PPTX에 그대로 노출된 바 있습니다. 수정 완료되었으나 회귀 방지를 위해 전 케이스에서 필수 확인합니다.

### 📚 2) 한국 상업용 부동산 실무 표준 용어 준수 (CRE Lexicon Standards)
외래어 직역 투를 배제하고 한국 실무 표준 용어를 사용해야 합니다.
- ❌ `네이밍 라이츠`, `브랜딩 라이츠` ➔ ✅ `사옥 단독 명칭 표기(간판 설치권)`, `기업 단독 브랜딩`
- ❌ `캡레이트` ➔ ✅ `연 순수익률 (Cap Rate)`
- ❌ `GOP` (단독 영문) ➔ ✅ `실질 영업이익 (GOP)`
- ❌ `TI / Rent Free` ➔ ✅ `인테리어 지원금(TI) / 렌트프리(무상임대)`

### 📑 3) PPTX 슬라이드 비중복 렌더링 원칙 (No-Duplicate Presentation)
- 비대칭 분할 레이아웃(A04, A05, A13 등)에서 좌측 영역과 우측 영역에 동일한 텍스트/불릿 항목이 중복 나열되지 않아야 합니다.
  * **좌측 영역**: 자산 가치 제안(Value Proposition) 리드문 및 거시적 투자 배경 서사
  * **우측 영역**: 3~4대 핵심 투자 지표 및 스탯 카드
  * **본문 오염 방지**: `**`, `•`, `>` 등 원문 마크다운 기호가 슬라이드에 노출되지 않고 정제되어야 함.

### 📐 4) 편집 디자인 및 타이틀 장식 정밀 정렬
- **헤더 세로 액센트 바**: 키커(Kicker), 타이틀(Title), 부제목(Sub)의 전체 높이를 감싸야 하며(`barH = sub ? 0.86 : 0.62`), 하단 본문 카드를 침범하는 불필요한 전폭 가로선이 없어야 합니다.
- **투자 논거 (A15)**: 4대 핵심 포인트가 2×2 균등 카드 그리드로 배치되고 하단에 `💡 종합 가치 제안`이 깔끔하게 정렬되어야 합니다.

### 🎨 5) 색상 접근성 원칙 (WCAG Contrast — v4.0 신규)
- **accent vs 배경**: 최소 3:1 대비 (장식·강조용)
- **본문 텍스트 vs 배경**: 최소 4.5:1 대비 (WCAG AA 기준)
- **다크 슬라이드(pro_dark_obsidian)**: darkBody vs darkCard 최소 3:1

> ⚠️ **Phase 2 실제 발견**: `credeal_signature` accent(`C8FF00` neon lime)가 흰색 배경 대비 1.18:1로 거의 안 보였습니다. `6B8E00`으로 교정 완료.

## 2. 테스트 절차 개요 및 환경 세팅

### 프로덕션 URL 경로

| 단계 | 경로 | 설명 |
| :---: | :--- | :--- |
| ① | `/broker/deal-card/new` | 원문 메모 입력 → **「1분 딜카드 만들기」** 클릭 |
| ② | `/broker/deal-card/[id]` | 생성된 딜카드 상세 (4탭: 개요·IM관리·매수자·분석) |
| ③ | 딜카드 하단 고정바 **「⚡ Basic IM」** 클릭 | `ImDataBottomSheet` 바텀시트 오픈 |
| ④ | 바텀시트에서 데이터 보강 + **「⚡ Basic IM 생성」** | 비동기 생성 → 3초 폴링 → `/broker/im-approval/[id]` 이동 |
| ⑤ | `/im-lite/[buildingId]` | 모바일 IM Lite 웹 뷰어 (공개, 인증 불필요) |
| ⑥ | 뷰어 하단 `📊 PPTX` 버튼 | `/api/public/im-lite/[id]/pptx?tier=basic` → `.pptx` 다운로드 |

- [ ] **브라우저**: Chrome 최신 (모바일 DevTools 390px 뷰포트 + 데스크톱 1920px 뷰포트)
- [ ] **PPTX 뷰어**: Microsoft PowerPoint 2021/365 또는 LibreOffice Impress
- [ ] **계정**: 브로커 로그인 상태 확인 (`/login`)
- [ ] **네트워크**: 프로덕션 API 정상 응답 확인 (HTTP 200)
- [ ] **자동화 사전 실행** (v4.0 신규):
  ```powershell
  # 자동화 434개 테스트 사전 통과 확인 (수동 검수 전 필수)
  ```
