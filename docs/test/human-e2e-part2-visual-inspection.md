## §7. 결함 등급 및 리포트 양식

테스트 중 발견된 결함은 다음 기준에 따라 분류하여 보고합니다.

**결함 심각도 (Severity):**
- **P0 (Critical)**: 시스템 크래시, 잘못된 데이터 바인딩(NaN), 치명적 페르소나 노출, 생성 불가
- **P1 (High)**: 레이아웃 심각한 깨짐(오버플로), 표준 용어 위반, 잘못된 수치 표시
- **P2 (Medium)**: 마이너한 정렬 어긋남, 권장 대비율 미달, 오탈자
- **P3 (Low)**: 미관상 개선 필요, 단순 UI/UX 제안

**리포트 양식 예시:**
```markdown
### [결함 보고] 렌트롤 테이블 6-7F 병합 미처리
- **심각도**: P1
- **재현 경로**: Case 1 서초 메디컬 타워 -> PPTX 생성 -> A03 슬라이드
- **현상**: 6-7F 병합된 행이 분리되거나 'undefined'로 표시됨.
- **기대 결과**: 렌트롤 원본 데이터에 따라 '6-7F'가 하나의 행으로 보존되어 표시되어야 함.
```
