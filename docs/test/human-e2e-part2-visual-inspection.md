# CRE DealCard 수동 E2E 테스트 가이드 (Part 2: 시각 품질 및 디자인 육안 검사)

**문서 버전:** v5.0  
**작성일:** 2026-08-18  
**관련 문서:** [Part 1: 데이터 파이프라인 및 백엔드 검증 가이드](./human-e2e-part1-data-pipeline.md)

본 문서는 QA 엔지니어 및 디자인 검수자가 CRE DealCard 플랫폼에서 생성된 **모바일 IM 웹 뷰어**와 **PPTX IM**의 시각적 품질, 레이아웃 무결성, 최근 개선 사항(해상도 증대, 디자인 개편 등)이 정상적으로 반영되었는지를 확인하기 위한 정밀 육안 검사 체크리스트입니다.

## §1. 모바일 IM 웹 뷰어 육안 검사 (체크리스트)

웹 뷰어에서 생성된 IM을 렌더링하고, 아래 30+ 항목을 모바일/데스크톱 뷰포트에서 확인합니다.

### 1.1. Hero Card (최상단 요약) 검사
- [ ] 건물명 및 주요 타이틀이 줄바꿈 없이(또는 적절하게) 표시되는가?
- [ ] 4대 핵심 지표(예: 연면적, 캡레이트 등)가 정렬되어 표시되는가?
- [ ] 매매가(또는 임대료) 텍스트의 폰트 크기와 두께(Weight)가 올바른가?
- [ ] 컴포넌트 간의 상하 간격(Margin/Padding)이 디자인 시스템과 일치하는가?

### 1.2. 사진 갤러리 검사
- [ ] 스와이프(모바일) 기능이 부드럽게 작동하는가?
- [ ] 좌우 화살표 네비게이션(데스크톱/태블릿)이 노출되고 클릭 시 정상 작동하는가?
- [ ] **[개선사항]** 이미지 화질이 깨지지 않고 선명한가? (maxWidth 1600, quality 85 적용 여부)
- [ ] **[개선사항]** 이미지 비율이 찌그러지지 않고 원본 비율(혹은 지정 비율)을 유지하는가?

### 1.3. 섹션별 내용 검사 (7섹션 아코디언)
- [ ] 각 아코디언의 접기/펴기 애니메이션이 자연스러운가?
- [ ] 투자 핵심 포인트, 입지 환경, 자산 스펙 등 텍스트가 잘리지 않고 출력되는가?
- [ ] 텍스트 블록 간 여백이 일관적인가?

### 1.4. 렌트롤 테이블 정합성 검사
- [ ] **[개선사항]** 결정론적(Deterministic) 렌트롤 테이블 주입이 정상 작동하는가? (LLM 임의 생성 테이블 텍스트가 아닌 컴포넌트 테이블 확인)
- [ ] 다층(Multi-floor) 병합 구조가 시각적으로 유지되며 깨짐이 없는가?
- [ ] 테이블 좌우 스크롤 시 고정 열(Fixed Column)이 정상적으로 동작하는가?

### 1.5. 지도 및 데이터 등급 검사
- [ ] **[개선사항]** 지도 해상도가 고해상도로 렌더링되는가? (640x360 → 1280x960 2배 스케일업 확인)
- [ ] 지도 마커가 정확한 위치를 가리키는가?
- [ ] 데이터 등급(예: Basic, Pro, 실거래 기반 등) 라벨이 적절한 위치에 렌더링되는가?

## §2. PPTX 슬라이드별 정밀 육안 검사 (아키타입 단위)

다운로드한 PPTX 파일을 열람하여 다음 항목을 검사합니다.

### A01 Cover (커버 슬라이드)
- [ ] 커버 스타일(5종 프리셋)이 선택한 대로 정상 반영되었는가?
- [ ] 건물 이미지의 화질 저하가 없는가?
- [ ] 타이틀 및 부제가 지정된 박스 내에 정렬되어 있는가?

### A02 Stat Grid (주요 지표 및 핵심 포인트)
- [ ] 상단 KPI 카드 배열이 균일한가?
- [ ] **[개선사항]** KPI 카드 하단에 '투자 핵심 포인트' 불릿(Bullet) 섹션이 추가되어 렌더링되는가?
- [ ] 불릿 텍스트가 카드 영역을 침범하지 않는가?

### A03 Large Table (렌트롤 및 대형 데이터 표)
- [ ] 결정론적 테이블 데이터가 정확히 주입되었는가?
- [ ] 테이블의 행 수가 슬라이드 높이를 초과하여 잘리지 않는가?
- [ ] 다층 병합(Rowspan)이 PPTX에서도 깨지지 않고 유지되는가?
- [ ] **[개선사항]** 콜아웃(Callout) 중복 제거 필터가 적용되어 동일한 강조 문구가 여러 번 나타나지 않는가?

### A04 Asymmetric 7:5 (좌측 스펙 + 우측 사진)
- [ ] 좌측 스펙 테이블과 텍스트의 비율(7), 우측 사진 비율(5)이 조화로운가?
- [ ] 우측 이미지가 비율에 맞게 크롭(Crop)되었는가?

### A05 Asymmetric 7:4 (KPI 그리드 중심)
- [ ] **[개선사항]** 가로 전체 너비를 사용하는 3-Column KPI 그리드가 정상적으로 렌더링되는가?
- [ ] 하단에 위치한 가치 제안(Value Proposition) 콜아웃 영역과 KPI 카 편집이 겹치지 않는가?

### A06 Diagram (입지 및 지도)
- [ ] **[개선사항]** 삽입된 지도의 해상도가 선명한가? (1280x960 생성분 확인)
- [ ] 지도 주변의 입지 서사 텍스트 박스 배치가 어색하지 않은가?

### A07 Risk (3블록 카드 - 리스크/완화방안)
- [ ] 3개의 카드가 동일한 높이와 너비를 유지하는가?
- [ ] 내부 텍스트 길이가 달라도 하단 정렬 또는 여백이 일관적인가?

### A10 Closing (넥스트 스텝 및 연락처)
- [ ] **[개선사항]** 기존 A09(프로세스) 슬라이드가 A10 내 하단 "가로 3단계 바(Horizontal 3-step bar)" 형태로 성공적으로 통합되었는가?
- [ ] **[개선사항]** 텍스트에서 불필요한 Provenance 점수나 시스템 메타데이터가 제거되었는가?

### A14 Gallery (포토 갤러리)
- [ ] **[개선사항]** 사진 뒤에 둥근 사각형(roundRect) 배경이 깔려 시각적 안정감을 주는가?
- [ ] **[개선사항]** 각 갤러리 이미지의 화질(quality 85 적용)이 우수하고, 비율이 찌그러지지 않았는가?

### A15 Thesis (종합 투자 논거)
- [ ] 상단 2x2 그리드 배열이 정중앙에 위치하는가?
- [ ] 하단 종합 가치 제안 문구가 강조되어(볼드/색상 등) 표시되는가?

## §3. 프리셋 템플릿 UI 및 에디터 검사

PPTX를 생성하는 웹 UI 및 에디터 화면의 시각적 요소 검사입니다.

- [ ] **[개선사항]** 프리셋 드롭다운 메뉴가 'Basic/Pro 카드 내'로 이동되었는가?
- [ ] **[개선사항]** 드롭다운 옆에 색상 스와치(Accent dot)가 프리셋 테마에 맞게 표시되는가?
- [ ] **[개선사항]** 하단에 중복 노출되던 Export Controls(내보내기 버튼 그룹) 영역이 제거되었는가?
- [ ] **[개선사항]** 에디터 헤더에 "← IM 관리로" 형태의 뒤로가기 네비게이션이 추가되어 정상 동작하는가?
- [ ] 5개의 프리셋 테마(Classic, Modern, Minimal 등)를 변경할 때 에디터의 미리보기 색상 및 폰트가 즉시 변경되는가?

## §4. CRE 실무 표준 용어 및 페르소나 격리 검사 (텍스트 무결성)

렌더링된 텍스트 내용의 비즈니스 품질을 육안으로 검수합니다.

- [ ] **페르소나 격리 원칙:** PPTX 슬라이드 제목, 본문, 웹 뷰어 어디에도 '60대 자산가를 위한', '법인 대표 맞춤' 등 특정 연령/성별/계층을 직접 지칭하는 문구가 노출되지 않았는가?
- [ ] **한국 실무 표준 용어 준수:** 어색한 번역투가 없는지 확인합니다.
  - [ ] `네이밍 라이츠` ➔ `사옥 단독 명칭 표기`
  - [ ] `캡레이트` ➔ `연 순수익률 (Cap Rate)`
  - [ ] `GOP` ➔ `실질 영업이익 (GOP)`
  - [ ] `TI / Rent Free` ➔ `인테리어 지원금(TI) / 렌트프리(무상임대)`

## §5. 디자인 품질 전문 검사 포인트 (유각 검사)

디자인 팀 또는 디자인 검수 담당자가 확인해야 할 세밀한 레이아웃 속성입니다.

- [ ] **헤더 세로 액센트 바 높이:** 각 슬라이드 타이틀 좌측의 액센트 바 높이가 텍스트 높이와 일치하는가?
- [ ] **가로 충돌선:** 컴포넌트 간, 텍스트 상자 간의 가로 선 겹침이나 간격 오류가 없는가?
- [ ] **비중복 프레젠테이션:** 좌/우 분할 레이아웃(A04, A05 등)에서 좌측(가치 제안 리드문)과 우측(핵심 포인트 카드)의 텍스트가 동일하게 반복되지 않는가?
- [ ] **텍스트 오버플로:** 박스나 슬라이드 바깥으로 밀려나가는 텍스트가 없는가?
- [ ] **WCAG 색상 대비:** 배경색과 텍스트 색상의 대비가 접근성 기준을 만족하는가? (예: 옅은 회색 배경에 흰색 텍스트 지양)
- [ ] **최소 폰트 크기:** PPTX 기준 부가 설명(캡션) 폰트가 최소 10pt 이상을 유지하는가?

## §7. 결함 등급 및 리포트 양식

시각적 결함 발견 시 아래 등급에 따라 이슈 트래커에 등록합니다.

* **Blocker (P0):** 텍스트가 완전히 겹쳐 읽을 수 없음, 테이블이 완전히 깨짐, 페르소나 노출 등 치명적 오류
* **Critical (P1):** 이미지가 심하게 찌그러짐, 지도가 렌더링되지 않음, 포스처 시퀀스 오류
* **Major (P2):** 용어 표준 미준수, 컴포넌트 간격 일정하지 않음, 오버플로 일부 발생
* **Minor (P3):** 색상 대비 약간 미흡, 디자인 스펙(Padding 등) 미세 오차

**[이슈 리포트 양식 예시]**
```text
- 발생 위치: PPTX 생성물 > A05 Asymmetric 슬라이드
- 브라우저/환경: Chrome Mac / PPTX Export
- 결함 내용: 3-column KPI 그리드의 세 번째 카드가 두 번째 카드와 2px 겹침
- 예상 결과: 세 카드가 16px 마진을 두고 균등 분할되어야 함
- 결함 등급: Major (P2)
```
