## A. 딜카드 파이프라인 (6개)

### A1. 메모 → 딜카드 생성 파이프라인

| 항목 | 내용 |
| :--- | :--- |
| **입력** | 브로커 자유 메모 (5~3,000자) |
| **처리** | PII 정제 → MemoParser(LLM) → 주소 지오코딩 → BuildingMiniTruth(LLM) → BlindTeaser(LLM) → SSoT Lite 저장 → Signal Card → Pipeline 초기화 → AutoMatch 백그라운드 |
| **출력** | `building_ssot_lite` + `building_signal_cards` + `document_objects(blind_teaser)` + `deal_pipeline_states` |
| **핵심 파일** | `from-memo/route.ts`, `broker-deal-card.ts`, `broker-deal-card.ts (AI agent)` |
| **API** | `POST /api/broker/deal-card/from-memo` |

**E2E 테스트 시나리오**:
```
시나리오 A1-1: 정상 메모 → 딜카드 생성
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[사전조건] 브로커 로그인 상태

[STEP 1] /broker/deal-card/new 접속
[STEP 2] 메모 입력:
  "서초구 서초동 1320-5 메디컬빌딩 165억 전층 병의원 만실"
[STEP 3] 「1분 딜카드 만들기」 클릭
[STEP 4] 5단계 진행바 완료 대기 (최대 120초)

[검증 포인트]
- [ ] /broker/deal-card/[id]로 리다이렉트 되는가?
- [ ] 개요 탭에 건물 스펙(대지/연면적/층수)이 표시되는가?
- [ ] 블라인드 티저에 실주소가 마스킹("서초권역")되어 있는가?
- [ ] PII(전화번호, 소유자명)가 hidden_fields에 격리되었는가?
- [ ] 파이프라인 상태가 "deal_card_created"인가?

시나리오 A1-2: 최소 메모 (5자 미만 → 차단)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[STEP 1] 메모 "강남"만 입력
[검증] 「1분 딜카드 만들기」 버튼이 비활성화 상태인가?

시나리오 A1-3: PII 포함 메모
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[STEP 1] 메모: "김철수 소유 010-1234-5678 서초동 빌딩 80억"
[검증]
- [ ] 블라인드 티저에 "김철수", "010-1234-5678"이 노출되지 않는가?
- [ ] hidden_fields에 개인정보가 격리 저장되었는가?
```

### D5. 임대 매칭 파이프라인

| 항목 | 내용 |
| :--- | :--- |
| **입력** | 임대 공간 + 임차 의향 |
| **처리** | 3-Stage: 월세 허용범위(±20%) → 보증금 허용범위(±15%) → 행정구역 → 전용면적 → 의미 유사도 → 앙상블 |
| **API** | `POST /api/broker/lease-match` |

**E2E 테스트 시나리오**:
```
시나리오 D5-1: 임대 매칭 S등급 생성

[STEP 1] 임대 공간: 강남 30평 월세 300만
[STEP 2] 임차 의향: 강남 25~35평 월세 250~350만 카페 용도

[검증 포인트]
- [ ] grade가 "S" 또는 "A"인가?
- [ ] 렌트프리/TI 인센티브 스코어가 반영되었는가?
```

### D6. 예측 & 클러스터링

| 항목 | 내용 |
| :--- | :--- |
| **입력** | 매칭 이력 + 거래 데이터 |
| **처리** | K-Means 클러스터링(k=3~6) → 로지스틱 회귀 전환 확률 예측 |
| **출력** | 클러스터 라벨, 전환 확률(%), 성공/리스크 요인 |
| **핵심 파일** | `buyer-clustering.ts`, `deal-conversion-predictor.ts` |

**E2E 테스트 시나리오**:
