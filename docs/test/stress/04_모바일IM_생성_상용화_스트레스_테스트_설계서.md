# 📑 딜카드 기반 모바일 IM(Investment Memorandum) 생성 상용화 스트레스 테스트 설계서

- **문서 버전**: v1.0 (상용화 프로덕션 기준)
- **대상 기능**: 딜카드 → 바텀시트 데이터 보강 → 공공 API 연동 → AI 포스처 서사/재무 모델링 → 모바일 IM 슬라이드 & PPTX 생성 파이프라인
- **적용 규격**: 온톨로지 SSoT v0.5, 4대 투자 포스처(`income`, `owner_occupier`, `value_add`, `development`), 한국 상업용 부동산 실무 기준

## 🎯 1. 개요 및 테스트 목표

본 문서는 브로커가 1분 딜카드 생성 후 **바텀시트(Bottom Sheet)를 통해 보충 데이터를 입력하고, 공공데이터(건축물대장/토지이용계획/지오코딩) 및 AI 작성 엔진을 결합하여 매수자용 모바일 IM(10~14장 슬라이드)을 원클릭으로 생성하는 전 과정의 상용화 스트레스 테스트**를 설계합니다.

### 🌟 핵심 테스트 목표
1. **하이브리드 데이터 융합 무결성 (Data Fusion)**: 브로커 입력값(재무/명도/특이사항)과 공공 API 조회값(대지/연면적/용도지역/층수)의 충돌 방지 및 출처(Provenance) 보존.
2. **4대 포스처별 AI 서사 및 재무 모델 완결성**: 투자 유형에 따른 맞춤형 슬라이드 구성 및 금융 수지분석(Cap Rate, WALE, 리모델링 수지, IRR)의 계산 정확도.
3. **극단적 엣지 케이스 및 결측치 대응 (Zero-Failure Fallback)**: 공공 API 타임아웃, 임대차 렌트롤 누락, 미등기 건물 등 불완전 데이터 상태에서도 무중단 정상 생성.
4. **모바일 뷰포트 및 PPTX 렌더링 품질**: 60대 고자산가가 모바일 스마트폰 화면에서 스크롤/스와이프할 때 텍스트 겹침, 테이블 잘림 없는 완벽한 가독성 보장.

## 🔬 3. 4대 상용화 스트레스 테스트 평가 축 및 합격 기준

### 📊 [축 1] 데이터 융합 및 결측치 Fallback 무결성 (Data Fusion & Fallback / 25점)
- **바텀시트 vs 공공 API 충돌 해결**:
  - 대지/연면적/층수/준공년도: 공공 건축물대장 데이터 우선 (`public_api` Provenance).
  - 매매가/임대차/명도: 브로커 입력 데이터 우선 (`broker_input` Provenance).
  - 면적 불일치(공부상 연면적 vs 실사용 연면적) 시 배지 및 각주 안내 표시 여부.
- **공공 API 타임아웃/오류 극단 상황**:
  - 공공 API 응답 지연(>5초) 또는 미등록 지번일 때 딜카드/바텀시트 입력값으로 100% 매끄러운 Fallback (`FALLBACK_STRATEGY` 작동).

---

### 📊 [축 2] 4대 포스처별 AI 서사 및 재무 수지 완결성 (Posture Narrative & Financials / 30점)
포스처별로 요구되는 핵심 슬라이드와 정밀 금융 수식이 정확히 산출되는지 검증:

1. **`income` (임대수익형 슬라이드 덱)**:
   - Cap Rate (NOI / Net Purchase Price), WALE (가중평균 잔여 임대기간), DSCR (부채감당률).
   - 테넌트 렌트롤(Tenant Rent Roll) 및 만실/공실 시나리오 분석 슬라이드.
2. **`owner_occupier` (사옥형 슬라이드 덱)**:
   - 층별 공간 활용 제안(지하 스튜디오, 지상 오피스, 옥상 테라스), 주차 수용능력, 층고(개방감).
   - 임차료 절감 효과 vs 사옥 매입 감가상각/이자비용 비교 분석 슬라이드.
3. **`value_add` (가치부가형 슬라이드 덱)**:
   - 현재 용적률 vs 법정 상한 용적률 여유 분석(증축 잠재력).
   - 리모델링 공사비 투입 후 예상 임대료(시세 정상화) 및 밸류업 후 매각 차익(Exit Cap Rate) 수지표.
4. **`development` (신축개발형 슬라이드 덱)**:
   - 토지이용계획 기반 신축 가설계 규모(건폐율/용적률 적용 연면적 산출).
   - 총 사업비(토지비+건축비+금융비) 대비 분양/임대 수지분석표 및 사업성(IRR) 시뮬레이션.

---

### 📊 [축 3] 온톨로지 SSoT v0.5 팩터 & 가드레일 준수 (Ontology & Compliance / 20점)
- **30계열 위험/입지 팩터 자동 매핑**:
  - `RISK_CATEGORY` (물리적 실사, 임대차 권리, 인허가 규제, 금융 대출) 실사 체크리스트 생성.
  - `LOCATION_CATEGORY` (교통, 배후 상권, 도로 접면, 공급/경쟁) 팩트 기반 요약.
- **컴플라이언스 & 톤앤매너**:
  - 과장 광고/확정 수익률 금지 가드레일(`validateColdModePitchGuard`) 100% 준수.
  - 60대 고자산가가 신뢰할 수 있는 정중하고 격조 높은 한국 상업용 부동산 금융 문체 유지.

### 📊 [축 4] 모바일 반응형 뷰포트 & PPTX 렌더링 무결성 (Visual QA / 25점)
- **모바일 웹 뷰어**:

  - 60대 시니어용 고대비 폰트 및 핵심 숫자(매가, 월세, 수익률) 강조 카드 렌더링.
- **PPTX 브리핑 덱**:

## ⚡ 5. 공공 API 장애 및 결측치 극단 스트레스 시나리오 (Chaos Testing)

| 시나리오 코드 | 결함 및 장애 상황 | 시스템 기대 동작 (Fallback Policy) | 합격 판정 기준 |

| **CHAOS-01** | 국토부 건축물대장 API 서버 500 에러 | 바텀시트 입력 면적/층수 및 딜카드 슬롯으로 즉시 대체, `data_absence` 경고 뱃지 미부착 | 중단 없이 슬라이드 생성 완료 |
