# T21: MS PowerPoint 정상 오픈 수동 검수 체크리스트

> **목적**: PPTX 파일이 MS PowerPoint(Windows/Mac)에서 경고/복구 없이 정상 오픈되고 렌더링되는지 확인

## 준비물
- [ ] Phase 1 E2E 테스트에서 생성된 `.pptx` 파일 (최소 2개 포스처)
- [ ] MS PowerPoint 2021+ (Windows)
- [ ] MS PowerPoint for Mac (가능한 경우)

---

## 1단계: 파일 오픈 검증

| # | 검수 항목 | Win | Mac | Pass/Fail |
| :---: | :--- | :---: | :---: | :---: |
| 1 | `.pptx` 더블클릭 시 **복구 프롬프트 없이** 정상 오픈 | ☐ | ☐ | |
| 2 | "이 파일에 문제가 있습니다" 경고 **미표시** | ☐ | ☐ | |
| 3 | 슬라이드 마스터 참조 오류 없음 (보기 → 슬라이드 마스터) | ☐ | ☐ | |
| 4 | 모든 슬라이드가 축소판에 정상 표시 (빈 슬라이드 없음) | ☐ | ☐ | |

## 2단계: 텍스트 렌더링 검증

| # | 검수 항목 | Win | Mac | Pass/Fail |
| :---: | :--- | :---: | :---: | :---: |
| 5 | **맑은 고딕** 폰트가 정상 렌더 (대체 폰트 경고 없음) | ☐ | ☐ | |
| 6 | **Pretendard** 숫자 폰트가 정상 렌더 (또는 정상 대체) | ☐ | ☐ | |
| 7 | 한글 텍스트 줄바꿈이 의도된 위치에서 발생 | ☐ | ☐ | |
| 8 | 텍스트가 도형 테두리를 **벗어나지 않음** | ☐ | ☐ | |

| 10 | 수직 액센트 바(line)가 정확한 위치에 렌더 | ☐ | ☐ | |
