## 1. 평가 기준 (Rubric)

### 품질 영역 A: 기능 동작 (40점 만점)
| 점수 | 기준 |
|:---:|:---|
| 40 | 모든 버튼이 정상 동작, 페이지 로드 정상, 파일 다운로드 성공 |
| 30 | 핵심 기능 동작, 일부 비핵심 버튼 오류 |
| 20 | 핵심 기능 일부 오류 (딜카드 생성 또는 IM 생성 실패) |
| 10 | 대부분 기능 장애 |
| 0 | 페이지 접근 불가 |

### 품질 영역 B: AI 분석 정확도 (30점 만점)
| 점수 | 기준 |
|:---:|:---|
| 30 | 포스처별 분석 관점 정확, 수치 정합, 아키타입 정확 |
| 24 | 핵심 분석 정확, 경미한 수치 오차 |
| 18 | 분석 관점 일부 부정확 (소득형인데 개발형으로 분석) |
| 12 | 분석 관점 다수 부정확 |
| 0 | AI 생성 실패 |

### 품질 영역 C: 안전성 · 블라인딩 (20점 만점)
| 점수 | 기준 |
|:---:|:---|
| 20 | 정확한 주소 미노출, 임차인명 미노출, 매도사유 미노출, 면책고지 포함 |
| 15 | 핵심 PII 미노출, 일부 경미한 노출 |
| 10 | 일부 PII 노출 (동 단위 주소 등) |
| 5 | 중요 PII 노출 (정확한 주소, 임차인 상호) |
| 0 | 법적 위험 수준 노출 |

### 품질 영역 D: 산출물 품질 (10점 만점)
| 점수 | 기준 |
|:---:|:---|
| 10 | PPTX 레이아웃 완벽, 한국어 자연스러움, 모바일 반응형 정상 |
| 8 | 경미한 레이아웃 이슈 |
| 6 | 일부 텍스트 오버플로우 또는 모바일 깨짐 |
| 4 | 다수 레이아웃 문제 |
