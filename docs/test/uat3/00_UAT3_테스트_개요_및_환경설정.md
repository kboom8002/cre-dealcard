# UAT-3. 인간 테스터 2인 E2E 프로덕션 테스트 가이드

> **문서 버전**: v1.0 | **최종 수정**: 2026-08-14  
> **대상 환경**: Production (`https://cre-dealcard.vercel.app` 또는 실 배포 URL)  
> **검증 대상**: **딜카드 생성 → 바텀시트 보충 데이터 입력 → 모바일 IM Basic 생성 → PPTX Basic 다운로드 및 슬라이드 무결성 검증**  
> **테스트 인원**: 인간 테스터 2인 (테스터 A, 테스터 B)  
> **예상 소요 시간**: 인당 약 20~25분 (총 50분 내외)

---

## 1. 테스트 목적 및 범위

본 테스트는 **실제 상용 프로덕션 환경**에서 중개사/투자자 페르소나를 가진 인간 테스터 2인이 **'복사-붙여넣기(Copy & Paste)'**만으로 가장 빠르고 정확하게 전체 파이프라인의 데이터 정합성과 시각적 완성도를 검증하기 위한 정밀 가이드입니다.

```
[1단계: 딜카드 생성] ──> [2단계: 바텀시트 입력] ──> [3단계: 모바일 IM 검토] ──> [4단계: PPTX 다운로드&검증]
 텍스트 메모 복붙         주소/재무/포스처 복붙        7개 섹션·가드레일 검증       슬라이드 레이아웃/표 검증
```

| 역할 | 담당 테스터 | 검증 시나리오 | 타깃 매물 특성 | 핵심 검증 포인트 |
|:---:|:---:|:---|:---|:---|

## 3. 프로덕션 환경 준비

### 3-1. 브라우저 및 프로그램 준비
1. **PC 웹 브라우저**: Google Chrome 또는 Microsoft Edge 최신 버전
2. **모바일 웹 브라우저 (선택/권장)**: 스마트폰 Safari 또는 Chrome 브라우저
3. **프레젠테이션 뷰어**: MS PowerPoint, Hancom 한쇼, 또는 Google Slides

### 3-2. 로그인 및 접속
1. 프로덕션 사이트 접속: `https://cre-dealcard.vercel.app/login`
2. 테스트 계정 로그인:
   - **테스터 A 계정**: `broker-tester1@credeal-test.com` (또는 지정된 공용 중개인 계정)
   - **테스터 B 계정**: `broker-tester2@credeal-test.com` (또는 지정된 공용 중개인 계정)
3. 대시보드(`/broker`) 진입 확인
