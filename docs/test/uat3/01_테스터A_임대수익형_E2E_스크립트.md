# 01. [테스터 A] 임대수익형 (income) E2E 실행 스크립트

> **담당 테스터**: 테스터 A (Tester 1)  
> **검증 대상 물건**: 서초구 잠원동 근생빌딩 (임대수익형)  
> **소요 시간**: 약 20분  
> **준비물**: PC 크롬 브라우저, MS PowerPoint (또는 PPTX 뷰어)

---

## 🚀 STEP 1. 딜카드 생성 (약 3분)

### 1-1. 화면 이동
- 코크핏 대시보드(`/broker`)에서 우측 상단 또는 하단 메뉴의 **`+ 새 딜카드`** 버튼 클릭
- `/broker/deal-card/new` 페이지 이동 확인

### 1-2. 메모 텍스트 복사 & 붙여넣기 (또는 메모함에서 불러오기)
- **방법 1 (직접 복붙)**: 아래 코드 블록의 텍스트를 **그대로 복사(Ctrl+C)하여 입력창에 붙여넣기(Ctrl+V)** 하세요.
- **방법 2 (메모함 불러오기)**: 우측 하단 **`📋 메모함에서 불러오기`** 버튼을 눌러 메모함에 저장된 잠원동 메모를 선택하세요.

```text
[급매] 서초구 잠원동 12-34 근생빌딩 매각
대지면적: 115평 (380.1㎡), 연면적: 380평 (1,256.2㎡)
규모: 지하 1층 / 지상 5층, 준공년도: 2012년, 승강기 1대 완비
용도지역: 제3종일반주거지역, 주차: 8대 자주식 가능
신사역/잠원역 도보 5분 거리 더블역세권, 대로 이면 8m 도로 접면 코너자리
매각 희망가: 85억원 (평당 약 7,390만원 수준, 가격 협의 일부 가능)
보증금 총액: 4억 5,000만원 / 월 임대료 총액: 2,850만원 / 관리비 총액: 320만원
현재 공실 없음 (만실 운영 중, 우량 F&B 및 IT/디자인 오피스 임차)
선순위 담보대출: 45억원 (금리 4.2% 이용 중, 승계 가능)
소유주 법인 구조조정 사유로 시세 대비 합리적 가격에 긴급 매각 진행
담당자: 박준형 팀장 (010-8877-9900, junhyung@brokerage.co.kr)
```

### 1-3. 딜카드 생성 실행
1. 글자 수 카운터가 정상 반영되는지 확인 (약 350자 이상)
2. (확인: 건물 사진 첨부 UI가 딜카드 생성에서 빠지고 가볍게 1분 생성에 집중됨)
3. 하단 **"1분 딜카드 만들기"** 버튼 클릭
4. 로딩 애니메이션 5단계 순차 진행 확인:
   - ⏳ `메모에서 매물 정보 추출 중`
   - ⏳ `건물 기본 신호 생성 중`
   - ⏳ `민감정보 식별 및 숨김 처리 중` (PII 마스킹)
   - ⏳ `블라인드 딜카드 생성 중`
   - ⏳ `카카오 문구 준비 중`
5. **딜카드 상세 페이지(`/broker/deal-card/{id}`) 자동 이동 확인**

### 1-4. 딜카드 생성 결과 1차 검증
- [ ] **블라인드 딜카드 메인 카드 뷰**: 상세 화면 최상단에 카카오톡 공유 스타일의 **완성도 높은 블라인드 딜카드 카드**가 시원하게 출력되는가?
- [ ] **핵심 딜 포인트 3선**: '만실 운영', '월 임대료 2,850만', '더블역세권' 등 매력적인 불릿 카드가 정상 표시되는가?
- [ ] **블라인드 안심 뱃지**: "잠원동 12-34" 상세 번지 및 "박준형 팀장", "전화번호", "이메일"이 노출되지 않고 100% 안전하게 보호 중인가?

## 📝 STEP 2. 바텀시트(Bottom Sheet) 보충 데이터 입력 (약 5분)

딜카드 상세 페이지에서 **"모바일 IM 만들기"** (또는 'IM 데이터 보강') 버튼을 클릭하면 화면 하단에서 바텀시트가 슬라이드 업 됩니다.

### 2-1. 기본 정보 및 주소 확인
- [ ] **투자 포스처**: `임대수익형 (income)` 선택 확인 (기본값)
- [ ] **주소 입력/검색**: 
  - 검색창에 `잠원동` 입력 후 검색 클릭 → 검색 목록에서 `서울특별시 서초구 잠원동` 또는 관련 지번 선택
  - (직접 입력 시: `서울특별시 서초구 잠원동 12-34` 복붙)

### 2-2. 재무 데이터 확인 및 복붙 보충

| 입력 필드명 | 입력/복붙할 값 | 비고 |
|:---|:---|:---|
| **매각 희망가 (만원)** | `850000` | 85억원 (자동 프리필 확인 또는 입력) |
| **월 임대료 총액 (만원)** | `2850` | 2,850만원 (자동 프리필 확인) |
| **보증금 총액 (만원)** | `45000` | 4억 5,000만원 (자동 프리필 확인) |
| **관리비 총액 (만원)** | `320` | 320만원 |
| **선순위 대출금 (만원)** | `450000` | 45억원 |
| **대출 상태** | `확인됨 (confirmed)` | 선택 |
| **공실률 (%)** | `0` | 만실 (0%) |

### 2-3. 임대차 상세 (렌트롤) 간이 입력 (선택/보충)
하단 '층별 임대차 추가' 버튼을 눌러 아래 데이터를 1~2개 층 입력해 보거나 자동 반영을 확인합니다:
- **B1~1층**: 보증금 `15000` 만원 / 월세 `1100` 만원 (근린생활시설 / F&B)
- **2~5층**: 보증금 `30000` 만원 / 월세 `1750` 만원 (업무시설 / 오피스)

### 2-4. IM 생성 시작 클릭
1. 하단 **"IM 생성 시작"** (또는 '모바일 IM 발행') 버튼 클릭
2. 진행 프로그레스 바 작동 확인 (`AI 분석 중...`)
3. 약 10~30초 후 **"✅ 7섹션 생성 완료!"** 토스트 및 검토 페이지(`/broker/im-approval/{id}`) 이동 확인

## 📊 STEP 4. PPTX Basic IM 다운로드 및 슬라이드 정밀 검증 (약 7분)

### 4-1. 다운로드 실행
- 모바일 IM 뷰어 상단/하단의 **`PPTX 다운로드`** (또는 브로커 패널의 `PPTX 다운로드`) 버튼 클릭
- 브라우저에 `[빌딩명]_Basic.pptx` (약 200KB~2MB) 파일이 정상 다운로드되는지 확인
