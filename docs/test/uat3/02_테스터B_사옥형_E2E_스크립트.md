# 02. [테스터 B] 사옥/자가사용형 (owner_occupied) E2E 실행 스크립트

> **담당 테스터**: 테스터 B (Tester 2)  
> **검증 대상 물건**: 마포구 연남동 디자인 사옥 빌딩 (사옥/자가사용형)  
> **소요 시간**: 약 20분  
> **준비물**: PC 크롬 브라우저, MS PowerPoint (또는 PPTX 뷰어)

---

## 🚀 STEP 1. 딜카드 생성 (약 3분)

### 1-1. 화면 이동
- 코크핏 대시보드(`/broker`)에서 우측 상단 또는 하단 메뉴의 **`+ 새 딜카드`** 버튼 클릭
- `/broker/deal-card/new` 페이지 이동 확인

### 1-2. 메모 텍스트 복사 & 붙여넣기 (또는 메모함에서 불러오기)
- **방법 1 (직접 복붙)**: 아래 코드 블록의 텍스트를 **그대로 복사(Ctrl+C)하여 입력창에 붙여넣기(Ctrl+V)** 하세요.
- **방법 2 (메모함 불러오기)**: 우측 하단 **`📋 메모함에서 불러오기`** 버튼을 눌러 메모함에 저장된 연남동 메모를 선택하세요.

```text
[사옥추천] 마포구 연남동 234-56 감성 디자인 사옥용 빌딩 매각
대지면적: 85평 (281.0㎡), 연면적: 245평 (810.0㎡)
규모: 지하 1층 / 지상 5층, 준공년도: 2019년 (수려한 노출콘크리트 신축급 외관)
용도지역: 제2종일반주거지역, 주차: 5대 가능 (자주식)
홍대입구역(2호선/공항철도/경의중앙선) 도보 8분, 연트럴파크 메인 상권 인접
매각 희망가: 65억원 (주변 사옥 거래사례 대비 평당가 우수)
현재 현 임차인(엔터테인먼트 본사) 사용 중이며, 매매 시 전층 명도 협의 완료(즉시 사옥 입주 가능)
천장고 3.8m 개방감 우수, 옥상 루프탑 테라스 및 지하 스튜디오 완비
IT기업, 미디어/스타트업, 크리에이티브 에이전시 통사옥으로 최적
소유주 개인 자금 확보 목적 매각
담당: 이진우 이사 (010-3344-5566, jinwoo.lee@realty.com)
```

### 1-3. 딜카드 생성 실행
1. 글자 수 카운터가 정상 반영되는지 확인 (약 350자 이상)
2. (확인: 건물 사진 첨부 UI가 딜카드 생성에서 빠지고 가볍게 1분 생성에 집중됨)
3. 하단 **"1분 딜카드 만들기"** 버튼 클릭
4. 로딩 애니메이션 5단계 순차 진행 확인:
   - ⏳ `메모에서 매물 정보 추출 중`
   - ⏳ `건물 기본 신호 생성 중`
   - ⏳ `민감정보 식별 및 숨김 처리 중` (PII 마스킹)
   - ⏳ `블라인드 딜카드 생성 중`
   - ⏳ `카카오 문구 준비 중`
5. **딜카드 상세 페이지(`/broker/deal-card/{id}`) 자동 이동 확인**

### 1-4. 딜카드 생성 결과 1차 검증
- [ ] **블라인드 딜카드 메인 카드 뷰**: 상세 화면 최상단에 카카오톡 공유 스타일의 **완성도 높은 블라인드 딜카드 카드**가 시원하게 출력되는가?
- [ ] **핵심 딜 포인트 3선**: '전층 명도 협의 완료', '천장고 3.8m 우수', '홍대입구역 도보 8분' 등 사옥 특화 불릿 카드가 정상 표시되는가?
- [ ] **블라인드 안심 뱃지**: "연남동 234-56" 상세 번지 및 "이진우 이사", "전화번호", "엔터테인먼트" 상호가 100% 안전하게 보호 중인가?

## 📝 STEP 2. 바텀시트(Bottom Sheet) 보충 데이터 입력 (약 5분)

딜카드 상세 페이지에서 **"모바일 IM 만들기"** 버튼을 클릭하여 바텀시트를 엽니다.

### 2-1. 투자 포스처 및 주소 설정
- [ ] **투자 포스처**: **`자가사용형 (owner_occupied)`** 선택 (드롭다운/토글)
- [ ] **주소 입력/검색**: 
  - 검색창에 `연남동` 입력 후 검색 클릭 → `서울특별시 마포구 연남동` 관련 주소 선택
  - (직접 입력 시: `서울특별시 마포구 연남동 234-56` 복붙)

### 2-2. 사옥형 특화 재무 및 공간 스펙 입력

| 입력 필드명 | 입력/복붙할 값 | 비고 |
|:---|:---|:---|
| **매각 희망가 (만원)** | `650000` | 65억원 |
| **수용 인원 (명)** | `60` | 예상 상주 인원 약 50~70명 |
| **희망 사용 층수** | `전층 (B1~5F)` | 통사옥 사용 조건 |
| **명도 조건** | `매도인 책임 명도 (입주시 즉시 사용)` | 명도 완료 조건 |
| **선순위 대출금 (만원)** | `0` | 무융자 또는 신규 법인대출 활용 |
| **대출 상태** | `대출 없음 (no_loan)` | 선택 |
| **공실률 (%)** | `0` | 현 매도자/임차인 사용 중 |

### 2-3. 물리 스펙 추가 (선택)
- **천장고 (m)**: `3.8`
- **승강기**: `유 (1대)`
- **주차 대수**: `5대`

### 2-4. IM 생성 시작 클릭
1. 하단 **"IM 생성 시작"** 버튼 클릭
2. 진행 프로그레스 바 작동 확인 (`AI 분석 중...`)
3. 약 10~30초 후 **"✅ 7섹션 생성 완료!"** 토스트 및 검토 페이지(`/broker/im-approval/{id}`) 이동 확인
