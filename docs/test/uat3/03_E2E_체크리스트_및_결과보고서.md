## 2. 결함 심각도 분류 기준

테스트 중 이슈가 발견된 경우 아래 기준에 따라 분류하여 기록합니다.

- 🔴 **CRITICAL (치명적)**: 
  - PPTX 파일이 열리지 않거나 프로그램 오류 발생
  - 딜카드 또는 모바일 IM 생성 중 무한 로딩 / 500 에러 발생
  - 민감정보(소유주 실명, 연락처, 상세 호실)가 블라인드 딜카드에 그대로 노출되는 경우
- 🟠 **MAJOR (주요)**:
  - PPTX 슬라이드에서 텍스트가 박스 밖으로 완전히 넘치거나 표 행이 심하게 겹치는 경우
  - 바텀시트에 입력한 매각가/임대료 수치가 모바일 IM에 잘못 반영되는 경우
  - 화면이 모바일에서 가로 스크롤되어 레이아웃이 깨지는 경우
- 🟡 **MINOR (경미)**:
  - 텍스트 오탈자 또는 약간의 여백 불균형
  - 버튼 클릭 후 로딩 인디케이터 표시 지연 (기능은 정상 동작)
