# 🧪 [UAT-3] 모바일 IM 지도 연동 & 이미지 갤러리 첨부·뷰어 E2E 테스트 스크립트

- **문서 ID**: `UAT-MIM-04-MAP-GALLERY`
- **테스트 목적**: 딜카드 상세 페이지에서 바텀시트를 열고, **정밀 주소 지오코딩 지도 연동 및 건물 내외관 사진 다중 업로드/캡션 지정 후 모바일 IM 생성 시, 모바일 뷰어에서 인터랙티브 지도와 고화질 갤러리 라이트박스(슬라이더/확대/스와이프)가 정상 작동하는지** 인간 테스터가 100% 검증.
- **예상 소요 시간**: 약 7~10분
- **테스트 환경**: PC 크롬 브라우저 (모바일 뷰 모드 `F12 → Ctrl+Shift+M` iPhone 14/Galaxy S20) 및 실제 모바일 스마트폰(카카오톡 인앱 브라우저 / Safari / Chrome).

## 📦 1. 테스트 준비물 (복사-붙여넣기 데이터셋)

### 📍 [테스트 주소 데이터]
```text
서울특별시 서초구 서초동 1320-5
```
*(또는 `서울특별시 강남구 역삼동 735-8`)*

### 🖼️ [테스트용 샘플 이미지 (PC 로컬 업로드 또는 URL 테스트용)]
테스터는 아래 샘플 사진 또는 본인의 스마트폰 앨범 사진 3~4장을 준비합니다:
1. **외관 사진 (대표)**: 건물 전경 및 대로변 접면 사진
2. **1층 로비/약국 사진**: 1층 내부 및 층고 사진
3. **기준층 병원/오피스 내부 사진**: 3층 병원 인테리어 사진
4. **옥상/주차장 사진**: 자주식 주차장 및 옥상 뷰 사진

## 🧭 2. 5단계 E2E 테스트 시나리오 (Click-by-Click Action)

```
[Step 1: 딜카드 진입] ──▶ [Step 2: 바텀시트 & 주소 검색] ──▶ [Step 3: 사진 업로드 & 캡션]
                                                                        │
[Step 5: 모바일 뷰어 지도/갤러리 검증] ◀── [Step 4: 모바일 IM 생성] ◀──┘
```

---

### 🔹 Step 1. 딜카드 상세에서 바텀시트 열기
1. 웹 브라우저에서 딜카드 상세 페이지(`/broker/deal-card/[id]`)에 접속합니다.
2. 페이지 하단 또는 우측 상단의 **`[ ⚡ Basic IM ]`** (또는 `[ 📱 모바일 IM 만들기 ]`) 버튼을 클릭합니다.
3. 화면 하단에서 **`ImDataBottomSheet` (데이터 보강 바텀시트)**가 부드럽게 슬라이드 업되는지 확인합니다.

---

### 🔹 Step 2. 정밀 주소 검색 및 지오코딩 확인
1. 바텀시트 상단의 **`건물 주소 (지번 또는 도로명)`** 입력창을 확인합니다.
2. `서울특별시 서초구 서초동 1320-5`를 입력하고 잠시 대기하거나 검색을 누릅니다.
3. 드롭다운 검색 결과 목록에 `서초동 1320-5 (도로명: 강남대로...)`가 노출되는지 확인하고 클릭합니다.
4. 주소 선택 시 PNU 코드 및 건물명이 자동으로 매핑되는지 확인합니다.

---

### 🔹 Step 3. 건물 내외관 사진 다중 업로드 & 캡션 등록
1. 바텀시트 내 **`📷 건물 현장 사진 첨부`** 섹션으로 스크롤합니다.
2. **`[ ➕ 사진 추가하기 ]`** 버튼을 클릭하여 준비한 사진 3~4장을 한 번에 다중 선택하여 업로드합니다.
3. 업로드된 사진들이 **썸네일 그리드로 즉각 렌더링**되는지 확인합니다.
4. 첫 번째 사진에 **`[ ⭐ 대표 사진 ]`** 뱃지가 붙어 있는지 확인합니다.
5. 각 사진 썸네일 하단의 **캡션(설명) 입력란**에 아래 내용을 순서대로 입력합니다:
   - 사진 1 캡션: `서초대로 25m 메인 도로변 외관 전경`
   - 사진 2 캡션: `1층 대형 약국 및 메디컬 로비`
   - 사진 3 캡션: `3층 안과·피부과 전문의원 내부 인테리어`
   - 사진 4 캡션: `자주식 18대 전용 주차장 및 옥상 휴게공간`
6. 필요 시 사진 순서 변경(드래그) 또는 특정 사진의 `[ ✕ 삭제 ]` 버튼이 정상 작동하는지 확인합니다.

---

### 🔹 Step 4. 모바일 IM 생성 트리거
1. 매매가(`1650000`), 보증금(`115000`), 월세(`5950`) 등 기본 수치가 채워져 있는지 확인합니다.
2. 바텀시트 맨 하단의 **`[ 🚀 모바일 IM 원클릭 생성하기 ]`** 버튼을 클릭합니다.
3. 로딩 인디케이터와 함께 "공공데이터 결합 및 AI 슬라이드 덱 생성 중..." 안내가 표시되는지 확인합니다.
4. 생성이 완료된 후 **모바일 IM 전용 뷰어 화면(`/broker/im/[id]` 또는 미리보기 모달)**으로 자동 전환되는지 확인합니다.

---

### 🔹 Step 5. 모바일 IM 뷰어 상의 지도 및 갤러리 육안 검사

#### 5-1. 히어로 커버 및 갤러리 슬라이더 검사
1. 모바일 IM 최상단 커버에 내가 등록한 **대표 외관 사진**이 고화질로 꽉 차게 렌더링되는지 확인합니다.
2. 사진을 좌우로 스와이프하거나 하단 썸네일 도트(Indicator)를 눌렀을 때, 2번·3번·4번 사진으로 부드럽게 전환되는지 확인합니다.
3. 각 사진 하단에 Step 3에서 입력한 **캡션 텍스트(`서초대로 25m 메인 도로변 외관 전경` 등)**가 깔끔하게 노출되는지 확인합니다.
4. 사진을 클릭했을 때 **풀스크린 라이트박스(Full-screen Lightbox)**가 열리며 핀치 줌(확대/축소) 또는 닫기(`✕`) 버튼이 잘 작동하는지 확인합니다.

#### 5-2. [입지 및 교통] 섹션 지도(Map) 인터랙션 검사
1. 상단 탭에서 **`[ 📍 입지 ]` (또는 `location_access`)** 탭을 클릭합니다.
2. 화면에 **정밀 지오코딩 지도(카카오맵/VWorld)**가 에러 없이 로드되는지 확인합니다.
3. 해당 건물 위치에 **골드/블루 핀 마커**가 정확히 꽂혀 있는지 확인합니다.
4. 지도를 손가락으로 드래그(이동) 및 확대/축소(`+`, `-`)할 수 있는지 확인합니다.
5. 지도 하단에 **주변 반경 인프라 정보(예: `강남역 도보 4분`, `양재역 도보 4분`, `서초대로 25m 접면`)**가 정확히 표시되는지 확인합니다.

## 🛠️ 4. 결함 발생 시 트러블슈팅 가이드

1. **주소 검색창이 열리지 않거나 검색 결과가 안 뜰 때**:
   - `.env.local`의 공공데이터 및 지오코딩 API Key 세팅을 확인합니다.
   - 키보드 입력 후 0.3초 대기(Debounce)가 정상 동작하는지 확인합니다.
2. **이미지 업로드 시 용량 초과 또는 엑스박스 발생 시**:
   - 장당 10MB 이하의 JPG/PNG/WebP 파일을 권장합니다.
   - Supabase Storage 버킷(`deal-photos` 또는 `building-images`)의 공개 권한(Public Access) 설정을 확인합니다.
3. **지도가 회색으로 표시되고 핀이 안 뜰 때**:
   - 브라우저 콘솔에서 카카오맵 JavaScript API SDK 키 허용 도메인(`localhost:3000` 및 Vercel 도메인)을 확인합니다.
