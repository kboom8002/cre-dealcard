> **작성일**: 2026-08-23  
> **대상 포스처**: `development` (신축 개발형)  
> **실매물 데이터**: 잠원동 두원빌딩 (242억, 2필지 11호실 명도) / 수택동 나대지 (89억, 3필지 나대지)  
> **검증 범위**: 메모 → 딜카드 → 바텀시트 → 모바일 IM → PPTX IM 전 파이프라인

## 0. 사전 준비

### 테스트 계정
| 역할 | 이메일 | 비고 |
|---|---|---|
| 중개인 A (소유자) | `broker-a@credeal.net` | 딜카드 생성 권한 |
| 시크릿 창 일반인 | 미로그인 | Public 마스킹 / 티저 검증 |

### 핵심 검증 관점 (개발형 특화)
- 렌트롤 섹션이 **억제**되고 개발 사업수지 섹션이 **활성화**되는지
- 용적률 이중 기준(지상 vs 공부상)이 정확히 **병기**되는지
- 명도 일정·비용이 사업수지에 **반영**되는지 (잠원동)
- 나대지일 때 건물 정보가 `not_applicable` 처리되는지 (수택동)
- Rent=0 조건에서 Cap Rate가 Infinity/NaN이 아닌 개발 수익률로 대체되는지
