# 프로덕션 E2E 테스트 스크립트 ③ — 운영형·사옥형·트레이딩형 (Operating / OwnerOccupied / Trading)

> **작성일**: 2026-08-23  
> **대상 포스처**: `operating` (호텔 운영형) / `owner_occupied` (사옥용) / `trading` (밸류애드)  
> **실매물 데이터**: 에이치에비뉴호텔 이대점 (300억) / 역삼동 사옥 (120억) / 대치동 근생 (150억)  
> **검증 범위**: 메모 → 딜카드 → 바텀시트 → 모바일 IM → PPTX IM 전 파이프라인  
> **수행 환경**: `https://credeal.net` (Production) / Chrome 최신 + iOS Safari

---

## 0. 사전 준비

### 테스트 계정
| 역할 | 이메일 | 비고 |
|---|---|---|
| 중개인 A (소유자) | `broker-a@credeal.net` | 딜카드 생성 권한 |
| 시크릿 창 일반인 | 미로그인 | Public 마스킹 / 티저 검증 |

### 핵심 검증 관점 (포스처 3종 교차)
- **Operating**: 임대차 NOI가 아닌 **GOP Cap Rate**가 주지표이며 렌트롤 섹션이 **억제**되는지
- **OwnerOccupied**: 수익률 대신 **점유비용·임차 절감액**이 Hero Card에 표시되는지
- **Trading**: **리모델링 비용·엑시트 가치**가 핵심이며 comps 부재 시 정상 처리되는지
