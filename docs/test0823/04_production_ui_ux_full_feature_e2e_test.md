> [!IMPORTANT]
> ## 📐 본 문서의 인지과학적 설계 원칙
>
> 이 문서는 **시니어 테스터(50~60대 중개인 포함)**도 혼자 따라할 수 있도록 다음 5대 인지과학 원리를 적용했습니다.
>
> | 원칙 | 적용 방식 |
> |---|---|
> | **① 청킹 (Chunking)** | 각 파이프라인을 3~5개 이하 스텝으로 묶어 작업기억 부하를 7±2 범위 내로 제한 |
> | **② 점진적 공개 (Progressive Disclosure)** | 쉬운 기능(Auth → Profile)에서 복잡한 기능(IM → PPTX)으로 난이도를 선형 증가 |
> | **③ 시각 앵커링 (Visual Anchoring)** | 🖱️ 조작, ✅ 기대결과, 📸 캡처, ⚠️ 주의, 💡 팁 등 일관된 아이콘으로 시선 유도 |
> | **④ 맥락 프라이밍 (Contextual Priming)** | 각 섹션 시작 시 "왜 이 기능이 중요한가"와 "어디서 시작하는가"를 먼저 제시 |
> | **⑤ 오류 인지 패턴 (Error Recognition)** | 정상/비정상 결과를 명시적으로 분리하고, 실패 시 즉시 기록할 양식을 인라인 배치 |

### 🔐 A. 인증 (Auth) — 서비스 진입의 관문

> **🧠 인지 프라이밍**: 이 단계는 사용자가 서비스에 "들어올 수 있는지"를 검증합니다.
> 가입 → 로그인 → 로그아웃 → 비번 리셋의 **순환 고리**가 빈틈없이 연결되는지 확인합니다.
>
> **📍 시작 위치**: 비로그인 상태로 `https://credeal.net` 접속
>
> **⏱️ 예상 소요**: 10분

#### A-1. 회원가입 (첫 인상 테스트)

| 항목 | 내용 |
|---|---|
| **🖱️ 조작** | `/signup` 접속 → 이름, 이메일, 비밀번호(8자 이상) 입력 → **「가입하기」** 클릭 |
| **✅ 정상 결과** | ① 가입 성공 후 `/broker` 대시보드로 자동 이동 ② 상단에 환영 인사말(Greeting) 표시 |
| **⚠️ 주의 관찰** | 비밀번호 강도 표시기가 작동하는가? 이미 가입된 이메일로 재시도 시 에러 메시지가 뜨는가? |
| **📸 캡처** | 대시보드 첫 진입 화면 (Greeting + KPI 카드 영역) |
| **🏷️ 판정** | Pass ☐ / Fail ☐ |

#### A-2. 로그아웃 (탈출 경로 검증)

| 항목 | 내용 |
|---|---|
| **🖱️ 조작** | 우측 상단 프로필 아바타 클릭 → **「로그아웃」** 클릭 |
| **✅ 정상 결과** | ① `/login` 페이지로 리다이렉트 ② 뒤로가기(Back) 시 `/broker`에 접근 불가 (Auth Guard 작동) |
| **⚠️ 비정상 신호** | 로그아웃 후 뒤로가기로 대시보드가 보이면 **세션 정리 실패** → P0 결함 |
| **🏷️ 판정** | Pass ☐ / Fail ☐ |

#### A-3. 로그인 실패 (방어벽 테스트)

| 항목 | 내용 |
|---|---|
| **🖱️ 조작** | `/login`에서 올바른 이메일 + **틀린 비밀번호** 입력 → **「로그인」** 클릭 |
| **✅ 정상 결과** | "이메일 또는 비밀번호가 일치하지 않습니다" 에러 메시지가 빨간색으로 표시됨 |
| **⚠️ 주의 관찰** | 에러 메시지에 "비밀번호가 틀렸습니다" 등 어느 필드가 틀렸는지 알려주면 **보안 결함** (정보 누출) |
| **🏷️ 판정** | Pass ☐ / Fail ☐ |

#### A-4. 정상 로그인 (Happy Path)

| 항목 | 내용 |
|---|---|
| **🖱️ 조작** | 올바른 이메일 + 비밀번호 입력 → **「로그인」** 클릭 |
| **✅ 정상 결과** | ① `/broker` 대시보드 진입 ② 이름이 포함된 인사말 헤더 표시 ③ KPI 카드 스와이프 가능 |
| **💡 추가 확인** | 브라우저 종료 후 재접속 시 세션이 유지되는가? (쿠키 기반 자동 로그인) |
| **🏷️ 판정** | Pass ☐ / Fail ☐ |

#### A-5. 비밀번호 재설정 (복구 경로)

| 항목 | 내용 |
|---|---|
| **🖱️ 조작** | `/login` → **「비밀번호 찾기」** 클릭 → 가입 이메일 입력 → 메일함 확인 → 링크 클릭 → 새 비밀번호 입력 |
| **✅ 정상 결과** | ① `/reset-password` 페이지에서 이메일 전송 성공 메시지 ② 메일 내 링크로 `/update-password` 이동 ③ 비밀번호 변경 후 자동 로그인 |
| **⚠️ 비정상 신호** | 메일이 5분 내에 도착하지 않으면 이메일 발송 시스템 점검 필요 |
| **🏷️ 판정** | Pass ☐ / Fail ☐ |

### 👤 B. 프로필 설정 (Profile) — 중개인 브랜딩 기반

> **🧠 인지 프라이밍**: 프로필은 중개인의 "디지털 명함"입니다.
> 입력한 정보가 정확히 저장되고, AI가 전문 소개글을 생성하며, 공개 페이지에 깔끔하게 노출되는지 검증합니다.
>
> **📍 시작 위치**: 대시보드 → 좌측 메뉴 또는 하단 '더보기' → **「프로필 설정」** (`/broker/profile`)

> **⏱️ 예상 소요**: 8분

#### B-1. 기본 정보 저장

| 항목 | 내용 |
|---|---|
| **🖱️ 조작** | 이름, 연락처, 소속 회사명, 한줄 소개(Tagline) 수정 → **「저장」** 클릭 |
| **✅ 정상 결과** | ① 상단에 "저장되었습니다" 토스트 알림 (녹색) ② 페이지 새로고침 후에도 변경 내용 유지 |
| **📸 캡처** | 저장 성공 토스트 메시지 + 저장된 필드 화면 |
| **🏷️ 판정** | Pass ☐ / Fail ☐ |

### 📝 C. 메모 (Memo) — 현장 정보의 디지털 포획

>
> **📍 시작 위치**: 화면 우하단 **유니버설 메모 FAB 버튼** (🟡 원형 플로팅 버튼) 또는 `/broker/memos`

|---|---|
| **🖱️ 조작** | FAB 버튼 클릭 → 메모 팝업 열림 → "강남역 100억 빌딩 매각건, 수익률 4% 이상" 입력 → **「저장」** |
| **✅ 정상 결과** | ① 메모 리스트(`/broker/memos`)에 새 항목이 최상단에 추가됨 ② 작성 시각이 "방금 전"으로 표시 |
| **⚠️ 주의 관찰** | 5자 미만 입력 시 저장 버튼이 비활성화(disabled)되는가? |

#### C-2. 음성 메모 (STT)

| 항목 | 내용 |
|---|---|

## 💻 curl API 교차 검증 (Backend Check)

> UI 테스트 중 이상이 발견되면 아래 명령어로 백엔드 API 상태를 교차 검증합니다.

```bash
# ─── 환경 설정 ───
BASE="https://credeal.net"
# TOKEN: 브라우저 DevTools → Application → Cookies → sb-*-auth-token 에서 추출
TOKEN="<로그인_토큰>"

# ─── 1. 인증 가드 검증 (401 예상) ───
curl -s -o /dev/null -w "%{http_code}" $BASE/api/broker/profile
# → 401 (미인증 접근 차단 확인)

# ─── 2. 프로필 조회 ───
curl -s $BASE/api/broker/profile \
  -H "Authorization: Bearer $TOKEN" | jq '.display_name, .slug'

# ─── 3. 메모 저장 ───
curl -s -X POST $BASE/api/broker/memo/save \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"rawText":"강남역 오피스빌딩 매각 165억 연면적 450평"}'

# ─── 4. 모닝 인텔리전스 ───
curl -s "$BASE/api/broker/morning-intelligence?region=gbd" \
  -H "Authorization: Bearer $TOKEN" | jq '.briefing[0:2]'

# ─── 5. 고객 목록 ───
curl -s "$BASE/api/broker/clients?type=buyer&grade=vip" \
  -H "Authorization: Bearer $TOKEN" | jq '.clients | length'

# ─── 6. 헬스체크 ───
curl -s $BASE/api/health | jq '.status'

# ─── 7. 크론 엔드포인트 인증 검증 (401 예상) ───
for ep in consistency-check data-hygiene hold-expiry morning-briefing weekly-magazine; do
  echo -n "$ep: "
  curl -s -o /dev/null -w "%{http_code}" $BASE/api/cron/$ep
  echo
done
```
