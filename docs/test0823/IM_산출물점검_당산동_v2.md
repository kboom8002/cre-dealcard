## 2. 🔴 회귀 2 — PPTX p6 텍스트 절삭 파손

| 위치 | 1차판 | **신판** |
|---|---|---|
| 라벨 | "현재 연 순수익률 (Cap Rate)" | **"현재 연 순수익률 (Cap R"** |
| 값 | "2.08% (연간 실질 임대수입 2억 3,352만 원)" | "2.08%" |
| 401호 | "갱신요구권(7년 잔여)으로 인해 시세 대신 법정 5% 상한(273만 원) 적용" | **"5%"** |
| 정상화 | "2.99% (실투자금 기준 3.09%)" | "2.99%" |

**"Cap R"에서 끊긴 것이 결정적입니다.** 단어 중간 절삭이고, **닫는 괄호가 없어 문법도 깨졌습니다.**

**"5%"만 남은 것은 더 나쁩니다.** 「401호 법정 상한 규제 반영」이라는 라벨 아래 값이 "5%"입니다. 매수인은 **무엇이 5%인지 알 수 없습니다.**

### 2.1 원인 추정

D7 §10의 텍스트 예산이 적용되면서 **`statValue` 제한이 라벨·설명에 걸린 것**으로 보입니다.

```
"현재 연 순수익률 (Cap R"  = 20자    ← 20자 컷 의심
"5%"                              ← 정규식 추출 실패 가능성
```

**D7 §10.2가 권고한 `enforceTextBudget()`의 종결어미 인식 절삭이 적용되지 않았습니다.** 단순 `truncateText()`가 걸린 것으로 보이며, **`…` 표시도 없습니다.**

> 1차 점검에서 "산술은 정확하고 문제는 전제와 라벨"이라고 했는데, **이번엔 라벨 자체가 파손됐습니다.** 정보가 줄어든 것이 아니라 **틀린 정보가 됐습니다.**

### 7.1 이번 개선은 E 계층에서만 이뤄졌습니다

| 계층 | 손댄 흔적 | 결과 |
|---|:-:|---|

| B 환각 | ✗ | — |

**UI 껍데기(아이콘·지도·사진·뱃지·버튼)와 PPTX 문구 정리만 진행됐습니다.** 계산·검증·데이터 계층은 손대지 않았습니다.

### 8.1 1번 — 뱃지는 검증 결과와 연동되어야 합니다

```ts
// ❌ 현재 — 무조건 표시
<Badge>✓ 확인됨</Badge>

// ✅ 게이트·결손과 연동
const status = deficiencies.some(d => d.affects.includes(sectionType))
  ? { label: '확인 필요', tone: 'warn' }
  : violations.some(v => v.section === sectionType)
  ? { label: '정본 확인', tone: 'block' }
  : { label: '자료 확보', tone: 'ok' };
```

**당산동 기준으로는 7개 섹션 중 최소 4개가 "확인 필요"여야 합니다.**

// ❌ 단어 중간 절삭 · 표시 없음
