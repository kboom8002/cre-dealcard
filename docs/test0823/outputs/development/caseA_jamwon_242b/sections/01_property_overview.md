# 이 매물, 어떤 자산인가

**핵심 한줄 정의: test 소재, 1990년 준공(브로커 제공 정보 기준)의 지하 1층~지상 5층 규모 임대·리포지셔닝 검토 자산입니다.**  
대지면적은 약 616.1㎡, 연면적은 약 1,200㎡로 제공되었으며(모두 브로커 제공 정보 기준·건축물대장 확인 필요), 제2종일반주거지역 내 위치합니다.  
건물의 세부 용도 및 공적 규모는 건축물대장 확인이 필요하며, 현재 월 임대료 0원·공실률 100%로 제공되어 안정적 현금흐름 확보를 위해서는 [임차인 업종 정보로 대체됨] 유치와 임대차 조건 재구성이 핵심 과제입니다.  
공실 상태는 초기 안정화 기간이 필요하다는 의미인 동시에, 층별 MD 구성과 임대료 전략을 새롭게 설계해 임대수익을 극대화할 수 있는 리포지셔닝 여지를 제공합니다.
