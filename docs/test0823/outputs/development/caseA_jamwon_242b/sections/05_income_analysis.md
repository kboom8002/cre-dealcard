# 내 돈 넣으면 수익이 나오는 딜인가

### Income Analysis

본 자산은 **공실률 100%**로 제공되어 있어, 현 시점의 월 임대료는 **₩0**이며 기존 임대수익 기반의 NOI 및 Cap Rate는 산정할 수 없습니다. 매수자는 매매희망가 **₩24,226,800,000**을 기준으로, 선순위 대출금·임차보증금·월 대출이자 및 임대차 조건 확인 후 실투자금과 실제 월 순수익을 확정해야 합니다. 대지면적은 약 **616.1㎡(브로커 제공, 공적장부 확인 필요)**이나 공시지가가 제공되지 않아 토지 지분 가치 비중 및 원금 하방 안전판은 현재 산정 불가합니다.

| 핵심 현금흐름 지표 | 산식 | 금액 / 상태 |
|---|---:|---:|
| 매매 희망가 | - | **₩24,226,800,000** |
| 월 임대료 | - | **₩0** |
| 공실률 | - | **100%** |
| 실투자금(내 돈) | 매매희망가 − 선순위 대출금 − 보증금 합계 | 선순위 대출금·보증금 미제공으로 **산정 불가** |
| 월 순수익(통장 입금액) | 월 임대료 − 월 대출이자 | ₩0 − 월 대출이자 = **대출이자 확인 필요** |
| 연 순수익(NOI 기준) | 월 순수익 × 12 | **산정 불가** |
| 자기자본수익률 | (연 순수익 ÷ 실투자금) × 100 | **산정 불가** |
| Cap Rate | 연 NOI ÷ 매매 희망가 × 100 | 현 임대수익 ₩0 기준 **산정 불가** |
| 토지 지분 가치 비중 | 공시지가 기준 토지가치 ÷ 매매희망가 × 100 | 공시지가 미제공으로 **산정 불가** |
