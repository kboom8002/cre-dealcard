# 내 돈 넣으면 수익이 나오는 딜인가

### Income Analysis

현재 입력 기준 매수자는 **매매희망가 89.00억원에서 선순위 대출금 및 보증금 합계를 차감한 금액을 실투자금으로 투입**하며, 월 임대료가 **0원으로 입력**되어 있어 임대차·대출 조건 확정 전에는 월 순수익 및 수익률을 확정할 수 없습니다. 특히 월 순수익은 단순 임대료가 아닌 **월 임대료에서 월 대출이자를 차감한 실제 통장 입금액** 기준으로 판단해야 합니다. 대지면적은 **약 651.2㎡(제공정보 기준, 공적장부 확인 필요)**이나 공시지가가 미제공되어 토지 지분 가치 비중 및 원금 하방 안전판은 산정 불가하며, 공시지가 확인 후 즉시 검증이 필요합니다.

| 구분 | 산식 | 현재 확인값 / 산정 결과 |
|---|---:|---:|
| 매매 희망가 | - | **8,900,000,000원 (89.00억원)** |
| 선순위 대출금 | - | 미제공 |
| 보증금 합계 | - | 미제공 |
| **실투자금(내 돈)** | 매매 희망가 − 선순위 대출금 − 보증금 합계 | **8,900,000,000원 − 선순위 대출금 − 보증금 합계** |
| 월 임대료 | - | 0원 입력값 |
| 월 대출이자 | - | 미제공 |
| **월 순수익(통장 입금액)** | 월 임대료 − 월 대출이자 | **0원 − 월 대출이자** |
| 연 순수익 | 월 순수익 × 12 | **(0원 − 월 대출이자) × 12** |
| **자기자본수익률** | 연 순수익 ÷ 실투자금 × 100 | 대출이자·보증금 확정 후 산정 가능 |
| NOI | 연 임대수입 − 운영비용 | 임대수입·운영비 미제공으로 산정 불가 |
| **Cap Rate** | NOI ÷ 매매 희망가 × 100 | NOI 미확정으로 산정 불가 |
| **WACC** | 자본비용과 타인자본비용의 가중평균 | 대출금리·LTV·요구수익률 미제공으로 산정 불가 |

| 원금 안전성 검토 | 산식 | 현황 |
|---|---:|---:|
| 대지 지분 가치 비중 | 공시지가 기준 토지 가치 ÷ 매매 희망가 × 100 | 공시지가 미제공으로 산정 불가 |
| 하방 경직성 판단 | 공시지가 기준 토지 가치 및 건물·토지 가치 배분 검토 | 공시지가 및 토지이용계획 확인 필요 |
