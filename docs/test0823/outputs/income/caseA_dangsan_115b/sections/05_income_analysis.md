# 내 돈 넣으면 수익이 나오는 딜인가

**실투자금은 ₩6,100,000,000이며, 월 순수익(임대료 입금액 기준)은 연 이자율 *i%* 적용 시 `₩19,460,000 - (₩4,258,333 × i)`로 산정됩니다.** 즉, 대출 가능성과 조건은 금융기관 심사, 담보평가, 차주 신용도, 시장금리에 따라 달라질 수 있습니다. 전에는 월 대출이자를 차감한 실제 통장 입금액과 자기자본수익률을 확정할 수 없으나, 현재 월 임대료 기준 연 환산 임대수입은 ₩233,520,000입니다.
