# 내 돈 넣으면 수익이 나오는 딜인가

## Income Analysis

매수 희망가 **120억 원** 기준, 선순위 대출금·임대보증금·월 대출이자 정보가 제공되지 않아 **실투자금 및 통장 입금 기준 월 순수익은 확정 산출이 불가**합니다. 현재 입력된 월 임대료는 **0원**으로, 실제 임대차 현황 및 금융조건 확인 전에는 NOI·Cap Rate·자기자본수익률을 제시할 수 없습니다. 또한 개별공시지가가 미제공되어 대지지분의 공시지가 기준 가치 비중 및 원금 하방 안전판은 추가 확인이 필요합니다.

| 항목 | 산식 | 제공 데이터 기준 | 산출 결과 |
|---|---:|---:|---:|
| 매매 희망가 | - | 12,000,000,000원 | **120억 원** |
| 선순위 대출금 | - | 미제공 | 산출 불가 |
| 임대보증금 합계 | - | 미제공 | 산출 불가 |
| **실투자금(내 돈)** | 매매 희망가 - 선순위 대출금 - 보증금 합계 | 대출금·보증금 미제공 | **산출 불가** |
| 월 임대료 | - | 0원 입력 | 0원 |
| 월 대출이자 | - | 미제공 | 산출 불가 |
| **월 순수익(통장 입금액)** | 월 임대료 - 월 대출이자 | 대출이자 미제공 | **산출 불가** |
| 연 순수익 | 월 순수익 × 12 | 월 순수익 산출 불가 | 산출 불가 |
| **자기자본수익률** | (연 순수익 ÷ 실투자금) × 100 | 실투자금·연 순수익 미확정 | **산출 불가** |
| **NOI** | 연 임대수입 - 운영비 | 임대수입·운영비 미제공 | **산출 불가** |
| **Cap Rate** | NOI ÷ 매매 희망가 × 100 | NOI 미확정 | **산출 불가** |
| WACC | 자본·차입 비용의 가중평균 | 대출 조건 및 요구수익률 미제공 | 산출 불가 |

| 원금 안전성 검토 항목 | 확인 현황 | 판단 |
|---|---|---|
| 대지면적 | 약 661.16㎡(브로커 제공) | 공시지가 확인 필요 |
| 대지 공시지가 가치 | 미제공 | 산출 불가 |
| **토지 지분 가치 비중** | 대지 공시지가 가치 ÷ 매매 희망가 × 100 | **개별공시지가 확인 후 산출 필요** |
| 하방 안전성 | 토지 공시지가 기반 가치 비중 확인 필요 | 현 단계 정량 판단 불가 |
