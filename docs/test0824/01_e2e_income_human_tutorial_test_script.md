## 1. 테스트 개요 및 사전 준비

### 1.1 테스트 목적
렌트롤 3단계 입력(R1/R2/R3) → 등급 기반 단일 IM 생성 → 승인 → 공개 전체 파이프라인을 검증합니다.
이번 세션 수정사항(등급 버그, IM 통합, K-익명성, 마크다운, LTV, 렌트롤 양식)의 회귀 테스트를 포함합니다.

### 1.2 테스트 환경
- **URL**: `https://credeal.net` 또는 `http://localhost:3000`
- **브라우저**: Chrome 최신 (1920×1080), 모바일 뷰어는 DevTools 390×844

### 1.3 사전 준비 파일
- `docs/imup/05_data/xlsx/CREDEAL_렌트롤_표준양식_v1.2.xlsx`
- `docs/imup/05_data/xlsx/CREDEAL_렌트롤_당산동_실측.xlsx`
- `docs/imup/05_data/xlsx/CREDEAL_렌트롤_양평동_실측.xlsx`

## 2. 렌트롤 3대 티어 정의

| 티어 | 명칭 | 입력 항목 | 기대 등급 |
|:---:|:---:|---|:---:|
| **R1** | 최소형 | 총 보증금 + 총 월임대료 + 공실률 | C~B등급 |
| **R2** | 필요형 | 호실별 텍스트 → AI LLM 파싱 | B등급 |
| **R3** | 완전형 | v1.2 XLSX 3-Sheet 업로드 | B~A등급 |

**핵심 규칙**: 구조화된 렌트롤(R3) 없이는 **A등급 도달 불가** (이번 세션 수정)

## 3. Case A: 당산동 115억 메디컬빌딩

### A-1. 기본 메모 등록 & 슬롯 추출

1. `[딜카드 등록]` → `[메모로 생성]` 클릭
2. 아래 텍스트 전체 복사·붙여넣기:

```text
[2025-05 현장 · 2025-05 매도인 면담 · 2025-05 임차인 현황 확인]

당산역(2호선/9호선) 도보 5분. 배후에 아파트 단지가 밀집해 있어 상권 배후가 두껍다.
국회대로·올림픽대로 접근이 좋고, 영등포구청·국회의사당 권역이라 유동도 안정적이다.

2002년 준공인데 관리 상태가 깨끗하다. 로비·복도·EV 다 손볼 데가 없다.
자주식 8대 주차에 전면 도로도 넉넉하다.

임차 구성이 이 물건의 핵심이다. 로뎀나무내과가 1F·2F·5F를 쓰고, 1F에 고은약국이
붙어 있다. 병원+약국 조합이라 공실 리스크가 낮고 회전이 없다.
3F 헬스장, 4F 국제와인. B1은 데이르 카페인데 소유주 자가 사용이고, 4F 일부도 자가다.

문제는 임대료다. 약국·내과는 11년째 인상이 없었다. 현재 월세 총 1,946만원인데
기준층(3F) 단가 62.4천원/평에 맞춰 재산정하면 2,867만원까지 올라간다. 47% 차이다.

자가 사용분 두 곳(B1 전체, 4F 일부)을 임대로 돌리는 것만으로도 상당 부분 채워진다.
매입 후 임대료 현실화를 전제로 보면 기대 수익률 연 3.1%.

토지 평당 75백만원. 인근 조사해보니 입지·부지 양호한 건 130~160백만원,
불리한 건 85~100백만원 선이다. 우리 물건은 그 아래다. 가격 경쟁력이 확실하다.

준공업지역인데 서울시가 2024년 10월에 제도개선 방안을 냈다. 지구단위계획 수립 시
주거용도 용적률 400%까지, 준주거/3종일반주거로 용도지역 변경도 추진 중이다.
현 용적률이 221.8%(지상 기준)라 여유가 크다.

등기가 층별구분등기다. 소유주가 형제 두 분인데 전체 매각에 두 분 다 동의하셨다.
매매희망가 115억.
```

3. **[AI 슬롯 추출] 클릭**
4. **추출 결과 확인** — 메모에 실제 존재하는 정보만 검증:

| 슬롯 항목 | 메모 내 근거 | 기대 결과 | 비어있어도 정상? |
|---|---|---|:---:|
| 매매희망가 | "매매희망가 115억" | **115억 원** | ❌ 필수 |
| 월 임대료 | "월세 총 1,946만원" | **1,946만 원** | ❌ 필수 |
| 포스처 | 임대수익 맥락 전반 | **income** | ❌ 필수 |
| 주소 | **(메모에 지번 없음)** | 비어있음 또는 "당산역 인근" | ✅ 정상 |
| 보증금 | **(메모에 총액 없음)** | 비어있음 | ✅ 정상 |
| 준공연도 | "2002년 준공" | 2002년 | △ 보너스 |
| 용도지역 | "준공업지역" | 준공업지역 | △ 보너스 |
| 주차 | "자주식 8대" | 자주식 8대 | △ 보너스 |

5. **메모 파싱 완료 팝업** 확인:
   - [ ] 팝업 텍스트가 다크 배경에서 **잘 보이는 색상**인가?
   - [ ] **[SSoT 슬롯 결과 보기]** 버튼 존재 여부

### A-2. R1 최소형 렌트롤 테스트

1. 딜카드 → **`[⚡ IM 생성]`** 버튼 클릭 (단일 버튼 확인 — `Basic IM`/`Pro IM` 아님)
2. 바텀시트 제목: **`📊 투자설명서(IM) 만들기`** 확인
3. 렌트롤 영역:
   - `총 월임대료`: 1,946만 원 자동 반영?
   - `총 보증금`: 메모에 없으므로 **빈 상태가 정상**
4. R1 단계 등급: **B등급 이하** (A등급이면 등급 버그)

---

### A-3. R2 필요형 렌트롤 테스트 (LLM 파싱)

1. 바텀시트 → `[텍스트/메모로 입력]` 탭
2. 아래 텍스트 붙여넣기:

```text
B1 카페(자가운영) 전용 96평 임대료 없음 소유자직접운영
1F 101호 고은약국 전용 23.7평 보증금 6000만원 월세 183만원 계약 2015-09-01 ~ 2026-08-31
1F 102호 로뎀나무내과 31.9평 보증금 1억4천 월세 883만원 1F+2F 통합계약 2026-08-31 만기
2F 201호 로뎀나무내과 76.3평 보증금 0 월세 0 (1층에 합산)
3F 301호 헬스장 76.3평 보증금 5000만원 월 455만원 2026-04-17 만기
4F 401호 국제와인 51.1평 보증금 3000만원 월 260만원 2025-04-30 만기
4F 402호 소유자 자가사용 25.1평 보증금/월세 없음
5F 501호 로뎀나무내과 55.6평 보증금 1000만원 월 165만원 2026-08-31 만기
```

3. **[AI 렌트롤 파싱 실행]** 클릭
4. 합계 검증: 월세 **1,946만** / 보증금 **29,000만 (2.9억)** / 자가 **2건**

### A-4. R3 완전형 렌트롤 테스트 (엑셀 업로드)

1. **[📥 빈 양식]** 버튼 클릭:
   - [ ] 파일명 `CREDEAL_렌트롤_표준양식_v1.2.xlsx`로 다운로드?
   - [ ] 셀 서식/색상/드롭다운이 포함된 원본 파일? (단순 헤더만 아님)
2. `CREDEAL_렌트롤_당산동_실측.xlsx` 업로드 → 덮어쓰기 승인

### A-5. 등급 산정 & IM 생성

| 단계 | 기대 등급 |
|---|:---:|
| R1 (메모만) | **C등급** |
| R2 (텍스트 파싱) | **B등급** |
| R3 (엑셀) + 사진 | **B~A등급** |

- [ ] **A등급은 R3 + 매매가 + 사진 모두 있을 때만** 달성되는가?

### A-6. IM 승인 검토 플로우

1. `/broker/im-approval/[id]` 진입
2. **제목 편집**: "핵심 입지 상가빌딩 매각"은 fallback — **편집 가능** input인가?
3. **서브제목**: "예: 연 수익률 6.4%..."은 **placeholder** — 실제값은 비어있음
4. **마크다운 렌더링**: 본문에 `###` 기호가 raw 텍스트로 안 보이는가?
5. **LTV 경고**: `⚠️ 대출금 미입력 → AI 가정` 표시되는가?
6. **K-익명성**: 8개 섹션 확인 후 승인 시 `❌ K-익명성 검증 실패` **안 나오는가?**
7. IM 상태 `published` 정상 전환?

### A-7. 모바일 IM 뷰어 검증

- [ ] Hero 카드 수치에 NaN/undefined 없음
- [ ] 7개 섹션 정순서 (자산→입지→임대→수익→리스크→논지→다음단계)
- [ ] 허위 하드코딩 문구 0건
- [ ] `###` 마크다운 잔재 0건
- [ ] `Basic IM` / `Pro IM` 문구 0건
- [ ] `연 순수익률 (Cap Rate)` 표준 용어 사용

## 4. Case B: 양평동 250억 더레드빌딩

선유도역 9호선 4번출구에서 도보 1분. 대로변이고 초역세권이다.

선유도역 대로변이라 사무실 임차 수요가 풍부하다. 안정적인 임대수익이 기대된다.
현재 지하 1층만 공실이다.

보증금 5억 3,500만원, 월 임대료 5,017만원, 관리비 648만원.
매매가 250억, 평당 1억 5,923만원.

준공업지역이고 공시지가가 ㎡당 948만 4천원(평당 3,135만원, 2023년 1월 기준)이다.
