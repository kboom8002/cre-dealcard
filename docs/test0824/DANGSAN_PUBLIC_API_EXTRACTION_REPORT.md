   - 대단지 아파트/복합건물 총괄표제부 주차 대수(2,504대)가 오염되던 것을 차단하고, 본 자산 단일 표제부의 **`자주식 8대`**로 정확히 반영.
3. **단가 벤치마킹 기준 표준화 (QA-BASIS-02)**:
   - 분자(연면적)와 분모(토지면적)를 혼동하여 발생하던 왜곡을 제거하고, **토지 평당 7,492만 원 (vs 인근 토지 실거래 1.3억~1.6억)** 및 **연면적 평당 3,331만 원 (vs 인근 연면적 실거래 3.25천~3.9천)**으로 기준(basis)을 엄격히 분리 표기.
4. **신뢰 신호 뱃지 격리 (QA-BADGE-01)**:
   - 미확인 데이터나 결손이 존재하는 섹션에 무분별하게 붙던 `✅ 공부확인` 뱃지를 완전 격리하여, 실제 공공데이터 검증이 완료된 섹션에만 조건부 노출.
5. **재무 수지 및 레버리지 수익률 분석 (QA-LEV-01, QA-LEV-02)**:
   - 매매가 115억, 보증금 2.9억, 월세 1,946만 원 기준 무차입 총수익률(2.03%)이 대출금리(4.5%)보다 낮아 발생하는 **역레버리지 현상을 정확히 명시**하고, 허위 과장 ROE를 완전 제거.
