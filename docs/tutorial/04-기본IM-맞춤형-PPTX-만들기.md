# 제4장. 기본 IM(맞춤형 PPTX 투자설명서) 만들기 — 다필지·수익률·렌트롤 완벽 지원

> **소요 시간**: 약 3분 | **관련 화면**: `/broker/buildings` (🏢 내 물건에서 IM 만들기)
> 딜카드 화면 하단의 [⚡ 기본 IM 만들기] 버튼만 누르면 정부 토지·건축물대장, V-World 연속지적도, 10년 공시지가, 실거래 사례를 자동으로 모아 8~12장 분량의 고품질 파워포인트(PPTX) 제안서를 만들어 드립니다.

## 🎯 이 장에서 꼭 기억하실 핵심 포인트

- **① 투자 목적(💰 임대수익 · 🏢 자가사용 · 🏗️ 신축/리모델링 · 🏨 운영형 · 📈 매매차익)을 고르면 그 목적에 꼭 맞는 입력칸과 슬라이드 구성이 자동으로 준비됩니다.**
- **② 주소를 검색하면 토지·건축물대장이 자동 연결되며, '양평동4가 117 외 2필지(134, 125-2)' 같은 다필지 합산도 손쉽게 처리됩니다.**
- **③ 매각가(+100억/+10억/+1억 버튼), 층별 임대현황(또는 v1.5 엑셀 파일 업로드), 매물 사진을 넣고 [⚡ IM 생성]을 누르면 약 45초 만에 완성됩니다.**

> 🎬 **따라하기 동영상**: [🎬 [따라하기 영상 3] 양평동 다필지 수익형 빌딩(250억) 기본 IM 만들기 전 과정](./videos/video-03-basic-im-generation.webm)

## [4-1단계] [⚡ 기본 IM 만들기] 클릭 후 ① 투자 목적 선택 & ② 주소·다필지 대장 연결

![기본 IM 입력 시트 상단: ① 투자 목적 5종 선택 및 ② 양평동4가 다필지 주소·건축물대장 자동 연결](./images/step-04-bottomsheet-posture-address.png)
*▲ [화면 안내] 기본 IM 입력 시트 상단: ① 투자 목적 5종 선택 및 ② 양평동4가 다필지 주소·건축물대장 자동 연결*

1. **👆 어디를 누르거나 입력하나요?**
   딜카드 상세 화면의 노란색 [⚡ 기본 IM 만들기] 버튼을 누른 뒤, 열리는 입력 시트 상단 3단계 진행 탭을 확인하고 ① 투자 목적([💰 임대수익 (추천)], [🏢 자가사용(사옥)], [🏗️ 신축·리모델링] 등)을 고른 뒤 ② 주소 입력란을 확인합니다.

2. **✅ 화면에서 무엇이 바뀌나요?**
   주소를 입력하고 검색하면 정부 건축물대장·토지대장에서 대지면적, 연면적, 층수, 준공연도, 용도지역을 자동으로 불러옵니다. 특히 영등포구 양평동4가 117번지처럼 여러 필지(117, 134, 125-2번지)로 이루어진 다필지 건물의 경우, 부속 필지가 함께 표시되며 합산 대지면적(518.7㎡, 약 157평)이 자동 계산됩니다.

3. **💡 왜 이 기능이 중요한가요? (중개 실무 포인트)**
   등기부나 건축물대장을 일일이 떼서 손으로 옮겨 적다가 오타가 나는 일을 원천 차단하고, 다필지 지번도 제안서 토지 슬라이드에 깔끔한 번지 표로 자동 수록됩니다.

   > 📌 **따라하기 꿀팁**: 입력 시트 맨 위의 [① 기본·가격], [② 임대차(선택)], [③ 사진·생성] 알약 버튼을 누르시면 긴 화면을 일일이 스크롤하지 않고도 원하는 위치로 한 번에 이동합니다!

## [4-2단계] ③ 매각 희망가 빠른 입력(+100억/+10억) 및 한글 금액 · 목표 수익률 역산 확인

![매각 희망가 빠른 금액 버튼(+100억/+10억/+1억)과 보증금·월 임대료 한글 실시간 표시 화면](./images/step-04-bottomsheet-price-yield.png)
*▲ [화면 안내] 매각 희망가 빠른 금액 버튼(+100억/+10억/+1억)과 보증금·월 임대료 한글 실시간 표시 화면*

1. **👆 어디를 누르거나 입력하나요?**
   ③ 매각 희망가 입력칸에 금액(만원 단위)을 입력하거나, 바로 아래에 있는 [+100억], [+10억], [+1억], [초기화] 빠른 합산 버튼을 클릭합니다.

2. **✅ 화면에서 무엇이 바뀌나요?**
   숫자 '0' 개수를 세느라 눈이 피로할 필요 없이 [+100억] 두 번, [+10억] 다섯 번을 누르면 '250억 원 (2,500,000만 원)'이 정확히 입력되며 입력칸 아래에 파란색 큰 글씨로 한글 금액이 실시간 표시됩니다. 또한 오른쪽 [목표 수익률 역산(예: 3.5%, 4.0%, 4.5%)] 버튼을 누르면 현재 월세 기준으로 적정 매각가가 얼마인지 즉시 계산해 보여줍니다.

3. **💡 왜 이 기능이 중요한가요? (중개 실무 포인트)**
   100억대 이상 빌딩에서 '0' 하나를 잘못 쳐서 25억이나 2,500억으로 표기되는 치명적인 실수를 완벽히 예방합니다.

4. **⚠️ 자주 하시는 실수 & 안심 예방법**
   금액 입력칸의 기본 단위는 '만 원'입니다(예: 115억 = 1,150,000만 원). 직접 숫자를 치실 때는 반드시 아래쪽에 파란 글씨로 뜨는 '한글 금액 확인(예: 115억 원)'을 눈으로 확인해 주세요.

## [4-3단계] 층별 임대현황(렌트롤) 입력/엑셀 업로드 및 사진 지정 후 [⚡ IM 생성]

![층별 임대현황(렌트롤) 입력표, 사진 ★대표/🏢외관 지정 및 하단 [⚡ IM 생성] 버튼](./images/step-04-bottomsheet-rentroll-photos.png)
*▲ [화면 안내] 층별 임대현황(렌트롤) 입력표, 사진 ★대표/🏢외관 지정 및 하단 [⚡ IM 생성] 버튼*

1. **👆 어디를 누르거나 입력하나요?**
   층별 임대차 현황 표를 확인(또는 [📊 엑셀(xlsx) 렌트롤 업로드] 버튼으로 v1.5 표준 양식 첨부)하고, 아래 사진 영역에서 건물 사진을 올린 뒤 가장 잘 나온 사진의 [★ 대표]와 [🏢 외관] 버튼을 누르고 맨 아래 노란색 [⚡ IM 생성] 버튼을 클릭합니다.

2. **✅ 화면에서 무엇이 바뀌나요?**
   • 층별 임대현황: 양평동 더레드빌딩(B1 공실, 1F 스타벅스 보증금 7,600만/월세 715만, 2F~10F 우량 임차인)이나 당산동 호산당빌딩(1F 약국·내과 통합계약 등)의 층별 내역이 표로 정리됩니다.
   • 사진 자동 분류: 사진을 여러 장 올리면 AI가 외관·로비·내부·주변을 자동 분류하고, 제안서 표지에 들어갈 [★ 대표] 사진과 물건 개요에 들어갈 [🏢 외관] 사진을 지정할 수 있습니다.
   • [⚡ IM 생성] 클릭 시 6단계 진행 안내와 함께 약 40~50초 만에 제안서가 완성됩니다.

3. **💡 왜 이 기능이 중요한가요? (중개 실무 포인트)**
   1층·2층 통합계약이나 자가사용 층, 공실 층이 섞여 있어도 크리딜 엔진이 중복 합산 없이 현행 수익률(As-Is)과 만실 가정 안정화 수익률(Stabilized)을 정확히 계산해 줍니다.

   > 📌 **따라하기 꿀팁**: 층별 면적 입력 시 ㎡(제곱미터)와 평(坪) 단위를 선택해 넣으실 수 있으며, 공적장부 층별 면적과 비교해 자동 검증됩니다. 매도인 렌트롤이 PPT·사진 캡처뿐이라면 [준비편 3~4단계]의 AI 챗봇 변환 지시문으로 표준 엑셀을 5분 만에 만드실 수 있습니다.

## [4-4단계] [비수익형 매물 팁] 사옥(자가사용) · 신축 개발부지 선택 시 맞춤형 입력칸 전환

![투자 목적을 [🏢 자가사용(사옥)]이나 [🏗️ 신축·리모델링]으로 바꾸었을 때 전환되는 맞춤형 입력 화면](./images/step-04-bottomsheet-owner-dev-mode.png)
*▲ [화면 안내] 투자 목적을 [🏢 자가사용(사옥)]이나 [🏗️ 신축·리모델링]으로 바꾸었을 때 전환되는 맞춤형 입력 화면*

1. **👆 어디를 누르거나 입력하나요?**
   임대수익 목적이 아닌 법인 사옥용 빌딩이나 노후 신축 부지 매물일 때는, 맨 위 ①번 단계에서 [🏢 자가사용(사옥)] 또는 [🏗️ 신축·리모델링] 버튼을 클릭합니다.

2. **✅ 화면에서 무엇이 바뀌나요?**
   • [🏢 자가사용(사옥)] 선택 시: 복잡한 월세 입력 대신 '즉시 입주(명도) 가능 면적/층수', '주차 가능 대수', '임직원 출퇴근 교통 강점' 입력칸이 나타납니다.
   • [🏗️ 신축·리모델링] 선택 시: '다필지 합산 대지면적', '목표 용적률(%)', '신축 계획 주용도 및 연면적' 입력칸으로 즉시 바뀝니다.

3. **💡 왜 이 기능이 중요한가요? (중개 실무 포인트)**
   월세가 없는 공실 사옥이나 나대지 매물인데도 억지로 임대료를 넣어야 하는 불편함이 전혀 없으며, 사옥·개발 전용 PPTX 슬라이드가 맞춤 생성됩니다.

## [4-5단계] [고급 편집 팁 ①] [중개인 추가 정보 (선택)] 열기 → '매입 후 전략(+ 전환 호실 추가)' 입력으로 안정화 기대수익률 완성하기

![[중개인 추가 정보 (선택)] 안의 [+ 전환 호실 추가] 버튼으로 공실·자가사용 층의 매입 후 임대 전환 전략을 입력하는 화면](./images/step-04-bottomsheet-rentroll-photos.png)
*▲ [화면 안내] [중개인 추가 정보 (선택)] 안의 [+ 전환 호실 추가] 버튼으로 공실·자가사용 층의 매입 후 임대 전환 전략을 입력하는 화면*

1. **👆 어디를 누르거나 입력하나요?**
   입력 시트 아래쪽의 [중개인 추가 정보 (선택)] 막대를 클릭해 펼친 뒤, 아래 [매입 후 전략 (안정화 기대수익률 산출)] 영역에서 우측 상단 [+ 전환 호실 추가] 버튼을 눌러 [층(예: B1, 4F, 7F) | 전환 구분(공실 → 임대 / 자가사용 → 임대) | 보증금(만원) | 월세(만원)] 4칸을 채웁니다(필요시 바로 아래 '추가 전략 메모'와 '목표 임대료(평당 만원/월)'도 함께 입력).

2. **✅ 화면에서 무엇이 바뀌나요?**
   • 입력 즉시 파란 안내 상자에 '합산 전환 보증금 +6,000만원 · 전환 월세 +540만원 (안정화 기대수익률 자동 반영)'처럼 합산 금액이 표시됩니다.
   • [02 요약 슬라이드]: 우측 상단 5번째 핵심 지표 카드가 '안정화 기대수익률 2.75% (현행 2.08% 대비 +0.67%p)'로 자동 표시되며, 3대 핵심 투자 포인트 #03에도 매입 후 임대 전환 전략이 자동 수록됩니다.
   • [06 렌트롤 슬라이드]: 하단 강조 박스에 '매입 후 전략 — 전환 시 안정화 기대수익률 2.75% (현행 2.08% 대비 +0.67%p) · 중개인입력' 제목과 함께 호실별 예상 보증금·임대료가 깔끔하게 정리됩니다.
   • [07 수익률 슬라이드]: 어려운 영문 'Cap Rate' 대신 한국 투자자에게 친숙한 '안정화 기대수익률(2.75%)'을 중심으로 표가 구성되고, 우측에는 한국부동산원(R-ONE) 해당 구(區) 10년 평균 지가변동률과 합산한 '운영수익률 + 자본수익률 = 단순 합산 기대수익률' 배너가 자동으로 완성됩니다.

3. **💡 왜 이 기능이 중요한가요? (중개 실무 포인트)**
   서울 역세권 빌딩은 현행 임대수익률만 보면 2~3%대로 낮아 보이지만, 공실(예: 쌍림동 B1 78평 공실, 창신동 5F 공실)·자가사용 층(예: 당산동 5F, 쌍림동 7F) 임대 전환 후의 '안정화 기대수익률'과 10년 평균 '토지 가치 상승률(자본수익률)'을 함께 제시하면 매수 고객의 투자 결정을 훨씬 빠르게 이끌어낼 수 있습니다.

5. **📋 바로 복사해서 따라 해보는 실전 문구 예시 (수익형 매입 후 전략(추가 전략 메모) 입력 예시 복사하기)**
   ```text
   4층(42평·현 창고/공실) 근린생활시설 임대 전환 시 보증금 3,000만 / 월 200만 원 추가 확보 가능
   5층(65평·현 소유주 자가사용) 임대 전환 시 보증금 3,000만 / 월 340만 원 추가 확보 가능
   ```

*▲ [화면 안내] 인근 매물 주소와 가격만 붙여넣고 [자동채움]을 누르면 도로·역세권·토지/연면적·평당가·본건 대비 할인율까지 9열로 자동 완성되는 시세 비교 기능*

1. **👆 어디를 누르거나 입력하나요?**
   같은 [중개인 추가 정보 (선택)] 서랍 안의 [인근 시세 비교 (최대 5행)]에서 ① [텍스트/표 붙여넣기] 버튼을 눌러 디스코·밸류맵·기존 제안서의 인근 실거래/매물 줄을 붙여넣고 ② [붙여넣기 반영]을 누른 뒤, ③ 추가된 각 행 우측의 파란색 [자동채움] 버튼을 클릭합니다. 지구단위계획이나 개발행위허가제한이 있는 매물은 바로 위 [규제·계획 메모 (최대 3건)]에서 [+ 추가]를 눌러 입력합니다.

2. **✅ 화면에서 무엇이 바뀌나요?**
   • [인근 시세 비교 자동채움]: '쌍림동 258 실거래 30억', '묵정동 29-6 매물 56억'처럼 주소와 가격만 붙여넣어도 실거래/매물 구분과 평당가가 자동 분리되고, [자동채움] 클릭 시 V-World·건축물대장·카카오맵을 즉시 조회해 도로 조건(대로변/중로각지), 지하철역 도보 시간, 토지면적(평), 연면적(평), 토지평당가(만원), 본건 대비(%)까지 9개 열을 2초 만에 채워 넣습니다!
   • [08 인근 시세 비교 슬라이드]: '구분 | 소재지 | 도로 | 지하철 | 토지면적(평) | 연면적(평) | 가격(억) | 토지평당가(만원) | 본건 대비' 9개 열이 빈칸 없이 꽉 찬 비교표와 본건 대비 요약 배너로 출력됩니다.
   • [규제·계획 메모 → 05 토지 정보 통합]: '지구단위계획(불허용도·건폐/용적 한도)'이나 '개발행위허가제한(근거·제한행위·기한 — 예: 창신1구역 도시환경정비 예정구역)'을 입력하고 '입지 설명'에 주간선도로·상권 특징을 한 줄 덧붙이면, 별도 슬라이드로 흩어지지 않고 04번 입지 슬라이드와 05번 토지이용계획확인원 표('중개인 확인 사항' 행)에 공문서 서식 그대로 통합됩니다.

3. **💡 왜 이 기능이 중요한가요? (중개 실무 포인트)**
   주변 매물 3~5건의 도로·지하철·토지면적·연면적·평당가를 일일이 대장 떼서 계산기로 나누던 1시간짜리 수작업이 '[텍스트/표 붙여넣기] → [붙여넣기 반영] → [자동채움] 클릭' 5초로 단축됩니다.
