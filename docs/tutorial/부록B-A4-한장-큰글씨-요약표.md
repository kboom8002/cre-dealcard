# 부록 B. 모니터 옆에 붙여두는 A4 1장 큰글씨 요약표 (Cheat Sheet)

> 💡 **이 페이지만 인쇄하셔서 사무실 모니터 옆에 붙여두시면 언제든 10초 만에 따라 하실 수 있습니다.**

### ⓪ IM 전 렌트롤 준비 — AI 챗봇으로 5분 변환 (준비편)
1. IM 입력 시트 렌트롤 상자에서 **`[📥 빈 양식]`** 내려받기
2. ChatGPT·Claude·Gemini에 매도인 자료(엑셀·PPT·사진 캡처) 올리기 → 설명서 준비편 3단계 **`[변환 지시문]`** 복사해 붙여넣기
3. AI가 준 16열 표를 복사 → 빈 양식 **'렌트롤' 시트 A13 칸** 클릭 후 **`Ctrl + V`** → C3·C4·C5·G9(㎡/평)·J3·J4 칸 채우고 저장
4. **`[엑셀/CSV 업로드]`** → **'v1.5'** 표시와 **보증금·월세·관리비 합계**를 원본과 대조 (주택 임차인 실명·연락처는 AI에 올리기 전에 지우기)

### ① 1분 딜카드 만들기 (소요시간 1분)
1. 상단 메뉴바 **`[➕ 새 물건 등록]`** 클릭
2. 카톡 매물 메모 복사(**`Ctrl + C`**) 후 입력창에 붙여넣기(**`Ctrl + V`**)
3. 우측 하단 파란색 **`[1분 딜카드 만들기]`** 클릭
4. **`[✏️ 딜카드 제목 · 카톡 공유 문구 직접 다듬기]`** 확인 후 **`[카톡 공유]`** 또는 **`[링크 복사]`**

### ② PPTX 제안서 · 기본 IM 만들기 & 슬라이드 편집 스튜디오 (소요시간 3분)
1. 딜카드 화면 맨 아래 노란색 **`[⚡ 기본 IM 만들기]`** 클릭
2. **① 투자 목적**(임대수익 / 자가사용 / 신축·리모델링) 선택 → **② 주소 검색**(다필지 지번·면적 자동 합산)
3. **③ 매각 희망가**(`+100억` / `+10억` 버튼) · 층별 임대현황(또는 엑셀 업로드) · 사진 등록(`★ 대표` / `🏢 외관`) 후 **`[⚡ IM 생성]`** 클릭
4. 완성 화면에서 황금색 **`[📐 슬라이드 미리보기 · 편집 후 다운로드]`** 클릭 → **10종 색상 테마 미리보기·글자 클릭 수정·AI 문구 다듬기** 후 **`[📥 편집 반영 PPTX 다운로드]`** (급할 때는 **`[⚡ PPTX 바로 다운로드]`** 클릭)

### ③ 주간 고객 소식지 5분 발행 (매주 월·화요일 아침 추천)
1. 상단 메뉴바 **`[📰 고객 소식지]`** 클릭 (5분 간단 모드 자동 실행)
2. **① 이번 주 한마디**: 시작 문장 추천 버튼 클릭 후 1~2문장 작성 (제목·3줄 요약·수익률 계산기 자동 포함)
3. **② 소개할 매물 & 관심 뉴스 3선**: 추천 매물(최대 3건) 체크 후 **`[✨ 부동산·경제·문화 황금배합 3선 자동 맞춤]`** 클릭 (🏢부동산 · 📈경제/금리 · ⚖️절세/상속 · 🎨문화/라이프 · ☕상권/트렌드 5대 채널에서 자유 선택 가능)
4. 하단 파란색 **`[🚀 이번 주 매거진 발행하기]`** 클릭 후 카카오톡·이메일 전송

### ④ 평생 써먹는 컴퓨터 단축키 & 안심 조작법 4가지
- **글씨 크게 확대**: 키보드 **`[Ctrl]`** 누른 채 **마우스 바퀴(휠) 위로 굴리기** (원래 크기는 `Ctrl + 0`)
- **복사 / 붙여넣기**: **`[Ctrl + C]`** (복사) → **`[Ctrl + V]`** (붙여넣기)
- **눈이 편한 밝은 화면**: 상단 우측 **`[☀️ 큰글씨 밝은 화면 (켜짐)]`** 버튼 확인
- **길을 잃었을 때**: 어느 화면에서든 상단 왼쪽 첫 번째 **`[🏠 홈 화면]`** 클릭
