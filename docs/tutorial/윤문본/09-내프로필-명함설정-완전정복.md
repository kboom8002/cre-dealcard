> 대표님의 성함, 전화번호, 중개사무소 상호, 사진, 자격증 번호가 각각 어디에 인쇄되는지 하나씩 설명합니다. 딜카드, PPTX 제안서 표지, 고객 소식지에 들어가는 위치를 차례로 짚어 봅니다.

## 🎯 이 장에서 꼭 기억하실 핵심 포인트

- **가장 중요한 [① 필수 기본 명함 정보 3가지(성함 · 전화번호 · 중개사무소 상호)]만 정확히 적어 두면 모든 제안서와 딜카드의 명함이 자동으로 완성됩니다.**

## [9-1단계] ① 가장 중요한 기본 명함 정보(사진 · 성함 · 연락처 · 상호 · 한줄 소개) 입력하기

![내 프로필 설정 상단: ① 어디에 표시되는지 알려주는 안내 배너, ② 필수 기본 명함 정보 입력란, ③ 상단 즉시 저장 버튼](./images/step-09-profile-top-essential.png)
*▲ [화면 안내] 내 프로필 설정 상단: ① 정보가 어디에 표시되는지 알려 주는 안내 띠, ② 필수 기본 명함 정보 입력란, ③ 상단 즉시 저장 버튼*

1. **👆 어디를 누르거나 입력하나요?**
   하단 바 [더보기] → [내 프로필 · 사무소 정보]로 들어가세요. 상단에 노란 테두리로 표시된 [① 기본 명함 정보] 상자에서 사진, 성함, 전화번호, 중개사무소 상호, 명함 한줄 소개를 입력하세요.

2. **✅ 화면에서 무엇이 바뀌나요?**
   • 성함 (예: 홍길동 대표공인중개사): PPTX 제안서 첫 장 표지 하단, 마지막 장 담당자란, 딜카드 하단, 소식지 상단에 인쇄됩니다.
   • 휴대폰/사무실 전화번호 (예: 010-1234-5678): 숫자만 입력해도 하이픈(-)이 자동으로 들어갑니다. 고객이 휴대폰에서 [전화 문의]를 누르면 바로 이 번호로 연결됩니다.
   • 중개사무소 상호 (예: 양평 삼성 공인중개사사무소): 제안서 표지의 기관명과 매수자용 웹 화면 상단에 표시됩니다.
   • 명함 한줄 소개: 카카오톡으로 명함이나 소식지를 보낼 때 제목으로 표시됩니다.

3. **💡 왜 이 기능이 중요한가요? (중개 실무 포인트)**
   처음 시작할 때 이 1번 상자만 채우고 [💾 변경사항 저장]을 눌러 두세요. 앞으로 만드는 수백 개의 딜카드와 PPTX 제안서에 대표님의 명함이 자동으로 들어갑니다.

## [9-2단계] ② 자격/등록번호 · ③ 전문 지역/자산 · ⑧ [✨ AI로 자기소개 자동 작성하기] 후 저장

![내 프로필 하단: 전문 지역·자산 버튼 선택(✓), ① [✨ AI로 자기소개 자동 작성하기], ② [💾 내 프로필 저장하기]](./images/step-09-profile-details-and-bio.png)
*▲ [화면 안내] 내 프로필 하단: 전문 지역·자산 버튼 선택(✓), ① [✨ AI로 자기소개 자동 작성하기], ② [💾 내 프로필 저장하기]*

1. **👆 어디를 누르거나 입력하나요?**
   화면을 아래로 내려 공인중개사 자격증 번호와 개업 연도를 입력하세요. 주로 활동하는 지역(예: 영등포구, 강남구, 서초구)과 건물 종류(꼬마빌딩, 오피스빌딩, 근린상가) 버튼을 눌러 파란색 체크(✓)를 켜세요. 마지막으로 맨 아래 [✨ AI로 자기소개 자동 작성하기 (추천)] 버튼과 [💾 내 프로필 · 사무소 정보 저장하기] 버튼을 누르세요.

2. **✅ 화면에서 무엇이 바뀌나요?**
   • 개업 연도(예: 2006)를 적으면 '경력 20년차'가 자동으로 계산됩니다.
   • 지역과 자산 버튼을 켜고 [✨ AI로 자기소개 자동 작성하기]를 누르면 약 3초 만에 인사말이 자동으로 작성되고 바로 저장됩니다. '영등포·강남 권역에서 20년간 꼬마빌딩과 수익형 빌딩을 전문 중개해 온...'과 같은 정중한 문장입니다.

3. **💡 왜 이 기능이 중요한가요? (중개 실무 포인트)**
   나머지 항목(블로그·유튜브 주소 등)은 운영하는 경우에만 적으면 됩니다. 없으면 비워 두어도 문제없습니다.
