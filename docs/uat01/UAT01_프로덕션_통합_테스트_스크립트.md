## 1. 테스트 목적 및 범위
- CREDEAL 플랫폼의 핵심 기능인 매각(Sale) 딜카드, IM(Investment Memorandum) 생성, 매칭·소통관리함(인박스) 파이프라인을 실제 프로덕션 환경에서 검증합니다.
- **4가지 UI 입력 채널 검증**: 메모 텍스트, 사진 첨부, xlsx 렌트롤, 바텀시트

## 2. 테스트 환경 및 계정
- **프로덕션 URL**: [https://cre-dealcard.vercel.app](https://cre-dealcard.vercel.app)
- **PC 브라우저**: Chrome 120+ (필수), Safari 17+ (권장)
- **모바일 디바이스**: iPhone 15 (Safari) 또는 Galaxy S24 (Chrome)
- **PowerPoint 뷰어**: MS Office 또는 Google Slides
- **네트워크**: 안정적인 WiFi 환경

### 테스트 계정

|:---|:---|:---|:---:|:---|
| 시니어 중개인 | broker-senior@credeal-test.com | Test!2026Sr | Pro | 전체 테스트 진행 |

### 로그인 방법
1. PC 또는 모바일 브라우저에서 `https://cre-dealcard.vercel.app`에 접속합니다.
2. 화면 중앙 또는 우측 상단의 **[로그인]** 버튼을 클릭합니다.
3. 이메일 입력란에 위의 테스트 계정(예: `broker-senior@credeal-test.com`)을 입력합니다.
4. 비밀번호 입력란에 비밀번호를 입력합니다.
5. **[로그인]** 버튼을 클릭합니다.
6. 로그인 성공 시 메인 대시보드 화면이 나타나는지 확인합니다. 📸 (로그인 완료 화면 캡처)

### xlsx 렌트롤 템플릿 다운로드 방법
다중 임차인 데이터 입력 테스트(P1, P5)를 위해 렌트롤 엑셀 템플릿이 필요합니다.
1. 상단 메뉴에서 **[스튜디오]** → **[임대(Lease)]** 탭으로 이동합니다.
2. 화면 중앙 우측의 **[엑셀 템플릿 다운로드]** 버튼을 클릭합니다.
3. 내 컴퓨터에 `rentroll_template.xlsx` 파일이 다운로드되었는지 확인합니다.
4. 해당 엑셀 파일을 열어 미리 데이터 입력을 준비합니다.

## 15. 용어 설명
- **캡레이트 (Cap Rate)**: 부동산의 순수익을 매매가격으로 나눈 비율. 투자 수익률 평가 지표.
- **NOI (Net Operating Income)**: 총 임대수입에서 영업경비를 제외한 순수 운영 수익.
- **환산보증금**: 보증금에 월세의 100배를 더한 금액.
- **용적률 (FAR)**: 대지면적에 대한 건축물 연면적 비율. 개발 가능성의 척도.
- **블라인드 처리**: 정보 노출 보안 기법 (건물명, 상세 주소, 임차인 이름 차단).
- **PII**: 개인을 식별할 수 있는 민감 개인 정보(주소, 상호, 이름 등).
- **NDA (비밀유지서약)**: 추가 민감 정보 공개 전 양자 간 동의하는 서약.
- **Gate**: 고객의 관심 단계에 맞춰 점진적으로 정보를 오픈하기 위한 인입 장치(G1/G2/G3).
