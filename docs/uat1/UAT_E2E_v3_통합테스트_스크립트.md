### 2.1 환경 요구사항
- [ ] Vercel 프로덕션 배포 완료 (최신 커밋 반영)
- [ ] 환경변수 확인:

  - NEXT_PUBLIC_KAKAO_APP_KEY 설정됨 (카카오 공유용)
