## 축별 상세 평가

### ① 시장 규모 & 성장성 (MKT)

| 항목 | OEM 매칭 (5/5) | 수출 에이전트 (4/5) | 유통 큐레이션 (4/5) |
|:---|:---|:---|:---|
| **TAM** | K-뷰티 OEM 시장 **~8조 원** | 수출 바우처 **~5천억** + 무역회사 시장 | K-뷰티 유통 거래 **~6조 원** |
| **SAM** | 국내 OEM 2,000사 × 해외 바이어 | 수출 중소기업 96,000사 중 디지털 전환 대상 | 해외 유통거래선 50,000+ 중 K-뷰티 특화 |
| **CAGR** | 12~15% (K-뷰티 수출 성장) | 8~10% (수출 중소기업 증가) | 10~12% (K-뷰티 유통 채널 확대) |
| **근거** | 가장 큰 TAM. 중국·동남아·미국·중동 모두 K-뷰티 OEM 수요 폭증. 글로벌 클린뷰티·K-뷰티 트렌드가 수요를 견인 | SAM이 넓지만 과금 가능 규모는 바우처 사업 의존도가 높음. 1인 무역회사 15,000개사는 유망하나 ARPU 낮음 | TAM은 OEM보다 작지만, 유통 마진율이 높아 건당 거래 가치가 큼. 구독 박스·라이브커머스 등 신채널 성장 |

**판정**: OEM이 시장 규모 면에서 압도적. 수출 에이전트는 넓지만 얕고, 유통 큐레이션은 건당 가치가 높음.

### ② 수익 모델 명확성 (REV)

| 항목 | OEM 매칭 (5/5) | 수출 에이전트 (3/5) | 유통 큐레이션 (4/5) |
|:---|:---|:---|:---|
| **핵심 과금** | 매칭 성사 수수료 (거래액의 2~5%) | SaaS 월 구독료 | 큐레이션 성사 수수료 + 카탈로그 생성 건당 |
| **보조 과금** | 프리미엄 제안서 생성 (건당), 공급사 프로필 부스트, 인증 검증 대행 | 제안서 생성 건당 과금, 바이어 DB 접근 요금 | 트렌드 리포트 구독, 프리미엄 분석, 브랜드 부스트 |
| **ARPU 추정** | 거래 건당 \$500~\$5,000 (OEM 계약 규모 대비) | 월 \$50~\$200 (중소기업 SaaS) | 큐레이션 세트당 \$300~\$2,000 |
| **LTV** | 높음 (재주문 반복) | 중간 (이탈 위험) | 높음 (시즌별 반복) |

```
수익 모델 다층성:

OEM 매칭 ████████████████████ 5층
  ├─ 매칭 수수료 (거래액 %)
  ├─ 제안서 생성 (건당)
  ├─ 공급사 프로필 광고
  ├─ 인증 검증 대행
  └─ 프리미엄 데이터 (시장 분석)

수출 에이전트 ████████████ 3층
  ├─ SaaS 구독 (월정액)
  ├─ 문서 생성 (건당)
  └─ 바이어 DB 접근

유통 큐레이션 ████████████████ 4층
  ├─ 큐레이션 수수료 (성사 건당)
  ├─ 카탈로그 생성 (건당)
  ├─ 트렌드 리포트 구독
  └─ 브랜드 프로모션
```

**판정**: OEM이 가장 명확하고 다층적. 수출 에이전트는 SaaS 월정액 의존이라 ARPU가 낮고, 중소기업 대상 가격 민감도 높음.

### ④ 고객 획득 용이성 (ACQ)

| 항목 | OEM 매칭 (2/5) | 수출 에이전트 (3/5) | 유통 큐레이션 (4/5) |
|:---|:---|:---|:---|
| **콜드스타트 문제** | **심각** — 양면 마켓플레이스 (공급사+바이어 동시 필요) | 편측 — 공급사만 먼저 확보 가능 | **약함** — 브랜드가 자발적으로 카탈로그 등록 유인 |
| **초기 공급 확보** | OEM 공장 50개사 수동 온보딩 필요 (3~6개월) | 제조사 홍보 통해 셀프 등록 유도 가능 | K-뷰티 브랜드 자체가 유통 채널 확보에 적극적 |
| **초기 수요 확보** | 해외 바이어 접근 채널 부재 (전시회 의존) | 바이어 DB 수동 구축 필요 | 유통사/바이어에게 "무료 카탈로그 생성" 미끼 제공 가능 |
| **Go-to-Market** | 전시회 (Cosmoprof, In-Cosmetics) + B2B 마케팅 | KOTRA/중기부 협업 + 수출 바우처 | 유통사 직접 영업 + 브랜드 셀프 등록 |
| **PMF 검증 속도** | 느림 (매칭 성사까지 2~3개월) | 중간 (SaaS 가입 후 활성 사용까지 1개월) | **빠름** (카탈로그 1건 생성으로 가치 즉시 체감) |

```
PMF 검증까지의 거리:

OEM 매칭
  공급사 확보(3개월) → 바이어 확보(2개월) → 매칭(1개월) → 성사(2개월)
  ════════════════════════════════════════════════════════ 8개월

수출 에이전트
  제조사 가입(1개월) → 문서 생성(즉시) → 바이어 접촉(2개월) → 성과(2개월)
  ══════════════════════════════════════════ 5개월

유통 큐레이션
  브랜드 등록(2주) → 카탈로그 생성(즉시) → 유통사 제안(2주) → 피드백(1개월)
  ══════════════════════════ 2개월 ← 최단
```

**판정**: 유통 큐레이션이 압도적으로 유리.
- **"무료 카탈로그 PPTX 생성"** 만으로도 초기 사용자 견인 가능 (Product-Led Growth)
- 브랜드 측은 유통 채널 확보에 항상 목마르므로 자발적 등록 유인이 강함
- OEM 매칭은 양면 콜드스타트가 **최대 리스크**

### ⑥ 확장성 & 플랫폼 효과 (SCALE)

| 항목 | OEM 매칭 (4/5) | 수출 에이전트 (5/5) | 유통 큐레이션 (4/5) |
|:---|:---|:---|:---|
| **업종 확장** | K-뷰티 → K-푸드 → K-패션 → 산업재 | **모든 수출 업종** 범용 | K-뷰티 → K-푸드 → K-리빙 |
| **지역 확장** | 한국 OEM → 동남아 OEM → 글로벌 | **글로벌 범용** | 한국 → 일본 → 동남아 브랜드 |
| **네트워크 효과** | 양면 (공급사↔바이어) | 한 쪽 (에이전트 커뮤니티) | 양면 (브랜드↔유통사) + 큐레이터 |
| **데이터 플라이휠** | 매칭 데이터 축적 → 정확도 향상 | 딜 히스토리 → 바이어 인텐트 학습 | 큐레이션 성과 → 추천 정확도 + 트렌드 예측 |
| **멀티 테넌트** | 지역별 → 산업별 격리 | **업종 무관 범용** SaaS | 채널별 → 카테고리별 격리 |

**판정**: 수출 에이전트가 **확장성 최고**. 업종·지역에 무관하게 범용 적용 가능한 SaaS 모델. 단, 범용성이 높은 만큼 특화 차별화가 약해지는 트레이드오프.

### 전략 제언

> [!IMPORTANT]
> **유통 큐레이션을 1순위 MVP로 추천하는 3가지 이유**
> 1. **최소 리스크**: 콜드스타트 약함 + 경쟁사 부재 + 가장 빠른 PMF 검증 (2개월)
> 2. **최대 효율**: 코드 재사용 65% + 16주 최단 개발 + PPTX 카탈로그가 즉시 가치 전달
> 3. **확장 기반**: 브랜드·상품 DB가 쌓이면 OEM 매칭·수출 에이전트로 자연스러운 확장

> [!TIP]
> **OEM 매칭과 수출 에이전트는 동점(27점)이지만 성격이 다릅니다:**
> - OEM 매칭 = **시장 규모·수익 모델이 강하지만 진입 장벽 높음** (공장 DB 확보)
> - 수출 에이전트 = **확장성·정책 연계 강하지만 수익화 느림** (SaaS 전환율)
>
> 따라서 유통 큐레이션 MVP로 상품·브랜드 DB를 확보한 뒤, OEM 매칭을 2차로 붙이는 것이 최적 경로입니다.
