## Part 1. 비전 & 개요

### 1.1 한 줄 정의

> **CureX**는 해외 유통사의 상품 요청을 AI가 분석하여, 한국 브랜드 제품을 자동 큐레이션하고,
> 채널 맞춤형 카탈로그·견적·물류 계획을 원스톱으로 생성하는 **B2B 유통 큐레이션 SaaS**입니다.

### 1.2 미션

**"한국 소비재 브랜드와 글로벌 유통사 사이의 정보 비대칭을 AI로 해소한다."**

현재 K-뷰티 유통 거래에서 브랜드는 "어떤 유통사가 내 제품을 원하는지" 모르고,
유통사는 "수천 개 한국 브랜드 중 내 채널에 맞는 제품이 무엇인지" 모릅니다.
CureX는 이 양방향 탐색 비용을 90% 절감합니다.

### 1.3 비전 로드맵

```
2026 Q4    K-뷰티 유통 큐레이션 MVP 런칭
2027 H1    K-뷰티 확장 + OEM 매칭 모듈 추가
2027 H2    K-푸드 · K-리빙 카테고리 확장
2028 H1    동남아 · 일본 브랜드 소싱 확장 (Korea → Asia)
2028 H2    글로벌 유통 큐레이션 플랫폼 (Asia → Global)
```

## Part 2. 시장 분석

### 2.1 시장 규모 (TAM → SAM → SOM)

```
┌──────────────────────────────────────────────────────────────┐
│  TAM (Total Addressable Market)                              │
│  글로벌 뷰티 유통 B2B 거래: ~$180B (약 240조 원)              │
│  ┌────────────────────────────────────────────────────┐      │
│  │  SAM (Serviceable Addressable Market)               │      │
│  │  K-뷰티 수출 유통 거래: ~$6B (약 8조 원)              │      │
│  │  ┌──────────────────────────────────────────┐       │      │
│  │  │  SOM (Serviceable Obtainable Market)      │       │      │
│  │  │  초기 타겟 유통 거래: ~$300M (약 4,000억)   │       │      │
│  │  │  (해외 유통거래선 상위 5,000개사 × 건당 $60K) │       │      │
│  │  └──────────────────────────────────────────┘       │      │
│  └────────────────────────────────────────────────────┘      │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 시장 성장 드라이버

| 드라이버 | 영향도 | 설명 |
|:---|:---|:---|
| K-뷰티 글로벌 확산 | ★★★★★ | K-뷰티 수출 CAGR 12~15%, 미국·중동·LATAM 신규 시장 진입 가속 |
| 유통 채널 다변화 | ★★★★☆ | 라이브커머스, 구독 박스, D2C, 소셜커머스 등 신채널 폭증 |
| 클린뷰티 · 비건 트렌드 | ★★★★☆ | 글로벌 규제 강화 → 성분 투명성·인증 검증 수요 증가 |
| 중소 브랜드 수출 증가 | ★★★☆☆ | 대기업 위주 → 인디 브랜드 직수출 확대 |
| AI/자동화 수용성 증가 | ★★★☆☆ | B2B 거래에서 AI 도구 활용 의지 상승 |

### 2.3 경쟁 환경

| 플레이어 유형 | 대표 | 강점 | 약점 | CureX 차별화 |
|:---|:---|:---|:---|:---|
| **글로벌 B2B 마켓플레이스** | Alibaba, Faire | 방대한 DB, 결제 인프라 | K-뷰티 비특화, 품질 검증 부재 | K-뷰티 특화 AI 큐레이션 |
| **전시회 기반** | Cosmoprof, CPHI | 대면 신뢰, 샘플 확인 | 연 1~2회, 사후 관리 부재 | 365일 디지털 큐레이션 |
| **유통사 자체 MD** | Sephora MD팀, Olive Young | 채널 전문성 | 한국 시장 탐색 한계, 비효율 | AI 기반 상품 추천 + 자동 카탈로그 |
| **한국 수출 에이전시** | 코스인, 뷰티플, 각종 에이전시 | 현지 네트워크 | 수작업, 확장 한계 | 자동화 + 데이터 기반 스케일 |
| **B2B 정보 플랫폼** | BeautySourcing, Cosmotrend | 데이터베이스 | 매칭 없음, 카탈로그 미생성 | 매칭 + 카탈로그 + 견적 원스톱 |

> **핵심 포지셔닝**: "검색 도구"가 아닌 **"AI 머천다이저"** — 상품 발굴부터 카탈로그 납품까지 원스톱.

### 3.3 핵심 기능 상세

#### 기능 ①: AI 큐레이션 세트 최적화

```
Input:
  유통사 Brief (카테고리, 예산, 테마, 소비자 타겟, 시즌)
  + 상품 DB (매칭 통과 상품 풀)

Process:
  1. Stage 1-3 매칭으로 후보 상품 선별 (100+ → 30~50개)
  2. 세트 최적화 알고리즘 실행:
     - 카테고리 분산 제약 (스킨케어 40% + 메이크업 30% + 기타 30%)
     - 가격대 분산 제약 (엔트리 30% + 미드 50% + 프리미엄 20%)
     - 브랜드 다양성 (최소 5개 브랜드)
     - 트렌드 커버리지 (클린뷰티/비건 등 테마 반영)
  3. 최적 세트 + 2~3개 대안 세트 제시

Output:
  추천 세트 (15~25 SKU) + 대안 A/B
  + 세트별 종합 점수 (매칭도, 마진, 트렌드 적합도)
  + AI 큐레이션 근거 설명
```

#### 기능 ②: 카탈로그 PPTX 자동 생성

```
Input:
  확정된 CurationSet + 채널 프로파일 + 디자인 토큰

Process:
  1. 채널 프로파일에 따라 슬라이드 시퀀스 결정
     (prestige: 스토리텔링 중심 20p / mass_market: 가격 중심 12p)
  2. 25 Slide Archetypes에서 해당 아키타입 선택
  3. 상품 데이터 → 슬라이드별 배치 (imlib 레이아웃 엔진)
  4. Sharp 이미지 파이프라인: 제품 사진 최적화
  5. Quality Gates 14개 통과 검증
  6. 큐레이터 승인 → 발행

Output:
  브랜디드 카탈로그 PPTX (16:9, 12~20p)
  + 웹 뷰어 (모바일 반응형)
  + PDF 변환본
```

#### 기능 ③: 마진 시뮬레이터 & 견적 자동화

```
Input:
  상품 단가 (MOQ별) + 물류 조건 (FOB/CIF/DDP) + 목적지국

Process:
  1. 상품별 원가 계산 (FOB 기준)
  2. 운송비 자동 산출 (CBM 기반 해상/항공/특송)
  3. 관세·부가세 자동 적용 (DDP일 경우)
  4. 유통사 마진율 시뮬레이션
  5. 최종 소비자가 역산

Output:
  견적표 (PPTX/PDF/Excel)
  + 마진 시뮬레이션 차트
  + FOB vs CIF vs DDP 비교표
```

### 3.4 딜 파이프라인 FSM

```
brief_received → matched → curated → proposed → feedback → revised → ordered → shipped → delivered
      │                                   │          │
      └───────── (거절) ──────────────────┘          │
                                                     └─── (수정 요청) → revised → proposed
```

| 단계 | 설명 | 자동화 |
|:---|:---|:---|
| `brief_received` | 유통사 요청서 접수 | AI 파싱 자동 |
| `matched` | 상품 매칭 완료 | 3-Stage 엔진 자동 |
| `curated` | 큐레이션 세트 확정 | 세트 최적화 AI + 큐레이터 확인 |
| `proposed` | 카탈로그 발송 | PPTX 자동 생성 + 승인 |
| `feedback` | 바이어 피드백 수신 | 자동 수집 |
| `revised` | 수정 반영 | 부분 자동 |
| `ordered` | 발주 확정 | PO 자동 생성 |
| `shipped` | 선적 | 추적번호 연동 |
| `delivered` | 인도 완료 | 자동 확인 |
