## Part 1. 비전 & 개요

### 1.1 한 줄 정의

> **SkinBridge**는 해외 고객의 피부 고민을 AI가 분석하여 한국 내 최적의 피부과·시술 클리닉을 매칭하고,
> 시술 제안서·견적·일정·통역·숙박까지 원스톱으로 설계하는 **K-더마 메디컬 큐레이션 플랫폼**입니다.

### 1.2 미션

**"세계 최고 수준의 한국 피부 시술을, 언어·정보·신뢰의 장벽 없이 누구나 경험할 수 있게 한다."**

한국은 인구 대비 피부과 밀집도 세계 1위, 비수술 에스테틱 기술력 최상위권이지만,
해외 환자는 "어떤 클리닉이 좋은지", "이 의사가 진짜 전문인지", "가격이 적정한지" 알 방법이 없습니다.
SkinBridge는 **Claim & Evidence 출처 증명**으로 이 정보 비대칭을 해소합니다.

### 1.3 비전 로드맵

```
2027 Q1    K-더마 시술 매칭 MVP (피부과 레이저·주사 특화)
2027 Q2    패키지 상품화 (시술+숙박+통역+관광)
2027 H2    성형외과·치과 확장 + 유통 큐레이션 통합
2028 H1    동남아 클리닉 확장 (태국·싱가포르)
2028 H2    글로벌 메디컬 에스테틱 플랫폼
```

## Part 3. 고객 여정 & 서비스 설계

### 3.1 환자 여정 (Patient Journey)

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Patient Journey                                 │
├──────────┬──────────┬──────────┬──────────┬──────────┬──────────┬─────┤

│ SNS/검색  │ 피부고민  │ AI 3-    │ 시술제안  │ 일정확정  │ 내원시술  │경과 │
│ 유튜브    │ 사진첨부  │ Stage    │ PPTX     │ 숙박연계  │ 통역동행  │체크 │
```

### 3.2 서비스 구성 — 3가지 상품 라인

#### 상품 A: Self-Match (셀프 매칭) — 무료/저가

```
타겟: 정보 탐색 단계, 가격 민감 고객
────────────────────────────────────
흐름:
  피부 고민 입력 (텍스트/사진) 
  → AI 시술 추천 (레이저? 보톡스? 필러?)
  → 클리닉 3~5개 자동 매칭 (S/A/B 등급)
  → 클리닉 프로필·가격·리뷰 비교
  → 직접 예약 요청 (SkinBridge 통해)

수익: 예약 성사 시 커미션 10%
```

#### 상품 B: Curated Package (큐레이티드 패키지) — 핵심 상품

```
타겟: 확실한 시술 의향, 올인원 원하는 고객
─────────────────────────────────────────
흐름:
  상담 폼 작성 (고민·예산·일정·선호)
  → 전문 코디네이터 + AI 공동 매칭
  → 맞춤 시술 제안서 PPTX 제공
    (클리닉 프로필 + B/A + 시술 계획 + 견적 + 일정)
  → 환자 피드백 → 수정 → 확정
  → 예약 + 숙박 + 통역 + 공항픽업 일괄 설계
  → 시술 진행 + 사후 경과 체크 (원격)

수익: 패키지 총액의 15~20%
건당 예상: $300~$1,000
```

#### 상품 C: VIP Concierge (VIP 컨시어지) — 프리미엄

```
타겟: 중동·미국 고액 고객, 프라이버시 중시
──────────────────────────────────────────
흐름:
  1:1 전담 코디네이터 배정
  → 화상 상담 → 맞춤 프로그램 설계 (3일~1주 체류)
  → 프리미엄 클리닉 독점 예약
  → 호텔 스위트 + 전용 통역 + 관광 일정
  → 귀국 후 3개월 원격 팔로업

수익: 프로그램 총액의 20~25%
건당 예상: $1,500~$5,000
```

### 5.4 시술 일정 최적화 알고리즘 (신규)

```typescript
interface TreatmentSequenceInput {
  treatments: {
    type: TreatmentCategory;
    duration: number;              // 시술 소요 시간 (분)
    recoveryDays: number;          // 시술 후 회복 일수
    canCombineSameDay: boolean;    // 당일 타시술 병행 가능 여부
    requiresFasting: boolean;      // 공복 필요 여부
    sequence_constraints: string[]; // e.g., "must_be_before:filler"
  }[];
  stayDuration: number;            // 총 체류 일수
  arrivalDate: string;
  departureDate: string;
}

interface OptimizedSchedule {
  days: {
    date: string;
    dayNumber: number;
    activities: {
      time: string;
      type: 'treatment' | 'recovery' | 'consultation' | 'free_time';
      treatment?: string;
      clinic?: string;
      notes: string;
    }[];
  }[];
  totalTreatmentDays: number;
  totalRecoveryDays: number;
  freeDays: number;               // 관광·쇼핑 가능일
  feasibility: 'optimal' | 'tight' | 'insufficient_stay';
  suggestion?: string;            // 체류일 부족 시 권장 연장
}

// 최적화 규칙:
// 1. 회복이 긴 시술(레이저) → 먼저
// 2. 주사류(보톡스, 필러) → 나중에 (즉시 효과, 회복 짧음)
// 3. 당일 병행 가능한 시술은 같은 날에 묶기
// 4. 출국 전날은 시술 없음 (비행기 내 붓기 고려)
// 5. 도착일은 상담 + 피부 분석만
```
