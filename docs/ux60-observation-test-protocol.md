# 60대 상업용 빌딩 중개사 관찰 테스트 프로토콜 (Phase 6)

> **목적**: 서울 소재 60대 개인 소형 상업용 빌딩 중개사(IT 비숙련층) 3~5명을 대상으로 **① 딜카드 생성·공유, ② 한국형 PPTX Basic IM(9면) 다운로드, ③ 주간 고객 소식지(모바일 매거진) 발행·이메일 발송·카톡 링크 복붙**의 3대 핵심 여정 무마찰(Zero-Friction) 달성 여부를 실측합니다.

---

## 1. 참가자 기준 및 테스트 환경

### 참가자 구성 (3~5명)
- **연령대**: 만 58세 ~ 68세
- **업종**: 서울(강남·서초·마포·성동·종로 등) 소형 빌딩/꼬마빌딩 전담 공인중개사 (1인 또는 소규모 사무소 대표)
- **IT 숙련도**: 카카오톡(PC·모바일) 및 엑셀 기본 열람은 가능하나, 복잡한 웹 SaaS나 영문 메뉴에는 익숙하지 않은 분

### 테스트 환경 (중개사무소 현장 또는 동일 환경 세팅)
- **주 기기 (PC 중심)**:
  - 사무실 데스크톱 또는 노트북 (Windows 10/11, Chrome/Edge, 디스플레이 배율 **125%** 권장)
  - PC 카카오톡 로그인 상태 (나에게 보내기 테스트용)
- **보조 기기 (모바일)**:
  - 참가자 본인 스마트폰 (글자 크기 115~130% 설정 상태 그대로 유지)

---

## 2. 진행 원칙 (Think-Aloud & 무개입 관찰)

1. **사전 설명 최소화**: 기능 사용법을 미리 설명하지 않고, 상황 시나리오만 제시합니다.
2. **막힘 지점(Hesitation) 기록**: 참가자가 5초 이상 마우스를 멈추거나 *"이게 무슨 뜻이지?"*, *"어디를 눌러야 하지?"*라고 말할 때 화면 위치와 원인을 즉시 기록합니다.
3. **도움 개입 기준**: 60초 이상 스스로 진행하지 못할 때만 최소 힌트를 제공하고, 해당 단계는 **개선 필요(Fail)**로 기록합니다.

---

## 3. 3대 핵심 과업 시나리오 및 합격 기준 (Pass/Fail)

### 과업 1: 주소 하나로 딜카드 만들고 카톡으로 보내기 (목표: 2분 이내)
- **시나리오**:
  > *"방금 건물주로부터 역삼동 꼬마빌딩 매각 의뢰를 받으셨습니다. 주소만 넣어서 고객에게 보낼 '딜카드'를 만들고, PC 카카오톡 '나에게 보내기'로 링크를 보내보세요."*
- **관찰 포인트**:
  - [ ] 홈 화면(`중개 업무 홈`)에서 `새 물건(딜카드) 만들기` 버튼을 5초 이내에 찾는가?
  - [ ] 처음 써보는 경우 `예시 매물로 10초 만에 체험해보기` 칩 또는 주소 검색을 막힘없이 사용하는가?
  - [ ] 건축물대장·토지·주변 실거래 자동 조회 대기 중 불안해하지 않고 진행 상태를 이해하는가?
  - [ ] 완성된 딜카드에서 `카톡 공유` 또는 `링크 복사`를 눌러 카카오톡 채팅창에 붙여넣기(`Ctrl+V`)까지 성공하는가?
- **정량 합격 기준**: 총 소요 시간 **120초 이하**, 막힘 횟수 **0회**

---

### 과업 2: PC에서 한국형 9면 PPTX 투자설명서(Basic IM) 파일 받기 (목표: 3분 이내)
- **시나리오**:
  > *"매수 희망 고객이 사무실에 방문하기로 해서 출력·편집 가능한 파워포인트(PPTX) 투자설명서가 필요합니다. 방금 만든 물건의 9면 표준 투자설명서를 만들어서 PC에 파워포인트 파일로 저장해보세요."*
- **관찰 포인트**:
  - [ ] 딜카드 상세 화면에서 `9면 표준 투자설명서(Basic IM)` 생성 버튼을 한눈에 찾는가?
  - [ ] 5대 투자 전략(`임대수익`, `자가사용`, `개발형`, `운영형`, `단기매매`)의 한글 한 줄 설명을 읽고 매물에 맞는 전략을 스스로 고르는가?
  - [ ] (선택) 임대차 현황표(엑셀) 업로드 시 `자동 불러오기` 및 호실 검증(V12) 안내 문구를 이해하는가?
  - [ ] 4단계 진행 안내(`① 공부 조회` → `② 수익률·실거래 계산` → `③ 9면 해설 작성` → `④ 도면·품질 검수`)를 보고 안심하고 기다리는가?
  - [ ] 생성 완료 후 **승인 화면** 또는 **딜카드 관리 패널**에서 `📊 PPTX 파일 받기 (9면)` 버튼을 눌러 `.pptx` 파일을 PC에서 즉시 여는가?
- **정량 합격 기준**:
  - PPTX 다운로드 버튼 발견 시간 **5초 이내**
  - 워터마크 없는 정식 9면 PPTX 파일 오픈 성공률 **100%**
  - 입력 누락 발생 시 한글 오류 안내(`건물 정보 보완하고 다시 만들기`)를 통한 자가 복구 성공률 **100%**

### 과업 3: 5분 간편 모드로 주간 소식지 발행 및 이메일 발송·카톡 복붙 (목표: 5분 이내)
- **시나리오**:
  > *"방금 만든 매물을 이번 주 고객 소식지(뉴스레터)에 실어서, 이메일 구독 고객에게는 자동 발송하고 카톡 고객에게는 인사말과 함께 링크를 복사해 보내보세요."*
- **관찰 포인트**:
  - [ ] 딜카드 화면의 `📰 이번 주 고객 소식지에 이 매물 소개하기` 버튼 또는 하단 메뉴 `소식지` 탭을 눌러 **5분 간단 모드**로 진입하는가?
  - [ ] 상단 제목(`고객 소식지 편집실`)과 4단계 간단 작성 흐름(시장 온도 → AI 한마디 → 매물 선택 → 뉴스 선택)을 스크롤만으로 막힘없이 완료하는가?
  - [ ] `발행하기` 후 완료 창에서 **이메일 자동 발송 결과**와 **카카오톡·문자 공유용 링크 복사**의 차이를 명확히 인지하는가?
  - [ ] `구독자 관리` 탭에서 `💬 인사말 + 링크 복사` 버튼을 눌러 카톡 단톡방/1:1 채팅창에 안내문과 링크를 한 번에 붙여넣는가?
- **정량 합격 기준**: 총 소요 시간 **5분(300초) 이하**, 영문/전문용어 질문 횟수 **0회**
