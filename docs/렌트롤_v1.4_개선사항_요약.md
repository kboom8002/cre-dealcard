# CREDEAL 렌트롤 표준 양식 v1.4 — 개선 사항 요약

작성일: 2026-10-05 · 기준: v1.3 → v1.4

## 한 줄 요약

v1.3의 계산 오류 3건을 고치고(통합계약 판정, 전용평당 월비용, 평가 기준일), IM 작성에 필요한 입력(매각가·연면적·시장 임대료·기타수입, 근거·렌트프리·입금 확인)과 IM 연계 검증 11개를 추가했습니다. 기존 A~Y열의 위치와 입력 방식은 그대로입니다.

## 1. 오류 수정 (가상 데이터로 다시 계산해 확인)

| # | v1.3 문제 | v1.4 수정 | 확인 결과 |
|---|---|---|---|
| 1 | 기입요령대로 통합계약의 대표 행에만 월세를 적으면 R1 판정이 **R0 미달** | 새 AD열 「금액 판정」으로 판정. 그룹마다 금액 행이 정확히 1개인지 검사 | 1F+2F 통합계약 예시: R0 미달 → **R3 표준형** |
| 2 | 통합계약의 전용평당 월비용을 대표 행 전용면적으로만 나눠 **과대 계산** | 그룹 전체 전용면적 합으로 나눔 (그룹에 전용면적 빈 행이 있으면 보류) | 227,273원 → **126,263원/전용평** |
| 3 | 평가 기준일 =TODAY() → 파일을 열 때마다 갱신권 잔여·계약 상태가 바뀜 | 평가 기준일 = 렌트롤 기준일(C5). C5가 비면 TODAY()로 대체 + 경고 | 같은 렌트롤이면 언제 열어도 같은 숫자 |
| 4 | 조건부 서식이 통합계약 비대표 행의 빈 보증금·월세를 오류(빨강)로 표시 | 비대표 행(계약그룹 있음)은 경고에서 제외 | — |
| 5 | 기입요령에 비대표 행에 적을 항목이 불명확 (R3 판정 실패 원인) | 적용법령·최초 계약일·대항력·근거도 **행마다** 적는다고 명시 | — |

## 2. 추가된 입력

**렌트롤 시트 H3:O8 — IM 연계 입력**

| 칸 | 항목 | 쓰임 |
|---|---|---|
| J3 | 매각(희망)가(원) | 단순 수익률 정본 계산 |
| J4 | 연면적(㎡, 건축물대장) | 임대면적 합계 대조 (호실 누락 감지) |
| J5~J7 + M5~M7 | 시장 임대료 1층·지상층·지하층(원/전용평·월) + 출처·조사일 | R3 임대료 정상화 시뮬 |
| J8 + M8 | 기타수입(원/월) + 내역 | 주차·안테나·광고 수입, 수익률 별도 줄 |

**렌트롤 시트 Z~AD열 — 행별 항목**

| 열 | 항목 | 입력 | 쓰임 |
|---|---|---|---|
| Z | 근거 | 계약서 원본 / 매도인 렌트롤 / 구두 | IM 렌트롤 장의 출처 배지 |
| AA | 렌트프리 잔여(개월) | 숫자 | 수익률에 "렌트프리 반영 전" 표시 |
| AB | 입금 확인(최근 12개월) | 정상 / 연체 / 미확인 | 연체 시 유의사항 장으로 이동 |
| AC | 만기 구간 (자동) | — | 만료 경과 / 12개월 내 / 12개월 초과 → 스태킹 플랜 |
| AD | 금액 판정 (자동) | — | 월세 누락 / 관리비 누락 / 금액 중복 / OK |

## 3. 자동검증 시트 — v1.4 추가 검증 (33행~)

| 코드 | 항목 | 판정 기준 |
|---|---|---|
| V01 | 통합계약 금액 | 월세 누락·금액 중복 0건이어야 발행 |
| V02 | 평가 기준일 | 렌트롤 기준일로 고정됐는지 |
| V03 | 임대면적 합 ÷ 연면적 | 75% 미만이면 호실 누락, 100% 초과면 면적 오기 의심 |
| V04 | 단순 수익률 | 연 월세 ÷ (매각가 − 보증금). IM 전 장의 정본 |
| V05 | 수익률 (기타수입 포함) | IM에는 별도 줄로 표기 |
| V06 | 12개월 내 만기 월세 비중 | 50% 초과면 IM 헤드라인에 반영 |
| V07 | 근거 분포 | 원본 / 매도인 / 구두 / 미기재 건수 |
| V08 | 입금 확인 | 연체·미확인 건수 |
| V09 | 렌트프리 호실 | 1건 이상이면 수익률 단서 |
| V10 | 시장 임대료 입력 | 금액·출처 칸 수 |
| V11 | R3+ 고품질 IM 준비 | R3 + 시장 임대료(출처 포함) 1칸 이상 + 근거 전 호실 |

해상도 판정(R1·R2)은 AD열 결과를 쓰도록 바꿨고, R3 조건 문구에 "통합계약의 비대표 행 포함"을 명시했습니다.

## 4. 바뀌지 않은 것

- A~Y열의 위치, 이름, 드롭다운 값, 단위(㎡·원·VAT 별도)
- 예시 행(13행)과 「예시 행」 자동 제외 규칙
- 환산보증금 지역 기준, 상임법·갱신권 계산식

## 5. 시스템 반영이 필요한 것

- 컬럼정의 시트에 새 항목의 업로드 필드명을 **제안값**으로 적었습니다 (evidence_level, rent_free_months, payment_status, asking_price_krw, gfa_sqm, market_rent_*, other_income_krw). 업로드 파서와 원장(lease_ledger)에 반영해야 IM에서 쓸 수 있습니다.
- 자동검증 V01(금액 중복)·V04(수익률)를 시스템 발행 차단 규칙과 맞춰야 합니다.

## 미확인 사항

- 실제 Excel과 CREDEAL 업로드 파서로는 테스트하지 않았습니다. LibreOffice 재계산(수식 1,149개, 오류 0)과 가상 통합계약 데이터로만 확인했습니다.
- 2018년 10월 상가건물임대차보호법 개정 전 계약의 10년 적용 여부는 계산식에 반영하지 않았습니다 (IM 매뉴얼에서 "확인 필요"로 처리).
